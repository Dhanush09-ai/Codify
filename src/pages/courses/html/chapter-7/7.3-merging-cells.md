# Chapter 7: HTML Tables

## Section 3: Merging Cells

Sometimes a table needs one cell to cover **more than one column or row**.

For example, a result table might have a heading like:

```text
+--------------------------------+
|       Student Information      |
+------------+-------------------+
| Name       | Department        |
+------------+-------------------+
| Owais      | CME               |
+------------+-------------------+
```

Here, **Student Information** covers two columns.

HTML allows us to merge cells using:

```text
colspan → Merge columns
rowspan → Merge rows
```

> **Simple idea:** `colspan` merges cells horizontally, while `rowspan` merges cells vertically.

---

## 1. What Is Cell Merging?

Normally, each table cell occupies one column and one row.

Example:

```html
<table>
    <tr>
        <td>A</td>
        <td>B</td>
        <td>C</td>
    </tr>
</table>
```

The result has three separate cells:

```text
+---+---+---+
| A | B | C |
+---+---+---+
```

Sometimes we want one cell to cover multiple cells.

For example:

```text
+-----------+
|     A     |
+-----+-----+
| B   | C   |
+-----+-----+
```

This is where cell merging is useful.

---

## 2. The `colspan` Attribute

The `colspan` attribute allows a cell to span across multiple columns.

Example:

```html
<tr>
    <td colspan="2">Student Information</td>
</tr>
```

Here:

```text
colspan="2"
```

means the cell covers **2 columns**.

Conceptually:

```text
+---------------------------+
|    Student Information    |
+-------------+-------------+
| Name        | Department  |
+-------------+-------------+
```

---

## 3. Basic `colspan` Example

Consider a table with two columns:

```html
<table>

    <tr>
        <th>Name</th>
        <th>Marks</th>
    </tr>

    <tr>
        <td>Owais</td>
        <td>95</td>
    </tr>

</table>
```

Now suppose we want a heading above both columns.

We can use:

```html
<table>

    <tr>
        <th colspan="2">Student Result</th>
    </tr>

    <tr>
        <th>Name</th>
        <th>Marks</th>
    </tr>

    <tr>
        <td>Owais</td>
        <td>95</td>
    </tr>

</table>
```

The first header covers both columns.

---

## 4. Understanding `colspan`

Think of:

```html
<td colspan="3">Hello</td>
```

as:

```text
+-----------------------+
|         Hello         |
+-----------------------+
       3 columns
```

The number tells the browser how many columns the cell should occupy.

Examples:

```html
<td colspan="2">...</td>
```

→ covers 2 columns.

```html
<td colspan="3">...</td>
```

→ covers 3 columns.

```html
<td colspan="4">...</td>
```

→ covers 4 columns.

---

## 5. Real-World Example: College Timetable

A college timetable can have a common heading across several periods.

```html
<table>

    <tr>
        <th colspan="3">Monday Timetable</th>
    </tr>

    <tr>
        <th>9:00</th>
        <th>10:00</th>
        <th>11:00</th>
    </tr>

    <tr>
        <td>Maths</td>
        <td>HTML</td>
        <td>DBMS</td>
    </tr>

</table>
```

The heading:

```html
<th colspan="3">Monday Timetable</th>
```

covers all three columns.

## 6. The `rowspan` Attribute

The `rowspan` attribute allows a cell to span across multiple rows.

Example:

```html
<td rowspan="2">CME</td>
```

This cell covers **2 rows**.

Conceptually:

```text
+--------+---------+
|        | Subject |
|  CME   +---------+
|        | Marks   |
+--------+---------+
```

The `CME` cell extends vertically across two rows.

---

## 7. Basic `rowspan` Example

Consider:

```html
<table>

    <tr>
        <th>Department</th>
        <th>Subject</th>
    </tr>

    <tr>
        <td>CME</td>
        <td>HTML</td>
    </tr>

    <tr>
        <td>CME</td>
        <td>DBMS</td>
    </tr>

</table>
```

The department is repeated.

We can merge those cells using `rowspan`:

```html
<table>

    <tr>
        <th>Department</th>
        <th>Subject</th>
    </tr>

    <tr>
        <td rowspan="2">CME</td>
        <td>HTML</td>
    </tr>

    <tr>
        <td>DBMS</td>
    </tr>

</table>
```

Now one `CME` cell covers both subject rows.

---

## 8. Understanding `rowspan`

Think of:

```html
<td rowspan="3">CME</td>
```

as:

```text
+---------+
|         |
|         |
|   CME   |
|         |
|         |
+---------+
  3 rows
```

The number tells the browser how many rows the cell should occupy.

Examples:

```html
<td rowspan="2">...</td>
```

→ covers 2 rows.

```html
<td rowspan="3">...</td>
```

→ covers 3 rows.

```html
<td rowspan="4">...</td>
```

→ covers 4 rows.

---

## 9. `colspan` vs `rowspan`

The easiest way to remember them is:

```text
colspan → column → horizontal
rowspan → row    → vertical
```

### `colspan`

Merges across columns.

```html
<td colspan="3">...</td>
```

Concept:

```text
+-----------------------+
|       One Cell        |
+-----------------------+
```

### `rowspan`

Merges across rows.

```html
<td rowspan="3">...</td>
```

Concept:

```text
+-------+
|       |
| Cell  |
|       |
|       |
+-------+
```

---

## 10. Combining `colspan` and `rowspan`

Both attributes can be used in the same table.

Example:

```html
<table>

    <tr>
        <th colspan="3">Student Details</th>
    </tr>

    <tr>
        <th rowspan="2">Name</th>
        <th>Subject</th>
        <th>Marks</th>
    </tr>

    <tr>
        <td>HTML</td>
        <td>95</td>
    </tr>

</table>
```

Here:

```text
colspan → Student Details covers 3 columns
rowspan → Name covers 2 rows
```

## 15. Why Use Cell Merging?

Cell merging is useful when information naturally belongs to multiple rows or columns.

Common examples include:

* College timetables
* Exam schedules
* Financial reports
* Employee schedules
* Product comparison tables
* School result sheets
* Invoices
* Monthly reports

For example, an invoice might have:

```text
+----------------------+----------+
|        Invoice       |          |
+----------------------+----------+
| Product | Qty | Price          |
+---------+-----+----------------+
| Keyboard|  2  | ₹3000          |
+---------+-----+----------------+
|              Total | ₹3000      |
+--------------------+-----------+
```

A merged heading can make the structure easier to understand.

---

## 16. Important Rule: Adjust the Number of Cells

When using `colspan` or `rowspan`, remember that the merged cell takes the place of multiple normal cells.

For example:

```html
<tr>
    <td colspan="2">Student</td>
    <td>95</td>
</tr>
```

This row visually contains three columns:

```text
+----------------+------+
|    Student     |  95  |
+----------------+------+
    2 columns       1
```

You should **not** add another cell for the second column because `colspan="2"` already occupies it.

---

## 17. Understanding Cell Counting

Suppose a table has 4 columns.

This:

```html
<tr>
    <td colspan="2">A</td>
    <td>B</td>
    <td>C</td>
</tr>
```

occupies:

```text
A → 2 columns
B → 1 column
C → 1 column
```

Total:

```text
2 + 1 + 1 = 4 columns
```

This is an important concept when creating merged tables.

---

## 18. `rowspan` Cell Counting

Suppose:

```html
<td rowspan="3">A</td>
```

The cell occupies one column across three rows.

Conceptually:

```text
Row 1 → A
Row 2 → A
Row 3 → A
```

You should not create another cell in those positions because the merged cell already occupies them.

---

## 19. Common Mistake: Wrong `colspan`

Suppose a table has three columns:

```html
<tr>
    <th colspan="2">Student Result</th>
</tr>
```

The cell covers only two columns.

If the heading should cover all three columns, use:

```html
<tr>
    <th colspan="3">Student Result</th>
</tr>
```

The value of `colspan` should match the number of columns you want the cell to cover.

---

## 20. Common Mistake: Adding Extra Cells

Incorrect:

```html
<tr>
    <td colspan="2">Student</td>
    <td>Information</td>
    <td>Extra</td>
</tr>
```

If the table has three columns, this row occupies:

```text
2 + 1 + 1 = 4 columns
```

That creates an incorrect structure.

Always calculate the total number of columns occupied by the cells.

---

## 21. Common Mistake: Confusing `colspan` and `rowspan`

Remember:

```text
colspan → across columns
rowspan → across rows
```

If you want:

```text
+----------------+
|     Header     |
+----------------+
| A | B | C      |
+---+---+--------+
```

use:

```html
<th colspan="3">Header</th>
```

If you want:

```text
+------+------+
|      | B    |
|  A   +------+
|      | C    |
+------+------+
```

use:

```html
<td rowspan="2">A</td>
```

## 22. Styling Merged Cells

Merged cells can be styled normally with CSS.

Example:

```css
table {
    border-collapse: collapse;
}

th,
td {
    border: 1px solid black;
    padding: 10px;
    text-align: center;
}
```

HTML:

```html
<table>

    <tr>
        <th colspan="3">Student Results</th>
    </tr>

    <tr>
        <th>Name</th>
        <th>Subject</th>
        <th>Marks</th>
    </tr>

</table>
```

CSS does not change how `colspan` or `rowspan` works. It only controls the appearance.

## 24. Quick Comparison

| Attribute | Purpose       | Direction  | Example       |
| :-------- | :------------ | :--------- | :------------ |
| `colspan` | Merge columns | Horizontal | `colspan="3"` |
| `rowspan` | Merge rows    | Vertical   | `rowspan="2"` |

Easy way to remember:

```text
COLspan → COLumns
ROWspan → ROWs
```

---

## 25. Key Points

* Cell merging allows one cell to occupy multiple rows or columns.
* `colspan` merges cells across columns.
* `rowspan` merges cells across rows.
* `colspan="3"` means the cell occupies three columns.
* `rowspan="2"` means the cell occupies two rows.
* `colspan` is mainly horizontal.
* `rowspan` is mainly vertical.
* Both can be used together.
* A merged cell occupies the positions of the cells it replaces.
* Do not add extra cells where a merged cell already occupies space.
* Always consider the total number of columns when using `colspan`.
* Use merging when it represents a meaningful relationship in the data.
* CSS can be used to style merged cells.
