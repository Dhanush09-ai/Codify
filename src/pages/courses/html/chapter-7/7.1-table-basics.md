# Chapter 7: HTML Tables

## Section 1: Table Basics

Tables are used to display **structured data in rows and columns**.

You see tables in many real-world situations:

* Student marks
* Employee details
* Product prices
* Class timetables
* Exam schedules
* Monthly expenses
* Course information

For example:

```text
+------------+-------+-------+
| Student    | Maths | HTML  |
+------------+-------+-------+
| Owais      |  95   |  92   |
| Ahmed      |  88   |  90   |
| Rahul      |  91   |  87   |
+------------+-------+-------+
```

HTML provides several elements to create this structure.

> **Simple idea:** An HTML table organizes related data into rows and columns.

---

## 1. What Is an HTML Table?

An HTML table is a collection of **rows and cells** used to display related information.

A basic table looks like this:

```html
<table>
    <tr>
        <td>HTML</td>
        <td>CSS</td>
    </tr>

    <tr>
        <td>JavaScript</td>
        <td>Python</td>
    </tr>
</table>
```

The browser displays the information in rows and columns.

---

## 2. The `<table>` Element

The `<table>` element creates the table.

Example:

```html
<table>
    ...
</table>
```

All the rows and cells of the table are placed inside `<table>`.

Think of it as the **container for the entire table**.

---

## 3. The `<tr>` Element

`<tr>` stands for **Table Row**.

It creates one row in a table.

Example:

```html
<table>

    <tr>
        ...
    </tr>

    <tr>
        ...
    </tr>

</table>
```

Each `<tr>` represents one horizontal row.

---

## 4. The `<td>` Element

`<td>` stands for **Table Data**.

It represents a normal data cell.

Example:

```html
<tr>
    <td>Owais</td>
    <td>95</td>
</tr>
```

This row contains two cells:

```text
Owais | 95
```

---

## 5. Basic Table Structure

A simple table contains:

```text
<table>
    ↓
    <tr>  → Row
        ↓
        <td> → Cell
        <td> → Cell

    <tr>  → Row
        ↓
        <td> → Cell
        <td> → Cell
</table>
```

Example:

```html
<table>

    <tr>
        <td>Name</td>
        <td>Age</td>
    </tr>

    <tr>
        <td>Owais</td>
        <td>16</td>
    </tr>

</table>
```

---

## 6. Understanding Rows and Columns

Consider this table:

```html
<table>

    <tr>
        <td>HTML</td>
        <td>CSS</td>
        <td>JavaScript</td>
    </tr>

    <tr>
        <td>Structure</td>
        <td>Style</td>
        <td>Behavior</td>
    </tr>

</table>
```

It has:

* **2 rows**
* **3 columns**
* **6 cells**

Visually:

```text
HTML       | CSS       | JavaScript
Structure  | Style     | Behavior
```

A row goes from **left to right**.

A column goes from **top to bottom**.

---

## 7. Creating a Student Table

Let's create a simple student table.

```html
<table>

    <tr>
        <td>Name</td>
        <td>Department</td>
        <td>Marks</td>
    </tr>

    <tr>
        <td>Owais</td>
        <td>CME</td>
        <td>95</td>
    </tr>

    <tr>
        <td>Ahmed</td>
        <td>CME</td>
        <td>88</td>
    </tr>

</table>
```

Conceptually:

```text
Name    | Department | Marks
Owais   | CME        | 95
Ahmed   | CME        | 88
```

---

## 8. Adding Borders With CSS

By default, table borders may not be visible.

CSS can be used to make the structure easier to see.

```html
<style>
    table,
    th,
    td {
        border: 1px solid black;
    }
</style>
```

Then:

```html
<table>
    <tr>
        <td>Name</td>
        <td>Marks</td>
    </tr>

    <tr>
        <td>Owais</td>
        <td>95</td>
    </tr>
</table>
```

The cells will have visible borders.

---

## 9. Adding Cell Padding

Padding creates space between the cell content and its border.

```css
td {
    padding: 10px;
}
```

Without padding:

```text
|Owais|
```

With padding:

```text
|  Owais  |
```

Padding improves readability.

---

## 10. Adding Spacing Between Cells

CSS can also control the space between table cells.

```css
table {
    border-spacing: 5px;
}
```

This creates space between adjacent cells.

For most modern designs, developers often use other CSS techniques such as `border-collapse` instead.

---

## 11. Collapsing Table Borders

A common table style is:

```css
table {
    border-collapse: collapse;
}
```

Example:

```html
<style>
    table {
        border-collapse: collapse;
    }

    th,
    td {
        border: 1px solid black;
        padding: 8px;
    }
</style>
```

This makes neighboring borders appear as a single border.

---

## 12. Adding a Table Header

A table normally has headings that describe its columns.

HTML provides the `<th>` element for this.

`<th>` stands for **Table Header**.

Example:

```html
<table>

    <tr>
        <th>Name</th>
        <th>Department</th>
        <th>Marks</th>
    </tr>

    <tr>
        <td>Owais</td>
        <td>CME</td>
        <td>95</td>
    </tr>

</table>
```

The first row contains headings:

```text
Name | Department | Marks
```

The following rows contain data.

---

## 13. `<th>` vs `<td>`

The two elements have different purposes.

### `<th>`

Used for a **header cell**.

```html
<th>Name</th>
```

### `<td>`

Used for a **data cell**.

```html
<td>Owais</td>
```

Simple difference:

```text
<th> → Header
<td> → Data
```

---

## 14. Why Use `<th>`?

Using `<th>` gives the table proper semantic meaning.

Compare:

```html
<td>Name</td>
<td>Marks</td>
```

with:

```html
<th>Name</th>
<th>Marks</th>
```

The second version clearly identifies these cells as column headings.

This is especially useful for accessibility and for understanding the structure of the data.

## 19. Adding a Table Caption

The `<caption>` element provides a title or description for the table.

Example:

```html
<table>

    <caption>Student Results</caption>

    <tr>
        <th>Name</th>
        <th>Marks</th>
    </tr>

    <tr>
        <td>Owais</td>
        <td>95</td>
    </tr>

</table>
```

The caption tells the user what the table represents.

---

## 20. Why Use `<caption>`?

Consider:

```html
<table>
```

A user may not immediately know what the table contains.

With:

```html
<table>

    <caption>Student Results</caption>

    ...
</table>
```

the purpose is clear.

Captions are especially useful for tables containing important information.

## 22. Table Structure at a Glance

A basic table can be understood like this:

```text
<table>
│
├── <caption> → Table title
│
├── <tr>      → Row
│   ├── <th>  → Header cell
│   ├── <th>  → Header cell
│   └── <th>  → Header cell
│
├── <tr>      → Row
│   ├── <td>  → Data cell
│   ├── <td>  → Data cell
│   └── <td>  → Data cell
│
└── <tr>      → Row
    ├── <td>  → Data cell
    ├── <td>  → Data cell
    └── <td>  → Data cell
```

## 23. Tables Should Represent Data

Tables should be used when information has a meaningful **row-and-column relationship**.

Good examples:

* Student marks
* Product specifications
* Timetables
* Exam schedules
* Price lists
* Employee records

For example:

```text
Student | Subject | Marks
```

Each value has a clear relationship with the others.

---

## 24. Do Not Use Tables for Page Layout

Older websites sometimes used tables to arrange the entire webpage.

For example:

```text
+-------------------------+
|         Header          |
+------+------------------+
| Menu |     Content      |
+------+------------------+
|         Footer          |
+-------------------------+
```

Modern HTML should generally use semantic elements and CSS layout systems such as:

* Flexbox
* CSS Grid

Tables should primarily represent **tabular data**, not the overall page layout.

---

## 25. Common Mistake: Forgetting `<tr>`

Incorrect:

```html
<table>
    <td>HTML</td>
    <td>CSS</td>
</table>
```

Correct:

```html
<table>
    <tr>
        <td>HTML</td>
        <td>CSS</td>
    </tr>
</table>
```

The cells belong inside a table row.

---

## 26. Common Mistake: Using `<td>` for Headers

Avoid:

```html
<tr>
    <td>Name</td>
    <td>Marks</td>
</tr>
```

when these cells are column headings.

Prefer:

```html
<tr>
    <th>Name</th>
    <th>Marks</th>
</tr>
```

This gives the header cells their proper semantic meaning.

---

## 27. Common Mistake: Uneven Columns

For a simple table, rows should generally contain a consistent number of cells unless you intentionally use features such as `colspan` or `rowspan`.

For example:

```html
<table>

    <tr>
        <th>Name</th>
        <th>Marks</th>
        <th>Grade</th>
    </tr>

    <tr>
        <td>Owais</td>
        <td>95</td>
        <td>A+</td>
    </tr>

</table>
```

Each row contains three cells.

This creates a clear three-column structure.

## 28. HTML Table Elements

Here are the important elements introduced in this topic:

| Element     | Purpose                 |
| :---------- | :---------------------- |
| `<table>`   | Creates the table       |
| `<tr>`      | Creates a table row     |
| `<th>`      | Creates a header cell   |
| `<td>`      | Creates a data cell     |
| `<caption>` | Gives the table a title |

Remember:

```text
<table> → Table
<tr>    → Row
<th>    → Header
<td>    → Data
<caption> → Table title
```

---

## Key Points

* `<table>` creates an HTML table.
* `<tr>` creates a table row.
* `<td>` creates a normal data cell.
* `<th>` creates a header cell.
* `<caption>` gives a table a title.
* Tables organize related information into rows and columns.
* Rows run horizontally.
* Columns run vertically.
* Use `<th>` for headings instead of using `<td>` for everything.
* CSS can add borders, padding, spacing, and other visual styles.
* `border-collapse: collapse` is commonly used to combine adjacent borders.
* Tables should be used for tabular data.
* Use Flexbox or CSS Grid for general webpage layouts instead of tables.
