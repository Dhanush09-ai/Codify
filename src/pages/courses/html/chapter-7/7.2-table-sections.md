# Chapter 7: HTML Tables

## Section 2: Semantic Table Sections

A simple table can be created using `<table>`, `<tr>`, `<th>`, and `<td>`.

But when a table becomes larger, it is useful to divide it into meaningful sections.

HTML provides three elements for this:

```text
<thead> → Table Header
<tbody> → Table Body
<tfoot> → Table Footer
```

These elements make the structure of a table clearer.

> **Simple idea:** Semantic table sections divide a table into its header, main data, and footer.

---

## 1. Why Use Semantic Table Sections?

Consider a large student result table:

```text
Student Results

Name       Subject       Marks
--------------------------------
Owais      HTML          95
Ahmed      HTML          88
Rahul      HTML          91
--------------------------------
Total                    274
```

There are three logical parts:

* Header → column headings
* Body → student records
* Footer → total or summary

HTML allows us to represent these parts directly.

---

## 2. The `<thead>` Element

`<thead>` stands for **Table Head**.

It contains the rows that represent the table's headings.

Example:

```html
<table>

    <thead>
        <tr>
            <th>Name</th>
            <th>Subject</th>
            <th>Marks</th>
        </tr>
    </thead>

</table>
```

The `<thead>` normally contains one or more `<tr>` elements.

---

## 3. The `<tbody>` Element

`<tbody>` stands for **Table Body**.

It contains the main data of the table.

Example:

```html
<table>

    <tbody>
        <tr>
            <td>Owais</td>
            <td>HTML</td>
            <td>95</td>
        </tr>

        <tr>
            <td>Ahmed</td>
            <td>HTML</td>
            <td>88</td>
        </tr>
    </tbody>

</table>
```

The student records are the main body of the table.

---

## 4. The `<tfoot>` Element

`<tfoot>` stands for **Table Foot**.

It contains summary information or other content related to the table's footer.

For example:

```html
<table>

    <tfoot>
        <tr>
            <td>Total</td>
            <td></td>
            <td>183</td>
        </tr>
    </tfoot>

</table>
```

It is commonly used for:

* Totals
* Averages
* Summaries
* Final calculations
* Other footer information

---

## 5. Basic Semantic Table Structure

A complete semantic table can look like this:

```html
<table>

    <thead>
        <tr>
            <th>Name</th>
            <th>Subject</th>
            <th>Marks</th>
        </tr>
    </thead>

    <tbody>
        <tr>
            <td>Owais</td>
            <td>HTML</td>
            <td>95</td>
        </tr>

        <tr>
            <td>Ahmed</td>
            <td>HTML</td>
            <td>88</td>
        </tr>
    </tbody>

    <tfoot>
        <tr>
            <td>Total</td>
            <td></td>
            <td>183</td>
        </tr>
    </tfoot>

</table>
```

The structure is:

```text
<table>
│
├── <thead>
│      └── Header row
│
├── <tbody>
│      ├── Data row
│      └── Data row
│
└── <tfoot>
       └── Summary row
```

---

## 6. `<thead>`, `<tbody>`, and `<tfoot>` vs `<th>`

These elements have different purposes.

### `<thead>`

Defines the **header section** of the table.

### `<th>`

Defines an individual **header cell**.

Example:

```html
<thead>
    <tr>
        <th>Name</th>
        <th>Marks</th>
    </tr>
</thead>
```

Here:

```text
<thead> → Section
<th>    → Header cells
```

---

## 7. `<tbody>` and `<td>`

The same idea applies to the table body.

```html
<tbody>

    <tr>
        <td>Owais</td>
        <td>95</td>
    </tr>

</tbody>
```

Here:

```text
<tbody> → Section containing the main data
<td>    → Individual data cells
```

## 11. Styling Semantic Sections

CSS can target each section separately.

For example:

```css
thead {
    background-color: #eeeeee;
}

tbody {
    background-color: white;
}

tfoot {
    font-weight: bold;
}
```

This allows the different sections to have different visual styles.

Remember:

> HTML defines the structure. CSS controls the appearance.

---

## 12. Styling Rows Inside Sections

You can also target rows within a section.

```css
thead tr {
    font-weight: bold;
}

tbody tr {
    border-bottom: 1px solid #ddd;
}

tfoot tr {
    font-weight: bold;
}
```

The selectors identify the section and then the rows inside it.

---

## 13. Multiple Rows in `<thead>`

A table header can contain more than one row.

For example:

```html
<thead>

    <tr>
        <th colspan="2">Student Information</th>
    </tr>

    <tr>
        <th>Name</th>
        <th>Department</th>
    </tr>

</thead>
```

This is useful for tables with grouped headings.

The details of `colspan` will be covered in a later topic.

---

## 14. Multiple Rows in `<tfoot>`

A footer can also contain multiple rows if the table needs more than one summary.

Example:

```html
<tfoot>

    <tr>
        <td>Total</td>
        <td>300</td>
    </tr>

    <tr>
        <td>Average</td>
        <td>75</td>
    </tr>

</tfoot>
```

This can be useful for reports containing several summary values.

---

## 15. Multiple `<tbody>` Sections

A table can contain multiple `<tbody>` elements.

For example:

```html
<table>

    <thead>
        <tr>
            <th>Name</th>
            <th>Department</th>
        </tr>
    </thead>

    <tbody>
        <tr>
            <td>Owais</td>
            <td>CME</td>
        </tr>
    </tbody>

    <tbody>
        <tr>
            <td>Rahul</td>
            <td>ECE</td>
        </tr>
    </tbody>

</table>
```

Multiple `<tbody>` elements can be useful when the table contains logically separate groups of rows.

---

## 16. Semantic Meaning

The biggest benefit of these elements is that they describe the **meaning and structure** of the table.

Compare:

```html
<table>

    <tr>
        <th>Name</th>
        <th>Marks</th>
    </tr>

    <tr>
        <td>Owais</td>
        <td>95</td>
    </tr>

</table>
```

with:

```html
<table>

    <thead>
        <tr>
            <th>Name</th>
            <th>Marks</th>
        </tr>
    </thead>

    <tbody>
        <tr>
            <td>Owais</td>
            <td>95</td>
        </tr>
    </tbody>

</table>
```

The second version explicitly communicates the table's structure.

---

## 17. Why Semantic Structure Matters

Semantic HTML can help:

* Browsers understand the document
* Assistive technologies understand relationships
* Developers maintain large tables
* CSS target specific table sections
* Search and accessibility tools interpret content more clearly

The important idea is to use HTML elements according to their meaning.

---

## 18. Table Sections Do Not Automatically Create Visual Layouts

Adding:

```html
<thead>
```

does not automatically mean the header will look a certain way in every design.

Similarly:

```html
<tfoot>
```

does not automatically create a special visual footer.

CSS can be used to control the appearance.

For example:

```css
thead {
    font-weight: bold;
}

tfoot {
    font-weight: bold;
}
```

The semantic elements provide structure; CSS provides styling.

## 20. Common Mistakes

### Mistake 1: Using `<thead>` Without a Table

Incorrect:

```html
<thead>
    <tr>
        <th>Name</th>
    </tr>
</thead>
```

A `<thead>` belongs inside a `<table>`.

Correct:

```html
<table>

    <thead>
        <tr>
            <th>Name</th>
        </tr>
    </thead>

</table>
```

---

### Mistake 2: Putting `<td>` Directly Inside `<tbody>`

Incorrect:

```html
<tbody>
    <td>Owais</td>
    <td>95</td>
</tbody>
```

Correct:

```html
<tbody>
    <tr>
        <td>Owais</td>
        <td>95</td>
    </tr>
</tbody>
```

The cells belong inside a row.

---

### Mistake 3: Confusing `<thead>` With `<th>`

Remember:

```text
<thead> → Header section
<th>    → Header cell
```

Example:

```html
<thead>
    <tr>
        <th>Name</th>
        <th>Marks</th>
    </tr>
</thead>
```

---

### Mistake 4: Using `<tfoot>` for Every Last Row

`<tfoot>` is not simply "the last row."

It is used for **footer or summary information**.

For example:

```html
<tfoot>
    <tr>
        <td>Total</td>
        <td>500</td>
    </tr>
</tfoot>
```

A normal final data record belongs in `<tbody>`.

---

## 21. Quick Comparison

| Element     | Meaning        | Contains                |
| :---------- | :------------- | :---------------------- |
| `<table>`   | Entire table   | Table sections and rows |
| `<caption>` | Table title    | Table description/title |
| `<thead>`   | Header section | Header rows             |
| `<tbody>`   | Main body      | Data rows               |
| `<tfoot>`   | Footer section | Summary/footer rows     |
| `<tr>`      | Table row      | Header or data cells    |
| `<th>`      | Header cell    | Header information      |
| `<td>`      | Data cell      | Normal table data       |

---

## 22. Easy Way to Remember

Think about a report:

```text
TABLE
│
├── THEAD
│   └── What are these columns?
│
├── TBODY
│   └── What is the actual data?
│
└── TFOOT
    └── What is the summary?
```

So:

```text
<thead> → Head
<tbody> → Body
<tfoot> → Foot
```

---

## Key Points

* `<thead>` represents the header section of a table.
* `<tbody>` represents the main body of the table.
* `<tfoot>` represents the footer or summary section.
* These elements are placed inside `<table>`.
* `<thead>`, `<tbody>`, and `<tfoot>` contain `<tr>` elements.
* `<tr>` contains `<th>` or `<td>` cells.
* `<th>` represents an individual header cell.
* `<td>` represents an individual data cell.
* A table can have multiple `<tbody>` sections.
* Semantic sections make large tables easier to understand and maintain.
* CSS can style each table section separately.
* `<tfoot>` is for footer or summary information, not simply any last row.
* Semantic table sections describe structure; CSS controls appearance.
