# Chapter 10: CSS & JavaScript Basics

## Section 2: Connecting to JavaScript

HTML creates the **structure** of a webpage.

CSS controls the **appearance** of a webpage.

JavaScript adds **behavior and interactivity**.

For example:

```text
HTML
 ↓
Structure

CSS
 ↓
Appearance

JavaScript
 ↓
Behavior & Interactivity
```

A webpage can use all three technologies together.

## 1. What Is JavaScript?

**JavaScript** is a programming language commonly used to make webpages interactive.

For example, JavaScript can:

* Respond to button clicks
* Change HTML content
* Change styles
* Validate forms
* Show or hide elements
* Create interactive menus
* Update information on a page
* Perform calculations
* Respond to user actions

Example:

```html
<button onclick="alert('Hello!')">
    Click Me
</button>
```

When the button is clicked, JavaScript displays a message.

## 3. Three Ways to Add JavaScript

JavaScript can be added to HTML in different ways.

The common approaches are:

```text
1. Inline JavaScript
2. Internal JavaScript
3. External JavaScript
```

External JavaScript is commonly preferred for larger projects because it keeps JavaScript separate from HTML.

---

# 4. Inline JavaScript

Inline JavaScript is written directly inside an HTML attribute.

Example:

```html
<button onclick="alert('Hello World!')">
    Click Me
</button>
```

Here:

```html
onclick="alert('Hello World!')"
```

contains JavaScript.

When the user clicks the button, the JavaScript runs.

---

## 5. Another Inline Example

```html
<button onclick="alert('Welcome to CODIFY!')">
    Start Learning
</button>
```

Clicking the button executes:

```javascript
alert('Welcome to CODIFY!');
```

This is simple, but inline JavaScript can become difficult to maintain when a project becomes larger.

---

# 6. Internal JavaScript

Internal JavaScript is written inside a `<script>` element.

Example:

```html
<!DOCTYPE html>
<html>

<head>
    <title>JavaScript Example</title>
</head>

<body>

    <button onclick="sayHello()">Click Me</button>

    <script>
        function sayHello() {
            alert("Hello World!");
        }
    </script>

</body>

</html>
```

The JavaScript is written directly inside the HTML document.

---

## 7. The `<script>` Element

The `<script>` element is used to include or define JavaScript.

Example:

```html
<script>
    alert("Hello!");
</script>
```

The browser recognizes the code inside the `<script>` element as JavaScript.

---

## 8. JavaScript in the `<body>`

A `<script>` element can be placed near the end of the `<body>`.

Example:

```html
<body>

    <h1>My Website</h1>

    <button>Click Me</button>

    <script>
        console.log("Page loaded");
    </script>

</body>
```

This is a common placement for scripts that interact with elements on the page.

---

# 9. External JavaScript

External JavaScript is stored in a separate `.js` file.

Example project:

```text
website/
│
├── index.html
└── script.js
```

The JavaScript file:

```javascript
console.log("Hello from JavaScript!");
```

The HTML connects to it using:

```html
<script src="script.js"></script>
```

---

# 10. The `src` Attribute

The `src` attribute specifies the location of an external JavaScript file.

Example:

```html
<script src="script.js"></script>
```

Here:

```text
src
 ↓
Location of JavaScript file
```

If the JavaScript file is inside a folder:

```text
website/
│
├── index.html
└── js/
    └── script.js
```

use:

```html
<script src="js/script.js"></script>
```

---

# 11. Simple External JavaScript Example

### `index.html`

```html
<!DOCTYPE html>
<html>

<head>
    <title>My Website</title>
</head>

<body>

    <h1>Welcome</h1>

    <button onclick="sayHello()">
        Click Me
    </button>

    <script src="script.js"></script>

</body>

</html>
```

### `script.js`

```javascript
function sayHello() {
    alert("Hello from JavaScript!");
}
```

When the user clicks the button, the function from `script.js` runs.

# 12. Why Use External JavaScript?

External JavaScript provides several benefits.

### Separation

HTML handles structure.

CSS handles presentation.

JavaScript handles behavior.

### Reusability

One JavaScript file can be used by multiple pages.

### Maintenance

You can modify JavaScript in one place.

### Cleaner HTML

HTML does not become filled with JavaScript code.

---

# 13. Multiple Pages Can Use One JavaScript File

Suppose a website contains:

```text
website/
│
├── index.html
├── about.html
├── contact.html
└── script.js
```

Each page can use:

```html
<script src="script.js"></script>
```

The same JavaScript file can provide common functionality across the website.

---

# 14. JavaScript File Paths

File paths work similarly to CSS.

Suppose:

```text
website/
│
├── index.html
└── js/
    └── script.js
```

Use:

```html
<script src="js/script.js"></script>
```

If the HTML file is inside another folder:

```text
website/
│
├── js/
│   └── script.js
│
└── pages/
    └── about.html
```

Use:

```html
<script src="../js/script.js"></script>
```

The `..` means:

> Go up to the parent directory.

# 16. Real-World Example: Login Form

A login page might contain:

```html
<form>
    <input type="email" id="email" placeholder="Email">

    <input type="password" id="password"
           placeholder="Password">

    <button type="submit">
        Login
    </button>
</form>
```

JavaScript can be used to:

* Check whether fields are filled
* Validate input
* Display messages
* Respond to form submission

For example:

```javascript
alert("Please enter your email.");
```

The HTML provides the form.

JavaScript provides the behavior.

---

# 17. Real-World Example: Button Interaction

HTML:

```html
<button id="startButton">
    Start Learning
</button>
```

JavaScript:

```javascript
document.getElementById("startButton")
    .addEventListener("click", function () {
        alert("Let's start learning!");
    });
```

Now JavaScript responds when the user clicks the button.

---

# 18. Real-World Example: Counter

HTML:

```html
<button id="increase">+</button>
<p id="count">0</p>
```

JavaScript:

```javascript
let count = 0;

document.getElementById("increase")
    .addEventListener("click", function () {

        count++;

        document.getElementById("count").textContent = count;
    });
```

Each click increases the displayed number.

This demonstrates how JavaScript can interact with HTML elements.

---

# 19. JavaScript and the DOM

JavaScript can interact with the **DOM**.

DOM stands for:

> **Document Object Model**

The browser represents the HTML document as a structure that JavaScript can access and modify.

For example:

```html
<h1 id="title">Hello</h1>
```

JavaScript:

```javascript
document.getElementById("title").textContent =
    "Welcome to CODIFY";
```

JavaScript changes the text displayed by the `<h1>`.

---

# 20. Changing HTML With JavaScript

HTML:

```html
<p id="message">Original message</p>
```

JavaScript:

```javascript
document.getElementById("message").textContent =
    "New message";
```

Before JavaScript:

```text
Original message
```

After JavaScript:

```text
New message
```

This is one of the basic ways JavaScript creates dynamic webpages.

---

# 21. Changing Styles With JavaScript

JavaScript can also change styles.

HTML:

```html
<p id="message">
    Hello!
</p>
```

JavaScript:

```javascript
document.getElementById("message")
    .style.color = "blue";
```

The text becomes blue.

However, for large styling changes, CSS classes are usually easier to maintain than putting many styles directly in JavaScript.

---

# 22. The `defer` Attribute

When loading an external JavaScript file, you may see:

```html
<script src="script.js" defer></script>
```

The `defer` attribute tells the browser to download the script while parsing the HTML and execute it after the document has been parsed.

Example:

```html
<head>

    <script src="script.js" defer></script>

</head>
```

This allows the script to be placed in the `<head>` while avoiding execution before the HTML document has been parsed.

---

# 23. `async` Attribute

Another attribute is:

```html
<script src="script.js" async></script>
```

`async` allows the script to download while the HTML is being parsed.

When the script finishes downloading, it can execute immediately.

This means the execution timing is different from `defer`.

A simplified comparison:

```text
defer
↓
Download while parsing
↓
Execute after HTML parsing

async
↓
Download while parsing
↓
Execute as soon as it finishes downloading
```

For scripts that depend on the page's HTML structure, `defer` is often useful.

---

# 24. `type="text/javascript"`

Older HTML examples sometimes contain:

```html
<script type="text/javascript" src="script.js"></script>
```

In modern HTML, this is generally unnecessary for normal JavaScript.

You can simply write:

```html
<script src="script.js"></script>
```

The browser already understands that the script is JavaScript.

---

# 25. Module JavaScript

Modern JavaScript also supports modules.

Example:

```html
<script type="module" src="app.js"></script>
```

The `type="module"` value tells the browser that the file should be treated as a JavaScript module.

Modules allow JavaScript code to be organized into separate files and imported when needed.

Example:

```javascript
import { greet } from "./utils.js";
```

This topic will be covered in more detail when learning JavaScript.

# 27. Common Mistakes

### Mistake 1: Wrong File Name

HTML:

```html
<script src="scripts.js"></script>
```

Actual file:

```text
script.js
```

These are different filenames.

---

### Mistake 2: Wrong Folder

If the JavaScript file is:

```text
js/script.js
```

do not write:

```html
<script src="script.js"></script>
```

Use:

```html
<script src="js/script.js"></script>
```

---

### Mistake 3: Forgetting `src`

Incorrect:

```html
<script href="script.js"></script>
```

Correct:

```html
<script src="script.js"></script>
```

The `<script>` element uses `src` for an external script.

---

### Mistake 4: Incorrect Closing Tag

Correct:

```html
<script src="script.js"></script>
```

Do not write:

```html
<script src="script.js">
```

without closing the element when using normal external script syntax.

---

### Mistake 5: Putting JavaScript in a CSS File

Do not put JavaScript inside:

```text
style.css
```

Use:

```text
script.js
```

CSS and JavaScript have different purposes.

# 30. What Happens When the Browser Loads JavaScript?

Suppose the browser finds:

```html
<script src="script.js"></script>
```

It needs to:

```text
Find script.js
      ↓
Load the file
      ↓
Read JavaScript
      ↓
Execute JavaScript
      ↓
JavaScript interacts with the page
```

The exact timing depends on how the script is included and whether attributes such as `defer` or `async` are used.

# 32. Key Points

* JavaScript adds behavior and interactivity to webpages.
* JavaScript can be added inline, internally, or externally.
* Inline JavaScript is written inside HTML attributes.
* Internal JavaScript is written inside `<script>`.
* External JavaScript is stored in a `.js` file.
* The `<script>` element is used to load or define JavaScript.
* The `src` attribute specifies the location of an external JavaScript file.
* External JavaScript can be shared between multiple HTML pages.
* Correct file paths are important.
* `defer` allows a script to download while HTML is parsed and execute after parsing.
* `async` allows a script to download while parsing and execute as soon as it is ready.
* Modern HTML does not normally require `type="text/javascript"`.
* JavaScript can interact with HTML through the DOM.
* `type="module"` can be used for JavaScript modules.
* Keeping HTML, CSS, and JavaScript separate helps organize larger projects.
