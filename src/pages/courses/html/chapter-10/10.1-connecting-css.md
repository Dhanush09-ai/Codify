# Chapter 10: CSS Basics

## Section 1: Connecting to CSS

HTML is used to create the **structure** of a webpage.

CSS is used to control the **appearance and layout** of that webpage.

For example:

```html
<h1>Welcome to CODIFY</h1>
<p>Learn HTML and CSS.</p>
```

Without CSS, the browser displays the content using its default styles.

With CSS, we can control:

* Colors
* Fonts
* Sizes
* Spacing
* Borders
* Layout
* Backgrounds
* Alignment

Before using CSS, we need to connect CSS with our HTML page.

---

## 1. What Is CSS?

**CSS** stands for **Cascading Style Sheets**.

CSS describes how HTML elements should look and behave visually.

Example:

```css
h1 {
    color: blue;
}
```

This tells the browser:

> Display the `<h1>` text in blue.

HTML:

```html
<h1>Hello World</h1>
```

CSS:

```css
h1 {
    color: blue;
}
```

The HTML provides the content.

The CSS provides the appearance.

---

## 2. HTML + CSS

Think of a webpage like a house.

```text
HTML
 ↓
Structure
 ↓
Walls, rooms, doors

CSS
 ↓
Appearance
 ↓
Colors, furniture, decoration
```

For example:

```html
<h1>My Website</h1>
<p>Welcome to my website.</p>
```

CSS:

```css
h1 {
    color: darkblue;
}

p {
    color: gray;
}
```

Together, HTML and CSS create a structured and styled webpage.

---

## 3. Three Ways to Add CSS

CSS can be connected to HTML in three common ways:

```text
1. Inline CSS
2. Internal CSS
3. External CSS
```

Each method has a different use case.

---

# 4. Inline CSS

Inline CSS is written directly inside an HTML element using the `style` attribute.

Example:

```html
<h1 style="color: blue;">Hello World</h1>
```

The CSS is written inside the element.

Another example:

```html
<p style="color: gray; font-size: 18px;">
    Welcome to my website.
</p>
```

Here:

```text
style="color: gray; font-size: 18px;"
```

contains the CSS rules.

---

## 5. Advantages of Inline CSS

Inline CSS can be useful when:

* You need to style one specific element.
* You are testing a quick style.
* You are working with a small example.

Example:

```html
<p style="color: red;">
    Error message
</p>
```

Only this paragraph receives the inline style.

---

## 6. Problems With Inline CSS

Using too much inline CSS can make HTML difficult to maintain.

Example:

```html
<h1 style="color: blue; font-size: 32px;">
    Welcome
</h1>

<p style="color: gray; font-size: 18px;">
    Learn HTML.
</p>

<button style="background: blue; color: white;">
    Start
</button>
```

The HTML becomes mixed with presentation.

For larger websites, a separate CSS file is usually easier to manage.

---

# 7. Internal CSS

Internal CSS is written inside a `<style>` element.

The `<style>` element is normally placed inside `<head>`.

Example:

```html
<!DOCTYPE html>
<html>
<head>

    <style>
        h1 {
            color: blue;
        }

        p {
            color: gray;
        }
    </style>

</head>

<body>

    <h1>Hello World</h1>
    <p>Welcome to my website.</p>

</body>
</html>
```

The CSS is contained within the HTML document.

---

## 8. When Is Internal CSS Useful?

Internal CSS can be useful when:

* A page has its own unique styles.
* You are creating a small single-page example.
* You do not need to share the styles with other pages.

For example:

```html
<style>
    body {
        background-color: lightgray;
    }

    h1 {
        color: darkblue;
    }
</style>
```

The styles apply to that HTML document.

---

# 9. External CSS

**External CSS** is written in a separate `.css` file.

For example:

```text
project/
│
├── index.html
└── style.css
```

HTML:

```html
<!DOCTYPE html>
<html>
<head>

    <link rel="stylesheet" href="style.css">

</head>

<body>

    <h1>Welcome to CODIFY</h1>
    <p>Learn web development.</p>

</body>
</html>
```

CSS:

```css
h1 {
    color: blue;
}

p {
    color: gray;
}
```

The HTML and CSS are stored separately.

---

# 10. The `<link>` Element

The `<link>` element connects an external resource to the HTML document.

For CSS, we commonly write:

```html
<link rel="stylesheet" href="style.css">
```

There are two important attributes here.

### `rel`

```html
rel="stylesheet"
```

This tells the browser that the linked resource is a stylesheet.

### `href`

```html
href="style.css"
```

This specifies the location of the CSS file.

So:

```html
<link rel="stylesheet" href="style.css">
```

means:

> Connect this HTML document to the stylesheet named `style.css`.

---

# 11. Where Should the CSS Link Go?

The external stylesheet is normally linked inside the `<head>`.

Correct:

```html
<head>
    <link rel="stylesheet" href="style.css">
</head>
```

Example:

```html
<!DOCTYPE html>
<html>

<head>
    <meta charset="UTF-8">
    <title>My Website</title>
    <link rel="stylesheet" href="style.css">
</head>

<body>

    <h1>Hello World</h1>

</body>

</html>
```

---

# 12. Creating a CSS File

Create a file named:

```text
style.css
```

Then write CSS inside it:

```css
body {
    font-family: Arial, sans-serif;
}

h1 {
    color: blue;
}
```

Then connect it to HTML:

```html
<link rel="stylesheet" href="style.css">
```

The browser can now apply the CSS to the HTML page.

---

# 13. File Paths Matter

The browser needs to know where the CSS file is located.

Suppose your project looks like:

```text
website/
│
├── index.html
└── css/
    └── style.css
```

Then the HTML should use:

```html
<link rel="stylesheet" href="css/style.css">
```

The path is relative to the HTML file.

---

## 14. CSS in the Same Folder

If the files are:

```text
website/
│
├── index.html
└── style.css
```

use:

```html
<link rel="stylesheet" href="style.css">
```

---

## 15. CSS Inside a Folder

If the structure is:

```text
website/
│
├── index.html
└── css/
    └── style.css
```

use:

```html
<link rel="stylesheet" href="css/style.css">
```

---

## 16. CSS in a Parent Folder

Consider:

```text
website/
│
├── css/
│   └── style.css
│
└── pages/
    └── about.html
```

From `about.html`, you need to go up one directory:

```html
<link rel="stylesheet" href="../css/style.css">
```

Here:

```text
.. 
```

means:

> Go to the parent directory.

---

# 17. External CSS for Multiple Pages

One of the biggest benefits of external CSS is that one stylesheet can be shared by multiple pages.

Project:

```text
website/
│
├── index.html
├── about.html
├── contact.html
└── style.css
```

Each page can use:

```html
<link rel="stylesheet" href="style.css">
```

The same CSS file can style all three pages.

---

# 18. Real-World Example: College Website

Imagine a college website with:

```text
Home
About
Courses
Contact
```

Instead of writing CSS separately on every page, create:

```text
style.css
```

Then connect it to every page:

```html
<link rel="stylesheet" href="style.css">
```

Now one CSS file can control common styles such as:

* Fonts
* Colors
* Buttons
* Navigation
* Headings
* Spacing

If you change:

```css
h1 {
    color: darkblue;
}
```

the change can appear on all pages using that stylesheet.

---

# 19. Why External CSS Is Commonly Used

External CSS provides several benefits.

### Separation

HTML handles structure.

CSS handles presentation.

### Reusability

One stylesheet can be used by multiple pages.

### Maintenance

You can update styles in one place.

### Cleaner HTML

HTML does not become filled with styling rules.

### Consistency

Multiple pages can share the same design.

---

# 20. Internal vs External CSS

| Method   | Location             | Common Use                 |
| -------- | -------------------- | -------------------------- |
| Inline   | Inside HTML element  | Small specific style       |
| Internal | `<style>` in HTML    | Single-page styles         |
| External | Separate `.css` file | Larger/multi-page websites |

Example:

```text
Inline
↓
<h1 style="color: blue;">

Internal
↓
<style>
    h1 { color: blue; }
</style>

External
↓
<link rel="stylesheet" href="style.css">
```

---

# 21. Recommended Approach

For most real-world websites, external CSS is a useful approach.

Example project:

```text
my-website/
│
├── index.html
├── about.html
├── contact.html
│
└── css/
    └── style.css
```

HTML:

```html
<link rel="stylesheet" href="css/style.css">
```

CSS:

```css
body {
    font-family: Arial, sans-serif;
}

h1 {
    color: darkblue;
}
```

This keeps the project organized.

# 22. Multiple Stylesheets

A webpage can connect to more than one stylesheet.

Example:

```html
<link rel="stylesheet" href="reset.css">
<link rel="stylesheet" href="style.css">
```

Another example:

```html
<link rel="stylesheet" href="base.css">
<link rel="stylesheet" href="components.css">
<link rel="stylesheet" href="responsive.css">
```

Large projects may separate CSS into multiple files for organization.

---

# 23. Connecting CSS From a CDN

CSS can also be loaded from another location, such as a CDN.

For example:

```html
<link rel="stylesheet"
      href="https://example.com/styles.css">
```

The browser requests the stylesheet from that URL.

External resources should be used carefully and from trusted sources.

---

# 24. What Happens When the Browser Loads the Page?

Suppose the HTML contains:

```html
<link rel="stylesheet" href="style.css">
```

The browser roughly does this:

```text
HTML file
   ↓
Find <link>
   ↓
Locate style.css
   ↓
Load CSS
   ↓
Apply CSS rules
   ↓
Display styled webpage
```

The browser combines the HTML structure with CSS rules to produce the rendered page.

---

# 25. What If the CSS File Is Missing?

Suppose:

```html
<link rel="stylesheet" href="style.css">
```

but the file does not exist.

The browser cannot load the stylesheet.

The HTML content can still appear, but the CSS rules will not be applied.

Common causes include:

```text
- Wrong filename
- Wrong folder
- Incorrect path
- Typing mistake
- Missing CSS file
```

---

# 26. Common Mistakes

### Mistake 1: Wrong File Name

HTML:

```html
<link rel="stylesheet" href="styles.css">
```

But the actual file is:

```text
style.css
```

These are different filenames.

---

### Mistake 2: Wrong Folder

If CSS is inside:

```text
css/style.css
```

do not write:

```html
<link rel="stylesheet" href="style.css">
```

Use:

```html
<link rel="stylesheet" href="css/style.css">
```

---

### Mistake 3: Forgetting `rel`

Incorrect:

```html
<link href="style.css">
```

Use:

```html
<link rel="stylesheet" href="style.css">
```

---

### Mistake 4: Putting the File Path in `rel`

Incorrect:

```html
<link rel="style.css" href="stylesheet">
```

Correct:

```html
<link rel="stylesheet" href="style.css">
```

---

### Mistake 5: Writing CSS Inside HTML Without `<style>`

Incorrect:

```html
<h1>
    color: blue;
</h1>
```

Correct internal CSS:

```html
<style>
    h1 {
        color: blue;
    }
</style>
```

# 29. Key Points

* CSS stands for Cascading Style Sheets.
* CSS controls the appearance and layout of HTML.
* CSS can be added using inline, internal, or external CSS.
* Inline CSS uses the `style` attribute.
* Internal CSS uses the `<style>` element.
* External CSS is stored in a separate `.css` file.
* External CSS is commonly useful for multi-page websites.
* The `<link>` element connects an external stylesheet.
* `rel="stylesheet"` identifies the linked resource as a stylesheet.
* `href` specifies the location of the CSS file.
* External stylesheets are normally linked inside `<head>`.
* File paths must correctly point to the CSS file.
* One external stylesheet can be shared across multiple HTML pages.
* Keeping HTML and CSS separate makes projects easier to maintain.
