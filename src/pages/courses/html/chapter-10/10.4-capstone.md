# Chapter 10: CSS & JavaScript Basics

## Section 4: Capstone Project

A **capstone project** is a practical project where you use the concepts you have learned throughout a course.

Instead of learning each HTML topic separately, you will now combine them to create a complete webpage.

In this project, you will use:

```text
HTML
 ↓
Structure and content

CSS
 ↓
Appearance and layout

JavaScript
 ↓
Interaction and behavior
```

The goal is not only to make a webpage that looks good, but also to understand how the different parts work together.

---

# 1. What Is a Capstone Project?

A capstone project is a larger practical task completed after learning several related concepts.

For this HTML course, the capstone project brings together topics such as:

* Headings
* Paragraphs
* Text formatting
* Links
* Images
* Audio and video
* Lists
* Tables
* Forms
* Semantic HTML
* CSS
* JavaScript
* Validation
* Debugging

You can think of it as a final practice project.

---

# 2. Why Build a Capstone Project?

Building a project helps you move from:

```text
Learning concepts
      ↓
Writing small examples
      ↓
Combining concepts
      ↓
Building a complete webpage
```

A project also helps you understand how different HTML elements work together.

# 5. Start With the HTML Structure

Begin with a basic HTML document:

```html
<!DOCTYPE html>
<html lang="en">

<head>

    <meta charset="UTF-8">

    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>Student Learning</title>

</head>

<body>

</body>

</html>
```

This provides the basic structure of the webpage.

---

# 6. Add a Header

The header introduces the website.

```html
<header>

    <h1>Student Learning</h1>

    <p>Learn. Practice. Grow.</p>

</header>
```

The `<header>` element provides a semantic container for introductory content.

---

# 7. Add Navigation

A navigation section can contain links to different parts of the page.

```html
<nav>

    <a href="#home">Home</a>
    <a href="#courses">Courses</a>
    <a href="#resources">Resources</a>
    <a href="#contact">Contact</a>

</nav>
```

The links can point to sections using their `id` values.

For example:

```html
<section id="courses">
```

The link:

```html
<a href="#courses">Courses</a>
```

jumps to that section.

---

# 8. Add the Main Content

Use `<main>` for the primary content of the page.

```html
<main>

    <section id="home">

        <h2>Welcome</h2>

        <p>
            Welcome to our student learning website.
            Explore courses and learning resources.
        </p>

    </section>

</main>
```

The `<main>` element helps identify the primary content of the webpage.

---

# 9. Add a Courses Section

You can use headings and lists to display courses.

```html
<section id="courses">

    <h2>Courses</h2>

    <ul>

        <li>HTML</li>
        <li>CSS</li>
        <li>JavaScript</li>
        <li>Programming Fundamentals</li>

    </ul>

</section>
```

An unordered list is useful when the order of items is not important.

---

# 10. Add Course Information

You can also create separate content for each course.

```html
<article>

    <h3>HTML</h3>

    <p>
        Learn how to create the structure of webpages.
    </p>

</article>

<article>

    <h3>CSS</h3>

    <p>
        Learn how to style and design webpages.
    </p>

</article>
```

The `<article>` element can represent a self-contained piece of content.

---

# 11. Add an Image

Images can make the webpage more informative.

```html
<img src="images/learning.jpg"
     alt="Students learning together">
```

Always provide meaningful alternative text when the image conveys useful information.

The `src` attribute specifies the image location.

The `alt` attribute provides alternative text.

---

A resource section can contain useful links.

<section id="resources">

    <h2>Learning Resources</h2>

    <ul>

        <li>
            <a href="https://example.com">

        </li>

        <li>

        </li>

    </ul>

# 13. Add a Table

Tables are useful for structured information.

For example, you can create a learning schedule:

```html
<table>

    <caption>Weekly Learning Schedule</caption>

    <thead>

        <tr>
            <th>Day</th>
            <th>Topic</th>
            <th>Duration</th>
        </tr>

    </thead>

    <tbody>

        <tr>
            <td>Monday</td>
            <td>HTML</td>
            <td>1 Hour</td>
        </tr>

        <tr>
            <td>Wednesday</td>
            <td>CSS</td>
            <td>1 Hour</td>
        </tr>

        <tr>
            <td>Friday</td>
            <td>JavaScript</td>
            <td>1 Hour</td>
        </tr>

    </tbody>

</table>
```

This combines several table concepts:

* `<table>`
* `<caption>`
* `<thead>`
* `<tbody>`
* `<tr>`
* `<th>`
* `<td>`

# 14. Add a Registration Form

A form allows users to provide information.

```html
<section id="contact">

    <h2>Join the Course</h2>

    <form>

        <label for="name">Name:</label>

        <input
            type="text"
            id="name"
            name="name"
            required
        >

        <label for="email">Email:</label>

        <input
            type="email"
            id="email"
            name="email"
            required
        >

        <button type="submit">
            Register
        </button>

    </form>

</section>
```

This example uses:

```text
label
input
button
form
required
```

These are important parts of an HTML form.

---

# 15. Add Different Input Types

You can make the form more useful by adding different controls.

```html
<label for="course">Choose a course:</label>

<select id="course" name="course">

    <option value="html">HTML</option>
    <option value="css">CSS</option>
    <option value="javascript">JavaScript</option>

</select>
```

You can also add:

```html
<input type="date">
```

or:

```html
<input type="number">
```

The input type should match the information you want the user to enter.

---

# 16. Add JavaScript

Now connect JavaScript to the webpage.

```html
<script src="js/script.js" defer></script>
```

The JavaScript file can contain:

```javascript
console.log("Student Learning website loaded.");
```

The browser will run the JavaScript when the page loads.

---

# 17. Add an Interactive Button

HTML:

```html
<button id="welcomeButton">
    Show Welcome Message
</button>
```

JavaScript:

```javascript
document.getElementById("welcomeButton")
    .addEventListener("click", function () {

        alert("Welcome to the Student Learning website!");

    });
```

Now the button responds to the user's click.

This demonstrates the connection between HTML and JavaScript.

---

# 18. Add Dynamic Text

Instead of using only an alert, JavaScript can change webpage content.

HTML:

```html
<p id="message">
    Click the button to begin.
</p>

<button id="startButton">
    Start Learning
</button>
```

JavaScript:

```javascript
document.getElementById("startButton")
    .addEventListener("click", function () {

        document.getElementById("message").textContent =
            "Your learning journey has started!";

    });
```

The paragraph changes when the button is clicked.

---

# 19. Connect CSS

Now connect the stylesheet.

Inside `<head>`:

```html
<link rel="stylesheet" href="css/style.css">
```

A simple CSS file could contain:

```css
body {
    font-family: Arial, sans-serif;
    margin: 0;
    padding: 20px;
}

header {
    text-align: center;
}

section {
    margin-bottom: 30px;
}

button {
    padding: 10px 16px;
}
```

This gives the webpage basic styling.

# 24. Complete JavaScript Example

The `script.js` file can contain:

```javascript
const button =
    document.getElementById("welcomeButton");

const message =
    document.getElementById("message");

button.addEventListener("click", function () {

    message.textContent =
        "Your learning journey has started!";

});
```

This demonstrates:

* Variables
* DOM selection
* Event handling
* Changing webpage content

After creating the files, open `index.html` in your browser.

Check:

```text
□ Does the page load?
□ Is the heading displayed?
□ Do navigation links work?
□ Does the image appear?
□ Does the table display correctly?
□ Does the form appear?
□ Does the button work?
□ Does JavaScript run?
□ Is the CSS loaded?
```

Testing helps you find problems before considering the project complete.

---

# 26. Validate the HTML

After creating the webpage, validate the HTML.

Look for:

```text
Errors
Warnings
Incorrect nesting
Invalid attributes
Structural problems
```

Fix important issues and test the page again.

Remember:

> Validation checks the code; it does not replace testing.

---

# 27. Debug the Project

If something does not work:

```text
1. Reproduce the problem
        ↓
2. Open Developer Tools
        ↓
3. Check the Console
        ↓
4. Inspect the HTML
        ↓
5. Check CSS
        ↓
6. Check file paths
        ↓
7. Fix the problem
        ↓
8. Test again
```

This is the debugging process you learned in the previous topic.
