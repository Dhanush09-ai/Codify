# Chapter 1: Introduction to the World Wide Web & HTML

## Section 4: Your First Webpage

Now that we understand what HTML is and have set up our development environment, it is time to create our **first webpage**.

We will create a simple HTML file, write some content, save it, and open it in a web browser.

> **Goal:** By the end of this topic, you will have created and opened your first HTML webpage.

---

### 1. Creating Your HTML File

First, create a folder for your webpage.

For example:

```text
my-first-website/
└── index.html
```

The file `index.html` will contain our HTML code.

Open the `index.html` file in your code editor.

---

### 2. Writing Your First HTML Code

Let's start with a very simple webpage:

```html
<h1>My First Webpage</h1>
<p>Hello, World!</p>
```

This code contains two HTML elements:

* `<h1>` creates a main heading.
* `<p>` creates a paragraph.

The browser reads these elements and displays their content as a webpage.

---

### 3. Saving the File

After writing the HTML code, save the file.

Make sure the file is saved with the `.html` extension:

```text
index.html
```

Not:

```text
index.txt
```

The `.html` extension tells the computer and browser that the file contains HTML.

> **Remember:** Always check the filename and extension when creating HTML files.

---

### 4. Opening Your Webpage

Now open `index.html` using a web browser.

You can usually:

1. Locate the `index.html` file.
2. Double-click it.
3. The browser will open the webpage.

The process looks like this:

```text
Write HTML
     ↓
Save index.html
     ↓
Open in Browser
     ↓
Webpage appears
```

Your browser should display something similar to:

```text
My First Webpage

Hello, World!
```

![Your first HTML webpage workflow](./images/first-webpage-workflow.svg)

---

### 5. Understanding What the Browser Displays

The browser does not normally display the HTML tags as ordinary text.

For example, we write:

```html
<h1>My First Webpage</h1>
```

The browser understands that `<h1>` represents a heading and displays:

```text
My First Webpage
```

Similarly:

```html
<p>Hello, World!</p>
```

is displayed as a paragraph.

This is how HTML gives meaning and structure to webpage content.

---

### 6. Adding More Content

We can add more HTML elements to our webpage.

For example:

```html
<h1>My First Webpage</h1>

<p>Hello, World!</p>

<h2>About Me</h2>

<p>I am learning HTML with CODIFY.</p>
```

The webpage will now contain:

```text
My First Webpage

Hello, World!

About Me

I am learning HTML with CODIFY.
```

We can continue adding content as we learn more HTML.

---

### 7. Making a Simple Student Page

Let's create a small real-world example.

Imagine we want to create a **student profile webpage**.

We can write:

```html
<h1>Student Profile</h1>

<h2>Mohammed</h2>

<p>Course: Computer Engineering</p>

<p>Learning: HTML and C Programming</p>
```

The browser will display the information as a simple student profile.

This is how real webpages begin: we first create the structure and content, then add styling and functionality later.

---

### 8. Changing the Webpage

One of the useful things about HTML development is that we can easily change the content.

Suppose we change:

```html
<h1>My First Webpage</h1>
```

to:

```html
<h1>Welcome to CODIFY</h1>
```

After saving the file and refreshing the browser, the heading will change.

The basic cycle is:

```text
Edit
  ↓
Save
  ↓
Refresh Browser
  ↓
See the Change
```

![Edit, save, and refresh cycle](./images/edit-save-refresh.svg)

This cycle is repeated frequently while creating webpages.

---

### 9. What Happens If We Make a Mistake?

HTML development involves making mistakes and fixing them.

For example:

```html
<h1>Welcome to CODIFY</h1
```

The closing `>` is missing.

Correct version:

```html
<h1>Welcome to CODIFY</h1>
```

If something does not appear as expected, check:

* Whether the tags are written correctly.
* Whether the file was saved.
* Whether the correct HTML file is open.
* Whether the browser page has been refreshed.
* Whether the filename ends with `.html`.

> **Tip:** Small mistakes are normal when learning HTML. Reading the code carefully and testing it helps you find them.

---

### 10. A Complete First Example

Here is a slightly larger first webpage:

```html
<h1>Welcome to My Website</h1>

<p>Hello! This is my first webpage.</p>

<h2>About Me</h2>

<p>I am learning HTML and web development.</p>

<h2>My Goal</h2>

<p>I want to build useful websites.</p>
```

This creates a simple webpage with:

* A main heading
* Paragraphs
* Smaller section headings
* Different pieces of information

![Example of a first webpage](./images/first-webpage-example.svg)

---

### 11. Real-World Connection

Think about a website such as a **college website**.

A simple first version might contain:

```html
<h1>ABC Polytechnic</h1>

<p>Welcome to ABC Polytechnic.</p>

<h2>Departments</h2>

<p>Computer Engineering</p>

<p>Electronics Engineering</p>
```

Later, we can add:

* Images
* Links
* Lists
* Forms
* CSS styling
* JavaScript interaction

So the simple webpage we create now is the starting point for much larger websites.

---

### 12. Your First HTML Workflow

The complete beginner workflow is:

```text
Create project folder
        ↓
Create index.html
        ↓
Write HTML
        ↓
Save the file
        ↓
Open in browser
        ↓
Check the webpage
        ↓
Edit HTML
        ↓
Save and refresh
```

This workflow will become a normal part of your HTML development process.

---

## Key Points

* `index.html` can be used as the main webpage file.
* HTML code is written inside an `.html` file.
* A browser reads HTML and displays the webpage.
* `<h1>` is commonly used for a main heading.
* `<p>` is used for a paragraph.
* Save the file before checking the changes in the browser.
* Refresh the browser after making changes.
* Mistakes are normal and can be fixed by checking the HTML code.
* The basic workflow is **write → save → open → test → improve**.
