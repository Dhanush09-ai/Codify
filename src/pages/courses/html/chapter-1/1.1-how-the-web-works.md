# Chapter 1: Introduction to the World Wide Web & HTML
## Section 1: How the Web Works (Clients, Servers, Browsers, & URLs)

The World Wide Web (WWW) is a massive global network that lets computers share documents, images, and applications. Whenever you open a browser and visit a website, multiple devices and rules work together behind the scenes.

---

### 1. The Client-Server Model
Every activity on the web relies on a conversation between two main roles:

* **The Client**: Your personal device (laptop, smartphone, or tablet) and the browser running on it. Think of the client as a customer at a restaurant ordering food from a menu.
* **The Server**: A powerful, specialized computer connected to the internet 24/7 that stores website files. Think of the server as the restaurant kitchen that prepares and delivers your order.

> **The Cycle:**
>
> 1. You type an address or click a link (**Request**).
> 2. The server locates the requested files and sends them back (**Response**).

### 2. What is a Web Browser?
A web browser is the client application you use to navigate the web (e.g., Google Chrome, Firefox, Safari).

* **Translation Engine**: Web servers deliver files written in code like HTML, CSS, and JavaScript.
* **Rendering**: A browser reads incoming code, interprets the tags, and draws the text, buttons, and pictures onto your screen as a webpage.

### 3. Understanding URLs (Web Addresses)
A URL (Uniform Resource Locator) is the unique address of a specific file or page on the internet.

| Part | Example | Purpose |
| :--- | :--- | :--- |
| **Protocol** | `https://` | The set of rules used to transfer data securely. |
| **Domain Name** | `example.com` | The human-friendly name of the website server. |
| **Path** | `/blog/post.html` | The exact folder and file location on the server.

### 4. What Happens When You Load a Webpage?
1. **Typing the URL**: You enter an address into your browser.
2. **DNS Lookup**: The browser contacts a DNS server—the internet's phonebook—to find the numeric IP address of the domain.
3. **Sending the Request**: Your browser sends an HTTP/HTTPS request to the server.
4. **Server Response**: The server processes the request and sends back the HTML files and assets.
5. **Rendering the Page**: The browser parses the code line by line and displays the interactive page.
