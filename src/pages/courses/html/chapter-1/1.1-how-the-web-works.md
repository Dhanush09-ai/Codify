# Chapter 1: Introduction to the World Wide Web & HTML
## Section 1: How the Web Works (Clients, Servers, Browsers, & URLs)

The World Wide Web (WWW) is a massive global network that lets computers share documents, images, and applications. Whenever you open a browser and visit a website, multiple devices and rules work together behind the scenes.

---

### 1. The Client-Server Model
Every activity on the web relies on a conversation between two main roles:

* **The Client**: This is your personal device (laptop, smartphone, or tablet) and the program running on it. Think of the client as a customer at a restaurant ordering food from a menu.
* **The Server**: This is a powerful, specialized computer connected to the internet 24/7 that stores website files (HTML documents, images, stylesheets). Think of the server as the restaurant kitchen that prepares and delivers your order.

> **The Cycle:**
> 1. You type an address or click a link (**Request**).
> 2. The server locates the requested files and sends them back (**Response**).

### 2. What is a Web Browser?
A web browser is the client application you use to navigate the web. Common browsers include Google Chrome, Mozilla Firefox, Apple Safari, and Microsoft Edge.

* **Translation Engine**: Web servers deliver files written in code like HTML, CSS, and JavaScript.
* **Rendering**: Humans cannot easily read raw HTML code. A browser reads the incoming code, interprets the tags, and draws (renders) the text, buttons, and pictures onto your screen as a complete webpage.

### 3. Understanding URLs (Web Addresses)
A URL (Uniform Resource Locator) is the unique address of a specific file or page on the internet, much like a street address for a house.

| Part | Example | Purpose |
| :--- | :--- | :--- |
| **Protocol** | `https://` | The set of rules used to transfer data. `https` is secure and encrypted. |
| **Domain Name** | `example.com` | The human-friendly name of the website server. |
| **Path** | `/blog/post.html` | The exact folder and file location on the server. |

### 4. Step-By-Step: What Happens When You Load a Webpage?
1. **Typing the URL**: You enter an address like `https://www.example.com` into your browser.
2. **DNS Lookup**: Computers do not find each other using letters; they use numbers called IP addresses (e.g., `93.184.216.34`). The browser contacts a DNS (Domain Name System) server—the internet's phonebook—to find the numeric IP address.
3. **Sending the Request**: Your browser sends an HTTP/HTTPS request to the server at that IP address asking for the webpage.
4. **Server Response**: The server processes the request and sends back the HTML file along with any images or stylesheets.
5. **Rendering the Page**: The browser parses the HTML file line by line and displays the interactive page on your screen.

---

### Summary Checklist
* **Client**: The device or software asking for content.
* **Server**: The computer holding the files and sending them back.
* **Browser**: The program that turns raw code into a visible webpage.
* **URL**: The specific web address pointing to where a file lives.
* **HTML**: The standard markup language used to structure every page sent across this system.
