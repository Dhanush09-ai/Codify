# Chapter 1: Introduction to the World Wide Web & HTML

## Section 3: Setting Up Your Environment

Before we start writing HTML, we need a simple **development environment**. A development environment contains the tools we use to write, save, open, and test our webpages.

For learning HTML, we mainly need:

* A **code editor**
* A **web browser**
* A **project folder**

![HTML Development Environment](./images/environment-tools.svg)

---

### 1. What Is a Development Environment?

A **development environment** is the collection of tools and files used to create and test a website.

For example, when creating a webpage, we can use:

* **VS Code** to write HTML.
* **Chrome or Edge** to view the webpage.
* A **project folder** to organize our files.

> **Simple idea:** A development environment is the place where we **write, save, and test our website**.

---

### 2. What Is a Code Editor?

A **code editor** is a program used to write and edit source code.

For HTML, some commonly used editors are:

* Visual Studio Code (VS Code)
* Notepad
* Notepad++
* Sublime Text

For this course, we can use **Visual Studio Code (VS Code)** because it provides useful features such as syntax highlighting, file management, and extensions.

For example:

```html
<h1>Welcome to CODIFY</h1>
<p>Learn HTML easily.</p>
```

A code editor helps us write and organize this code.

---

### 3. Why Do We Need a Code Editor?

A code editor makes writing HTML easier and more organized.

It can help us:

* Create HTML files.
* Highlight HTML syntax.
* Find and replace text.
* Organize project files.
* Detect some common mistakes.
* Install useful extensions.

> **Remember:** A code editor is used to **write code**, while a browser is used to **view the webpage**.

---

### 4. What Is a Web Browser?

A **web browser** is software used to open and view webpages.

Examples include:

* Google Chrome
* Microsoft Edge
* Mozilla Firefox
* Safari

When we open an HTML file in a browser, the browser reads the HTML and displays the webpage.

For example:

```html
<h1>My First Webpage</h1>
<p>Hello, World!</p>
```

The browser displays:

```text
My First Webpage

Hello, World!
```

The HTML tags are used by the browser to understand the content.

![Browser and HTML workflow](./images/html-workflow.svg)

---

### 5. Creating a Project Folder

It is a good practice to keep all files related to a website inside one main folder.

For example:

```text
my-website/
│
├── index.html
├── images/
├── styles/
└── scripts/
```

The folders can be used for different types of files:

| File / Folder | Purpose                    |
| :------------ | :------------------------- |
| `index.html`  | Main webpage               |
| `images/`     | Images used in the website |
| `styles/`     | CSS files                  |
| `scripts/`    | JavaScript files           |

Keeping files organized makes a project easier to understand and maintain.

![Website Project Structure](./images/project-structure.svg)

---

### 6. What Is `index.html`?

`index.html` is commonly used as the **main or home page** of a website.

For example:

```text
my-website/
└── index.html
```

The `.html` part is the **file extension**. It tells the computer that the file contains HTML.

Other webpages can also have names such as:

```text
about.html
contact.html
courses.html
login.html
```

Later, these pages can be connected using HTML links.

---

### 7. Creating Your First HTML File

To create your first HTML file:

1. Create a folder for your website.
2. Open the folder in VS Code.
3. Create a new file.
4. Name it `index.html`.
5. Write HTML code.
6. Save the file.
7. Open it in a browser.

For example:

```html
<h1>My Website</h1>
<p>Welcome to my first webpage.</p>
```

![Creating and testing an HTML page](./images/html-workflow.svg)

---

### 8. Write → Save → Preview

A simple HTML development cycle is:

```text
Write HTML
    ↓
Save the file
    ↓
Open / Preview in browser
    ↓
Check the result
    ↓
Make changes
    ↓
Save and preview again
```

For example, suppose we write:

```html
<h1>Welcom to CODIFY</h1>
```

There is a spelling mistake in `Welcom`.

We can change it to:

```html
<h1>Welcome to CODIFY</h1>
```

After saving the file, we can refresh the browser and check the result.

> **Simple idea:** Web development involves writing, testing, finding mistakes, and improving the page repeatedly.

---

### 9. Opening HTML Locally

For simple HTML projects, we can open an HTML file directly in a browser.

The basic process is:

```text
index.html
     ↓
Web Browser
     ↓
Webpage
```

The webpage is running on our own computer. It has not yet been published on the Internet.

For larger projects, developers may use a **local development server** to preview their websites.

---

### 10. File Naming Rules

Good file names make a project easier to manage.

Some useful rules are:

* Use clear and meaningful names.
* Use lowercase names when possible.
* Avoid unnecessary spaces.
* Use the correct file extension.
* Keep related files inside appropriate folders.

For example:

```text
Good:
index.html
about.html
student-profile.html

Avoid:
My Website Final Version.html
```

Using a consistent naming style becomes more useful as the project grows.

---

### 11. Real-World Example: College Website

Imagine that we are creating a website for a college.

We could organize the project like this:

```text
college-website/
│
├── index.html
├── about.html
├── departments.html
├── contact.html
│
├── images/
│   ├── college-logo.png
│   └── campus.jpg
│
├── styles/
│   └── style.css
│
└── scripts/
    └── script.js
```

Here:

* HTML files contain the webpage structure.
* The `images` folder contains images.
* The `styles` folder contains CSS.
* The `scripts` folder contains JavaScript.

![College Website Project Structure](./images/project-structure.svg)

This type of organization keeps the project clean and easier to manage.

---

### 12. What Do We Need to Start HTML?

The basic tools are:

| Tool               | Purpose                     |
| :----------------- | :-------------------------- |
| **Code Editor**    | Write HTML code             |
| **Web Browser**    | View and test webpages      |
| **File Manager**   | Create and organize files   |
| **Project Folder** | Keep website files together |

You do not need complicated software to start learning HTML.

---

## Key Points

* A **development environment** contains the tools used to create and test webpages.
* A **code editor** is used to write HTML.
* A **web browser** is used to view and test webpages.
* `index.html` is commonly used as the main webpage.
* Website files should be organized inside a project folder.
* Folders such as `images`, `styles`, and `scripts` help organize a project.
* The basic development cycle is **write → save → preview → improve**.
* A webpage opened locally is different from a website published on the Internet.
