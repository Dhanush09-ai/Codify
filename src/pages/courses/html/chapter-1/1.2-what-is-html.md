# Chapter 1: Introduction to the World Wide Web & HTML
## Section 2: What is HTML?

HTML stands for **HyperText Markup Language**. It is the standard markup language used to create the structure and content of webpages.

When you visit a website, the browser receives files from a server and interprets the HTML to build the basic structure of the page.

---

### 1. What Does HTML Stand For?

**HTML** means **HyperText Markup Language**.

The name can be understood in three parts:

* **HyperText**: Text that can contain links to other webpages or resources.
* **Markup**: Special tags are used to describe and organize content.
* **Language**: HTML follows a defined set of rules and syntax.

> **Important:** HTML is a **markup language**, not a programming language. It describes the structure and meaning of webpage content.

### 2. What Does HTML Do?

HTML tells the browser what different pieces of webpage content are.

For example:

```html
<h1>Welcome to CODIFY</h1>
<p>Learn programming for free.</p>
<a href="courses.html">View Courses</a>
```

Here:

* `<h1>` represents a main heading.
* `<p>` represents a paragraph.
* `<a>` represents a link.

The browser reads these HTML elements and uses them to build the webpage.

### 3. HTML Provides the Structure of a Webpage

Think about a webpage like a **house**:

* **HTML** → Structure of the house
* **CSS** → Design, colors, and appearance
* **JavaScript** → Actions and behavior

For example, a college webpage may contain:

* College name
* Welcome message
* College logo
* Department list
* Admission link

HTML provides the structure for all of these parts.

> **Simple idea:** HTML tells the browser **what the content is and how it is organized**.

### 4. HTML Uses Tags

HTML uses **tags** to identify different types of content.

For example:

```html
<h1>My College</h1>
```

In this example:

* `<h1>` is the opening tag.
* `My College` is the content.
* `</h1>` is the closing tag.
* The complete structure is an HTML element.

Some commonly used HTML tags are:

| Tag | Purpose |
| :--- | :--- |
| `<h1>` | Main heading |
| `<p>` | Paragraph |
| `<a>` | Link |
| `<img>` | Image |
| `<ul>` | Unordered list |
| `<button>` | Button |

Tags, elements, and attributes will be studied in more detail in the next chapters.

### 5. How the Browser Uses HTML

A web browser such as Chrome, Firefox, or Safari reads HTML files and interprets their tags.

The basic process is:

1. The browser requests a webpage.
2. The server sends the webpage files.
3. The browser receives the HTML.
4. The browser reads the HTML elements.
5. The browser builds and displays the webpage.

For example:

```html
<h1>Student Profile</h1>
<p>Name: Mohammed</p>
```

The browser uses the HTML structure to display a heading and a paragraph instead of simply showing the tags as ordinary text.

### 6. HTML, CSS, and JavaScript

HTML, CSS, and JavaScript have different responsibilities.

| Technology | Main Purpose | Example |
| :--- | :--- | :--- |
| **HTML** | Structure and content | Heading, paragraph, image |
| **CSS** | Appearance and layout | Color, size, spacing |
| **JavaScript** | Behavior and interaction | Menu opens when clicked |

Consider a **college login page**.

HTML can create:

* Username field
* Password field
* Login button
* Page heading

CSS can control:

* Colors
* Font sizes
* Spacing
* Page layout

JavaScript can handle:

* Checking user input
* Showing messages
* Performing actions after clicking Login

So, HTML is the basic structure on which the other technologies work.

### 7. HTML in a Real-World Website

Imagine a college website.

The webpage may contain:

```text
ABC Polytechnic
        ↓
    About Us
        ↓
    Departments
        ↓
   Student Login
        ↓
   Contact Details
```

HTML can organize these sections using headings, paragraphs, links, lists, images, and other elements.

For example:

```html
<h1>ABC Polytechnic</h1>

<h2>Departments</h2>

<ul>
    <li>Computer Engineering</li>
    <li>Electronics</li>
    <li>Mechanical Engineering</li>
</ul>

<a href="login.html">Student Login</a>
```

This code describes the content and structure of the webpage.

### 8. Why Is HTML Important?

HTML is important because:

* It provides the basic structure of webpages.
* It organizes text, images, links, lists, and other content.
* Browsers use HTML to understand webpage structure.
* It works together with CSS and JavaScript.
* It is one of the fundamental technologies used on the World Wide Web.

> **Remember:** HTML focuses mainly on the **structure and meaning of content**. CSS focuses on presentation, while JavaScript adds behavior and interaction.

## Key Points

* HTML stands for **HyperText Markup Language**.
* HTML is a **markup language**, not a programming language.
* HTML defines the **structure and content** of a webpage.
* HTML uses **tags** to describe different types of content.
* A browser reads and interprets HTML to display a webpage.
* HTML, CSS, and JavaScript have different responsibilities.
* HTML provides the foundation for webpages.
