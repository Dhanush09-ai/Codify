# Chapter 9: Semantic HTML

## Section 4: Figures & Captions

Images, diagrams, charts, code examples, and other visual content are common parts of webpages.

Sometimes a visual is closely connected to the surrounding content and needs a description or caption.

HTML provides two useful semantic elements for this purpose:

```html
<figure>
<figcaption>
```

These elements allow us to group visual or referenced content with its caption.

---

## 1. What Is a `<figure>`?

The `<figure>` element represents **self-contained content** that is related to the main content.

It is commonly used for:

* Images
* Diagrams
* Charts
* Illustrations
* Code examples
* Other referenced content

Example:

```html
<figure>
    <img src="html-structure.png" alt="HTML document structure">
</figure>
```

The `<figure>` element groups the image as one meaningful unit.

---

## 2. What Is `<figcaption>`?

The `<figcaption>` element provides a caption or description for the content inside a `<figure>`.

Example:

```html
<figure>

    <img src="html-structure.png"
         alt="Diagram showing the structure of an HTML document">

    <figcaption>
        Basic structure of an HTML document.
    </figcaption>

</figure>
```

Here:

```text
<figure>
    ↓
Image + Caption
```

The caption explains what the figure represents.

---

## 3. Why Use `<figure>` Instead of `<div>`?

You could write:

```html
<div>
    <img src="html.png" alt="HTML structure">
    <p>Basic HTML structure.</p>
</div>
```

This works, but `<div>` does not communicate the relationship between the image and its caption.

A semantic version is:

```html
<figure>

    <img src="html.png" alt="HTML structure">

    <figcaption>
        Basic HTML structure.
    </figcaption>

</figure>
```

The semantic version clearly communicates:

> This content is a figure with a caption.

---

## 4. Basic Figure Structure

The general structure is:

```html
<figure>

    <!-- Figure content -->

    <figcaption>
        Caption
    </figcaption>

</figure>
```

For an image:

```html
<figure>

    <img src="computer.jpg"
         alt="Laptop displaying a webpage">

    <figcaption>
        A laptop displaying a webpage.
    </figcaption>

</figure>
```

The `<figcaption>` belongs to the `<figure>`.

---

## 5. Figure With an Image

One of the most common uses is an image with a caption.

Example:

```html
<figure>

    <img src="mountains.jpg"
         alt="Snow-covered mountains">

    <figcaption>
        Snow-covered mountains during winter.
    </figcaption>

</figure>
```

The image provides the visual information.

The caption provides additional context.

## 8. Figure With Code

A figure does not have to contain an image.

It can contain code.

Example:

```html
<figure>

    <pre><code>
function greet() {
    console.log("Hello");
}
    </code></pre>

    <figcaption>
        A simple JavaScript greeting function.
    </figcaption>

</figure>
```

This is useful when the code example is referenced by the surrounding content.

---

## 9. Figure With a Table

A table can also be placed inside a figure when the table is treated as referenced content with a caption.

Example:

```html
<figure>

    <table>
        <tr>
            <th>Language</th>
            <th>Type</th>
        </tr>
        <tr>
            <td>HTML</td>
            <td>Markup</td>
        </tr>
        <tr>
            <td>CSS</td>
            <td>Style Sheet</td>
        </tr>
    </table>

    <figcaption>
        Common web technologies.
    </figcaption>

</figure>
```

However, tables should still use proper table structure and accessibility features.

---

## 10. Caption Position

A `<figcaption>` can appear before or after the figure content.

For example:

```html
<figure>

    <figcaption>
        HTML document structure.
    </figcaption>

    <img src="html-structure.png"
         alt="HTML document structure">

</figure>
```

It can also appear after the image:

```html
<figure>

    <img src="html-structure.png"
         alt="HTML document structure">

    <figcaption>
        HTML document structure.
    </figcaption>

</figure>
```

Both structures are valid.

Choose the position that makes sense for your content and design.

---

## 11. Figure vs Image

A common question is:

> Should every image be placed inside `<figure>`?

**No.**

An image does not need `<figure>` simply because it is an image.

For example:

```html
<img src="logo.png" alt="CODIFY logo">
```

may be perfectly appropriate.

A `<figure>` is useful when the content is a self-contained unit that is referenced by the surrounding content or benefits from a caption.

---

## 12. Image Without a Figure

Consider a website logo:

```html
<img src="logo.png" alt="CODIFY logo">
```

There may be no need for:

```html
<figure>
    <img src="logo.png" alt="CODIFY logo">
</figure>
```

The logo is simply part of the page structure.

## 14. `<figcaption>` Is Not the Same as `alt`

This is very important.

Consider:

```html
<figure>

    <img src="html.png"
         alt="Diagram showing the basic HTML structure">

    <figcaption>
        Basic structure of an HTML document.
    </figcaption>

</figure>
```

The `alt` attribute and `<figcaption>` have different purposes.

### `alt`

The `alt` attribute provides alternative text for the image.

It is especially important when the image cannot be seen or loaded.

```html
<img src="html.png"
     alt="Diagram showing the basic HTML structure">
```

### `<figcaption>`

The `<figcaption>` provides a visible caption for the figure.

```html
<figcaption>
    Basic structure of an HTML document.
</figcaption>
```

Think of it as:

```text
alt
 ↓
Alternative text for the image

figcaption
 ↓
Visible caption for the figure
```

---

## 15. Do Not Simply Duplicate the Same Text

Avoid unnecessary duplication like:

```html
<figure>

    <img src="html.png"
         alt="Basic HTML structure">

    <figcaption>
        Basic HTML structure
    </figcaption>

</figure>
```

The exact wording may be unnecessarily repetitive.

Instead, provide useful information in each place when appropriate.

For example:

```html
<figure>

    <img src="html.png"
         alt="Diagram showing head and body elements">

    <figcaption>
        The basic structure of an HTML document.
    </figcaption>

</figure>
```

The alternative text describes the image.

The caption gives the reader additional context.

---

## 16. Figure and Accessibility

Using semantic `<figure>` and `<figcaption>` can make the relationship between content and its caption clearer.

Example:

```html
<figure>

    <img src="keyboard.jpg"
         alt="Person typing HTML code on a laptop">

    <figcaption>
        Writing HTML code in a code editor.
    </figcaption>

</figure>
```

The figure has:

* Visual content
* Alternative text
* A visible caption
* A meaningful semantic relationship

---

## 17. Figure Can Be Moved From Its Original Position

A useful feature of a figure is that it represents a self-contained piece of content.

For example, a diagram can be moved to another part of the page without destroying the meaning of the main article.

Example:

```html
<article>

    <h1>How Websites Work</h1>

    <p>
        A browser communicates with a web server.
    </p>

    <figure>

        <img src="browser-server.png"
             alt="Diagram showing communication between browser and server">

        <figcaption>
            Browser and server communication.
        </figcaption>

    </figure>

    <p>
        The server sends the requested resources back to the browser.
    </p>

</article>
```

The figure supports the article but remains a distinct content unit.

A figure can contain more than one related piece of content.

## 22. Figure Does Not Mean "Image Container"

Remember that `<figure>` is more general than an image container.

It can represent:

```text
<figure>
    ↓
Self-contained referenced content

    ├── Image
    ├── Diagram
    ├── Chart
    ├── Code
    ├── Table
    └── Other suitable content
```

The important idea is the **meaningful relationship between the content and its caption/context**.

---

## 23. Styling Figures With CSS

HTML defines the structure.

CSS can control the appearance.

HTML:

```html
<figure>

    <img src="html.png"
         alt="HTML document structure">

    <figcaption>
        Basic HTML document structure.
    </figcaption>

</figure>
```

CSS:

```css
figure {
    max-width: 600px;
}

figcaption {
    text-align: center;
    margin-top: 10px;
}
```

The HTML remains semantic while CSS controls the design.

## 24. Common Mistakes

### Mistake 1: Using `<figure>` for Every Image

Not every image needs a figure.

Use `<figure>` when the content forms a meaningful, self-contained unit.

---

### Mistake 2: Confusing `alt` With `<figcaption>`

They serve different purposes.

```text
alt
↓
Alternative text for an image

figcaption
↓
Visible caption for a figure
```

---

### Mistake 3: Leaving the Image Without Useful `alt` Text

For meaningful images, provide appropriate alternative text.

Example:

```html
<img src="diagram.png"
     alt="Diagram showing how a browser communicates with a server">
```

---

### Mistake 4: Using `<p>` Instead of `<figcaption>`

You could write:

```html
<figure>

    <img src="html.png" alt="HTML structure">

    <p>Basic HTML structure.</p>

</figure>
```

But if the text is specifically the caption for the figure, use:

```html
<figcaption>
    Basic HTML structure.
</figcaption>
```

---

### Mistake 5: Using a Caption Only for Decoration

A caption should provide useful information about the figure.

Avoid meaningless captions such as:

```html
<figcaption>
    Image
</figcaption>
```

when more useful context is available.

---

## 25. Figure Checklist

Before using `<figure>`, ask:

```text
- Is this content a self-contained unit?
- Is it related to the surrounding content?
- Would a caption provide useful context?
- Does the image have appropriate alt text?
- Am I using <figcaption> for a real caption?
- Am I avoiding unnecessary <figure> elements?
- Does the figure still make sense as a separate content unit?
```

---

## 26. Key Points

* `<figure>` represents self-contained, referenced content.
* `<figcaption>` provides a caption for a figure.
* Figures are commonly used for images, diagrams, charts, code, and other related content.
* Not every image needs to be inside `<figure>`.
* `<figcaption>` can appear before or after the figure content.
* `alt` and `<figcaption>` have different purposes.
* `alt` provides alternative text for an image.
* `<figcaption>` provides a visible caption for the figure.
* A figure can contain multiple related pieces of content.
* Figures can be styled with CSS.
* Semantic figures can make the relationship between content and its caption clearer.
* Captions should provide useful context.
* Use `<figure>` based on meaning, not simply because the content is an image.

---

## Quick Revision

```text
<figure>
    ↓
Self-contained referenced content

<figcaption>
    ↓
Caption for the figure

<img alt="">
    ↓

```

> **Use `<figure>` when content forms a meaningful, self-contained unit, and use `<figcaption>` when that content needs a caption.**
