# Chapter 9: Semantic HTML

## Section 2: Page Layout Elements

A webpage is usually divided into different areas such as a header, navigation, main content, side content, and footer.

HTML provides **semantic layout elements** that help describe these areas clearly.

A typical webpage can look like:

```text
+----------------------------------+
|             HEADER               |
+----------------------------------+
|          NAVIGATION              |
+----------------------------------+
|                                  |
|          MAIN CONTENT            |
|                                  |
|   +--------------------------+   |
|   |        ARTICLE           |   |
|   +--------------------------+   |
|                                  |
|              ASIDE               |
|                                  |
+----------------------------------+
|             FOOTER               |
+----------------------------------+
```

Instead of using `<div>` for every area, semantic elements can describe the purpose of each part.

---

## 1. Main Page Layout Elements

The most common semantic layout elements are:

```html
<header>
<nav>
<main>
<section>
<article>
<aside>
<footer>
```

Each element has a different purpose.

| Element     | Main Purpose                    |
| :---------- | :------------------------------ |
| `<header>`  | Introductory or heading content |
| `<nav>`     | Major navigation links          |
| `<main>`    | Primary page content            |
| `<section>` | Thematic group of content       |
| `<article>` | Self-contained content          |
| `<aside>`   | Related or secondary content    |
| `<footer>`  | Footer information              |

---

## 2. The `<header>` Element

The `<header>` element contains introductory content for a page or section.

Example:

```html
<header>
    <h1>CODIFY</h1>
    <p>Learn programming easily.</p>
</header>
```

A header may contain:

* Website logo
* Main heading
* Introduction
* Navigation
* Author information

For example, a blog article can have its own header:

```html
<article>

    <header>
        <h2>Learning HTML</h2>
        <p>Published on September 30, 2026</p>
    </header>

    <p>
        HTML is used to structure webpages.
    </p>

</article>
```

The `<header>` does not always mean "the top of the entire webpage."

It can also introduce a particular section or article.

---

## 3. The `<nav>` Element

The `<nav>` element represents a major navigation area.

Example:

```html
<nav>
    <a href="/">Home</a>
    <a href="/courses">Courses</a>
    <a href="/practice">Practice</a>
    <a href="/about">About</a>
</nav>
```

It tells browsers and assistive technologies that these links form a navigation area.

A website may have more than one navigation area when different navigation systems are needed.

---

## 4. The `<main>` Element

The `<main>` element represents the primary content of the webpage.

Example:

```html
<main>

    <h1>HTML Course</h1>

    <p>
        Welcome to the HTML course.
    </p>

</main>
```

The main content should represent the central purpose of the page.

Repeated content such as:

* Main navigation
* Site-wide header
* Site-wide footer

normally does not belong inside `<main>`.

A document normally has one `<main>` element.

---

## 5. The `<section>` Element

The `<section>` element groups related content around a particular topic.

Example:

```html
<section>

    <h2>HTML Basics</h2>

    <p>
        Learn the basic concepts of HTML.
    </p>

</section>
```

A section usually has a heading that describes its topic.

For example, a course page could contain:

```html
<main>

    <section>
        <h2>HTML Basics</h2>
        <p>Learn HTML fundamentals.</p>
    </section>

    <section>
        <h2>HTML Forms</h2>
        <p>Learn how to create forms.</p>
    </section>

</main>
```

Each section represents a different topic.

---

## 6. The `<article>` Element

The `<article>` element represents a self-contained piece of content.

Examples include:

* Blog posts
* News articles
* Forum posts
* Product reviews
* Course articles

Example:

```html
<article>

    <h2>What Is HTML?</h2>

    <p>
        HTML is a markup language used to structure webpages.
    </p>

</article>
```

An article should generally make sense as an independent piece of content.

---

## 7. The `<aside>` Element

The `<aside>` element contains content related to the main content but not part of its main flow.

Example:

```html
<aside>

    <h2>Quick Tip</h2>

    <p>
        Use semantic HTML to create meaningful page structure.
    </p>

</aside>
```

Common examples include:

* Sidebars
* Related articles
* Quick tips
* Advertisements
* Additional information

---

## 8. The `<footer>` Element

The `<footer>` element contains footer information for a page or section.

Example:

```html
<footer>

    <p>Copyright 2026 CODIFY</p>

</footer>
```

A footer can contain:

* Copyright information
* Contact information
* Related links
* Author information

A `<footer>` can belong to the entire webpage or to an individual section or article.

---

## 9. Putting the Elements Together

A simple webpage can use all of these elements:

```html
<header>
    <h1>CODIFY</h1>
</header>

<nav>
    <a href="/">Home</a>
    <a href="/courses">Courses</a>
    <a href="/practice">Practice</a>
</nav>

<main>

    <article>

        <header>
            <h2>HTML Course</h2>
        </header>

        <section>
            <h3>HTML Basics</h3>
            <p>Learn the fundamentals of HTML.</p>
        </section>

        <section>
            <h3>HTML Forms</h3>
            <p>Learn how to create HTML forms.</p>
        </section>

        <footer>
            <p>End of article</p>
        </footer>

    </article>

    <aside>
        <h2>Related Topics</h2>
        <p>CSS Basics</p>
    </aside>

</main>

<footer>
    <p>Copyright 2026 CODIFY</p>
</footer>
```

Notice that some semantic elements can be **nested** inside other semantic elements.

## 10. Page Layout Does Not Mean Visual Design

Semantic layout elements describe the structure of the page.

They do not automatically create a modern layout.

For example:

```html
<header>Header</header>
<main>Main Content</main>
<footer>Footer</footer>
```

does not automatically mean that the page will have a specific visual design.

CSS controls the visual layout.

```css
header {
    padding: 20px;
}

main {
    max-width: 1000px;
    margin: auto;
}

footer {
    padding: 20px;
}
```

Think of it as:

```text
HTML
 ↓
Structure + Meaning

CSS
 ↓
Layout + Appearance
```

---

## 11. HTML Layout vs CSS Layout

HTML defines **what each part is**.

CSS defines **where and how each part appears**.

For example:

```html
<aside>
    <h2>Related Topics</h2>
</aside>
```

HTML says:

> This is related or secondary content.

CSS can then place it beside the main content:

```css
main {
    display: flex;
    gap: 30px;
}
```

The semantic meaning remains the same even if the visual layout changes.

## 12. A Two-Column Layout

A common website layout has:

```text
+--------------------------------------+
|              HEADER                  |
+--------------------------------------+
|               NAV                    |
+--------------------------------------+
|                    |                 |
|    MAIN CONTENT     |     ASIDE      |
|                    |                 |
|                    |                 |
+--------------------------------------+
|              FOOTER                  |
+--------------------------------------+
```

HTML:

```html
<header>
    <h1>My Website</h1>
</header>

<nav>
    <a href="/">Home</a>
    <a href="/about">About</a>
</nav>

<main>

    <section>
        <h2>Welcome</h2>
        <p>
            Welcome to my website.
        </p>
    </section>

    <aside>
        <h2>Related</h2>
        <p>Latest articles</p>
    </aside>

</main>

<footer>
    <p>Copyright 2026</p>
</footer>
```

CSS can then turn the main area into a two-column layout.

## 15. Nested Semantic Elements

Semantic elements can be placed inside one another when their meanings make sense.

Example:

```html
<main>

    <article>

        <header>
            <h1>HTML Course</h1>
        </header>

        <section>
            <h2>Introduction</h2>
            <p>Learn the basics.</p>
        </section>

        <footer>
            <p>Written by CODIFY</p>
        </footer>

    </article>

</main>
```

Here:

```text
main
 ↓
article
 ├── header
 ├── section
 └── footer
```

Each element has a meaningful role.

---

## 16. Multiple `<section>` Elements

A page can contain multiple sections.

Example:

```html
<main>

    <section>
        <h2>About HTML</h2>
        <p>HTML structures webpages.</p>
    </section>

    <section>
        <h2>HTML Elements</h2>
        <p>Elements define different types of content.</p>
    </section>

    <section>
        <h2>HTML Forms</h2>
        <p>Forms collect user information.</p>
    </section>

</main>
```

Each section focuses on a different topic.

---

## 17. Multiple `<article>` Elements

A page can also contain multiple articles.

For example, a news homepage:

```html
<main>

    <article>
        <h2>Technology News</h2>
        <p>Latest technology updates...</p>
    </article>

    <article>
        <h2>Sports News</h2>

    </article>

    <article>
        <h2>Education News</h2>
        <p>Latest education updates...</p>
    </article>

```

Each article represents an independent piece of content.

## 18. Layout Elements and Accessibility

Semantic layout elements can help assistive technologies understand the structure of a webpage.

For example:

```html
<header>...</header>
<nav>...</nav>
<main>...</main>
<aside>...</aside>
<footer>...</footer>
```

These elements provide meaningful structural information.

A screen reader can use this information to help users understand and navigate the page.

This is one reason semantic layout is preferred over using generic `<div>` elements for everything.

---

## 19. Layout Elements and Search Engines

Semantic structure can also help search engines understand the organization of a page.

For example:

```html
<main>
    <article>
        <h1>HTML Tutorial</h1>
        <section>
            <h2>HTML Basics</h2>
        </section>
    </article>
</main>
```

The structure provides context about:

* Main content
* Article content
* Topics
* Headings

However, semantic HTML alone does not guarantee better search rankings.

---

## 20. When to Use `<div>`

Semantic elements should be preferred when they accurately describe the content.

But `<div>` is still useful for generic grouping.

Example:

```html
<div class="card">
    <h2>HTML</h2>
    <p>Learn HTML basics.</p>
</div>
```

If the container does not have a specific semantic meaning, `<div>` can be appropriate.

Do not force a semantic element simply because you want to avoid `<div>`.

---

## 21. Common Layout Mistakes

### Mistake 1: Using `<main>` Multiple Times

Avoid creating several main content areas:

```html
<main>...</main>
<main>...</main>
```

A document normally has one `<main>`.

---

### Mistake 2: Using `<nav>` for Every Link

Not every link needs to be inside `<nav>`.

Use `<nav>` for major navigation areas.

---

### Mistake 3: Using `<section>` Only for Styling

Do not use `<section>` simply because you want to create a visual box.

Use it when the content represents a meaningful thematic grouping.

---

### Mistake 4: Using `<article>` for Every Container

Not every content box is an article.

Use `<article>` when the content can be considered a self-contained piece.

---

### Mistake 5: Expecting HTML to Create the Complete Layout

HTML provides structure.

CSS is normally responsible for:

* Columns
* Spacing
* Colors
* Alignment
* Responsive design
* Visual appearance

## 23. A Complete Semantic Layout

```html
<!DOCTYPE html>

<html lang="en">

<head>
    <meta charset="UTF-8">
    <title>CODIFY</title>
</head>

<body>

    <header>
        <h1>CODIFY</h1>
        <p>Learn programming for free.</p>
    </header>

    <nav>
        <a href="/">Home</a>
        <a href="/courses">Courses</a>
        <a href="/practice">Practice</a>
        <a href="/about">About</a>
    </nav>

    <main>

        <article>

            <header>
                <h2>HTML Course</h2>
            </header>

            <section>
                <h3>Introduction</h3>
                <p>
                    Learn the basics of HTML.
                </p>
            </section>

            <section>
                <h3>HTML Elements</h3>
                <p>
                    Learn about HTML elements and attributes.
                </p>
            </section>

            <footer>
                <p>End of HTML course article.</p>
            </footer>

        </article>

        <aside>
            <h2>Related Courses</h2>
            <p>CSS</p>
            <p>JavaScript</p>
        </aside>

    </main>

    <footer>
        <p>Copyright 2026 CODIFY</p>
    </footer>

</body>

</html>
```

This is a good example of combining semantic layout elements to describe a complete webpage.

---

## 24. Key Points

* Semantic layout elements describe the purpose of different page areas.
* `<header>` provides introductory content.
* `<nav>` contains major navigation links.
* `<main>` contains the primary content.
* `<section>` groups related content.
* `<article>` represents self-contained content.
* `<aside>` contains related or secondary content.
* `<footer>` contains footer information.
* Semantic elements can be nested when their meanings make sense.
* A document normally has one `<main>` element.
* A page can have multiple `<section>` and `<article>` elements.
* Semantic HTML helps accessibility and page structure.
* CSS controls the visual layout and appearance.
* `<div>` remains useful for generic containers.
* Choose layout elements according to meaning, not simply appearance.
