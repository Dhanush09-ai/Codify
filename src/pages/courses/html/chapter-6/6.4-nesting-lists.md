# Chapter 6: Lists & Tables

## Section 4: Nesting Lists

Sometimes a list contains **another list inside it**.

This is called **nesting lists**.

For example, a course may contain chapters, and each chapter may contain topics:

```text
1. HTML
   1.1 Introduction
   1.2 Elements
   1.3 Attributes

2. CSS
   2.1 Selectors
   2.2 Colors
   2.3 Fonts
```

The smaller list is nested inside the larger list.

> **Simple idea:** A nested list is a list placed inside another list.

---

## 1. What Is a Nested List?

A nested list is a list that appears inside another list item.

For example:

```html
<ol>
    <li>
        HTML
        <ul>
            <li>Elements</li>
            <li>Attributes</li>
        </ul>
    </li>
</ol>
```

Here:

* The `<ol>` is the outer list.
* The first `<li>` contains the topic `HTML`.
* The `<ul>` is the nested list.
* Its `<li>` elements are sub-items of `HTML`.

---

## 2. Basic Structure

The important rule is:

> **The nested list should be placed inside the `<li>` that it belongs to.**

Correct:

```html
<ul>
    <li>
        HTML
        <ul>
            <li>Headings</li>
            <li>Paragraphs</li>
        </ul>
    </li>
</ul>
```

The nested `<ul>` belongs to the `HTML` list item.

---

## 3. Why Do We Use Nested Lists?

Nested lists are useful when information has a **hierarchical structure**.

Common examples include:

* Course chapters and topics
* Categories and subcategories
* Menus and submenus
* File and folder structures
* Product categories
* Step-by-step instructions with substeps

For example:

```text
Web Development
    HTML
        Headings
        Paragraphs
        Links
    CSS
        Colors
        Fonts
```

The indentation makes the relationship between the items clear.

---

## 4. Unordered List Inside an Unordered List

A `<ul>` can contain another `<ul>`.

Example:

```html
<ul>
    <li>
        Fruits

        <ul>
            <li>Apple</li>
            <li>Banana</li>
            <li>Orange</li>
        </ul>
    </li>

    <li>
        Vegetables

        <ul>
            <li>Carrot</li>
            <li>Potato</li>
            <li>Tomato</li>
        </ul>
    </li>
</ul>
```

The structure is:

```text
• Fruits
    • Apple
    • Banana
    • Orange

• Vegetables
    • Carrot
    • Potato
    • Tomato
```

---

## 5. Ordered List Inside an Ordered List

An `<ol>` can also contain another `<ol>`.

Example:

```html
<ol>
    <li>
        Learn HTML

        <ol>
            <li>Learn headings</li>
            <li>Learn paragraphs</li>
            <li>Learn links</li>
        </ol>
    </li>

    <li>
        Learn CSS

        <ol>
            <li>Learn selectors</li>
            <li>Learn colors</li>
            <li>Learn fonts</li>
        </ol>
    </li>
</ol>
```

Conceptually:

```text
1. Learn HTML
    1. Learn headings
    2. Learn paragraphs
    3. Learn links

2. Learn CSS
    1. Learn selectors
    2. Learn colors
    3. Learn fonts
```

---

## 6. Ordered List Inside an Unordered List

Different list types can be nested.

Example:

```html
<ul>
    <li>
        Web Development

        <ol>
            <li>Learn HTML</li>
            <li>Learn CSS</li>
            <li>Learn JavaScript</li>
        </ol>
    </li>
</ul>
```

Result:

```text
• Web Development
    1. Learn HTML
    2. Learn CSS
    3. Learn JavaScript
```

The outer list is unordered, while the inner list is ordered.

---

## 7. Unordered List Inside an Ordered List

The opposite is also possible.

```html
<ol>
    <li>
        Frontend Development

        <ul>
            <li>HTML</li>
            <li>CSS</li>
            <li>JavaScript</li>
        </ul>
    </li>

    <li>
        Backend Development
    </li>
</ol>
```

Result:

```text
1. Frontend Development
    • HTML
    • CSS
    • JavaScript

2. Backend Development
```

---

## 8. The Most Important Nesting Rule

A common mistake is placing the nested list directly inside `<ol>` or `<ul>` without putting it inside an `<li>`.

### Incorrect

```html
<ol>
    <li>HTML</li>

    <ul>
        <li>Headings</li>
        <li>Paragraphs</li>
    </ul>
</ol>
```

### Correct

```html
<ol>
    <li>
        HTML

        <ul>
            <li>Headings</li>
            <li>Paragraphs</li>
        </ul>
    </li>
</ol>
```

The nested list belongs to the `HTML` list item, so it should be inside that `<li>`.

Each nested list represents a deeper level of information.

## 14. Nested Ordered Lists for Steps and Substeps

Nested ordered lists are useful when a process contains smaller steps.

Example:

```html
<ol>
    <li>
        Create the HTML file

            <li>Open VS Code.</li>
            <li>Create a new file.</li>
            <li>Save it as index.html.</li>
        </ol>
    </li>

    <li>
        Write the HTML

        <ol>
            <li>Add the boilerplate.</li>
            <li>Add a heading.</li>
            <li>Add a paragraph.</li>
        </ol>
    </li>
</ol>
```

Conceptually:

```text
1. Create the HTML file
    1. Open VS Code.
    2. Create a new file.
    3. Save it as index.html.

2. Write the HTML
    1. Add the boilerplate.
    2. Add a heading.
    3. Add a paragraph.
```

## 15. Mixing List Types

You are not limited to nesting the same type of list.

For example:

```html
<ol>
    <li>
        Frontend

        <ul>
            <li>HTML</li>
            <li>CSS</li>

            <li>
                JavaScript

                <ol>
                    <li>Variables</li>
                    <li>Functions</li>
                </ol>
            </li>
        </ul>
    </li>

    <li>Backend</li>
</ol>
```

Here:

* The outer list is ordered.
* The second level is unordered.
* The third level is ordered again.

HTML allows this kind of nesting when it correctly represents the content structure.

## 17. Styling Nested Lists

CSS can control the appearance of nested lists.

Example:

```css
ul ul {
    margin-left: 20px;
}
```

This adds indentation to a nested unordered list.

You can also change the marker style:

```css
ul {
    list-style-type: disc;
}

ul ul {
    list-style-type: circle;
}
```

The HTML defines the structure, while CSS controls the presentation.

---

## 18. Nested Lists and Semantic HTML

Nesting lists correctly gives the document a meaningful structure.

For example:

```html
<ol>
    <li>
        Chapter 1

        <ul>
            <li>Lesson 1</li>
            <li>Lesson 2</li>
        </ul>
    </li>

    <li>
        Chapter 2

        <ul>
            <li>Lesson 1</li>
            <li>Lesson 2</li>
        </ul>
    </li>
</ol>
```

The browser can understand that:

```text
Chapter 1
    contains Lesson 1 and Lesson 2

Chapter 2
    contains Lesson 1 and Lesson 2
```

This is better than using spaces, `<br>`, or random `<div>` elements to imitate indentation.

## 19. Common Mistake: Incorrect Placement

### Incorrect

```html
<ul>
    <li>HTML</li>

    <ul>
        <li>Headings</li>
        <li>Paragraphs</li>
    </ul>

    <li>CSS</li>
</ul>
```

The nested list is not inside the `HTML` `<li>`.

### Correct

```html
<ul>
    <li>
        HTML

        <ul>
            <li>Headings</li>
            <li>Paragraphs</li>
        </ul>
    </li>

    <li>CSS</li>
</ul>
```

The nested list belongs to `HTML`.

---

## 20. Common Mistake: Using Spaces Instead of Nesting

Avoid trying to create hierarchy with spaces:

```html
<ul>
    <li>HTML</li>
    <li>    Headings</li>
    <li>    Paragraphs</li>
</ul>
```

The spaces do not create a real parent-child relationship.

Use a nested list:

```html
<ul>
    <li>
        HTML

        <ul>
            <li>Headings</li>
            <li>Paragraphs</li>
        </ul>
    </li>
</ul>
```

---

## 21. Common Mistake: Using `<br>` for Hierarchy

Avoid:

```html
HTML<br>
&nbsp;&nbsp;&nbsp;Headings<br>
&nbsp;&nbsp;&nbsp;Paragraphs
```

This only creates visual spacing.

Use semantic nested lists instead:

```html
<ul>
    <li>
        HTML
        <ul>
            <li>Headings</li>
            <li>Paragraphs</li>
        </ul>
    </li>
</ul>
```

---

## 22. Nested Lists vs Flat Lists

A flat list:

```html
<ul>
    <li>HTML</li>
    <li>Headings</li>
    <li>Paragraphs</li>
    <li>CSS</li>
    <li>Colors</li>
</ul>
```

Does not clearly show which topics belong to which subject.

A nested list:

```html
<ul>
    <li>
        HTML
        <ul>
            <li>Headings</li>
            <li>Paragraphs</li>
        </ul>
    </li>

    <li>
        CSS
        <ul>
            <li>Colors</li>
        </ul>
    </li>
</ul>
```

Clearly represents the hierarchy.

---

## 24. Key Points

* A nested list is a list inside another list item.
* The nested list should be placed inside the relevant `<li>`.
* `<ol>` can contain nested `<ol>` or `<ul>` lists.
* `<ul>` can contain nested `<ul>` or `<ol>` lists.
* Different list types can be mixed.
* Nested lists are useful for hierarchical information.
* Common uses include menus, courses, categories, folders, and substeps.
* Use semantic nesting instead of spaces or `<br>` elements.
* CSS can control the visual appearance of nested lists.
* Correct nesting makes the relationship between parent and child items clear.
