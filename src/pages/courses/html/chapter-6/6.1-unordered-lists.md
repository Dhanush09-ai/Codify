# Chapter 6: Lists & Tables

## Section 1: Unordered Lists

Lists are commonly used on webpages to organize related information.

For example, a website may use a list to display:

* Navigation links
* Features
* Shopping items
* Course topics
* Requirements
* Skills
* Ingredients

HTML provides different types of lists. In this section, we will learn about **unordered lists**.

> **Simple idea:** An unordered list displays related items where the order does not matter.

---

## 1. What Is an Unordered List?

An unordered list is a list where the items do not have a specific order.

For example:

```text
Programming Languages
• C
• C++
• Java
• Python
```

The order of these languages does not necessarily matter.

In HTML, an unordered list is created using the `<ul>` element.

---

## 2. The `<ul>` Element

`<ul>` stands for **Unordered List**.

Basic syntax:

```html id="g9p2zn"
<ul>
    <li>C</li>
    <li>Java</li>
    <li>Python</li>
</ul>
```

The browser normally displays the items with bullet points.

The result looks approximately like:

```text
• C
• Java
• Python
```

---

## 3. The `<li>` Element

`<li>` stands for **List Item**.

Each individual item in a list is written using `<li>`.

Example:

```html id="m3k7pl"
<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>
```

Here:

* `<ul>` creates the list.
* Each `<li>` creates one list item.

> **Important:** `<li>` elements should normally be placed inside a list such as `<ul>` or `<ol>`.

---

## 4. Simple Example

```html id="y7s4q2"
<h2>My Skills</h2>

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>C Programming</li>
    <li>JavaScript</li>
</ul>
```

This creates a heading followed by an unordered list.

The browser displays:

```text
My Skills

• HTML
• CSS
• C Programming
• JavaScript
```

---

## 5. When Should You Use an Unordered List?

Use an unordered list when the order of the items is not important.

For example:

```html id="v2c8nk"
<h2>Required Tools</h2>

<ul>
    <li>VS Code</li>
    <li>Web Browser</li>
    <li>HTML File</li>
</ul>
```

It does not matter which tool appears first.

---

## 6. Unordered List vs Paragraphs

Consider this:

```html id="g2d9ws"
<p>HTML</p>
<p>CSS</p>
<p>JavaScript</p>
```

These are separate paragraphs.

If the content represents a group of related items, a list is more meaningful:

```html id="j5f8qr"
<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>
```

The second example tells the browser that these items form a list.

## 10. Bullet Points

Browsers usually display unordered list items using bullets.

Example:

```html id="x4k8dp"
<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>
```

The default appearance is approximately:

```text
• HTML
• CSS
• JavaScript
```

The exact appearance can be changed using CSS.

---

## 11. Changing Bullet Style with CSS

CSS can change the appearance of the bullets.

Example:

```html id="z7m2kp"
<ul class="topics">
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>
```

```css id="r4v8hx"
.topics {
    list-style-type: square;
}
```

The bullets can become square-shaped.

---

## 12. Common `list-style-type` Values

Some common values include:

```css id="q1n6vy"
ul {
    list-style-type: disc;
}
```

```css id="h8k3ws"
ul {
    list-style-type: circle;
}
```

```css id="c5p9dz"
ul {
    list-style-type: square;
}
```

These produce different bullet styles.

### Common values:

| Value    | Appearance    |
| :------- | :------------ |
| `disc`   | Filled circle |
| `circle` | Empty circle  |
| `square` | Square        |

The default style is commonly `disc`.

---

## 13. Removing Bullets

Sometimes a list is used for website navigation, and the bullets are not wanted.

CSS can remove them:

```css id="v3x7qa"
ul {
    list-style-type: none;
}
```

Example:

```html id="f5k2mr"
<nav>
    <ul>
        <li><a href="index.html">Home</a></li>
        <li><a href="courses.html">Courses</a></li>
        <li><a href="about.html">About</a></li>
    </ul>
</nav>
```

With CSS:

```css id="m7w1kp"
nav ul {
    list-style-type: none;
}
```

the bullets can be removed.

---

## 14. Lists and Navigation

Unordered lists are frequently used to structure navigation menus.

Example:

```html id="n4x8cb"
<nav>
    <ul>
        <li><a href="index.html">Home</a></li>
        <li><a href="courses.html">Courses</a></li>
        <li><a href="practice.html">Practice</a></li>
        <li><a href="contact.html">Contact</a></li>
    </ul>
</nav>
```

Here:

* `<nav>` identifies navigation content.
* `<ul>` groups the navigation items.
* `<li>` represents each menu item.
* `<a>` creates the actual link.

This structure is commonly used for website menus.

---

## 15. Nested Unordered Lists

An unordered list can contain another unordered list.

This is called a **nested list**.

Example:

```html id="a2j9vc"
<ul>
    <li>
        Frontend
        <ul>
            <li>HTML</li>
            <li>CSS</li>
            <li>JavaScript</li>
        </ul>
    </li>

    <li>
        Backend
        <ul>
            <li>Node.js</li>
            <li>Python</li>
        </ul>
    </li>
</ul>
```

The structure becomes:

```text
• Frontend
    • HTML
    • CSS
    • JavaScript
• Backend
    • Node.js
    • Python
```

---

## 16. Why Use Nested Lists?

Nested lists are useful when information has categories and subcategories.

For example:

```text
• Programming
    • C
    • C++
    • Java
• Web Development
    • HTML
    • CSS
    • JavaScript
```

The hierarchy is easier to understand when represented using nested lists.

---

## 17. Important Structure of Nested Lists

The nested `<ul>` should be inside the relevant `<li>`.

Correct:

```html id="h6q3ts"
<ul>
    <li>
        Web Development

        <ul>
            <li>HTML</li>
            <li>CSS</li>
        </ul>
    </li>
</ul>
```

This clearly shows that HTML and CSS are sub-items of Web Development.

---

## 18. Incorrect List Structure

Avoid placing the nested list directly beside the list items without a containing `<li>`.

For example:

```html id="w5p7kn"
<ul>
    <li>Web Development</li>

    <ul>
        <li>HTML</li>
        <li>CSS</li>
    </ul>
</ul>
```

The nested list should be associated with its parent item.

Prefer:

```html id="j8r2mv"
<ul>
    <li>
        Web Development

        <ul>
            <li>HTML</li>
            <li>CSS</li>
        </ul>
    </li>
</ul>
```

---

## 19. Lists with Links

Each list item can contain a link.

Example:

```html id="e7k4qy"
<ul>
    <li><a href="html.html">HTML</a></li>
    <li><a href="css.html">CSS</a></li>
    <li><a href="javascript.html">JavaScript</a></li>
</ul>
```

This is commonly used in:

* Navigation menus
* Sidebars
* Course menus
* Documentation websites

---

## 20. Lists with Images

A list item can contain an image.

Example:

```html id="c9v5la"
<ul>
    <li>
        <img src="html.png" alt="HTML logo">
        HTML
    </li>

    <li>
        <img src="css.png" alt="CSS logo">
        CSS
    </li>
</ul>
```

The `<li>` can contain different types of content.

---

## 21. Lists Can Contain More Than Text

A list item does not have to contain only a single word.

For example:

```html id="r2m8fx"
<ul>
    <li>
        <strong>HTML</strong>
        - Structure of webpages
    </li>

    <li>
        <strong>CSS</strong>
        - Styling of webpages
    </li>

    <li>
        <strong>JavaScript</strong>
        - Adds interactivity
    </li>
</ul>
```

Each list item can contain other inline elements and suitable content.

---

## 22. Accessibility and Lists

Using semantic list elements is important.

If content is genuinely a list, use:

```html id="q3p6vn"
<ul>
    <li>Item 1</li>
    <li>Item 2</li>
</ul>
```

instead of manually creating bullet characters:

```html id="u5d9kc"
<p>• Item 1</p>
<p>• Item 2</p>
```

The semantic HTML structure gives browsers and assistive technologies meaningful information about the content.

---

## 23. Do Not Use Lists Only for Spacing

A list should represent a group of related items.

Avoid using:

```html id="z8x4mb"
<ul>
    <li>&nbsp;</li>
    <li>&nbsp;</li>
</ul>
```

just to create empty space.

Use CSS for layout and spacing.

For example:

```css id="t6w2qp"
section {
    margin-top: 20px;
}
```

---

## 24. Unordered Lists and CSS Layout

CSS can be used to create horizontal navigation.

HTML:

```html id="c4p8ws"
<nav>
    <ul class="menu">
        <li><a href="index.html">Home</a></li>
        <li><a href="courses.html">Courses</a></li>
        <li><a href="about.html">About</a></li>
    </ul>
</nav>
```

CSS:

```css id="x9k3mv"
.menu {
    list-style: none;
    display: flex;
    gap: 20px;
}
```

The list remains semantically a list, while CSS controls its visual layout.

---

## 25. `list-style` Shorthand

CSS also provides the `list-style` shorthand property.

Example:

```css id="v7q2bd"

    list-style: square;
}
```

You can also remove bullets:

```css id="r5m8kx"

    list-style: none;
}
```

This is a convenient way to control list styling.

## 29. Common Mistakes

### Mistake 1: Forgetting `<li>`

Incorrect:

```html id="g4m8xq"
<ul>
    HTML
    CSS
    JavaScript
</ul>
```

Correct:

```html id="t9p2kv"
<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>
```

---

### Mistake 2: Using `<ul>` for Ordered Information

If the order matters, an unordered list may not be appropriate.

For example:

```text
1. Create an account
2. Verify your email
3. Log in
```

This is ordered information and will be covered with ordered lists.

---

### Mistake 3: Using `<br>` to Create Lists

Avoid:

```html id="n6r3qw"
HTML<br>
CSS<br>
JavaScript<br>
```

If these are related list items, use:

```html id="d8v5mx"
<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>
```

---

### Mistake 4: Manually Adding Bullet Characters

Avoid:

```html id="a3j7kp"
<p>• HTML</p>
<p>• CSS</p>
<p>• JavaScript</p>
```

Use semantic list elements instead:

```html id="f8m2wy"
<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>
```

---

## Key Points

* `<ul>` creates an unordered list.
* `<li>` creates an individual list item.
* Unordered lists are used when the order of items does not matter.
* Browsers normally display unordered list items with bullets.
* CSS can change or remove bullet styles.
* Common bullet styles include `disc`, `circle`, and `square`.
* `list-style: none` can remove bullets.
* Unordered lists are commonly used for navigation menus.
* A `<li>` can contain links, images, text, and other suitable content.
* Unordered lists can be nested to create categories and subcategories.
* A nested `<ul>` should normally be placed inside its related `<li>`.
* Semantic lists are better than manually creating bullets with text or `<br>`.
* CSS should be used for layout and spacing rather than using empty list items.
* `<ul>` and `<li>` help browsers and assistive technologies understand list structure.
