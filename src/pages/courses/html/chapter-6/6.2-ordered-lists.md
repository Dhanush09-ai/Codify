# Chapter 6: Lists & Tables

## Section 2: Ordered Lists

Sometimes the order of items is important.

For example:

1. Open the website.
2. Create an account.
3. Verify your email.
4. Log in.

HTML provides the `<ol>` element to create this type of list.

> **Simple idea:** Use an ordered list when the sequence or position of the items matters.

---

## 1. What Is an Ordered List?

An ordered list is a list where the items have a specific order.

The browser normally displays the items using numbers.

Example:

```html
<ol>
    <li>Open VS Code</li>
    <li>Create an HTML file</li>
    <li>Write your HTML code</li>
    <li>Open the file in a browser</li>
</ol>
```

The browser displays:

```text
1. Open VS Code
2. Create an HTML file
3. Write your HTML code
4. Open the file in a browser
```

---

## 2. The `<ol>` Element

`<ol>` stands for **Ordered List**.

Basic syntax:

```html
<ol>
    <li>First item</li>
    <li>Second item</li>
    <li>Third item</li>
</ol>
```

The `<ol>` element creates the ordered list, while `<li>` creates each list item.

---

## 3. The `<li>` Element

`<li>` stands for **List Item**.

Example:

```html
<ol>
    <li>Install VS Code</li>
    <li>Create a project</li>
    <li>Write HTML</li>
</ol>
```

Here:

* `<ol>` defines the ordered list.
* `<li>` defines each item.
* The browser automatically adds the numbering.

You do not need to manually write `1.`, `2.`, and `3.`.

---

## 4. Simple Example

```html
<h2>How to Make Tea</h2>

<ol>
    <li>Boil water.</li>
    <li>Add tea powder.</li>
    <li>Add milk and sugar.</li>
    <li>Boil for a few minutes.</li>
    <li>Serve the tea.</li>
</ol>
```

The order matters because the steps need to be performed in sequence.

---

## 5. When Should You Use an Ordered List?

Use an ordered list when changing the order can change the meaning or result.

Common examples include:

* Instructions
* Tutorials
* Recipes
* Rankings
* Procedures
* Step-by-step guides
* Exam instructions

For example:

```text
1. Create an account
2. Verify your email
3. Log in
```

The user should normally follow these steps in order.

---

## 6. Ordered List vs Unordered List

The main difference is whether the order matters.

### Ordered List

```html
<ol>
    <li>Create account</li>
    <li>Verify email</li>
    <li>Log in</li>
</ol>
```

Result:

```text
1. Create account
2. Verify email
3. Log in
```

### Unordered List

```html
<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>
```

Result:

```text
• HTML
• CSS
• JavaScript
```

> **Remember:** `<ol>` = order matters, `<ul>` = order does not matter.

---

## 7. Changing the Numbering Type

By default, ordered lists use numbers.

You can change the numbering style using the `type` attribute.

Common values include:

```text
1
A
a
I
i
```

---

## 8. Numbered List

The default numbering style is decimal numbers.

```html
<ol type="1">
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ol>
```

Result:

```text
1. HTML
2. CSS
3. JavaScript
```

`type="1"` represents decimal numbering.

---

## 9. Uppercase Letters

Use `type="A"` for uppercase letters.

```html
<ol type="A">
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ol>
```

Result:

```text
A. HTML
B. CSS
C. JavaScript
```

---

## 10. Lowercase Letters

Use `type="a"` for lowercase letters.

```html
<ol type="a">
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ol>
```

Result:

```text
a. HTML
b. CSS
c. JavaScript
```

---

## 11. Uppercase Roman Numerals

Use `type="I"` for uppercase Roman numerals.

```html
<ol type="I">
    <li>Introduction</li>
    <li>HTML Basics</li>
    <li>HTML Elements</li>
</ol>
```

Result:

```text
I. Introduction
II. HTML Basics
III. HTML Elements
```

---

## 12. Lowercase Roman Numerals

Use `type="i"` for lowercase Roman numerals.

```html
<ol type="i">
    <li>Introduction</li>
    <li>HTML Basics</li>
    <li>HTML Elements</li>
</ol>
```

Result:

```text
i. Introduction
ii. HTML Basics
iii. HTML Elements
```

---

## 13. Ordered List Numbering Types

| Type | Example    |
| :--- | :--------- |
| `1`  | 1, 2, 3    |
| `A`  | A, B, C    |
| `a`  | a, b, c    |
| `I`  | I, II, III |
| `i`  | i, ii, iii |

Example:

```html
<ol type="A">
    <li>First topic</li>
    <li>Second topic</li>
</ol>
```

---

## 14. Starting From a Specific Number

The `start` attribute allows an ordered list to begin from a specific number.

Example:

```html
<ol start="5">
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ol>
```

Result:

```text
5. HTML
6. CSS
7. JavaScript
```

The list does not have to start at `1`.

---

## 15. Starting an Alphabetical List

The `start` attribute can also work with letter-based numbering.

For example:

```html
<ol type="A" start="3">
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ol>
```

Result:

```text
C. HTML
D. CSS
E. JavaScript
```

---

## 16. Reversing an Ordered List

The `reversed` attribute makes the numbering count downward.

Example:

```html
<ol reversed>
    <li>Step Three</li>
    <li>Step Two</li>
    <li>Step One</li>
</ol>
```

Result:

```text
3. Step Three
2. Step Two
1. Step One
```

The `reversed` attribute does not require a value.

---

## 17. Reversed List With a Start Value

You can combine `reversed` with `start`.

```html
<ol start="5" reversed>
    <li>Fifth</li>
    <li>Fourth</li>
    <li>Third</li>
</ol>
```

Result:

```text
5. Fifth
4. Fourth
3. Third
```

This can be useful for countdown-style lists or rankings.

---

## 18. The `value` Attribute

The `value` attribute can change the number of an individual `<li>`.

Example:

```html
<ol>
    <li>First</li>
    <li value="5">Fifth</li>
    <li>Sixth</li>
</ol>
```

The numbering becomes approximately:

```text
1. First
5. Fifth
6. Sixth
```

The following items continue from the new value.

---

## 19. Nested Ordered Lists

An ordered list can contain another ordered list.

Example:

```html
<ol>
    <li>
        Learn HTML

        <ol>
            <li>Learn headings</li>
            <li>Learn paragraphs</li>
            <li>Learn links</li>
        </ol>
    </li>

    <li>
        Learn CSS
    </li>
</ol>
```

The structure is approximately:

```text
1. Learn HTML
    1. Learn headings
    2. Learn paragraphs
    3. Learn links
2. Learn CSS
```

Nested lists are useful when a topic has smaller steps or subtopics.

---

## 20. Ordered List Inside an Unordered List

Different types of lists can also be nested.

Example:

```html
<ul>
    <li>
        Web Development

        <ol>
            <li>Learn HTML</li>
            <li>Learn CSS</li>
            <li>Learn JavaScript</li>
        </ol>
    </li>
</ul>
```

Result:

```text
• Web Development
    1. Learn HTML
    2. Learn CSS
    3. Learn JavaScript
```

---

## 21. Unordered List Inside an Ordered List

The opposite is also possible.

```html
<ol>
    <li>
        Frontend

        <ul>
            <li>HTML</li>
            <li>CSS</li>
            <li>JavaScript</li>
        </ul>
    </li>

    <li>Backend</li>
</ol>
```

Result:

```text
1. Frontend
    • HTML
    • CSS
    • JavaScript
2. Backend
```

## 26. Ordered Lists and Navigation

Ordered lists are not normally necessary for basic navigation because the position of navigation links usually does not matter.

For example, this is generally more appropriate:

```html
<ul>
    <li><a href="index.html">Home</a></li>
    <li><a href="courses.html">Courses</a></li>
    <li><a href="about.html">About</a></li>
</ul>
```

Use `<ol>` when the navigation itself represents a meaningful sequence.

---

## 27. Accessibility and Semantic HTML

Using `<ol>` tells the browser that the items have a meaningful order.

For example:

```html
<ol>
    <li>Download the file.</li>
    <li>Open the file.</li>
    <li>Install the software.</li>
</ol>
```

This is more meaningful than manually typing:

```html
<p>1. Download the file.</p>
<p>2. Open the file.</p>
<p>3. Install the software.</p>
```

Semantic HTML gives browsers and assistive technologies useful information about the content structure.

---

## 28. Don't Manually Number Items

Avoid:

```html
<p>1. Open the application.</p>
<p>2. Create a project.</p>
<p>3. Save the file.</p>
```

Prefer:

```html
<ol>
    <li>Open the application.</li>
    <li>Create a project.</li>
    <li>Save the file.</li>
</ol>
```

The browser manages the numbering automatically.

---

## 29. Styling Ordered Lists with CSS

CSS can change the appearance of ordered lists.

Example:

```css
ol {
    padding-left: 30px;
}
```

You can also use:

```css
ol {
    list-style-type: upper-roman;
}
```

This displays Roman numerals.

CSS is useful when you want to control presentation without changing the meaning of the HTML.

---

## 30. CSS vs HTML Numbering

HTML attributes can define the numbering behavior:

```html
<ol type="A">
```

CSS can control the visual list style:

```css
ol {
    list-style-type: upper-alpha;
}
```

Both approaches can affect how the list marker appears.

For normal HTML content, choose the approach that best fits the meaning and presentation requirements of the project.

## 32. Common Mistakes

### Mistake 1: Using `<ul>` When Order Matters

If the items are steps:

```html
<ul>
    <li>Open the file.</li>
    <li>Edit the code.</li>
    <li>Save the file.</li>
</ul>
```

An ordered list is more appropriate:

```html
<ol>
    <li>Open the file.</li>
    <li>Edit the code.</li>
    <li>Save the file.</li>
</ol>
```

---

### Mistake 2: Manually Numbering Items

Avoid:

```html
<ol>
    <li>1. HTML</li>
    <li>2. CSS</li>
    <li>3. JavaScript</li>
</ol>
```

This produces duplicate numbering because the browser already creates the list markers.

Use:

```html
<ol>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ol>
```

---

### Mistake 3: Forgetting `<li>`

Incorrect:

```html
<ol>
    HTML
    CSS
    JavaScript
</ol>
```

Correct:

```html
<ol>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ol>
```

---

### Mistake 4: Using `<br>` to Create Steps

Avoid:

```html
1. Open the file.<br>
2. Edit the code.<br>
3. Save the file.
```

Use semantic HTML:

```html
<ol>
    <li>Open the file.</li>
    <li>Edit the code.</li>
    <li>Save the file.</li>
</ol>
```

---

## Key Points

* `<ol>` creates an ordered list.
* `<li>` creates each list item.
* Ordered lists are used when the order of items matters.
* Browsers automatically create list markers.
* The default ordered list uses numbers.
* The `type` attribute can use `1`, `A`, `a`, `I`, or `i`.
* The `start` attribute changes where numbering begins.
* The `reversed` attribute makes numbering count downward.
* The `value` attribute can change the marker value of an individual list item.
* Ordered lists can contain nested lists.
* `<ol>` and `<ul>` can be nested inside each other.
* Do not manually type numbers inside `<li>` elements.
* Do not use `<br>` or separate paragraphs to create semantic lists.
* Use ordered lists for steps, procedures, recipes, instructions, and other sequences.
* CSS can control the visual appearance of ordered lists.
* Semantic lists provide meaningful structure for browsers and assistive technologies.
