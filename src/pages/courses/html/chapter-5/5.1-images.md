# Chapter 5: Images & Media

## Section 1: Displaying Images

Images make webpages more useful, attractive, and easier to understand.

HTML provides the `<img>` element to display images on a webpage.

Images can be used for:

* Website logos
* Product pictures
* Profile pictures
* Course illustrations
* Diagrams
* Screenshots
* Icons
* Banners

> **Simple idea:** The `<img>` element tells the browser which image to display and provides important information about that image.

---

### 1. The `<img>` Element

The basic syntax is:

```html
<img src="image.jpg" alt="Description of image">
```

The `<img>` element uses attributes to provide information about the image.

The two most important attributes are:

* `src` → tells the browser where the image is
* `alt` → provides alternative text for the image

Example:

```html
<img src="logo.png" alt="CODIFY Logo">
```

---

### 2. The `src` Attribute

`src` stands for **source**.

It tells the browser the location of the image file.

Example:

```html
<img src="logo.png" alt="Website Logo">
```

Here:

```text
src="logo.png"
```

tells the browser to find `logo.png`.

The image can be stored:

* In the same folder
* Inside another folder
* At another location on the website
* At an external URL

---

### 3. Image in the Same Folder

Suppose your project contains:

```text
website/
├── index.html
└── logo.png
```

Since both files are in the same folder:

```html
<img src="logo.png" alt="Website Logo">
```

can be used.

---

### 4. Image Inside a Folder

Suppose your project contains:

```text
website/
├── index.html
└── images/
    └── logo.png
```

The image is inside the `images` folder.

Use:

```html
<img src="images/logo.png" alt="Website Logo">
```

The path is relative to the HTML file.

---

### 5. Image in a Parent Folder

Suppose:

```text
website/
├── images/
│   └── logo.png
└── pages/
    └── about.html
```

The current file is:

```text
pages/about.html
```

To access the image:

```html
<img src="../images/logo.png" alt="Website Logo">
```

Here:

```text
..
```

means to go up one folder.

---

### 6. Using an Absolute Image URL

An image can also be loaded from an external website.

Example:

```html
<img
    src="https://www.example.com/images/photo.jpg"
    alt="Example photo"
>
```

The `src` contains the complete URL.

However, when building your own website, storing and serving your own image files is usually more reliable.

---

### 7. The `alt` Attribute

The `alt` attribute provides **alternative text** for an image.

Example:

```html
<img src="student.jpg" alt="Student studying HTML">
```

The alternative text can be useful when:

* The image cannot be loaded
* A screen reader is reading the page
* The user cannot see the image
* The image is unavailable

> **Important:** Write `alt` text that communicates the purpose or meaning of the image.

---

### 8. Good `alt` Text

Suppose the image shows a laptop displaying HTML code.

Good:

```html
<img src="html-code.jpg" alt="HTML code displayed on a laptop">
```

Less useful:

```html
<img src="html-code.jpg" alt="image">
```

The second example does not explain what the image represents.

---

### 9. Decorative Images

Some images are purely decorative and do not add meaningful information.

For such images, an empty `alt` attribute can be used:

```html
<img src="decoration.png" alt="">
```

This tells assistive technologies that the image is decorative.

Do not simply remove the `alt` attribute.

---

### 10. Why `alt` Text Matters

Imagine this image:

```html
<img src="logo.png" alt="CODIFY logo">
```

If the image fails to load, the browser can display the alternative text.

The user may see something similar to:

```text
CODIFY logo
```

The `alt` text therefore provides useful information even when the image itself is unavailable.

---

### 11. The `<img>` Element Does Not Need a Closing Tag

Unlike elements such as:

```html
<p>Hello</p>
```

the `<img>` element does not have a separate closing tag.

Correct:

```html
<img src="logo.png" alt="Logo">
```

Do not write:

```html
<img src="logo.png" alt="Logo"></img>
```

In HTML, `<img>` is a **void element**.

---

### 12. Adding an Image to a Webpage

Example:

```html
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <title>My Website</title>
</head>

<body>

    <h1>Welcome to CODIFY</h1>

    <img src="images/logo.png" alt="CODIFY Logo">

</body>

</html>
```

The browser loads the image from:

```text
images/logo.png
```

and displays it below the heading.

---

### 13. Controlling Image Size

HTML provides `width` and `height` attributes.

Example:

```html
<img
    src="logo.png"
    alt="CODIFY Logo"
    width="300"
    height="150"
>
```

This tells the browser the displayed dimensions of the image.

However, CSS is generally preferred for controlling presentation and responsive sizing.

Example:

```html
<img
    src="logo.png"
    alt="CODIFY Logo"
    class="logo"
>
```

```css
.logo {
    width: 300px;
    height: auto;
}
```

---

### 14. Why `height: auto` Is Useful

Suppose an image has its width changed.

If you force both width and height to unrelated values, the image can become distorted.

For example:

```css
img {
    width: 300px;
    height: 100px;
}
```

If the original proportions do not match these dimensions, the image may look stretched.

Instead:

```css
img {
    width: 300px;
    height: auto;
}
```

allows the browser to maintain the image's aspect ratio.

---

### 15. Responsive Images

A common CSS rule is:

```css
img {
    max-width: 100%;
    height: auto;
}
```

This prevents an image from becoming wider than its containing element.

For example, on a smaller screen, a large image can shrink to fit the available space.

This is especially useful for:

* Mobile websites
* Tablets
* Responsive layouts
* Course platforms

---

### 16. Image File Paths

Understanding paths is important when displaying images.

Suppose:

```text
website/
├── index.html
├── images/
│   ├── logo.png
│   └── banner.jpg
└── pages/
    └── about.html
```

From `index.html`:

```html
<img src="images/logo.png" alt="Logo">
```

From `about.html`:

```html
<img src="../images/logo.png" alt="Logo">
```

The path changes because the current HTML files are located in different folders.

---

### 17. Common Image Formats

Different image formats are commonly used on websites.

#### JPEG / JPG

Common for photographs.

```text
photo.jpg
```

Good for:

* Photos
* Real-world images
* Images with many colors

#### PNG

Useful when transparency or lossless quality is needed.

```text
logo.png
```

Good for:

* Logos
* Graphics
* Transparent images

#### GIF

Can support simple animations.

```text
animation.gif
```

#### SVG

A vector image format that is especially useful for:

* Logos
* Icons
* Simple graphics

```text
logo.svg
```

#### WebP

A modern image format designed to provide efficient image compression.

```text
photo.webp
```

---

### 18. Choosing an Image Format

There is no single format that is always best.

For example:

| Image            | Possible Format  |
| :--------------- | :--------------- |
| Photograph       | JPG / WebP       |
| Transparent logo | PNG / WebP / SVG |
| Simple icon      | SVG              |
| Simple animation | GIF / WebP       |
| Modern web image | WebP             |

The choice depends on image content, quality requirements, browser support, and performance needs.

---

### 19. Image Loading Errors

If the browser cannot find the image, the image may not appear correctly.

For example:

```html
<img src="images/logo.png" alt="CODIFY Logo">
```

If the actual file is:

```text
image/logo.png
```

instead of:

```text
images/logo.png
```

the path is incorrect.

Always check:

* Folder name
* File name
* File extension
* Relative path
* Uppercase/lowercase differences where relevant

---

### 20. File Name and Path Example

Suppose the actual file is:

```text
images/
└── college-logo.png
```

Correct:

```html
<img src="images/college-logo.png" alt="College Logo">
```

Incorrect:

```html
<img src="images/logo.png" alt="College Logo">
```

The browser looks for a file named `logo.png`, but the actual file is `college-logo.png`.

---

### 21. Real-World Example: College Website

A college website might display its logo:

```html
<header>
    <img
        src="images/college-logo.png"
        alt="ABC Polytechnic College logo"
    >

    <h1>ABC Polytechnic College</h1>
</header>
```

The image helps users identify the institution.

---

### 22. Real-World Example: Online Course

An HTML course could display a lesson illustration:

```html
<section>
    <h2>How HTML Works</h2>

    <img
        src="images/html-structure.png"
        alt="Diagram showing the structure of an HTML document"
    >

    <p>
        HTML provides the structure of a webpage.
    </p>
</section>
```

The image supports the explanation instead of simply decorating the page.

---

### 23. Real-World Example: Product Page

An online store might display a product:

```html
<article>
    <h2>Laptop</h2>

    <img
        src="images/laptop.jpg"
        alt="Silver laptop computer"
    >

    <p>Powerful laptop for everyday work and study.</p>
</article>
```

The `alt` text describes the image's useful content.

---

### 24. Images and Links

An image can also be placed inside an anchor element.

Example:

```html
<a href="index.html">
    <img src="logo.png" alt="CODIFY Home">
</a>
```

Clicking the image activates the link.

This pattern is commonly used for website logos.

---

### 25. Complete Example

```html
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <title>Displaying Images</title>

    <style>
        img {
            max-width: 100%;
            height: auto;
        }
    </style>
</head>

<body>

    <header>
        <a href="index.html">
            <img
                src="images/logo.png"
                alt="CODIFY Logo"
            >
        </a>
    </header>

    <main>

        <h1>Learn HTML</h1>

        <img
            src="images/html-structure.png"
            alt="Diagram showing HTML document structure"
        >

        <p>
            HTML is used to structure content on webpages.
        </p>

    </main>

</body>

</html>
```

This example demonstrates:

* The `<img>` element
* The `src` attribute
* The `alt` attribute
* Relative image paths
* Images inside links
* Responsive image sizing

---

## Key Points

* The `<img>` element is used to display images.
* `src` specifies the location of the image.
* `alt` provides alternative text.
* `<img>` is a void element and does not need a closing tag.
* Image paths can be relative or absolute.
* `..` can be used to move to a parent directory.
* CSS is generally preferred for controlling image presentation.
* `max-width: 100%` can help images fit smaller screens.
* `height: auto` helps preserve the image's aspect ratio.
* Common image formats include JPG, PNG, GIF, SVG, and WebP.
* Decorative images can use an empty `alt=""`.
* Images can also be placed inside `<a>` elements to make them clickable.
* Correct file paths are essential for images to load successfully.
