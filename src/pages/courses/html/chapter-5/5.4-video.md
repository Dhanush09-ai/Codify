# Chapter 5: Images & Media

## Section 4: Video Elements

Videos are an important part of modern websites. They can be used for tutorials, demonstrations, lectures, advertisements, product presentations, and many other types of content.

HTML provides the `<video>` element to add video content directly to a webpage.

> **Simple idea:** Use `<video>` when you want users to watch a video directly on your webpage.

---

## 1. The `<video>` Element

The basic syntax is:

```html
<video controls>
    <source src="video.mp4" type="video/mp4">
</video>
```

The `<video>` element creates a video player.

The `controls` attribute displays controls such as:

* Play
* Pause
* Volume
* Progress bar
* Fullscreen

---

## 2. A Simple Video Example

```html
<video controls>
    <source src="lesson.mp4" type="video/mp4">
</video>
```

If the browser supports the video format, the user can play it using the built-in controls.

---

## 3. The `controls` Attribute

The `controls` attribute tells the browser to display video controls.

Example:

```html
<video controls>
    <source src="html-lesson.mp4" type="video/mp4">
</video>
```

Without `controls`, the browser may not display the normal playback interface.

For a user-controlled video, `controls` is usually important.

---

## 4. Using the `src` Attribute

You can also specify the video file directly using `src`.

```html
<video
    controls
    src="videos/lesson.mp4"
>
</video>
```

Here:

```text
videos/lesson.mp4
```

is the path to the video file.

Just like images and audio, video paths can be relative or absolute.

---

## 5. Using `<source>`

A more flexible method is to use `<source>` inside `<video>`.

```html
<video controls>
    <source src="lesson.mp4" type="video/mp4">
</video>
```

The `<source>` element provides:

* The video file
* The file's MIME type

---

## 6. Multiple Video Sources

Different browsers may support different video formats.

You can provide multiple sources:

```html
<video controls>
    <source src="lesson.mp4" type="video/mp4">
    <source src="lesson.webm" type="video/webm">
</video>
```

The browser can select a source it supports.

> **Simple idea:** Multiple `<source>` elements can provide fallback video formats.

---

## 7. Common Video Formats

Some common video formats used on the web include:

* MP4
* WebM
* Ogg

### MP4

MP4 is widely used for web video.

```html
<video controls>
    <source src="lesson.mp4" type="video/mp4">
</video>
```

It is commonly used for:

* Tutorials
* Course videos
* Product demonstrations
* Recorded lectures

### WebM

WebM is another format designed for web media.

```html
<video controls>
    <source src="lesson.webm" type="video/webm">
</video>
```

### Ogg

Ogg video can also be encountered on the web.

```html
<video controls>
    <source src="lesson.ogv" type="video/ogg">
</video>
```

---

## 8. Video Format Comparison

| Format | Common Use        | General Characteristics   |
| :----- | :---------------- | :------------------------ |
| MP4    | General web video | Widely supported          |
| WebM   | Web video         | Designed for web delivery |
| Ogg    | Web media         | Open media format         |

The best choice depends on the project's requirements and browser support.

---

## 9. The `type` Attribute

The `type` attribute tells the browser what type of video is being provided.

For MP4:

```html
<source
    src="lesson.mp4"
    type="video/mp4"
>
```

For WebM:

```html
<source
    src="lesson.webm"
    type="video/webm"
>
```

For Ogg:

```html
<source
    src="lesson.ogv"
    type="video/ogg"
>
```

The MIME type should match the actual media format.

---

## 10. Fallback Text

You can put text inside the `<video>` element.

```html
<video controls>
    <source src="lesson.mp4" type="video/mp4">

    Your browser does not support HTML video.
</video>
```

The text can provide fallback information if the browser cannot use the video element.

---

## 11. Setting Video Dimensions

The `width` and `height` attributes can specify the video's dimensions.

```html
<video
    controls
    width="640"
    height="360"
>
    <source src="lesson.mp4" type="video/mp4">
</video>
```

Here:

```text
width  = 640 pixels
height = 360 pixels
```

This gives the video a 16:9 display area.

---

## 12. Responsive Video

A fixed width may not work well on every screen.

CSS can be used to make a video responsive.

```css
video {
    max-width: 100%;
    height: auto;
}
```

This allows the video to shrink when the available screen width is smaller.

For example, a large video can fit inside a mobile screen instead of overflowing the page.

---

## 13. The `poster` Attribute

The `poster` attribute specifies an image that is displayed before the video starts playing.

Example:

```html
<video
    controls
    poster="images/html-course.jpg"
>
    <source src="html-course.mp4" type="video/mp4">
</video>
```

The poster image can act as a preview or thumbnail.

> **Simple idea:** `poster` is the preview image shown before playback begins.

---

## 14. Why Use a Poster Image?

A poster image can make a video easier to understand before the user plays it.

For example:

```text
[ HTML Course Preview Image ]

        ▶ Play
```

The image might show:

* Course title
* Speaker
* Topic
* Video thumbnail
* Illustration

---

## 15. The `autoplay` Attribute

The `autoplay` attribute asks the browser to start the video automatically.

```html
<video controls autoplay>
    <source src="intro.mp4" type="video/mp4">
</video>
```

However, modern browsers can restrict autoplay, especially when the video has sound.

Because unexpected video playback can be disruptive, autoplay should be used carefully.

---

## 16. Autoplay with Muted Video

A muted video is more likely to be allowed to autoplay in many browser situations.

Example:

```html
<video
    autoplay
    muted
    loop
>
    <source src="background.mp4" type="video/mp4">
</video>
```

This pattern can be used for certain decorative or background videos.

The user should still be able to access the important content without depending on autoplay.

---

## 17. The `loop` Attribute

The `loop` attribute makes the video start again after it finishes.

Example:

```html
<video controls loop>
    <source src="demonstration.mp4" type="video/mp4">
</video>
```

It can be useful for:

* Short demonstrations
* Repeating animations
* Background videos

---

## 18. The `muted` Attribute

The `muted` attribute starts the video without sound.

```html
<video controls muted>
    <source src="preview.mp4" type="video/mp4">
</video>
```

The user can usually enable sound using the video controls.

---

## 19. Combining Video Attributes

Several attributes can be used together.

```html
<video
    controls
    width="640"
    height="360"
    poster="thumbnail.jpg"
>
    <source src="lesson.mp4" type="video/mp4">
</video>
```

This example provides:

* Playback controls
* Video dimensions
* A preview image
* A video source

---

## 20. The `preload` Attribute

The `preload` attribute gives the browser a hint about how much video data should be loaded before playback.

Common values include:

```text
none
metadata
auto
```

### `none`

```html
<video controls preload="none">
```

The browser is told not to preload the video.

### `metadata`

```html
<video controls preload="metadata">
```

The browser may load information such as the duration.

### `auto`

```html
<video controls preload="auto">
```

The browser may preload more video data.

> **Important:** `preload` is a hint. The browser ultimately decides how much data to load.

---

## 21. Choosing a Preload Value

Videos can be large files.

If a webpage contains many videos, loading all of them immediately can consume a lot of bandwidth.

For example:

```html
<video controls preload="none">
    <source src="large-course-video.mp4" type="video/mp4">
</video>
```

can tell the browser that the video does not need to be preloaded.

---

## 22. Video File Paths

Video paths work similarly to image and audio paths.

Suppose:

```text
website/
├── index.html
└── videos/
    └── lesson.mp4
```

Use:

```html
<video controls>
    <source src="videos/lesson.mp4" type="video/mp4">
</video>
```

If the HTML file is inside another folder:

```text
website/
├── videos/
│   └── lesson.mp4
└── pages/
    └── lesson.html
```

Use:

```html
<video controls>
    <source src="../videos/lesson.mp4" type="video/mp4">
</video>
```

## 26. Video Accessibility

Video content should be accessible to as many users as possible.

For videos containing spoken dialogue, captions are often important.

HTML provides the `<track>` element for text tracks such as captions.

Example:

```html
<video controls>
    <source src="lesson.mp4" type="video/mp4">

    <track
        src="captions.vtt"
        kind="captions"
        srclang="en"
        label="English"
    >
</video>
```

The caption file uses the WebVTT format.

---

## 27. Why Captions Matter

Captions can help:

* Users who are deaf or hard of hearing
* Users watching without sound
* Users learning a language
* Users in noisy or quiet environments
* Users who want to read along

For educational videos, captions can be especially useful.

---

## 28. Video Transcript

For important educational content, a transcript can also be provided.

Example:

```html
<h2>Video Transcript</h2>

<p>
    HTML is a markup language used to structure
    content on webpages.
</p>
```

A transcript gives users access to the information in text form.

---

## 29. Captions vs Transcript

They serve different purposes.

### Captions

Appear while the video is playing.

```text
HTML is used to structure webpages.
```

### Transcript

Provides the spoken content as a separate block of text.

```text
HTML is a markup language used to structure
content on webpages...
```

For educational content, providing both can be useful.

---

## 30. Video File Size

Video files can be much larger than images and audio files.

For example:

```text
short-video.mp4 → 20 MB
course-video.mp4 → 150 MB
```

Large videos can take longer to load and consume more bandwidth.

Consider:

* Appropriate resolution
* Compression
* Video length
* File format
* Hosting method

---

## 31. Video Compression

Video compression can reduce file size.

For example:

```text
Original → 500 MB
Optimized → 100 MB
```

The exact result depends on the video and compression settings.

The goal is to maintain acceptable visual quality while avoiding unnecessary file size.

---

## 32. Avoid Unnecessarily High Resolution

Suppose a video is displayed in a small lesson card.

Using an extremely high-resolution video may waste bandwidth.

Choose a resolution appropriate for the intended display and viewing experience.

For example:

```text
Small preview → lower resolution
Full lesson → higher resolution
```

---

Avoid:

```text

newvideo.mp4
```

Prefer:

```text

```

Meaningful filenames make projects easier to manage.

A project can keep videos in a dedicated directory.

```text
website/
├── index.html

│   └── style.css
├── images/
│   ├── logo.svg

    ├── tags-and-elements.mp4
```

This makes the project easier to maintain.

---

## 35. HTML Video vs External Video Platforms

The `<video>` element is useful when you control the video file and want to serve it directly from your website.

For very large video libraries, websites may use dedicated video hosting or streaming services.

For example, a website could use:

```text
Your website
     ↓
Video hosting service
     ↓
User watches video
```

The best approach depends on:

* Number of videos
* Video size
* Traffic
* Streaming requirements
* Hosting resources

## 37. Common Mistakes

### Mistake 1: Incorrect File Path

```html
<video controls>
    <source src="video/lesson.mp4" type="video/mp4">
</video>
```

Make sure the file actually exists at that location.

---

### Mistake 2: Wrong MIME Type

For MP4:

```html
type="video/mp4"
```

For WebM:

```html
type="video/webm"
```

For Ogg:

```html
type="video/ogg"
```

The type should match the actual video format.

---

### Mistake 3: Forgetting `controls`

```html
<video>
    <source src="lesson.mp4" type="video/mp4">
</video>
```

For a normal user-controlled video, use:

```html
<video controls>
```

---

### Mistake 4: Using Huge Video Files

A very large video can consume unnecessary bandwidth.

Optimize the video appropriately before using it on a webpage.

---

### Mistake 5: No Captions for Important Spoken Content

If a video contains important dialogue, consider providing captions.

```html
<track
    src="captions.vtt"
    kind="captions"
    srclang="en"
    label="English"
>
```

## Key Points

* The `<video>` element is used to add video to a webpage.
* `controls` displays playback controls.
* `<source>` provides video files and their MIME types.
* Multiple `<source>` elements can provide fallback formats.
* Common web video formats include MP4, WebM, and Ogg.
* `poster` specifies the preview image shown before playback.
* `width` and `height` can specify video dimensions.
* CSS can make videos responsive.
* `autoplay` requests automatic playback but may be restricted by browsers.
* `muted` starts a video without sound.
* `loop` repeats the video.
* `preload` provides a hint about how the video should be loaded.
* `<track>` can provide captions and other text tracks.
* Captions improve accessibility.
* Transcripts can provide important video information as text.
* Large video files should be optimized appropriately.
* Meaningful filenames and organized folders make projects easier to maintain.
* The `<video>` element is useful when your website directly serves video files.
