# Chapter 3: Text & Content

## Section 4: Preformatted Text & Code

When displaying normal text, HTML usually ignores extra spaces and line breaks in the source code.

But sometimes we need the browser to **preserve the exact spacing and line breaks**.

This is especially useful when displaying:

* Source code
* Command-line output
* ASCII diagrams
* Text where spacing is meaningful

HTML provides the `<pre>` and `<code>` elements for these situations.

> **Simple idea:** `<pre>` preserves formatting, while `<code>` identifies content as computer code.

---

### 1. What Is Preformatted Text?

**Preformatted text** is text where spaces, tabs, and line breaks are preserved.

HTML provides the `<pre>` element for this purpose.

Example:

```html
<pre>
Line 1
    Line 2
        Line 3
</pre>
```

The browser preserves the spacing and line breaks inside `<pre>`.

The result will look approximately like:

```text
Line 1
    Line 2
        Line 3
```

This is different from normal HTML text.

---

### 2. Normal Text vs `<pre>`

Consider this normal paragraph:

```html
<p>
    Hello
        World
            HTML
</p>
```

The browser normally collapses the extra whitespace.

But with `<pre>`:

```html
<pre>
Hello
    World
        HTML
</pre>
```

the spaces and line breaks are preserved.

> **Remember:** `<pre>` tells the browser that the formatting inside the element is important.

---

### 3. Why Is `<pre>` Useful?

The `<pre>` element is useful when the exact formatting of text matters.

Common uses include:

* Programming code
* Terminal output
* ASCII diagrams
* Fixed-format text
* Examples where spaces and line breaks are meaningful

For example:

```html
<pre>
+----------------+
|    CODIFY      |
+----------------+
</pre>
```

The spaces and line arrangement are preserved.

---

### 4. What Is the `<code>` Element?

The `<code>` element represents **computer code**.

For example:

```html
<p>Use <code>printf()</code> to display output in C.</p>
```

The browser understands that `printf()` is a piece of computer code.

Another example:

```html
<p>Create a file named <code>index.html</code>.</p>
```

The filename is presented as code-related content.

---

### 5. Inline Code

`<code>` is often used for **small pieces of code inside a sentence**.

Example:

```html
<p>
    Use <code>int age = 20;</code> to create an integer variable.
</p>
```

Here, the code is part of a normal paragraph.

Another example:

```html
<p>
    The <code>&lt;h1&gt;</code> element creates a main heading.
</p>
```

This is called **inline code** because it appears within normal text.

---

### 6. `<pre>` vs `<code>`

These elements have different purposes.

| Element       | Purpose                            |
| :------------ | :--------------------------------- |
| `<pre>`       | Preserves spaces and line breaks   |
| `<code>`      | Identifies computer code           |
| `<pre><code>` | Displays a formatted block of code |

For example:

```html
<code>printf("Hello");</code>
```

represents a small piece of code.

While:

```html
<pre><code>
#include <stdio.h>

int main() {
    printf("Hello");
}
</code></pre>
```

represents a larger formatted code block.

---

### 7. Using `<pre>` and `<code>` Together

For multi-line programming examples, `<pre>` and `<code>` are commonly used together.

Example:

```html
<pre><code>
#include <stdio.h>

int main() {
    printf("Hello, World!");
    return 0;
}
</code></pre>
```

Here:

* `<code>` identifies the content as programming code.
* `<pre>` preserves the spaces and line breaks.

This combination is commonly used on programming tutorial websites.

---

### 8. Real-World Example: CODIFY Code Lesson

Imagine CODIFY is displaying a C programming example.

```html
<h2>Hello World in C</h2>

<p>Here is a simple C program:</p>

<pre><code>
#include <stdio.h>

int main() {
    printf("Hello, World!");
    return 0;
}
</code></pre>
```

The user can see the program with its original structure and indentation.

This is much more suitable than putting the entire program inside a normal `<p>` element.

---

### 9. Indentation in Code

Indentation is important in programming examples because it makes the code easier to understand.

For example:

```html
<pre><code>
if (age >= 18) {
    printf("Adult");
}
</code></pre>
```

The indentation makes it clear that `printf()` belongs inside the `if` block.

Because `<pre>` preserves whitespace, the indentation remains visible.

---

### 10. Displaying HTML Code on a Webpage

There is an important problem when displaying HTML code itself.

Suppose we want to show this code as text:

```html
<h1>Hello</h1>
```

If we simply write:

```html
<pre><code>
<h1>Hello</h1>
</code></pre>
```

the browser may interpret `<h1>` as an actual HTML heading instead of displaying it as code.

To display HTML syntax as text, special characters need to be represented using **HTML character references**.

For example:

```html
<pre><code>
&lt;h1&gt;Hello&lt;/h1&gt;
</code></pre>
```

The browser displays:

```text
<h1>Hello</h1>
```

without treating it as an actual heading.

---

### 11. Common HTML Character References

Some characters have special meanings in HTML.

Common examples include:

| Character | Character Reference |
| :-------- | :------------------ |
| `<`       | `&lt;`              |
| `>`       | `&gt;`              |
| `&`       | `&amp;`             |
| `"`       | `&quot;`            |

For example:

```html
<pre><code>
&lt;p&gt;Hello World&lt;/p&gt;
</code></pre>
```

The browser displays:

```text
<p>Hello World</p>
```

as text.

> **Tip:** When displaying HTML code inside a webpage, remember to escape characters that the browser could interpret as HTML markup.

---

### 12. Displaying a C Program

C code does not normally contain HTML tags, so it can be displayed more directly.

Example:

```html
<pre><code>
#include <stdio.h>

int main() {
    int a = 10;
    int b = 20;

    printf("%d", a + b);

    return 0;
}
</code></pre>
```

The `<pre>` element preserves the indentation and line breaks, while `<code>` identifies the content as code.

---

### 13. Displaying Terminal Output

`<pre>` can also be useful for command-line output.

Example:

```html
<pre>
C:\Users\Student&gt; gcc program.c
C:\Users\Student&gt; program.exe

Hello, World!
</pre>
```

The line structure is preserved.

This can be useful in programming tutorials where both commands and their output need to be shown.

---

### 14. `<pre>` Is Not a Replacement for CSS

The `<pre>` element preserves whitespace, but it should not be used simply because you want a particular font, size, or visual design.

For example, don't use:

```html
<pre>
This is just a normal paragraph.
</pre>
```

when a normal paragraph is more appropriate.

Instead:

```html
<p>This is just a normal paragraph.</p>
```

Use `<pre>` when preserving the formatting is actually meaningful.

> **Remember:** HTML provides the meaning and structure. CSS can later control the visual appearance of code blocks.

---

### 15. Real-World Example: ASCII Diagram

Suppose we want to show the structure of a simple website:

```html
<pre>
Website
|
+-- Header
|
+-- Main Content
|   |
|   +-- Article
|   +-- Sidebar
|
+-- Footer
</pre>
```

Without `<pre>`, the spaces and line breaks may not be preserved correctly.

With `<pre>`, the diagram keeps its intended structure.

---

### 16. Code Blocks in Learning Platforms

Programming websites often display code examples using a structure similar to:

```html
<pre><code>
function hello() {
    console.log("Hello");
}
</code></pre>
```

This gives the browser semantic information about the content and preserves the formatting.

A real programming platform may also use CSS and JavaScript to add features such as:

* Syntax highlighting
* Copy buttons
* Line numbers
* Code themes
* Code execution

These features are built on top of the basic HTML structure.

---

### 17. Complete Example

Here is a simple webpage demonstrating both inline code and a code block:

```html
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <title>Preformatted Text and Code</title>
</head>

<body>

    <h1>Learning C Programming</h1>

    <p>
        Use <code>printf()</code> to display output in C.
    </p>

    <h2>Example Program</h2>

    <pre><code>
#include <stdio.h>

int main() {
    printf("Hello, World!");
    return 0;
}
</code></pre>

    <h2>Output</h2>

    <pre>
Hello, World!
    </pre>

</body>

</html>
```

This example demonstrates:

* Normal text using `<p>`
* Inline code using `<code>`
* A formatted code block using `<pre><code>`
* Program output using `<pre>`

---

## Key Points

* `<pre>` is used for **preformatted text**.
* `<pre>` preserves spaces, tabs, and line breaks.
* `<code>` represents computer code.
* `<code>` is useful for both inline code and code blocks.
* `<pre><code>` is commonly used for multi-line programming examples.
* `<pre>` is useful for terminal output and ASCII diagrams.
* HTML code displayed as text may need character references such as `&lt;` and `&gt;`.
* `<pre>` should be used when preserving formatting is meaningful.
* CSS can be used to control the visual appearance of code blocks.
