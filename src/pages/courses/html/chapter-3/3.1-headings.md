# Chapter 3: Text & Content

## Section 1: Headings Hierarchy

Headings are an important part of almost every webpage. They help organize content into clear sections and make a webpage easier to read.

HTML provides **six levels of headings**, from `<h1>` to `<h6>`.

> **Simple idea:** Headings create a clear **content hierarchy**, from the most important heading to smaller subheadings.

---

### 1. What Are HTML Headings?

HTML headings are used to give titles to sections of a webpage.

The six heading elements are:

```html
<h1>Heading 1</h1>
<h2>Heading 2</h2>
<h3>Heading 3</h3>
<h4>Heading 4</h4>
<h5>Heading 5</h5>
<h6>Heading 6</h6>
```

The number represents the heading level.

* `<h1>` is the highest-level heading.
* `<h2>` is a subheading of `<h1>`.
* `<h3>` can be a subheading of `<h2>`.
* This continues down to `<h6>`.

---

### 2. The Six Heading Levels

HTML provides six heading levels:

| Tag    | Typical Use          |
| :----- | :------------------- |
| `<h1>` | Main page heading    |
| `<h2>` | Major section        |
| `<h3>` | Subsection           |
| `<h4>` | Smaller subsection   |
| `<h5>` | Further subdivision  |
| `<h6>` | Lowest heading level |

For example:

```html
<h1>HTML Course</h1>

<h2>Chapter 1: Introduction</h2>

<h3>What is HTML?</h3>

<h4>HTML Elements</h4>
```

This creates a clear relationship between the sections.

---

### 3. What Is Heading Hierarchy?

**Heading hierarchy** means arranging headings according to their level and importance.

For example:

```text
<h1>HTML Course
    │
    ├── <h2>Introduction
    │       ├── <h3>What is HTML?
    │       └── <h3>History of HTML
    │
    └── <h2>HTML Basics
            ├── <h3>Tags
            └── <h3>Elements
```

The structure makes it easier to understand how different sections are related.

---

### 4. The `<h1>` Heading

`<h1>` is normally used for the **main heading or main title** of a page.

Example:

```html
<h1>Learn HTML</h1>
```

For a college webpage:

```html
<h1>ABC Polytechnic College</h1>
```

The `<h1>` should describe the main purpose or topic of the page.

For example, on a course page:

```html
<h1>HTML Tutorial</h1>
```

---

### 5. The `<h2>` Heading

`<h2>` is commonly used for major sections under the main heading.

Example:

```html
<h1>HTML Tutorial</h1>

<h2>Introduction to HTML</h2>

<h2>HTML Elements</h2>

<h2>HTML Forms</h2>
```

Here, all three `<h2>` elements represent major sections of the HTML tutorial.

---

### 6. The `<h3>` Heading

`<h3>` can be used for subsections inside an `<h2>` section.

For example:

```html
<h1>HTML Tutorial</h1>

<h2>Introduction to HTML</h2>

<h3>What is HTML?</h3>
<p>HTML is used to structure webpages.</p>

<h3>History of HTML</h3>
<p>HTML has evolved over many years.</p>
```

Here, `What is HTML?` and `History of HTML` are subsections of `Introduction to HTML`.

---

### 7. Headings from `<h4>` to `<h6>`

The lower heading levels are useful when content needs more detailed organization.

For example:

```html
<h2>Web Development</h2>

<h3>Frontend Development</h3>

<h4>HTML</h4>

<h5>HTML Elements</h5>

<h6>Heading Elements</h6>
```

Most beginner webpages will mainly use `<h1>`, `<h2>`, and `<h3>`.

The other levels are useful for deeply structured content.

---

### 8. Heading Size Is Not the Main Purpose

Browsers normally display different heading levels at different sizes.

For example:

```html
<h1>Main Heading</h1>
<h2>Section Heading</h2>
<h3>Subsection Heading</h3>
```

The `<h1>` usually appears larger than `<h2>`, and `<h2>` usually appears larger than `<h3>`.

However, **heading levels should not be chosen only because of their visual size**.

Do not use:

```html
<h6>This looks like the size I want</h6>
```

just because you want small text.

If you want to change the visual size of text, CSS should be used.

> **Remember:** HTML headings describe **structure and importance**. CSS controls their visual appearance.

---

### 9. A Good Heading Structure

Consider a course webpage:

```html
<h1>HTML Course</h1>

<h2>Chapter 1: Introduction</h2>

<h3>What is HTML?</h3>
<h3>History of HTML</h3>

<h2>Chapter 2: HTML Building Blocks</h2>

<h3>Tags and Elements</h3>
<h3>HTML Boilerplate</h3>

<h2>Chapter 3: Text and Content</h2>

<h3>Headings</h3>
<h3>Paragraphs</h3>
```

This creates a logical structure:

```text
HTML Course
│
├── Chapter 1
│   ├── What is HTML?
│   └── History of HTML
│
├── Chapter 2
│   ├── Tags and Elements
│   └── HTML Boilerplate
│
└── Chapter 3
    ├── Headings
    └── Paragraphs
```

---

### 10. Avoid Skipping Levels Without a Reason

It is generally better to keep heading levels logically organized.

For example:

```html
<h1>HTML Course</h1>
<h2>HTML Basics</h2>
<h3>HTML Elements</h3>
```

is easier to understand than:

```html
<h1>HTML Course</h1>
<h4>HTML Basics</h4>
<h2>HTML Elements</h2>
```

The second structure does not clearly communicate the intended hierarchy.

> **Tip:** Choose heading levels based on the structure of your content, not simply on how large you want the text to appear.

---

### 11. Headings and Accessibility

Headings are also important for **accessibility**.

People using screen readers can use headings to understand the structure of a webpage and move between sections.

A logical heading structure helps users understand:

* What the page is about.
* Where major sections begin.
* Which content belongs to each section.
* How sections relate to each other.

This is another reason to use headings according to their meaning rather than only their appearance.

---

### 12. Real-World Example: College Website

Imagine a college website with information about departments.

A suitable structure could be:

```html
<h1>ABC Polytechnic</h1>

<h2>About the College</h2>

<h2>Departments</h2>

<h3>Computer Engineering</h3>
<p>Information about the Computer Engineering department.</p>

<h3>Electronics Engineering</h3>
<p>Information about the Electronics Engineering department.</p>

<h3>Mechanical Engineering</h3>
<p>Information about the Mechanical Engineering department.</p>

<h2>Contact Us</h2>
```

Here:

* `<h1>` identifies the main page.
* `<h2>` identifies major sections.
* `<h3>` identifies individual departments.

This creates a logical content hierarchy.

---

### 13. Headings and SEO

Search engines use many signals to understand webpage content, and headings help communicate the structure and topics of a page.

A clear heading structure can make the content easier to understand for both users and software.

For example:

```html
<h1>Learn HTML</h1>

<h2>HTML Basics</h2>

<h3>Tags</h3>
<h3>Elements</h3>

<h2>HTML Forms</h2>

<h3>Input Fields</h3>
```

The headings clearly communicate the relationship between the topics.

> **Important:** Do not fill headings with unnecessary keywords just for search engines. Write useful, meaningful headings for the actual content.

---

### 14. Complete Example

Here is a complete example showing a useful heading hierarchy:

```html
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <title>CODIFY HTML Course</title>
</head>

<body>

    <h1>HTML Course</h1>

    <h2>Introduction</h2>
    <h3>What is HTML?</h3>
    <p>HTML is used to structure webpages.</p>

    <h3>History of HTML</h3>
    <p>HTML has evolved over time.</p>

    <h2>HTML Building Blocks</h2>
    <h3>Tags and Elements</h3>
    <p>Tags and elements form the basic structure of HTML.</p>

    <h3>Attributes</h3>
    <p>Attributes provide additional information about elements.</p>

</body>

</html>
```

This is a simple example of using headings to organize a webpage.

---

## Key Points

* HTML provides **six heading levels**, from `<h1>` to `<h6>`.
* `<h1>` is normally used for the main heading of a page.
* `<h2>` is commonly used for major sections.
* `<h3>` and lower levels can be used for subsections.
* Heading levels should represent the **structure and importance** of content.
* Do not choose heading levels only because of their visual size.
* Use CSS when you need to change the appearance or size of text.
* A logical heading hierarchy improves readability and accessibility.
* Meaningful headings can also help software understand the structure of a webpage.
