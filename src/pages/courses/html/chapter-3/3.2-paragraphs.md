# Chapter 3: Text & Content

## Section 2: Paragraphs & Line Breaks

Webpages contain different types of text such as headings, paragraphs, instructions, descriptions, and messages.

In HTML, the `<p>` element is used for paragraphs, while the `<br>` element is used when you need a line break inside text.

> **Simple idea:** Use `<p>` for separate paragraphs and `<br>` when you need to start text on a new line without creating a new paragraph.

---

### 1. What Is a Paragraph?

A **paragraph** is a block of related text.

HTML uses the `<p>` element to create a paragraph.

Example:

```html
<p>HTML is used to structure webpages.</p>
```

The opening tag is:

```html
<p>
```

The closing tag is:

```html
</p>
```

The text between them is the paragraph content.

---

### 2. Creating Multiple Paragraphs

You can create multiple paragraphs by using multiple `<p>` elements.

```html
<p>HTML is used to structure webpages.</p>

<p>CSS is used to style webpages.</p>

<p>JavaScript can add interaction to webpages.</p>
```

The browser displays each paragraph as a separate block of text.

For example:

```text
HTML is used to structure webpages.

CSS is used to style webpages.

JavaScript can add interaction to webpages.
```

This makes longer content easier to read.

---

### 3. Why Use `<p>` Instead of Just Writing Text?

Consider:

```html
HTML is used to structure webpages.
CSS is used to style webpages.
JavaScript can add interaction.
```

Although the browser can display the text, the HTML does not clearly identify the separate pieces as paragraphs.

A better structure is:

```html
<p>HTML is used to structure webpages.</p>
<p>CSS is used to style webpages.</p>
<p>JavaScript can add interaction.</p>
```

The `<p>` element gives the text meaningful structure.

> **Remember:** HTML is about describing the structure and meaning of content, not just making text appear on the screen.

---

### 4. Paragraphs in a Real-World Webpage

Imagine an "About Us" section on a college website.

```html
<h2>About Our College</h2>

<p>ABC Polytechnic was established to provide quality technical education.</p>

<p>Our college offers several diploma programs for students.</p>
```

Here:

* `<h2>` identifies the section heading.
* The first `<p>` contains the first paragraph.
* The second `<p>` contains another paragraph.

This creates a clear content structure.

---

### 5. What Is a Line Break?

A **line break** moves the following text to a new line.

HTML provides the `<br>` element for this purpose.

Example:

```html
<p>Hello<br>Welcome to CODIFY.</p>
```

The browser displays:

```text
Hello
Welcome to CODIFY.
```

The `<br>` element does not create a new paragraph. It simply moves the next content to the next line.

---

### 6. `<br>` Is a Void Element

Unlike `<p>`, the `<br>` element does not need a closing tag.

Correct:

```html
<br>
```

Do not write:

```html
</br>
```

The `<br>` element is a **void element**.

It does not contain content between an opening and closing tag.

---

### 7. Paragraph vs Line Break

It is important to understand the difference.

A paragraph:

```html
<p>First paragraph.</p>

<p>Second paragraph.</p>
```

represents two separate blocks of content.

A line break:

```html
<p>First line<br>Second line</p>
```

keeps the text within the same paragraph but moves part of it to a new line.

Think of it like this:

```text
<p> → New paragraph
<br> → New line
```

---

### 8. When Should You Use `<br>`?

Use `<br>` when a line break is actually part of the content.

For example, an address can naturally contain separate lines:

```html
<p>
    ABC Polytechnic<br>
    Main Road<br>
    Hyderabad<br>
    Telangana
</p>
```

The browser displays the address on separate lines.

Another example is a poem or a short piece of text where the line breaks are meaningful:

```html
<p>
    Line one<br>
    Line two<br>
    Line three
</p>
```

---

### 9. Do Not Use `<br>` for Page Spacing

A common beginner mistake is using many `<br>` elements to create large empty spaces.

For example:

```html
<h1>Welcome</h1>

<br>
<br>
<br>
<br>

<p>Learn HTML with CODIFY.</p>
```

This is not a good way to create layout spacing.

If you need to control spacing, CSS should normally be used.

> **Remember:** `<br>` is for a meaningful **line break**, not for controlling page layout.

---

### 10. Whitespace in HTML

HTML generally treats multiple spaces and line breaks in the source code as normal whitespace when displaying text.

For example:

```html
<p>Hello       World</p>
```

The browser will normally display the words with ordinary spacing rather than preserving every space exactly as written.

Similarly:

```html
<p>
    Hello
    World
</p>
```

will not automatically display "Hello" and "World" on separate lines just because they were written on separate lines in the HTML source.

If you specifically want a line break in the displayed content, use:

```html
<br>
```

---

### 11. Example of Whitespace vs `<br>`

This:

```html
<p>
    Hello
    World
</p>
```

does not mean:

```text
Hello
World
```

To explicitly create the line break:

```html
<p>
    Hello<br>
    World
</p>
```

Now the browser displays:

```text
Hello
World
```

This difference is important when creating structured text.

---

### 12. Combining Headings, Paragraphs, and Line Breaks

We can combine these elements to create a simple webpage:

```html
<h1>About CODIFY</h1>

<p>CODIFY is a student-friendly learning platform.</p>

<h2>Our Goal</h2>

<p>
    Learn programming step by step.<br>
    Practice regularly.<br>
    Build real projects.
</p>
```

Here:

* `<h1>` creates the main heading.
* `<h2>` creates a section heading.
* `<p>` creates paragraphs.
* `<br>` creates line breaks inside the paragraph.

---

### 13. Real-World Example: Contact Information

A contact section is another good use of `<br>`.

```html
<h2>Contact Us</h2>

<p>
    CODIFY Learning Center<br>
    Main Road<br>
    Hyderabad, Telangana<br>
    India
</p>
```

Each `<br>` creates a new line while keeping the contact information together as one block.

---

### 14. Real-World Example: Student Introduction

A simple student introduction could look like:

```html
<h1>Student Profile</h1>

<p>
    Name: Mohammed Owais<br>
    Course: Computer Engineering<br>
    Interest: Web Development
</p>
```

This is useful when several short pieces of related information need to appear on separate lines.

For larger structured information, other HTML elements such as lists may be more appropriate. We will learn about those later.

---

### 15. A Complete Example

Here is a simple webpage using headings, paragraphs, and line breaks:

```html
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <title>Paragraphs and Line Breaks</title>
</head>

<body>

    <h1>Welcome to CODIFY</h1>

    <p>
        CODIFY helps students learn programming
        and web development step by step.
    </p>

    <h2>What We Learn</h2>

    <p>
        HTML<br>
        CSS<br>
        JavaScript
    </p>

    <h2>Contact</h2>

    <p>
        CODIFY Learning Center<br>
        Hyderabad, Telangana<br>
        India
    </p>

</body>

</html>
```

This example demonstrates how different text elements can work together to create a readable webpage.

---

## Key Points

* The `<p>` element is used to create a paragraph.
* Each `<p>` element represents a separate paragraph of content.
* The `<br>` element creates a line break.
* `<br>` is a void element and does not need a closing tag.
* A paragraph and a line break have different purposes.
* Use `<p>` for separate blocks of related text.
* Use `<br>` when a line break is meaningful to the content.
* Do not use many `<br>` elements to create page spacing.
* CSS should normally be used for layout and spacing.
* Line breaks written in HTML source code do not automatically become visible line breaks in the browser.
