# Chapter 3: Text & Content

## Section 3: Text Formatting

Text is one of the most important parts of a webpage. HTML provides several elements that can give text a specific **meaning or emphasis**.

For example, we may want to make text important, emphasize a word, show a deleted price, or display computer-related content.

> **Simple idea:** HTML text-formatting elements can describe the **meaning and purpose** of text. CSS can be used later to control how that text looks.

---

### 1. Bold Text with `<b>`

The `<b>` element is used to draw attention to text without adding special importance to its meaning.

Example:

```html
<p>This is <b>important information</b> for students.</p>
```

The text inside `<b>` is normally displayed in bold.

Another example:

```html
<p>Learn <b>HTML</b> with CODIFY.</p>
```

> **Remember:** `<b>` mainly draws visual attention to text.

---

### 2. Important Text with `<strong>`

The `<strong>` element indicates that the text has **strong importance**.

Example:

```html
<p><strong>Important:</strong> Save your work regularly.</p>
```

Browsers normally display `<strong>` text in bold, but its meaning is more important than simply making text bold.

For example:

```html
<p>
    <strong>Warning:</strong> Do not delete this file.
</p>
```

The word "Warning" is important information, so `<strong>` is appropriate.

### `<b>` vs `<strong>`

```html
<b>Important</b>
```

mainly draws attention to the text.

```html
<strong>Important</strong>
```

indicates that the text has strong importance.

> **Tip:** Use `<strong>` when the text is actually important, rather than choosing it only because it looks bold.

---

### 3. Italic Text with `<i>`

The `<i>` element is used for text that is set apart from the surrounding text, often for terms, technical words, or other special text.

Example:

```html
<p>The word <i>HTML</i> stands for HyperText Markup Language.</p>
```

The text inside `<i>` is normally displayed in an italic style.

Another example:

```html
<p>The term <i>metadata</i> describes information about a document.</p>
```

> **Remember:** `<i>` is not simply a replacement for CSS. It can indicate that text is set apart from the surrounding content.

---

### 4. Emphasized Text with `<em>`

The `<em>` element represents **emphasis**.

Example:

```html
<p>You <em>must</em> save your file before closing the editor.</p>
```

Browsers normally display `<em>` text in italics.

The important difference is that `<em>` gives the text semantic emphasis.

For example:

```html
<p>Always <em>check</em> your code before submitting it.</p>
```

The word "check" is emphasized as part of the meaning of the sentence.

### `<i>` vs `<em>`

```html
<i>HTML</i>
```

sets the term apart from the surrounding text.

```html
<em>must</em>
```

adds emphasis to the meaning of the word.

> **Simple idea:** Use `<em>` when you want to emphasize the meaning of a word or phrase.

---

### 5. Underlined Text with `<u>`

The `<u>` element represents text that is marked or annotated in some way.

Example:

```html
<p>Please read the <u>terms and conditions</u>.</p>
```

Browsers commonly display the text with an underline.

However, underlining can sometimes be confused with links.

For normal visual styling, CSS is generally a better choice.

---

### 6. Smaller Text with `<small>`

The `<small>` element represents smaller or less prominent text.

Example:

```html
<p>HTML Course <small>Updated in 2026</small></p>
```

It is often useful for supporting information, notes, disclaimers, or copyright text.

Another example:

```html
<p>Price: ₹500 <small>including applicable taxes</small></p>
```

The main information remains prominent while the additional information is less prominent.

---

### 7. Deleted Text with `<del>`

The `<del>` element represents text that has been **deleted or removed**.

Example:

```html
<p>Old price: <del>₹1000</del></p>
```

Browsers normally display deleted text with a line through it.

A common real-world example is a product price:

```html
<p>
    Original Price: <del>₹1000</del>
</p>
```

The deleted text communicates that the original value is no longer current.

---

### 8. Inserted Text with `<ins>`

The `<ins>` element represents text that has been **inserted or added**.

Example:

```html
<p>
    New price: <ins>₹800</ins>
</p>
```

Browsers commonly display inserted text with an underline.

`<ins>` and `<del>` can be used together to show a change:

```html
<p>
    Price:
    <del>₹1000</del>
    <ins>₹800</ins>
</p>
```

This can communicate that the old price was changed to a new price.

---

### 9. Superscript with `<sup>`

The `<sup>` element displays text as **superscript**, meaning it appears slightly above the normal text line.

Example:

```html
<p>10<sup>2</sup> = 100</p>
```

This is useful for mathematical expressions and other content.

Another common example is an ordinal:

```html
<p>1<sup>st</sup> position</p>
```

The `st` appears above the normal text.

---

### 10. Subscript with `<sub>`

The `<sub>` element displays text as **subscript**, meaning it appears slightly below the normal text line.

A common example is a chemical formula:

```html
<p>H<sub>2</sub>O</p>
```

This displays the `2` below the normal text line.

Another example:

```html
<p>CO<sub>2</sub></p>
```

Subscript is useful for chemical formulas and mathematical notation.

---

### 11. Combining Formatting Elements

HTML formatting elements can be combined when appropriate.

For example:

```html
<p>
    <strong>Important:</strong>
    You should <em>always</em> save your work.
</p>
```

Here:

* `<strong>` indicates important information.
* `<em>` emphasizes a particular word.

Another example:

```html
<p>
    <strong>Price:</strong>
    <del>₹1000</del>
    <ins>₹800</ins>
</p>
```

The elements communicate different meanings.

---

### 12. Nesting Formatting Elements

Formatting elements can be nested.

For example:

```html
<p>
    <strong>This is <em>very important</em>.</strong>
</p>
```

Here, `<em>` is inside `<strong>`.

The structure is:

```text
<strong>
    This is
        <em>very important</em>
</strong>
```

When nesting elements, make sure the tags are properly closed.

Correct:

```html
<strong><em>Important text</em></strong>
```

Incorrect:

```html
<strong><em>Important text</strong></em>
```

> **Remember:** Close nested elements in the reverse order in which they were opened.

---

### 13. Code Text with `<code>`

The `<code>` element represents a piece of computer code.

Example:

```html
<p>Use the <code>printf()</code> function to display output in C.</p>
```

It is useful when explaining programming concepts.

Another example:

```html
<p>Create a file named <code>index.html</code>.</p>
```

This helps distinguish code-related text from ordinary text.

---

### 14. Preformatted Text with `<pre>`

The `<pre>` element represents **preformatted text**.

Whitespace and line breaks inside `<pre>` are generally preserved.

Example:

```html
<pre>
Line 1
    Line 2
        Line 3
</pre>
```

The spacing and line breaks are displayed in the browser.

This can be useful for displaying formatted text or code examples.

---

### 15. `<code>` and `<pre>` Together

For displaying a block of code, `<code>` is often used together with `<pre>`.

Example:

```html
<pre><code>
#include <stdio.h>

int main() {
    printf("Hello World");
}
</code></pre>
```

Here:

* `<code>` identifies the content as code.
* `<pre>` preserves the formatting and line breaks.

This combination is commonly used for code examples.

---

### 16. Real-World Example: Product Page

Imagine an online store showing a discounted product.

```html
<h2>Wireless Keyboard</h2>

<p>
    Original Price:
    <del>₹2000</del>
</p>

<p>
    Offer Price:
    <strong>₹1499</strong>
</p>

<p>
    <small>Limited-time offer.</small>
</p>
```

Different elements communicate different information:

* `<del>` shows the old price.
* `<strong>` highlights the important current price.
* `<small>` displays supporting information.

---

### 17. Real-World Example: Learning Website

A programming lesson might use several formatting elements:

```html
<h2>Important Concepts</h2>

<p>
    You <strong>must</strong> understand variables before
    learning advanced programming.
</p>

<p>
    For example, use <code>int age = 20;</code> to declare
    an integer variable in C.
</p>

<p>
    Water is represented by H<sub>2</sub>O.
</p>
```

This makes the content more meaningful and easier to understand.

---

### 18. HTML Meaning vs Visual Appearance

It is important to understand that HTML elements can communicate meaning, while CSS controls presentation.

For example:

```html
<strong>Important</strong>
```

means that the text is important.

If you only want to make text visually bold, CSS can be used.

Similarly, instead of using HTML elements simply to control font size, color, or spacing, use CSS for visual design.

> **Good practice:** Use HTML for **meaning and structure** and CSS for **appearance and layout**.

---

## Key Points

* `<b>` draws attention to text without adding special importance.
* `<strong>` represents text with strong importance.
* `<i>` sets text apart from surrounding content.
* `<em>` represents emphasis.
* `<u>` represents marked or annotated text and is commonly displayed underlined.
* `<small>` represents less prominent or supporting text.
* `<del>` represents deleted or removed content.
* `<ins>` represents inserted or added content.
* `<sup>` displays superscript text.
* `<sub>` displays subscript text.
* `<code>` represents computer code.
* `<pre>` preserves whitespace and line breaks.
* `<pre>` and `<code>` can be combined to display formatted code.
* HTML elements should be chosen based on meaning, while CSS should normally handle visual styling.
