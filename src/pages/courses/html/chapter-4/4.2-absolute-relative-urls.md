# Chapter 4: Links & Navigation

## Section 2: Absolute vs. Relative URLs

When creating links in HTML, you need to tell the browser **where the resource is located**.

There are two common ways to specify a URL:

* **Absolute URL**
* **Relative URL**

Understanding the difference is important when building websites with multiple pages, folders, images, stylesheets, and other resources.

> **Simple idea:** An absolute URL gives the complete address, while a relative URL gives the path from the current page.

---

### 1. What Is a URL?

**URL** stands for **Uniform Resource Locator**.

A URL is an address used to locate a resource on the web or inside a website.

For example:

```text id="n4q8yx"
https://www.example.com/about.html
```

This tells the browser where to find a particular resource.

URLs can be used with many HTML elements and attributes.

For example:

```html id="k7v2pm"
<a href="https://www.example.com">Visit Example</a>
```

Here, the URL is stored in the `href` attribute.

---

### 2. What Is an Absolute URL?

An **absolute URL** provides the complete address of a resource.

Example:

```html id="m8c3qa"
<a href="https://www.example.com/about.html">
    About Us
</a>
```

The browser has all the information it needs to locate the resource.

An absolute URL commonly contains:

```text id="x2v7kp"
https://www.example.com/about.html
│      │               │
│      │               └── Path
│      └────────────────── Domain
└───────────────────────── Protocol
```

---

### 3. Parts of an Absolute URL

Consider:

```text id="r5n9wb"
https://www.example.com/courses/html.html
```

It contains:

* `https` → protocol
* `www.example.com` → domain
* `/courses/html.html` → path

Together, these form the complete address.

---

### 4. Examples of Absolute URLs

Here are some examples:

```html id="p7m4dc"
<a href="https://www.google.com">Google</a>

<a href="https://www.example.com/about.html">
    About
</a>

<a href="https://www.example.com/images/logo.png">
    Logo
</a>
```

Each URL provides a complete destination.

Absolute URLs are especially useful when linking to resources on another website.

---

### 5. What Is a Relative URL?

A **relative URL** specifies the location of a resource relative to the current webpage.

For example:

```html id="q3x8na"
<a href="about.html">About Us</a>
```

The browser interprets `about.html` based on the location of the current page.

Suppose the current page is:

```text id="k9m2wd"
/website/index.html
```

and the file is:

```text id="u6p4zs"
/website/about.html
```

Then:

```html id="e8r5vt"
<a href="about.html">About Us</a>
```

can be used to link from `index.html` to `about.html`.

---

### 6. Why Are Relative URLs Useful?

Relative URLs are useful when working with your own website.

They allow you to link between files without writing the complete domain every time.

For example:

```html id="a2c6mv"
<a href="about.html">About</a>
<a href="contact.html">Contact</a>
<a href="courses.html">Courses</a>
```

This is convenient for a website containing many pages.

---

### 7. Absolute vs. Relative URL

Consider these two links:

```html id="v8q3mx"
<a href="https://www.example.com/about.html">
    About
</a>
```

and:

```html id="z5n7pc"
<a href="about.html">
    About
</a>
```

The first is an **absolute URL**.

The second is a **relative URL**.

| Feature                              | Absolute URL | Relative URL |
| :----------------------------------- | :----------- | :----------- |
| Complete address                     | Yes          | No           |
| Usually contains domain              | Yes          | No           |
| Depends on current page location     | No           | Yes          |
| Useful for external websites         | Yes          | Usually not  |
| Useful for pages inside your project | Yes          | Yes          |

---

### 8. Website Folder Structure

Understanding folders makes relative URLs much easier.

Imagine this project:

```text id="w6k3qp"
website/
│
├── index.html
├── about.html
├── contact.html
│
├── courses/
│   ├── html.html
│   └── css.html
│
└── images/
    └── logo.png
```

The files are organized into different folders.

The relative URL depends on **where the current HTML file is located**.

---

### 9. Linking to a File in the Same Folder

Suppose you are inside:

```text id="c8r4md"
website/index.html
```

and want to open:

```text id="j5t7vx"
website/about.html
```

Use:

```html id="z9p2wk"
<a href="about.html">About</a>
```

Both files are in the same folder.

---

### 10. Linking to a File Inside a Folder

Suppose the current page is:

```text id="a4m7nx"
website/index.html
```

and you want to open:

```text id="p3v8cq"
website/courses/html.html
```

Use:

```html id="s6d2yk"
<a href="courses/html.html">HTML Course</a>
```

The browser starts from the current folder and enters the `courses` folder.

---

### 11. Linking to a File in a Parent Folder

The `..` notation means **go up one folder**.

Suppose the structure is:

```text id="f8w3mq"
website/
├── index.html
└── courses/
    └── html.html
```

The current page is:

```text id="r6k2vz"
courses/html.html
```

To return to `index.html`, use:

```html id="d4p9xs"
<a href="../index.html">Home</a>
```

Here:

```text id="q1n7bc"
..
```

means go up one directory.

---

### 12. Going Up Multiple Folders

You can use `..` more than once.

Suppose:

```text id="v9c4mx"
website/
├── index.html
└── courses/
    └── html/
        └── chapter1/
            └── lesson.html
```

The current page is:

```text id="h2k7qa"
lesson.html
```

To reach `index.html`, you need to go up three folders:

```html id="n6r3wp"
<a href="../../../index.html">Home</a>
```

Each `..` moves up one folder.

```text id="7xq5km"
..     → chapter1 → html
../..  → html → courses
../../.. → courses → website
```

---

### 13. Linking to an Image

Suppose:

```text id="m4w8ps"
website/
├── index.html
└── images/
    └── logo.png
```

From `index.html`, the image can be referenced using:

```html id="k7n3vx"
<img src="images/logo.png" alt="Website Logo">
```

This is a relative URL because the path is relative to `index.html`.

---

### 14. Linking from a Nested Folder

Now suppose the structure is:

```text id="q8m2vd"
website/
├── index.html
├── images/
│   └── logo.png
└── pages/
    └── about.html
```

Inside `about.html`, the image is one folder above and then inside `images`.

Use:

```html id="b5r9kx"
<img src="../images/logo.png" alt="Website Logo">
```

The path works like this:

```text id="e7c3mw"
.. 
↓
website/

images/logo.png
↓
website/images/logo.png
```

---

### 15. Relative URLs Depend on the Current Page

This is one of the most important things to remember.

Suppose:

```text id="s3v8qn"
website/
├── index.html
├── images/
│   └── logo.png
└── pages/
    └── about.html
```

From `index.html`:

```html id="x6k2pb"
<img src="images/logo.png" alt="Logo">
```

From `about.html`:

```html id="c9m4wt"
<img src="../images/logo.png" alt="Logo">
```

The destination is the same, but the relative path is different because the current pages are in different folders.

> **Remember:** A relative URL is always interpreted based on the location of the current document.

---

### 16. Root-Relative URLs

A path beginning with `/` can be relative to the **website's root**.

Example:

```html id="z7p3vn"
<a href="/courses/html.html">HTML Course</a>
```

The browser interprets `/courses/html.html` from the root of the website.

This is different from:

```html id="k5m8rx"
<a href="courses/html.html">HTML Course</a>
```

The second path is relative to the current document's location.

> **Note:** Root-relative paths depend on the website being served from an appropriate root. They may behave differently when opening files directly from your computer.

---

### 17. Absolute URLs for External Websites

Suppose your website has a link to another website.

Using an absolute URL is appropriate:

```html id="u3x7mp"
<a href="https://www.example.com">
    Visit Example
</a>
```

The complete domain is included because the destination is outside your own project.

---

### 18. Relative URLs for Your Own Pages

Suppose your project contains:

```text id="j8q4yc"
website/
├── index.html
├── about.html
└── contact.html
```

You can use:

```html id="h2m6vp"
<a href="about.html">About</a>
<a href="contact.html">Contact</a>
```

This keeps the links short and easy to maintain.

---

### 19. Real-World Example: CODIFY Website

Imagine a simplified CODIFY website:

```text id="p6x9kw"
codify/
│
├── index.html
├── about.html
│
├── courses/
│   ├── html.html
│   └── c.html
│
└── images/
    └── logo.png
```

From `index.html`, you could write:

```html id="r4v8ns"
<nav>
    <a href="index.html">Home</a>
    <a href="about.html">About</a>
    <a href="courses/html.html">HTML</a>
    <a href="courses/c.html">C Programming</a>
</nav>
```

All of these are relative URLs.

For an external website:

```html id="m7c2qa"
<a href="https://www.example.com">
    External Website
</a>
```

This is an absolute URL.

### 20. Real-World Example: Course Lessons

Consider a course structure:

```text id="w3n8pk"
html-course/
├── index.html
└── chapter-1/
    ├── 1.1-introduction.html
    ├── 1.2-what-is-html.html
    └── 1.3-environment.html
```

From `index.html`, you can link to:

```html id="d5k7mx"
<a href="chapter-1/1.1-introduction.html">
    Introduction
</a>

<a href="chapter-1/1.2-what-is-html.html">
    What is HTML?
</a>

<a href="chapter-1/1.3-environment.html">
    Setting Up Your Environment
</a>
```

The paths are relative to `index.html`.

---

### 21. Common Mistake: Wrong Relative Path

Suppose:

```text id="n9x4vc"
website/
├── index.html
└── pages/
    └── about.html
```

Inside `about.html`, this is incorrect if you want to return to `index.html`:

```html id="q2m7ws"
<a href="index.html">Home</a>
```

Why?

Because the browser looks for:

```text id="a6k3yp"
website/pages/index.html
```

But the actual file is:

```text id="c8v5rn"
website/index.html
```

The correct path is:

```html id="f4x9mq"
<a href="../index.html">Home</a>
```

---

### 22. A Simple Way to Think About Relative Paths

When using a relative URL, ask:

**"Where is my current HTML file?"**

Then:

1. Stay in the same folder if the file is there.
2. Enter a folder using its name.
3. Go up one folder using `..`.
4. Repeat `..` when you need to go up multiple folders.

For example:

```text id="y5r8qc"
Same folder:
about.html

Inside a folder:
pages/about.html

Go up one folder:
../index.html

Go up two folders:
../../index.html
```

---

### 23. Complete Example

```html id="v7m3kp"
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <title>URLs Example</title>
</head>

<body>

    <h1>CODIFY</h1>

    <!-- Relative URLs -->
    <nav>
        <a href="index.html">Home</a>
        <a href="about.html">About</a>
        <a href="courses/html.html">HTML Course</a>
    </nav>

    <!-- Absolute URL -->
    <p>
        <a href="https://www.example.com">
            Visit External Website
        </a>
    </p>

</body>

</html>
```

This example shows how both types of URLs can be used in the same webpage.

---

## Key Points

* URL stands for **Uniform Resource Locator**.
* An **absolute URL** provides the complete address of a resource.
* A **relative URL** provides a path relative to the current document.
* Absolute URLs commonly include the protocol and domain.
* Relative URLs are commonly used for files inside your own website.
* `..` means **go up one directory**.
* Multiple `..` values can be used to move up multiple directories.
* A relative URL depends on the location of the current HTML document.
* A path beginning with `/` can refer to a location from the website root.
* Absolute URLs are commonly useful for external websites.
* Relative URLs make links between files in the same project shorter and easier to manage.
