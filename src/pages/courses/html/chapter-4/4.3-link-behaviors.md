# Chapter 4: Links & Navigation

## Section 3: Link Behaviors

A link does more than simply take a user from one page to another. HTML provides different attributes and URL types that control **how a link behaves** when the user activates it.

For example, a link can:

* Open in the current tab
* Open in a new tab
* Move to a specific section
* Open an email application
* Open a phone application
* Download a file
* Navigate to another page

> **Simple idea:** The destination comes from the URL, while attributes such as `target`, `download`, and `rel` can influence how the link behaves.

---

### 1. Default Link Behavior

By default, when a user clicks a normal link, the browser navigates to the destination in the **current browsing context**.

Example:

```html id="x7m2qa"
<a href="about.html">About Us</a>
```

If the user clicks the link, the browser opens `about.html` in the current tab.

This is the most common behavior for links within a website.

---

### 2. Opening a Link in a New Tab

The `target` attribute can be used to specify where the linked resource should open.

Example:

```html id="k4p8vn"
<a href="https://www.example.com" target="_blank">
    Visit Example
</a>
```

The value:

```text id="q5r9mc"
_blank
```

requests that the browser open the destination in a new browsing context, commonly a new tab.

The exact behavior can depend on the browser and user settings.

---

### 3. Why Use a New Tab?

Opening a link in a new tab can be useful when the user should keep the current page available.

For example, a learning website might provide a reference link:

```html id="v8n3xp"
<a href="https://www.example.com" target="_blank" rel="noopener">
    Open Reference
</a>
```

The student can visit the reference while keeping the lesson available.

However, not every link needs to open a new tab.

> **Good practice:** Use new-tab behavior when it provides a clear benefit to the user, rather than for every link.

---

### 4. The `rel` Attribute

The `rel` attribute describes the relationship between the current page and the linked resource.

Example:

```html id="m6q2wd"
<a
    href="https://www.example.com"
    target="_blank"
    rel="noopener"
>
    Visit Example
</a>
```

Here:

```text id="n7c4yp"
rel="noopener"
```

helps prevent the newly opened page from accessing the opener through `window.opener`.

This is a useful security practice when using `_blank`.

---

### 5. `target="_self"`

The value `_self` tells the browser to open the destination in the current browsing context.

Example:

```html id="p3v7ks"
<a href="about.html" target="_self">
    About
</a>
```

This is effectively the normal behavior of a standard link.

Therefore, these generally behave the same:

```html id="r8m2qx"
<a href="about.html">About</a>
```

and:

```html id="c5n9wb"
<a href="about.html" target="_self">About</a>
```

---

### 6. `target="_blank"`

`_blank` requests a new browsing context.

Example:

```html id="h4x8mv"
<a href="https://example.com" target="_blank" rel="noopener">
    Open Website
</a>
```

This is commonly used for external resources when keeping the current page open is useful.

---

### 7. `target="_parent"` and `target="_top"`

The `target` attribute also supports other browsing-context keywords.

For example:

```html id="y6k3qp"
<a href="page.html" target="_parent">
    Open Page
</a>
```

`_parent` targets the parent browsing context when the page is inside a nested browsing context such as an iframe.

Another value is:

```html id="u9m5vc"
<a href="page.html" target="_top">
    Open Page
</a>
```

`_top` targets the top-level browsing context.

These values are mainly relevant when working with nested browsing contexts such as frames or iframes.

> **For normal websites:** `_self` and `_blank` are the values you will encounter most often.

---

### 8. Opening an Email Application

The `mailto:` URL scheme can create a link that opens the user's configured email application.

Example:

```html id="w3p7ns"
<a href="mailto:student@example.com">
    Email Us
</a>
```

The browser or operating system may open an email application.

You can also include a subject:

```html id="q8m4vx"
<a href="mailto:student@example.com?subject=HTML%20Question">
    Ask a Question
</a>
```

The `%20` represents a space in a URL.

---

### 9. Opening a Phone Application

The `tel:` scheme can be used for phone links.

Example:

```html id="f5n9kc"
<a href="tel:+911234567890">
    Call Us
</a>
```

On a device that supports phone calls, activating the link may open the phone application.

This is especially useful for mobile websites.

---

### 10. Downloading a File

The `download` attribute can indicate that a linked resource is intended to be downloaded.

Example:

```html id="m7x2qb"
<a href="notes.pdf" download>
    Download Notes
</a>
```

Instead of simply navigating to the PDF, the browser may download it.

The actual behavior can depend on browser and server settings.

You can also suggest a filename:

```html id="v4n8pw"
<a href="notes.pdf" download="HTML-Notes.pdf">
    Download HTML Notes
</a>
```

The browser may use `HTML-Notes.pdf` as the suggested download filename.

---

### 11. Linking to a Page Section

A link can move the user to a specific element using an ID.

Example:

```html id="c6q3my"
<a href="#contact">Go to Contact</a>
```

The destination element might be:

```html id="j9r5vk"
<h2 id="contact">Contact Us</h2>
```

When the link is activated, the browser moves to the element with the matching ID.

This is useful for:

* Table of contents
* Long articles
* Documentation
* Course lessons
* FAQ pages

---

### 12. Opening a Section on Another Page

You can also combine a page URL with a fragment identifier.

Example:

```html id="s8m2xp"
<a href="about.html#team">
    Meet Our Team
</a>
```

If `about.html` contains:

```html id="a5k7qn"
<h2 id="team">Our Team</h2>
```

the browser opens `about.html` and moves to the `team` section.

---

### 13. The `download` Attribute vs Normal Link

Consider:

```html id="n4p8yc"
<a href="notes.pdf">Open Notes</a>
```

This normally navigates to the PDF.

Compare it with:

```html id="w7m3vx"
<a href="notes.pdf" download>Download Notes</a>
```

The second link indicates that the resource is intended to be downloaded.

> **Remember:** The `download` attribute is a request to download; browser and server behavior can affect the final result.

---

### 14. Link to an External Website

External links commonly use an absolute URL.

Example:

```html id="q5x9mk"
<a href="https://www.example.com">
    Visit Example
</a>
```

If you want the external resource to open separately:

```html id="r8v2pc"
<a
    href="https://www.example.com"
    target="_blank"
    rel="noopener"
>
    Visit Example
</a>
```

Here:

* `href` specifies the destination.
* `target="_blank"` requests a new browsing context.
* `rel="noopener"` provides an important security relationship.

---

### 15. Link States

Links can have different states depending on how the user interacts with them.

Common CSS link states include:

```text id="d3k7mq"
:link
:visited
:hover
:active
```

These are CSS pseudo-classes rather than HTML attributes.

For example:

```css id="h6p2vn"
a:hover {
    text-decoration: underline;
}
```

This changes the appearance of a link when the pointer is over it.

> **Important:** HTML defines the link structure and behavior, while CSS can control its visual appearance.

---

### 16. Visited Links

A link may become a **visited link** after the user has visited its destination.

CSS can target visited links using:

```css id="v9m4qx"
a:visited {
    text-decoration: underline;
}
```

The browser may also apply its own default styling for visited links.

The exact appearance can be changed with CSS.

---

### 17. Hovering Over a Link

When the pointer is placed over a link, it is in the **hover** state.

Example:

```css id="b2x7mc"
a:hover {
    text-decoration: underline;
}
```

This can provide visual feedback to the user.

For example, a navigation link could change appearance when the pointer moves over it.

---

### 18. Active Link State

The `:active` pseudo-class can style a link while it is being activated.

Example:

```css id="n8c3wp"
a:active {
    text-decoration: underline;
}
```

This state is usually very brief because it occurs during activation.

---

### 19. Link Behavior and Accessibility

Links should be understandable and usable by different users.

Use descriptive link text.

Good:

```html id="x4q9mv"
<a href="html-course.html">
    Start the HTML Course
</a>
```

Less descriptive:

```html id="r7m2kc"
<a href="html-course.html">
    Click here
</a>
```

The first link clearly communicates its purpose.

Also, do not rely only on color to communicate that something is a link. CSS can provide additional visual cues such as underlines or other styling.

---

### 20. Links vs Buttons

Links and buttons have different purposes.

Use a **link** when the user is going somewhere:

```html id="j5v8qp"
<a href="courses.html">View Courses</a>
```

Use a **button** when the user is performing an action:

```html id="c3n7mx"
<button type="button">Start Quiz</button>
```

For example:

* "Open Profile" → link
* "Go to Course" → link
* "Submit Answer" → button
* "Delete Item" → button

> **Simple rule:** If it navigates to a resource, it is usually a link. If it performs an action on the current page, it is usually a button.

---

### 21. Real-World Example: Learning Website

A learning website might use different link behaviors:

```html id="w6k2pv"
<nav>
    <a href="index.html">Home</a>
    <a href="courses.html">Courses</a>
</nav>

<p>
    <a href="#quiz">Jump to Quiz</a>
</p>

<p>
    <a
        href="https://www.example.com/reference"
        target="_blank"
        rel="noopener"
    >
        Open Reference
    </a>
</p>

<p>
    <a href="notes.pdf" download>
        Download Notes
    </a>
</p>

<h2 id="quiz">Topic Quiz</h2>
```

This example demonstrates:

* Normal navigation
* Same-page navigation
* External link behavior
* Download behavior

---

### 22. Real-World Example: CODIFY Course Page

A CODIFY lesson page could have:

```html id="p8x3qm"
<nav>
    <a href="previous.html">Previous</a>
    <a href="index.html">Course Home</a>
    <a href="next.html">Next</a>
</nav>

<p>
    <a href="#quiz">Jump to Quiz</a>
</p>

<section id="quiz">
    <h2>Topic Quiz</h2>
    <p>Test your understanding of this lesson.</p>
</section>

<p>
    <a href="lesson-notes.pdf" download>
        Download Lesson Notes
    </a>
</p>
```

This creates a useful navigation system for a learning platform.

### 23. Complete Example

```html id="m4q7vx"
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">

<body>

    <h1>HTML Course</h1>

    <nav>
        <a href="index.html">Home</a>
        <a href="previous.html">Previous</a>

    </nav>

    <p>
        <a href="#quiz">Jump to Quiz</a>
    </p>

        <a
            href="https://www.example.com"
            target="_blank"
            rel="noopener"
        >
            Open Reference
        </a>
    </p>

    <p>
        <a href="notes.pdf" download>
            Download Notes
        </a>
    </p>

    <p>
        <a href="mailto:student@example.com">
            Email Instructor
        </a>
    </p>

    <section id="quiz">
        <h2>Topic Quiz</h2>
        <p>Test what you learned.</p>
    </section>

</body>

</html>
```

This example combines several common link behaviors in one webpage.

---

## Key Points

* Normal links usually open in the current browsing context.
* `target="_blank"` requests a new browsing context, commonly a new tab.
* `target="_self"` represents the current browsing context.
* `_parent` and `_top` are mainly useful with nested browsing contexts.
* `rel="noopener"` is useful with `_blank` links.
* `mailto:` creates an email link.
* `tel:` creates a phone link.
* `download` indicates that a resource is intended to be downloaded.
* `#id` moves the user to a section of the current page.
* `page.html#id` can move the user to a section of another page.
* CSS pseudo-classes such as `:hover`, `:visited`, and `:active` can style different link states.
* Use descriptive link text.
* Use links for navigation and buttons for actions.
