# Chapter 4: Links & Navigation

## Section 1: The Anchor Element

Links are one of the most important parts of the web. They allow users to move from one webpage to another, open another resource, download a file, or move to a different section of the same page.

HTML uses the **anchor element**, `<a>`, to create links.

> **Simple idea:** The `<a>` element connects one resource to another.

---

### 1. What Is the Anchor Element?

The anchor element is written using the `<a>` tag.

Basic syntax:

```html id="r7m3q1"
<a href="https://www.example.com">Visit Example</a>
```

Here:

* `<a>` is the anchor element.
* `href` specifies where the link should go.
* `Visit Example` is the clickable text.
* `</a>` closes the anchor element.

When the user clicks the link, the browser navigates to the address specified by `href`.

---

### 2. The `href` Attribute

The `href` attribute stands for **Hypertext Reference**.

It tells the browser the destination of the link.

Example:

```html id="c2n8xp"
<a href="https://www.google.com">Google</a>
```

The destination is:

```text
https://www.google.com
```

Without a useful `href` value, the link does not have a meaningful destination.

> **Remember:** The `<a>` element creates the link, while `href` specifies its destination.

---

### 3. Link Text

The text between `<a>` and `</a>` becomes the clickable part of the link.

Example:

```html id="j8k4vs"
<a href="https://www.example.com">Learn More</a>
```

The user sees:

**Learn More**

and can click it to visit the specified destination.

The link text should clearly describe where the link leads.

Good:

```html id="m1q6dc"
<a href="courses.html">View HTML Courses</a>
```

Less useful:

```html id="x5p9nb"
<a href="courses.html">Click here</a>
```

Descriptive link text gives users more information about the destination.

---

### 4. Linking to Another Website

An anchor can link to another website by using an **absolute URL**.

Example:

```html id="w4f7ks"
<a href="https://www.wikipedia.org/">Visit Wikipedia</a>
```

An absolute URL contains the complete web address.

Another example:

```html id="u3n8ha"
<a href="https://www.w3.org/">Visit W3C</a>
```

When clicked, the browser navigates to that website.

---

### 5. Absolute URLs

An **absolute URL** provides the complete address of a resource.

Example:

```html id="v6s2pk"
<a href="https://example.com/about.html">
    About Us
</a>
```

The URL includes:

* Protocol: `https`
* Domain: `example.com`
* Path: `/about.html`

Absolute URLs are commonly used when linking to resources on another website.

---

### 6. Relative URLs

A **relative URL** points to a resource relative to the current webpage.

Suppose your project contains:

```text
website/
├── index.html
├── about.html
└── contact.html
```

From `index.html`, you can link to `about.html` like this:

```html id="f0v4yd"
<a href="about.html">About Us</a>
```

You do not need to write the complete domain.

The browser understands that `about.html` is located relative to the current page.

---

### 7. Linking to a Page in a Folder

Suppose the project looks like this:

```text
website/
├── index.html
└── pages/
    └── courses.html
```

From `index.html`, the link can be:

```html id="t6y8pc"
<a href="pages/courses.html">Courses</a>
```

The path tells the browser to enter the `pages` folder and open `courses.html`.

---

### 8. Moving Up a Folder

The `..` notation means **go up one directory**.

Suppose:

```text
website/
├── index.html
└── pages/
    └── about.html
```

Inside `about.html`, you can return to `index.html` using:

```html id="b8r2zm"
<a href="../index.html">Home</a>
```

Here:

```text
.. 
```

means go up from the `pages` folder to the main `website` folder.

---

### 9. Linking to a Specific Section of a Page

An anchor can also take the user to a specific section of the same page.

This uses an **ID**.

First, give an element an `id`:

```html id="p3c7na"
<h2 id="contact">Contact Us</h2>
```

Then create a link:

```html id="e9v2kf"
<a href="#contact">Go to Contact</a>
```

When the user clicks the link, the browser moves to the element with the matching `id`.

The `#` indicates that the link points to an ID on the current page.

---

### 10. Linking Between Pages and Sections

You can also link directly to a section on another page.

Suppose `about.html` contains:

```html id="n5x8qr"
<h2 id="team">Our Team</h2>
```

Another page can link directly to that section:

```html id="d7m4kp"
<a href="about.html#team">Meet Our Team</a>
```

The browser opens `about.html` and moves to the element with the ID `team`.

---

### 11. Opening a Link in a New Tab

The `target` attribute can specify where the linked document should open.

For example:

```html id="q2s6mv"
<a href="https://example.com" target="_blank">
    Open Example
</a>
```

`target="_blank"` tells the browser to open the destination in a new browsing context, commonly a new tab.

A common secure pattern for external links is:

```html id="a9k3wp"
<a href="https://example.com" target="_blank" rel="noopener">
    Open Example
</a>
```

The `rel="noopener"` value helps prevent the newly opened page from accessing the opener through `window.opener`.

---

### 12. Linking to an Email Address

The anchor element can also create an email link.

Use the `mailto:` scheme:

```html id="h7p1qs"
<a href="mailto:student@example.com">
    Email Us
</a>
```

When the user activates the link, their device may open the configured email application.

You can also provide a subject:

```html id="n2c8vx"
<a href="mailto:student@example.com?subject=Course%20Question">
    Ask a Question
</a>
```

The `%20` represents a space in a URL.

---

### 13. Linking to a Phone Number

The `tel:` scheme can be used to create a phone link:

```html id="k4d9rt"
<a href="tel:+911234567890">
    Call Us
</a>
```

On devices that support phone calls, activating the link may open the phone application.

This is especially useful on mobile websites.

---

### 14. Download Links

The `<a>` element can also be used to provide a downloadable resource.

For example:

```html id="v8q3mz"
<a href="notes.pdf" download>
    Download Notes
</a>
```

The `download` attribute indicates that the resource is intended to be downloaded rather than simply navigated to.

The actual behavior can depend on the browser and server response.

---

### 15. Images Can Be Links

An anchor does not have to contain only text.

An image can be placed inside an anchor:

```html id="c6w2pk"
<a href="index.html">
    <img src="logo.png" alt="CODIFY Home">
</a>
```

Now the image acts as the clickable link.

This is commonly used for website logos that return users to the homepage.

---

### 16. Links and Accessibility

Link text should clearly communicate the destination or purpose of the link.

Good:

```html id="s7q5vd"
<a href="html-course.html">Learn HTML</a>
```

Less descriptive:

```html id="e3n6qa"
<a href="html-course.html">Click here</a>
```

"Learn HTML" tells the user what will happen when the link is activated.

Meaningful link text is especially helpful for users who navigate webpages using assistive technologies.

---

### 17. Styling Links

Browsers normally provide default visual styling for links.

For example, links are often displayed with an underline and a different color.

HTML provides the structure:

```html id="r1m5cx"
<a href="courses.html">Courses</a>
```

CSS can later be used to control the appearance:

```css id="t7x2qp"
a {
    color: blue;
    text-decoration: none;
}
```

The HTML tells the browser that the text is a link, while CSS controls how the link looks.

> **Remember:** Use HTML for structure and CSS for presentation.

---

### 18. Real-World Example: Navigation Menu

A website navigation bar commonly contains several anchor elements.

```html id="k9w3fv"
<nav>
    <a href="index.html">Home</a>
    <a href="courses.html">Courses</a>
    <a href="about.html">About</a>
    <a href="contact.html">Contact</a>
</nav>
```

Each link takes the user to a different page.

This is one of the most common uses of the anchor element.

---

### 19. Real-World Example: CODIFY Course Navigation

A learning platform could provide links to different HTML lessons:

```html id="d4p8mz"
<nav>
    <a href="chapter-1/1.1-introduction.html">
        Introduction
    </a>

    <a href="chapter-1/1.2-what-is-html.html">
        What is HTML?
    </a>

    <a href="chapter-1/1.3-setting-up-environment.html">
        Setting Up Your Environment
    </a>
</nav>
```

Each anchor connects the student to a different lesson.

---

### 20. Real-World Example: Table of Contents

A long webpage can use links to jump between sections.

```html id="n8c4ys"
<h1>HTML Course</h1>

<nav>
    <a href="#introduction">Introduction</a>
    <a href="#elements">Elements</a>
    <a href="#forms">Forms</a>
</nav>

<h2 id="introduction">Introduction</h2>
<p>Learn the basics of HTML.</p>

<h2 id="elements">Elements</h2>
<p>Learn about HTML elements.</p>

<h2 id="forms">Forms</h2>
<p>Learn how HTML forms work.</p>
```

Clicking a link in the navigation moves the user to the corresponding section.

---

### 21. Complete Example

Here is a simple webpage demonstrating several types of links:

```html id="w2q7vn"
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <title>Anchor Element</title>
</head>

<body>

    <h1>CODIFY</h1>

    <nav>
        <a href="index.html">Home</a>
        <a href="courses.html">Courses</a>
        <a href="about.html">About</a>
    </nav>

    <h2 id="courses">HTML Course</h2>

    <p>
        Start learning HTML from the basics.
    </p>

    <a href="chapter-1/1.1-introduction.html">
        Start Course
    </a>

    <h2 id="contact">Contact</h2>

    <p>
        <a href="mailto:student@example.com">
            Email Us
        </a>
    </p>

    <p>
        <a href="#courses">
            Back to Courses
        </a>
    </p>

</body>

</html>
```

This example demonstrates:

* Links to other pages
* Relative URLs
* Links to page sections
* Email links
* Navigation links

---

## Key Points

* The `<a>` element is used to create hyperlinks.
* The `href` attribute specifies the destination.
* The text inside an anchor is normally the clickable link text.
* Absolute URLs contain a complete web address.
* Relative URLs point to resources relative to the current page.
* `#id` can be used to link to a specific section of a page.
* `target="_blank"` can open a link in a new browsing context.
* `rel="noopener"` is a useful security attribute when using `_blank`.
* `mailto:` creates an email link.
* `tel:` creates a phone link.
* The `download` attribute can be used for download links.
* Images can be placed inside `<a>` to make them clickable.
* Good link text should clearly describe the link's destination or purpose.
* CSS can be used to change the visual appearance of links.
