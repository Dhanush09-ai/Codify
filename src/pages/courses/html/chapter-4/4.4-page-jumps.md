# Chapter 4: Links & Navigation

## Section 4: Page Jumps & Email Links

Not every link needs to take the user to a completely different webpage.

Sometimes you want a link to:

* Jump to a section on the same page
* Jump to a section on another page
* Return to the top of a long page
* Open an email application
* Create an email with a subject or message

HTML supports these behaviors using **fragment identifiers** and URL schemes such as `mailto:`.

> **Simple idea:** Use `#id` for page jumps and `mailto:` for email links.

---

### 1. What Is a Page Jump?

A **page jump** moves the user directly to a particular section of a webpage.

For example, imagine a long HTML lesson with:

* Introduction
* HTML Elements
* Attributes
* Examples
* Quiz

Instead of making the user scroll through the entire page, you can provide a link that takes them directly to the quiz.

---

### 2. Using the `id` Attribute

First, give the destination element a unique `id`.

Example:

```html id="x4m7qp"
<h2 id="quiz">Topic Quiz</h2>
```

The value `quiz` identifies this particular section.

Then create a link:

```html id="k8v2nc"
<a href="#quiz">Jump to Quiz</a>
```

When the user activates the link, the browser moves to:

```html id="p6r3wm"
<h2 id="quiz">Topic Quiz</h2>
```

---

### 3. Understanding `#`

The `#` symbol in:

```html id="v9c5kx"
<a href="#quiz">Jump to Quiz</a>
```

indicates a **fragment identifier**.

The browser looks for an element whose `id` matches the value after `#`.

So:

```text id="j3n8qa"
#quiz
```

matches:

```html id="m7x2vp"
id="quiz"
```

The names must match.

---

### 4. Complete Page Jump Example

```html id="q5r8nc"
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <title>Page Jumps</title>
</head>

<body>

    <h1>HTML Course</h1>

    <p>
        <a href="#introduction">Introduction</a>
    </p>

    <p>
        <a href="#quiz">Jump to Quiz</a>
    </p>

    <h2 id="introduction">Introduction</h2>
    <p>
        HTML is used to structure webpages.
    </p>

    <h2 id="quiz">Topic Quiz</h2>
    <p>
        Test your understanding of HTML.
    </p>

</body>

</html>
```

Clicking **Jump to Quiz** moves directly to the element with `id="quiz"`.

---

### 5. Page Jumps Are Useful for Long Pages

Page jumps are especially useful when a page contains a lot of content.

Common examples include:

* Documentation
* Tutorials
* Online courses
* FAQs
* Articles
* Terms and conditions
* Table of contents

For example:

```html id="w6m2vp"
<nav>
    <a href="#html">HTML</a>
    <a href="#css">CSS</a>
    <a href="#javascript">JavaScript</a>
</nav>
```

Each link can take the user to a corresponding section.

---

### 6. Table of Contents

A table of contents is a common real-world use of page jumps.

Example:

```html id="c8q4nx"
<h1>Learn HTML</h1>

<nav>
    <a href="#basics">HTML Basics</a>
    <a href="#elements">HTML Elements</a>
    <a href="#links">HTML Links</a>
    <a href="#quiz">Quiz</a>
</nav>

<h2 id="basics">HTML Basics</h2>
<p>Learn the fundamentals of HTML.</p>

<h2 id="elements">HTML Elements</h2>
<p>Learn about HTML elements.</p>

<h2 id="links">HTML Links</h2>
<p>Learn how to create hyperlinks.</p>

<h2 id="quiz">Quiz</h2>
<p>Test your knowledge.</p>
```

The navigation at the top provides quick access to each section.

---

### 7. Jumping Back to the Top

You can also create a link that returns the user to the top of a page.

One simple approach is to give the top element an ID:

```html id="n5v9kc"
<body id="top">
```

Then create a link:

```html id="r7m3qx"
<a href="#top">Back to Top</a>
```

When the user clicks the link, the browser moves back to the element with `id="top"`.

---

### 8. Empty Fragment for the Top

A link such as:

```html id="x2k6mp"
<a href="#">Back to Top</a>
```

can also point to the top of the current page.

However, using a meaningful ID such as:

```html id="q8v4nc"
<a href="#top">Back to Top</a>
```

can make the intended destination clearer.

> **Tip:** Use meaningful IDs for important page sections.

---

### 9. IDs Must Be Unique

An `id` identifies a particular element on a page.

Avoid using the same ID for multiple elements.

Good:

```html id="m3q7vx"
<h2 id="html">HTML</h2>
<h2 id="css">CSS</h2>
```

Problematic:

```html id="p9k2wc"
<h2 id="topic">HTML</h2>
<h2 id="topic">CSS</h2>
```

A page jump should have a clear, unique destination.

---

### 10. Page Jumps to Another Page

A fragment can also be combined with another page's URL.

Suppose `about.html` contains:

```html id="d6r8mp"
<h2 id="team">Our Team</h2>
```

Another page can link directly to that section:

```html id="w4n7qx"
<a href="about.html#team">
    Meet Our Team
</a>
```

The browser will:

1. Open `about.html`
2. Find the element with `id="team"`
3. Move to that section

---

### 11. External Page Fragments

The same idea can be used with an absolute URL when the destination page supports the fragment.

Example:

```html id="j8c3mv"
<a href="https://www.example.com/help#installation">
    Installation Help
</a>
```

The browser opens the page and requests the `installation` fragment.

The destination page must contain a matching element for the jump to have a specific target.

---

### 12. What Is an Email Link?

An email link allows a user to activate a link that opens their configured email application.

HTML uses the `mailto:` URL scheme.

Basic example:

```html id="v5q9nk"
<a href="mailto:student@example.com">
    Email Us
</a>
```

The browser or operating system may open the user's configured email application.

---

### 13. Basic `mailto:` Syntax

The basic structure is:

```text id="r2m7xc"
mailto:email@example.com
```

For example:

```html id="p6k4vw"
<a href="mailto:hello@example.com">
    Contact Us
</a>
```

The email address appears after `mailto:`.

---

### 14. Adding an Email Subject

You can provide a subject using the `subject` parameter.

Example:

```html id="n8x3mq"
<a href="mailto:hello@example.com?subject=HTML%20Question">
    Ask a Question
</a>
```

Here:

```text id="c5v7kp"
subject=HTML%20Question
```

sets the suggested email subject.

`%20` represents a space.

The email application may open with a subject similar to:

```text
HTML Question
```

---

### 15. Adding an Email Body

You can also provide suggested content for the email body.

Example:

```html id="w4q9nc"
<a href="mailto:hello@example.com?body=I%20have%20a%20question%20about%20HTML.">
    Ask About HTML
</a>
```

When supported by the email application, the message body can be pre-filled.

---

### 16. Subject and Body Together

You can include multiple parameters.

Example:

```html id="m7p2vx"
<a href="mailto:hello@example.com?subject=HTML%20Question&body=I%20need%20help%20with%20HTML.">
    Email Instructor
</a>
```

Here:

```text id="q3k8wp"
subject=HTML%20Question
```

sets the subject.

And:

```text id="x6n4mc"
body=I%20need%20help%20with%20HTML.
```

provides the suggested body.

The parameters are separated using `&`.

---

### 17. Encoding Spaces in Email Links

URLs cannot always contain ordinary spaces.

For example, instead of:

```text id="v9m3qx"
subject=HTML Question
```

use:

```text id="k4r7np"
subject=HTML%20Question
```

`%20` represents a space.

This is called **URL encoding**.

Other special characters may also need encoding when they appear inside a URL.

---

### 18. Email Link With a Visible Label

The email address does not have to be the visible link text.

Example:

```html id="c8q2mv"
<a href="mailto:support@example.com">
    Contact Support
</a>
```

The user sees:

**Contact Support**

instead of the actual email address.

This is often more readable in a webpage.

---

### 19. Real-World Example: Course Support

Imagine a learning platform where students can contact support.

```html id="p5n8xc"
<h2>Need Help?</h2>

<p>
    If you have a question about this lesson,
    <a href="mailto:support@example.com?subject=HTML%20Course%20Question">
        contact support
    </a>.
</p>
```

The link opens an email application with a suggested subject.

<nav>

* An email support link

### 21. Combining Page Jumps With Navigation

A long webpage can provide a navigation menu at the top and a **Back to Top** link at the bottom.

```html id="t8q4mn"
<body id="top">

    <h1>HTML Tutorial</h1>

    <nav>
        <a href="#basics">Basics</a>
        <a href="#examples">Examples</a>
        <a href="#quiz">Quiz</a>
    </nav>

    <section id="basics">
        <h2>HTML Basics</h2>
        <p>Learn the basics of HTML.</p>
    </section>

    <section id="examples">
        <h2>Examples</h2>
        <p>Practice with examples.</p>
    </section>

    <section id="quiz">
        <h2>Quiz</h2>
        <p>Test your understanding.</p>
    </section>

    <a href="#top">Back to Top</a>

</body>
```

This pattern is common on long documentation and learning pages.

---

### 22. Page Jump vs Normal Link

Compare:

```html id="q3m8vx"
<a href="about.html">About</a>
```

and:

```html id="d7n2kc"
<a href="#about">About</a>
```

The first:

```text
about.html
```

opens another page.

The second:

```text
#about
```

moves to an element with `id="about"` on the current page.

So:

| Link              | Behavior                                  |
| :---------------- | :---------------------------------------- |
| `about.html`      | Opens another page                        |
| `#about`          | Jumps to a section on the current page    |
| `about.html#team` | Opens another page and jumps to a section |
| `mailto:...`      | Opens a configured email application      |

---

### 23. Common Mistakes

#### Mistake 1: Missing `#`

Incorrect:

```html id="h5r9mx"
<a href="quiz">Quiz</a>
```

If you want to jump to an ID on the current page, use:

```html id="v8k3qp"
<a href="#quiz">Quiz</a>
```

---

#### Mistake 2: Mismatched ID

This will not correctly match:

```html id="x2m7nc"
<a href="#Quiz">Quiz</a>

<h2 id="quiz">Topic Quiz</h2>
```

The fragment and ID should match appropriately.

Use:

```html id="p4q8vw"
<a href="#quiz">Quiz</a>

<h2 id="quiz">Topic Quiz</h2>
```

---

#### Mistake 3: Duplicate IDs

Avoid:

```html id="n6c3mx"
<h2 id="quiz">Quiz 1</h2>
<h2 id="quiz">Quiz 2</h2>
```

Use unique IDs instead:

```html id="r7v2kp"
<h2 id="quiz1">Quiz 1</h2>
<h2 id="quiz2">Quiz 2</h2>
```

## Key Points

* A page jump moves the user directly to a particular section.
* Page jumps commonly use an `id` and a fragment such as `#quiz`.
* The `href` value should match the destination element's ID.
* IDs should be unique within a page.
* `#id` jumps to an element on the current page.
* `page.html#id` opens another page and jumps to a specific section.
* A `mailto:` link can open the user's configured email application.
* `subject` can provide a suggested email subject.
* `body` can provide suggested email content.
* `%20` represents a space in a URL.
* Page jumps are useful for tables of contents, tutorials, documentation, and long pages.
* A meaningful ID such as `#quiz` is clearer than an unexplained fragment.
* Page jumps and email links are both created using the `<a>` element.
