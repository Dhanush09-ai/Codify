# Chapter 2: HTML Building Blocks

## Section 1: Tags, Elements & Attributes

In the previous chapter, we created our first webpage using HTML. Now it is time to understand the basic building blocks used inside HTML.

The three important concepts in this topic are:

* **Tags**
* **Elements**
* **Attributes**

Understanding these concepts will make it much easier to write and read HTML code.

---

### 1. What Are HTML Tags?

HTML uses **tags** to tell the browser what type of content something is.

For example:

```html
<h1>Welcome to CODIFY</h1>
```

Here:

* `<h1>` is the **opening tag**.
* `</h1>` is the **closing tag**.
* `Welcome to CODIFY` is the content.

The browser understands that this content is a heading.

Some common HTML tags are:

| Tag     | Purpose         |
| :------ | :-------------- |
| `<h1>`  | Main heading    |
| `<h2>`  | Section heading |
| `<p>`   | Paragraph       |
| `<a>`   | Link            |
| `<img>` | Image           |
| `<ul>`  | Unordered list  |

> **Simple idea:** Tags tell the browser **what a piece of content represents**.

---

### 2. Opening and Closing Tags

Most HTML elements use an opening tag and a closing tag.

For example:

```html
<p>Hello, World!</p>
```

The opening tag is:

```html
<p>
```

The closing tag is:

```html
</p>
```

Notice that the closing tag contains a `/`.

Another example:

```html
<h1>My Website</h1>
```

Opening tag:

```html
<h1>
```

Closing tag:

```html
</h1>
```

The content is placed between the opening and closing tags.

---

### 3. What Is an HTML Element?

An **HTML element** usually consists of:

* Opening tag
* Content
* Closing tag

For example:

```html
<p>Learn HTML with CODIFY.</p>
```

The complete structure is one **HTML element**.

```text
<p>          → Opening tag
Learn HTML   → Content
</p>         → Closing tag
```

So:

```html
<p>Learn HTML with CODIFY.</p>
```

is an HTML element.

> **Remember:** A tag is a part of an element. The complete structure is called an **element**.

---

### 4. Tag vs Element

These two terms are often confused.

Consider:

```html
<h1>My First Website</h1>
```

* `<h1>` is a **tag**.
* `</h1>` is a **closing tag**.
* `<h1>My First Website</h1>` is the **element**.

A simple way to remember it:

```text
Tag + Content + Closing Tag
             ↓
          Element
```

---

### 5. What Are Attributes?

An **attribute** provides additional information about an HTML element.

Attributes are normally written inside the opening tag.

For example:

```html
<a href="https://example.com">Visit Website</a>
```

Here:

* `<a>` is the tag.
* `href` is an **attribute**.
* `"https://example.com"` is the attribute value.
* `Visit Website` is the content.

The `href` attribute tells the browser where the link should go.

---

### 6. Attribute Syntax

The general structure of an attribute is:

```html
<tag attribute="value">
```

For example:

```html
<p class="intro">Welcome to CODIFY.</p>
```

Here:

```text
class        → Attribute
"intro"      → Attribute value
```

Multiple attributes can also be used:

```html
<img src="logo.png" alt="CODIFY Logo" width="200">
```

This image element has three attributes:

* `src`
* `alt`
* `width`

> **Important:** Attributes provide additional information about an element.

---

### 7. Real-World Example: A Website Link

Imagine a college website has a link to its admission page.

We can write:

```html
<a href="admissions.html">Admissions</a>
```

Here:

* `<a>` tells the browser that this is a link.
* `href` tells the browser where the link should go.
* `Admissions` is the text displayed to the user.

So attributes allow us to give additional information to HTML elements.

---

### 8. Real-World Example: An Image

Suppose a college website needs to display its logo.

```html
<img src="college-logo.png" alt="College Logo">
```

Here:

* `<img>` represents an image.
* `src` specifies the image file.
* `alt` provides alternative text describing the image.

The browser uses the `src` value to find the image.

### 9. Attributes Belong Inside the Opening Tag

Attributes are written inside the opening tag.

Correct:

```html
<a href="about.html">About Us</a>
```

Incorrect:

```html
<a> href="about.html" About Us</a>
```

The attribute belongs inside the opening `<a>` tag.

Another example:

```html
<img src="logo.png" alt="College Logo">
```

Both `src` and `alt` are inside the `<img>` tag.

---

### 10. Some Elements Do Not Have Closing Tags

Not every HTML element has a separate closing tag.

For example:

```html
<img src="logo.png" alt="College Logo">
```

The `<img>` element does not need a closing `</img>` tag.

Another common example is:

```html
<br>
```

It creates a line break.

These are commonly called **void elements** because they do not contain normal content between an opening and closing tag.

We will study these elements in more detail as we continue learning HTML.

---

### 11. Nested Elements

HTML elements can be placed inside other HTML elements.

This is called **nesting**.

For example:

```html
<div>
    <h1>CODIFY</h1>
    <p>Learn programming for free.</p>
</div>
```

Here:

* `<div>` is the outer element.
* `<h1>` is inside the `<div>`.
* `<p>` is also inside the `<div>`.

The structure can be visualized as:

```text
<div>
   ├── <h1>
   └── <p>
</div>
```

Proper nesting is important when writing HTML.

---

### 12. A Complete Example

Let's combine tags, elements, and attributes:

```html
<h1>ABC Polytechnic</h1>

<p>Welcome to our college website.</p>

<a href="admissions.html">View Admissions</a>

<img src="college-logo.png" alt="ABC Polytechnic Logo">
```

In this example:

| HTML    | What It Represents         |
| :------ | :------------------------- |
| `<h1>`  | Tag used for the heading   |
| `<p>`   | Tag used for the paragraph |
| `<a>`   | Tag used for the link      |
| `href`  | Attribute of the link      |
| `<img>` | Image element              |
| `src`   | Image file location        |
| `alt`   | Alternative text           |

This is the basic pattern you will use throughout HTML development.

---

## Key Points

* **Tags** tell the browser what type of content an element represents.
* An **element** usually contains an opening tag, content, and closing tag.
* **Attributes** provide additional information about an element.
* Attributes are written inside the opening tag.
* Attribute values are commonly written inside quotation marks.
* Elements can contain other elements through **nesting**.
* Some elements, such as `<img>` and `<br>`, do not have separate closing tags.
* Correct nesting and syntax are important when writing HTML.
