# Chapter 2: HTML Building Blocks

## Section 3: Metadata Essentials

In the previous topic, we learned about the **HTML boilerplate** and the `<head>` section.

The `<head>` contains information about the webpage that is useful to the browser, search engines, and other software. This information is called **metadata**.

> **Simple idea:** Metadata is **information about the webpage**, rather than the main content displayed on the page.

---

### 1. What Is Metadata?

**Metadata** means information that describes other information.

In HTML, metadata is usually placed inside the `<head>` element.

For example:

```html
<head>
    <title>My Website</title>
    <meta charset="UTF-8">
</head>
```

The user normally does not see these elements as part of the main webpage content.

Instead, they provide information that helps the browser and other tools understand the document.

---

### 2. Where Is Metadata Placed?

Metadata is normally placed inside:

```html
<head>

    <!-- Metadata goes here -->

</head>
```

A basic HTML document can look like:

```html
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <title>My Website</title>
</head>

<body>

    <h1>Welcome to My Website</h1>

</body>

</html>
```

Here, the `<head>` contains information about the document, while the `<body>` contains the visible webpage content.

---

### 3. The `<title>` Element

The `<title>` element provides a title for the webpage.

Example:

```html
<title>CODIFY - Learn HTML</title>
```

The title is commonly displayed in the browser tab.

For example:

```text
┌─────────────────────────────────────┐
│ CODIFY - Learn HTML          +      │
├─────────────────────────────────────┤
│                                     │
│       Welcome to CODIFY             │
│                                     │
└─────────────────────────────────────┘
```

A useful title should clearly describe the page.

For example:

```html
<title>HTML Tutorial - CODIFY</title>
```

is more meaningful than:

```html
<title>Page 1</title>
```

---

### 4. The `<meta>` Element

The `<meta>` element provides metadata about an HTML document.

For example:

```html
<meta charset="UTF-8">
```

The `<meta>` element does not normally display content on the webpage.

It gives information to the browser or other software.

A page can contain multiple `<meta>` elements.

For example:

```html
<head>

    <meta charset="UTF-8">
    <meta name="description" content="Learn HTML with CODIFY">

</head>
```

---

### 5. Character Encoding

One of the most important metadata settings is:

```html
<meta charset="UTF-8">
```

The `charset` attribute specifies the character encoding used by the document.

**UTF-8** supports a very large range of characters and symbols.

This is especially useful when a webpage contains different languages or special characters.

For example:

```html
<meta charset="UTF-8">
```

is normally placed near the beginning of the `<head>`.

> **Remember:** Using UTF-8 helps the browser correctly interpret characters in your webpage.

---

### 6. The `lang` Attribute

The `<html>` element can specify the main language of the document.

For example:

```html
<html lang="en">
```

Here:

* `lang` is an attribute.
* `en` represents English.

For a webpage written mainly in Telugu, for example, the language could be specified differently.

The language information helps browsers and assistive technologies understand the document's primary language.

---

### 7. The Description Metadata

A webpage can provide a description using the `description` metadata.

Example:

```html
<meta name="description" content="Learn HTML step by step with CODIFY.">
```

Here:

* `name="description"` identifies the type of metadata.
* `content="..."` contains the description.

The description provides a short summary of what the webpage is about.

For example, a course page could use:

```html
<meta name="description"
      content="Learn HTML basics, tags, elements, and attributes.">
```

This describes the page to software that uses the document metadata.

---

### 8. The `name` and `content` Attributes

Many metadata elements use `name` and `content`.

For example:

```html
<meta name="description" content="Learn HTML with CODIFY.">
```

Think of it like this:

```text
name
 ↓
What type of information is this?

content
 ↓
What is the actual information?
```

For example:

```text
name = description
content = Learn HTML with CODIFY.
```

This pattern is commonly used for metadata.

---

### 9. The Viewport Metadata

For modern websites, especially websites designed for phones and tablets, you will commonly see:

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

This tells the browser how to handle the webpage's viewport on different devices.

The important parts are:

* `width=device-width` — uses the device's width.
* `initial-scale=1.0` — sets the initial zoom level.

This is commonly included in modern HTML webpages.

For example:

```html
<head>

    <meta charset="UTF-8">

    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>CODIFY</title>

</head>
```

---

### 10. Linking CSS from the `<head>`

The `<head>` can also contain information that connects the webpage to other resources.

For example:

```html
<link rel="stylesheet" href="style.css">
```

This tells the browser to load a CSS stylesheet.

Here:

* `<link>` creates a relationship with another resource.
* `rel="stylesheet"` tells the browser that the resource is a stylesheet.
* `href="style.css"` specifies the CSS file.

The CSS itself is not metadata, but the `<link>` element is commonly placed inside `<head>` because it provides information about resources associated with the document.

---

### 11. Metadata vs Visible Content

It is important to understand the difference between metadata and webpage content.

| Location / Element | Purpose                     |
| :----------------- | :-------------------------- |
| `<title>`          | Provides the document title |
| `<meta>`           | Provides metadata           |
| `<link>`           | Connects related resources  |
| `<h1>`             | Visible main heading        |
| `<p>`              | Visible paragraph           |
| `<img>`            | Displays an image           |

For example:

```html
<head>
    <title>Student Portal</title>
    <meta name="description" content="Student information portal.">
</head>

<body>
    <h1>Welcome Students</h1>
    <p>Login to access your account.</p>
</body>
```

The `<head>` contains document information, while the `<body>` contains the content users see.

---

### 12. A Complete Metadata Example

Here is a simple modern HTML document containing several useful pieces of metadata:

```html
<!DOCTYPE html>
<html lang="en">

<head>

    <meta charset="UTF-8">

    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <meta name="description"
          content="Learn HTML step by step with CODIFY.">

    <title>HTML Tutorial - CODIFY</title>

</head>

<body>

    <h1>Learn HTML</h1>

    <p>Start learning HTML step by step.</p>

</body>

</html>
```

The browser uses the information in the `<head>` while the user sees the main content from the `<body>`.

---

### 13. Real-World Example: CODIFY Course Page

Imagine we are creating a CODIFY lesson page called **HTML Tags and Elements**.

We could use:

```html
<head>

    <meta charset="UTF-8">

    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <meta name="description"
          content="Learn HTML tags, elements, and attributes.">

    <title>Tags, Elements & Attributes - CODIFY</title>

</head>
```

This provides useful information about the page before the actual lesson content begins.

The visible lesson can then be placed inside `<body>`.

---

### 14. Why Is Metadata Important?

Metadata is important because it helps different software understand your webpage.

It can help with:

* Character encoding.
* Page titles.
* Mobile display behavior.
* Page descriptions.
* Language information.
* Connections to external resources.

> **Remember:** Metadata is mainly about helping software **understand and handle the webpage**, rather than directly displaying content to the user.

---

## Key Points

* **Metadata** is information about a webpage.
* Metadata is normally placed inside the `<head>`.
* `<title>` defines the webpage title.
* `<meta>` is used to provide metadata.
* `<meta charset="UTF-8">` specifies character encoding.
* `lang` specifies the primary language of the document.
* `name` and `content` are commonly used with metadata.
* The viewport metadata helps webpages work properly across different device sizes.
* `<link>` can connect the HTML document to external resources such as CSS.
* Metadata and visible webpage content have different purposes.
