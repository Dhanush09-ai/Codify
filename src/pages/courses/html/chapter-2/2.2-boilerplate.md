# Chapter 2: HTML Building Blocks

## Section 2: The Boilerplate

In the previous topic, we learned about **tags, elements, and attributes**. Now we will learn about the basic structure that most HTML documents start with.

This basic structure is called the **HTML boilerplate**.

> **Simple idea:** An HTML boilerplate is a ready-made basic structure that gives your webpage the correct starting point.

---

### 1. What Is an HTML Boilerplate?

An **HTML boilerplate** is the standard basic structure of an HTML document.

A simple HTML boilerplate looks like this:

```html
<!DOCTYPE html>
<html>
<head>
    <title>My First Webpage</title>
</head>
<body>

    <h1>Welcome to CODIFY</h1>
    <p>This is my first webpage.</p>

</body>
</html>
```

You can add your own content inside this structure.

The boilerplate helps the browser understand how the HTML document is organized.

---

### 2. Why Do We Need a Boilerplate?

We could write HTML without using the complete structure, especially for very small examples.

However, a proper HTML document should have a standard structure.

The boilerplate:

* Provides a consistent starting point.
* Separates document information from visible content.
* Helps browsers understand the document.
* Makes webpages easier to organize.
* Gives us a place to add metadata, styles, and scripts later.

> **Remember:** The boilerplate is the **foundation** of a normal HTML document.

---

### 3. Understanding `<!DOCTYPE html>`

The first line of a modern HTML document is:

```html
<!DOCTYPE html>
```

This is called the **DOCTYPE declaration**.

It tells the browser that the document is an HTML document and that it should use the modern HTML standard.

It is not an ordinary HTML element.

For example:

```html
<!DOCTYPE html>
<html>
```

The DOCTYPE normally appears at the very beginning of the document.

> **Important:** Write `<!DOCTYPE html>` before the `<html>` element.

---

### 4. The `<html>` Element

The `<html>` element is the main container for the HTML document.

Example:

```html
<html>

    <!-- HTML document content -->

</html>
```

Almost everything in an HTML document is placed inside the `<html>` element.

It contains two major sections:

```text
<html>
   │
   ├── <head>
   │
   └── <body>
</html>
```

These two sections have different purposes.

---

### 5. The `<head>` Element

The `<head>` contains information **about the webpage**.

For example:

```html
<head>
    <title>My Website</title>
</head>
```

The `<head>` can contain:

* The webpage title.
* Character encoding information.
* Links to CSS files.
* Metadata.
* Other information used by the browser.

Most content inside `<head>` is not directly displayed as normal page content.

---

### 6. The `<title>` Element

The `<title>` element defines the title of the webpage.

Example:

```html
<title>CODIFY - Learn HTML</title>
```

The title is commonly shown in the browser tab.

For example:

```text
┌─────────────────────────────────────┐
│ CODIFY - Learn HTML       +         │
├─────────────────────────────────────┤
│                                     │
│       Welcome to CODIFY             │
│                                     │
└─────────────────────────────────────┘
```

The title helps users identify the webpage when multiple browser tabs are open.

> **Important:** The `<title>` is placed inside `<head>`, not inside `<body>`.

---

### 7. The `<body>` Element

The `<body>` contains the content that users normally see on the webpage.

For example:

```html
<body>

    <h1>Welcome to CODIFY</h1>
    <p>Learn HTML step by step.</p>

</body>
```

The body can contain:

* Headings
* Paragraphs
* Images
* Links
* Lists
* Tables
* Forms
* Buttons
* Other HTML elements

So, when you want to add visible webpage content, you will usually work inside `<body>`.

---

### 8. `<head>` vs `<body>`

The difference can be remembered easily:

| Section  | Main Purpose                  |
| :------- | :---------------------------- |
| `<head>` | Information about the webpage |
| `<body>` | Visible webpage content       |

For example:

```html
<head>
    <title>Student Portal</title>
</head>

<body>
    <h1>Welcome Students</h1>
    <p>Login to access your account.</p>
</body>
```

The title belongs in the `<head>`, while the heading and paragraph belong in the `<body>`.

---

### 9. Complete HTML Boilerplate

Let's look at the complete structure again:

```html
<!DOCTYPE html>
<html>

<head>
    <title>My First Webpage</title>
</head>

<body>

    <h1>Welcome to CODIFY</h1>
    <p>Learn HTML step by step.</p>

</body>

</html>
```

The structure can be visualized as:

```text
DOCTYPE
   ↓
<html>
   │
   ├── <head>
   │      └── <title>
   │
   └── <body>
          ├── <h1>
          └── <p>
```

### 10. Adding the `lang` Attribute

The `<html>` element can have a `lang` attribute.

For example:

```html
<html lang="en">
```

Here:

* `lang` is an attribute.
* `en` means English.

A complete beginning can therefore look like:

```html
<!DOCTYPE html>
<html lang="en">
```

The `lang` attribute helps browsers and assistive technologies understand the primary language of the webpage.

---

### 11. Adding Character Encoding

We can also specify the character encoding using:

```html
<meta charset="UTF-8">
```

This is normally placed inside the `<head>`.

For example:

```html
<head>
    <meta charset="UTF-8">
    <title>My Website</title>
</head>
```

**UTF-8** supports a very large range of characters and symbols.

This is useful when webpages contain different languages or special characters.

---

### 12. A Modern Basic Boilerplate

A more complete basic HTML document can look like this:

```html
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <title>My Website</title>
</head>

<body>

    <h1>Welcome to My Website</h1>
    <p>This is my first webpage.</p>

</body>

</html>
```

This structure is a good starting point for many beginner HTML projects.

---

### 13. Real-World Example: College Website

Imagine we are creating a college website.

Our basic document could be:

```html
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <title>ABC Polytechnic</title>
</head>

<body>

    <h1>ABC Polytechnic</h1>

    <p>Welcome to ABC Polytechnic.</p>

    <h2>Departments</h2>

    <p>Computer Engineering</p>
    <p>Electronics Engineering</p>

</body>

</html>
```

Here:

* `<!DOCTYPE html>` declares the document type.
* `<html>` contains the whole document.
* `<head>` contains webpage information.
* `<title>` provides the browser tab title.
* `<body>` contains visible college content.

---

### 14. Using Boilerplate in a Code Editor

Many code editors can generate a basic HTML structure automatically.

For example, in VS Code, typing:

```text
!
```

and using the **Emmet abbreviation** can generate a basic HTML document structure.

This saves time and reduces the need to type the same structure repeatedly.

However, it is still important to understand what each part of the boilerplate does.

> **Remember:** Do not just memorize the boilerplate. Understand the purpose of each part.

---

## Key Points

* An **HTML boilerplate** is the standard starting structure of an HTML document.
* `<!DOCTYPE html>` declares the document as HTML.
* `<html>` is the main container of the document.
* `<head>` contains information about the webpage.
* `<title>` defines the title shown in the browser tab.
* `<body>` contains the visible webpage content.
* `lang="en"` specifies the primary language as English.
* `<meta charset="UTF-8">` specifies the character encoding.
* A boilerplate provides a consistent foundation for building webpages.
* Code editors such as VS Code can generate the basic boilerplate automatically.
