# Chapter 8: HTML Forms

## Section 2: Basic Inputs

The `<input>` element is one of the most commonly used elements in HTML forms.

It allows users to enter or select information such as:

* Names
* Email addresses
* Passwords
* Numbers
* Dates
* Search terms
* Phone numbers

The `<input>` element is a **void element**, which means it does not need a closing tag.

Example:

```html
<input type="text">
```

> **Simple idea:** The `type` attribute tells the browser what kind of input control to display.

---

## 1. Basic `<input>` Syntax

The basic structure is:

```html
<input type="text">
```

For example:

```html
<label for="name">Name:</label>
<input type="text" id="name" name="name">
```

Here:

```text
<input> → Creates the input control
type    → Defines the kind of input
id      → Identifies the element
name    → Identifies the submitted field
```

---

## 2. Text Input

The `text` type creates a single-line text box.

Example:

```html
<label for="name">Full Name:</label>
<input type="text" id="name" name="name">
```

It can be used for information such as:

* Name
* City
* Username
* College name

A browser may display it like:

```text
Full Name: [________________]
```

---

## 3. `placeholder`

The `placeholder` attribute displays a temporary hint inside an input.

Example:

```html
<input
    type="text"
    name="username"
    placeholder="Enter your username"
>
```

The user may see:

```text
[ Enter your username       ]
```

The placeholder disappears when the user starts entering a value.

> **Important:** A placeholder is a hint, not a replacement for a proper `<label>`.

Better:

```html
<label for="username">Username:</label>

<input
    type="text"
    id="username"
    name="username"
    placeholder="Enter your username"
>
```

---

## 4. `value`

The `value` attribute provides an initial value for an input.

Example:

```html
<input
    type="text"
    name="city"
    value="Hyderabad"
>
```

The input initially contains:

```text
[ Hyderabad ]
```

Unlike a placeholder, the value is actual input data and can be submitted if the control is successful during form submission.

---

## 5. Email Input

Use:

```html
<input type="email">
```

for email addresses.

Example:

```html
<label for="email">Email:</label>

<input
    type="email"
    id="email"
    name="email"
    placeholder="you@example.com"
>
```

The browser can provide built-in validation for the expected email format when the form is submitted.

For example:

```text
user@example.com
```

is a typical valid-looking email address.

---

## 6. Password Input

Use:

```html
<input type="password">
```

for password fields.

Example:

```html
<label for="password">Password:</label>

<input
    type="password"
    id="password"
    name="password"
>
```

The browser normally hides the characters while they are being entered.

For example:

```text
[ •••••••••• ]
```

> **Important:** `type="password"` hides the characters visually, but it does not encrypt the data. Secure transmission requires HTTPS.

---

## 7. Number Input

Use:

```html
<input type="number">
```

when the user should enter a number.

Example:

```html
<label for="age">Age:</label>

<input
    type="number"
    id="age"
    name="age"
>
```

Browsers may provide controls for increasing or decreasing the value.

You can also specify limits:

```html
<input
    type="number"
    name="age"
    min="1"
    max="100"
>
```

Here:

```text
min → Minimum allowed value
max → Maximum allowed value
```

---

## 8. `min` and `max`

The `min` attribute specifies the minimum allowed value.

The `max` attribute specifies the maximum allowed value.

Example:

```html
<input
    type="number"
    name="marks"
    min="0"
    max="100"
>
```

This is useful for things such as:

* Marks
* Age
* Quantity
* Ratings

For example:

```text
Marks: [ 95 ]
```

A value outside the specified range can fail browser validation when the form is submitted.

---

## 9. `step`

The `step` attribute controls the allowed increments for certain input types.

Example:

```html
<input
    type="number"
    name="quantity"
    min="0"
    step="1"
>
```

Another example:

```html
<input
    type="number"
    name="rating"
    min="0"
    max="5"
    step="0.5"
>
```

Possible values can include:

```text
0
0.5
1
1.5
2
...
5
```

---

## 10. Required Inputs

The `required` attribute tells the browser that the user must provide a value before submitting the form.

Example:

```html
<input
    type="text"
    name="username"
    required
>
```

If the user leaves it empty and submits the form, the browser can display a validation message.

Another example:

```html
<input
    type="email"
    name="email"
    required
>
```

---

## 11. `readonly`

The `readonly` attribute makes a text-like input's value not editable by the user.

Example:

```html
<input
    type="text"
    name="studentId"
    value="CME102"
    readonly
>
```

The user can normally select or copy the value, but cannot edit it through the control.

A readonly control can still be included in form submission.

---

## 12. `disabled`

The `disabled` attribute disables an input.

Example:

```html
<input
    type="text"
    name="username"
    value="Owais"
    disabled
>
```

A disabled control:

* Cannot normally be interacted with
* Is usually displayed as unavailable
* Is not included in normal form submission

This is an important difference between `readonly` and `disabled`.

---

## 13. `readonly` vs `disabled`

| Attribute  | User can edit? | Normally submitted? |
| :--------- | :------------- | :------------------ |
| `readonly` | No             | Yes                 |
| `disabled` | No             | No                  |

Easy way to remember:

```text
readonly  → Can see/use, but cannot edit
disabled  → Cannot use
```

## 14. Search Input

HTML provides a specific input type for search fields:

```html
<input type="search">
```

Example:

```html
<form action="/search" method="get">

    <label for="query">Search:</label>

    <input
        type="search"
        id="query"
        name="q"
        placeholder="Search courses"
    >

    <button type="submit">Search</button>

</form>
```

A search input is useful for:

* Website search
* Product search
* Course search
* Document search

## 16. Telephone Input

Use:

```html
<input type="tel">
```

for telephone numbers.

Example:

```html
<label for="phone">Phone:</label>

<input
    type="tel"
    id="phone"
```

A phone number is generally better represented as a telephone value rather than a mathematical number.

The browser may provide a date picker.

for selecting a time.

## 19. Checkbox Input

A checkbox allows the user to select or deselect an option.

Example:

```html
<input
    type="checkbox"
    id="terms"
    name="terms"
>

<label for="terms">
    I agree to the terms
</label>
```

A checkbox can represent a yes/no choice.

For example:

```text
☐ I agree to the terms
```

When selected:

```text
☑ I agree to the terms
```

---

## 20. Multiple Checkboxes

You can provide several independent choices.

Example:

```html
<p>Select your skills:</p>

<input type="checkbox" id="html" name="skills" value="html">
<label for="html">HTML</label>

<input type="checkbox" id="css" name="skills" value="css">
<label for="css">CSS</label>

<input type="checkbox" id="js" name="skills" value="javascript">
<label for="js">JavaScript</label>
```

The user can select more than one option.

```text
☑ HTML
☑ CSS
☐ JavaScript
```

---

## 21. Radio Buttons

Radio buttons are used when the user should choose **one option from a group**.

Example:

```html
<p>Select your year:</p>

<input
    type="radio"
    id="first"
    name="year"
    value="first"
>

<label for="first">First Year</label>

<input
    type="radio"
    id="second"
    name="year"
    value="second"
>

<label for="second">Second Year</label>

<input
    type="radio"
    id="third"
    name="year"
    value="third"
>

<label for="third">Third Year</label>
```

The important part is that the radio buttons have the **same `name`**:

```text
name="year"
```

This makes them one group.

---

## 22. Radio Buttons vs Checkboxes

| Control      | Purpose                                           |
| :----------- | :------------------------------------------------ |
| Checkbox     | Select zero, one, or multiple independent options |
| Radio button | Select one option from a group                    |

Example:

```text
Skills:
☑ HTML
☑ CSS
☑ JavaScript
```

Multiple choices are possible.

But:

```text
Year:
○ First Year
○ Second Year
○ Third Year
```

Only one year should normally be selected.

```html
<input type="file">
```

Example:

```html
<label for="resume">Upload Resume:</label>

<input
```

## 24. Multiple File Selection

The `multiple` attribute allows more than one file to be selected.

Example:

```html
<input
    type="file"
    name="documents"
    multiple
>
```

Without `multiple`, the control normally allows one selected file.

With `multiple`, the user can select multiple files.

---

## 25. Hidden Input

The `hidden` type creates an input that is not displayed to the user.

Example:

```html
<input
    type="hidden"
    name="course"
    value="html"
>
```

This can be used to include additional information in a form submission.

> **Important:** Hidden does not mean secure. A user can inspect the HTML and see hidden form fields. Do not store secrets or passwords in hidden inputs.

---

## 26. Submit Button

An input can also create a submit button:

```html
<input type="submit" value="Submit">
```

Example:

```html
<form>

    <input type="text" name="name">

    <input
        type="submit"
        value="Submit"
    >

</form>
```

The `value` determines the text displayed on the button.

However, the `<button>` element is often more flexible:

```html
<button type="submit">Submit</button>
```

---

## 27. Reset Input

The reset input can reset form controls to their initial values.

Example:

```html
<input
    type="reset"
    value="Reset"
>
```

Example form:

```html
<form>

    <input
        type="text"
        name="name"
    >

    <input
        type="email"
        name="email"
    >

    <input
        type="reset"
        value="Reset"
    >

</form>
```

Clicking the reset button restores controls to their initial values.

> **Tip:** Use reset buttons carefully because users can accidentally clear information they have entered.

## 28. The `required` Attribute With Different Inputs

`required` can be used with many form controls.

Text:

```html
<input type="text" required>
```

Email:

```html
<input type="email" required>
```

Number:

```html
<input type="number" required>
```

Checkbox:

```html
<input type="checkbox" required>
```

Radio groups can also use `required` so that an option must be selected.

---

## 29. The `minlength` and `maxlength` Attributes

For text-like inputs, you can control the number of characters.

Example:

```html
<input
    type="text"
    name="username"
    minlength="3"
    maxlength="20"
>
```

Here:

```text
minlength="3"  → At least 3 characters
maxlength="20" → At most 20 characters
```

This can be useful for usernames and similar fields.

---

## 30. The `size` Attribute

The `size` attribute can specify the visible width of certain text-like inputs.

Example:

```html
<input
    type="text"
    name="username"
    size="30"
>
```

This affects the displayed width of the input control.

> **Important:** `size` does not set the maximum number of characters. Use `maxlength` for that.

## 32. Choosing the Correct Input Type

Choose an input type based on the information being collected.

| Information             | Input type |
| :---------------------- | :--------- |
| Name                    | `text`     |
| Email                   | `email`    |
| Password                | `password` |
| Number                  | `number`   |
| Search                  | `search`   |
| Website                 | `url`      |
| Phone                   | `tel`      |
| Date                    | `date`     |
| Time                    | `time`     |
| File                    | `file`     |
| Yes/No choice           | `checkbox` |
| One choice from a group | `radio`    |

Using the correct type gives the browser useful information about the expected data.

## 33. Common Mistakes

### Mistake 1: Using `number` for phone numbers

Avoid:

```html
<input type="number" name="phone">
```

Prefer:

```html
<input type="tel" name="phone">
```

A telephone number is not normally used for mathematical calculations.

---

### Mistake 2: Using placeholder instead of a label

Avoid:

```html
<input
    type="email"
    placeholder="Enter email"
>
```

Prefer:

```html
<label for="email">Email:</label>

<input
    type="email"
    id="email"
    name="email"
    placeholder="you@example.com"
>
```

---

### Mistake 3: Giving radio buttons different names

Incorrect:

```html
<input type="radio" name="year1">
<input type="radio" name="year2">
```

They may behave as separate groups.

Correct:

```html
<input type="radio" name="year" value="first">
<input type="radio" name="year" value="second">
<input type="radio" name="year" value="third">
```

---

### Mistake 4: Thinking `disabled` values are submitted

A disabled control is not included in normal form submission.

```html
<input
    type="text"
    name="username"
    value="Owais"
    disabled
>
```

If you need the value submitted while preventing editing, `readonly` may be more appropriate for supported controls.

---

### Mistake 5: Thinking password inputs encrypt data

This:

```html
<input type="password">
```

only controls how the value is displayed.

It does not provide encryption.

Use HTTPS when transmitting sensitive information.

## Key Points

* `<input>` is one of the most important HTML form elements.
* It is a void element and does not need a closing tag.
* The `type` attribute determines the input control.
* `text` is used for general single-line text.
* `email` is used for email addresses.
* `password` hides entered characters visually.
* `number` is used for numeric values.
* `tel` is intended for telephone numbers.
* `url` is intended for web addresses.
* `search` is designed for search fields.
* `date` and `time` allow users to enter dates and times.
* `checkbox` allows independent selections.
* Radio buttons allow one choice from a group.
* Radio buttons in the same group normally use the same `name`.
* `file` allows users to choose files.
* `required` enables built-in required-field validation.
* `placeholder` provides a hint but should not replace a label.
* `readonly` prevents editing while the value can normally still be submitted.
* `disabled` prevents interaction and the control is normally not submitted.
* `min`, `max`, and `step` can constrain numeric/date inputs.
* `minlength` and `maxlength` control text length.
* `multiple` allows multiple selections where supported.
* `type="password"` does not encrypt data; HTTPS is needed for secure transmission.
