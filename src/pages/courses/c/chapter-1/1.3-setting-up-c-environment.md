# Chapter 1: Introduction to C

## Section 3: Setting Up C Environment

In the previous lessons, we learned about C programming, its features, and its applications.

Now it is time to **set up the environment required to write and run C programs**.

---

### 1. What Do We Need to Write C Programs?

To write and run C programs, we need a few basic tools.

#### C Compiler

A **C compiler** converts C source code into machine code that the computer can execute.

Some commonly used C compilers are:

* GCC
* Clang
* Microsoft Visual C

For beginners, **GCC** is a popular choice.

#### Code Editor

A code editor is used to write and edit C source code.

Some commonly used editors are:

* Visual Studio Code
* Code::Blocks
* Dev-C++

In this course, we will use **Visual Studio Code** as the code editor.

#### Terminal

A terminal allows us to run commands for compiling and executing C programs.

On Windows, we can use:

* Command Prompt
* PowerShell
* VS Code Terminal

---

### 2. Installing Visual Studio Code

**Visual Studio Code**, commonly called VS Code, is a lightweight code editor.

It can be used to write C programs and many other types of code.

To use VS Code for C programming:

1. Download and install VS Code.
2. Open VS Code.
3. Create a folder for your C programs.
4. Open the folder in VS Code.

You can then create C source files inside the folder.

---

### 3. Installing a C Compiler

A C compiler is required to convert C source code into an executable program.

For this course, we can use **GCC**.

After installing GCC, we can check whether it is available from the terminal.

Open the terminal and type:

```text
gcc --version
```

If GCC is installed correctly, the terminal will display information about the installed GCC version.

For example:

```text
gcc (GCC) 13.2.0
```

The exact version may be different depending on the compiler installed on your computer.

---

### 4. Creating Your First C File

After setting up the editor and compiler, create a new file in VS Code.

Name the file:

```text
main.c
```

The `.c` extension tells the computer that the file contains **C source code**.

Now write a simple C program:

```c
#include <stdio.h>

int main() {
    printf("Hello, C!");
    return 0;
}
```

Save the file before compiling it.

---

### 5. Compiling a C Program

Open the terminal in the folder containing `main.c`.

Use the following command:

```text
gcc main.c -o main
```

Here:

* `gcc` → C compiler command
* `main.c` → C source file
* `-o main` → specifies the name of the output program

If there are no errors, the compiler creates an executable program.

On Windows, it may create:

```text
main.exe
```

---

### 6. Running a C Program

After successfully compiling the program, we can run it from the terminal.

On Windows, use:

```text
main
```

or:

```text
.\main.exe
```

The output will be:

```text
Hello, C!
```

The complete process is:

```text
Write C Code
     ↓
Save as main.c
     ↓
Compile using GCC
     ↓
Executable File
     ↓
Run the Program
     ↓
Output
```

---

### 7. Common Setup Problems

Beginners may face a few common problems while setting up C.

#### `'gcc' is not recognized`

This usually means that GCC is not installed correctly or its location has not been added to the system PATH.

Check that GCC is installed and available from the terminal.

#### Compilation Error

If the C program contains a syntax error, GCC will display an error message.

For example:

```c
printf("Hello, C!")
```

The semicolon is missing.

Correct version:

```c
printf("Hello, C!");
```

#### Program Does Not Run

Make sure that:

* The program was compiled successfully.
* You are running the correct executable.
* The terminal is opened in the correct folder.

## Real-World Example 🌍

Imagine a student wants to create a simple **college marks calculator** using C.

Before writing the program, the student needs:

* A code editor to write the program.
* A C compiler to compile the program.
* A terminal to run the program.

The basic workflow is:

```text
Write Program
     ↓
Compile Program
     ↓
Run Program
     ↓
Check Result
```

This same process is used when developing larger C programs.

---

## Key Points

* A C compiler converts C source code into an executable program.
* GCC is a commonly used C compiler.
* VS Code can be used to write C programs.
* C source files normally use the `.c` extension.
* `gcc --version` can be used to check the GCC installation.
* `gcc main.c -o main` compiles a C program.
* The compiled program can then be executed from the terminal.
* Compilation errors should be fixed before running the program.
