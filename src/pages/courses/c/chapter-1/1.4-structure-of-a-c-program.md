# Chapter 1: Introduction to C

## Section 4: Structure of a C Program

A C program follows a specific structure. Understanding this structure helps you write, read, and debug C programs easily.

A basic C program usually contains header files, the `main()` function, declarations, statements, and comments.

### 1. Basic Structure of a C Program

A simple C program looks like this:

```c
#include <stdio.h>

int main()
{
    printf("Hello, World!");
    return 0;
}
```

```output
Hello, World!
```

Each part of this program has a specific purpose.

### 2. Header Files

Header files provide functions that we can use in our program.

For example:

```c
#include <stdio.h>
```

Here:

* `#include` tells the compiler to include a header file.
* `stdio.h` stands for **Standard Input Output Header**.
* It provides functions such as `printf()` and `scanf()`.

Example:

```c
#include <stdio.h>

int main()
{
    printf("Welcome to C");
    return 0;
}
```

```output
Welcome to C
```

### 3. The main() Function

Every C program starts execution from the `main()` function.

```c
int main()
{
    printf("C Programming");
    return 0;
}
```

Here:

* `int` is the return type.
* `main()` is the starting point of the program.
* `{ }` contains the statements of the function.
* `return 0;` indicates that the program finished successfully.

```output
C Programming
```

### 4. Statements

Statements are instructions given to the computer.

For example:

```c
printf("Hello");
printf("Welcome");
```

Each statement normally ends with a semicolon `;`.

Complete program:

```c
#include <stdio.h>

int main()
{
    printf("Hello\n");
    printf("Welcome");
    return 0;
}
```

```output
Hello
Welcome
```

Here, `\n` moves the cursor to the next line.

### 5. Variables and Declarations

Variables are used to store data.

For example:

```c
#include <stdio.h>

int main()
{
    int age = 16;

    printf("Age = %d", age);

    return 0;
}
```

```output
Age = 16
```

Here:

* `int` specifies the data type.
* `age` is the variable name.
* `16` is the value stored in the variable.

### 6. Comments

Comments are notes written inside a program. They are ignored by the compiler.

#### Single-Line Comment

A single-line comment starts with `//`.

```c
#include <stdio.h>

int main()
{
    // Print a message
    printf("Hello, C!");

    return 0;
}
```

```output
Hello, C!
```

#### Multi-Line Comment

A multi-line comment starts with `/*` and ends with `*/`.

```c
#include <stdio.h>

int main()
{
    /*
       This program
       prints a message.
    */

    printf("Learning C");

    return 0;
}
```

```output
Learning C
```

### 7. Complete Structure of a C Program

A C program can contain the following parts:

```text
Header Files
     ↓
main() Function
     ↓
Variable Declarations
     ↓
Statements
     ↓
return Statement
```

Example:

```c
#include <stdio.h>

int main()
{
    int a = 10;
    int b = 20;
    int sum = a + b;

    printf("Sum = %d", sum);

    return 0;
}
```

```output
Sum = 30
```

The program:

1. Includes the `stdio.h` header file.
2. Starts execution from `main()`.
3. Creates variables `a`, `b`, and `sum`.
4. Calculates the sum.
5. Prints the result.
6. Returns `0`.

### 8. Common Symbols in C Programs

| Symbol  | Purpose                             |
| ------- | ----------------------------------- |
| `#`     | Used in preprocessor directives     |
| `< >`   | Used around system header files     |
| `{ }`   | Defines a block of code             |
| `( )`   | Used with functions and expressions |
| `;`     | Ends a statement                    |
| `//`    | Single-line comment                 |
| `/* */` | Multi-line comment                  |

### 9. Common Mistakes

#### Missing Semicolon

Incorrect:

```c
printf("Hello")
```

Correct:

```c
printf("Hello");
```

#### Missing Braces

The statements inside `main()` must be placed inside `{ }`.

Correct:

```c
int main()
{
    printf("Hello");
    return 0;
}
```

#### Forgetting the Header File

When using `printf()`, include:

```c
#include <stdio.h>
```

#### Incorrect Capitalization

C is case-sensitive.

For example:

```c
printf("Hello");
```

is correct, while:

```c
Printf("Hello");
```

is different and can cause an error.

## Real-World Example 🌍

Suppose you are creating a small program for a school system to display a student's marks.

```c
#include <stdio.h>

int main()
{
    int marks = 85;

    printf("Student Marks = %d", marks);

    return 0;
}
```

```output
Student Marks = 85
```

The same structure can later be used for larger programs such as student management systems, billing systems, and banking applications.

## Key Points

* A C program normally starts execution from the `main()` function.
* Header files provide useful functions.
* `#include <stdio.h>` is commonly used for input and output.
* Statements usually end with a semicolon `;`.
* `{ }` are used to define blocks of code.
* Variables are used to store data.
* `printf()` is used to display output.
* `return 0;` indicates successful completion of the program.
* Comments are used to explain code and are ignored by the compiler.
* C is case-sensitive.
