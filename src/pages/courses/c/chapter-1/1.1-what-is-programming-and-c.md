# Chapter 1: Introduction to C

## Section 1: What is Programming & C?

Programming is the process of giving instructions to a computer to perform a specific task.

A computer cannot understand normal human language directly. We use **programming languages** to write instructions that a computer can understand and execute.

Now it is time to understand **programming and the C programming language**.

---

### 1. What is Programming?

A **program** is a set of instructions written to solve a problem or perform a particular task.

For example, if we want a computer to calculate the sum of two numbers, we can follow these steps:

1. Take the first number.
2. Take the second number.
3. Add both numbers.
4. Display the result.

These steps can be converted into a program.

### Real-World Example

Imagine a **vending machine**.

When you select a product, the machine follows a sequence of instructions:

* Check the selected product.
* Check the payment.
* Prepare the product.
* Give the product to the user.

Programming works in a similar way. We give the computer a sequence of instructions, and it performs them.

### 3. What is C?

**C is a general-purpose programming language** developed by **Dennis Ritchie** at Bell Labs in the early 1970s.

C is known for being:

* Fast
* Efficient
* Portable
* Close to computer hardware

C is also useful for learning the fundamental concepts of programming.

### 5. How Does a C Program Work?

A C program is written as **source code**.

The computer does not directly execute C source code. A **compiler** translates the C source code into machine code that the computer can execute.

The basic process is:

```text
C Source Code
      ↓
   Compiler
      ↓
 Machine Code
      ↓
    Output
```

For example:

```c
#include <stdio.h>

int main() {
    printf("Hello, C!");
    return 0;
}
```

The compiler translates this C program into machine code.

The program then produces:

```output
Hello, C!
```

---

### 6. A Simple C Program

Let's look at a simple C program that adds two numbers:

```c
#include <stdio.h>

int main() {
    int a = 10;
    int b = 20;

    int sum = a + b;

    printf("Sum = %d", sum);

    return 0;
}
```

```output
Sum = 30
```

The program works as follows:

* `int a = 10;` stores the first number.
* `int b = 20;` stores the second number.
* `a + b` calculates the sum.
* `printf()` displays the result.
* `return 0;` ends the program.

We will learn each of these concepts in detail in the following lessons.

### 7. Programming and Problem Solving

Programming is not only about writing code.

A programmer first **understands the problem** and then creates a solution.

A simple problem-solving process is:

1. Understand the problem.
2. Identify the input.
3. Decide the required processing.
4. Identify the output.
5. Write the steps or algorithm.
6. Convert the steps into C code.
7. Test the program.
8. Fix errors if necessary.

### Example: Area of a Rectangle

Suppose we want to find the area of a rectangle.

**Input:**

* Length
* Width

**Formula:**

```text
Area = Length × Width
```

**Output:**

* Area of the rectangle

The formula can then be converted into a C program.
