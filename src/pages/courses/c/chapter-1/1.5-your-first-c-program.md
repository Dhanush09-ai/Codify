# Chapter 1: Introduction to C

## Section 5: Your First C Program

Now that you know the basic structure of a C program, let's write and run your first C program.

We will start with a simple program that displays a message on the screen.

### 1. Creating a C File

To write a C program:

1. Open your code editor.
2. Create a new file.
3. Save the file with the `.c` extension.
4. For example, save it as `main.c`.

The `.c` extension tells the compiler that the file contains C source code.

### 2. Writing Your First C Program

Let's write a simple C program:

```c
#include <stdio.h>

int main()
{
    printf("Hello, C!");
    return 0;
}
```

```output
Hello, C!
```

This program prints `Hello, C!` on the screen.

### 3. Understanding the Program

Let's understand each part of the program.

#### #include <stdio.h>

```c
#include <stdio.h>
```

This includes the `stdio.h` header file.

It provides functions such as `printf()` that are used for input and output.

#### int main()

```c
int main()
{
    // Program statements
}
```

The `main()` function is where the execution of a C program begins.

`int` means that the function returns an integer value.

#### printf()

```c
printf("Hello, C!");
```

`printf()` is used to display text on the screen.

The text inside `" "` is called a string.

#### return 0;

```c
return 0;
```

This ends the `main()` function and indicates that the program completed successfully.

### 4. Printing Different Messages

You can change the message inside `printf()`.

For example:

```c
#include <stdio.h>

int main()
{
    printf("Welcome to Codify!");
    return 0;
}
```

```output
Welcome to Codify!
```

Another example:

```c
#include <stdio.h>

int main()
{
    printf("I am learning C programming.");
    return 0;
}
```

```output
I am learning C programming.
```

### 5. Printing Multiple Lines

You can use `\n` to move the output to the next line.

```c
#include <stdio.h>

int main()
{
    printf("Hello!\n");
    printf("Welcome to C programming.\n");
    printf("Let's learn C.");

    return 0;
}
```

```output
Hello!
Welcome to C programming.
Let's learn C.
```

Here, `\n` is called a **newline character**.

### 6. Printing Numbers

`printf()` can also display numbers.

For example:

```c
#include <stdio.h>

int main()
{
    printf("%d", 100);
    return 0;
}
```

```output
100
```

Here, `%d` is used to display an integer value.

You can also print text and numbers together:

```c
#include <stdio.h>

int main()
{
    printf("My age is %d", 16);
    return 0;
}
```

```output
My age is 16
```

### 7. Using Variables

You can store a value in a variable and print it.

```c
#include <stdio.h>

int main()
{
    int age = 16;

    printf("Age = %d", age);

    return 0;
}
```

```output
Age = 16
```

Here:

* `int` is the data type.
* `age` is the variable.
* `16` is the value stored in the variable.
* `%d` is used to print the integer value.

### 8. Using Multiple printf() Statements

A program can contain multiple `printf()` statements.

```c
#include <stdio.h>

int main()
{
    printf("Name: Owais\n");
    printf("Course: C Programming\n");
    printf("Level: Beginner");

    return 0;
}
```

```output
Name: Owais
Course: C Programming
Level: Beginner
```

Each `printf()` statement displays its content in the order in which it appears.

### 9. Common Mistakes

#### Missing Semicolon

Every `printf()` statement should end with `;`.

Incorrect:

```c
printf("Hello, C!")
```

Correct:

```c
printf("Hello, C!");
```

#### Missing Header File

When using `printf()`, include:

```c
#include <stdio.h>
```

#### Incorrect Capitalization

C is case-sensitive.

Correct:

```c
printf("Hello");
```

Incorrect:

```c
Printf("Hello");
```

#### Forgetting Quotes

Text printed using `printf()` should be placed inside double quotes.

Correct:

```c
printf("Hello, C!");
```

## Real-World Example 🌍

Imagine a student wants to create a simple program to display their course information.

```c
#include <stdio.h>

int main()
{
    printf("Student Information\n");
    printf("Name: Owais\n");
    printf("Course: C Programming\n");
    printf("Status: Learning");

    return 0;
}
```

```output
Student Information
Name: Owais
Course: C Programming
Status: Learning
```

The same idea can be used to display information in larger programs such as student management systems, billing systems, and registration systems.

## Key Points

* A C program is usually saved with the `.c` extension.
* Program execution starts from the `main()` function.
* `#include <stdio.h>` provides standard input/output functions.
* `printf()` is used to display output.
* `\n` moves the output to a new line.
* `%d` is used to display integer values.
* Variables can be used to store and display data.
* C statements normally end with a semicolon `;`.
* C is case-sensitive.
* `return 0;` indicates successful completion of the program.
