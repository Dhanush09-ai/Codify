# Chapter 10: Structures

## Section 2: Array of Structures & Structure Pointers

A structure can store information about one record.

For example, one `Student` structure can store the details of one student.

But real programs often need to store information about **many students**.

C allows us to create an **array of structures**.

We can also create **pointers to structures** to access and modify structure data efficiently.

---

## 1. Array of Structures

An array of structures stores multiple structure variables of the same type.

For example:

```c
struct Student {
    char name[50];
    int age;
    float marks;
};
```

We can create an array:

```c
struct Student students[3];
```

This creates space for 3 student records.

Each element is a complete `Student` structure:

```text
students[0] → First student
students[1] → Second student
students[2] → Third student
```

---

## 2. Initializing an Array of Structures

An array of structures can be initialized when it is declared.

```c
#include <stdio.h>

struct Student {
    char name[50];
    int age;
    float marks;
};

int main() {
    struct Student students[3] = {
        {"Owais", 18, 91.5},
        {"Ali", 19, 85.0},
        {"Sara", 18, 88.5}
    };

    return 0;
}
```

Each set of values belongs to one structure element.

---

## 3. Accessing Array Elements

We use an array index followed by the dot operator.

For example:

```c
students[0].name
students[0].age
students[0].marks
```

Example:

```c
#include <stdio.h>

struct Student {
    char name[50];
    int age;
    float marks;
};

int main() {
    struct Student students[3] = {
        {"Owais", 18, 91.5},
        {"Ali", 19, 85.0},
        {"Sara", 18, 88.5}
    };

    printf("%s\n", students[0].name);
    printf("%d\n", students[1].age);
    printf("%.2f\n", students[2].marks);

    return 0;
}
```

```output
Owais
19
88.50
```

The general form is:

```c
array[index].member
```

---

## 4. Printing All Structure Records

A loop can be used to process every structure in the array.

```c
#include <stdio.h>

struct Student {
    char name[50];
    int age;
    float marks;
};

int main() {
    struct Student students[3] = {
        {"Owais", 18, 91.5},
        {"Ali", 19, 85.0},
        {"Sara", 18, 88.5}
    };

    for (int i = 0; i < 3; i++) {
        printf("Name: %s\n", students[i].name);
        printf("Age: %d\n", students[i].age);
        printf("Marks: %.2f\n\n", students[i].marks);
    }

    return 0;
}
```

```output
Name: Owais
Age: 18
Marks: 91.50

Name: Ali
Age: 19
Marks: 85.00

Name: Sara
Age: 18
Marks: 88.50
```

The loop changes the index `i`, allowing us to access each student.

## 5. Taking Input for an Array of Structures

We can also take input from the user.

```c
#include <stdio.h>

struct Student {
    char name[50];
    int age;
    float marks;
};

int main() {
    struct Student students[2];

    for (int i = 0; i < 2; i++) {
        printf("Enter name: ");
        scanf("%49s", students[i].name);

        printf("Enter age: ");
        scanf("%d", &students[i].age);

        printf("Enter marks: ");
        scanf("%f", &students[i].marks);
    }

    printf("\nStudent Details\n");

    for (int i = 0; i < 2; i++) {
        printf("%s %d %.2f\n",
               students[i].name,
               students[i].age,
               students[i].marks);
    }

    return 0;
}
```

```output
Enter name: Owais
Enter age: 18
Enter marks: 90
Enter name: Ali
Enter age: 19
Enter marks: 85

Student Details
Owais 18 90.00
Ali 19 85.00
```

## 6. Finding the Highest Marks

An array of structures can be searched just like a normal array.

For example, we can find the student with the highest marks.

```c
#include <stdio.h>

struct Student {
    char name[50];
    int age;
    float marks;
};

int main() {
    struct Student students[3] = {
        {"Owais", 18, 91.5},
        {"Ali", 19, 85.0},
        {"Sara", 18, 88.5}
    };

    int highest = 0;

    for (int i = 1; i < 3; i++) {
        if (students[i].marks > students[highest].marks) {
            highest = i;
        }
    }

    printf("Top Student: %s\n", students[highest].name);
    printf("Marks: %.2f\n", students[highest].marks);

    return 0;
}
```

```output
Top Student: Owais
Marks: 91.50
```

Here, `highest` stores the index of the structure containing the highest marks.

## 7. Structure Pointer

A pointer can store the address of a structure variable.

Example:

```c
struct Student {
    char name[50];
    int age;
};

struct Student student;

struct Student *ptr = &student;
```

Here:

```text
student
   ↑
   |
ptr
```

`ptr` contains the address of `student`.

---

## 8. Accessing Structure Members Through a Pointer

There are two ways to access a structure member through a pointer.

Using `*` and `.`:

```c
(*ptr).age
```

Or using the **arrow operator `->`**:

```c
ptr->age
```

Both mean the same thing.

```c
#include <stdio.h>

struct Student {
    char name[50];
    int age;
};

int main() {
    struct Student student = {"Owais", 18};

    struct Student *ptr = &student;

    printf("%s\n", (*ptr).name);
    printf("%d\n", (*ptr).age);

    printf("%s\n", ptr->name);
    printf("%d\n", ptr->age);

    return 0;
}
```

```output
Owais
18
Owais
18
```

---

## 9. The Arrow `->` Operator

The arrow operator is used when a pointer points to a structure.

Syntax:

```c
pointer->member
```

For example:

```c
ptr->age
ptr->name
```

This is equivalent to:

```c
(*ptr).age
(*ptr).name
```

### Remember

```text
Normal structure variable → .
Structure pointer         → ->
```

---

## 10. Modifying a Structure Through a Pointer

A structure pointer can be used to modify the original structure.

```c
#include <stdio.h>

struct Student {
    char name[50];
    int age;
};

int main() {
    struct Student student = {"Owais", 18};

    struct Student *ptr = &student;

    ptr->age = 19;

    printf("Name = %s\n", student.name);
    printf("Age = %d\n", student.age);

    return 0;
}
```

```output
Name = Owais
Age = 19
```

The pointer points to the original structure, so changing:

```c
ptr->age
```

changes:

```c
student.age
```

## 11. Structure Pointer with `typedef`

Using `typedef` can make structure declarations shorter.

```c
#include <stdio.h>

typedef struct {
    char name[50];
    int age;
    float marks;
} Student;

int main() {
    Student student = {"Owais", 18, 92.5};

    Student *ptr = &student;

    printf("Name = %s\n", ptr->name);
    printf("Age = %d\n", ptr->age);
    printf("Marks = %.2f\n", ptr->marks);

    return 0;
}
```

```output
Name = Owais
Age = 18
Marks = 92.50
```

## 12. Pointer to Each Element of an Array of Structures

A pointer can point to an element of an array of structures.

```c
#include <stdio.h>

typedef struct {
    int id;
    float price;
} Product;

int main() {
    Product products[3] = {
        {101, 250.50},
        {102, 400.00},
        {103, 150.75}
    };

    Product *ptr = &products[0];

    printf("ID = %d\n", ptr->id);
    printf("Price = %.2f\n", ptr->price);

    return 0;
}
```

```output
ID = 101
Price = 250.50
```

The pointer points to the first structure in the array.

---

## 13. Traversing an Array of Structures Using a Pointer

A structure pointer can move through an array of structures.

```c
#include <stdio.h>

typedef struct {
    int id;
    float price;
} Product;

int main() {
    Product products[3] = {
        {101, 250.50},
        {102, 400.00},
        {103, 150.75}
    };

    Product *ptr = products;

    for (int i = 0; i < 3; i++) {
        printf("ID = %d, Price = %.2f\n",
               ptr->id, ptr->price);

        ptr++;
    }

    return 0;
}
```

```output
ID = 101, Price = 250.50
ID = 102, Price = 400.00
ID = 103, Price = 150.75
```

When `ptr++` is used, the pointer moves to the next `Product` structure.

---

## 14. Passing a Structure Pointer to a Function

A pointer to a structure can be passed to a function.

```c
#include <stdio.h>

typedef struct {
    char name[50];
    int age;
} Student;

void printStudent(Student *ptr) {
    printf("Name = %s\n", ptr->name);
    printf("Age = %d\n", ptr->age);
}

int main() {
    Student student = {"Owais", 18};

    printStudent(&student);

    return 0;
}
```

```output
Name = Owais
Age = 18
```

The function receives the address of the structure.

Inside the function, the arrow operator is used:

```c
ptr->name
ptr->age
```

---

## 15. Modifying a Structure in a Function

A structure pointer allows a function to modify the original structure.

```c
#include <stdio.h>

typedef struct {
    char name[50];
    float marks;
} Student;

void addBonus(Student *ptr) {
    ptr->marks += 5;
}

int main() {
    Student student = {"Owais", 80.0};

    addBonus(&student);

    printf("Name = %s\n", student.name);
    printf("Marks = %.2f\n", student.marks);

    return 0;
}
```

```output
Name = Owais
Marks = 85.00
```

The function changes the original `student` because it receives its address.

## 16. 🌍 Real-World Example: Product Records

An online store may need to store information about many products.

An array of structures can store the records:

```c
#include <stdio.h>

typedef struct {
    int id;
    char name[50];
    float price;
} Product;

int main() {
    Product products[3] = {
        {101, "Keyboard", 750.00},
        {102, "Mouse", 450.00},
        {103, "Monitor", 8500.00}
    };

    Product *ptr = products;

    for (int i = 0; i < 3; i++) {
        printf("ID: %d\n", ptr->id);
        printf("Name: %s\n", ptr->name);
        printf("Price: %.2f\n\n", ptr->price);

        ptr++;
    }

    return 0;
}
```

```output
ID: 101
Name: Keyboard
Price: 750.00

ID: 102
Name: Mouse
Price: 450.00

ID: 103
Name: Monitor
Price: 8500.00
```

Here:

* The array stores multiple product records.
* The pointer accesses each product.
* `->` accesses the members through the pointer.

## ⚠️ Common Mistakes

### 1. Using `.` with a structure pointer

If:

```c
Student *ptr;
```

use:

```c
ptr->age
```

not:

```c
ptr.age
```

---

### 2. Forgetting parentheses with `*` and `.`

This:

```c
(*ptr).age
```

is correct.

The parentheses are necessary because `.` has higher precedence than `*`.

The simpler form is:

```c
ptr->age
```

---

### 3. Using `->` with a normal structure variable

If:

```c
Student student;
```

use:

```c
student.age
```

not:

```c
student->age
```

The arrow operator is for a pointer to a structure.

---

### 4. Using an invalid structure pointer

Before using:

```c
ptr->age
```

make sure `ptr` points to a valid structure.

---

### 5. Going outside an array of structures

If:

```c
Student students[3];
```

valid indexes are:

```text
0 1 2
```

Do not access:

```c
students[3]
```

because it is outside the array.

---

## 🔑 Key Points

* An array of structures stores multiple records of the same structure type.
* Structure array elements are accessed using `array[index].member`.
* A pointer can store the address of a structure.
* The `.` operator is used with a normal structure variable.
* The `->` operator is used with a pointer to a structure.
* `ptr->member` is equivalent to `(*ptr).member`.
* A structure pointer can modify the original structure.
* A pointer can traverse an array of structures using pointer arithmetic.
* Structure pointers can be passed to functions.
* `typedef` can make structure declarations shorter.
