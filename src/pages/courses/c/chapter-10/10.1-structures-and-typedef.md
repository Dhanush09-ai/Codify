# Chapter 10: Structures

## Section 1: Introduction to Structures & typedef

In C, we often need to store information about a real-world object.

For example, a student may have:

* Name
* Roll number
* Age
* Marks

These values can have **different data types**.

A structure allows us to group related variables of different data types under one name.

---

## 1. What is a Structure?

A **structure** is a user-defined data type that groups related variables together.

For example, a student can have:

```text
Name    → string
Age     → int
Marks   → float
```

Instead of creating separate variables:

```c
char name[50];
int age;
float marks;
```

we can group them into one structure.

```c
struct Student {
    char name[50];
    int age;
    float marks;
};
```

Now `Student` represents a collection of related information.

---

## 2. Declaring a Structure

The general syntax is:

```c
struct StructureName {
    dataType member1;
    dataType member2;
    dataType member3;
};
```

Example:

```c
struct Student {
    char name[50];
    int age;
    float marks;
};
```

Here:

* `struct Student` is the structure type.
* `name` is a member.
* `age` is a member.
* `marks` is a member.

The semicolon after the closing `}` is required.

---

## 3. Creating a Structure Variable

After defining a structure, we can create variables of that structure type.

```c
struct Student {
    char name[50];
    int age;
    float marks;
};

int main() {
    struct Student student1;

    return 0;
}
```

Here:

```c
struct Student student1;
```

creates a structure variable named `student1`.

---

## 4. Accessing Structure Members

The **dot operator `.`** is used to access members of a structure.

Example:

```c
#include <stdio.h>

struct Student {
    char name[50];
    int age;
    float marks;
};

int main() {
    struct Student student1;

    student1.age = 18;
    student1.marks = 85.5;

    printf("Age = %d\n", student1.age);
    printf("Marks = %.2f\n", student1.marks);

    return 0;
}
```

```output
Age = 18
Marks = 85.50
```

The general form is:

```c
structureVariable.member
```

For example:

```c
student1.age
student1.marks
```

---

## 5. Initializing a Structure

A structure can be initialized when it is created.

```c
#include <stdio.h>

struct Student {
    char name[50];
    int age;
    float marks;
};

int main() {
    struct Student student1 = {"Owais", 18, 92.5};

    printf("Name = %s\n", student1.name);
    printf("Age = %d\n", student1.age);
    printf("Marks = %.2f\n", student1.marks);

    return 0;
}
```

```output
Name = Owais
Age = 18
Marks = 92.50
```

The values are assigned to the members in the same order in which they are declared.

---

## 6. Structure with Different Data Types

One important feature of structures is that their members can have different data types.

Example:

```c
struct Product {
    int id;
    char name[50];
    float price;
};
```

Here:

| Member  | Data Type  |
| ------- | ---------- |
| `id`    | `int`      |
| `name`  | `char[50]` |
| `price` | `float`    |

This makes structures useful for representing real-world records.

---

## 7. Taking Input into a Structure

We can take input directly into structure members.

```c
#include <stdio.h>

struct Student {
    char name[50];
    int age;
    float marks;
};

int main() {
    struct Student student;

    printf("Enter name: ");
    scanf("%49s", student.name);

    printf("Enter age: ");
    scanf("%d", &student.age);

    printf("Enter marks: ");
    scanf("%f", &student.marks);

    printf("\nStudent Details\n");
    printf("Name = %s\n", student.name);
    printf("Age = %d\n", student.age);
    printf("Marks = %.2f\n", student.marks);

    return 0;
}
```

```output
Enter name: Owais
Enter age: 18
Enter marks: 90.5

Student Details
Name = Owais
Age = 18
Marks = 90.50
```

Notice the difference:

For an integer:

```c
scanf("%d", &student.age);
```

For a character array:

```c
scanf("%49s", student.name);
```

The array name already represents the address of its first character in this context, so `&` is not used for `student.name`.

---

## 8. Multiple Structure Variables

We can create multiple variables of the same structure type.

```c
#include <stdio.h>

struct Student {
    char name[50];
    int age;
    float marks;
};

int main() {
    struct Student student1 = {"Owais", 18, 90.5};
    struct Student student2 = {"Ali", 19, 85.0};

    printf("%s - %.2f\n", student1.name, student1.marks);
    printf("%s - %.2f\n", student2.name, student2.marks);

    return 0;
}
```

```output
Owais - 90.50
Ali - 85.00
```

Both variables have the same structure but contain different data.

---

## 9. Using `typedef` with Structures

Writing:

```c
struct Student student1;
```

every time can be a little lengthy.

C provides `typedef` to create an alternative name for a data type.

For example:

```c
typedef struct {
    char name[50];
    int age;
    float marks;
} Student;
```

Now we can simply write:

```c
Student student1;
```

instead of:

```c
struct Student student1;
```

---

## 10. Structure with `typedef`

A common syntax is:

```c
typedef struct {
    dataType member1;
    dataType member2;
    dataType member3;
} TypeName;
```

Example:

```c
#include <stdio.h>

typedef struct {
    char name[50];
    int age;
    float marks;
} Student;

int main() {
    Student student1 = {"Owais", 18, 92.5};

    printf("Name = %s\n", student1.name);
    printf("Age = %d\n", student1.age);
    printf("Marks = %.2f\n", student1.marks);

    return 0;
}
```

```output
Name = Owais
Age = 18
Marks = 92.50
```

Here:

```c
typedef struct {
    ...
} Student;
```

creates `Student` as an alias for the structure type.

---

## 11. `typedef` with a Named Structure

We can also give the structure a name.

```c
typedef struct Student {
    char name[50];
    int age;
    float marks;
} Student;
```

Now both the structure tag and typedef name are available.

We can create variables using:

```c
Student student1;
```

The `typedef` name makes the declaration shorter.

---

## 12. Why Use Structures?

Structures are useful when multiple pieces of information belong together.

For example, a student record can contain:

```text
Student
├── Roll Number
├── Name
├── Age
└── Marks
```

Instead of managing separate variables, one structure can represent the complete record.

Structures are commonly used for:

* Student records
* Employee records
* Product information
* Bank account information
* Book details
* Customer records

---

## 13. Structure Assignment

One structure variable can be assigned to another structure variable of the same type.

Example:

```c
#include <stdio.h>

typedef struct {
    int id;
    float price;
} Product;

int main() {
    Product p1 = {101, 250.50};
    Product p2;

    p2 = p1;

    printf("ID = %d\n", p2.id);
    printf("Price = %.2f\n", p2.price);

    return 0;
}
```

```output
ID = 101
Price = 250.50
```

The values of `p1` are copied into `p2`.

---

## 14. Structure Members Can Be Modified

Structure members can be changed after the structure variable is created.

```c
#include <stdio.h>

typedef struct {
    char name[50];
    int age;
} Student;

int main() {
    Student student = {"Owais", 18};

    student.age = 19;

    printf("Name = %s\n", student.name);
    printf("Age = %d\n", student.age);

    return 0;
}
```

```output
Name = Owais
Age = 19
```

The statement:

```c
student.age = 19;
```

changes only the `age` member.

---

## 15. Structure vs Array

Structures and arrays are both used to group data, but they are different.

### Array

An array normally stores multiple values of the **same data type**.

```c
int marks[5];
```

### Structure

A structure can store members of **different data types**.

```c
struct Student {
    char name[50];
    int age;
    float marks;
};
```

| Array                            | Structure                      |
| -------------------------------- | ------------------------------ |
| Usually stores same type of data | Can store different data types |
| Accessed using index             | Accessed using member name     |
| Example: `marks[2]`              | Example: `student.marks`       |

## 16. 🌍 Real-World Example: Student Record

A college application may need to store a student's complete information.

A structure can group these details together:

```c
#include <stdio.h>

typedef struct {
    int rollNumber;
    char name[50];
    float marks;
} Student;

int main() {
    Student student = {101, "Owais", 91.5};

    printf("Student Record\n");
    printf("Roll Number = %d\n", student.rollNumber);
    printf("Name = %s\n", student.name);
    printf("Marks = %.2f\n", student.marks);

    return 0;
}
```

```output
Student Record
Roll Number = 101
Name = Owais
Marks = 91.50
```

Here, one `Student` variable stores all the information related to that student.

## ⚠️ Common Mistakes

### 1. Forgetting the semicolon after the structure

Correct:

```c
struct Student {
    int age;
};
```

The semicolon after `}` is required.

---

### 2. Forgetting `struct`

If you define:

```c
struct Student {
    int age;
};
```

you normally create a variable as:

```c
struct Student student;
```

unless you use `typedef`.

---

### 3. Using the wrong member name

If the structure contains:

```c
struct Student {
    int age;
};
```

use:

```c
student.age
```

not:

```c
student.year
```

---

### 4. Confusing `.` with `->`

For a normal structure variable, use:

```c
student.age
```

The `->` operator is used when working with a **pointer to a structure**, which will be covered later.

---

### 5. Confusing `typedef` with a new structure

`typedef` creates another name for an existing type.

For example:

```c
typedef int Number;
```

Now:

```c
Number x;
```

means the same type as:

```c
int x;
```

It does not create a completely new built-in data type.

---

## 🔑 Key Points

* A structure groups related variables together.
* Structure members can have different data types.
* A structure is declared using the `struct` keyword.
* Structure members are accessed using the `.` operator.
* Multiple variables can be created from the same structure type.
* A structure can be initialized when it is declared.
* `typedef` can create a shorter name for a structure type.
* Structures are useful for representing real-world records.
* Arrays usually store values of the same type, while structures can contain different types.
* Structure variables of the same type can be assigned to each other.
