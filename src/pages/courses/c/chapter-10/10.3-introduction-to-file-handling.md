# Chapter 10: Structures

## Section 3: Introduction to File Handling

So far, we have stored data in variables, arrays, and structures. But this data is usually lost when the program ends.

**File handling** allows a C program to store data permanently in a file and read it again later.

For example, a student management program can save student details in a file instead of losing them when the program closes.

---

## 1. What is File Handling?

**File handling** is the process of creating, opening, reading, writing, and closing files using a C program.

Files can be used to store:

* Student records
* Employee details
* Marks
* Product information
* Text data
* Program-generated reports

### Why Do We Need Files?

Consider this program:

```c
#include <stdio.h>

int main() {
    int marks = 95;

    printf("Marks = %d", marks);

    return 0;
}
```

```output
Marks = 95
```

The value `95` is stored in memory while the program is running.

When the program ends, the value is no longer available.

A file allows us to save the value permanently.

---

## 2. File Handling in C

C provides functions for working with files through the **`stdio.h`** header file.

Some important file functions are:

| Function    | Purpose                          |
| ----------- | -------------------------------- |
| `fopen()`   | Opens or creates a file          |
| `fprintf()` | Writes formatted data to a file  |
| `fscanf()`  | Reads formatted data from a file |
| `fgetc()`   | Reads one character              |
| `fputc()`   | Writes one character             |
| `fgets()`   | Reads a line/string              |
| `fputs()`   | Writes a string                  |
| `fclose()`  | Closes a file                    |

---

## 3. The `FILE` Pointer

C uses a special data type called **`FILE`** to work with files.

We normally create a file pointer like this:

```c
FILE *fp;
```

Here:

* `FILE` is a type provided by `stdio.h`
* `fp` is a file pointer
* `*` means `fp` is a pointer

The file pointer keeps track of the file being used by the program.

---

## 4. Opening a File with `fopen()`

The `fopen()` function is used to open a file.

### Syntax

```c
FILE *fp = fopen("filename", "mode");
```

Example:

```c
#include <stdio.h>

int main() {
    FILE *fp;

    fp = fopen("data.txt", "w");

    return 0;
}
```

Here:

* `"data.txt"` is the file name
* `"w"` is the file mode
* `fp` stores the file information

---

## 5. File Opening Modes

The second argument of `fopen()` specifies what we want to do with the file.

| Mode   | Meaning                        |
| ------ | ------------------------------ |
| `"r"`  | Open for reading               |
| `"w"`  | Open for writing               |
| `"a"`  | Open for appending             |
| `"r+"` | Open for reading and writing   |
| `"w+"` | Open for reading and writing   |
| `"a+"` | Open for reading and appending |

### `"w"` Mode

The `"w"` mode is used to write data into a file.

```c
FILE *fp = fopen("data.txt", "w");
```

If the file does not exist, it can be created.

If the file already contains data, opening it with `"w"` can replace the existing contents.

### `"r"` Mode

The `"r"` mode is used to read an existing file.

```c
FILE *fp = fopen("data.txt", "r");
```

The file must already exist for reading.

### `"a"` Mode

The `"a"` mode is used to add new data at the end of a file.

```c
FILE *fp = fopen("data.txt", "a");
```

Existing data is preserved, and new data is added at the end.

---

## 6. Checking Whether a File Opened Successfully

A file may fail to open.

For example, a file opened in `"r"` mode may not exist.

Therefore, it is good practice to check whether `fopen()` returned `NULL`.

```c
#include <stdio.h>

int main() {
    FILE *fp;

    fp = fopen("data.txt", "r");

    if (fp == NULL) {
        printf("File could not be opened.");
    } else {
        printf("File opened successfully.");
    }

    return 0;
}
```

```output
File could not be opened.
```

`NULL` means that the file could not be opened successfully.

---

## 7. Writing to a File

The `fprintf()` function can be used to write formatted data into a file.

### Syntax

```c
fprintf(file_pointer, "format", values);
```

Example:

```c
#include <stdio.h>

int main() {
    FILE *fp;

    fp = fopen("student.txt", "w");

    if (fp == NULL) {
        printf("File could not be opened.");
        return 1;
    }

    fprintf(fp, "Name: Owais\n");
    fprintf(fp, "Marks: 95\n");

    fclose(fp);

    printf("Data written successfully.");

    return 0;
}
```

```output
Data written successfully.
```

The file `student.txt` will contain:

```output
Name: Owais
Marks: 95
```

Notice that `fprintf()` uses the file pointer `fp` instead of `printf()`.

---

## 8. `printf()` vs `fprintf()`

Both functions can display formatted data, but their destination is different.

### `printf()`

```c
printf("Hello");
```

It normally displays the output on the screen.

### `fprintf()`

```c
fprintf(fp, "Hello");
```

It writes the output to the file represented by `fp`.

| Function    | Destination |
| ----------- | ----------- |
| `printf()`  | Screen      |
| `fprintf()` | File        |

---

## 9. Closing a File

After finishing work with a file, we should close it using `fclose()`.

### Syntax

```c
fclose(fp);
```

Example:

```c
#include <stdio.h>

int main() {
    FILE *fp;

    fp = fopen("data.txt", "w");

    if (fp == NULL) {
        printf("Unable to open file.");
        return 1;
    }

    fprintf(fp, "Hello, File!");

    fclose(fp);

    printf("File closed successfully.");

    return 0;
}
```

```output
File closed successfully.
```

Closing a file is important because it releases the resources associated with the file.

---

## 10. Reading from a File with `fscanf()`

The `fscanf()` function can be used to read formatted data from a file.

### Syntax

```c
fscanf(file_pointer, "format", &variables);
```

Example:

```c
#include <stdio.h>

int main() {
    FILE *fp;
    int marks;

    fp = fopen("marks.txt", "r");

    if (fp == NULL) {
        printf("File could not be opened.");
        return 1;
    }

    fscanf(fp, "%d", &marks);

    printf("Marks = %d", marks);

    fclose(fp);

    return 0;
}
```

If `marks.txt` contains:

```output
95
```

The output will be:

```output
Marks = 95
```

## 11. Writing and Reading a Student Record

We can combine structures and file handling.

```c
#include <stdio.h>

struct Student {
    char name[30];
    int marks;
};

int main() {
    struct Student s;

    FILE *fp = fopen("student.txt", "w");

    if (fp == NULL) {
        printf("File could not be opened.");
        return 1;
    }

    printf("Enter name: ");
    scanf("%29s", s.name);

    printf("Enter marks: ");
    scanf("%d", &s.marks);

    fprintf(fp, "%s %d\n", s.name, s.marks);

    fclose(fp);

    printf("Student data saved.");

    return 0;
}
```

Example output:

```output
Enter name: Owais
Enter marks: 95
Student data saved.
```

The file will contain:

```output
Owais 95
```

## 12. Reading a Character with `fgetc()`

The `fgetc()` function reads one character from a file.

### Syntax

```c
fgetc(file_pointer);
```

Example:

```c
#include <stdio.h>

int main() {
    FILE *fp;
    char ch;

    fp = fopen("data.txt", "r");

    if (fp == NULL) {
        printf("File could not be opened.");
        return 1;
    }

    ch = fgetc(fp);

    printf("First character: %c", ch);

    fclose(fp);

    return 0;
}
```

If the file contains:

```output
Hello
```

The output will be:

```output
First character: H
```

---

## 13. Writing a Character with `fputc()`

The `fputc()` function writes one character to a file.

### Syntax

```c
fputc(character, file_pointer);
```

Example:

```c
#include <stdio.h>

int main() {
    FILE *fp;

    fp = fopen("data.txt", "w");

    if (fp == NULL) {
        printf("File could not be opened.");
        return 1;
    }

    fputc('H', fp);
    fputc('i', fp);

    fclose(fp);

    printf("Characters written.");

    return 0;
}
```

```output
Characters written.
```

The file will contain:

```output
Hi
```

---

## 14. Reading a String with `fgets()`

The `fgets()` function can read a line of text from a file.

### Syntax

```c
fgets(string, size, file_pointer);
```

Example:

```c
#include <stdio.h>

int main() {
    FILE *fp;
    char text[100];

    fp = fopen("data.txt", "r");

    if (fp == NULL) {
        printf("File could not be opened.");
        return 1;
    }

    fgets(text, sizeof(text), fp);

    printf("Text: %s", text);

    fclose(fp);

    return 0;
}
```

If the file contains:

```output
Hello Codify
```

The output will be:

```output
Text: Hello Codify
```

---

## 15. Writing a String with `fputs()`

The `fputs()` function writes a string into a file.

### Syntax

```c
fputs(string, file_pointer);
```

Example:

```c
#include <stdio.h>

int main() {
    FILE *fp;

    fp = fopen("data.txt", "w");

    if (fp == NULL) {
        printf("File could not be opened.");
        return 1;
    }

    fputs("Welcome to Codify!\n", fp);
    fputs("Learn C Programming.", fp);

    fclose(fp);

    printf("Text written successfully.");

    return 0;
}
```

```output
Text written successfully.
```

The file will contain:

```output
Welcome to Codify!
Learn C Programming.
```

## 16. Basic File Handling Process

Most file-handling programs follow these steps:

```text
Open File
   ↓
Check File
   ↓
Read / Write Data
   ↓
Close File
```

For example:

```c
FILE *fp;

fp = fopen("data.txt", "w");

if (fp == NULL) {
    return 1;
}

fprintf(fp, "Hello");

fclose(fp);
```

This simple pattern is important to remember.

Without file handling:

```text

        ↓

        ↓

        ↓
```

## ⚠️ Common Mistakes

### Mistake 1: Not checking `fopen()`

Incorrect:

```c
FILE *fp = fopen("data.txt", "r");

fprintf(fp, "Hello");
```

If the file could not be opened, `fp` may be `NULL`.

Better:

```c
FILE *fp = fopen("data.txt", "r");

if (fp == NULL) {
    printf("File could not be opened.");
    return 1;
}
```

---

### Mistake 2: Forgetting to close the file

Always close the file after completing the operation.

```c
fclose(fp);
```

---

### Mistake 3: Using the wrong mode

For example, `"w"` can replace existing file contents.

If you want to add data to the end, use:

```c
fopen("data.txt", "a");
```

---

### Mistake 4: Forgetting `&` with `fscanf()`

For normal variables, `fscanf()` needs their address.

Incorrect:

```c
fscanf(fp, "%d", marks);
```

Correct:

```c
fscanf(fp, "%d", &marks);
```

* `fputc()` writes one character.
