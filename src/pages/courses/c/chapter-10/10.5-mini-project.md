## 1. Mini Project: Student Record Management System

### Project Goal

Create a C program that stores student information and saves it into a file.

Each student will have:

* Roll number
* Name
* Marks

The program will:

1. Take student details as input.
2. Store the details in a structure.
3. Display the student details.
4. Save the details into a file.

---

## 2. Step 1: Create the Structure

First, create a structure for a student.

```c
#include <stdio.h>

struct Student {
    int rollNo;
    char name[30];
    float marks;
};
```

The structure contains three members:

| Member   | Data Type  | Purpose             |
| -------- | ---------- | ------------------- |
| `rollNo` | `int`      | Student roll number |
| `name`   | `char[30]` | Student name        |
| `marks`  | `float`    | Student marks       |

---

## 3. Step 2: Create a Student Variable

Create a variable using the structure.

```c
struct Student student;
```

Now we can access its members using the dot `.` operator.

```c
student.rollNo = 101;
student.marks = 95.5;
```

---

## 4. Step 3: Take Student Input

We can use `scanf()` to read the student details.

```c
printf("Enter roll number: ");
scanf("%d", &student.rollNo);

printf("Enter name: ");
scanf("%29s", student.name);

printf("Enter marks: ");
scanf("%f", &student.marks);
```

For the character array `name`, we do not use `&` with the array name.

---

## 5. Step 4: Display the Student Details

After taking the input, display the information.

```c
printf("\nStudent Details\n");
printf("Roll Number: %d\n", student.rollNo);
printf("Name: %s\n", student.name);
printf("Marks: %.2f\n", student.marks);
```

---

## 6. Step 5: Save the Details to a File

Now combine the structure with file handling.

```c
FILE *fp;

fp = fopen("students.txt", "w");

if (fp == NULL) {
    printf("File could not be opened.");
    return 1;
}

fprintf(fp, "%d %s %.2f\n",
        student.rollNo,
        student.name,
        student.marks);

fclose(fp);
```

The student information is now stored in `students.txt`.

## 7. Complete Mini Project

Here is the complete program:

```c
#include <stdio.h>

struct Student {
    int rollNo;
    char name[30];
    float marks;
};

int main() {
    struct Student student;
    FILE *fp;

    printf("Enter roll number: ");
    scanf("%d", &student.rollNo);

    printf("Enter name: ");
    scanf("%29s", student.name);

    printf("Enter marks: ");
    scanf("%f", &student.marks);

    printf("\nStudent Details\n");
    printf("Roll Number: %d\n", student.rollNo);
    printf("Name: %s\n", student.name);
    printf("Marks: %.2f\n", student.marks);

    fp = fopen("students.txt", "w");

    if (fp == NULL) {
        printf("File could not be opened.");
        return 1;
    }

    fprintf(fp, "%d %s %.2f\n",
            student.rollNo,
            student.name,
            student.marks);

    fclose(fp);

    printf("\nStudent data saved successfully.");

    return 0;
}
```

Example:

```output
Enter roll number: 101
Enter name: Owais
Enter marks: 95.5

Student Details
Roll Number: 101
Name: Owais
Marks: 95.50

Student data saved successfully.
```

The file `students.txt` will contain:

```output
101 Owais 95.50
```

## 13. Chapter 10 Revision

Let's quickly review the main concepts from this chapter.

### Structures

A structure groups related variables of different data types.

```c
struct Student {
    int rollNo;
    char name[30];
};
```

### `typedef`

`typedef` can give a simpler name to a type.

```c
typedef struct {
    int rollNo;
    char name[30];
} Student;
```

### Array of Structures

Multiple structure objects can be stored in an array.

```c
Student students[50];
```

### Structure Pointer

A pointer can point to a structure.

```c
Student *ptr;
```

Members can be accessed using:

```c
ptr->rollNo
```

### File Handling

Files allow data to be stored beyond the lifetime of a program.

Important functions include:

```c
fopen()
fprintf()
fscanf()
fgetc()
fputc()
fgets()
fputs()
fclose()
```

### Debugging

Debugging means finding and fixing errors in a program.

## 🔑 Chapter 10 Key Points

* Structures group related data.
* `.` accesses members through a normal structure variable.
* `->` accesses members through a structure pointer.
* `typedef` can create a simpler type name.
* Arrays of structures can store multiple records.
* Structure pointers can be used to work with structure objects.
* File handling allows data to be stored in files.
* `fopen()` opens a file.
* `fprintf()` writes formatted data.
* `fscanf()` reads formatted data.
* `fclose()` closes a file.
* Problem solving starts with understanding the requirements.
* Algorithms help plan a solution.
* Test cases help verify programs.
* Debugging helps find and fix errors.
* Breaking large problems into smaller steps makes them easier to solve.
