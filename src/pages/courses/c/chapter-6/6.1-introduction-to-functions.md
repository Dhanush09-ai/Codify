# Chapter 6: Functions

## Section 1: Introduction to Functions

A **function** is a block of code designed to perform a specific task.

Functions help us divide a large program into smaller and manageable parts.

For example, instead of writing the same code multiple times, we can place that code inside a function and call the function whenever we need it.

### 1. Why Do We Need Functions?

Consider a program that needs to print a message several times.

Without functions, we may have to repeat the same code:

```c id="p4k8mz"
#include <stdio.h>

int main() {
    printf("Welcome to Codify!\n");
    printf("Welcome to Codify!\n");
    printf("Welcome to Codify!\n");

    return 0;
}
```

Instead, we can create a function:

```c id="w7q3nc"
#include <stdio.h>

void welcome() {
    printf("Welcome to Codify!\n");
}

int main() {
    welcome();
    welcome();
    welcome();

    return 0;
}
```

```output id="t5m9vx"
Welcome to Codify!
Welcome to Codify!
Welcome to Codify!
```

The function `welcome()` contains the code for printing the message.

### 2. Basic Structure of a Function

A simple function looks like this:

```c id="r2n6ka"
return_type function_name() {
    // code
}
```

For example:

```c id="h8c4wp"
void greet() {
    printf("Hello!");
}
```

Here:

* `void` → return type
* `greet` → function name
* `()` → function parameter list
* `{ }` → function body

The statements inside `{ }` are executed when the function is called.

### 3. Creating a Simple Function

Let's create a function that prints a message.

```c id="m6v3qy"
#include <stdio.h>

void greet() {
    printf("Hello, Student!");
}

int main() {
    greet();

    return 0;
}
```

```output id="x9p5sd"
Hello, Student!
```

The function is created using:

```c id="q7w2je"
void greet() {
    printf("Hello, Student!");
}
```

Then it is called using:

```c id="c3n8rf"
greet();
```

### 4. Calling a Function

**Calling a function** means asking the program to execute the code inside that function.

For example:

```c id="v5k9ma"
#include <stdio.h>

void message() {
    printf("Learning C is easy with practice!\n");
}

int main() {
    message();

    return 0;
}
```

```output id="b8r4tx"
Learning C is easy with practice!
```

The function `message()` is called from `main()`.

### 5. Calling a Function Multiple Times

A function can be called more than once.

```c id="j6p2we"
#include <stdio.h>

void printNumber() {
    printf("10\n");
}

int main() {
    printNumber();
    printNumber();
    printNumber();

    return 0;
}
```

```output id="n4s7kc"
10
10
10
```

The same function is reused three times.

### 6. Functions Reduce Repetition

Suppose we need to print a line many times.

Instead of repeating the `printf()` statement:

```c id="a8m3qy"
printf("----------------\n");
printf("----------------\n");
printf("----------------\n");
```

We can create a function:

```c id="f2v7nx"
#include <stdio.h>

void printLine() {
    printf("----------------\n");
}

int main() {
    printLine();
    printLine();
    printLine();

    return 0;
}
```

```output id="s5k9wp"
----------------
----------------
----------------
```

This makes the program easier to organize and reuse.

### 7. Functions and `main()`

The `main()` function is a special function in C.

Program execution starts from `main()`.

We can create our own functions and call them from `main()`.

For example:

```c id="d7q4mb"
#include <stdio.h>

void startProgram() {
    printf("Program started.\n");
}

int main() {
    startProgram();

    return 0;
}
```

```output id="e9w2ka"
Program started.
```

Here, execution starts from `main()`, and `main()` calls `startProgram()`.

### 8. Benefits of Functions

Functions provide several benefits:

| Benefit         | Description                                        |
| --------------- | -------------------------------------------------- |
| Reusability     | The same function can be called multiple times     |
| Readability     | Programs become easier to understand               |
| Organization    | Large programs can be divided into smaller tasks   |
| Maintenance     | Changes can be made in one place                   |
| Less repetition | Common code does not need to be written repeatedly |

### 9. Real-World Example 🌍

Think about a calculator application.

A calculator may have separate tasks such as:

* Addition
* Subtraction
* Multiplication
* Division

Each task can be placed inside its own function.

For example:

```c id="k3x8vf"
#include <stdio.h>

void add() {
    int a = 10;
    int b = 5;

    printf("Sum = %d", a + b);
}

int main() {
    add();

    return 0;
}
```

```output id="u6m2pc"
Sum = 15
```

As the program becomes larger, separate functions can make each task easier to manage.

## Common Mistakes

### Mistake 1: Creating a Function but Not Calling It

This function is created:

```c id="y4n7qs"
void greet() {
    printf("Hello!");
}
```

But if we never write:

```c id="r8c5ka"
greet();
```

the function will not execute.

### Mistake 2: Forgetting the Parentheses

A function call needs parentheses.

Correct:

```c id="p6w3me"
greet();
```

### Mistake 3: Forgetting the Return Type

A function definition needs a return type.

For a function that does not return a value, we can use:

```c id="z2v9ht"
void greet() {
    printf("Hello!");
}
```

### Mistake 4: Confusing Function Definition and Function Call

A function definition creates the function:

```c id="s7k4nb"
void greet() {
    printf("Hello!");
}
```

A function call executes it:

```c id="c5m8rx"
greet();
```

## Key Points

* A function is a block of code designed to perform a specific task.
* Functions help divide large programs into smaller parts.
* A function can be called multiple times.
* Functions reduce repeated code.
* `main()` is the starting point of a C program.
* Functions can be called from `main()`.
* A function has a return type, name, parameter list, and body.
* `void` is used when a function does not return a value.
* Creating a function and calling a function are different operations.
