# Chapter 6: Functions

## Section 2: Function Declaration, Definition & Calling

In C, a function is commonly handled in three steps:

1. **Function Declaration**
2. **Function Definition**
3. **Function Calling**

Understanding these three steps is important for writing and organizing C programs.

### 1. Function Declaration

A **function declaration** tells the compiler about a function before the function is used.

It tells the compiler:

* The function name
* The return type
* The parameters, if any

The basic syntax is:

```c id="d4m7qa"
return_type function_name(parameters);
```

For example:

```c id="p8x3nc"
int add(int a, int b);
```

This tells the compiler that there is a function named `add` that:

* Returns an `int`
* Accepts two `int` parameters

The declaration is also called a **function prototype**.

### 2. Function Definition

A **function definition** contains the actual code that the function executes.

For example:

```c id="k5w9rt"
int add(int a, int b) {
    return a + b;
}
```

Here:

* `int` → return type
* `add` → function name
* `int a, int b` → parameters
* `return a + b;` → function body

The definition tells the compiler what the function actually does.

### 3. Function Calling

A **function call** is used to execute a function.

For example:

```c id="v2n6sm"
int result = add(10, 20);
```

Here, `add(10, 20)` calls the function and passes `10` and `20` to it.

### 4. Complete Example

Let's combine declaration, definition, and calling.

```c id="q7c4yp"
#include <stdio.h>

int add(int a, int b);  // Declaration

int add(int a, int b) { // Definition
    return a + b;
}

int main() {
    int result = add(10, 20); // Calling

    printf("Sum = %d", result);

    return 0;
}
```

```output id="m8r5ka"
Sum = 30
```

The program works in this order:

1. The compiler sees the declaration.
2. The function definition provides the actual code.
3. `main()` calls the function.
4. The function calculates the result.
5. The returned value is stored in `result`.

### 5. Why Do We Need a Function Declaration?

A declaration is especially useful when the function definition is written **after `main()`**.

For example:

```c id="f3w8nd"
#include <stdio.h>

int add(int a, int b);

int main() {
    printf("%d", add(5, 3));

    return 0;
}

int add(int a, int b) {
    return a + b;
}
```

```output id="t6p2vx"
8
```

The declaration tells the compiler about `add()` before `main()` calls it.

### 6. Function Definition Before main()

If the function is defined before `main()`, a separate declaration is usually not needed.

```c id="r9k4mc"
#include <stdio.h>

int add(int a, int b) {
    return a + b;
}

int main() {
    printf("%d", add(5, 3));

    return 0;
}
```

```output id="z5q7wb"
8
```

Here, the compiler sees the complete function definition before `main()` uses it.

### 7. Declaration vs Definition vs Calling

| Term        | Purpose                               | Example                         |
| ----------- | ------------------------------------- | ------------------------------- |
| Declaration | Tells the compiler about the function | `int add(int, int);`            |
| Definition  | Contains the function's actual code   | `int add(int a, int b) { ... }` |
| Calling     | Executes the function                 | `add(5, 3);`                    |

### 8. Function Declaration with No Parameters

A function that does not take parameters can be declared as:

```c id="n2v6qs"
void greet(void);
```

Its definition can be:

```c id="w4m8ka"
void greet(void) {
    printf("Hello!");
}
```

And it can be called using:

```c id="c7p3rx"
greet();
```

### 9. Real-World Example 🌍

Imagine a calculator program with a function for addition.

The program can first declare the function, define its calculation, and then call it when needed.

```c id="h6s9vd"
#include <stdio.h>

int calculateTotal(int price, int quantity);

int calculateTotal(int price, int quantity) {
    return price * quantity;
}

int main() {
    int total = calculateTotal(50, 3);

    printf("Total = %d", total);

    return 0;
}
```

```output id="j3k8mf"
Total = 150
```

The declaration tells the compiler about `calculateTotal()`, the definition performs the calculation, and the call executes the function.

## Common Mistakes

### Mistake 1: Forgetting the Semicolon in a Declaration

Correct:

```c id="a8q5mz"
int add(int a, int b);
```

The declaration ends with a semicolon.

### Mistake 2: Putting a Semicolon After a Function Definition

A function definition normally does not end with a semicolon after the closing brace.

Correct:

```c id="x4n7cp"
int add(int a, int b) {
    return a + b;
}
```

### Mistake 3: Calling a Function with the Wrong Number of Arguments

If the function expects two parameters:

```c id="s6w2ka"
int add(int a, int b);
```

it should be called with two suitable arguments:

```c id="m9r4vx"
add(10, 20);
```

### Mistake 4: Confusing Declaration with Definition

Remember:

```c id="q2p8nd"
int add(int a, int b);
```

is a **declaration**.

While:

```c id="v5k3wr"
int add(int a, int b) {
    return a + b;
}
```

is a **definition**.

And:

```c id="b7m6qa"
add(10, 20);
```

is a **function call**.

## Key Points

* A function declaration tells the compiler about a function.
* A function definition contains the actual function code.
* A function call executes the function.
* A function declaration is also called a function prototype.
* A declaration ends with a semicolon.
* A separate declaration is useful when the function is defined after `main()`.
* If the function definition appears before `main()`, a separate declaration is usually not needed.
* The function declaration and definition should have compatible return types and parameters.
