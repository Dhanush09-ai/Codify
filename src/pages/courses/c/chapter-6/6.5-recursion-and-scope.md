# Chapter 6: Functions

## Section 5: Recursion & Scope of Variables

Two important concepts related to functions are **recursion** and **scope of variables**.

* **Recursion** means a function calls itself.
* **Scope** tells us where a variable can be accessed in a program.

---

## 1. What is Recursion?

**Recursion** is a process in which a function calls itself to solve a problem.

A recursive function must have a **base condition** to stop the repeated function calls.

### Basic Structure

```c id="recbasic"
return_type function_name()
{
    if (condition)
    {
        return;
    }

    function_name();
}
```

The function keeps calling itself until the stopping condition is reached.

---

## 2. Simple Recursion Example

The following program prints numbers from `1` to `5` using recursion.

```c id="recprint"
#include <stdio.h>

void printNumbers(int number)
{
    if (number > 5)
    {
        return;
    }

    printf("%d ", number);

    printNumbers(number + 1);
}

int main()
{
    printNumbers(1);

    return 0;
}
```


```output id="recprintout"
1 2 3 4 5
```

### How It Works

```text
printNumbers(1)
      ↓
printNumbers(2)
      ↓
printNumbers(3)
      ↓
printNumbers(4)
      ↓
printNumbers(5)
      ↓
printNumbers(6)
      ↓
Stop
```

When `number` becomes `6`, the condition:

```c id="reccondition"
if (number > 5)
{
    return;
}
```

stops the recursion.

---

## 3. Base Condition

The **base condition** is the condition that stops a recursive function.

Without a proper stopping condition, the function can keep calling itself.

Example:

```c id="recbase"
if (number > 5)
{
    return;
}
```

When the condition becomes true, the function stops making further recursive calls.

### Remember

```text
Recursive Call → Function calls itself
Base Condition → Stops the recursion
```

---

## 4. Recursion Example: Factorial

Recursion can be used to calculate the factorial of a number.

For example:

```text
5! = 5 × 4 × 3 × 2 × 1
   = 120
```

### C Program

```c id="recfact"
#include <stdio.h>

int factorial(int n)
{
    if (n == 1)
    {
        return 1;
    }

    return n * factorial(n - 1);
}

int main()
{
    int result = factorial(5);

    printf("Factorial = %d", result);

    return 0;
}
```


```output id="recfactout"
Factorial = 120
```

The function calls itself with a smaller value each time.

```text
factorial(5)
    ↓
5 × factorial(4)
    ↓
4 × factorial(3)
    ↓
3 × factorial(2)
    ↓
2 × factorial(1)
    ↓
1
```

## 5. What is Scope of a Variable?

The **scope of a variable** means the part of the program where that variable can be accessed.

A variable is not always available throughout the entire program.

For example, a variable declared inside a function can normally be used only inside that function.

---

## 6. Local Variables

A variable declared inside a function or block is called a **local variable**.

It can be accessed only within its scope.

### Example

```c id="localscope"
#include <stdio.h>

void display()
{
    int number = 10;

    printf("Number = %d", number);
}

int main()
{
    display();

    return 0;
}
```


```output id="localscopeout"
Number = 10
```

Here, `number` is a local variable of the `display()` function.

It is available inside `display()`.

---

## 7. Variables in Different Functions

Different functions can have variables with the same name.

These variables are separate from each other.

```c id="localsame"
#include <stdio.h>

void first()
{
    int number = 10;

    printf("First = %d\n", number);
}

void second()
{
    int number = 20;

    printf("Second = %d", number);
}

int main()
{
    first();
    second();

    return 0;
}
```


```output id="localsameout"
First = 10
Second = 20
```

The `number` in `first()` and the `number` in `second()` are separate local variables.

---

## 8. Block Scope

A variable declared inside a block `{ }` can be accessed within that block.

Example:

```c id="blockscope"
#include <stdio.h>

int main()
{
    if (1)
    {
        int number = 50;

        printf("Number = %d", number);
    }

    return 0;
}
```


```output id="blockscopeout"
Number = 50
```

The variable `number` belongs to the block inside the `if` statement.

---

## 9. Local and Global Variables

A variable declared outside all functions is called a **global variable**.

A variable declared inside a function is called a **local variable**.

| Local Variable                      | Global Variable                                     |
| ----------------------------------- | --------------------------------------------------- |
| Declared inside a function or block | Declared outside functions                          |
| Available within its scope          | Can be accessed by functions according to its scope |
| Used for local tasks                | Can be used for shared data                         |

### Example

```c id="localglobal"
#include <stdio.h>

int globalNumber = 100;

void display()
{
    int localNumber = 50;

    printf("Global = %d\n", globalNumber);
    printf("Local = %d", localNumber);
}

int main()
{
    display();

    return 0;
}
```


```output id="localglobalout"
Global = 100
Local = 50
```

Here:

* `globalNumber` is declared outside the functions.
* `localNumber` is declared inside `display()`.

---

## 10. Recursion and Scope Together

Each function call in recursion has its own local variables.

For example:

```c id="recscope"
#include <stdio.h>

void count(int n)
{
    if (n == 0)
    {
        return;
    }

    printf("%d ", n);

    count(n - 1);
}

int main()
{
    count(3);

    return 0;
}
```


```output id="recscopeout"
3 2 1
```

Each recursive call works with its own function call and local data.

## Real-World Example 🌍

Think about a set of instructions that repeatedly performs the same task until a condition is reached.

For example, a system may process items one by one:

```text
Process item
    ↓
Are more items available?
    ↓
   Yes
    ↓
Process next item
    ↓
   ...
    ↓
   No
    ↓
   Stop
```

This idea is similar to recursion: the same function is called again until a stopping condition is reached.

Scope is useful because variables used for one task can be kept within the part of the program where they are needed.

---

## Common Mistakes

### Mistake 1: Forgetting the Base Condition

A recursive function needs a condition that stops the recursive calls.

Always make sure the recursive function can reach its stopping condition.

---

### Mistake 2: Calling a Local Variable Outside Its Scope

Incorrect:

```c id="wrongscope"
void display()
{
    int number = 10;
}

int main()
{
    printf("%d", number);
}
```

`number` is declared inside `display()`, so it cannot be accessed directly from `main()`.

---

### Mistake 3: Confusing Local and Global Variables

Remember:

```text
Inside function/block → Local variable

Outside functions → Global variable
```

---

## Key Points

* **Recursion** means a function calls itself.
* A recursive function needs a **base condition** to stop.
* Recursion can be useful for problems that can be broken into smaller similar problems.
* **Scope** defines where a variable can be accessed.
* A local variable is declared inside a function or block.
* A global variable is declared outside functions.
* Variables with the same name in different functions can be separate local variables.
* Always make sure recursive calls eventually reach their stopping condition.
