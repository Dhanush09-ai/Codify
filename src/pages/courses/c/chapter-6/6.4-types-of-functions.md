# Chapter 6: Functions

## Section 4: Types of Functions

In C, functions can be classified based on whether they **take parameters** and whether they **return a value**.

There are four common types of functions:

1. No parameters and no return value
2. Parameters and no return value
3. No parameters but return a value
4. Parameters and return a value

Understanding these four types makes it easier to decide how a function should be written.

---

## 1. No Parameters and No Return Value

This type of function:

* Does not receive any value.
* Does not return any value.
* Usually performs a simple task.

The return type is commonly `void`.

### Example

```c id="nprnv1"
#include <stdio.h>

void greet()
{
    printf("Hello, Welcome to Codify!");
}

int main()
{
    greet();

    return 0;
}
```


```output id="nprno1"
Hello, Welcome to Codify!
```

Here:

* `greet()` has no parameters.
* `greet()` does not return a value.
* `void` means the function does not return a value.

---

## 2. Parameters but No Return Value

This type of function:

* Receives values through parameters.
* Does not return a value.
* Usually performs an operation and directly displays the result.

### Example

```c id="pnrv01"
#include <stdio.h>

void displaySum(int a, int b)
{
    printf("Sum = %d", a + b);
}

int main()
{
    displaySum(10, 20);

    return 0;
}
```


```output id="pnro01"
Sum = 30
```

Here:

* `a` and `b` are parameters.
* `10` and `20` are passed to the function.
* The function prints the result.
* The function does not return a value.

---

## 3. No Parameters but Return Value

This type of function:

* Does not receive any parameters.
* Returns a value to the calling code.

### Example

```c id="nprv01"
#include <stdio.h>

int getNumber()
{
    return 50;
}

int main()
{
    int number = getNumber();

    printf("Number = %d", number);

    return 0;
}
```


```output id="npro01"
Number = 50
```

Here:

* `getNumber()` has no parameters.
* The function returns `50`.
* The returned value is stored in `number`.

---

## 4. Parameters and Return Value

This type of function:

* Receives one or more parameters.
* Performs an operation.
* Returns a value.

This is a very common type of function.

### Example

```c id="prv01a"
#include <stdio.h>

int add(int a, int b)
{
    return a + b;
}

int main()
{
    int result = add(15, 25);

    printf("Sum = %d", result);

    return 0;
}
```


```output id="prvo01"
Sum = 40
```

Here:

* `a` and `b` are parameters.
* `15` and `25` are passed to the function.
* The function calculates the sum.
* `return` sends the result back to `main()`.

---

## 5. Comparison of the Four Types

| Type   | Parameters | Return Value | Example                  |
| ------ | ---------- | ------------ | ------------------------ |
| Type 1 | No         | No           | `void greet()`           |
| Type 2 | Yes        | No           | `void add(int a, int b)` |
| Type 3 | No         | Yes          | `int getNumber()`        |
| Type 4 | Yes        | Yes          | `int add(int a, int b)`  |

## 7. Real-World Example 🌍

Consider a simple billing program.

A function can receive the price and quantity and return the total amount.

```c id="bill01"
#include <stdio.h>

float calculateTotal(float price, int quantity)
{
    return price * quantity;
}

int main()
{
    float total;

    total = calculateTotal(100.0, 3);

    printf("Total = %.2f", total);

    return 0;
}
```


```output id="billo1"
Total = 300.00
```

This is an example of:

**Parameters + Return Value**

because:

* `price` and `quantity` are parameters.
* The calculated total is returned.

## Common Mistakes

### Mistake 1: Forgetting `void`

If a function does not return a value, `void` can be used as its return type.

```c id="mist1"
void greet()
{
    printf("Hello");
}
```

---

### Mistake 2: Returning a value from a `void` function

A `void` function should not be used to return a normal value.

Incorrect:

```c id="mist2"
void add(int a, int b)
{
    return a + b;
}
```

If the function needs to return the sum, use `int`:

```c id="mist3"
int add(int a, int b)
{
    return a + b;
}
```

---

### Mistake 3: Confusing parameters and return values

Remember:

```text
Parameters → Data goes into the function

Return Value → Result comes out of the function
```

---

## Key Points

* C functions can be grouped into four common types.
* A function may have parameters or may have no parameters.
* A function may return a value or may return no value.
* `void` is commonly used when a function does not return a value.
* The most flexible type uses both parameters and a return value.
* Parameters send data into a function.
* Return values send results back from a function.
