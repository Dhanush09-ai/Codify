# Chapter 6: Functions

## Section 3: Parameters & Return Values

Functions become more useful when we can **send data to them** and **get a result back**.

* **Parameters** allow us to send values into a function.
* **Return values** allow a function to send a result back to the calling code.

---

## 1. What are Parameters?

A **parameter** is a variable used in a function to receive a value.

### Syntax

```c
return_type function_name(data_type parameter1, data_type parameter2)
{
    // function body
}
```

Example:

```c
#include <stdio.h>

void greet(char name[])
{
    printf("Hello, %s!", name);
}

int main()
{
    greet("Owais");

    return 0;
}
```


```output
Hello, Owais!
```

Here:

* `name` is the **parameter**.
* `"Owais"` is the value passed to the function.

---

## 2. Function with One Parameter

A function can have one parameter.

```c
#include <stdio.h>

void square(int number)
{
    printf("Square = %d", number * number);
}

int main()
{
    square(5);

    return 0;
}
```


```output
Square = 25
```

The value `5` is passed to the parameter `number`.

---

## 3. Function with Multiple Parameters

A function can also accept multiple parameters.

```c
#include <stdio.h>

void add(int a, int b)
{
    printf("Sum = %d", a + b);
}

int main()
{
    add(10, 20);

    return 0;
}
```


```output
Sum = 30
```

Here:

* `a` receives `10`
* `b` receives `20`

The function then adds both values.

---

## 4. What is a Return Value?

A **return value** is the result sent back from a function to the place where the function was called.

For example:

```c
#include <stdio.h>

int add(int a, int b)
{
    return a + b;
}

int main()
{
    int result = add(10, 20);

    printf("Sum = %d", result);

    return 0;
}
```


```output
Sum = 30
```

The function:

```c
return a + b;
```

sends the value `30` back to `main()`.

The returned value is stored in:

```c
int result
```

---

## 5. Return Type

The **return type** tells us what type of value a function returns.

Examples:

| Return Type | Returned Value |
| ----------- | -------------- |
| `int`       | Integer        |
| `float`     | Decimal value  |
| `char`      | Character      |
| `void`      | No value       |

Example using `int`:

```c
int multiply(int a, int b)
{
    return a * b;
}
```

The function returns an integer, so its return type is `int`.

---

## 6. Function with Parameters and Return Value

A function can have both **parameters** and a **return value**.

```c
#include <stdio.h>

int multiply(int a, int b)
{
    return a * b;
}

int main()
{
    int result;

    result = multiply(6, 4);

    printf("Product = %d", result);

    return 0;
}
```


```output
Product = 24
```

The flow is:

```text
6, 4
  ↓
multiply()
  ↓
6 × 4
  ↓
24
  ↓
result
```

---

## 7. Using the Return Value Directly

We do not always need to store the returned value in a variable.

We can use it directly.

```c
#include <stdio.h>

int square(int number)
{
    return number * number;
}

int main()
{
    printf("Square = %d", square(7));

    return 0;
}
```


```output
Square = 49
```

Here, the returned value is directly used inside `printf()`.

---

## 8. Parameters vs Return Values

Parameters and return values work in opposite directions.

```text
Calling Code
     |
     |  Parameters
     ↓
   Function
     |
     |  Return Value
     ↓
Calling Code
```

| Parameters                       | Return Value                 |
| -------------------------------- | ---------------------------- |
| Send data to a function          | Sends a result back          |
| Written inside function brackets | Written using `return`       |
| Can have multiple parameters     | A function returns one value |
| Example: `add(10, 20)`           | Example: `return a + b;`     |

---

## 9. Real-World Example 🌍

Imagine a calculator application.

We can create a function that calculates the total price.

```c
#include <stdio.h>

float calculateTotal(float price, int quantity)
{
    return price * quantity;
}

int main()
{
    float total;

    total = calculateTotal(50.5, 3);

    printf("Total = %.2f", total);

    return 0;
}
```


```output
Total = 151.50
```

Here:

* `price` and `quantity` are parameters.
* The function calculates the total.
* `return` sends the result back.
* `total` stores the returned value.

## 10. Common Mistakes

### Mistake 1: Forgetting the return statement

Incorrect:

```c
int add(int a, int b)
{
    a + b;
}
```

Correct:

```c
int add(int a, int b)
{
    return a + b;
}
```

---

### Mistake 2: Using the wrong return type

Incorrect:

```c
int getNumber()
{
    return 5.5;
}
```

If the function is meant to return a decimal value, use a suitable return type such as `float`.

```c
float getNumber()
{
    return 5.5;
}
```

---

### Mistake 3: Passing the wrong number of arguments

If a function has two parameters:

```c
int add(int a, int b)
```

it should normally be called with two values:

```c
add(10, 20);
```

---

## Key Points

* A **parameter** receives data inside a function.
* A function can have one or multiple parameters.
* A **return value** sends a result back from a function.
* The return type tells what type of value the function returns.
* The `return` statement is used to send a value back.
* A function can have both parameters and a return value.
* Returned values can be stored in variables or used directly.
