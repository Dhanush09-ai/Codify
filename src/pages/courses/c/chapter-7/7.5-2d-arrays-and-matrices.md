# Chapter 7: Arrays

## Section 5: Two-Dimensional Arrays & Matrices

A **two-dimensional array (2D array)** is an array that stores data in **rows and columns**.

It is useful for representing tables, grids, and matrices.

For example:

```text
10 20 30
40 50 60
70 80 90
```

This array has:

* 3 rows
* 3 columns
* 9 elements

---

## 1. What is a Two-Dimensional Array?

A 2D array can be thought of as a table.

For example:

```text
       Column
       0   1   2
     +---+---+---+
Row 0|10 |20 |30 |
     +---+---+---+
Row 1|40 |50 |60 |
     +---+---+---+
Row 2|70 |80 |90 |
     +---+---+---+
```

In C, a 2D array is declared using two sizes:

```c
int numbers[3][3];
```

Here:

* `3` represents the number of rows.
* The second `3` represents the number of columns.

---

## 2. Declaring a 2D Array

The general syntax is:

```c
data_type array_name[rows][columns];
```

For example:

```c
int matrix[2][3];
```

This creates a matrix with:

* 2 rows
* 3 columns
* 6 elements

The indexes start from `0`.

For a `2 x 3` array:

```text
matrix[0][0]  matrix[0][1]  matrix[0][2]
matrix[1][0]  matrix[1][1]  matrix[1][2]
```

---

## 3. Initializing a 2D Array

We can initialize a 2D array when declaring it.

### Example

```c
#include <stdio.h>

int main() {
    int matrix[2][3] = {
        {10, 20, 30},
        {40, 50, 60}
    };

    printf("%d\n", matrix[0][0]);
    printf("%d\n", matrix[1][2]);

    return 0;
}
```


```output
10
60
```

`matrix[0][0]` contains `10`.

`matrix[1][2]` contains `60`.

---

## 4. Accessing Elements

Each element is accessed using:

```c
array[row][column]
```

For example:

```c
matrix[1][2]
```

means:

* Row = `1`
* Column = `2`

Consider:

```text
10 20 30
40 50 60
```

The indexes are:

```text
[0][0] = 10    [0][1] = 20    [0][2] = 30
[1][0] = 40    [1][1] = 50    [1][2] = 60
```

### Example

```c
#include <stdio.h>

int main() {
    int matrix[2][3] = {
        {10, 20, 30},
        {40, 50, 60}
    };

    printf("Element = %d", matrix[1][1]);

    return 0;
}
```


```output
Element = 50
```

---

## 5. Taking Input into a 2D Array

We can use nested loops to read values into a 2D array.

### Example

```c
#include <stdio.h>

int main() {
    int matrix[2][3];

    printf("Enter 6 numbers:\n");

    for (int i = 0; i < 2; i++) {
        for (int j = 0; j < 3; j++) {
            scanf("%d", &matrix[i][j]);
        }
    }

    return 0;
}
```

The outer loop controls the **rows**.

The inner loop controls the **columns**.

---

## 6. Printing a 2D Array

Nested loops can also be used to print all elements.

### Example

```c
#include <stdio.h>

int main() {
    int matrix[2][3] = {
        {10, 20, 30},
        {40, 50, 60}
    };

    for (int i = 0; i < 2; i++) {
        for (int j = 0; j < 3; j++) {
            printf("%d ", matrix[i][j]);
        }

        printf("\n");
    }

    return 0;
}
```


```output
10 20 30
40 50 60
```

The outer loop moves through rows, while the inner loop moves through columns.

---

## 7. Understanding Nested Loops

For a 2D array, nested loops are commonly used.

```c
for (int i = 0; i < rows; i++) {
    for (int j = 0; j < columns; j++) {
        // Work with matrix[i][j]
    }
}
```

Here:

* `i` represents the row.
* `j` represents the column.

For a `3 x 3` matrix, the loops visit:

```text
[0][0] [0][1] [0][2]
[1][0] [1][1] [1][2]
[2][0] [2][1] [2][2]
```

---

## 8. Finding the Sum of Matrix Elements

We can calculate the sum of all elements using nested loops.

### Example

```c
#include <stdio.h>

int main() {
    int matrix[2][3] = {
        {10, 20, 30},
        {40, 50, 60}
    };

    int sum = 0;

    for (int i = 0; i < 2; i++) {
        for (int j = 0; j < 3; j++) {
            sum += matrix[i][j];
        }
    }

    printf("Sum = %d", sum);

    return 0;
}
```


```output
Sum = 210
```

The calculation is:

```text
10 + 20 + 30 + 40 + 50 + 60 = 210
```

## 9. Adding Two Matrices

Two matrices of the same size can be added.

For example:

```text
Matrix A        Matrix B

1 2             5 6
3 4             7 8
```

Addition is performed element by element:

```text
1 + 5 = 6
2 + 6 = 8
3 + 7 = 10
4 + 8 = 12
```

The result is:

```text
6  8
10 12
```

### Example

```c
#include <stdio.h>

int main() {
    int a[2][2] = {
        {1, 2},
        {3, 4}
    };

    int b[2][2] = {
        {5, 6},
        {7, 8}
    };

    int sum[2][2];

    for (int i = 0; i < 2; i++) {
        for (int j = 0; j < 2; j++) {
            sum[i][j] = a[i][j] + b[i][j];
        }
    }

    printf("Result:\n");

    for (int i = 0; i < 2; i++) {
        for (int j = 0; j < 2; j++) {
            printf("%d ", sum[i][j]);
        }

        printf("\n");
    }

    return 0;
}
```


```output
Result:
6 8
10 12
```

## 10. Matrix Transpose

The **transpose** of a matrix changes its rows into columns and its columns into rows.

For example:

```text
Original:

1 2 3
4 5 6
```

Transpose:

```text
1 4
2 5
3 6
```

### Example

```c
#include <stdio.h>

int main() {
    int matrix[2][3] = {
        {1, 2, 3},
        {4, 5, 6}
    };

    printf("Transpose:\n");

    for (int j = 0; j < 3; j++) {
        for (int i = 0; i < 2; i++) {
            printf("%d ", matrix[i][j]);
        }

        printf("\n");
    }

    return 0;
}
```


```output
Transpose:
1 4
2 5
3 6
```

Notice that the loop order is changed:

```c
for (int j = 0; j < 3; j++)
```

comes before:

```c
for (int i = 0; i < 2; i++)
```

## 11. Matrix with User Input

We can combine input and output using nested loops.

### Example

```c
#include <stdio.h>

int main() {
    int matrix[2][2];

    printf("Enter 4 numbers:\n");

    for (int i = 0; i < 2; i++) {
        for (int j = 0; j < 2; j++) {
            scanf("%d", &matrix[i][j]);
        }
    }

    printf("Matrix:\n");

    for (int i = 0; i < 2; i++) {
        for (int j = 0; j < 2; j++) {
            printf("%d ", matrix[i][j]);
        }

        printf("\n");
    }

    return 0;
}
```

### Example Output

```output
Enter 4 numbers:
10
20
30
40
Matrix:
10 20
30 40
```

int marks[3][3] = {

## Common Mistakes ⚠️

### 1. Confusing rows and columns

For:

```c
int matrix[2][3];
```

there are:

* `2` rows
* `3` columns

### 2. Using incorrect indexes

For:

```c
int matrix[2][3];
```

valid indexes are:

```text
Rows:    0, 1
Columns: 0, 1, 2
```

For example:

```c
matrix[1][2]
```

is valid.

But:

```c
matrix[2][3]
```

is outside the array.

### 3. Forgetting the `&` in `scanf`

Use:

```c
scanf("%d", &matrix[i][j]);
```

not:

```c
scanf("%d", matrix[i][j]);
```

### 4. Using only one loop

A 2D array normally needs nested loops when processing all rows and columns:

```c
for (int i = 0; i < rows; i++) {
    for (int j = 0; j < columns; j++) {
        // process element
    }
}
```

### 5. Using the wrong dimensions

Make sure the loop limits match the array dimensions.

For:

```c
int matrix[2][3];
```

use:

```c
for (int i = 0; i < 2; i++)
```

for rows and:

```c
for (int j = 0; j < 3; j++)
```

for columns.

---

## Key Points 📌

* A 2D array stores data in rows and columns.
* A matrix is commonly represented using a 2D array.
* The syntax is `array[row][column]`.
* Array indexes start from `0`.
* Nested loops are commonly used to process 2D arrays.
* The outer loop usually handles rows.
* The inner loop usually handles columns.
* 2D arrays can be used for tables and grids.
* Matrices of the same size can be added element by element.
* A matrix can be transposed by changing rows into columns.
