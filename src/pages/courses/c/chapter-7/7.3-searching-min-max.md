# Chapter 7: Arrays

## Section 3: Searching & Finding Maximum/Minimum

Arrays are useful when we need to store and work with multiple values.

In this section, we will learn how to:

* Search for an element in an array
* Check whether an element exists
* Find the maximum value
* Find the minimum value
* Use loops to process array elements

---

## 1. Searching in an Array

**Searching** means checking whether a particular value exists in an array.

One simple method is **Linear Search**.

In linear search, we check each element one by one from the beginning of the array.

### Example

```c id="linear-search"
#include <stdio.h>

int main() {
    int numbers[5] = {10, 20, 30, 40, 50};
    int search = 30;
    int found = 0;

    for (int i = 0; i < 5; i++) {
        if (numbers[i] == search) {
            found = 1;
            break;
        }
    }

    if (found)
        printf("Element found");
    else
        printf("Element not found");

    return 0;
}
```


```output id="linear-search-output"
Element found
```

The loop checks each element until it finds `30`.

The `break` statement stops the loop once the element is found.

## 2. Searching with the Element's Position

Sometimes we need to know the **position (index)** of the searched element.

### Example

```c id="search-position"
#include <stdio.h>

int main() {
    int numbers[5] = {15, 25, 35, 45, 55};
    int search = 45;
    int position = -1;

    for (int i = 0; i < 5; i++) {
        if (numbers[i] == search) {
            position = i;
            break;
        }
    }

    if (position != -1)
        printf("Element found at index %d", position);
    else
        printf("Element not found");

    return 0;
}
```


```output id="search-position-output"
Element found at index 3
```

Remember that array indexing starts from **0**.

So:

| Index | Value |
| ----: | ----: |
|     0 |    15 |
|     1 |    25 |
|     2 |    35 |
|     3 |    45 |
|     4 |    55 |

## 3. Searching for User Input

We can also ask the user for the value they want to search for.

### Example

```c id="user-search"
#include <stdio.h>

int main() {
    int numbers[5];
    int search;
    int found = 0;

    printf("Enter 5 numbers:\n");

    for (int i = 0; i < 5; i++) {
        scanf("%d", &numbers[i]);
    }

    printf("Enter number to search: ");
    scanf("%d", &search);

    for (int i = 0; i < 5; i++) {
        if (numbers[i] == search) {
            found = 1;
            break;
        }
    }

    if (found)
        printf("Element found");
    else
        printf("Element not found");

    return 0;
}
```

### Example Output

```output id="user-search-output"
Enter 5 numbers:
10
25
30
45
60
Enter number to search: 30
Element found
```

## 4. Finding the Maximum Value

The **maximum** is the largest value in an array.

For example:

```text
10  45  20  80  35
```

The maximum value is:

```text
80
```

### How It Works

1. Assume the first element is the maximum.
2. Compare it with every other element.
3. If a larger value is found, update the maximum.
4. Continue until the end of the array.

### Example

```c id="find-maximum"
#include <stdio.h>

int main() {
    int numbers[5] = {10, 45, 20, 80, 35};
    int max = numbers[0];

    for (int i = 1; i < 5; i++) {
        if (numbers[i] > max) {
            max = numbers[i];
        }
    }

    printf("Maximum = %d", max);

    return 0;
}
```


```output id="find-maximum-output"
Maximum = 80
```

## 6. Finding Both Maximum and Minimum

We can find both the maximum and minimum values using a single loop.

### Example

```c id="min-max"
#include <stdio.h>

int main() {
    int numbers[6] = {25, 10, 45, 5, 60, 30};

    int max = numbers[0];
    int min = numbers[0];

    for (int i = 1; i < 6; i++) {
        if (numbers[i] > max) {
            max = numbers[i];
        }

        if (numbers[i] < min) {
            min = numbers[i];
        }
    }

    printf("Maximum = %d\n", max);
    printf("Minimum = %d", min);

    return 0;
}
```


```output id="min-max-output"
Maximum = 60
Minimum = 5
```

Using one loop allows us to find both values while traversing the array once.

## 7. Searching and Finding Maximum/Minimum Together

We can combine different array operations in one program.

### Example

```c id="array-operations"
#include <stdio.h>

int main() {
    int numbers[5] = {12, 35, 8, 42, 20};
    int search = 35;

    int max = numbers[0];
    int min = numbers[0];
    int found = 0;

    for (int i = 0; i < 5; i++) {

        if (numbers[i] == search) {
            found = 1;
        }

        if (numbers[i] > max) {
            max = numbers[i];
        }

        if (numbers[i] < min) {
            min = numbers[i];
        }
    }

    if (found)
        printf("Element found\n");
    else
        printf("Element not found\n");

    printf("Maximum = %d\n", max);
    printf("Minimum = %d", min);

    return 0;
}
```


```output id="array-operations-output"
Element found
Maximum = 42
Minimum = 8
```

## 8. Why Start with `numbers[0]`?

When finding maximum or minimum, we usually start with the first element.

```c
int max = numbers[0];
int min = numbers[0];
```

This is better than using a fixed value such as:

```c
int max = 0;
```

because the array might contain only negative numbers.

For example:

```text
-10  -25  -5  -40
```

The maximum is `-5`.

Starting `max` with `0` would give an incorrect result.

So, using the first array element as the initial value works correctly for both positive and negative numbers.

## 9. Real-World Example 🌍

Imagine a teacher has the marks of five students:

```text
75  82  68  91  80
```

The teacher may want to find:

* Whether a particular mark exists
* The highest mark
* The lowest mark

Using an array and loops, all these operations can be performed easily.

For example:

```c id="student-marks"
#include <stdio.h>

int main() {
    int marks[5] = {75, 82, 68, 91, 80};

    int max = marks[0];
    int min = marks[0];

    for (int i = 1; i < 5; i++) {
        if (marks[i] > max)
            max = marks[i];

        if (marks[i] < min)
            min = marks[i];
    }

    printf("Highest mark = %d\n", max);
    printf("Lowest mark = %d", min);

    return 0;
}
```


```output id="student-marks-output"
Highest mark = 91
Lowest mark = 68
```

## Common Mistakes ⚠️

### 1. Starting the loop from the wrong index

If you already use:

```c
int max = numbers[0];
```

you can start comparison from index `1`:

```c
for (int i = 1; i < 5; i++)
```

### 2. Using `i <= 5`

This is incorrect for an array of 5 elements:

```c
for (int i = 0; i <= 5; i++)
```

The valid indexes are:

```text
0, 1, 2, 3, 4
```

Use:

```c
for (int i = 0; i < 5; i++)
```

### 3. Initializing maximum with zero

Avoid:

```c
int max = 0;
```

when the array can contain negative values.

Use:

```c
int max = numbers[0];
```

### 4. Forgetting the `break`

When you only need to know whether an element exists, `break` can stop the search after finding it.

```c
if (numbers[i] == search) {
    found = 1;
    break;
}
```

### 5. Confusing index with position

For:

```text
10 20 30 40
```

`40` is at:

* Index: `3`
* Human-readable position: `4`

C uses **zero-based indexing**, so the index is `3`.

---

## Key Points 📌

* Searching means checking whether a value exists in an array.
* Linear search checks elements one by one.
* Array indexes start from `0`.
* `break` can stop a search when the element is found.
* Maximum means the largest value.
* Minimum means the smallest value.
* Initialize `max` and `min` using the first array element.
* A single loop can find both maximum and minimum.
* Always keep the loop within the valid array indexes.
