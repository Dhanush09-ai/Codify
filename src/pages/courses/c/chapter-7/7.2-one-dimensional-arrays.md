# Chapter 7: Arrays

## Section 2: One-Dimensional Arrays

A **one-dimensional array** is a simple list of elements stored under one variable name.

Each element is accessed using a single index.

For example:

```c id="onedarray"
int marks[5] = {80, 75, 90, 85, 70};
```

The array contains five values:

```text id="arrayview"
Index:    0    1    2    3    4
         ┌────┬────┬────┬────┬────┐
Marks:   │ 80 │ 75 │ 90 │ 85 │ 70 │
         └────┴────┴────┴────┴────┘
```

---

## 1. Declaring a One-Dimensional Array

The syntax is:

```c id="1dsyntax"
data_type array_name[size];
```

Example:

```c id="1ddeclare"
int numbers[5];
```

This creates an integer array with five elements.

The valid indexes are:

```text id="1dindexes"
0  1  2  3  4
```

---

## 2. Initializing a One-Dimensional Array

We can initialize an array when declaring it.

```c id="1dinit"
int numbers[5] = {10, 20, 30, 40, 50};
```

Each value is stored at a different index.

```text id="1dmap"
numbers[0] → 10
numbers[1] → 20
numbers[2] → 30
numbers[3] → 40
numbers[4] → 50
```

---

## 3. Accessing Elements

We use the index to access an individual element.

```c id="1daccess"
#include <stdio.h>

int main()
{
    int numbers[5] = {10, 20, 30, 40, 50};

    printf("First = %d\n", numbers[0]);
    printf("Third = %d\n", numbers[2]);
    printf("Last = %d", numbers[4]);

    return 0;
}
```


```output id="1daccessout"
First = 10
Third = 30
Last = 50
```

---

## 4. Updating Array Elements

An element can be changed using its index.

```c id="1dupdate"
#include <stdio.h>

int main()
{
    int numbers[4] = {10, 20, 30, 40};

    numbers[2] = 100;

    printf("%d %d %d %d",
           numbers[0],
           numbers[1],
           numbers[2],
           numbers[3]);

    return 0;
}
```


```output id="1dupdateout"
10 20 100 40
```

The statement:

```c id="1dupdatestmt"
numbers[2] = 100;
```

changes the third element from `30` to `100`.

---

## 5. Taking Input into an Array

We can use `scanf()` to read values into an array.

```c id="1dinput"
#include <stdio.h>

int main()
{
    int numbers[5];

    for (int i = 0; i < 5; i++)
    {
        scanf("%d", &numbers[i]);
    }

    printf("Array elements: ");

    for (int i = 0; i < 5; i++)
    {
        printf("%d ", numbers[i]);
    }

    return 0;
}
```

### Input

```text
10 20 30 40 50
```


```output id="1dinputout"
Array elements: 10 20 30 40 50
```

The loop allows us to read each element one by one.

---

## 6. Using a Loop with an Array

Loops are very useful with one-dimensional arrays.

Instead of writing:

```c id="withoutloop"
printf("%d ", numbers[0]);
printf("%d ", numbers[1]);
printf("%d ", numbers[2]);
printf("%d ", numbers[3]);
printf("%d ", numbers[4]);
```

we can use a loop:

```c id="withloop"
for (int i = 0; i < 5; i++)
{
    printf("%d ", numbers[i]);
}
```

Here, `i` acts as the array index.

```text id="loopindexes"
i = 0 → numbers[0]
i = 1 → numbers[1]
i = 2 → numbers[2]
i = 3 → numbers[3]
i = 4 → numbers[4]
```

---

## 7. Finding the Sum of Array Elements

We can use a loop to calculate the sum of all elements.

```c id="1dsum"
#include <stdio.h>

int main()
{
    int numbers[5] = {10, 20, 30, 40, 50};
    int sum = 0;

    for (int i = 0; i < 5; i++)
    {
        sum = sum + numbers[i];
    }

    printf("Sum = %d", sum);

    return 0;
}
```


```output id="1dsumout"
Sum = 150
```

The loop adds each element to `sum`.

---

## 8. Finding the Average

We can also calculate the average of array elements.

```c id="1daverage"
#include <stdio.h>

int main()
{
    int marks[5] = {80, 70, 90, 60, 100};
    int sum = 0;
    float average;

    for (int i = 0; i < 5; i++)
    {
        sum = sum + marks[i];
    }

    average = (float)sum / 5;

    printf("Average = %.2f", average);

    return 0;
}
```


```output id="1daverageout"
Average = 80.00
```

The type cast `(float)` makes the division produce a decimal result.

---

## 9. Traversing an Array

**Traversing** means visiting each element of an array one by one.

Example:

```c id="1dtraverse"
#include <stdio.h>

int main()
{
    int numbers[5] = {5, 10, 15, 20, 25};

    for (int i = 0; i < 5; i++)
    {
        printf("%d ", numbers[i]);
    }

    return 0;
}
```


```output id="1dtraverseout"
5 10 15 20 25
```

The loop visits every element from index `0` to index `4`.

---

## 10. Reading an Array in Reverse

We can also traverse an array from the last element to the first.

```c id="1dreverse"
#include <stdio.h>

int main()
{
    int numbers[5] = {10, 20, 30, 40, 50};

    for (int i = 4; i >= 0; i--)
    {
        printf("%d ", numbers[i]);
    }

    return 0;
}
```


```output id="1dreverseout"
50 40 30 20 10
```

The loop starts at index `4` and decreases until index `0`.

## 11. Array of Different Data Types

One-dimensional arrays can be created using different data types.

### Integer Array

```c id="intarray"
int numbers[3] = {10, 20, 30};
```

### Float Array

```c id="floatarray"
float prices[3] = {10.5, 20.5, 30.5};
```

### Character Array

```c id="chararray"
char letters[3] = {'A', 'B', 'C'};
```

The elements of an individual array must match its declared type.

## 12. Real-World Example 🌍

Suppose a teacher wants to store the marks of five students.

```c id="studentmarks"
#include <stdio.h>

int main()
{
    int marks[5] = {85, 72, 91, 68, 88};
    int sum = 0;

    for (int i = 0; i < 5; i++)
    {
        sum = sum + marks[i];
    }

    printf("Total Marks = %d", sum);

    return 0;
}
```


```output id="studentmarksout"
Total Marks = 404
```

Instead of using five separate variables, the teacher can store all marks in one array.

## Common Mistakes

### Mistake 1: Starting the index from 1

Incorrect:

```c id="wrongindex"
numbers[1]
```

when trying to access the first element.

Correct:

```c id="correctindex"
numbers[0]
```

---

### Mistake 2: Using `<=` in the loop condition

For an array of size `5`, this is incorrect:

```c id="wrongloop"
for (int i = 0; i <= 5; i++)
{
    printf("%d ", numbers[i]);
}
```

The last valid index is `4`.

Correct:

```c id="correctloop"
for (int i = 0; i < 5; i++)
{
    printf("%d ", numbers[i]);
}
```

---

### Mistake 3: Forgetting `&` with `scanf()`

When reading an integer into an array element, use:

```c id="scanfcorrect"
scanf("%d", &numbers[i]);
```

The `&` is required for `scanf()` to store the input in the integer variable.

---

## Key Points

* A **one-dimensional array** stores elements in a single sequence.
* Array indexing starts from `0`.
* An array of size `n` has valid indexes from `0` to `n - 1`.
* A `for` loop is commonly used to process array elements.
* Array elements can be read, printed, changed, and processed.
* We can calculate values such as sum and average using arrays.
* Traversing means visiting array elements one by one.
* Arrays can store integers, floating-point values, characters, and other supported data types.
