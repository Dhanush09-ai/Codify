# Chapter 7: Arrays

## Section 4: Sorting & Reversing Arrays

Arrays can store multiple values, but sometimes we need to arrange those values in a particular order.

In this section, we will learn how to:

* Sort an array in ascending order
* Sort an array in descending order
* Swap two elements
* Reverse an array
* Use loops to rearrange array elements

---

## 1. What is Sorting?

**Sorting** means arranging the elements of an array in a particular order.

There are two common orders:

### Ascending Order

Smallest to largest.

```text
2  5  8  12  20
```

### Descending Order

Largest to smallest.

```text
20  12  8  5  2
```

---

## 2. Swapping Two Elements

To sort an array, we often need to **swap** two elements.

Swapping means exchanging their values.

For example:

```text
Before:
10  20

After:
20  10
```

In C, a temporary variable can be used.

### Example

```c id="swap-elements"
#include <stdio.h>

int main() {
    int a = 10;
    int b = 20;
    int temp;

    temp = a;
    a = b;
    b = temp;

    printf("a = %d\n", a);
    printf("b = %d", b);

    return 0;
}
```


```output id="swap-elements-output"
a = 20
b = 10
```

The variable `temp` temporarily stores one value while the values are exchanged.

---

## 3. Sorting an Array in Ascending Order

One simple way to sort an array is to compare two elements and swap them when they are in the wrong order.

### Example

```c id="ascending-sort"
#include <stdio.h>

int main() {
    int numbers[5] = {40, 10, 50, 20, 30};
    int temp;

    for (int i = 0; i < 5 - 1; i++) {
        for (int j = i + 1; j < 5; j++) {
            if (numbers[i] > numbers[j]) {
                temp = numbers[i];
                numbers[i] = numbers[j];
                numbers[j] = temp;
            }
        }
    }

    printf("Sorted array: ");

    for (int i = 0; i < 5; i++) {
        printf("%d ", numbers[i]);
    }

    return 0;
}
```


```output id="ascending-sort-output"
Sorted array: 10 20 30 40 50
```

Here, whenever the earlier element is greater than the later element, the two values are swapped.

---

## 4. Sorting an Array in Descending Order

For descending order, we simply reverse the comparison.

Instead of:

```c id="ascending-condition"
if (numbers[i] > numbers[j])
```

we use:

```c id="descending-condition"
if (numbers[i] < numbers[j])
```

### Example

```c id="descending-sort"
#include <stdio.h>

int main() {
    int numbers[5] = {40, 10, 50, 20, 30};
    int temp;

    for (int i = 0; i < 5 - 1; i++) {
        for (int j = i + 1; j < 5; j++) {
            if (numbers[i] < numbers[j]) {
                temp = numbers[i];
                numbers[i] = numbers[j];
                numbers[j] = temp;
            }
        }
    }

    printf("Sorted array: ");

    for (int i = 0; i < 5; i++) {
        printf("%d ", numbers[i]);
    }

    return 0;
}
```


```output id="descending-sort-output"
Sorted array: 50 40 30 20 10
```

## 5. Sorting Using User Input

We can also read the array elements from the user and then sort them.

### Example

```c id="input-sort"
#include <stdio.h>

int main() {
    int numbers[5];
    int temp;

    printf("Enter 5 numbers:\n");

    for (int i = 0; i < 5; i++) {
        scanf("%d", &numbers[i]);
    }

    for (int i = 0; i < 5 - 1; i++) {
        for (int j = i + 1; j < 5; j++) {
            if (numbers[i] > numbers[j]) {
                temp = numbers[i];
                numbers[i] = numbers[j];
                numbers[j] = temp;
            }
        }
    }

    printf("Sorted array: ");

    for (int i = 0; i < 5; i++) {
        printf("%d ", numbers[i]);
    }

    return 0;
}
```

### Example Output

```output id="input-sort-output"
Enter 5 numbers:
45
12
80
25
30
Sorted array: 12 25 30 45 80
```

## 6. What is Reversing an Array?

**Reversing** an array means changing the order of its elements from first-to-last into last-to-first.

For example:

```text
Before:
10 20 30 40 50
```

After reversing:

```text
50 40 30 20 10
```

---

## 7. Reversing an Array Using Another Array

One simple method is to use a second array.

### Example

```c id="reverse-second-array"
#include <stdio.h>

int main() {
    int numbers[5] = {10, 20, 30, 40, 50};
    int reverse[5];

    for (int i = 0; i < 5; i++) {
        reverse[i] = numbers[4 - i];
    }

    printf("Reversed array: ");

    for (int i = 0; i < 5; i++) {
        printf("%d ", reverse[i]);
    }

    return 0;
}
```


```output id="reverse-second-array-output"
Reversed array: 50 40 30 20 10
```

The expression:

```c id="reverse-index"
numbers[4 - i]
```

selects the elements from the end of the original array.

---

## 8. Reversing an Array Using Swapping

We can reverse an array without creating another array.

The idea is to swap:

* First element with last element
* Second element with second-last element
* Continue until the middle is reached

For example:

```text
10 20 30 40 50
↑              ↑
└──── swap ────┘

50 20 30 40 10

   ↑        ↑
   └─ swap ─┘

50 40 30 20 10
```

### Example

```c id="reverse-swap"
#include <stdio.h>

int main() {
    int numbers[5] = {10, 20, 30, 40, 50};
    int temp;

    for (int i = 0; i < 5 / 2; i++) {
        temp = numbers[i];
        numbers[i] = numbers[4 - i];
        numbers[4 - i] = temp;
    }

    printf("Reversed array: ");

    for (int i = 0; i < 5; i++) {
        printf("%d ", numbers[i]);
    }

    return 0;
}
```


```output id="reverse-swap-output"
Reversed array: 50 40 30 20 10
```

This method uses the same array and does not require another array.

## 10. Sorting vs Reversing

Sorting and reversing are different operations.

| Operation | Meaning                        | Example       |
| --------- | ------------------------------ | ------------- |
| Sorting   | Arranging values in order      | `10 20 30 40` |
| Reversing | Changing the order of elements | `40 30 20 10` |

For example, if the original array is:

```text
30 10 40 20
```

Ascending sorting gives:

```text
10 20 30 40
```

But reversing the original array gives:

```text
20 40 10 30
```

Reversing does **not** mean sorting in descending order.

---

## 11. Real-World Example 🌍

Imagine an application stores the scores of students:

```text
75 90 65 80 85
```

Sorting can be used to arrange the scores:

```text
65 75 80 85 90
```

Reversing can be used when the application needs to display the stored records from the last one to the first one.

These operations are useful when working with lists of numbers, records, scores, and other data.

## Common Mistakes ⚠️

### 1. Using the wrong comparison for sorting

For ascending order:

```c
if (numbers[i] > numbers[j])
```

For descending order:

```c
if (numbers[i] < numbers[j])
```

### 2. Forgetting to use a temporary variable

Incorrect swapping can lose one of the values.

Use:

```c
temp = a;
a = b;
b = temp;
```

### 3. Going beyond the array boundary

For an array of 5 elements, valid indexes are:

```text
0 1 2 3 4
```

Do not access:

```c id="invalid-index"
numbers[5]
```

### 4. Reversing all the way through the array

When using swapping, only half of the array needs to be processed:

```c id="half-array"
for (int i = 0; i < 5 / 2; i++)
```

If you continue through the entire array, the elements will be swapped back to their original positions.

### 5. Confusing reversing with descending sorting

Reversing:

```text
30 10 40 20
↓
20 40 10 30
```

Descending sorting:

```text
30 10 40 20
↓
40 30 20 10
```

They are not the same operation.

---

## Key Points 📌

* Sorting arranges array elements in a particular order.
* Ascending order goes from smallest to largest.
* Descending order goes from largest to smallest.
* Swapping is used to exchange two values.
* A temporary variable makes swapping simple.
* Reversing changes the order of elements.
* An array can be reversed using another array.
* An array can also be reversed by swapping elements in the same array.
* When reversing using swaps, only half of the array needs to be processed.
* Reversing and descending sorting are different operations.
