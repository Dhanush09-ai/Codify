# Chapter 7: Arrays

## Section 1: Introduction to Arrays

An **array** is a collection of multiple values of the **same data type** stored under one variable name.

Arrays are useful when we need to store many related values.

For example, instead of creating five separate variables:

```c id="separatevars"
int mark1 = 80;
int mark2 = 75;
int mark3 = 90;
int mark4 = 85;
int mark5 = 70;
```

we can use one array:

```c id="marksarray"
int marks[5] = {80, 75, 90, 85, 70};
```

Now all five marks are stored in the `marks` array.

---

## 1. Why Do We Need Arrays?

Suppose we want to store the marks of 100 students.

Without an array, we would need many separate variables:

```text
mark1
mark2
mark3
...
mark100
```

This would make the program difficult to write and manage.

With an array, we can store all the values using one variable:

```c id="manymarks"
int marks[100];
```

This makes it easier to store and process a collection of values.

---

## 2. Array Declaration

The basic syntax for declaring an array is:

```c id="arraysyntax"
data_type array_name[size];
```

For example:

```c id="arraydeclare"
int numbers[5];
```

Here:

* `int` → data type
* `numbers` → array name
* `5` → number of elements

This creates an integer array that can store **5 values**.

---

## 3. Array Index

Each element in an array has a position called an **index**.

In C, array indexing starts from **0**.

For an array of 5 elements:

```text
Index:    0    1    2    3    4
         ┌────┬────┬────┬────┬────┐
Array:   │ 10 │ 20 │ 30 │ 40 │ 50 │
         └────┴────┴────┴────┴────┘
```

So:

```text
numbers[0] → 10
numbers[1] → 20
numbers[2] → 30
numbers[3] → 40
numbers[4] → 50
```

The first element is always at index `0`.

---

## 4. Initializing an Array

We can give values to an array when declaring it.

### Example

```c id="arrayinit"
#include <stdio.h>

int main()
{
    int numbers[5] = {10, 20, 30, 40, 50};

    printf("%d", numbers[0]);

    return 0;
}
```


```output id="arrayinitout"
10
```

The value at index `0` is `10`.

---

## 5. Accessing Array Elements

We use the array name and index to access an element.

```c id="arrayaccess"
#include <stdio.h>

int main()
{
    int numbers[5] = {10, 20, 30, 40, 50};

    printf("%d\n", numbers[0]);
    printf("%d\n", numbers[2]);
    printf("%d", numbers[4]);

    return 0;
}
```


```output id="arrayaccessout"
10
30
50
```

Remember:

```text
numbers[0] → First element
numbers[1] → Second element
numbers[2] → Third element
numbers[3] → Fourth element
numbers[4] → Fifth element
```

---

## 6. Changing an Array Element

We can change the value stored at a particular index.

```c id="arraychange"
#include <stdio.h>

int main()
{
    int numbers[3] = {10, 20, 30};

    numbers[1] = 100;

    printf("%d %d %d", numbers[0], numbers[1], numbers[2]);

    return 0;
}
```


```output id="arraychangeout"
10 100 30
```

The statement:

```c
numbers[1] = 100;
```

changes the second element from `20` to `100`.

---

## 7. Printing Array Elements

We can access each element individually.

```c id="arrayprint"
#include <stdio.h>

int main()
{
    int numbers[5] = {10, 20, 30, 40, 50};

    printf("%d ", numbers[0]);
    printf("%d ", numbers[1]);
    printf("%d ", numbers[2]);
    printf("%d ", numbers[3]);
    printf("%d", numbers[4]);

    return 0;
}
```


```output id="arrayprintout"
10 20 30 40 50
```

Later, we can use loops to process all array elements more easily.

---

## 8. Array Size and Number of Elements

When we write:

```c
int numbers[5];
```

the array can hold **5 integer elements**.

The valid indexes are:

```text
0, 1, 2, 3, 4
```

The last valid index is always:

```text
size - 1
```

So for an array of size `5`:

```text
5 - 1 = 4
```

Therefore, the last element is:

```c
numbers[4]
```

---

## 9. Common Array Mistake: Wrong Index

Suppose we have:

```c
int numbers[5] = {10, 20, 30, 40, 50};
```

The valid indexes are:

```text
0 to 4
```

Do not try to access:

```c
numbers[5]
```

because index `5` is outside the array's valid range.

Always remember:

```text
Array size = 5
Valid indexes = 0, 1, 2, 3, 4
```

## 10. Real-World Example 🌍

Imagine a student has marks for five subjects:

```text
Maths       → 85
Physics     → 78
Chemistry   → 90
Programming → 95
English     → 80
```

These values can be stored in one array:

```c id="marksreal"
#include <stdio.h>

int main()
{
    int marks[5] = {85, 78, 90, 95, 80};

    printf("Programming Marks = %d", marks[3]);

    return 0;
}
```


```output id="marksrealout"
Programming Marks = 95
```

The programming mark is stored at index `3`.

---

## Common Mistakes

### Mistake 1: Forgetting that indexing starts at 0

For:

```c
int numbers[5];
```

the first element is:

```c
numbers[0]
```

not:

```c
numbers[1]
```

---

### Mistake 2: Using an invalid index

For an array of 5 elements, the valid indexes are:

```text
0 to 4
```

Do not use an index outside this range.

---

### Mistake 3: Mixing data types

An array stores elements of the same declared data type.

For example:

```c
int numbers[3];
```

is an integer array.

It should be used to store integer values.

---

## Key Points

* An **array** stores multiple values of the same data type.
* All elements are accessed using one array name.
* Array indexing in C starts from `0`.
* The syntax is `data_type array_name[size];`.
* An array of size `5` has indexes `0` through `4`.
* Individual elements are accessed using `array_name[index]`.
* Array elements can be changed using their indexes.
* Always use a valid array index.
