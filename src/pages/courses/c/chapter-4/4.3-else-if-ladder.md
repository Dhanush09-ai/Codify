# Chapter 4: Conditions

## Section 3: Else-if Ladder

Sometimes a program needs to check **more than two conditions**.

For example, a student's grade may depend on their marks:

* 90 or above → Grade A
* 75 or above → Grade B
* 60 or above → Grade C
* 40 or above → Grade D
* Below 40 → Fail

For situations like this, C provides the **else-if ladder**.

---

## 1. What is an Else-if Ladder?

An **else-if ladder** is used to check multiple conditions one after another.

### Syntax

```c id="elseif_syntax"
if (condition1) {
    // statements
}
else if (condition2) {
    // statements
}
else if (condition3) {
    // statements
}
else {
    // statements when all conditions are false
}
```

C checks the conditions from **top to bottom**.

* If the first condition is true, its block executes.
* The remaining conditions are skipped.
* If the first condition is false, C checks the next condition.
* The `else` block executes if all conditions are false.

---

## 2. How an Else-if Ladder Works

Consider this flow:

```text id="elseif_flow"
        Condition 1
        /        \
     True       False
      ↓            ↓
   Block 1     Condition 2
                  /    \
               True    False
                ↓        ↓
             Block 2  Condition 3
                         /    \
                      True    False
                       ↓        ↓
                    Block 3   else
                              ↓
                           Block 4
```

Only **one block** of an else-if ladder is executed.

---

## 3. Simple Else-if Example

Let's check whether a number is positive, negative, or zero.

```c id="positive_negative"
#include <stdio.h>

int main() {
    int number = -5;

    if (number > 0) {
        printf("Positive");
    }
    else if (number < 0) {
        printf("Negative");
    }
    else {
        printf("Zero");
    }

    return 0;
}
```

```output id="positive_negative_output"
Negative
```

The program first checks:

```text id="positive_check"
number > 0
```

This is false.

Then it checks:

```text id="negative_check"
number < 0
```

This is true.

Therefore, it prints:

```text id="negative_result"
Negative
```

## 4. Multiple Conditions

An else-if ladder can contain several conditions.

### Example

```c id="multiple_conditions"
#include <stdio.h>

int main() {
    int number = 15;

    if (number > 20) {
        printf("Greater than 20");
    }
    else if (number > 10) {
        printf("Greater than 10");
    }
    else if (number > 5) {
        printf("Greater than 5");
    }
    else {
        printf("5 or less");
    }

    return 0;
}
```

```output id="multiple_conditions_output"
Greater than 10
```

The first condition is false:

```text id="condition_a"
15 > 20
```

The second condition is true:

```text id="condition_b"
15 > 10
```

So C executes that block and skips the remaining conditions.

---

## 5. Why Order Matters

The order of conditions is very important in an else-if ladder.

Consider:

```c id="order_example"
int marks = 85;

if (marks >= 40) {
    printf("Pass");
}
else if (marks >= 75) {
    printf("Grade B");
}
```

The first condition:

```text id="first_condition"
marks >= 40
```

is already true.

Therefore, `Grade B` will never be checked.

A better order is to check the higher range first:

```c id="correct_order"
if (marks >= 75) {
    printf("Grade B");
}
else if (marks >= 40) {
    printf("Pass");
}
```

Now the program checks the more specific condition first.

---

## 6. Grade Example

An else-if ladder is commonly used to assign grades.

```c id="grade_example"
#include <stdio.h>

int main() {
    int marks = 82;

    if (marks >= 90) {
        printf("Grade A");
    }
    else if (marks >= 75) {
        printf("Grade B");
    }
    else if (marks >= 60) {
        printf("Grade C");
    }
    else if (marks >= 40) {
        printf("Grade D");
    }
    else {
        printf("Fail");
    }

    return 0;
}
```

```output id="grade_output"
Grade B
```

The program checks:

```text id="grade_check"
82 >= 90   → false
82 >= 75   → true
```

So it prints:

```text id="grade_result"
Grade B
```

The remaining conditions are not checked.

## 7. Else-if Ladder Without `else`

The final `else` is optional.

You can write an else-if ladder without it.

### Example

```c id="no_else"
#include <stdio.h>

int main() {
    int temperature = 35;

    if (temperature > 40) {
        printf("Very Hot");
    }
    else if (temperature > 30) {
        printf("Hot");
    }
    else if (temperature > 20) {
        printf("Normal");
    }

    return 0;
}
```

```output id="no_else_output"
Hot
```

If none of the conditions is true, nothing happens because there is no final `else`.

---

## 8. Else-if with Logical Operators

Conditions in an else-if ladder can use logical operators such as `&&` and `||`.

### Example

```c id="logical_elseif"
#include <stdio.h>

int main() {
    int age = 20;
    int has_id = 1;

    if (age < 18) {
        printf("Not eligible");
    }
    else if (age >= 18 && has_id == 1) {
        printf("Eligible");
    }
    else {
        printf("ID required");
    }

    return 0;
}
```

```output id="logical_elseif_output"
Eligible
```

Here, the second condition contains two conditions joined using `&&`.

Both must be true.

## 9. Real-World Example 🌍

Imagine a simple electricity billing system.

Different units can have different charges or categories.

```c id="electricity_example"
#include <stdio.h>

int main() {
    int units = 180;

    if (units <= 100) {
        printf("Low usage");
    }
    else if (units <= 200) {
        printf("Medium usage");
    }
    else if (units <= 300) {
        printf("High usage");
    }
    else {
        printf("Very high usage");
    }

    return 0;
}
```

```output id="electricity_output"
Medium usage
```

Since `180 <= 100` is false and `180 <= 200` is true, the program prints:

```text id="electricity_result"
Medium usage
```

## 10. Else-if Ladder vs Multiple `if` Statements

These two approaches are different.

### Else-if Ladder

```c id="elseif_single"
if (marks >= 90) {
    printf("A");
}
else if (marks >= 75) {
    printf("B");
}
```

Only the first matching block is executed.

### Multiple `if` Statements

```c id="multiple_if"
if (marks >= 90) {
    printf("A");
}

if (marks >= 75) {
    printf("B");
}
```

Both conditions are checked independently.

For example, if `marks = 95`, both conditions are true, so both blocks can execute.

Use an else-if ladder when the choices are **alternative possibilities**.

---

## Common Mistakes ⚠️

### 1. Putting conditions in the wrong order

For ranges, check the higher or more specific condition first.

Good:

```c id="good_order"
if (marks >= 90) {
    printf("A");
}
else if (marks >= 75) {
    printf("B");
}
```

---

### 2. Forgetting that only the first matching block executes

Once C finds a true condition in an else-if ladder, it skips the remaining conditions.

---

### 3. Using separate `if` statements when choices are alternatives

If only one result should be selected, an else-if ladder is often more suitable.

---

### 4. Forgetting the final `else`

The final `else` is optional, but it is useful when you want to handle all cases that do not match the previous conditions.

---

### 5. Using `=` instead of `==`

Remember:

```c id="assignment_operator"
=
```

assigns a value.

```c id="comparison_operator"
==
```

compares two values.

For example:

```c id="comparison_example"
if (number == 10) {
    printf("Number is 10");
}
```

---

## Key Points 📌

* An **else-if ladder** is used to check multiple conditions.
* Conditions are checked from **top to bottom**.
* The first true condition executes its block.
* Once one block executes, the remaining conditions are skipped.
* The final `else` is optional.
* The order of conditions is important.
* Else-if ladders are useful for grades, ranges, categories, and multiple choices.
* Multiple separate `if` statements can execute more than one block, while an else-if ladder selects only the first matching block.
