# Chapter 4: Conditions

## Section 5: Ternary Operator

The **ternary operator** is a short way to write a simple `if-else` condition.

It is called **ternary** because it works with three parts:

1. A condition
2. The value when the condition is true
3. The value when the condition is false

### 1. Syntax

The syntax of the ternary operator is:

```c
condition ? value_if_true : value_if_false;
```

For example:

```c
int age = 20;

int result = (age >= 18) ? 1 : 0;
```

Here:

* `age >= 18` is the condition.
* `1` is returned when the condition is true.
* `0` is returned when the condition is false.

### 2. Simple Example

Let's check whether a number is positive or negative.

```c
#include <stdio.h>

int main() {
    int number = 10;

    const char *result = (number >= 0) ? "Positive" : "Negative";

    printf("%s", result);

    return 0;
}
```

```output
Positive
```

The condition `number >= 0` is true, so `"Positive"` is selected.

### 3. Ternary Operator with Numbers

The ternary operator can directly select between two numbers.

```c
#include <stdio.h>

int main() {
    int a = 15;
    int b = 10;

    int greater = (a > b) ? a : b;

    printf("Greater = %d", greater);

    return 0;
}
```

```output
Greater = 15
```

If `a > b` is true, `a` is selected. Otherwise, `b` is selected.

### 4. Ternary Operator vs if-else

The following `if-else` code:

```c
int age = 20;
int result;

if (age >= 18) {
    result = 1;
} else {
    result = 0;
}
```

Can be written using the ternary operator:

```c
int age = 20;

int result = (age >= 18) ? 1 : 0;
```

The ternary operator is useful when the condition is **simple** and only one value needs to be selected.

### 5. Finding the Smaller Number

We can also use the ternary operator to find the smaller of two numbers.

```c
#include <stdio.h>

int main() {
    int a = 8;
    int b = 12;

    int smaller = (a < b) ? a : b;

    printf("Smaller = %d", smaller);

    return 0;
}
```

```output
Smaller = 8
```

### 6. Using Ternary Operator in printf()

A ternary expression can also be used directly inside `printf()`.

```c
#include <stdio.h>

int main() {
    int number = 7;

    printf("%s", (number % 2 == 0) ? "Even" : "Odd");

    return 0;
}
```

```output
Odd
```

Here, the ternary operator checks whether the number is divisible by `2`.

### 7. Real-World Example 🌍

Suppose a shopping website gives free delivery when the order amount is ₹500 or more.

```c
#include <stdio.h>

int main() {
    int amount = 750;

    const char *delivery = (amount >= 500) ? "Free Delivery" : "Delivery Charge";

    printf("%s", delivery);

    return 0;
}
```

```output
Free Delivery
```

The condition checks the order amount and selects the appropriate message.

## Common Mistakes

### Mistake 1: Forgetting the `:`

Incorrect:

```c
int result = (10 > 5) ? 100;
```

Correct:

```c
int result = (10 > 5) ? 100 : 200;
```

A ternary operator always needs both `?` and `:`.

### Mistake 2: Using `=` instead of `==`

Incorrect:

```c
int result = (number = 10) ? 1 : 0;
```

For comparison, use:

```c
int result = (number == 10) ? 1 : 0;
```

### Mistake 3: Using Ternary for Complex Conditions

Avoid making very long or complicated ternary expressions.

For complex conditions, `if-else` is usually easier to read.

## Key Points

* The ternary operator is a short form of simple `if-else`.
* Its syntax is `condition ? true_value : false_value`.
* It has three parts.
* The `?` separates the condition from the true value.
* The `:` separates the true value from the false value.
* It can be used to select between two values.
* It can also be used directly inside expressions such as `printf()`.
