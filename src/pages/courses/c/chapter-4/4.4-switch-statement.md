# Chapter 4: Conditions

## Section 4: `switch` Statement

Sometimes a program needs to choose one option from several possible choices.

For example:

* `1` → Monday
* `2` → Tuesday
* `3` → Wednesday
* `4` → Thursday

Instead of writing many `if-else` conditions, C provides the **`switch` statement**.

The `switch` statement is useful when we want to compare one expression with several fixed values.

---

## 1. What is a `switch` Statement?

A `switch` statement allows a program to select one block of code based on the value of an expression.

### Syntax

```c id="switch_syntax"
switch (expression) {
    case value1:
        // statements
        break;

    case value2:
        // statements
        break;

    case value3:
        // statements
        break;

    default:
        // statements
}
```

The important parts are:

| Keyword   | Purpose                    |
| --------- | -------------------------- |
| `switch`  | Starts the selection       |
| `case`    | Specifies a possible value |
| `break`   | Exits the switch           |
| `default` | Runs when no case matches  |

---

## 2. Simple `switch` Example

Let's display a message based on a number.

```c id="simple_switch"
#include <stdio.h>

int main() {
    int number = 2;

    switch (number) {
        case 1:
            printf("One");
            break;

        case 2:
            printf("Two");
            break;

        case 3:
            printf("Three");
            break;

        default:
            printf("Invalid number");
    }

    return 0;
}
```

```output id="simple_switch_output"
Two
```

The value of `number` is `2`.

C compares it with each `case`.

When it finds:

```text id="switch_match"
case 2:
```

that block is executed.

---

## 3. The `case` Statement

A `case` represents a possible value of the expression.

For example:

```c id="case_example"
switch (choice) {
    case 1:
        printf("Start");
        break;

    case 2:
        printf("Stop");
        break;
}
```

If:

```text id="choice_value"
choice = 1
```

the program executes:

```text id="case_result"
Start
```

If:

```text id="choice_value2"
choice = 2
```

it executes:

```text id="case_result2"
Stop
```

---

## 4. The `break` Statement

The `break` statement is commonly used to stop execution of the `switch` after a matching case.

Example:

```c id="break_example"
switch (number) {
    case 1:
        printf("One");
        break;

    case 2:
        printf("Two");
        break;
}
```

When `case 1` matches:

```text id="break_flow"
case 1
  ↓
print "One"
  ↓
break
  ↓
exit switch
```

Without `break`, execution can continue into the next case.

---

## 5. What Happens Without `break`?

If `break` is missing, C continues executing the statements in the following cases.

This is called **fall-through**.

### Example

```c id="fallthrough_example"
#include <stdio.h>

int main() {
    int number = 1;

    switch (number) {
        case 1:
            printf("One\n");

        case 2:
            printf("Two\n");

        case 3:
            printf("Three\n");
    }

    return 0;
}
```

```output id="fallthrough_output"
One
Two
Three
```

The program starts from `case 1` and continues into the following cases because there are no `break` statements.

For beginners, remember to use `break` when you want only one case to execute.

---

## 6. The `default` Case

The `default` case is executed when none of the cases matches the switch expression.

### Example

```c id="default_example"
#include <stdio.h>

int main() {
    int number = 5;

    switch (number) {
        case 1:
            printf("One");
            break;

        case 2:
            printf("Two");
            break;

        case 3:
            printf("Three");
            break;

        default:
            printf("Invalid number");
    }

    return 0;
}
```

```output id="default_output"
Invalid number
```

Since there is no `case 5`, the `default` block executes.

---

## 7. `switch` with Characters

A `switch` statement can also be used with a character.

### Example

```c id="character_switch"
#include <stdio.h>

int main() {
    char grade = 'B';

    switch (grade) {
        case 'A':
            printf("Excellent");
            break;

        case 'B':
            printf("Very Good");
            break;

        case 'C':
            printf("Good");
            break;

        default:
            printf("Invalid grade");
    }

    return 0;
}
```

```output id="character_switch_output"
Very Good
```

Here, the switch expression is the character:

```text id="grade_value"
'B'
```

So `case 'B'` is selected.

---

## 8. Multiple Cases with the Same Action

Sometimes different cases should perform the same action.

You can place multiple `case` labels before the same statements.

### Example

```c id="multiple_cases"
#include <stdio.h>

int main() {
    int day = 6;

    switch (day) {
        case 1:
        case 7:
            printf("Weekend");
            break;

        case 2:
        case 3:
        case 4:
        case 5:
        case 6:
            printf("Weekday");
            break;

        default:
            printf("Invalid day");
    }

    return 0;
}
```

```output id="multiple_cases_output"
Weekend
```

Here, both `case 1` and `case 7` lead to the same `"Weekend"` block.

---

## 9. `switch` vs `if-else`

Both `switch` and `if-else` can be used for decision making, but they are useful in different situations.

| `switch`                     | `if-else`                         |
| ---------------------------- | --------------------------------- |
| Good for fixed values        | Good for conditions and ranges    |
| Uses `case` values           | Uses conditions                   |
| Uses `break` to stop a case  | Does not need `break`             |
| Can have a `default` case    | Can have a final `else`           |
| Useful for menus and choices | Useful for comparisons and ranges |

### Example

A `switch` is suitable for:

```c id="switch_choice"
switch (choice) {
    case 1:
        printf("Add");
        break;

    case 2:
        printf("Delete");
        break;
}
```

An `if-else` is more suitable for:

```c id="if_range"
if (marks >= 90) {
    printf("A");
}
else if (marks >= 75) {
    printf("B");
}
```

## 10. `switch` with a Menu

A common use of `switch` is creating a simple menu.

### Example

```c id="menu_switch"
#include <stdio.h>

int main() {
    int choice = 2;

    printf("1. Start\n");
    printf("2. Settings\n");
    printf("3. Exit\n");

    switch (choice) {
        case 1:
            printf("Starting...");
            break;

        case 2:
            printf("Opening Settings...");
            break;

        case 3:
            printf("Exiting...");
            break;

        default:
            printf("Invalid choice");
    }

    return 0;
}
```

```output id="menu_switch_output"
1. Start
2. Settings
3. Exit
Opening Settings...
```

The value of `choice` is `2`, so the second case executes.

## 11. Real-World Example 🌍

Imagine a vending machine with different choices.

```c id="vending_switch"
#include <stdio.h>

int main() {
    int choice = 3;

    switch (choice) {
        case 1:
            printf("Water selected");
            break;

        case 2:
            printf("Juice selected");
            break;

        case 3:
            printf("Milk selected");
            break;

        default:
            printf("Invalid selection");
    }

```

```output id="vending_switch_output"

```

The program checks the selected number and performs the corresponding action.

## Common Mistakes ⚠️

### 1. Forgetting `break`

Without `break`, execution may continue into the next cases.

Example:

```c id="missing_break"
case 1:
    printf("One");

case 2:
    printf("Two");
```

If `case 1` matches, both messages can be printed.

---

### 2. Forgetting `default`

`default` is optional, but it is useful for handling unexpected values.

```c id="default_case"
default:
    printf("Invalid choice");
```

---

### 3. Using conditions inside `case`

A `case` normally specifies a fixed matching value.

For example:

```c id="fixed_case"
case 1:
```

For range-based conditions such as:

```text id="range_condition"
marks >= 75
```

an `if-else` ladder is generally more suitable.

---

### 4. Using duplicate case values

Two cases in the same `switch` cannot have the same value.

Avoid:

```c id="duplicate_case"
case 1:
    printf("One");

case 1:
    printf("Another One");
```

---

## Key Points 📌

* `switch` is used for selecting between multiple fixed choices.
* `case` specifies a possible matching value.
* `break` exits the `switch` after a case executes.
* Without `break`, execution can fall through to later cases.
* `default` runs when no case matches.
* A `switch` can work with values such as integers and characters.
* Multiple `case` labels can share the same block.
* `switch` is useful for menus and fixed choices.
* `if-else` is generally more suitable for ranges and complex conditions.
