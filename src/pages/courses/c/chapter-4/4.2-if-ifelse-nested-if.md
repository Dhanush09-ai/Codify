# Chapter 4: Conditions

## Section 2: `if`, `if-else` & Nested `if`

In the previous lesson, we learned how conditions help a program make decisions.

C provides different forms of the `if` statement for handling different situations:

* `if`
* `if-else`
* Nested `if`

These statements allow a program to execute different code depending on whether a condition is true or false.

---

## 1. The `if` Statement

The `if` statement executes a block of code **only when the condition is true**.

### Syntax

```c id="if_syntax"
if (condition) {
    // statements
}
```

If the condition is:

* **True** → the statements inside the block execute.
* **False** → the block is skipped.

### Example

```c id="simple_if"
#include <stdio.h>

int main() {
    int age = 20;

    if (age >= 18) {
        printf("You are an adult.");
    }

    return 0;
}
```

```output id="simple_if_output"
You are an adult.
```

The condition:

```text id="if_condition"
age >= 18
```

is true because `age` is `20`.

Therefore, the `printf()` statement is executed.

---

## 2. `if` with a False Condition

If the condition is false, the code inside the `if` block is not executed.

### Example

```c id="if_false"
#include <stdio.h>

int main() {
    int age = 15;

    if (age >= 18) {
        printf("You are an adult.");
    }

    return 0;
}
```

```output id="if_false_output"
```

The condition is false because `15` is not greater than or equal to `18`.

Therefore, nothing is printed.

---

## 3. The `if-else` Statement

Sometimes a program needs to perform one action when a condition is true and another action when it is false.

For this situation, we use `if-else`.

### Syntax

```c id="if_else_syntax"
if (condition) {
    // statements when condition is true
}
else {
    // statements when condition is false
}
```

There are two possible paths:

```text id="if_else_flow"
          Condition
          /      \
       True     False
        ↓          ↓
      if block   else block
```

### Example

```c id="if_else_example"
#include <stdio.h>

int main() {
    int marks = 65;

    if (marks >= 40) {
        printf("Pass");
    }
    else {
        printf("Fail");
    }

    return 0;
}
```

```output id="if_else_output"
Pass
```

Since `65 >= 40` is true, the `if` block executes.

---

## 4. `if-else` with a False Condition

Let's change the marks:

```c id="if_else_false"
#include <stdio.h>

int main() {
    int marks = 30;

    if (marks >= 40) {
        printf("Pass");
    }
    else {
        printf("Fail");
    }

    return 0;
}
```

```output id="if_else_false_output"
Fail
```

Here:

```text id="false_marks"
30 >= 40
```

is false.

Therefore, the `else` block executes.

## 5. Comparing Two Numbers

`if-else` can be used to compare two values.

### Example

```c id="compare_numbers"
#include <stdio.h>

int main() {
    int a = 25;
    int b = 15;

    if (a > b) {
        printf("a is greater");
    }
    else {
        printf("b is greater or equal");
    }

    return 0;
}
```

```output id="compare_numbers_output"
a is greater
```

The condition:

```text id="compare_condition"
a > b
```

is true because `25 > 15`.

---

## 6. Checking Even or Odd

Conditions can also be used with the modulus operator `%`.

If a number is divisible by `2`, it is even.

### Example

```c id="even_odd"
#include <stdio.h>

int main() {
    int number = 14;

    if (number % 2 == 0) {
        printf("Even");
    }
    else {
        printf("Odd");
    }

    return 0;
}
```

```output id="even_odd_output"
Even
```

Here:

```text id="even_calculation"
14 % 2 = 0
```

Therefore, the condition is true.

## 7. What is a Nested `if`?

An `if` statement placed inside another `if` statement is called a **nested `if`**.

It is useful when a second condition should be checked only after the first condition is true.

### Syntax

```c id="nested_if_syntax"
if (condition1) {

    if (condition2) {
        // statements
    }
}
```

The inner `if` is checked only when the outer `if` condition is true.

---

## 8. Simple Nested `if` Example

Suppose we want to check whether a person is an adult and then check whether they have an ID.

```c id="nested_if_example"
#include <stdio.h>

int main() {
    int age = 20;
    int has_id = 1;

    if (age >= 18) {

        if (has_id == 1) {
            printf("Access allowed.");
        }
    }

    return 0;
}
```

```output id="nested_if_output"
Access allowed.
```

First, C checks:

```text id="nested_first"
age >= 18
```

This is true.

Then it checks:

```text id="nested_second"
has_id == 1
```

This is also true.

Therefore, the message is printed.

---

## 9. Nested `if` When the Outer Condition is False

The inner `if` is not checked when the outer condition is false.

```c id="nested_outer_false"

int main() {

        }
    }

    return 0;
}
```

```output id="nested_outer_false_output"
```

The outer condition:

```text id="outer_false"
age >= 18
```

is false.

Therefore, the inner `if` is not executed.

## 10. Nested `if-else`

A nested `if` can also contain an `else` statement.

### Example

```c id="nested_if_else"
#include <stdio.h>

int main() {
    int marks = 75;

    if (marks >= 40) {

        if (marks >= 75) {
            printf("Excellent");
        }
        else {
            printf("Pass");
        }

    }
    else {
        printf("Fail");
    }

    return 0;
}
```

```output id="nested_if_else_output"
Excellent
```

The program first checks:

```text id="nested_marks"
marks >= 40
```

Since `75 >= 40` is true, it checks the inner condition:

```text id="nested_marks2"
marks >= 75
```

This is also true, so it prints:

```text id="nested_result"
Excellent
```

## 11. Difference Between `if` and `if-else`

| `if`                                     | `if-else`                            |
| ---------------------------------------- | ------------------------------------ |
| Executes code when the condition is true | Provides two possible paths          |
| Does nothing when the condition is false | Executes the `else` block when false |
| Used when only one action is required    | Used when there are two alternatives |

### Example

`if`:

```c id="if_only"
if (age >= 18) {
    printf("Adult");
}
```

`if-else`:

```c id="if_else_compare"
if (age >= 18) {
    printf("Adult");
}
else {
    printf("Minor");
}
```

---

## 12. Difference Between `if-else` and Nested `if`

An `if-else` is useful when there are **two alternatives**.

A nested `if` is useful when a second condition depends on the first condition being true.

### `if-else`

```text id="if_else_flow2"
Condition
 /     \
True   False
 ↓       ↓
Action  Action
```

### Nested `if`

```text id="nested_flow2"
First Condition
      ↓
    True
      ↓
Second Condition
   /       \
 True      False
  ↓          ↓
Action     Action
```

## 13. Real-World Example 🌍

Imagine a school system checking whether a student is eligible for an exam.

First, the program checks attendance.

If attendance is enough, it checks whether the student has paid the exam fee.

```c id="school_nested"
#include <stdio.h>

int main() {
    int attendance = 80;
    int fee_paid = 1;

    if (attendance >= 75) {

        if (fee_paid == 1) {
            printf("Student is eligible for the exam.");
        }
    }

    return 0;
}
```

```output id="school_nested_output"
Student is eligible for the exam.
```

The program performs the second check only after the attendance condition is satisfied.

## Common Mistakes ⚠️

### 1. Using `=` instead of `==`

Remember:

```c id="assignment_vs_equal"
=
```

assigns a value.

While:

```c id="comparison_equal"
==
```

compares two values.

Example:

```c id="correct_equal"
if (marks == 40) {
    printf("Marks are 40");
}
```

---

### 2. Forgetting the `else` braces

For multiple statements, use braces:

```c id="else_braces"
if (marks >= 40) {
    printf("Pass");
}
else {
    printf("Try again");
}
```

---

### 3. Confusing nested `if` with `if-else`

Nested `if` means an `if` statement is placed inside another `if`.

```c id="nested_difference"
if (condition1) {
    if (condition2) {
        printf("Both conditions are true");
    }
}
```

---

### 4. Incorrectly matching `else`

An `else` belongs to the nearest unmatched `if`.

Using braces makes the code easier to understand and prevents mistakes.

---

## Key Points 📌

* `if` executes a block when its condition is true.
* `if-else` provides two possible execution paths.
* `else` executes when the `if` condition is false.
* A **nested `if`** means an `if` statement inside another `if`.
* The inner condition of a nested `if` is checked only when the outer condition is true.
* Conditions commonly use relational and logical operators.
* Use `==` for comparison and `=` for assignment.
* Curly braces `{ }` make conditional blocks clear and easier to manage.
