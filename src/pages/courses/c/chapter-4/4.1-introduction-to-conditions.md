# Chapter 4: Conditions

## Section 1: Introduction to Conditions

Programs often need to make decisions.

For example:

* If a student scores 40 or more marks, they pass.
* If a number is greater than 0, it is positive.
* If the password is correct, access is allowed.
* If it is raining, you may carry an umbrella.

In C, **conditions** are used to make these decisions.

---

## 1. What is a Condition?

A **condition** is an expression that can be checked to determine whether something is **true or false**.

For example:

```c id="condition_basic"
age >= 18
```

This condition checks whether `age` is greater than or equal to `18`.

Another example:

```c id="condition_number"
number > 0
```

This checks whether `number` is greater than `0`.

---

## 2. True and False in C

C uses numbers to represent logical results.

* `0` means **false**
* Any non-zero value means **true**

For example:

```c id="true_false"
#include <stdio.h>

int main() {
    int a = 10;

    printf("%d\n", a > 5);
    printf("%d\n", a < 5);

    return 0;
}
```

```output id="true_false_output"
1
0
```

Here:

```text
10 > 5
```

is true, so C gives:

```text
1
```

And:

```text
10 < 5
```

is false, so C gives:

```text
0
```

---

## 3. Conditions Using Relational Operators

Relational operators are commonly used to create conditions.

| Operator | Meaning                  | Example  |
| -------- | ------------------------ | -------- |
| `>`      | Greater than             | `a > b`  |
| `<`      | Less than                | `a < b`  |
| `>=`     | Greater than or equal to | `a >= b` |
| `<=`     | Less than or equal to    | `a <= b` |
| `==`     | Equal to                 | `a == b` |
| `!=`     | Not equal to             | `a != b` |

### Example

```c id="relational_condition"
#include <stdio.h>

int main() {
    int marks = 75;

    printf("%d", marks >= 40);

    return 0;
}
```

```output id="relational_condition_output"
1
```

Because `75 >= 40` is true.

---

## 4. Why Do We Need Conditions?

Without conditions, a program would mostly execute instructions in the same order every time.

Conditions allow a program to **choose what to do based on a situation**.

For example:

```text
Marks >= 40
      ↓
   Condition
    /     \
  True    False
   ↓        ↓
 Pass      Fail
```

This is called **decision making**.

---

## 5. The `if` Statement

The `if` statement is one of the most basic ways to use a condition in C.

Syntax:

```c id="if_syntax"
if (condition) {
    // statements
}
```

If the condition is true, the statements inside the `{ }` are executed.

If the condition is false, they are skipped.

### Example

```c id="simple_if"
#include <stdio.h>

int main() {
    int age = 20;

    if (age >= 18) {
        printf("You are eligible.");
    }

    return 0;
}
```

```output id="simple_if_output"
You are eligible.
```

The condition:

```text id="f2x1me"
age >= 18
```

is true because `age` is `20`.

Therefore, the `printf()` statement runs.

---

## 6. What Happens When the Condition is False?

If the condition is false, the statements inside the `if` block are not executed.

### Example

```c id="false_condition"
#include <stdio.h>

int main() {
    int age = 15;

    if (age >= 18) {
        printf("You are eligible.");
    }

    return 0;
}
```

```output id="false_condition_output"
```

The condition:

```text id="l4xqpr"
age >= 18
```

is false because `age` is `15`.

Therefore, the `printf()` statement is skipped.

---

## 7. Conditions Using Variables

Conditions can use variables.

For example:

```c id="variable_condition"
#include <stdio.h>

int main() {
    int number = 25;

    if (number > 10) {
        printf("Number is greater than 10.");
    }

    return 0;
}
```

```output id="variable_condition_output"
Number is greater than 10.
```

Here, the value stored in `number` is compared with `10`.

---

## 8. Conditions Using Expressions

A condition can also contain an expression.

For example:

```c id="expression_condition"
#include <stdio.h>

int main() {
    int a = 10;
    int b = 5;

    if (a + b > 12) {
        printf("Condition is true.");
    }

    return 0;
}
```

```output id="expression_condition_output"
Condition is true.
```

First:

```text
10 + 5 = 15
```

Then:

```text
15 > 12
```

The condition is true.

---

## 9. Using Logical Operators in Conditions

Logical operators can combine multiple conditions.

The main logical operators are:

| Operator | Meaning |   |    |
| -------- | ------- | - | -- |
| `&&`     | AND     |   |    |
| `        |         | ` | OR |
| `!`      | NOT     |   |    |

### Example Using `&&`

```c id="logical_and_condition"
#include <stdio.h>

int main() {
    int age = 20;
    int has_id = 1;

    if (age >= 18 && has_id == 1) {
        printf("Access allowed.");
    }

    return 0;
}
```

```output id="logical_and_condition_output"
Access allowed.
```

Both conditions are true:

```text
age >= 18
```

and

```text
has_id == 1
```

Therefore, the complete condition is true.

---

## 10. `if` Block

The statements controlled by an `if` condition are placed inside curly braces `{ }`.

Example:

```c id="if_block"
if (marks >= 40) {
    printf("Pass");
    printf("Good job");
}
```

Both statements belong to the `if` block.

If the condition is true, both statements execute.

It is good practice to use braces even when there is only one statement.

---

## 11. Real-World Example 🌍

Imagine a shopping application that checks whether a customer has enough money to buy a product.

```c id="shopping_condition"
#include <stdio.h>

int main() {
    int balance = 500;
    int price = 350;

    if (balance >= price) {
        printf("Purchase allowed.");
    }

    return 0;
}
```

```output id="shopping_condition_output"
Purchase allowed.
```

The program checks:

```text
balance >= price
```

Since:

```text
500 >= 350
```

is true, the purchase is allowed.

## Common Mistakes ⚠️

### 1. Using `=` instead of `==`

Remember:

```c
=
```

is the **assignment operator**.

While:

```c
==
```

checks whether two values are equal.

Example:

```c id="equal_comparison"
if (a == 10) {
    printf("a is 10");
}
```

---

### 2. Forgetting parentheses

An `if` condition should be written inside parentheses:

```c
if (age >= 18) {
    printf("Adult");
}
```

---

### 3. Forgetting braces

For multiple statements, use braces:

```c id="braces_example"
if (marks >= 40) {
    printf("Pass");
    printf("Congratulations");
}
```

---

### 4. Confusing `0` and non-zero values

In C:

```text
0       → false
non-zero → true
```

For example:

```c id="zero_nonzero"
if (1) {
    printf("True");
}
```

The condition is true because `1` is non-zero.

---

## Key Points 📌

* A **condition** is used to make a decision.
* A condition can be **true or false**.
* In C, `0` represents false.
* Any non-zero value represents true.
* Relational operators are commonly used to create conditions.
* The `if` statement executes code when its condition is true.
* `&&`, `||`, and `!` can be used to combine or modify conditions.
* Use `==` to compare values and `=` to assign a value.
* Curly braces `{ }` define the statements inside a block.
