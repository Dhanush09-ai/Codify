# Chapter 5: Loops

## Section 1: Introduction to Loops

A **loop** is used to execute a block of code repeatedly.

For example, if we want to print `"Hello"` 5 times, we could write `printf()` five times. But this becomes difficult when we need to repeat something many times.

Loops allow us to write the code once and execute it multiple times.

### 1. Why Do We Need Loops?

Without a loop, printing numbers from 1 to 5 would require multiple statements:

```c id="v9q3lm"
#include <stdio.h>

int main() {
    printf("1\n");
    printf("2\n");
    printf("3\n");
    printf("4\n");
    printf("5\n");

    return 0;
}
```

This works, but it is repetitive.

With a loop, the same task can be written more efficiently.

```c id="x7k2pa"
#include <stdio.h>

int main() {
    int i;

    for (i = 1; i <= 5; i++) {
        printf("%d\n", i);
    }

    return 0;
}
```

```output id="m4r8tc"
1
2
3
4
5
```

The loop repeats the `printf()` statement until the condition becomes false.

### 2. How Does a Loop Work?

A loop generally has three important parts:

1. **Initialization** – gives the loop variable its starting value.
2. **Condition** – decides whether the loop should continue.
3. **Update** – changes the loop variable after each repetition.

For example:

```c id="q2w8ne"
for (i = 1; i <= 5; i++) {
    printf("%d\n", i);
}
```

Here:

* `i = 1` → Initialization
* `i <= 5` → Condition
* `i++` → Update
* `printf()` → Code that is repeated

### 3. Types of Loops in C

C provides three main types of loops:

| Loop            | Description                                                   |
| --------------- | ------------------------------------------------------------- |
| `for` loop      | Useful when the number of repetitions is known                |
| `while` loop    | Useful when a condition controls the repetition               |
| `do-while` loop | Executes the code at least once before checking the condition |

We will learn each type of loop in the following sections.

### 4. Repeating an Operation

Loops are useful when the same operation needs to be performed many times.

For example, calculating the square of numbers from 1 to 5:

```c id="a6v3ks"
#include <stdio.h>

int main() {
    int i;

    for (i = 1; i <= 5; i++) {
        printf("%d ", i * i);
    }

    return 0;
}
```

```output id="c8y5rp"
1 4 9 16 25
```

The same calculation is performed for each value of `i`.

### 5. Loop Condition

The condition determines whether the loop continues.

Consider:

```c id="n3f7bd"
int i = 1;

while (i <= 3) {
    printf("%d ", i);
    i++;
}
```

```output id="p5j9wx"
1 2 3
```

The loop continues while `i <= 3`.

When `i` becomes `4`, the condition becomes false and the loop stops.

### 6. Infinite Loop

An **infinite loop** is a loop that never stops because its condition always remains true.

For example:

```c id="t6h2mv"
while (1) {
    printf("Hello");
}
```

Here, `1` is always true, so the loop continues forever.

Infinite loops can be useful in some programs, but they should be used carefully.

### 7. Real-World Example 🌍

Imagine a school attendance system that needs to process the attendance of 50 students.

Instead of writing the same code 50 times, a loop can repeat the operation for each student.

For example:

```c id="r8k4zs"
#include <stdio.h>

int main() {
    int student;

    for (student = 1; student <= 5; student++) {
        printf("Checking student %d\n", student);
    }

    return 0;
}
```

```output id="u2c7qa"
Checking student 1
Checking student 2
Checking student 3
Checking student 4
Checking student 5
```

The same idea can be used for a larger number of students.

## Common Mistakes

### Mistake 1: Forgetting the Update

Be careful to update the loop variable.

```c
int i = 1;

while (i <= 5) {
    printf("%d ", i);
}
```

The value of `i` never changes, so the loop does not reach its stopping condition.

Correct:

```c
int i = 1;

while (i <= 5) {
    printf("%d ", i);
    i++;
}
```

### Mistake 2: Using the Wrong Condition

Always check whether the condition allows the required number of repetitions.

For example:

```c
i < 5
```

runs for `1, 2, 3, 4`, while:

```c
i <= 5
```

runs for `1, 2, 3, 4, 5`.

### Mistake 3: Creating an Unintended Infinite Loop

Make sure the loop variable eventually reaches a value that makes the condition false.

## Key Points

* A loop repeats a block of code.
* Loops reduce repetitive code.
* C has three main loops: `for`, `while`, and `do-while`.
* A loop usually has initialization, a condition, and an update.
* The condition controls whether the loop continues.
* The loop variable should normally change so the loop can eventually stop.
* An infinite loop continues without reaching a stopping condition.
