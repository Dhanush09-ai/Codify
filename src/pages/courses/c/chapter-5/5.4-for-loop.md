# Chapter 5: Loops

## Section 4: for Loop

The **`for` loop** is used to repeat a block of code a specific number of times.

It is especially useful when we know how many times the loop should run.

For example, if we want to print numbers from `1` to `10`, a `for` loop can do this using only a few lines of code.

### 1. Syntax of for Loop

The basic syntax is:

```c id="f7k2ma"
for (initialization; condition; update) {
    // code to repeat
}
```

A `for` loop has three main parts:

1. **Initialization** – runs once at the beginning.
2. **Condition** – checked before every iteration.
3. **Update** – changes the loop variable after each iteration.

For example:

```c id="p4x9wc"
for (int i = 1; i <= 5; i++) {
    printf("%d ", i);
}
```

Here:

* `int i = 1` → Initialization
* `i <= 5` → Condition
* `i++` → Update

### 2. Simple Example

Let's print numbers from 1 to 5.

```c id="m6q3rt"
#include <stdio.h>

int main() {
    int i;

    for (i = 1; i <= 5; i++) {
        printf("%d ", i);
    }

    return 0;
}
```

```output id="v8n5ka"
1 2 3 4 5
```

The loop starts with `i = 1` and continues while `i <= 5`.

### 3. How for Loop Works

Consider:

```c id="c2w7ep"
for (i = 1; i <= 3; i++) {
    printf("%d ", i);
}
```

The execution happens like this:

| Step | Value of `i` | Condition        | Action    |
| ---- | -----------: | ---------------- | --------- |
| 1    |            1 | `1 <= 3` → true  | Print `1` |
| 2    |            2 | `2 <= 3` → true  | Print `2` |
| 3    |            3 | `3 <= 3` → true  | Print `3` |
| 4    |            4 | `4 <= 3` → false | Stop      |

The initialization happens only once. The condition and update are handled during the loop execution.

### 4. Printing Numbers in Reverse

We can use `i--` to decrease the loop variable.

```c id="r5j8hd"
#include <stdio.h>

int main() {
    int i;

    for (i = 5; i >= 1; i--) {
        printf("%d ", i);
    }

    return 0;
}
```

```output id="t3y6qb"
5 4 3 2 1
```

Here, the loop starts at `5` and decreases `i` after each iteration.

### 5. Printing Even Numbers

A `for` loop can be used to print even numbers.

```c id="n7p4sx"
#include <stdio.h>

int main() {
    int i;

    for (i = 2; i <= 10; i += 2) {
        printf("%d ", i);
    }

    return 0;
}
```

```output id="k9m2vf"
2 4 6 8 10
```

The update `i += 2` increases the value by `2` each time.

### 6. Calculating a Sum

We can use a `for` loop to calculate the sum of numbers.

```c id="w4c8za"
#include <stdio.h>

int main() {
    int i;
    int sum = 0;

    for (i = 1; i <= 5; i++) {
        sum = sum + i;
    }

    printf("Sum = %d", sum);

    return 0;
}
```

```output id="d6r3yp"
Sum = 15
```

The loop calculates:

`1 + 2 + 3 + 4 + 5 = 15`

### 7. for Loop Without Braces

If a loop contains only one statement, braces can be omitted.

For example:

```c id="h8v5qn"
for (int i = 1; i <= 5; i++)
    printf("%d ", i);
```

This is valid C code.

However, braces are usually easier to read and safer when adding more statements later.

```c id="b3k7wm"
for (int i = 1; i <= 5; i++) {
    printf("%d ", i);
}
```

### 8. for Loop vs while Loop

Both `for` and `while` loops can perform repeated operations.

For example, this `for` loop:

```c id="q5x2na"
for (int i = 1; i <= 5; i++) {
    printf("%d ", i);
}
```

Can be written using a `while` loop:

```c id="s9m4kc"
int i = 1;

while (i <= 5) {
    printf("%d ", i);
    i++;
}
```

A `for` loop is often convenient when initialization, condition, and update are closely related.

### 9. Real-World Example 🌍

Imagine a school system that needs to display the roll numbers of students from `1` to `10`.

A `for` loop can easily repeat the operation:

```c id="u6r8pf"
#include <stdio.h>

int main() {
    int rollNumber;

    for (rollNumber = 1; rollNumber <= 10; rollNumber++) {
        printf("Student Roll Number: %d\n", rollNumber);
    }

    return 0;
}
```

```output id="e2v5ls"
Student Roll Number: 1
Student Roll Number: 2
Student Roll Number: 3
Student Roll Number: 4
Student Roll Number: 5
Student Roll Number: 6
Student Roll Number: 7
Student Roll Number: 8
Student Roll Number: 9
Student Roll Number: 10
```

## Common Mistakes

### Mistake 1: Forgetting the Update

Be careful when writing the update expression.

For example:

```c id="y7n3qd"
for (int i = 1; i <= 5;) {
    printf("%d ", i);
}
```

The value of `i` never changes, so the loop can become infinite.

Correct:

```c id="z4k8ma"
for (int i = 1; i <= 5; i++) {
    printf("%d ", i);
}
```

### Mistake 2: Using the Wrong Condition

Compare these two conditions:

```c id="a5w9rc"
i < 5
```

and:

```c id="j3p6vf"
i <= 5
```

The first stops before `5`, while the second includes `5`.

### Mistake 3: Putting a Semicolon After the for Statement

Be careful with:

```c id="m8q2tx"
for (int i = 1; i <= 5; i++);
{
    printf("%d ", i);
}
```

The semicolon makes the loop body empty and can cause unexpected behavior.

Normally, write:

```c id="c6v4yp"
for (int i = 1; i <= 5; i++) {
    printf("%d ", i);
}
```

## Key Points

* The `for` loop is used to repeat a block of code.
* It is useful when the number of repetitions is known or controlled by a counter.
* A `for` loop has initialization, condition, and update.
* Initialization runs once at the beginning.
* The condition is checked before each iteration.
* The update runs after each iteration.
* `i++` increases a value by `1`.
* `i--` decreases a value by `1`.
* `i += 2` increases a value by `2`.
* Forgetting to update the loop variable can cause an infinite loop.
