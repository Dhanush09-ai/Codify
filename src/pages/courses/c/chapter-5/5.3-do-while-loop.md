# Chapter 5: Loops

## Section 3: do-while Loop

The **`do-while` loop** is used to execute a block of code repeatedly while a condition is true.

The main difference between a `while` loop and a `do-while` loop is that a `do-while` loop executes its code **at least once** before checking the condition.

### 1. Syntax of do-while Loop

The basic syntax is:

```c id="m7q2ka"
do {
    // code to repeat
} while (condition);
```

Notice that the `do-while` loop has a **semicolon (`;`)** after the condition.

The execution works like this:

1. The code inside `do` is executed.
2. The condition is checked.
3. If the condition is true, the loop runs again.
4. If the condition is false, the loop stops.

### 2. Simple Example

Let's print numbers from 1 to 5.

```c id="p4x8nd"
#include <stdio.h>

int main() {
    int i = 1;

    do {
        printf("%d ", i);
        i++;
    } while (i <= 5);

    return 0;
}
```

```output id="r6v3tz"
1 2 3 4 5
```

The loop prints the value and then checks whether `i <= 5`.

### 3. do-while Executes at Least Once

Consider this example:

```c id="c8w5hs"
#include <stdio.h>

int main() {
    int i = 10;

    do {
        printf("%d", i);
    } while (i < 5);

    return 0;
}
```

```output id="y2k9pf"
10
```

The condition `i < 5` is false, but the value `10` is still printed.

This happens because the `do` block executes **before** the condition is checked.

### 4. while vs do-while

The main difference is when the condition is checked.

#### while Loop

```c id="f5n3qa"
int i = 10;

while (i < 5) {
    printf("%d", i);
}
```

The condition is checked first, so the code executes **zero times**.

#### do-while Loop

```c id="j8v4mc"
int i = 10;

do {
    printf("%d", i);
} while (i < 5);
```

The code executes **once** before the condition is checked.

| Feature                   | `while`              | `do-while`          |
| ------------------------- | -------------------- | ------------------- |
| Condition checked         | Before the loop body | After the loop body |
| Minimum executions        | 0                    | 1                   |
| Semicolon after condition | No                   | Yes                 |

### 5. Using do-while for Repeated Input

A `do-while` loop is useful when an action should happen at least once.

For example, we can ask the user to enter a positive number and continue asking while the number is not positive.

```c id="v9k6rb"
#include <stdio.h>

int main() {
    int number;

    do {
        printf("Enter a positive number: ");
        scanf("%d", &number);
    } while (number <= 0);

    printf("You entered: %d", number);

    return 0;
}
```

The user is asked for input at least once.

### 6. Printing Numbers in Reverse

A `do-while` loop can also be used to print numbers in reverse.

```c id="n4t7wx"
#include <stdio.h>

int main() {
    int i = 5;

    do {
        printf("%d ", i);
        i--;
    } while (i >= 1);

    return 0;
}
```

```output id="b3q8lm"
5 4 3 2 1
```

### 7. Simple Menu Example

A common use of the `do-while` loop is a menu that should be displayed at least once.

```c id="s6p2ye"
#include <stdio.h>

int main() {
    int choice;

    do {
        printf("\n1. Start");
        printf("\n2. Exit");
        printf("\nEnter your choice: ");
        scanf("%d", &choice);

    } while (choice != 2);

    printf("\nProgram ended.");

    return 0;
}
```

The menu is displayed first and then the choice is checked.

### 8. Real-World Example 🌍

Imagine an ATM menu.

When a user enters an ATM, the menu should be shown at least once. After completing an operation, the menu can be displayed again until the user chooses to exit.

A `do-while` loop is suitable for this type of situation because the menu must appear at least once.

## Common Mistakes

### Mistake 1: Forgetting the Semicolon

Incorrect:

```c id="q5m8vx"
do {
    printf("Hello");
} while (i < 5)
```

Correct:

```c id="e7r3ka"
do {
    printf("Hello");
} while (i < 5);
```

A `do-while` statement requires a semicolon after the condition.

### Mistake 2: Thinking the Condition Is Checked First

Remember:

```c id="h2w6pd"
do {
    // runs first
} while (condition);
```

The loop body runs before the condition is checked.

### Mistake 3: Forgetting to Update the Loop Variable

For example:

```c id="u8c4zn"
int i = 1;

do {
    printf("%d ", i);
} while (i <= 5);
```

The value of `i` never changes, so the condition remains true.

If an update is required, use:

```c id="a3k9wf"
i++;
```

inside the loop.

## Key Points

* The `do-while` loop executes the loop body before checking the condition.
* A `do-while` loop executes **at least once**.
* The condition is checked after each iteration.
* A semicolon is required after the `while` condition.
* It is useful for menus and situations where an action must happen at least once.
* The loop variable should be updated when necessary to avoid an unintended infinite loop.
