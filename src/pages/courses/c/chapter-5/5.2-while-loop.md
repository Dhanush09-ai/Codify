# Chapter 5: Loops

## Section 2: while Loop

The **`while` loop** is used to repeatedly execute a block of code as long as a condition is true.

It is useful when we do not know exactly how many times the loop should run beforehand.

### 1. Syntax of while Loop

The basic syntax is:

```c id="q1w7ea"
while (condition) {
    // code to repeat
}
```

The condition is checked before each iteration.

* If the condition is **true**, the code inside the loop runs.
* If the condition is **false**, the loop stops.

### 2. Simple Example

Let's print numbers from 1 to 5.

```c id="m8r2kp"
#include <stdio.h>

int main() {
    int i = 1;

    while (i <= 5) {
        printf("%d ", i);
        i++;
    }

    return 0;
}
```

```output id="v5t9cx"
1 2 3 4 5
```

Here:

* `i = 1` initializes the variable.
* `i <= 5` is the condition.
* `i++` increases `i` after each iteration.

### 3. How while Loop Works

Consider this code:

```c id="d3k6qa"
int i = 1;

while (i <= 3) {
    printf("%d ", i);
    i++;
}
```

The execution happens like this:

| Iteration | `i` | Condition        | Output     |
| --------- | --: | ---------------- | ---------- |
| 1         |   1 | `1 <= 3` → true  | `1`        |
| 2         |   2 | `2 <= 3` → true  | `2`        |
| 3         |   3 | `3 <= 3` → true  | `3`        |
| 4         |   4 | `4 <= 3` → false | Loop stops |

The condition is checked before every iteration.

### 4. Printing Numbers in Reverse

A `while` loop can also be used to print numbers in reverse order.

```c id="f7n2wm"
#include <stdio.h>

int main() {
    int i = 5;

    while (i >= 1) {
        printf("%d ", i);
        i--;
    }

    return 0;
}
```

```output id="k4p8zs"
5 4 3 2 1
```

Here, `i--` decreases the value of `i` after every iteration.

### 5. Calculating a Sum

We can use a `while` loop to calculate the sum of numbers.

```c id="b6r3yt"
#include <stdio.h>

int main() {
    int i = 1;
    int sum = 0;

    while (i <= 5) {
        sum = sum + i;
        i++;
    }

    printf("Sum = %d", sum);

    return 0;
}
```

```output id="n9c5vx"
Sum = 15
```

The loop adds:

`1 + 2 + 3 + 4 + 5 = 15`

### 6. Reading Input Until a Condition

A `while` loop can be useful when we want to continue processing until a particular condition is reached.

For example, we can keep reading numbers until the user enters `0`.

```c id="s2j8hf"
#include <stdio.h>

int main() {
    int number;

    printf("Enter numbers (0 to stop): ");
    scanf("%d", &number);

    while (number != 0) {
        printf("You entered %d\n", number);
        scanf("%d", &number);
    }

    return 0;
}
```

If the user enters `0`, the condition `number != 0` becomes false and the loop stops.

### 7. while Loop and Initial Condition

The `while` loop may execute **zero times** if its condition is false from the beginning.

```c id="e5x1ru"
#include <stdio.h>

int main() {
    int i = 10;

    while (i < 5) {
        printf("%d ", i);
        i++;
    }

    return 0;
}
```

There is no output because `10 < 5` is false before the first iteration.

### 8. Real-World Example 🌍

Imagine a simple login system that allows a user to keep entering a PIN until the correct PIN is entered.

A `while` loop can represent this repeated checking process.

```c id="h7m4pc"
#include <stdio.h>

int main() {
    int pin = 0;
    int correctPin = 1234;

    while (pin != correctPin) {
        printf("Enter PIN: ");
        scanf("%d", &pin);
    }

    printf("Access granted");

    return 0;
}
```

The loop continues while the entered PIN is incorrect.

## Common Mistakes

### Mistake 1: Forgetting to Update the Variable

Incorrect:

```c id="x3q9lv"
int i = 1;

while (i <= 5) {
    printf("%d ", i);
}
```

The value of `i` never changes, so the condition remains true.

Correct:

```c id="p8d2ka"
int i = 1;

while (i <= 5) {
    printf("%d ", i);
    i++;
}
```

### Mistake 2: Using the Wrong Condition

Make sure the condition matches the required range.

For example:

```c id="j6v4qs"
while (i < 5)
```

does not include `5`.

But:

```c id="w2n8fe"
while (i <= 5)
```

includes `5`.

### Mistake 3: Forgetting to Initialize the Variable

The loop variable should have a valid starting value before the loop.

Correct:

```c id="c7r5md"
int i = 1;

while (i <= 5) {
    printf("%d ", i);
    i++;
}
```

## Key Points

* The `while` loop repeats code while a condition is true.
* The condition is checked **before** each iteration.
* A `while` loop can execute zero times.
* The loop variable should usually be initialized before the loop.
* The loop variable should be updated inside the loop when needed.
* Forgetting the update can create an unintended infinite loop.
* `while` loops are useful when the number of repetitions is not known in advance.
