# Chapter 2: C Basics

## Section 1: Keywords, Identifiers & Comments

In C, keywords, identifiers, and comments are basic building blocks of a program.

Understanding them helps you write clean and correct C programs.

### 1. What are Keywords?

Keywords are **reserved words** in C that have a special meaning to the compiler.

You cannot use a keyword as a variable, function, or other user-defined name.

Some common C keywords are:

| Keyword  | Purpose                            |
| -------- | ---------------------------------- |
| `int`    | Defines an integer data type       |
| `float`  | Defines a floating-point data type |
| `char`   | Defines a character data type      |
| `if`     | Used for decision making           |
| `else`   | Used with `if`                     |
| `for`    | Used for looping                   |
| `while`  | Used for looping                   |
| `return` | Returns a value from a function    |
| `void`   | Represents no value                |
| `struct` | Defines a structure                |

For example:

```c
#include <stdio.h>

int main()
{
    int age = 16;

    printf("Age = %d", age);

    return 0;
}
```

```output
Age = 16
```

Here, `int` and `return` are keywords.

### 2. Rules for Keywords

Keywords have fixed meanings in C.

For example:

```c
int number = 10;
```

Here, `int` must be used as the data type.

You cannot use it as a variable name:

```c
int int = 10;
```

This produces a compilation error because `int` is a reserved keyword.

### 3. What are Identifiers?

Identifiers are names given by the programmer to different elements of a program.

They can be used for:

* Variables
* Functions
* Arrays
* Structures
* Other user-defined elements

Example:

```c
#include <stdio.h>

int main()
{
    int marks = 85;

    printf("Marks = %d", marks);

    return 0;
}
```

```output
Marks = 85
```

Here, `marks` is an identifier.

### 4. Rules for Identifiers

There are some rules for creating identifiers in C.

#### Rule 1: Use Letters, Digits, and Underscore

An identifier can contain:

* Letters (`A-Z`, `a-z`)
* Digits (`0-9`)
* Underscore (`_`)

Example:

```c
int student1;
int student_marks;
```

#### Rule 2: Do Not Start with a Digit

Incorrect:

```c
int 1student;
```

Correct:

```c
int student1;
```

#### Rule 3: Spaces Are Not Allowed

Incorrect:

```c
int student marks;
```

Correct:

```c
int student_marks;
```

#### Rule 4: Keywords Cannot Be Used

Incorrect:

```c
int return;
```

`return` is a C keyword, so it cannot be used as an identifier.

#### Rule 5: C is Case-Sensitive

These are different identifiers:

```c
int age;
int Age;
int AGE;
```

C treats `age`, `Age`, and `AGE` as different names.

### 5. Valid and Invalid Identifiers

| Identifier     | Valid? | Reason                                       |
| -------------- | ------ | -------------------------------------------- |
| `age`          | Yes    | Valid name                                   |
| `student_name` | Yes    | Underscore is allowed                        |
| `marks1`       | Yes    | Digits are allowed after the first character |
| `_value`       | Yes    | Can start with underscore                    |
| `1marks`       | No     | Cannot start with a digit                    |
| `student name` | No     | Spaces are not allowed                       |
| `float`        | No     | `float` is a keyword                         |

### 6. What are Comments?

Comments are notes written inside a program to explain the code.

The compiler ignores comments during program execution.

Comments are useful for:

* Explaining code
* Making programs easier to understand
* Adding notes
* Temporarily disabling code

C supports two types of comments:

1. Single-line comments
2. Multi-line comments

### 7. Single-Line Comments

A single-line comment starts with `//`.

```c
#include <stdio.h>

int main()
{
    // Display a message
    printf("Hello, C!");

    return 0;
}
```

```output
Hello, C!
```

Everything after `//` on that line is treated as a comment.

### 8. Multi-Line Comments

A multi-line comment starts with `/*` and ends with `*/`.

```c
#include <stdio.h>

int main()
{
    /*
       This program
       displays a message.
    */

    printf("Learning C");

    return 0;
}
```

```output
Learning C
```

Multi-line comments can extend across several lines.

### 9. Using Comments to Explain Code

Comments can make a program easier to understand.

```c
#include <stdio.h>

int main()
{
    // Store the student's marks
    int marks = 90;

    // Display the marks
    printf("Marks = %d", marks);

    return 0;
}
```

```output
Marks = 90
```

The comments explain what each part of the program does, but they do not affect the output.

### 10. Keywords vs Identifiers vs Comments

| Feature          | Keywords       | Identifiers              | Comments           |
| ---------------- | -------------- | ------------------------ | ------------------ |
| Meaning          | Reserved words | Programmer-defined names | Notes in the code  |
| Created by       | C language     | Programmer               | Programmer         |
| Used by compiler | Yes            | Yes                      | Ignored            |
| Example          | `int`          | `marks`                  | `// Display marks` |

## Real-World Example 🌍

Suppose you are writing a program to store a student's details.

```c
#include <stdio.h>

int main()
{
    // Store student information
    int studentAge = 16;
    int studentMarks = 85;

    printf("Age = %d\n", studentAge);
    printf("Marks = %d", studentMarks);

    return 0;
}
```

```output
Age = 16
Marks = 85
```

Here:

* `int` and `return` are **keywords**.
* `studentAge` and `studentMarks` are **identifiers**.
* `// Store student information` is a **comment**.

## Key Points

* Keywords are reserved words with special meanings in C.
* Keywords cannot be used as identifiers.
* Identifiers are names created by the programmer.
* Identifiers can contain letters, digits, and underscores.
* An identifier cannot start with a digit.
* Spaces are not allowed in identifiers.
* C is case-sensitive.
* Comments are ignored by the compiler.
* `//` is used for single-line comments.
* `/* */` is used for multi-line comments.
