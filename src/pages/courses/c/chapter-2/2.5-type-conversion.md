# Chapter 2: Variables and Data

## Section 5: Type Conversion

**Type conversion** means changing a value from one data type to another data type.

For example, we can convert an `int` value into a `float`.

```c
int number = 10;
float value = (float)number;
```

Here, the integer value `10` is converted to a `float`.

There are two common types of type conversion in C:

1. Implicit Type Conversion
2. Explicit Type Conversion

---

## 1. Implicit Type Conversion

**Implicit type conversion** happens automatically by the C compiler.

We do not need to write any special conversion code.

For example:

```c
#include <stdio.h>

int main()
{
    int number = 10;
    float value = number;

    printf("Number = %d\n", number);
    printf("Value = %.1f", value);

    return 0;
}
```

```output
Number = 10
Value = 10.0
```

Here, the `int` value `10` is automatically converted to a `float`.

The compiler performs the conversion because `float` can store the integer value.

---

## 2. Explicit Type Conversion

**Explicit type conversion** is when we manually tell C to convert a value into another data type.

This is also called **type casting**.

The basic syntax is:

```c
(data_type)value
```

For example:

```c
float result = (float)10;
```

Here, `(float)` tells C to convert `10` into a `float`.

---

## 3. Converting `int` to `float`

We can use type casting to convert an integer into a decimal value.

```c
#include <stdio.h>

int main()
{
    int number = 10;

    float value = (float)number;

    printf("Value = %.1f", value);

    return 0;
}
```

```output
Value = 10.0
```

The `(float)` tells the compiler to treat `number` as a floating-point value.

---

## 4. Type Conversion in Division

Type conversion is especially useful when performing division.

Consider this program:

```c
#include <stdio.h>

int main()
{
    int a = 5;
    int b = 2;

    float result = a / b;

    printf("Result = %.1f", result);

    return 0;
}
```

```output
Result = 2.0
```

Why is the result `2.0` instead of `2.5`?

Because both `a` and `b` are integers.

So:

```c
a / b
```

performs integer division first, producing `2`.

Then the result is stored in the `float` variable.

We can use type casting to get the decimal result.

```c
#include <stdio.h>

int main()
{
    int a = 5;
    int b = 2;

    float result = (float)a / b;

    printf("Result = %.1f", result);

    return 0;
}
```

```output
Result = 2.5
```

Here, `(float)a` converts `a` to a floating-point value before division.

Therefore:

```text
5.0 / 2 = 2.5
```

---

## 5. Converting `float` to `int`

We can also convert a `float` value into an `int`.

For example:

```c
#include <stdio.h>

int main()
{
    float number = 10.75;

    int value = (int)number;

    printf("Value = %d", value);

    return 0;
}
```

```output
Value = 10
```

The decimal part is removed when the value is converted to an integer.

So:

```text
10.75 → 10
```

This does not round the value to the nearest integer.

---

## 6. Converting `char` to `int`

A `char` can also be converted to an integer.

Characters are represented internally using numeric character codes.

For example:

```c
#include <stdio.h>

int main()
{
    char ch = 'A';

    int value = (int)ch;

    printf("Character = %c\n", ch);
    printf("Value = %d", value);

    return 0;
}
```

```output
Character = A
Value = 65
```

The numeric value shown depends on the character encoding used by the system.

---

## Real-World Example 🌍

Suppose a program needs to calculate the average of two marks.

The marks are stored as integers:

```c
#include <stdio.h>

int main()
{
    int mark1 = 85;
    int mark2 = 90;

    float average;

    average = (float)(mark1 + mark2) / 2;

    printf("Average = %.2f", average);

    return 0;
}
```

```output
Average = 87.50
```

The type conversion makes sure that the division can produce a decimal result.

---

## Common Mistakes

### Forgetting Type Conversion During Integer Division

If both values are integers:

```c
int a = 5;
int b = 2;

float result = a / b;
```

The division happens using integers first, so the result is `2`.

To get `2.5`, convert one value:

```c
float result = (float)a / b;
```

---

### Expecting `float` to Round When Converting to `int`

For example:

```c
float number = 9.8;
int value = (int)number;
```

The result is:

```text
9
```

The decimal part is discarded.

---

### Using the Wrong Type

Choose the target data type carefully.

For example:

```c
int value = (int)10.5;
```

This removes the decimal part.

If the decimal part is needed, use a floating-point type instead.

---

## Key Points

* Type conversion means changing a value from one data type to another.
* **Implicit conversion** happens automatically.
* **Explicit conversion** is performed manually by the programmer.
* Explicit conversion is also called **type casting**.
* The syntax for type casting is `(data_type)value`.
* Type conversion is useful when performing calculations with different data types.
* Converting `float` to `int` removes the decimal part.
* Type casting can be important when performing division.
* Converting one operand to `float` can produce a decimal division result.
