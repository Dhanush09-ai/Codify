# Chapter 2: Variables and Data

## Section 3: Data Types

A **data type** tells the C compiler what kind of data a variable can store.

For example, a variable may store an integer, decimal number, character, or other type of data.

Choosing the correct data type helps the compiler understand how the data should be stored and used.

---

### 1. Why Do We Need Data Types?

When we create a variable, we need to tell C what type of value it will store.

For example:

```c
int age = 16;
```

Here, `int` tells C that `age` will store an integer value.

Another example:

```c
float price = 99.50;
```

Here, `float` tells C that `price` can store a decimal value.

---

### 2. Common Data Types in C

Some commonly used C data types are:

| Data Type | Used For              | Example    |
| --------- | --------------------- | ---------- |
| `int`     | Integer numbers       | `10`       |
| `float`   | Decimal numbers       | `10.5`     |
| `double`  | Larger decimal values | `10.56789` |
| `char`    | A single character    | `'A'`      |

Let's understand each one.

---

### 3. int Data Type

The `int` data type is used to store **whole numbers**.

Whole numbers do not contain a decimal point.

For example:

```c
#include <stdio.h>

int main()
{
    int age = 16;

    printf("Age = %d", age);

    return 0;
}
```

```output
Age = 16
```

Here:

* `int` is the data type.
* `age` is the variable.
* `16` is the value stored in the variable.
* `%d` is used to print an integer.

Other examples of integer values:

```text
0
10
25
100
-50
```

---

### 4. float Data Type

The `float` data type is used to store **decimal numbers**.

For example:

```c
#include <stdio.h>

int main()
{
    float price = 99.50;

    printf("Price = %.2f", price);

    return 0;
}
```

```output
Price = 99.50
```

Here, `price` stores a decimal value.

The format specifier `%.2f` displays the value with two digits after the decimal point.

Another example:

```c
float temperature = 36.5;
```

---

### 5. double Data Type

The `double` data type is also used to store decimal numbers.

It generally provides more precision than `float`.

For example:

```c
#include <stdio.h>

int main()
{
    double distance = 12345.6789;

    printf("Distance = %.4f", distance);

    return 0;
}
```

```output
Distance = 12345.6789
```

`double` is useful when more decimal precision is needed.

For example:

```c
double pi = 3.1415926535;
```

---

### 6. char Data Type

The `char` data type is used to store a **single character**.

A character is written inside single quotes `' '`.

For example:

```c
#include <stdio.h>

int main()
{
    char grade = 'A';

    printf("Grade = %c", grade);

    return 0;
}
```

```output
Grade = A
```

Here:

* `char` is the data type.
* `grade` is the variable.
* `'A'` is the character stored in the variable.
* `%c` is used to print a character.

Examples of characters:

```text
'A'
'B'
'7'
'@'
'#'
```

A `char` variable stores one character, not a complete word.

---

### 7. Different Data Types with Variables

We can use different data types in the same program.

For example:

```c
#include <stdio.h>

int main()
{
    int age = 16;
    float height = 5.6;
    double price = 999.9999;
    char grade = 'A';

    printf("Age = %d\n", age);
    printf("Height = %.1f\n", height);
    printf("Price = %.4f\n", price);
    printf("Grade = %c\n", grade);

    return 0;
}
```

```output
Age = 16
Height = 5.6
Price = 999.9999
Grade = A
```

Each variable has a different data type depending on the kind of data it stores.

---

### 8. Data Type and Format Specifier

When using `printf()`, the format specifier should match the type of value being printed.

Common examples:

| Data Type | Format Specifier | Example   |
| --------- | ---------------- | --------- |
| `int`     | `%d`             | `100`     |
| `float`   | `%f`             | `25.5`    |
| `double`  | `%f`             | `25.5678` |
| `char`    | `%c`             | `'A'`     |

For example:

```c
int marks = 95;
float percentage = 95.5;
char grade = 'A';
```

They can be printed as:

```c
printf("%d\n", marks);
printf("%f\n", percentage);
printf("%c\n", grade);
```

---

### 9. Choosing the Correct Data Type

Choose a data type based on the value you want to store.

For example:

```c
int students = 50;
```

The number of students is a whole number, so `int` is suitable.

```c
float temperature = 36.5;
```

Temperature may contain a decimal value, so `float` can be used.

```c
char section = 'A';
```

A section represented by one character can use `char`.

```c
double distance = 123456.789123;
```

A decimal value requiring more precision can use `double`.

---

## Real-World Example 🌍

Imagine a student management program.

The program needs to store a student's age, percentage, and grade.

Different data types can be used for each value:

```c
#include <stdio.h>

int main()
{
    int age = 16;
    float percentage = 95.5;
    char grade = 'A';

    printf("Student Details\n");
    printf("Age: %d\n", age);
    printf("Percentage: %.1f\n", percentage);
    printf("Grade: %c\n", grade);

    return 0;
}
```

```output
Student Details
Age: 16
Percentage: 95.5
Grade: A
```

Here, each variable uses a data type suitable for the information it stores.

## Common Mistakes

### Using `char` for Multiple Characters

Incorrect:

```c
char name = "Owais";
```

A `char` is used for a single character.

For example:

```c
char grade = 'A';
```

Strings are covered in a later topic.

---

### Using Double Quotes for a Character

Incorrect:

```c
char grade = "A";
```

Correct:

```c
char grade = 'A';
```

A character uses single quotes.

---

### Using the Wrong Format Specifier

For example:

```c
int age = 16;

printf("%c", age);
```

The format specifier does not match the intended data type.

For an integer, use:

```c
printf("%d", age);
```

---

## Key Points

* A data type tells C what kind of data a variable stores.
* `int` is used for integer numbers.
* `float` is used for decimal numbers.
* `double` is used for decimal numbers with more precision.
* `char` is used for a single character.
* Characters are written inside single quotes.
* The format specifier should match the type of value being printed.
* `%d` is commonly used to print integers.
* `%f` is commonly used to print floating-point values.
* `%c` is used to print a character.
* Choosing the correct data type helps the program store and use data correctly.
