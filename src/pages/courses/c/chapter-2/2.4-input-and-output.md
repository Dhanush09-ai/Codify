# Chapter 2: Variables and Data

## Section 4: Input & Output

In C, **input** means taking data from the user, while **output** means displaying information on the screen.

C mainly uses `printf()` for output and `scanf()` for input.

---

## 1. Output Using `printf()`

The `printf()` function is used to display text and values on the screen.

Example:

```c
#include <stdio.h>

int main()
{
    printf("Hello, Codify!");

    return 0;
}
```

```output
Hello, Codify!
```

Here, `printf()` displays the message on the screen.

---

## 2. Printing Variables

We can also use `printf()` to display the value stored in a variable.

For example:

```c
#include <stdio.h>

int main()
{
    int age = 16;

    printf("Age = %d", age);

    return 0;
}
```

```output
Age = 16
```

The `%d` format specifier is used to display an integer.

Different data types use different format specifiers.

| Data Type | Format Specifier |
| --------- | ---------------- |
| `int`     | `%d`             |
| `float`   | `%f`             |
| `double`  | `%f`             |
| `char`    | `%c`             |

---

## 3. Input Using `scanf()`

The `scanf()` function is used to take input from the user.

For example:

```c
#include <stdio.h>

int main()
{
    int age;

    printf("Enter your age: ");
    scanf("%d", &age);

    printf("Your age is %d", age);

    return 0;
}
```

If the user enters:

```text
16
```

The output will be:

```output
Enter your age: 16
Your age is 16
```

Here:

* `int age;` creates an integer variable.
* `scanf()` takes input from the user.
* `%d` tells `scanf()` that an integer is expected.
* `&age` gives the memory address of the `age` variable.

---

## 4. Why Do We Use `&` with `scanf()`?

When using `scanf()` with most basic variables, we use `&` before the variable name.

For example:

```c
scanf("%d", &age);
```

The `&` tells `scanf()` where the variable is stored so that it can place the entered value there.

Example:

```c
#include <stdio.h>

int main()
{
    int number;

    printf("Enter a number: ");
    scanf("%d", &number);

    printf("You entered: %d", number);

    return 0;
}
```

```output
Enter a number: 25
You entered: 25
```

---

## 5. Taking Different Types of Input

The format specifier used in `scanf()` depends on the data type.

### Integer Input

```c
int age;

scanf("%d", &age);
```

### Float Input

```c
float price;

scanf("%f", &price);
```

### Character Input

```c
char grade;

scanf(" %c", &grade);
```

The space before `%c` can help ignore a leftover whitespace character.

---

## 6. Taking Multiple Inputs

We can take multiple values using a single `scanf()` statement.

For example:

```c
#include <stdio.h>

int main()
{
    int age;
    float percentage;

    printf("Enter age and percentage: ");
    scanf("%d %f", &age, &percentage);

    printf("Age = %d\n", age);
    printf("Percentage = %.1f", percentage);

    return 0;
}
```

If the user enters:

```text
16 95.5
```

The output will be:

```output
Enter age and percentage: 16 95.5
Age = 16
Percentage = 95.5
```

The first value is stored in `age` and the second value is stored in `percentage`.

---

## 7. Input and Output Together

Most beginner C programs use both input and output.

For example, we can create a program that takes two numbers and displays their sum.

```c
#include <stdio.h>

int main()
{
    int a, b, sum;

    printf("Enter two numbers: ");
    scanf("%d %d", &a, &b);

    sum = a + b;

    printf("Sum = %d", sum);

    return 0;
}
```

If the user enters:

```text
10 20
```

The output will be:

```output
Enter two numbers: 10 20
Sum = 30
```

The program follows these steps:

1. Creates variables.
2. Takes two numbers from the user.
3. Adds the numbers.
4. Stores the result in `sum`.
5. Displays the result.

## Common Mistakes

### Forgetting `&` in `scanf()`

Incorrect:

```c
scanf("%d", age);
```

Correct:

```c
scanf("%d", &age);
```

For basic variables, `&` is normally required with `scanf()`.

### Using the Wrong Format Specifier

For an integer:

```c
int age;
scanf("%d", &age);
```

For a float:

```c
float price;
scanf("%f", &price);
```

The format specifier should match the type of input.

### Forgetting `#include <stdio.h>`

`printf()` and `scanf()` are provided by the standard input/output library.

Therefore, beginner programs using these functions should include:

```c
#include <stdio.h>
```

## Key Points

* **Input** means taking data from the user.
* **Output** means displaying information on the screen.
* `printf()` is used for output.
* `scanf()` is used for input.
* Format specifiers tell C what type of data is being handled.
* `%d` is commonly used for integers.
* `%f` is commonly used for floating-point values.
* `%c` is used for characters.
* `&` is normally used before basic variable names in `scanf()`.
* A program can take input, process it, and display the result.
