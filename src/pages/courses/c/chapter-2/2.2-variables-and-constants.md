# Chapter 2: C Basics

## Section 2: Variables & Constants

Variables and constants are used to store values in a C program.

A **variable** can change its value during program execution, while a **constant** keeps the same value.

### 1. What is a Variable?

A variable is a named memory location used to store a value.

For example:

```c
#include <stdio.h>

int main()
{
    int age = 16;

    printf("Age = %d", age);

    return 0;
}
```

```output
Age = 16
```

Here:

* `int` is the data type.
* `age` is the variable name.
* `16` is the value stored in the variable.

### 2. Declaring a Variable

A variable can be declared before assigning a value to it.

```c
#include <stdio.h>

int main()
{
    int age;

    age = 16;

    printf("Age = %d", age);

    return 0;
}
```

```output
Age = 16
```

The declaration tells the compiler that `age` is an integer variable.

### 3. Initializing a Variable

Assigning a value to a variable when it is declared is called **initialization**.

```c
#include <stdio.h>

int main()
{
    int marks = 85;

    printf("Marks = %d", marks);

    return 0;
}
```

```output
Marks = 85
```

Here, `marks` is declared and initialized with the value `85`.

### 4. Changing the Value of a Variable

The value of a variable can be changed after it is declared.

```c
#include <stdio.h>

int main()
{
    int score = 50;

    printf("Before = %d\n", score);

    score = 80;

    printf("After = %d", score);

    return 0;
}
```

```output
Before = 50
After = 80
```

This is why it is called a **variable** — its value can change.

### 5. Declaring Multiple Variables

You can declare multiple variables of the same data type.

```c
#include <stdio.h>

int main()
{
    int age = 16, marks = 90;

    printf("Age = %d\n", age);
    printf("Marks = %d", marks);

    return 0;
}
```

```output
Age = 16
Marks = 90
```

You can also declare them separately:

```c
#include <stdio.h>

int main()
{
    int age = 16;
    int marks = 90;

    printf("Age = %d\n", age);
    printf("Marks = %d", marks);

    return 0;
}
```

```output
Age = 16
Marks = 90
```

### 6. Variables with Different Data Types

Variables can store different types of values.

```c
#include <stdio.h>

int main()
{
    int age = 16;
    float height = 5.6;
    char grade = 'A';

    printf("Age = %d\n", age);
    printf("Height = %.1f\n", height);
    printf("Grade = %c", grade);

    return 0;
}
```

```output
Age = 16
Height = 5.6
Grade = A
```

Here:

* `int` stores whole numbers.
* `float` stores decimal numbers.
* `char` stores a single character.

### 7. What is a Constant?

A constant is a value that **cannot be changed** during program execution.

In C, the `const` keyword can be used to create a constant.

```c
#include <stdio.h>

int main()
{
    const int DAYS = 7;

    printf("Days in a week = %d", DAYS);

    return 0;
}
```

```output
Days in a week = 7
```

Here, `DAYS` is a constant.

Trying to change its value later will cause a compilation error.

### 8. Creating Constants with const

The general syntax is:

```c
const data_type constant_name = value;
```

For example:

```c
#include <stdio.h>

int main()
{
    const float PI = 3.14;

    printf("PI = %.2f", PI);

    return 0;
}
```

```output
PI = 3.14
```

The value of `PI` should not be changed in the program.

### 9. Variable vs Constant

Variables and constants are different in an important way.

| Feature          | Variable                | Constant              |
| ---------------- | ----------------------- | --------------------- |
| Value can change | Yes                     | No                    |
| Keyword          | Data type such as `int` | `const`               |
| Example          | `int age = 16;`         | `const int DAYS = 7;` |
| Used for         | Values that may change  | Fixed values          |

Example:

```c
#include <stdio.h>

int main()
{
    int score = 50;
    const int MAX_SCORE = 100;

    score = 80;

    printf("Score = %d\n", score);
    printf("Maximum Score = %d", MAX_SCORE);

    return 0;
}
```

```output
Score = 80
Maximum Score = 100
```

Here, `score` can change, but `MAX_SCORE` is fixed.

### 10. Naming Variables and Constants

Good names make programs easier to understand.

Good variable names:

```c
int studentAge;
int totalMarks;
float temperature;
```

Good constant names:

```c
const int MAX_MARKS = 100;
const float PI = 3.14;
```

It is common to write constants using uppercase letters, although C does not require this.

Avoid unclear names such as:

```c
int x;
int a;
int n;
```

when a more descriptive name would make the program easier to understand.

## Real-World Example 🌍

Imagine a school program that stores a student's marks and the maximum possible marks.

```c
#include <stdio.h>

int main()
{
    int marks = 85;
    const int MAX_MARKS = 100;

    printf("Student Marks = %d\n", marks);
    printf("Maximum Marks = %d", MAX_MARKS);

    return 0;
}
```

```output
Student Marks = 85
Maximum Marks = 100
```

Here:

* `marks` is a variable because the student's marks can be different.
* `MAX_MARKS` is a constant because the maximum marks are fixed at `100`.

## Key Points

* A variable is a named memory location used to store data.
* A variable's value can be changed.
* Variables can be declared and initialized.
* A constant stores a value that should not change.
* The `const` keyword is used to declare constants.
* Variables and constants should have meaningful names.
* C is case-sensitive.
* Uppercase names are commonly used for constants.
* The data type determines what kind of value a variable can store.
