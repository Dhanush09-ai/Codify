# Chapter 9: Pointers

## Section 1: Introduction to Pointers

A **pointer** is a special variable that stores the **memory address of another variable**.

Pointers are an important part of C because they allow us to work directly with memory.

For example:

```c
int age = 20;
```

The variable `age` stores the value `20` somewhere in memory.

A pointer can store the **address of `age`**.

```text
age
┌─────────┐
│   20    │
└─────────┘
    ↑
    │
 pointer
┌─────────┐
│ address │
└─────────┘
```

---

## 1. What Is a Memory Address?

Every variable is stored at some location in the computer's memory.

That location has an **address**.

For example, imagine:

```text
Variable: age
Value:    20
Address:  1000
```

The actual address is usually much more complex, but the idea is:

```text
age
Value   → 20
Address → some memory location
```

A pointer can store that memory location.

---

## 2. Declaring a Pointer

A pointer is declared using the `*` symbol.

### Syntax

```c
data_type *pointer_name;
```

For example:

```c
int *ptr;
```

This declares `ptr` as a pointer to an `int`.

Other examples:

```c
char *ptr;
float *ptr;
double *ptr;
```

The data type tells the compiler what type of value the pointer is expected to point to.

---

## 3. Storing the Address of a Variable

The `&` operator is called the **address-of operator**.

It gives the memory address of a variable.

### Example

```c
#include <stdio.h>

int main() {
    int age = 20;
    int *ptr;

    ptr = &age;

    printf("Age = %d", age);

    return 0;
}
```


```output
Age = 20
```

Here:

```c
ptr = &age;
```

means:

> Store the address of `age` inside `ptr`.

---

## 4. Understanding `&`

The `&` operator gets the address of a variable.

For example:

```c
int number = 50;
```

We can get its address using:

```c
&number
```

Example:

```c
#include <stdio.h>

int main() {
    int number = 50;

    printf("Value = %d\n", number);
    printf("Address = %p", (void *)&number);

    return 0;
}
```


The address will be different on different computers and program runs.

Example:

```output
Value = 50
Address = 0x7ffd1234abcd
```

> 💡 Do not expect your address to match the example. Memory addresses are system-dependent.

---

## 5. The `*` Operator

The `*` symbol has an important use with pointers.

When used with a pointer variable, it **dereferences** the pointer.

Dereferencing means:

> Access the value stored at the address held by the pointer.

### Example

```c
#include <stdio.h>

int main() {
    int number = 50;
    int *ptr = &number;

    printf("Value = %d", *ptr);

    return 0;
}
```


```output
Value = 50
```

Here:

```c
ptr = &number;
```

stores the address of `number`.

And:

```c
*ptr
```

accesses the value stored at that address.

---

## 6. Three Important Concepts

When learning pointers, remember these three concepts:

### 1. Variable

```c
int number = 50;
```

`number` stores the value `50`.

### 2. Address-of Operator

```c
&number
```

Gives the address of `number`.

### 3. Dereference Operator

```c
*ptr
```

Accesses the value stored at the address inside `ptr`.

So:

```text
number      → value
&number     → address of number
ptr         → stores the address
*ptr        → value at that address
```

---

## 7. A Simple Pointer Example

```c
#include <stdio.h>

int main() {
    int number = 100;
    int *ptr = &number;

    printf("Number = %d\n", number);
    printf("Value using pointer = %d\n", *ptr);

    return 0;
}
```


```output
Number = 100
Value using pointer = 100
```

Both `number` and `*ptr` access the same value.

---

## 8. Changing a Value Using a Pointer

A pointer can also be used to change the value of a variable.

### Example

```c
#include <stdio.h>

int main() {
    int number = 10;
    int *ptr = &number;

    *ptr = 50;

    printf("Number = %d", number);

    return 0;
}
```


```output
Number = 50
```

Initially:

```text
number = 10
```

After:

```c
*ptr = 50;
```

the value becomes:

```text
number = 50
```

This happens because `ptr` points to `number`.

---

## 9. Pointer Relationship

Consider:

```c
int number = 25;
int *ptr = &number;
```

The relationship is:

```text
┌───────────────┐
│ number = 25   │
└───────────────┘
       ↑
       │
      &number
       │
┌───────────────┐
│ ptr           │
│ stores address│
└───────────────┘
```

Therefore:

```c
number
```

gives the value directly.

```c
&number
```

gives the address.

```c
ptr
```

gives the address stored in the pointer.

```c
*ptr
```

gives the value at that address.

---

## 10. Printing a Pointer Address

The `%p` format specifier is used to print a pointer address.

It is commonly written with a cast to `void *`.

### Example

```c
#include <stdio.h>

int main() {
    int number = 25;
    int *ptr = &number;

    printf("Address = %p", (void *)ptr);

    return 0;
}
```


The exact address will vary.

Example:

```output
Address = 0x7ffd1234abcd
```

The important point is that `ptr` contains the address of `number`.

---

## 11. Pointer and Variable Address

Consider:

```c
int number = 25;
int *ptr = &number;
```

Then:

```c
&number
```

and:

```c
ptr
```

represent the same address.

And:

```c
number
```

and:

```c
*ptr
```

represent the same value.

Conceptually:

```text
&number == ptr
number  == *ptr
```

---

## 12. Pointers with Different Data Types

Pointers can point to different types of variables.

### Integer Pointer

```c
int number = 10;
int *ptr = &number;
```

### Character Pointer

```c
char letter = 'A';
char *ptr = &letter;
```

### Float Pointer

```c
float price = 25.5;
float *ptr = &price;
```

The pointer type should match the type of data it points to.

---

## 13. Character Pointer Example

```c
#include <stdio.h>

int main() {
    char letter = 'A';
    char *ptr = &letter;

    printf("Letter = %c", *ptr);

    return 0;
}
```


```output
Letter = A
```

Here, `ptr` stores the address of the character variable `letter`.

---

## 14. Using a Pointer to Read and Modify Data

Pointers can both read and modify the value of the variable they point to.

### Example

```c
#include <stdio.h>

int main() {
    int marks = 75;
    int *ptr = &marks;

    printf("Before = %d\n", *ptr);

    *ptr = 90;

    printf("After = %d", *ptr);

    return 0;
}
```


```output
Before = 75
After = 90
```

The pointer provides access to the original variable.

---

## 15. NULL Pointer

A pointer can be initialized with `NULL` when it is not pointing to a valid object.

### Example

```c
#include <stdio.h>

int main() {
    int *ptr = NULL;

    if (ptr == NULL) {
        printf("Pointer is NULL");
    }

    return 0;
}
```


```output
Pointer is NULL
```

A `NULL` pointer does not point to a valid variable that you can safely dereference.

So this should **not** be done:

```c
*ptr = 10;
```

when `ptr` is `NULL`.

---

## 16. Why Are Pointers Useful?

Pointers are useful for many tasks in C.

They are commonly used for:

* Accessing memory addresses
* Modifying variables indirectly
* Passing data to functions
* Working with arrays
* Working with strings
* Dynamic memory allocation
* Building data structures

Pointers become especially useful when working with functions, arrays, and dynamic memory.

---

## 🌍 Real-World Example: Updating a Value

Imagine a program stores a student's marks.

Instead of changing the variable directly, a pointer can be used to access and update it.

```c
#include <stdio.h>

int main() {
    int marks = 70;
    int *ptr = &marks;

    printf("Old marks: %d\n", marks);

    *ptr = 85;

    printf("New marks: %d", marks);

    return 0;
}
```


```output
Old marks: 70
New marks: 85
```

The pointer allows the program to modify the original variable.

## ⚠️ Common Mistakes

### 1. Using an uninitialized pointer

Incorrect:

```c
int *ptr;

*ptr = 10;
```

`ptr` does not point to a valid variable.

Instead:

```c
int number;
int *ptr = &number;

*ptr = 10;
```

---

### 2. Confusing `&` and `*`

Remember:

```c
&number
```

means:

> Address of `number`

While:

```c
*ptr
```

means:

> Value at the address stored in `ptr`

---

### 3. Dereferencing a NULL pointer

Do not do:

```c
int *ptr = NULL;

printf("%d", *ptr);
```

A `NULL` pointer should not be dereferenced.

---

### 4. Using the wrong pointer type

For example:

```c
int number = 10;
char *ptr = &number;
```

The pointer type does not match the variable type.

Use:

```c
int *ptr = &number;
```

---

### 5. Confusing the pointer with the value

Suppose:

```c
int number = 20;
int *ptr = &number;
```

Then:

```text
ptr  → address
*ptr → value
```

Do not confuse the two.

---

## 🔑 Key Points

* A pointer stores the memory address of another variable.
* Pointers are declared using `*`.
* The `&` operator gets the address of a variable.
* The `*` operator can dereference a pointer.
* `ptr` stores an address.
* `*ptr` accesses the value at that address.
* A pointer can be used to modify the original variable.
* `%p` is used to print a pointer address.
* `NULL` represents a pointer that does not point to a valid object.
* Never dereference an uninitialized or `NULL` pointer.
* Pointer type should generally match the type of variable being pointed to.
