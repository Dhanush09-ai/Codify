# Chapter 9: Pointers

## Section 4: Pointers with Functions

Pointers and functions work together in an important way in C.

Normally, when a variable is passed to a function, the function receives a **copy** of its value.

Using pointers, we can pass the **address** of a variable to a function. The function can then access or modify the original variable.

---

## 1. Passing a Normal Variable to a Function

Consider this example:

```c
#include <stdio.h>

void changeValue(int x) {
    x = 100;
}

int main() {
    int number = 10;

    changeValue(number);

    printf("%d\n", number);

    return 0;
}
```

```output
10
```

The value of `number` remains `10`.

Why?

Because the function receives a **copy** of `number`.

Changing `x` does not change the original variable.

---

## 2. Passing an Address to a Function

A pointer allows us to pass the address of a variable.

```c
#include <stdio.h>

void changeValue(int *ptr) {
    *ptr = 100;
}

int main() {
    int number = 10;

    changeValue(&number);

    printf("%d\n", number);

    return 0;
}
```

```output
100
```

Here:

```c
changeValue(&number);
```

passes the address of `number`.

The function receives that address:

```c
void changeValue(int *ptr)
```

Then:

```c
*ptr = 100;
```

changes the value stored at that address.

Therefore, the original `number` becomes `100`.

---

## 3. How It Works

Suppose:

```c
int number = 10;
```

We pass:

```c
changeValue(&number);
```

The function receives the address:

```c
int *ptr
```

The relationship is:

```text
number
  |
  | value = 10
  |
  ↓
memory address
  ↑
  |
 ptr
```

When we write:

```c
*ptr
```

we access the original `number`.

---

## 4. Modifying Two Variables Using Pointers

A function can modify multiple variables using pointers.

```c
#include <stdio.h>

void changeValues(int *a, int *b) {
    *a = 100;
    *b = 200;
}

int main() {
    int x = 10;
    int y = 20;

    changeValues(&x, &y);

    printf("x = %d\n", x);
    printf("y = %d\n", y);

    return 0;
}
```

```output
x = 100
y = 200
```

The addresses of both variables are passed to the function.

---

## 5. Swapping Two Variables Using Pointers

One of the most common uses of pointers with functions is **swapping two variables**.

Without pointers, a function cannot directly change the original variables.

With pointers:

```c
#include <stdio.h>

void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main() {
    int x = 10;
    int y = 20;

    swap(&x, &y);

    printf("x = %d\n", x);
    printf("y = %d\n", y);

    return 0;
}
```

```output
x = 20
y = 10
```

### How the Swap Works

Initially:

```text
x = 10
y = 20
```

The function receives their addresses.

```c
int temp = *a;
```

`temp` gets `10`.

Then:

```c
*a = *b;
```

`x` becomes `20`.

Finally:

```c
*b = temp;
```

`y` becomes `10`.

---

## 6. Returning Multiple Results Using Pointers

A C function can directly return only one value using `return`.

Pointers allow a function to store multiple results in variables supplied by the caller.

For example, we can calculate both sum and difference:

```c
#include <stdio.h>

void calculate(int a, int b, int *sum, int *difference) {
    *sum = a + b;
    *difference = a - b;
}

int main() {
    int sum;
    int difference;

    calculate(20, 8, &sum, &difference);

    printf("Sum = %d\n", sum);
    printf("Difference = %d\n", difference);

    return 0;
}
```

```output
Sum = 28
Difference = 12
```

The function stores the results directly into `sum` and `difference`.

---

## 7. Pointers and Arrays in Functions

When an array is passed to a function, the function can work with its elements through a pointer.

```c
#include <stdio.h>

void printArray(int *ptr, int size) {
    for (int i = 0; i < size; i++) {
        printf("%d ", *(ptr + i));
    }
}

int main() {
    int numbers[] = {10, 20, 30, 40, 50};

    printArray(numbers, 5);

    return 0;
}
```

```output
10 20 30 40 50
```

The array name provides the address of its first element when passed to the function.

Inside the function:

```c
*(ptr + i)
```

accesses each element.

---

## 8. Modifying Array Elements Inside a Function

A function can modify an array using a pointer.

```c
#include <stdio.h>

void doubleValues(int *ptr, int size) {
    for (int i = 0; i < size; i++) {
        *(ptr + i) = *(ptr + i) * 2;
    }
}

int main() {
    int numbers[] = {1, 2, 3, 4, 5};

    doubleValues(numbers, 5);

    for (int i = 0; i < 5; i++) {
        printf("%d ", numbers[i]);
    }

    return 0;
}
```

```output
2 4 6 8 10
```

The function changes the original array elements.

---

## 9. Passing a String to a Function

A string can be passed to a function using a character pointer.

```c
#include <stdio.h>

void printString(char *ptr) {
    while (*ptr != '\0') {
        printf("%c", *ptr);
        ptr++;
    }
}

int main() {
    char name[] = "Codify";

    printString(name);

    return 0;
}
```

```output
Codify
```

The pointer starts at the first character and moves until it reaches `'\0'`.

---

## 10. Modifying a String Inside a Function

Because a character array can be modified, a function can change its characters through a pointer.

```c
#include <stdio.h>

void makeFirstUpper(char *ptr) {
    if (*ptr >= 'a' && *ptr <= 'z') {
        *ptr = *ptr - 32;
    }
}

int main() {
    char word[] = "hello";

    makeFirstUpper(word);

    printf("%s\n", word);

    return 0;
}
```

```output
Hello
```

The function receives the address of the first character.

Then:

```c
*ptr = *ptr - 32;
```

changes the first character from lowercase to uppercase.

## 11. Pointer Parameters

When a function needs to receive an address, its parameter is declared as a pointer.

For example:

```c
void update(int *ptr)
```

Here:

* `int *ptr` means `ptr` stores the address of an `int`.
* `*ptr` accesses the integer stored at that address.

A function can have multiple pointer parameters:

```c
void calculate(int *sum, int *product)
```

---

## 12. Passing a Pointer to a Function

Suppose we have:

```c
int number = 50;
```

We can pass its address:

```c
update(&number);
```

The function can receive it:

```c
void update(int *ptr)
```

And access the original value:

```c
*ptr
```

The basic pattern is:

```text
Variable
   ↓
   &
Address
   ↓
Pointer parameter
   ↓
   *
Original value
```

---

## 13. Function Can Modify the Original Variable

Consider:

```c
#include <stdio.h>

void increase(int *ptr) {
    (*ptr)++;
}

int main() {
    int number = 10;

    increase(&number);

    printf("%d\n", number);

    return 0;
}
```

```output
11
```

The function changes the original variable because it receives its address.

The expression:

```c
(*ptr)++;
```

means that the value pointed to by `ptr` is increased by `1`.

Parentheses are important here.

---

## 14. Pointers and Return Values

Pointers do not replace the `return` statement.

A function can still return a value normally:

```c
int square(int number) {
    return number * number;
}
```

Pointers are useful when the function needs to:

* modify original variables
* produce multiple results
* modify arrays
* modify character arrays
* work directly with memory addresses

For example:

```c
int square(int number)
```

returns one result.

But:

```c
void calculate(int a, int b, int *sum, int *difference)
```

can store multiple results through pointer parameters.

---

## 15. Pointer Parameters and NULL

A pointer parameter should point to a valid memory location before it is dereferenced.

For example:

```c
void update(int *ptr) {
    if (ptr != NULL) {
        *ptr = 100;
    }
}
```

The check:

```c
ptr != NULL
```

helps prevent dereferencing a null pointer.

Example:

```c
#include <stdio.h>

void update(int *ptr) {
    if (ptr != NULL) {
        *ptr = 100;
    }
}

int main() {
    int number = 10;

    update(&number);

    printf("%d\n", number);

    return 0;
}
```

```output
100
```

## 🌍 Real-World Example: Updating Student Marks

Imagine a program that needs to increase a student's marks.

A function can receive the address of the marks variable and update the original value.

```c
#include <stdio.h>

void addBonus(int *marks) {
    *marks = *marks + 5;
}

int main() {
    int marks = 80;

    addBonus(&marks);

    printf("Marks = %d\n", marks);

    return 0;
}
```

```output
Marks = 85
```

The function does not need to return the new marks because it directly changes the original variable through its pointer.

## ⚠️ Common Mistakes

### 1. Passing a value instead of an address

If the function expects an `int *`:

```c
void update(int *ptr)
```

pass an address:

```c
update(&number);
```

Not:

```c
update(number);
```

---

### 2. Forgetting to dereference

If `ptr` points to an integer:

```c
int *ptr;
```

then:

```c
ptr
```

is the address.

But:

```c
*ptr
```

is the value.

To modify the original variable, use:

```c
*ptr = 100;
```

---

### 3. Dereferencing NULL

Do not do:

```c
int *ptr = NULL;

*ptr = 10;
```

A NULL pointer does not point to a valid object.

---

### 4. Using the wrong pointer type

The pointer type should normally match the variable type.

For example:

```c
int number = 10;
int *ptr = &number;
```

Here `ptr` is an `int *` because `number` is an `int`.

---

### 5. Forgetting the address operator

If a function expects a pointer:

```c
void change(int *ptr)
```

and you want to pass `number`, use:

```c
change(&number);
```

The `&` provides the address.

---

## 🔑 Key Points

* A normal function parameter receives a copy of a value.
* A pointer parameter receives an address.
* Passing an address allows a function to modify the original variable.
* `&variable` gives the variable's address.
* `*ptr` accesses the value stored at that address.
* Pointers are commonly used for swapping variables.
* Pointers allow functions to produce multiple results.
* Arrays can be passed to functions using pointers.
* Strings can be passed using `char *`.
* A pointer should point to valid memory before it is dereferenced.
* Check for `NULL` when a pointer may be null.
