# Chapter 9: Pointers

## Section 5: Dynamic Memory Allocation

Sometimes a program does not know how much memory it will need when the program starts.

C provides **Dynamic Memory Allocation (DMA)** to allocate memory while the program is running.

Dynamic memory is allocated from the **heap** and is accessed using pointers.

The main functions used for dynamic memory allocation are:

* `malloc()`
* `calloc()`
* `realloc()`
* `free()`

These functions are provided by:

```c
#include <stdlib.h>
```

---

## 1. What is Dynamic Memory Allocation?

In normal variable declaration, memory is allocated automatically.

For example:

```c
int number;
```

The compiler knows that an `int` variable is required.

For an array:

```c
int numbers[5];
```

memory for 5 integers is allocated.

But what if the number of elements is known only while the program is running?

For example, the user enters:

```text
Enter number of students: 100
```

Instead of creating a fixed-size array, we can allocate memory for exactly the required number of students.

This is where dynamic memory allocation is useful.

---

## 2. Static vs Dynamic Memory Allocation

### Static Allocation

The size is determined before the program runs.

```c
int numbers[5];
```

The array can store exactly 5 integers.

### Dynamic Allocation

The memory is allocated while the program is running.

```c
int *numbers;

numbers = malloc(5 * sizeof(int));
```

Now memory for 5 integers is requested dynamically.

| Static Allocation            | Dynamic Allocation                        |
| ---------------------------- | ----------------------------------------- |
| Size is fixed                | Size can be decided at runtime            |
| Usually declared directly    | Uses memory allocation functions          |
| Example: `int a[5]`          | Example: `malloc()`                       |
| Memory managed automatically | Programmer must release it using `free()` |

---

## 3. The `malloc()` Function

`malloc()` stands for **memory allocation**.

It allocates a block of memory of the requested size.

Syntax:

```c
ptr = malloc(size);
```

The size is specified in **bytes**.

For example:

```c
int *ptr = malloc(sizeof(int));
```

This requests enough memory to store one `int`.

Because `malloc()` returns an address, it is stored in a pointer.

---

## 4. Using `malloc()` for One Integer

Example:

```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    int *ptr;

    ptr = malloc(sizeof(int));

    *ptr = 25;

    printf("%d\n", *ptr);

    free(ptr);

    return 0;
}
```

```output
25
```

Here:

1. `ptr` is an integer pointer.
2. `malloc()` allocates memory for one integer.
3. `*ptr = 25` stores `25` in that memory.
4. `free(ptr)` releases the allocated memory.

---

## 5. Why Use `sizeof()`?

Different data types require different amounts of memory.

Instead of assuming the size of an `int`, use:

```c
sizeof(int)
```

For example:

```c
int *ptr = malloc(sizeof(int));
```

This makes the code easier to maintain and ensures the requested size matches the type.

For an array of `n` integers:

```c
int *ptr = malloc(n * sizeof(int));
```

---

## 6. Allocating Memory for an Array

Suppose the user enters the number of elements.

```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    int n;

    printf("Enter number of elements: ");
    scanf("%d", &n);

    int *numbers = malloc(n * sizeof(int));

    for (int i = 0; i < n; i++) {
        numbers[i] = (i + 1) * 10;
    }

    for (int i = 0; i < n; i++) {
        printf("%d ", numbers[i]);
    }

    free(numbers);

    return 0;
}
```

```output
Enter number of elements: 5
10 20 30 40 50
```

The important part is:

```c
int *numbers = malloc(n * sizeof(int));
```

If `n` is `5`, memory for 5 integers is requested.

---

## 7. Checking `malloc()` Failure

Memory allocation can fail.

If `malloc()` cannot allocate the requested memory, it returns `NULL`.

Therefore, it is good practice to check the pointer.

```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    int *ptr = malloc(sizeof(int));

    if (ptr == NULL) {
        printf("Memory allocation failed\n");
        return 1;
    }

    *ptr = 100;

    printf("%d\n", *ptr);

    free(ptr);

    return 0;
}
```

```output
100
```

The check:

```c
if (ptr == NULL)
```

makes sure that the allocation was successful before using the memory.

---

## 8. The `calloc()` Function

`calloc()` stands for **contiguous allocation**.

It allocates memory for multiple elements and initializes the allocated bytes to zero.

Syntax:

```c
ptr = calloc(number_of_elements, size_of_each_element);
```

For example:

```c
int *numbers = calloc(5, sizeof(int));
```

This allocates memory for 5 integers.

The allocated integers are initially zero.

---

## 9. Example Using `calloc()`

```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    int *numbers = calloc(5, sizeof(int));

    if (numbers == NULL) {
        printf("Memory allocation failed\n");
        return 1;
    }

    for (int i = 0; i < 5; i++) {
        printf("%d ", numbers[i]);
    }

    free(numbers);

    return 0;
}
```

```output
0 0 0 0 0
```

Unlike `malloc()`, `calloc()` initializes the allocated memory to zero.

---

## 10. `malloc()` vs `calloc()`

Both functions allocate dynamic memory, but they are used slightly differently.

| `malloc()`                        | `calloc()`                                |
| --------------------------------- | ----------------------------------------- |
| Allocates one block of memory     | Allocates memory for multiple elements    |
| Takes one main size argument      | Takes number of elements and element size |
| Memory is not initialized to zero | Allocated bytes are initialized to zero   |
| `malloc(size)`                    | `calloc(count, size)`                     |

Example:

```c
int *a = malloc(5 * sizeof(int));
```

and:

```c
int *b = calloc(5, sizeof(int));
```

Both can provide space for 5 integers.

---

## 11. The `realloc()` Function

Sometimes the program needs to change the size of already allocated memory.

For example, suppose we initially allocate space for 3 integers but later need space for 5.

`realloc()` can resize the allocated memory.

Syntax:

```c
ptr = realloc(ptr, new_size);
```

Example:

```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    int *numbers = malloc(3 * sizeof(int));

    if (numbers == NULL) {
        return 1;
    }

    numbers[0] = 10;
    numbers[1] = 20;
    numbers[2] = 30;

    numbers = realloc(numbers, 5 * sizeof(int));

    if (numbers == NULL) {
        return 1;
    }

    numbers[3] = 40;
    numbers[4] = 50;

    for (int i = 0; i < 5; i++) {
        printf("%d ", numbers[i]);
    }

    free(numbers);

    return 0;
}
```

```output
10 20 30 40 50
```

`realloc()` can move the memory block to another location if necessary.

---

## 12. Checking `realloc()` Safely

It is safer to use a temporary pointer with `realloc()`.

Instead of directly doing:

```c
numbers = realloc(numbers, newSize);
```

we can use:

```c
int *temp = realloc(numbers, newSize);

if (temp == NULL) {
    free(numbers);
    return 1;
}

numbers = temp;
```

This prevents losing the original pointer if the reallocation fails.

---

## 13. The `free()` Function

Memory allocated using:

* `malloc()`
* `calloc()`
* `realloc()`

should be released when it is no longer needed.

Use:

```c
free(ptr);
```

Example:

```c
int *ptr = malloc(5 * sizeof(int));

/* use the memory */

free(ptr);
```

After `free()`:

```text
Allocated memory → released
```

---

## 14. Why `free()` Is Important

If dynamically allocated memory is not released, the program may continue to hold memory that it no longer needs.

This is called a **memory leak**.

Example:

```c
void function() {
    int *ptr = malloc(100 * sizeof(int));

    /* use ptr */

    // free(ptr) is missing
}
```

Every time the function runs, memory may be allocated without being released.

Correct:

```c
void function() {
    int *ptr = malloc(100 * sizeof(int));

    /* use ptr */

    free(ptr);
}
```

---

## 15. Setting a Pointer to `NULL` After `free()`

After freeing memory, the pointer still contains its old address.

It is often useful to set it to `NULL`.

```c
free(ptr);
ptr = NULL;
```

Now the pointer does not point to the previously allocated memory.

This can help prevent accidental reuse of the pointer.

## 16. Complete Example: Dynamic Array

The following program asks the user for the number of elements and dynamically creates an array.

```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    int n;

    printf("Enter number of elements: ");
    scanf("%d", &n);

    int *numbers = malloc(n * sizeof(int));

    if (numbers == NULL) {
        printf("Memory allocation failed\n");
        return 1;
    }

    for (int i = 0; i < n; i++) {
        printf("Enter element %d: ", i + 1);
        scanf("%d", &numbers[i]);
    }

    printf("Array: ");

    for (int i = 0; i < n; i++) {
        printf("%d ", numbers[i]);
    }

    free(numbers);
    numbers = NULL;

    return 0;
}
```

```output
Enter number of elements: 4
Enter element 1: 10
Enter element 2: 20
Enter element 3: 30
Enter element 4: 40
Array: 10 20 30 40
```

The array size is decided by the user while the program is running.

## 17. Dynamic Memory and Pointers

Dynamic memory allocation depends heavily on pointers.

For example:

```c
int *numbers = malloc(5 * sizeof(int));
```

Here:

* `malloc()` allocates memory.
* `numbers` stores the address of that memory.
* `numbers[i]` accesses an element.
* `free(numbers)` releases the memory.

The basic relationship is:

```text
malloc()
   ↓
Allocated memory
   ↓
Pointer stores address
   ↓
Use memory
   ↓
free()
```

## 🌍 Real-World Example: Student Records

Suppose a college application needs to store marks for an unknown number of students.

Instead of creating:

```c
int marks[1000];
```

we can ask how many students there are and allocate memory accordingly.

```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    int students;

    printf("Enter number of students: ");
    scanf("%d", &students);

    int *marks = malloc(students * sizeof(int));

    if (marks == NULL) {
        printf("Memory allocation failed\n");
        return 1;
    }

    for (int i = 0; i < students; i++) {
        marks[i] = 80 + i;
    }

    for (int i = 0; i < students; i++) {
        printf("Student %d: %d\n", i + 1, marks[i]);
    }

    free(marks);

    return 0;
}
```

```output
Enter number of students: 3
Student 1: 80
Student 2: 81
Student 3: 82
```

The amount of memory depends on the number of students entered by the user.

## ⚠️ Common Mistakes

### 1. Forgetting to include `<stdlib.h>`

The dynamic memory functions are declared in:

```c
#include <stdlib.h>
```

---

### 2. Using memory without checking `NULL`

Always check whether allocation succeeded before using the pointer.

```c
if (ptr == NULL) {
    printf("Memory allocation failed\n");
}
```

---

### 3. Forgetting `free()`

Memory allocated dynamically should be released when it is no longer needed.

```c
free(ptr);
```

---

### 4. Using memory after `free()`

Do not use:

```c
free(ptr);

printf("%d", *ptr);
```

After `free()`, the previously allocated memory must not be accessed through that pointer.

---

### 5. Freeing the same memory twice

Do not do:

```c
free(ptr);
free(ptr);
```

The same allocated block should not be freed more than once.

---

### 6. Allocating the wrong amount of memory

For an array of `n` integers, use:

```c
malloc(n * sizeof(int))
```

not simply:

```c
malloc(n)
```

because `n` represents the number of integers, while `malloc()` expects a number of bytes.

---

## 🔑 Key Points

* Dynamic memory is allocated while the program is running.
* Dynamic memory is accessed using pointers.
* `malloc()` allocates a block of memory.
* `calloc()` allocates memory for multiple elements and initializes the allocated bytes to zero.
* `realloc()` changes the size of an allocated memory block.
* `free()` releases dynamically allocated memory.
* `malloc()`, `calloc()`, `realloc()`, and `free()` are declared in `<stdlib.h>`.
* Always check whether allocation returned `NULL`.
* Do not access memory after it has been freed.
* Free dynamically allocated memory when it is no longer needed.
* `sizeof()` helps calculate the correct amount of memory required for a data type.
