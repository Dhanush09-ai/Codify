# Chapter 9: Pointers

## Section 2: Address, Dereference & Pointer Arithmetic

Pointers become easier to understand when we clearly understand three important concepts:

1. **Address** — where a variable is stored in memory
2. **Dereference** — accessing the value through a pointer
3. **Pointer arithmetic** — moving a pointer through memory locations

These concepts are especially important when working with arrays and dynamic memory.

---

## 1. Address of a Variable

Every variable is stored somewhere in memory.

The `&` operator is used to get the address of a variable.

### Example

```c
#include <stdio.h>

int main() {
    int number = 25;

    printf("Value = %d\n", number);
    printf("Address = %p", (void *)&number);

    return 0;
}
```


The actual address can be different on every computer or program run.

```output
Value = 25
Address = 0x7ffd1234abcd
```

The important part is:

```c
&number
```

This gives the address of `number`.

---

## 2. Storing an Address in a Pointer

A pointer can store the address of another variable.

```c
int number = 25;
int *ptr = &number;
```

Here:

```text
number → stores 25
ptr    → stores the address of number
```

We can print the pointer:

```c
#include <stdio.h>

int main() {
    int number = 25;
    int *ptr = &number;

    printf("Address of number = %p", (void *)ptr);

    return 0;
}
```


```output
Address of number = 0x7ffd1234abcd
```

The exact address will vary.

---

## 3. Dereferencing a Pointer

**Dereferencing** means accessing the value stored at the address held by a pointer.

The `*` operator is used for dereferencing.

### Example

```c
#include <stdio.h>

int main() {
    int number = 25;
    int *ptr = &number;

    printf("Value = %d", *ptr);

    return 0;
}
```


```output
Value = 25
```

Here:

```c
ptr
```

contains the address of `number`.

And:

```c
*ptr
```

gives the value stored at that address.

---

## 4. Address vs Dereference

Consider:

```c
int number = 50;
int *ptr = &number;
```

There are three important expressions:

| Expression | Meaning                              |
| ---------- | ------------------------------------ |
| `number`   | Value of the variable                |
| `&number`  | Address of the variable              |
| `*ptr`     | Value at the address stored in `ptr` |

Conceptually:

```text
number  → 50
&number → address
ptr     → address
*ptr    → 50
```

Therefore:

```c
*ptr == number
```

because both access the value `50`.

---

## 5. Changing a Value Through a Pointer

Dereferencing a pointer does not only allow us to read a value.

It can also be used to modify the original variable.

### Example

```c
#include <stdio.h>

int main() {
    int number = 10;
    int *ptr = &number;

    *ptr = 100;

    printf("Number = %d", number);

    return 0;
}
```


```output
Number = 100
```

The statement:

```c
*ptr = 100;
```

changes the value stored in `number`.

---

## 6. What Is Pointer Arithmetic?

Pointer arithmetic means performing operations such as:

* `ptr + 1`
* `ptr - 1`
* `ptr++`
* `ptr--`

on a pointer.

Pointer arithmetic is commonly used with arrays.

For example:

```c
int numbers[] = {10, 20, 30};
int *ptr = numbers;
```

Here, `ptr` points to the first element.

Moving the pointer forward allows us to access the next elements.

---

## 7. Pointer Increment

The `++` operator can move a pointer to the next element.

### Example

```c
#include <stdio.h>

int main() {
    int numbers[] = {10, 20, 30};
    int *ptr = numbers;

    printf("%d\n", *ptr);

    ptr++;

    printf("%d", *ptr);

    return 0;
}
```


```output
10
20
```

Initially:

```text
ptr → 10
```

After:

```c
ptr++;
```

the pointer moves to the next `int`.

```text
ptr → 20
```

---

## 8. Pointer Decrement

The `--` operator moves a pointer to the previous element.

### Example

```c
#include <stdio.h>

int main() {
    int numbers[] = {10, 20, 30};
    int *ptr = &numbers[2];

    printf("%d\n", *ptr);

    ptr--;

    printf("%d", *ptr);

    return 0;
}
```


```output
30
20
```

Initially, `ptr` points to `30`.

After:

```c
ptr--;
```

it points to `20`.

---

## 9. Pointer Addition

We can add an integer to a pointer.

### Example

```c
#include <stdio.h>

int main() {
    int numbers[] = {10, 20, 30, 40, 50};
    int *ptr = numbers;

    printf("%d\n", *(ptr + 2));

    return 0;
}
```


```output
30
```

Here:

```c
ptr
```

points to `numbers[0]`.

So:

```c
ptr + 2
```

points to `numbers[2]`.

Therefore:

```c
*(ptr + 2)
```

gives:

```text
30
```

---

## 10. Pointer Subtraction

Pointers can also be subtracted when they point into the same array.

### Example

```c
#include <stdio.h>

int main() {
    int numbers[] = {10, 20, 30, 40, 50};

    int *start = &numbers[0];
    int *end = &numbers[4];

    printf("Distance = %td", end - start);

    return 0;
}
```


```output
Distance = 4
```

The result represents the number of array elements between the two pointers.

---

## 11. Pointer Arithmetic Depends on Data Type

Pointer arithmetic does not simply move by one byte.

The amount of movement depends on the pointer's data type.

For example:

```c
int *ptr;
```

When we do:

```c
ptr++;
```

the pointer moves to the next `int` object.

Similarly:

```c
char *ptr;
```

moves to the next `char` object.

The C language handles the correct amount of movement based on the pointed-to type.

---

## 12. Pointer Arithmetic with Arrays

Pointers and arrays are closely related.

Consider:

```c
int numbers[] = {10, 20, 30, 40};
```

A pointer can be used to access the elements.

```c
#include <stdio.h>

int main() {
    int numbers[] = {10, 20, 30, 40};
    int *ptr = numbers;

    printf("%d\n", *ptr);
    printf("%d\n", *(ptr + 1));
    printf("%d\n", *(ptr + 2));
    printf("%d", *(ptr + 3));

    return 0;
}
```


```output
10
20
30
40
```

The relationship is:

```text
*(ptr + 0) → numbers[0]
*(ptr + 1) → numbers[1]
*(ptr + 2) → numbers[2]
*(ptr + 3) → numbers[3]
```

---

## 13. Array Indexing and Pointer Arithmetic

These two expressions access the same array element:

```c
numbers[2]
```

and:

```c
*(numbers + 2)
```

### Example

```c
#include <stdio.h>

int main() {
    int numbers[] = {10, 20, 30, 40};

    printf("%d\n", numbers[2]);
    printf("%d", *(numbers + 2));

    return 0;
}
```


```output
30
30
```

This is an important relationship between arrays and pointers.

---

## 14. Traversing an Array Using a Pointer

A pointer can be used instead of an array index to visit every element.

### Example

```c
#include <stdio.h>

int main() {
    int numbers[] = {10, 20, 30, 40, 50};
    int *ptr = numbers;
    int i;

    for (i = 0; i < 5; i++) {
        printf("%d ", *(ptr + i));
    }

    return 0;
}
```


```output
10 20 30 40 50
```

Here:

```c
*(ptr + i)
```

accesses each element.

---

## 15. Incrementing a Pointer in a Loop

We can also increment the pointer itself.

### Example

```c
#include <stdio.h>

int main() {
    int numbers[] = {10, 20, 30, 40, 50};
    int *ptr = numbers;
    int i;

    for (i = 0; i < 5; i++) {
        printf("%d ", *ptr);
        ptr++;
    }

    return 0;
}
```


```output
10 20 30 40 50
```

Each `ptr++` moves the pointer to the next array element.

---

## 16. Pointer Comparison

Pointers that point into the same array can be compared.

For example:

```c
ptr1 < ptr2
```

can tell us which position comes first in that array.

### Example

```c
#include <stdio.h>

int main() {
    int numbers[] = {10, 20, 30, 40};

    int *ptr1 = &numbers[0];
    int *ptr2 = &numbers[3];

    if (ptr1 < ptr2) {
        printf("ptr1 comes before ptr2");
    }

    return 0;
}
```


```output
ptr1 comes before ptr2
```

---

## 17. Moving Backward Through an Array

A pointer can also move backward.

### Example

```c
#include <stdio.h>

int main() {
    int numbers[] = {10, 20, 30, 40, 50};
    int *ptr = &numbers[4];

    while (ptr >= numbers) {
        printf("%d ", *ptr);
        ptr--;
    }

    return 0;
}
```


```output
50 40 30 20 10
```

The pointer starts at the last element and moves toward the first.

---

## 18. Important Pointer Arithmetic Rules

Pointer arithmetic should be used carefully.

Valid operations include:

```c
ptr++;
ptr--;
ptr + n;
ptr - n;
ptr1 - ptr2;
```

when the pointers are used in an appropriate context, especially within the same array.

A pointer should not be moved outside the valid array range and then dereferenced.

For example, if an array contains 5 elements:

```c
int numbers[5];
```

valid elements are:

```text
numbers[0] to numbers[4]
```

The pointer may be positioned one past the last element for certain pointer operations, but that one-past position must **not be dereferenced**.

---

## 19. Pointer Arithmetic Example

Let's combine several operations.

```c
#include <stdio.h>

int main() {
    int numbers[] = {5, 10, 15, 20, 25};
    int *ptr = numbers;

    printf("First = %d\n", *ptr);

    ptr += 2;

    printf("Third = %d\n", *ptr);

    ptr--;

    printf("Second = %d", *ptr);

    return 0;
}
```


```output
First = 5
Third = 15
Second = 10
```

The pointer moves:

```text
Start
  ↓
5  10  15  20  25
↑
ptr

After ptr += 2:

5  10  15  20  25
         ↑
         ptr

After ptr--:

5  10  15  20  25
     ↑
     ptr
```

## 🌍 Real-World Example: Processing Array Values

Pointers can be useful when processing a group of values stored in an array.

For example, we can calculate the sum using a pointer.

```c
#include <stdio.h>

int main() {
    int marks[] = {80, 75, 90, 85, 70};
    int *ptr = marks;
    int sum = 0;
    int i;

    for (i = 0; i < 5; i++) {
        sum += *ptr;
        ptr++;
    }

    printf("Total = %d", sum);

    return 0;
}
```


```output
Total = 400
```

The pointer moves through the array and accesses each mark.

## ⚠️ Common Mistakes

### 1. Confusing `ptr` and `*ptr`

If:

```c
int number = 10;
int *ptr = &number;
```

then:

```text
ptr  → address
*ptr → value
```

---

### 2. Dereferencing an invalid pointer

Do not access memory through a pointer that does not point to a valid object.

For example:

```c
int *ptr = NULL;
printf("%d", *ptr);
```

is invalid.

---

### 3. Moving outside an array

If an array has 5 elements, do not dereference a pointer at an invalid position.

```c
int numbers[5];
```

Valid elements are:

```text
0, 1, 2, 3, 4
```

---

### 4. Confusing pointer arithmetic with integer arithmetic

For an `int *` pointer:

```c
ptr + 1
```

means move to the next `int`, not simply add `1` byte to the address.

---

### 5. Subtracting unrelated pointers

Pointer subtraction is meaningful when the pointers refer to elements of the same array, or the corresponding one-past position.

Do not assume subtraction of arbitrary unrelated pointers gives a useful result.

---

## 🔑 Key Points

* `&variable` gives the address of a variable.
* A pointer stores an address.
* `*pointer` dereferences the pointer and accesses the value.
* Dereferencing can be used to read or modify a value.
* `ptr++` moves a pointer to the next element.
* `ptr--` moves a pointer to the previous element.
* `ptr + n` moves forward by `n` elements.
* `ptr - n` moves backward by `n` elements.
* Pointer arithmetic is especially useful with arrays.
* `*(ptr + i)` can be used to access array elements.
* Pointers to elements of the same array can be subtracted.
* Never dereference an invalid or one-past-the-end pointer.
