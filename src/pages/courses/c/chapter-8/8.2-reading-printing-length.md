# Chapter 8: Strings

## Section 2: Reading, Printing & String Length

In the previous lesson, we learned that a string is a sequence of characters stored in a character array.

Now we will learn how to:

* Read a string from the user
* Print a string
* Read strings containing spaces
* Understand `%s`
* Find the length of a string
* Use `strlen()`

---

## 1. Reading a String with `scanf()`

We can use `scanf()` with `%s` to read a string.

### Example

```c
#include <stdio.h>

int main() {
    char name[20];

    printf("Enter your name: ");
    scanf("%s", name);

    printf("Name: %s", name);

    return 0;
}
```


```output
Enter your name: Owais
Name: Owais
```

Notice that we use:

```c
scanf("%s", name);
```

We do **not** use `&name` here.

The array name already represents the address of its first element when passed to `scanf()`.

---

## 2. How `%s` Works

The `%s` format specifier tells `scanf()` to read characters into a string.

For example:

```c
char name[20];

scanf("%s", name);
```

If the user enters:

```text
Owais
```

the characters are stored as:

```text
O  w  a  i  s  \0
```

The null character `'\0'` marks the end of the string.

---

## 3. Reading a String with Spaces

A limitation of:

```c
scanf("%s", name);
```

is that `%s` stops reading when it encounters whitespace.

For example, if the user enters:

```text
Mohammed Owais
```

`scanf("%s", name)` reads only:

```text
Mohammed
```

It stops at the space.

To read a complete line containing spaces, we can use `fgets()`.

---

## 4. Reading a Complete Line with `fgets()`

The `fgets()` function can read a line of text, including spaces.

### Example

```c
#include <stdio.h>

int main() {
    char name[50];

    printf("Enter your full name: ");
    fgets(name, sizeof(name), stdin);

    printf("Name: %s", name);

    return 0;
}
```


```output
Enter your full name: Mohammed Owais
Name: Mohammed Owais
```

Here:

```c
fgets(name, sizeof(name), stdin);
```

reads characters from standard input and stores them in `name`.

---

## 5. `scanf()` vs `fgets()`

Both can be used to read strings, but they behave differently.

| Method                     | Reads spaces? | Common use    |
| -------------------------- | ------------- | ------------- |
| `scanf("%s", name)`        | No            | Single word   |
| `fgets(name, size, stdin)` | Yes           | Complete line |

For example:

```text
Input:
Owais
```

Both methods can read it.

But for:

```text
Input:
Mohammed Owais
```

`scanf("%s", name)` reads only `Mohammed`, while `fgets()` can read the complete line.

---

## 6. Printing a String

The `%s` format specifier is used with `printf()` to print a complete string.

### Example

```c
#include <stdio.h>

int main() {
    char message[] = "Welcome to Codify!";

    printf("%s", message);

    return 0;
}
```


```output
Welcome to Codify!
```

We can also print additional text:

```c
printf("Message: %s", message);
```

The output will be:

```text
Message: Welcome to Codify!
```

---

## 7. Printing Individual Characters

A string is a character array, so individual characters can also be printed.

Use `%c` for one character.

### Example

```c
#include <stdio.h>

int main() {
    char word[] = "Hello";

    printf("%c\n", word[0]);
    printf("%c\n", word[1]);
    printf("%c", word[4]);

    return 0;
}
```


```output
H
e
o
```

Remember:

* `%s` → complete string
* `%c` → single character

---

## 8. Finding String Length

The **length of a string** is the number of characters in the string, excluding the null character `'\0'`.

For example:

```text
Hello
```

has a length of:

```text
5
```

The `'\0'` is not counted as part of the string length.

C provides a library function called:

```c
strlen()
```

to find the length of a string.

---

## 9. Using `strlen()`

The `strlen()` function is available in the `<string.h>` header file.

### Example

```c
#include <stdio.h>
#include <string.h>

int main() {
    char word[] = "Hello";

    printf("Length = %zu", strlen(word));

    return 0;
}
```


```output
Length = 5
```

Here:

```c
strlen(word)
```

returns the number of characters before the null character.

---

## 10. Why `strlen()` Does Not Count `'\0'`

Consider:

```text
H  e  l  l  o  \0
```

There are 6 characters stored in the array.

However, the string length is:

```text
5
```

because `'\0'` only marks the end of the string.

So:

```c
strlen("Hello")
```

returns:

```text
5
```

not `6`.

---

## 11. Finding Length of Different Strings

### Example

```c
#include <stdio.h>
#include <string.h>

int main() {
    char name[] = "Owais";
    char language[] = "C";
    char message[] = "Hello World";

    printf("%zu\n", strlen(name));
    printf("%zu\n", strlen(language));
    printf("%zu", strlen(message));

    return 0;
}
```


```output
5
1
11
```

The space in `"Hello World"` is also a character, so its length is `11`.

---

## 12. Finding String Length Without `strlen()`

We can also find the length manually using a loop.

The loop continues until it reaches `'\0'`.

### Example

```c
#include <stdio.h>

int main() {
    char word[] = "Hello";
    int length = 0;

    while (word[length] != '\0') {
        length++;
    }

    printf("Length = %d", length);

    return 0;
}
```


```output
Length = 5
```

The variable `length` counts each character until the null character is reached.

---

## 13. Reading and Finding the Length

We can combine string input with `strlen()`.

### Example

```c
#include <stdio.h>
#include <string.h>

int main() {
    char name[50];

    printf("Enter your name: ");
    scanf("%49s", name);

    printf("Name: %s\n", name);
    printf("Length: %zu", strlen(name));

    return 0;
}
```


```output
Enter your name: Owais
Name: Owais
Length: 5
```

The `49` in:

```c
scanf("%49s", name);
```

limits the number of characters read so that space remains for the null character.

---

## 14. Reading a Full Name and Finding Its Length

For input containing spaces, `fgets()` can be used.

### Example

```c
#include <stdio.h>
#include <string.h>

int main() {
    char name[50];

    printf("Enter your full name: ");
    fgets(name, sizeof(name), stdin);

    printf("Name: %s", name);
    printf("Length: %zu", strlen(name));

    return 0;
}
```

When using `fgets()`, the newline entered by the user may also be stored in the array.

For example, the input:

```text
Owais
```

may be stored as:

```text
O  w  a  i  s  \n  \0
```

Therefore, `strlen()` can include the newline character when it is present.

---

## 15. String Length Using a Function

We can create our own function to find the length of a string.

### Example

```c
#include <stdio.h>

int stringLength(char str[]) {
    int length = 0;

    while (str[length] != '\0') {
        length++;
    }

    return length;
}

int main() {
    char word[] = "Programming";

    printf("Length = %d", stringLength(word));

    return 0;
}
```


```output
Length = 11
```

This function counts characters until it reaches `'\0'`.

---

## 16. Important String Format Specifiers

Some commonly used format specifiers are:

| Format Specifier | Purpose                     |
| ---------------- | --------------------------- |
| `%s`             | Read or print a string      |
| `%c`             | Read or print one character |
| `%d`             | Integer                     |
| `%f`             | Floating-point value        |

For strings, the most important ones are:

```text
%s → string
%c → character
```

## 17. Real-World Example 🌍

Imagine a registration form that asks a student for their name.

The program can read the name and determine how many characters it contains.

### Example

```c
#include <stdio.h>
#include <string.h>

int main() {
    char name[50];

    printf("Enter your name: ");
    fgets(name, sizeof(name), stdin);

    printf("You entered: %s", name);
    printf("Number of characters: %zu", strlen(name));

    return 0;
}
```

### Example Output

```output
Enter your name: Owais
You entered: Owais
Number of characters: 6
```

The length may be `6` here because `fgets()` can store the newline character along with the input.

## Common Mistakes ⚠️

### 1. Using `&` with a string in `scanf()`

For a character array:

```c
char name[20];
```

use:

```c
scanf("%19s", name);
```

not:

```c
scanf("%19s", &name);
```

### 2. Expecting `%s` to read spaces

This:

```c
scanf("%s", name);
```

reads only one word.

For example:

```text
Mohammed Owais
```

will be read as:

```text
Mohammed
```

Use `fgets()` when you need to read a complete line.

### 3. Forgetting `<string.h>`

When using:

```c
strlen(name)
```

include:

```c
#include <string.h>
```

### 4. Counting `'\0'` as part of the string length

For:

```text
Hello\0
```

the string length is:

```text
5
```

not `6`.

### 5. Forgetting the newline with `fgets()`

`fgets()` may store the newline character when there is enough space.

For example:

```text
Owais\n\0
```

contains the newline character as part of the stored input.

---

## Key Points 📌

* `%s` can be used with `scanf()` to read a single word.
* `%s` stops reading when whitespace is encountered.
* `fgets()` can read a complete line containing spaces.
* `%s` is used with `printf()` to print a complete string.
* `%c` is used to print a single character.
* `strlen()` is used to find the length of a string.
* `strlen()` does not count the null character `'\0'`.
* `strlen()` is declared in `<string.h>`.
* `fgets()` may store the newline character in the string.
* A string's length is the number of characters before `'\0'`.
