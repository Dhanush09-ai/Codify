# Chapter 8: Strings

## Section 1: Introduction to Strings

A **string** is a sequence of characters.

In C, strings are stored using an array of characters.

For example:

```text
Hello
```

is a string containing five characters.

In C, a string is always ended with a special character called the **null character**:

```c
'\0'
```

The null character tells C where the string ends.

---

## 1. What is a String?

A string can contain:

* Letters
* Numbers
* Spaces
* Special characters

For example:

```text
Hello
Owais
C Programming
12345
```

In C, strings are represented using a `char` array.

### Example

```c
#include <stdio.h>

int main() {
    char name[] = "Owais";

    printf("%s", name);

    return 0;
}
```


```output
Owais
```

Here:

```c
char name[] = "Owais";
```

creates a character array containing the string `"Owais"`.

---

## 2. Strings are Character Arrays

A string in C is stored as an array of characters.

For example:

```c
char name[] = "Hello";
```

is stored conceptually as:

```text
H  e  l  l  o  \0
```

The `\0` is the **null character**.

It marks the end of the string.

So `"Hello"` requires **6 characters of storage**, not 5.

---

## 3. Character Array vs String

A character array and a string are closely related, but a valid C string must end with `'\0'`.

### Character Array

```c
char letters[] = {'H', 'e', 'l', 'l', 'o'};
```

This is an array of characters, but it does not contain a null character.

### String

```c
char word[] = {'H', 'e', 'l', 'l', 'o', '\0'};
```

This is a proper C string.

The simpler way to create the same string is:

```c
char word[] = "Hello";
```

C automatically adds the null character.

---

## 4. Declaring a String

A string can be declared using a character array.

The general syntax is:

```c
char string_name[size];
```

For example:

```c
char name[20];
```

This creates a character array that can store a string of up to **19 characters**, because one position is needed for `'\0'`.

We can also let C determine the size:

```c
char name[] = "Owais";
```

C automatically allocates enough space for the characters and the null character.

---

## 5. Initializing a String

There are different ways to initialize a string.

### Using a String Literal

```c
char name[] = "Owais";
```

This is the most common method.

### Using Individual Characters

```c
char name[] = {'O', 'w', 'a', 'i', 's', '\0'};
```

Both represent the same string.

### Example

```c
#include <stdio.h>

int main() {
    char name1[] = "Owais";
    char name2[] = {'O', 'w', 'a', 'i', 's', '\0'};

    printf("%s\n", name1);
    printf("%s", name2);

    return 0;
}
```


```output
Owais
Owais
```

---

## 6. The Null Character `'\0'`

The null character is written as:

```c
'\0'
```

It has a special purpose in C strings.

It tells string-related functions where the string ends.

For example:

```text
C  \0
```

represents the string:

```text
C
```

Another example:

```text
C  o  d  i  f  y  \0
```

represents:

```text
Codify
```

The null character is **not normally displayed** when the string is printed.

---

## 7. Printing a String

The `%s` format specifier is used to print a string.

### Example

```c
#include <stdio.h>

int main() {
    char language[] = "C Programming";

    printf("%s", language);

    return 0;
}
```


```output
C Programming
```

Here `%s` tells `printf()` that the value is a string.

---

## 8. Accessing Individual Characters

Because a string is stored in a character array, we can access individual characters using an index.

For example:

```c
char word[] = "Hello";
```

The characters are stored as:

```text
Index:   0  1  2  3  4
         H  e  l  l  o
```

We can access them using:

```c
word[0]
word[1]
word[2]
```

### Example

```c
#include <stdio.h>

int main() {
    char word[] = "Hello";

    printf("%c\n", word[0]);
    printf("%c\n", word[2]);
    printf("%c", word[4]);

    return 0;
}
```


```output
H
l
o
```

Use `%c` when printing a single character.

Use `%s` when printing the complete string.

---

## 9. Changing Characters in a String

Since a string is stored in a character array, individual characters can be changed.

### Example

```c
#include <stdio.h>

int main() {
    char word[] = "Hello";

    word[0] = 'Y';

    printf("%s", word);

    return 0;
}
```


```output
Yello
```

Only the first character was changed:

```text
Hello
↓
Yello
```

---

## 10. Traversing a String

We can use a loop to visit every character in a string.

A common condition is:

```c
word[i] != '\0'
```

This means the loop continues until the null character is reached.

### Example

```c
#include <stdio.h>

int main() {
    char word[] = "Hello";

    for (int i = 0; word[i] != '\0'; i++) {
        printf("%c\n", word[i]);
    }

    return 0;
}
```


```output
H
e
l
l
o
```

The loop stops when it reaches `'\0'`.

---

## 11. String Length and Array Size

Consider:

```c
char word[] = "Hello";
```

The string contains:

```text
5 characters
```

But the character array requires:

```text
6 positions
```

because it also stores:

```c
'\0'
```

So:

```text
H  e  l  l  o  \0
```

has 6 characters in memory, while the string's visible length is 5.

This difference is important when working with strings.

---

## 12. Strings with Spaces

A string can contain spaces.

For example:

```c
char message[] = "Hello World";
```

contains a space between `Hello` and `World`.

### Example

```c
#include <stdio.h>

int main() {
    char message[] = "Hello World";

    printf("%s", message);

    return 0;
}
```


```output
Hello World
```

The space is also a character stored in the array.

## 13. Common String Examples

Strings are commonly used to store:

| Type of Data | Example           |
| ------------ | ----------------- |
| Name         | `"Owais"`         |
| City         | `"Nandyal"`       |
| Language     | `"C"`             |
| Message      | `"Hello World"`   |
| Course       | `"C Programming"` |

For example:

```c
char name[] = "Owais";
char city[] = "Nandyal";
char course[] = "C Programming";
```

## 14. Real-World Example 🌍

Imagine a student registration program.

The program may need to store:

* Student name
* City
* Course name

These values can be stored using strings.

### Example

```c
#include <stdio.h>

int main() {
    char name[] = "Owais";
    char city[] = "Nandyal";
    char course[] = "C Programming";

    printf("Name: %s\n", name);
    printf("City: %s\n", city);
    printf("Course: %s", course);

    return 0;
}
```


```output
Name: Owais
City: Nandyal
Course: C Programming
```

## Common Mistakes ⚠️

### 1. Forgetting the Null Character

When manually creating a string using characters, remember to include:

```c
'\0'
```

For example:

```c
char word[] = {'H', 'i', '\0'};
```

### 2. Using `%c` to Print a Complete String

This prints only one character:

```c
printf("%c", word);
```

Use:

```c
printf("%s", word);
```

to print the complete string.

### 3. Using `%s` for One Character

For one character:

```c
printf("%c", word[0]);
```

For a complete string:

```c
printf("%s", word);
```

### 4. Forgetting That Indexing Starts at 0

For:

```c
char word[] = "Hello";
```

the indexes are:

```text
H → 0
e → 1
l → 2
l → 3
o → 4
```

### 5. Not Leaving Space for `'\0'`

If you want to manually create space for a string of 5 characters, you need at least:

```c
char word[6];
```

because one extra position is required for `'\0'`.

---

## Key Points 📌

* A string is a sequence of characters.
* C stores strings using character arrays.
* Strings end with the null character `'\0'`.
* `%s` is used to print a complete string.
* `%c` is used to print a single character.
* String indexing starts from `0`.
* Individual characters can be accessed using indexes.
* Individual characters can be changed in a character array.
* A string containing 5 visible characters needs at least 6 positions when stored with its null character.
* Strings are useful for storing names, messages, city names, course names, and other text.
