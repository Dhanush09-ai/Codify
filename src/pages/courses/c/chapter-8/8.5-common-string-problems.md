# Chapter 8: Strings

## Section 5: Common String Problems

While working with strings in C, some problems occur frequently.

These problems usually happen because strings are character arrays and must always be handled carefully.

In this section, we will look at some common string problems and how to solve them.

---

## 1. Finding the Length of a String

The `strlen()` function can be used to find the number of characters in a string.

### Example

```c
#include <stdio.h>
#include <string.h>

int main() {
    char text[] = "Hello";

    printf("Length = %zu", strlen(text));

    return 0;
}
```


```output
Length = 5
```

Remember that `strlen()` does **not** count the null character `'\0'`.

---

## 2. Counting Characters Manually

We can also find the length of a string using a loop.

### Example

```c
#include <stdio.h>

int main() {
    char text[] = "Hello";
    int count = 0;

    while (text[count] != '\0') {
        count++;
    }

    printf("Length = %d", count);

    return 0;
}
```


```output
Length = 5
```

The loop continues until it reaches `'\0'`.

---

## 3. Counting Vowels in a String

A common problem is counting how many vowels are present in a string.

The vowels are:

```text
a, e, i, o, u
```

### Example

```c
#include <stdio.h>

int main() {
    char text[] = "programming";
    int count = 0;
    int i = 0;

    while (text[i] != '\0') {
        if (text[i] == 'a' || text[i] == 'e' ||
            text[i] == 'i' || text[i] == 'o' ||
            text[i] == 'u') {
            count++;
        }

        i++;
    }

    printf("Vowels = %d", count);

    return 0;
}
```


```output
Vowels = 3
```

The vowels in `"programming"` are:

```text
o, a, i
```

---

## 4. Counting Digits in a String

A string can contain numbers as characters.

For example:

```text
"abc123"
```

contains three digit characters.

### Example

```c
#include <stdio.h>

int main() {
    char text[] = "abc123xyz";
    int count = 0;
    int i = 0;

    while (text[i] != '\0') {
        if (text[i] >= '0' && text[i] <= '9') {
            count++;
        }

        i++;
    }

    printf("Digits = %d", count);

    return 0;
}
```


```output
Digits = 3
```

The condition:

```c
text[i] >= '0' && text[i] <= '9'
```

checks whether the current character is a digit.

---

## 5. Counting Spaces in a String

Spaces are also characters inside a string.

### Example

```c
#include <stdio.h>

int main() {
    char text[] = "C programming is easy";
    int count = 0;
    int i = 0;

    while (text[i] != '\0') {
        if (text[i] == ' ') {
            count++;
        }

        i++;
    }

    printf("Spaces = %d", count);

    return 0;
}
```


```output
Spaces = 3
```

There are three spaces between the words.

## 6. Reversing a String

Another common string problem is reversing the characters.

For example:

```text
Hello
```

becomes:

```text
olleH
```

### Example

```c
#include <stdio.h>
#include <string.h>

int main() {
    char text[] = "Hello";
    int i;
    int length = strlen(text);

    for (i = length - 1; i >= 0; i--) {
        printf("%c", text[i]);
    }

    return 0;
}
```


```output
olleH
```

The loop starts from the last character and moves toward the first character.

---

## 7. Checking Whether a String Is a Palindrome

A palindrome is a word or string that reads the same forward and backward.

For example:

```text
madam
```

is a palindrome.

### Example

```c
#include <stdio.h>
#include <string.h>

int main() {
    char text[] = "madam";
    int left = 0;
    int right = strlen(text) - 1;
    int palindrome = 1;

    while (left < right) {
        if (text[left] != text[right]) {
            palindrome = 0;
            break;
        }

        left++;
        right--;
    }

    if (palindrome) {
        printf("Palindrome");
    } else {
        printf("Not a palindrome");
    }

    return 0;
}
```


```output
Palindrome
```

The first and last characters are compared, then the second and second-last characters, and so on.

## 8. Converting Lowercase Characters to Uppercase

A string can contain lowercase letters.

We can convert them to uppercase using character ranges.

### Example

```c
#include <stdio.h>

int main() {
    char text[] = "hello";
    int i = 0;

    while (text[i] != '\0') {
        if (text[i] >= 'a' && text[i] <= 'z') {
            text[i] = text[i] - 'a' + 'A';
        }

        i++;
    }

    printf("%s", text);

    return 0;
}
```


```output
HELLO
```

The program checks each character and changes lowercase letters to uppercase.

---

## 9. Converting Uppercase Characters to Lowercase

The same idea can be used in the opposite direction.

### Example

```c
#include <stdio.h>

int main() {
    char text[] = "HELLO";
    int i = 0;

    while (text[i] != '\0') {
        if (text[i] >= 'A' && text[i] <= 'Z') {
            text[i] = text[i] - 'A' + 'a';
        }

        i++;
    }

    printf("%s", text);

    return 0;
}
```


```output
hello
```

## 10. Counting Words in a String

A simple way to count words is to count spaces and add one, when the string contains normal single spaces between words.

### Example

```c
#include <stdio.h>

int main() {
    char text[] = "C programming is easy";
    int spaces = 0;
    int i = 0;

    while (text[i] != '\0') {
        if (text[i] == ' ') {
            spaces++;
        }

        i++;
    }

    printf("Words = %d", spaces + 1);

    return 0;
}
```


```output
Words = 4
```

The words are:

```text
C
programming
is
easy
```

> ⚠️ This simple method assumes there is one space between words and no unnecessary spaces at the beginning or end.

## 11. Finding the First Occurrence of a Character

The `strchr()` function can be used to search for a character.

### Example

```c
#include <stdio.h>
#include <string.h>

int main() {
    char text[] = "programming";

    char *result = strchr(text, 'g');

    if (result != NULL) {
        printf("Character found");
    } else {
        printf("Character not found");
    }

    return 0;
}
```


```output
Character found
```

`strchr()` returns a pointer to the first occurrence of the character.

---

## 12. Finding a Substring

The `strstr()` function searches for one string inside another string.

### Example

```c
#include <stdio.h>
#include <string.h>

int main() {
    char text[] = "I like programming";

    if (strstr(text, "programming") != NULL) {
        printf("Substring found");
    } else {
        printf("Substring not found");
    }

    return 0;
}
```


```output
Substring found
```

This is useful when checking whether a particular word or text exists inside a larger string.

## 13. Removing the Newline from `fgets()`

When `fgets()` reads a line, it can store the newline character `'\n'` when the user presses Enter.

For example, the input:

```text
Hello
```

may be stored as:

```text
H e l l o \n \0
```

We can remove the newline using `strcspn()`.

### Example

```c
#include <stdio.h>
#include <string.h>

int main() {
    char name[50];

    printf("Enter your name: ");
    fgets(name, sizeof(name), stdin);

    name[strcspn(name, "\n")] = '\0';

    printf("Hello %s", name);

    return 0;
}
```

### Input

```text
Owais
```


```output
Enter your name: Hello Owais
```

`strcspn()` finds the position of the newline character, and we replace it with `'\0'`.

## 14. Comparing Strings Correctly

A common mistake is trying to compare strings using `==`.

Incorrect:

```c
if (str1 == str2)
```

For character arrays, use `strcmp()`.

### Correct Example

```c
#include <stdio.h>
#include <string.h>

int main() {
    char str1[] = "Hello";
    char str2[] = "Hello";

    if (strcmp(str1, str2) == 0) {
        printf("Same");
    } else {
        printf("Different");
    }

    return 0;
}
```


```output
Same
```

---

## 15. Copying a String Safely

When copying strings, the destination array must have enough space.

### Example

```c
#include <stdio.h>
#include <string.h>

int main() {
    char source[] = "Hello";
    char destination[20];

    strcpy(destination, source);

    printf("%s", destination);

    return 0;
}
```


```output
Hello
```

The destination has enough space for the characters and the null character.

## 🌍 Real-World Example: Analyzing a Message

Suppose a program receives a message and needs to count the number of vowels.

```c
#include <stdio.h>

int main() {
    char message[] = "Welcome to Codify";
    int vowels = 0;
    int i = 0;

    while (message[i] != '\0') {
        if (message[i] == 'a' || message[i] == 'e' ||
            message[i] == 'i' || message[i] == 'o' ||
            message[i] == 'u' ||
            message[i] == 'A' || message[i] == 'E' ||
            message[i] == 'I' || message[i] == 'O' ||
            message[i] == 'U') {
            vowels++;
        }

        i++;
    }

    printf("Vowels = %d", vowels);

    return 0;
}
```


```output
Vowels = 6
```

String problems like counting characters, searching text, checking palindromes, and changing letter case are common in beginner C programs.

## ⚠️ Common Mistakes

### 1. Forgetting the null character

Every normal C string must end with:

```c
'\0'
```

Do not accidentally remove or overwrite it.

---

### 2. Using `==` to compare strings

Incorrect:

```c
str1 == str2
```

Use:

```c
strcmp(str1, str2) == 0
```

---

### 3. Buffer too small

Always make sure the character array has enough space for:

* all characters
* the null character `'\0'`

---

### 4. Ignoring the newline from `fgets()`

`fgets()` can store `'\n'`.

If necessary, remove it before processing the string.

---

### 5. Forgetting case sensitivity

These are different strings:

```text
Hello
hello
```

String functions such as `strcmp()` treat uppercase and lowercase characters differently.

---

### 6. Incorrect word counting

Counting spaces and adding one is only a simple method.

It may give incorrect results when there are:

* multiple spaces
* leading spaces
* trailing spaces
* tabs

---

## 🔑 Key Points

* Strings are character arrays ending with `'\0'`.
* `strlen()` finds the number of characters.
* A loop can also be used to process every character.
* Vowels, digits, spaces, and other characters can be counted.
* Strings can be reversed using indexes.
* A palindrome can be checked by comparing characters from both ends.
* Lowercase and uppercase characters can be converted using character ranges.
* `strcmp()` is used to compare string contents.
* `strchr()` searches for a character.
* `strstr()` searches for a substring.
* `fgets()` may store a newline character.
* Always make sure character arrays have enough space.
