# Chapter 8: Strings

## Section 3: Copying & Concatenating Strings

In C, strings are stored as arrays of characters ending with a special character called the **null character (`'\0'`)**.

C provides functions to **copy** one string into another and **join (concatenate)** two strings.

The commonly used functions are:

| Function    | Purpose                                 |
| ----------- | --------------------------------------- |
| `strcpy()`  | Copies one string into another          |
| `strncpy()` | Copies a specified number of characters |
| `strcat()`  | Joins two strings                       |
| `strncat()` | Joins a specified number of characters  |

These functions are available in the `<string.h>` header file.

---

## 1. Copying Strings with `strcpy()`

The `strcpy()` function copies the complete string from one character array to another.

### Syntax

```c
strcpy(destination, source);
```

* `destination` → string where the data is copied
* `source` → string that is copied

### Example

```c
#include <stdio.h>
#include <string.h>

int main() {
    char source[] = "Hello";
    char destination[20];

    strcpy(destination, source);

    printf("%s", destination);

    return 0;
}
```


```output
Hello
```

The contents of `source` are copied into `destination`.

---

## 2. How `strcpy()` Works

Suppose we have:

```c
char source[] = "Hello";
char destination[20];

strcpy(destination, source);
```

The characters are copied one by one, including the null character `'\0'`.

Conceptually:

```text
source:      H  e  l  l  o  \0
             ↓  ↓  ↓  ↓  ↓  ↓
destination: H  e  l  l  o  \0
```

After copying, both arrays contain the string `"Hello"`.

> ⚠️ The destination array must have enough space to store the copied string, including the null character.

---

## 3. Copying with `strncpy()`

The `strncpy()` function copies a specified number of characters from one string to another.

### Syntax

```c
strncpy(destination, source, n);
```

Here, `n` specifies the maximum number of characters to copy.

### Example

```c
#include <stdio.h>
#include <string.h>

int main() {
    char source[] = "Programming";
    char destination[20];

    strncpy(destination, source, 7);
    destination[7] = '\0';

    printf("%s", destination);

    return 0;
}
```


```output
Program
```

Only the first 7 characters are copied.

> 💡 When using `strncpy()`, be careful about the null character. If the source string is long enough, `strncpy()` may not automatically add `'\0'` when `n` characters are copied.

---

## 4. `strcpy()` vs `strncpy()`

| Function             | Description                                                  |
| -------------------- | ------------------------------------------------------------ |
| `strcpy()`           | Copies the complete source string                            |
| `strncpy()`          | Copies up to a specified number of characters                |
| Number of characters | `strcpy()` decides based on `'\0'`                           |
| Control              | `strncpy()` gives control over the maximum characters copied |

### Example

```c
char source[] = "Computer";
char a[20];
char b[20];

strcpy(a, source);

strncpy(b, source, 4);
b[4] = '\0';
```

Now:

```text
a → Computer
b → Comp
```

---

## 5. Concatenating Strings with `strcat()`

**Concatenation** means joining two strings together.

The `strcat()` function adds the second string to the end of the first string.

### Syntax

```c
strcat(destination, source);
```

The `source` string is added to the end of `destination`.

### Example

```c
#include <stdio.h>
#include <string.h>

int main() {
    char first[30] = "Hello ";
    char second[] = "World";

    strcat(first, second);

    printf("%s", first);

    return 0;
}
```


```output
Hello World
```

Before `strcat()`:

```text
first  → "Hello "
second → "World"
```

After `strcat()`:

```text
first → "Hello World"
```

The original `second` string remains unchanged.

---

## 6. Concatenating More Than Two Strings

You can use `strcat()` multiple times.

### Example

```c
#include <stdio.h>
#include <string.h>

int main() {
    char text[50] = "C";
    
    strcat(text, " Programming");
    strcat(text, " Language");

    printf("%s", text);

    return 0;
}
```


```output
C Programming Language
```

Each call adds the new string to the end of `text`.

---

## 7. Adding a Space Between Strings

When joining strings, C does not automatically add spaces.

For example:

```c
char first[30] = "Hello";
char second[] = "World";

strcat(first, second);
```

The result is:

```text
HelloWorld
```

If you want a space, include it yourself.

### Example

```c
#include <stdio.h>
#include <string.h>

int main() {
    char first[30] = "Hello";
    char second[] = " World";

    strcat(first, second);

    printf("%s", first);

    return 0;
}
```


```output
Hello World
```

---

## 8. Concatenating Using `strncat()`

The `strncat()` function adds a specified number of characters from the source string.

### Syntax

```c
strncat(destination, source, n);
```

### Example

```c
#include <stdio.h>
#include <string.h>

int main() {
    char first[30] = "Hello ";
    char second[] = "Programming";

    strncat(first, second, 4);

    printf("%s", first);

    return 0;
}
```


```output
Hello Prog
```

Only the first 4 characters of `second` are added.

---

## 9. Copying a String to the End of Another String

You can also use the end position of a string as the destination.

For example:

```c
strcpy(str1 + strlen(str1), str2);
```

Suppose:

```c
char str1[30] = "Hello ";
char str2[] = "World";
```

Then:

```c
strcpy(str1 + strlen(str1), str2);
```

copies `str2` starting at the end of `str1`.

The result is:

```text
Hello World
```

This works because:

```c
strlen(str1)
```

gives the position of the null character at the end of the string.

So:

```c
str1 + strlen(str1)
```

points to the location where the new string can begin.

### Example

```c
#include <stdio.h>
#include <string.h>

int main() {
    char str1[30] = "Hello ";
    char str2[] = "World";

    strcpy(str1 + strlen(str1), str2);

    printf("%s", str1);

    return 0;
}
```


```output
Hello World
```

This produces a result similar to using:

```c
strcat(str1, str2);
```

---

## 10. Copying and Concatenating Strings Together

We can use both `strcpy()` and `strcat()` in the same program.

### Example

```c
#include <stdio.h>
#include <string.h>

int main() {
    char first[50];
    char last[] = "Mohammed";

    strcpy(first, "Hello ");
    strcat(first, last);

    printf("%s", first);

    return 0;
}
```


```output
Hello Mohammed
```

Here:

1. `strcpy()` creates the initial string.
2. `strcat()` adds another string to its end.

---

## 11. Important Difference Between Copying and Concatenating

Copying and concatenating perform different operations.

### Copying

```c
strcpy(destination, source);
```

The destination becomes a copy of the source.

```text
Before:

destination → "Apple"
source      → "Mango"

After:

destination → "Mango"
source      → "Mango"
```

### Concatenating

```c
strcat(destination, source);
```

The source is added to the end of the destination.

```text
Before:

destination → "Apple"
source      → "Mango"

After:

destination → "AppleMango"
source      → "Mango"
```

## 12. String Function Summary

| Function    | Purpose                 | Example            |
| ----------- | ----------------------- | ------------------ |
| `strcpy()`  | Copy complete string    | `strcpy(a, b)`     |
| `strncpy()` | Copy limited characters | `strncpy(a, b, 5)` |
| `strcat()`  | Join complete string    | `strcat(a, b)`     |
| `strncat()` | Join limited characters | `strncat(a, b, 5)` |

All these functions require:

```c
#include <string.h>
```

## 🌍 Real-World Example: Creating a Full Name

Suppose a program stores a person's first name and last name separately.

We can combine them into a full name.

```c
#include <stdio.h>
#include <string.h>

int main() {
    char firstName[] = "Owais";
    char lastName[] = "Mohammed";
    char fullName[50];

    strcpy(fullName, firstName);
    strcat(fullName, " ");
    strcat(fullName, lastName);

    printf("Full Name: %s", fullName);

    return 0;
}
```


```output
Full Name: Owais Mohammed
```

This type of operation can be useful when creating names, addresses, messages, or other text from separate pieces.

## ⚠️ Common Mistakes

### 1. Destination array is too small

Incorrect:

```c
char destination[5];

strcpy(destination, "Hello World");
```

The destination does not have enough space.

Make sure the destination array is large enough.

---

### 2. Forgetting `<string.h>`

String functions such as `strcpy()` and `strcat()` require:

```c
#include <string.h>
```

---

### 3. Confusing `strcpy()` and `strcat()`

Remember:

```c
strcpy(a, b);
```

means **copy `b` into `a`**.

```c
strcat(a, b);
```

means **add `b` to the end of `a`**.

---

### 4. Forgetting the space

This:

```c
strcat(first, last);
```

may produce:

```text
OwaisMohammed
```

If you need a space, add one:

```c
strcat(first, " ");
strcat(first, last);
```

---

### 5. Forgetting the null character with `strncpy()`

When using `strncpy()`, make sure the destination is properly null-terminated when necessary.

For example:

```c
strncpy(destination, source, 5);
destination[5] = '\0';
```

---

## 🔑 Key Points

* `strcpy()` copies a complete string.
* `strncpy()` copies a specified number of characters.
* `strcat()` joins one string to the end of another.
* `strncat()` joins a specified number of characters.
* These functions are declared in `<string.h>`.
* The destination array must have enough space.
* `strcpy()` replaces the destination contents.
* `strcat()` keeps the destination contents and adds the source at the end.
* C does not automatically add spaces while concatenating.
* Be careful about the null character `'\0'`, especially when using `strncpy()`.
