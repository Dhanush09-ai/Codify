# Chapter 3: Operators

## Section 2: Relational & Logical Operators

**Relational operators** are used to compare two values.

**Logical operators** are used to combine multiple conditions.

These operators are commonly used when making decisions in a C program.

---

## 1. Relational Operators

Relational operators compare two values.

The result of a relational expression is either:

* `1` → True
* `0` → False

For example:

```c
int a = 10;
int b = 5;

printf("%d", a > b);
```

```output
1
```

Since `10` is greater than `5`, the condition is true.

---

## 2. Relational Operators in C

C provides these relational operators:

| Operator | Meaning                  | Example    |
| -------- | ------------------------ | ---------- |
| `>`      | Greater than             | `10 > 5`   |
| `<`      | Less than                | `10 < 5`   |
| `>=`     | Greater than or equal to | `10 >= 10` |
| `<=`     | Less than or equal to    | `5 <= 10`  |
| `==`     | Equal to                 | `10 == 10` |
| `!=`     | Not equal to             | `10 != 5`  |

Let's understand them with examples.

---

## 3. Greater Than `>`

The `>` operator checks whether the first value is greater than the second value.

```c
#include <stdio.h>

int main()
{
    int a = 10;
    int b = 5;

    printf("%d", a > b);

    return 0;
}
```

```output
1
```

`10 > 5` is true, so the result is `1`.

---

## 4. Less Than `<`

The `<` operator checks whether the first value is less than the second value.

```c
#include <stdio.h>

int main()
{
    int a = 5;
    int b = 10;

    printf("%d", a < b);

    return 0;
}
```

```output
1
```

`5 < 10` is true.

---

## 5. Greater Than or Equal To `>=`

The `>=` operator checks whether the first value is greater than or equal to the second value.

```c
#include <stdio.h>

int main()
{
    int a = 10;
    int b = 10;

    printf("%d", a >= b);

    return 0;
}
```

```output
1
```

The condition is true because `10` is equal to `10`.

---

## 6. Less Than or Equal To `<=`

The `<=` operator checks whether the first value is less than or equal to the second value.

```c
#include <stdio.h>

int main()
{
    int a = 5;
    int b = 10;

    printf("%d", a <= b);

    return 0;
}
```

```output
1
```

The condition is true because `5` is less than `10`.

---

## 7. Equal To `==`

The `==` operator checks whether two values are equal.

```c
#include <stdio.h>

int main()
{
    int a = 10;
    int b = 10;

    printf("%d", a == b);

    return 0;
}
```

```output
1
```

### `=` vs `==`

These two operators are different.

`=` is the **assignment operator**:

```c
int number = 10;
```

`==` is the **equality operator**:

```c
number == 10
```

The first assigns a value, while the second compares values.

---

## 8. Not Equal To `!=`

The `!=` operator checks whether two values are different.

```c
#include <stdio.h>

int main()
{
    int a = 10;
    int b = 5;

    printf("%d", a != b);

    return 0;
}
```

```output
1
```

Since `10` and `5` are different, the result is `1`.

---

## 9. Logical Operators

Logical operators are used to combine or reverse conditions.

C has three main logical operators:

| Operator | Name        | Meaning                      |            |                                     |
| -------- | ----------- | ---------------------------- | ---------- | ----------------------------------- |
| `&&`     | Logical AND | Both conditions must be true |            |                                     |
| `        |             | `                            | Logical OR | At least one condition must be true |
| `!`      | Logical NOT | Reverses the result          |            |                                     |

---

## 10. Logical AND `&&`

The `&&` operator returns true only when **both conditions are true**.

For example:

```c
#include <stdio.h>

int main()
{
    int age = 20;

    printf("%d", age >= 18 && age <= 60);

    return 0;
}
```

```output
1
```

Both conditions are true:

```text
age >= 18  → true
age <= 60  → true
```

Therefore, the final result is `1`.

---

## 11. Logical OR `||`

The `||` operator returns true when **at least one condition is true**.

```c
#include <stdio.h>

int main()
{
    int age = 16;

    printf("%d", age < 18 || age > 60);

    return 0;
}
```

```output
1
```

The first condition is true:

```text
age < 18 → true
```

Therefore, the complete expression is true.

---

## 12. Logical NOT `!`

The `!` operator reverses a condition.

For example:

```c
#include <stdio.h>

int main()
{
    int a = 10;
    int b = 5;

    printf("%d", !(a < b));

    return 0;
}
```

```output
1
```

Here:

```text
a < b → false
```

The `!` operator reverses false to true.

---

## 13. Combining Relational and Logical Operators

Relational and logical operators can be used together.

For example:

```c
#include <stdio.h>

int main()
{
    int marks = 75;

    printf("%d", marks >= 40 && marks <= 100);

    return 0;
}
```

```output
1
```

Both conditions are true:

```text
marks >= 40 → true
marks <= 100 → true
```

Therefore, the final result is `1`.

---

## 14. Using Operators with User Input

We can take values from the user and compare them.

```c
#include <stdio.h>

int main()
{
    int age;

    printf("Enter your age: ");
    scanf("%d", &age);

    printf("Adult: %d", age >= 18);

    return 0;
}
```

If the user enters:

```text
20
```

The output will be:

```output
Enter your age: 20
Adult: 1
```

If the user enters a value below `18`, the comparison produces `0`.

---

## Real-World Example 🌍

Relational and logical operators can be used to check whether a student has passed an exam.

For example, suppose a student needs at least `40` marks.

```c
#include <stdio.h>

int main()
{
    int marks;

    printf("Enter your marks: ");
    scanf("%d", &marks);

    printf("Passed: %d", marks >= 40);

    return 0;
}
```

If the user enters:

```text
75
```

The output will be:

```output
Enter your marks: 75
Passed: 1
```

The expression:

```c
marks >= 40
```

checks whether the marks are greater than or equal to `40`.

## Common Mistakes

### Using `=` Instead of `==`

Incorrect when comparing:

```c
if (age = 18)
```

The `=` operator assigns a value.

For comparison, use:

```c
if (age == 18)
```

### Confusing `&&` and `||`

`&&` requires both conditions to be true.

```c
age >= 18 && age <= 60
```

`||` requires at least one condition to be true.

```c
age < 18 || age > 60
```

### Forgetting That Comparisons Produce `0` or `1`

For example:

```c
printf("%d", 10 > 5);
```

The result is:

```text
1
```

A false comparison produces:

```text
0
```

---

## Key Points

* Relational operators are used to compare values.
* A true relational expression produces `1`.
* A false relational expression produces `0`.
* `>` means greater than.
* `<` means less than.
* `>=` means greater than or equal to.
* `<=` means less than or equal to.
* `==` checks whether two values are equal.
* `!=` checks whether two values are different.
* `&&` means logical AND.
* `||` means logical OR.
* `!` means logical NOT.
* `=` and `==` have different purposes.
