# Chapter 3: Operators

## Section 5: Operator Precedence & Expressions

When an expression contains more than one operator, C needs to know **which operator should be evaluated first**.

This is called **operator precedence**.

For example:

```c
int result = 10 + 5 * 2;
```

The answer is `20`, not `30`, because multiplication has higher precedence than addition.

Understanding operator precedence helps you write expressions correctly and avoid unexpected results.

---

## 1. What is Operator Precedence?

**Operator precedence** determines the order in which operators are evaluated in an expression.

For example:

```c
int result = 10 + 5 * 2;
```

C evaluates:

```text
5 * 2
```

first.

Then:

```text
10 + 10
```

So the result is:

```text
20
```

### Example

```c id="precedence_basic"
#include <stdio.h>

int main() {
    int result = 10 + 5 * 2;

    printf("Result = %d", result);

    return 0;
}
```

```output id="precedence_basic_output"
Result = 20
```

---

## 2. Common Operator Precedence

Here are some commonly used operators in C, from **higher precedence to lower precedence**:

| Priority | Operators                   | Description                       |   |            |
| -------- | --------------------------- | --------------------------------- | - | ---------- |
| 1        | `()`                        | Parentheses                       |   |            |
| 2        | `*`, `/`, `%`               | Multiplication, Division, Modulus |   |            |
| 3        | `+`, `-`                    | Addition, Subtraction             |   |            |
| 4        | `<`, `<=`, `>`, `>=`        | Relational operators              |   |            |
| 5        | `==`, `!=`                  | Equality operators                |   |            |
| 6        | `&&`                        | Logical AND                       |   |            |
| 7        | `                           |                                   | ` | Logical OR |
| 8        | `?:`                        | Conditional operator              |   |            |
| 9        | `=`, `+=`, `-=`, `*=`, `/=` | Assignment operators              |   |            |

**Higher priority operators are evaluated before lower priority operators.**

---

## 3. Multiplication Before Addition

Multiplication, division, and modulus have higher precedence than addition and subtraction.

Consider:

```c
int result = 10 + 6 * 2;
```

First:

```text
6 * 2 = 12
```

Then:

```text
10 + 12 = 22
```

So:

```text
Result = 22
```

### Example

```c id="precedence_math"
#include <stdio.h>

int main() {
    int result = 10 + 6 * 2;

    printf("Result = %d", result);

    return 0;
}
```

```output id="precedence_math_output"
Result = 22
```

---

## 4. Using Parentheses

Parentheses `()` have very high precedence and can be used to control the order of evaluation.

For example:

```c
int result = (10 + 6) * 2;
```

First:

```text
10 + 6 = 16
```

Then:

```text
16 * 2 = 32
```

### Example

```c id="precedence_parentheses"
#include <stdio.h>

int main() {
    int result = (10 + 6) * 2;

    printf("Result = %d", result);

    return 0;
}
```

```output id="precedence_parentheses_output"
Result = 32
```

### Without Parentheses

```c
int result = 10 + 6 * 2;
```

Result:

```text
22
```

### With Parentheses

```c
int result = (10 + 6) * 2;
```

Result:

```text
32
```

Parentheses make the intended calculation clear.

---

## 5. Multiplication, Division and Modulus

The operators:

```text
*
/
%
```

have the same precedence.

When operators have the same precedence, C generally evaluates them from **left to right**.

For example:

```c
int result = 20 / 5 * 2;
```

First:

```text
20 / 5 = 4
```

Then:

```text
4 * 2 = 8
```

So the result is:

```text
8
```

### Example

```c id="same_precedence"
#include <stdio.h>

int main() {
    int result = 20 / 5 * 2;

    printf("Result = %d", result);

    return 0;
}
```

```output id="same_precedence_output"
Result = 8
```

---

## 6. Addition and Subtraction

The operators:

```text
+
-
```

also have the same precedence.

They are evaluated from **left to right**.

For example:

```c
int result = 20 - 5 + 3;
```

First:

```text
20 - 5 = 15
```

Then:

```text
15 + 3 = 18
```

So:

```text
Result = 18
```

### Example

```c id="add_sub_precedence"
#include <stdio.h>

int main() {
    int result = 20 - 5 + 3;

    printf("Result = %d", result);

    return 0;
}
```

```output id="add_sub_precedence_output"
Result = 18
```

---

## 7. Expressions in C

An **expression** is a combination of values, variables, constants, and operators that produces a result.

Examples:

```c
10 + 5
```

```c
a * b
```

```c
x > 10
```

```c
a + b * c
```

### Example

```c id="expression_example"
#include <stdio.h>

int main() {
    int a = 10;
    int b = 5;

    int result = a + b * 2;

    printf("Result = %d", result);

    return 0;
}
```

```output id="expression_example_output"
Result = 20
```

Here:

```text
b * 2
```

is evaluated first.

Then:

```text
a + 10
```

is evaluated.

---

## 8. Relational Expressions

Relational operators can also be used in expressions.

For example:

```c
int result = 10 + 5 > 12;
```

C first evaluates:

```text
10 + 5
```

which gives:

```text
15
```

Then:

```text
15 > 12
```

which is true.

In C, a true condition normally produces `1`.

So:

```text
Result = 1
```

### Example

```c id="relational_expression"
#include <stdio.h>

int main() {
    int result = 10 + 5 > 12;

    printf("Result = %d", result);

    return 0;
}
```

```output id="relational_expression_output"
Result = 1
```

---

## 9. Logical Expressions

Logical operators can also be combined with other operators.

For example:

```c
int result = 10 > 5 && 8 < 12;
```

The relational expressions are evaluated first:

```text
10 > 5  →  1
8 < 12  →  1
```

Then:

```text
1 && 1
```

gives:

```text
1
```

### Example

```c id="logical_expression"
#include <stdio.h>

int main() {
    int result = 10 > 5 && 8 < 12;

    printf("Result = %d", result);

    return 0;
}
```

```output id="logical_expression_output"
Result = 1
```

---

## 10. Changing the Order with Parentheses

Parentheses are useful when you want a specific part of an expression to be evaluated first.

Consider:

```c
int result = 10 + 5 * 2;
```

Result:

```text
20
```

Now add parentheses:

```c
int result = (10 + 5) * 2;
```

Result:

```text
30
```

### Example

```c id="change_order"
#include <stdio.h>

int main() {
    int result1 = 10 + 5 * 2;
    int result2 = (10 + 5) * 2;

    printf("Without parentheses = %d\n", result1);
    printf("With parentheses = %d", result2);

    return 0;
}
```

```output id="change_order_output"
Without parentheses = 20
With parentheses = 30
```

---

## 11. A Simple Rule to Remember

For many beginner-level arithmetic expressions, remember:

```text
Parentheses
     ↓
*, /, %
     ↓
+, -
     ↓
Relational
     ↓
Equality
     ↓
&&
     ↓
||
     ↓
Assignment
```

Operators higher in the list are generally evaluated first.

When operators have the same precedence, their **associativity** determines the evaluation direction.

## 12. Real-World Example 🌍

Suppose a shop calculates the total price of 3 notebooks costing ₹20 each and adds a ₹10 bag charge.

```c
int total = 3 * 20 + 10;
```

First:

```text
3 * 20 = 60
```

Then:

```text
60 + 10 = 70
```

So the total is:

```text
₹70
```

### Example

```c id="real_world_precedence"
#include <stdio.h>

int main() {
    int total = 3 * 20 + 10;

    printf("Total = %d", total);

    return 0;
}
```

```output id="real_world_precedence_output"
Total = 70
```

## Common Mistakes ⚠️

### 1. Ignoring precedence

Incorrectly expecting:

```c
10 + 5 * 2
```

to produce:

```text
30
```

The actual result is:

```text
20
```

because `*` has higher precedence than `+`.

---

### 2. Forgetting parentheses

If you want addition to happen first, write:

```c
(10 + 5) * 2
```

instead of:

```c
10 + 5 * 2
```

---

### 3. Assuming everything is evaluated left to right

Operators with different precedence levels are not simply evaluated from left to right.

For example:

```c
10 + 5 * 2
```

multiplication happens before addition.

---

### 4. Making complex expressions difficult to read

Instead of writing a confusing expression, use parentheses:

```c
result = (a + b) * (c - d);
```

This makes the intended order easier to understand.

---

## Key Points 📌

* **Operator precedence** determines which operators are evaluated first.
* Parentheses can be used to control the order of evaluation.
* `*`, `/`, and `%` have higher precedence than `+` and `-`.
* Operators with the same precedence generally follow their associativity rules.
* An **expression** combines values, variables, and operators to produce a result.
* Relational and logical operators can also be part of expressions.
* Use parentheses when you want your intended calculation to be clear.
