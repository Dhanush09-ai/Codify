# Chapter 3: Operators

## Section 3: Assignment & Increment/Decrement Operators

**Assignment operators** are used to assign values to variables.

**Increment and decrement operators** are used to increase or decrease a variable's value by `1`.

These operators are commonly used when working with variables, calculations, and loops.

---

## 1. Assignment Operator `=`

The `=` operator is called the **assignment operator**.

It assigns a value to a variable.

For example:

```c
int number = 10;
```

Here, the value `10` is assigned to the variable `number`.

Example:

```c
#include <stdio.h>

int main()
{
    int number;

    number = 25;

    printf("Number = %d", number);

    return 0;
}
```

```output
Number = 25
```

The assignment can also be done when declaring the variable:

```c
int number = 25;
```

---

## 2. Compound Assignment Operators

C provides several compound assignment operators.

| Operator | Meaning             | Example  | Equivalent To |
| -------- | ------------------- | -------- | ------------- |
| `+=`     | Add and assign      | `a += 5` | `a = a + 5`   |
| `-=`     | Subtract and assign | `a -= 5` | `a = a - 5`   |
| `*=`     | Multiply and assign | `a *= 5` | `a = a * 5`   |
| `/=`     | Divide and assign   | `a /= 5` | `a = a / 5`   |
| `%=`     | Modulus and assign  | `a %= 5` | `a = a % 5`   |

Let's look at each one.

---

## 3. Addition Assignment `+=`

The `+=` operator adds a value to a variable and stores the result back in that variable.

For example:

```c
#include <stdio.h>

int main()
{
    int number = 10;

    number += 5;

    printf("Number = %d", number);

    return 0;
}
```

```output
Number = 15
```

This:

```c
number += 5;
```

is equivalent to:

```c
number = number + 5;
```

---

## 4. Subtraction Assignment `-=`

```c
int main()

    printf("Number = %d", number);

    return 0;
}
```

```output
Number = 7
```

This:


```c
number = number - 3;
```

## 8. Increment Operator `++`

The `++` operator is called the **increment operator**.

It increases a variable's value by `1`.

For example:

```c
#include <stdio.h>

int main()
{
    int number = 10;

    number++;

    printf("Number = %d", number);

    return 0;
}
```

```output
Number = 11
```

This:

```c
number++;
```

is equivalent to:

```c
number = number + 1;
```

---

## 9. Decrement Operator `--`

The `--` operator is called the **decrement operator**.

It decreases a variable's value by `1`.

For example:

```c
#include <stdio.h>

int main()
{
    int number = 10;

    number--;

    printf("Number = %d", number);

    return 0;
}
```

```output
Number = 9
```

This:

```c
number--;
```

is equivalent to:

```c
number = number - 1;
```

---

## 10. Prefix and Postfix Operators

The increment and decrement operators can be used in two forms:

* **Prefix**
* **Postfix**

### Prefix Increment

In prefix increment, `++` is written before the variable.

```c
++number;
```

The variable is increased by `1` before its value is used in the expression.

### Postfix Increment

In postfix increment, `++` is written after the variable.

```c
number++;
```

The variable is increased by `1` after its current value is used in the expression.

For example:

```c
#include <stdio.h>

int main()
{
    int a = 5;
    int b;

    b = ++a;

    printf("a = %d\n", a);
    printf("b = %d", b);

    return 0;
}
```

```output
a = 6
b = 6
```

Here, `a` is increased first, and then its value is assigned to `b`.

---

## 11. Postfix Increment Example

Consider:

```c
#include <stdio.h>

int main()
{
    int a = 5;
    int b;

    b = a++;

    printf("a = %d\n", a);
    printf("b = %d", b);

    return 0;
}
```

```output
a = 6
b = 5
```

Here, the current value of `a` is assigned to `b` first.

Then `a` is increased by `1`.

So:

```text
b = 5
a = 6
```

---

## 12. Prefix and Postfix Decrement

The same concept applies to the decrement operator.

Prefix decrement:

```c
--number;
```

Postfix decrement:

```c
number--;
```

For example:

```c
#include <stdio.h>

int main()
{
    int a = 5;
    int b;

    b = --a;

    printf("a = %d\n", a);
    printf("b = %d", b);

    return 0;
}
```

```output
a = 4
b = 4
```

With postfix decrement:

```c
#include <stdio.h>

int main()
{
    int a = 5;
    int b;

    b = a--;

    printf("a = %d\n", a);
    printf("b = %d", b);

    return 0;
}
```

```output
a = 4
b = 5
```

## Real-World Example 🌍

Assignment and increment operators can be useful for keeping track of quantities.

For example, suppose a shop receives new products.

```c
#include <stdio.h>

int main()
{
    int products = 20;

    products += 5;

    printf("Products = %d", products);

    return 0;
}
```

```output
Products = 25
```

Here:

```c
products += 5;
```

adds `5` to the existing number of products.

Increment can also be used when one new product is added:

```c
products++;
```

## Common Mistakes

### Confusing `=` and `==`

The `=` operator assigns a value.

```c
number = 10;
```

The `==` operator compares two values.

```c
number == 10
```

They have different purposes.

### Forgetting That `++` Changes the Variable

For example:

```c
int number = 10;

number++;
```

After this statement, `number` is `11`.

### Confusing Prefix and Postfix

These are not always the same when used inside a larger expression:

```c
++a
```

and

```c
a++
```

Prefix changes the value before it is used, while postfix uses the current value first and then changes it.

---

## Key Points

* `=` is the assignment operator.
* Assignment operators store values in variables.
* `+=` adds a value and assigns the result.
* `-=` subtracts a value and assigns the result.
* `*=` multiplies a value and assigns the result.
* `/=` divides a value and assigns the result.
* `%=` calculates the remainder and assigns the result.
* `++` increases a variable by `1`.
* `--` decreases a variable by `1`.
* Increment and decrement can be used in prefix or postfix form.
* Prefix changes the value before it is used in an expression.
* Postfix uses the current value first and then changes it.
