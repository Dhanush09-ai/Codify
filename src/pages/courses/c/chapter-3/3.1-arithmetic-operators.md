# Chapter 3: Operators

## Section 1: Arithmetic Operators

**Arithmetic operators** are used to perform mathematical calculations in C.

For example, we can use arithmetic operators to add, subtract, multiply, and divide numbers.

---

## 1. Arithmetic Operators in C

C provides the following basic arithmetic operators:

| Operator | Name           | Example  |
| -------- | -------------- | -------- |
| `+`      | Addition       | `10 + 5` |
| `-`      | Subtraction    | `10 - 5` |
| `*`      | Multiplication | `10 * 5` |
| `/`      | Division       | `10 / 5` |
| `%`      | Modulus        | `10 % 5` |

Let's understand each operator.

---

## 2. Addition Operator `+`

The `+` operator is used to add two values.

Example:

```c
#include <stdio.h>

int main()
{
    int a = 10;
    int b = 5;
    int result = a + b;

    printf("Result = %d", result);

    return 0;
}
```

```output
Result = 15
```

Here:

```c
result = a + b;
```

adds `10` and `5`.

---

## 3. Subtraction Operator `-`

The `-` operator is used to subtract one value from another.

```c
#include <stdio.h>

int main()
{
    int a = 10;
    int b = 5;
    int result = a - b;

    printf("Result = %d", result);

    return 0;
}
```

```output
Result = 5
```

Here, `5` is subtracted from `10`.

---

## 4. Multiplication Operator `*`

The `*` operator is used to multiply two values.

```c
#include <stdio.h>

int main()
{
    int a = 10;
    int b = 5;
    int result = a * b;

    printf("Result = %d", result);

    return 0;
}
```

```output
Result = 50
```

Here, `10 × 5 = 50`.

---

## 5. Division Operator `/`

The `/` operator is used to divide one value by another.

```c
#include <stdio.h>

int main()
{
    int a = 10;
    int b = 5;
    int result = a / b;

    printf("Result = %d", result);

    return 0;
}
```

```output
Result = 2
```

Here, `10 / 5 = 2`.

### Integer Division

When both values are integers, C performs integer division.

For example:

```c
int result = 7 / 2;
```

The result is:

```text
3
```

The decimal part is discarded.

To get a decimal result, at least one value can be a floating-point value:

```c
float result = 7.0 / 2;
```

```output
3.500000
```

---

## 6. Modulus Operator `%`

The `%` operator is called the **modulus operator**.

It gives the **remainder** after division.

For example:

```c
#include <stdio.h>

int main()
{
    int result = 10 % 3;

    printf("Remainder = %d", result);

    return 0;
}
```

```output
Remainder = 1
```

Because:

```text
10 ÷ 3 = 3 remainder 1
```

So:

```text
10 % 3 = 1
```

Another example:

```c
int result = 20 % 4;
```

The result is:

```text
0
```

because `20` is completely divisible by `4`.

---

## 7. Using Arithmetic Operators Together

We can use multiple arithmetic operators in the same expression.

For example:

```c
#include <stdio.h>

int main()
{
    int a = 10;
    int b = 5;

    int result = a + b * 2;

    printf("Result = %d", result);

    return 0;
}
```

```output
Result = 20
```

The multiplication is performed before addition:

```text
5 × 2 = 10
10 + 10 = 20
```

This is because C follows **operator precedence**.

---

## 8. Arithmetic Operators with User Input

Arithmetic operators can also be used with values entered by the user.

```c
#include <stdio.h>

int main()
{
    int a, b;

    printf("Enter two numbers: ");
    scanf("%d %d", &a, &b);

    printf("Addition = %d\n", a + b);
    printf("Subtraction = %d\n", a - b);
    printf("Multiplication = %d\n", a * b);
    printf("Division = %d\n", a / b);
    printf("Remainder = %d", a % b);

    return 0;
}
```

If the user enters:

```text
10 3
```

The output will be:

```output
Enter two numbers: 10 3
Addition = 13
Subtraction = 7
Multiplication = 30
Division = 3
Remainder = 1
```

## Real-World Example 🌍

Arithmetic operators are commonly used in programs that perform calculations.

For example, a simple shopping program can calculate the total price of two products.

```c
#include <stdio.h>

int main()
{
    int price1 = 100;
    int price2 = 150;
    int total;

    total = price1 + price2;

    printf("Total Price = %d", total);

    return 0;
}
```

```output
Total Price = 250
```

Here, the `+` operator is used to calculate the total price.

## Common Mistakes

### Forgetting Integer Division

```c
int result = 7 / 2;
```

The result is `3`, not `3.5`, because both values are integers.

For a decimal result:

```c
float result = 7.0 / 2;
```

### Confusing `/` and `%`

The `/` operator gives the quotient.

```c
10 / 3
```

Result:

```text
3
```

The `%` operator gives the remainder.

```c
10 % 3
```

Result:

```text
1
```

### Dividing by Zero

Do not divide an integer by zero.

For example:

```c
int result = 10 / 0;
```

This is invalid and should not be used.

---

## Key Points

* Arithmetic operators are used for mathematical calculations.
* `+` is used for addition.
* `-` is used for subtraction.
* `*` is used for multiplication.
* `/` is used for division.
* `%` gives the remainder after integer division.
* Integer division discards the decimal part.
* Multiple arithmetic operators can be used in one expression.
* C follows operator precedence when evaluating expressions.
* Division by zero should be avoided.
