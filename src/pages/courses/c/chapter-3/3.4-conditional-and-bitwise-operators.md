# Chapter 3: Operators

## Section 4: Conditional & Bitwise Operators

C provides some additional operators that are useful for making short decisions and working with individual bits.

In this lesson, we will learn about:

1. Conditional operator `?:`
2. Bitwise AND `&`
3. Bitwise OR `|`
4. Bitwise XOR `^`
5. Bitwise NOT `~`
6. Left shift `<<`
7. Right shift `>>`

---

## 1. Conditional Operator `?:`

The **conditional operator** is also called the **ternary operator** because it uses three parts.

It provides a short way to choose between two values based on a condition.

The syntax is:

```c
condition ? value_if_true : value_if_false;
```

For example:

```c
int age = 20;

char *result = age >= 18 ? "Adult" : "Minor";
```

If `age >= 18` is true, `"Adult"` is selected.

Otherwise, `"Minor"` is selected.

---

## 2. Conditional Operator Example

```c
#include <stdio.h>

int main()
{
    int number = 10;

    int result = number > 0 ? 1 : 0;

    printf("Result = %d", result);

    return 0;
}
```

```output
Result = 1
```

The condition:

```c
number > 0
```

is true, so `1` is selected.

---

## 3. Conditional Operator with User Input

The conditional operator can also be used with user input.

```c
#include <stdio.h>

int main()
{
    int number;

    printf("Enter a number: ");
    scanf("%d", &number);

    printf("%s", number % 2 == 0 ? "Even" : "Odd");

    return 0;
}
```

If the user enters:

```text
8
```

The output will be:

```output
Enter a number: 8
Even
```

The condition checks whether the remainder is `0`.

## 4. Bitwise Operators

**Bitwise operators** work directly with the individual bits of integer values.

For example, the decimal number `5` can be represented in binary as:

```text
5 = 0101
```

Bitwise operators perform operations on these binary bits.

C provides the following bitwise operators:

| Operator | Name        | Example    |    |    |
| -------- | ----------- | ---------- | -- | -- |
| `&`      | Bitwise AND | `5 & 3`    |    |    |
| `        | `           | Bitwise OR | `5 | 3` |
| `^`      | Bitwise XOR | `5 ^ 3`    |    |    |
| `~`      | Bitwise NOT | `~5`       |    |    |
| `<<`     | Left Shift  | `5 << 1`   |    |    |
| `>>`     | Right Shift | `5 >> 1`   |    |    |

---

## 5. Bitwise AND `&`

The `&` operator performs a **bitwise AND** operation.

A bit becomes `1` only when both corresponding bits are `1`.

For example:

```text
  5 = 0101
  3 = 0011
-----------
5 & 3 = 0001
```

So:

```text
5 & 3 = 1
```

Example:

```c
#include <stdio.h>

int main()
{
    int result = 5 & 3;

    printf("Result = %d", result);

    return 0;
}
```

```output
Result = 1
```

---

## 6. Bitwise OR `|`

The `|` operator performs a **bitwise OR** operation.

A bit becomes `1` when at least one of the corresponding bits is `1`.

For example:

```text
  5 = 0101
  3 = 0011
-----------
5 | 3 = 0111
```

So:

```text
5 | 3 = 7
```

Example:

```c
#include <stdio.h>

int main()
{
    int result = 5 | 3;

    printf("Result = %d", result);

    return 0;
}
```

```output
Result = 7
```

---

## 7. Bitwise XOR `^`

The `^` operator performs a **bitwise XOR** operation.

A bit becomes `1` when the two corresponding bits are different.

For example:

```text
  5 = 0101
  3 = 0011
-----------
5 ^ 3 = 0110
```

So:

```text
5 ^ 3 = 6
```

Example:

```c
#include <stdio.h>

int main()
{
    int result = 5 ^ 3;

    printf("Result = %d", result);

    return 0;
}
```

```output
Result = 6
```

---

## 8. Bitwise NOT `~`

The `~` operator is called **bitwise NOT**.

It reverses every bit:

```text
0 → 1
1 → 0
```

For example:

```c
int number = 5;
int result = ~number;
```

The exact decimal result of `~` depends on the integer representation and size used by the system.

For beginner programs, remember that `~` **inverts the bits** of an integer.

---

## 9. Left Shift `<<`

The `<<` operator shifts the bits to the left.

For example:

```c
#include <stdio.h>

int main()
{
    int result = 5 << 1;

    printf("Result = %d", result);

    return 0;
}
```

```output
Result = 10
```

Binary representation:

```text
5 = 0101
```

After shifting left by one position:

```text
0101 → 1010
```

`1010` represents `10`.

---

## 10. Right Shift `>>`

The `>>` operator shifts the bits to the right.

For example:

```c
#include <stdio.h>

int main()
{
    int result = 8 >> 1;

    printf("Result = %d", result);

    return 0;
}
```

```output
Result = 4
```

Binary representation:

```text
8 = 1000
```

After shifting right by one position:

```text
1000 → 0100
```

`0100` represents `4`.

---

## 11. Conditional vs Bitwise Operators

The conditional operator and bitwise operators have different purposes.

| Operator | Purpose                                        |            |
| -------- | ---------------------------------------------- | ---------- |
| `?:`     | Selects one of two values based on a condition |            |
| `&`      | Bitwise AND                                    |            |
| `        | `                                              | Bitwise OR |
| `^`      | Bitwise XOR                                    |            |
| `~`      | Bitwise NOT                                    |            |
| `<<`     | Left shift                                     |            |
| `>>`     | Right shift                                    |            |

Do not confuse bitwise operators with logical operators.

For example:

```c
a && b
```

uses **logical AND**.

While:

```c
a & b
```

uses **bitwise AND**.

They have different purposes.

## Real-World Example 🌍

The conditional operator can be useful when a program needs to select one of two messages.

For example, a program can check whether a student passed.

```c
#include <stdio.h>

int main()
{
    int marks = 75;

    printf("%s", marks >= 40 ? "Pass" : "Fail");

    return 0;
}
```

```output
Pass
```

The condition:

```c
marks >= 40
```

is true, so `"Pass"` is selected.

## Common Mistakes

### Confusing `&` with `&&`

These operators are different.

`&&` is the **logical AND** operator:

```c
a && b
```

`&` is the **bitwise AND** operator:

```c
a & b
```

### Confusing `|` with `||`

`||` is the logical OR operator:

```c
a || b
```

`|` is the bitwise OR operator:

```c
a | b
```

### Forgetting the Three Parts of `?:`

The conditional operator requires:

```c
condition ? value_if_true : value_if_false
```

For example:

```c
int result = age >= 18 ? 1 : 0;
```

---

## Key Points

* The conditional operator `?:` is also called the ternary operator.
* It provides a short way to choose between two values.
* Bitwise operators work on individual bits of integer values.
* `&` performs bitwise AND.
* `|` performs bitwise OR.
* `^` performs bitwise XOR.
* `~` inverts the bits.
* `<<` shifts bits to the left.
* `>>` shifts bits to the right.
* Logical operators such as `&&` and `||` are different from bitwise operators such as `&` and `|`.
