# Chapter 4: Control Statements

## Section 1: Introduction to Conditions

Programs often need to make decisions.

For example:

* If a student gets enough marks, show **"Pass"**.
* If a person's age is 18 or above, show **"Eligible"**.
* If a number is even, display **"Even"**.
* Otherwise, display **"Odd"**.

C++ uses **conditions** to make these decisions.

A condition is an expression that produces either:

* `true`
* `false`

Conditions are commonly created using **relational and logical operators**.

---

## 1. What Is a Condition?

A condition is an expression that checks whether something is true or false.

### Example

```cpp
int age = 20;

age >= 18
```

The condition checks:

```text
Is age greater than or equal to 18?
```

Since `age` is `20`, the condition is `true`.

### Another Example

```cpp
int marks = 30;

marks >= 40
```

This condition is `false` because `30` is less than `40`.

---

## 2. Boolean Values

C++ has a Boolean data type called `bool`.

A `bool` variable can store:

```text
true
false
```

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    bool isStudent = true;

    cout << isStudent;

    return 0;
}
```

```output
1
```

By default, C++ displays:

* `1` for `true`
* `0` for `false`

You can also use `boolalpha` to display `true` and `false` as words.

```cpp
#include <iostream>
using namespace std;

int main() {
    bool isStudent = true;

    cout << boolalpha << isStudent;

    return 0;
}
```

```output
true
```

---

## 3. Conditions Using Relational Operators

Relational operators are commonly used to create conditions.

| Operator | Meaning                  |
| -------- | ------------------------ |
| `==`     | Equal to                 |
| `!=`     | Not equal to             |
| `>`      | Greater than             |
| `<`      | Less than                |
| `>=`     | Greater than or equal to |
| `<=`     | Less than or equal to    |

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int number = 10;

    cout << (number > 5) << endl;
    cout << (number == 10) << endl;
    cout << (number < 5);

    return 0;
}
```

```output
1
1
0
```

Here:

```text
number > 5   → true
number == 10 → true
number < 5   → false
```

---

## 4. Conditions Using Logical Operators

Multiple conditions can be combined using logical operators.

The main logical operators are:

| Operator | Name | Meaning                      |    |                                     |
| -------- | ---- | ---------------------------- | -- | ----------------------------------- |
| `&&`     | AND  | Both conditions must be true |    |                                     |
| `        |      | `                            | OR | At least one condition must be true |
| `!`      | NOT  | Reverses the condition       |    |                                     |

### Example with AND

```cpp
int age = 20;
int marks = 75;

(age >= 18) && (marks >= 40)
```

Both conditions are true, so the complete condition is `true`.

### Example with OR

```cpp
int marks = 30;

(marks < 35) || (marks > 90)
```

The first condition is true, so the complete condition is `true`.

---

## 5. Using Conditions in Programs

A condition becomes useful when a program needs to make a decision.

For example:

```cpp
#include <iostream>
using namespace std;

int main() {
    int age = 20;

    if (age >= 18) {
        cout << "Eligible";
    }

    return 0;
}
```

```output
Eligible
```

Here, the condition:

```cpp
age >= 18
```

is checked.

Since it is true, the statement inside the `if` block is executed.

The `if` statement will be studied in detail in the next section.

---

## 6. True and False Conditions

A condition can directly produce a Boolean result.

```cpp
#include <iostream>
using namespace std;

int main() {
    int number = 15;

    bool result = number > 10;

    cout << boolalpha << result;

    return 0;
}
```

```output
true
```

The expression:

```cpp
number > 10
```

is true because `15` is greater than `10`.

---

## 7. Conditions with Variables

Conditions can compare variables with each other.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 20;
    int b = 10;

    bool result = a > b;

    cout << boolalpha << result;

    return 0;
}
```

```output
true
```

Here:

```text
a = 20
b = 10
```

Therefore:

```text
20 > 10 → true
```

## 8. Real-World Example 🌍

Suppose an online shopping application checks whether a customer qualifies for free delivery.

```cpp
#include <iostream>
using namespace std;

int main() {
    int orderAmount = 750;

    bool freeDelivery = orderAmount >= 500;

    cout << boolalpha << freeDelivery;

    return 0;
}
```

```output
true
```

The condition:

```cpp
orderAmount >= 500
```

checks whether the order amount is at least ₹500.

Since the order amount is ₹750, the condition is true.

## 9. Common Mistakes

### Mistake 1: Using `=` Instead of `==`

Incorrect:

```cpp
if (number = 10)
```

The `=` operator is used for assignment.

For comparison, use:

```cpp
if (number == 10)
```

---

### Mistake 2: Forgetting That Conditions Produce Boolean Results

For example:

```cpp
int number = 8;

bool result = number > 10;
```

The result is:

```text
false
```

It does not store `10` or `8`.

---

### Mistake 3: Confusing `&&` and `||`

Use `&&` when **both** conditions must be true.

```cpp
age >= 18 && hasID
```

Use `||` when **at least one** condition can be true.

```cpp
hasEmail || hasPhone
```

---

### Mistake 4: Comparing Values Incorrectly

Remember the meaning of the operators:

```text
>   greater than
<   less than
>=  greater than or equal to
<=  less than or equal to
==  equal to
!=  not equal to
```

Choosing the wrong operator can produce an incorrect decision.

---

## Key Points

* Conditions help programs make decisions.
* A condition produces `true` or `false`.
* `bool` is the Boolean data type in C++.
* Relational operators are commonly used to create conditions.
* Logical operators can combine multiple conditions.
* `&&` means both conditions must be true.
* `||` means at least one condition must be true.
* `!` reverses a condition.
* Conditions are commonly used with `if`, `else`, and loops.
* The `=` operator assigns a value, while `==` compares values.
