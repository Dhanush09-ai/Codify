# Chapter 4: Control Statements

## Section 3: else-if Ladder

Sometimes a program needs to check **more than two conditions**.

For example, a student's result may be classified as:

* Excellent
* Very Good
* Good
* Pass
* Fail

Using many separate `if` statements can make the code difficult to understand.

The **else-if ladder** allows us to check multiple conditions one after another.

---

## 1. What Is an else-if Ladder?

An `else-if` ladder contains multiple conditions.

The program checks the conditions from **top to bottom**.

* If the first condition is true, its block executes.
* The remaining conditions are skipped.
* If the first condition is false, the next condition is checked.
* If all conditions are false, the final `else` block executes.

### Syntax

```cpp
if (condition1) {
    // statements
} else if (condition2) {
    // statements
} else if (condition3) {
    // statements
} else {
    // statements
}
```

---

## 2. Simple else-if Example

Let's check a student's marks.

```cpp
#include <iostream>
using namespace std;

int main() {
    int marks = 75;

    if (marks >= 90) {
        cout << "Excellent";
    } else if (marks >= 75) {
        cout << "Very Good";
    } else if (marks >= 50) {
        cout << "Good";
    } else if (marks >= 40) {
        cout << "Pass";
    } else {
        cout << "Fail";
    }

    return 0;
}
```

```output
Very Good
```

The program checks the conditions in order:

```text
75 >= 90  → false
75 >= 75  → true
```

So `"Very Good"` is printed.

The remaining conditions are not checked.

---

## 3. How the else-if Ladder Works

Consider:

```cpp
if (condition1) {
    // Block 1
} else if (condition2) {
    // Block 2
} else if (condition3) {
    // Block 3
} else {
    // Block 4
}
```

The execution happens like this:

```text
        condition1?
          /    \
       true    false
        |        |
     Block 1  condition2?
                 /   \
              true   false
               |       |
            Block 2  condition3?
                       /   \
                    true   false
                     |       |
                  Block 3  Block 4
```

Only **one block** from the entire ladder is executed.

---

## 4. else-if Ladder Without a Final else

The final `else` is optional.

For example:

```cpp
#include <iostream>
using namespace std;

int main() {
    int temperature = 35;

    if (temperature >= 40) {
        cout << "Very Hot";
    } else if (temperature >= 30) {
        cout << "Hot";
    } else if (temperature >= 20) {
        cout << "Normal";
    }

    return 0;
}
```

```output
Hot
```

If none of the conditions is true, nothing is printed because there is no final `else`.

---

## 5. Using else-if for Grades

An else-if ladder is useful for assigning grades.

```cpp
#include <iostream>
using namespace std;

int main() {
    int marks = 82;

    if (marks >= 90) {
        cout << "Grade A+";
    } else if (marks >= 80) {
        cout << "Grade A";
    } else if (marks >= 70) {
        cout << "Grade B";
    } else if (marks >= 60) {
        cout << "Grade C";
    } else if (marks >= 40) {
        cout << "Grade D";
    } else {
        cout << "Grade F";
    }

    return 0;
}
```

```output
Grade A
```

Since `82 >= 80`, the program prints `"Grade A"`.

---

## 6. Order of Conditions Matters

The order of conditions is very important in an else-if ladder.

Consider:

```cpp
int marks = 85;

if (marks >= 40) {
    cout << "Pass";
} else if (marks >= 80) {
    cout << "Excellent";
}
```

The output will be:

```output
Pass
```

Why?

Because `85 >= 40` is already true.

The program executes the first block and does not check the later condition.

### Correct Order

More specific or higher-range conditions should usually come first:

```cpp
if (marks >= 80) {
    cout << "Excellent";
} else if (marks >= 40) {
    cout << "Pass";
} else {
    cout << "Fail";
}
```

Now the output is:

```output
Excellent
```

## 7. Checking Positive, Negative, or Zero

An else-if ladder can classify a number into three categories.

```cpp
#include <iostream>
using namespace std;

int main() {
    int number = -8;

    if (number > 0) {
        cout << "Positive";
    } else if (number < 0) {
        cout << "Negative";
    } else {
        cout << "Zero";
    }

    return 0;
}
```

```output
Negative
```

The program checks:

```text
number > 0  → false
number < 0  → true
```

Therefore, `"Negative"` is printed.

## 8. Real-World Example 🌍

Suppose an online shopping application calculates a discount based on the purchase amount.

```cpp
#include <iostream>
using namespace std;

int main() {
    int amount = 2500;

    if (amount >= 5000) {
        cout << "30% Discount";
    } else if (amount >= 3000) {
        cout << "20% Discount";
    } else if (amount >= 2000) {
        cout << "10% Discount";
    } else {
        cout << "No Discount";
    }

    return 0;
}
```

```output
10% Discount
```

The amount is `2500`.

So:

```text
2500 >= 5000 → false
2500 >= 3000 → false
2500 >= 2000 → true
```

The program prints `"10% Discount"`.

## 9. else-if Ladder vs Multiple if Statements

An else-if ladder and multiple separate `if` statements can behave differently.

### Multiple `if` Statements

```cpp
if (marks >= 40) {
    cout << "Pass";
}

if (marks >= 80) {
    cout << "Excellent";
}
```

If `marks` is `85`, both conditions are true, so both blocks can execute.

### else-if Ladder

```cpp
if (marks >= 40) {
    cout << "Pass";
} else if (marks >= 80) {
    cout << "Excellent";
}
```

Only the first true block executes.

This is why the order of conditions is important.

## 10. Common Mistakes

### Mistake 1: Incorrect Condition Order

Incorrect:

```cpp
if (marks >= 40) {
    cout << "Pass";
} else if (marks >= 90) {
    cout << "Excellent";
}
```

The `90` condition can never be reached when marks are `90` or more because `marks >= 40` is already true.

Better:

```cpp
if (marks >= 90) {
    cout << "Excellent";
} else if (marks >= 40) {
    cout << "Pass";
}
```

---

### Mistake 2: Using Separate if Statements Unnecessarily

If only one result should be selected, an else-if ladder is usually clearer:

```cpp
if (marks >= 90) {
    cout << "A+";
} else if (marks >= 80) {
    cout << "A";
} else if (marks >= 70) {
    cout << "B";
}
```

---

### Mistake 3: Forgetting the Final else

If you want a default result when none of the conditions matches, add an `else`.

```cpp
if (marks >= 40) {
    cout << "Pass";
} else {
    cout << "Fail";
}
```

---

## Key Points

* An else-if ladder is used to check multiple conditions.
* Conditions are checked from top to bottom.
* The first true condition is executed.
* Once a condition is true, the remaining conditions are skipped.
* The final `else` is optional.
* The order of conditions is important.
* Higher or more specific conditions should generally be checked first.
* An else-if ladder is useful for grades, ranges, categories, and menu-like decisions.
* Use separate `if` statements when multiple conditions may need to execute independently.
