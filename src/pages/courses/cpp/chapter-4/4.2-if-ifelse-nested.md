# Chapter 4: Decision Making

## Section 2: if, if-else & Nested if

Programs often need to make decisions based on conditions.

C++ provides `if` and `if-else` statements to control which part of a program should execute.

You can also place one `if` statement inside another `if` statement. This is called a **nested if**.

In this lesson, you will learn:

* `if` statement
* `if-else` statement
* Nested `if`
* Nested `if-else`
* Common mistakes

---

## 1. The `if` Statement

The `if` statement executes a block of code only when its condition is `true`.

### Syntax

```cpp
if (condition) {
    // statements
}
```

If the condition is true, the statements inside the braces execute.

If the condition is false, they are skipped.

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int age = 20;

    if (age >= 18) {
        cout << "You are eligible.";
    }

    return 0;
}
```

```output
You are eligible.
```

Here:

```text
age >= 18
```

is true, so the message is printed.

---

## 2. `if` with a False Condition

When the condition is false, the code inside the `if` block is not executed.

```cpp
#include <iostream>
using namespace std;

int main() {
    int age = 15;

    if (age >= 18) {
        cout << "You are eligible.";
    }

    cout << "Program continues.";

    return 0;
}
```

```output
Program continues.
```

The condition is false because `15` is less than `18`.

Therefore, the `if` block is skipped.

---

## 3. The `if-else` Statement

The `if-else` statement provides two choices.

* If the condition is `true`, the `if` block executes.
* If the condition is `false`, the `else` block executes.

### Syntax

```cpp
if (condition) {
    // statements when condition is true
} else {
    // statements when condition is false
}
```

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int number = 7;

    if (number % 2 == 0) {
        cout << "Even";
    } else {
        cout << "Odd";
    }

    return 0;
}
```

```output
Odd
```

Since `7 % 2` is `1`, the condition is false.

Therefore, the `else` block executes.

---

## 4. Checking Positive and Negative Numbers

`if-else` can be used to make simple numerical decisions.

```cpp
#include <iostream>
using namespace std;

int main() {
    int number = -5;

    if (number >= 0) {
        cout << "Positive or Zero";
    } else {
        cout << "Negative";
    }

    return 0;
}
```

```output
Negative
```

The condition:

```cpp
number >= 0
```

is false, so the `else` block executes.

---

## 5. Checking Pass or Fail

A common use of `if-else` is checking whether a student has passed.

```cpp
#include <iostream>
using namespace std;

int main() {
    int marks = 65;

    if (marks >= 40) {
        cout << "Pass";
    } else {
        cout << "Fail";
    }

    return 0;
}
```

```output
Pass
```

The condition `marks >= 40` is true, so `"Pass"` is printed.

---

## 6. Nested `if`

An `if` statement inside another `if` statement is called a **nested if**.

### Syntax

```cpp
if (condition1) {
    if (condition2) {
        // statements
    }
}
```

The inner `if` is checked only when the outer `if` condition is true.

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int age = 20;
    bool hasID = true;

    if (age >= 18) {
        if (hasID) {
            cout << "Entry allowed.";
        }
    }

    return 0;
}
```

```output
Entry allowed.
```

Here, two conditions must be satisfied:

```text
age >= 18
hasID == true
```

---

## 7. Nested `if-else`

An `if-else` statement can also be placed inside another `if` or `else` block.

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int number = 10;

    if (number >= 0) {
        if (number == 0) {
            cout << "Zero";
        } else {
            cout << "Positive";
        }
    } else {
        cout << "Negative";
    }

    return 0;
}
```

```output
Positive
```

The program first checks:

```text
number >= 0
```

This is true.

Then it checks:

```text
number == 0
```

This is false.

Therefore, the inner `else` executes and prints `"Positive"`.

---

## 8. Multiple Conditions with Nested `if`

Nested `if` statements are useful when one decision depends on another decision.

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int age = 20;
    int marks = 75;

    if (age >= 18) {
        if (marks >= 40) {
            cout << "Eligible";
        } else {
            cout << "Not eligible due to marks";
        }
    } else {
        cout << "Not eligible due to age";
    }

    return 0;
}
```

```output
Eligible
```

The program first checks the age.

Only if the age condition is true does it check the marks.

---

## 9. Real-World Example 🌍

Imagine a college system checking whether a student can attend an examination.

The student must:

1. Be registered.
2. Have sufficient attendance.

```cpp
#include <iostream>
using namespace std;

int main() {
    bool registered = true;
    int attendance = 85;

    if (registered) {
        if (attendance >= 75) {
            cout << "Student can attend the exam.";
        } else {
            cout << "Attendance is too low.";
        }
    } else {
        cout << "Student is not registered.";
    }

    return 0;
}
```

```output
Student can attend the exam.
```

The outer condition checks registration first.

Then the inner condition checks attendance.

## 10. `if` Without Braces

For a single statement, braces are optional.

For example:

```cpp
if (age >= 18)
    cout << "Eligible";
```

However, using braces is generally clearer, especially for beginners:

```cpp
if (age >= 18) {
    cout << "Eligible";
}
```

Braces also make it safer when adding more statements later.

---

## 11. The Dangling `else`

When `if` statements are nested without braces, an `else` belongs to the **nearest unmatched `if`**.

For example:

```cpp
if (a == 10)
    if (b == 20)
        cout << "A";
    else
        cout << "B";
```

The `else` belongs to:

```cpp
if (b == 20)
```

not the outer `if`.

Using braces makes the intended structure clearer:

```cpp
if (a == 10) {
    if (b == 20) {
        cout << "A";
    } else {
        cout << "B";
    }
}
```

### Good Practice

Use braces with nested conditions to make the code easier to read and avoid confusion.

---

## 12. Common Mistakes

### Mistake 1: Using `=` Instead of `==`

Incorrect:

```cpp
if (number = 10) {
    cout << "Ten";
}
```

For comparison, use:

```cpp
if (number == 10) {
    cout << "Ten";
}
```

---

### Mistake 2: Forgetting Braces in Nested `if`

Nested conditions can become difficult to understand without braces.

Prefer:

```cpp
if (age >= 18) {
    if (hasID) {
        cout << "Allowed";
    }
}
```

instead of writing complicated nested statements without braces.

---

### Mistake 3: Wrong `else` Association

Remember that an `else` without braces belongs to the nearest unmatched `if`.

Using braces helps avoid this problem.

---

### Mistake 4: Using Separate `if` Statements When `if-else` Is Needed

Consider:

```cpp
if (marks >= 40) {
    cout << "Pass";
}

if (marks < 40) {
    cout << "Fail";
}
```

This can work for these mutually exclusive conditions, but `if-else` expresses the two-choice decision more clearly:

```cpp
if (marks >= 40) {
    cout << "Pass";
} else {
    cout << "Fail";
}
```

---

## Key Points

* `if` executes code when a condition is true.
* `if-else` provides two possible execution paths.
* The `else` block executes when the `if` condition is false.
* An `if` inside another `if` is called a nested `if`.
* Nested conditions are useful when one decision depends on another.
* Braces `{}` make conditional code easier to read and maintain.
* An `else` without braces belongs to the nearest unmatched `if`.
* Use `==` for comparison and `=` for assignment.
* Conditions can use relational and logical operators.
