# Chapter 4: Control Statements

## Section 5: break, continue & Conditional Operator

In C++, `break`, `continue`, and the conditional operator are useful for controlling how a program executes.

* `break` stops a loop or `switch`.
* `continue` skips the current loop iteration.
* The conditional operator provides a short way to choose between two expressions.

---

## 1. The `break` Statement

The `break` statement immediately stops the execution of a loop or `switch` statement.

### Syntax

```cpp
break;
```

When `break` is executed inside a loop, the program exits the loop and continues with the statement after it.

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 10; i++) {
        if (i == 5) {
            break;
        }

        cout << i << " ";
    }

    return 0;
}
```


```output
1 2 3 4
```

When `i` becomes `5`, `break` stops the loop.

---

## 2. break in a `while` Loop

`break` can also be used inside a `while` loop.

```cpp
#include <iostream>
using namespace std;

int main() {
    int i = 1;

    while (i <= 10) {
        if (i == 6) {
            break;
        }

        cout << i << " ";
        i++;
    }

    return 0;
}
```


```output
1 2 3 4 5
```

The loop stops when `i` becomes `6`.

---

## 3. break in a `switch`

As we saw in the previous topic, `break` is also commonly used with `switch`.

```cpp
switch (choice) {
    case 1:
        cout << "Start";
        break;

    case 2:
        cout << "Exit";
        break;

    default:
        cout << "Invalid choice";
}
```

Here, `break` prevents execution from continuing into the next case.

---

## 4. The `continue` Statement

The `continue` statement skips the remaining statements of the current loop iteration.

The loop then moves to its next iteration.

### Syntax

```cpp
continue;
```

Unlike `break`, `continue` does **not** stop the entire loop.

---

## 5. Example of `continue`

Let's print numbers from 1 to 10 but skip `5`.

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 10; i++) {
        if (i == 5) {
            continue;
        }

        cout << i << " ";
    }

    return 0;
}
```


```output
1 2 3 4 6 7 8 9 10
```

When `i` becomes `5`, `continue` skips the `cout` statement for that iteration.

The loop then continues with `6`.

---

## 6. break vs continue

Both statements control loops, but they work differently.

| `break`                                  | `continue`                                       |
| ---------------------------------------- | ------------------------------------------------ |
| Stops the loop completely                | Skips the current iteration                      |
| Execution moves outside the loop         | Execution moves to the next iteration            |
| Can be used in loops and `switch`        | Used with loops                                  |
| Useful when the required result is found | Useful when certain iterations should be skipped |

### Example

```cpp
for (int i = 1; i <= 5; i++) {
    if (i == 3) {
        break;
    }

    cout << i << " ";
}
```

Output:

```output
1 2
```

The loop stops at `3`.

Now using `continue`:

```cpp
for (int i = 1; i <= 5; i++) {
    if (i == 3) {
        continue;
    }

    cout << i << " ";
}
```

Output:

```output
1 2 4 5
```

Only `3` is skipped.

---

## 7. Using continue with a `while` Loop

`continue` can also be used with a `while` loop.

Be careful to update the loop variable correctly.

```cpp
#include <iostream>
using namespace std;

int main() {
    int i = 0;

    while (i < 5) {
        i++;

        if (i == 3) {
            continue;
        }

        cout << i << " ";
    }

    return 0;
}
```


```output
1 2 4 5
```

The value `3` is skipped.

---

## 8. The Conditional Operator

The **conditional operator** is a short way of writing a simple `if-else` decision.

It is also called the **ternary operator** because it uses three parts.

### Syntax

```cpp
condition ? expression1 : expression2;
```

It works like this:

* If the condition is `true`, `expression1` is selected.
* If the condition is `false`, `expression2` is selected.

---

## 9. Simple Conditional Operator Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int age = 18;

    string result = (age >= 18) ? "Adult" : "Not Adult";

    cout << result;

    return 0;
}
```


```output
Adult
```

The condition `age >= 18` is true, so `"Adult"` is selected.

---

## 10. Finding the Larger Number

The conditional operator can be used to find the larger of two numbers.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 25;
    int b = 40;

    int larger = (a > b) ? a : b;

    cout << "Larger number: " << larger;

    return 0;
}
```


```output
Larger number: 40
```

Since `a > b` is false, the value of `b` is selected.

---

## 11. Conditional Operator vs if-else

The conditional operator and `if-else` can perform similar simple decisions.

### Using if-else

```cpp
if (a > b) {
    larger = a;
}
else {
    larger = b;
}
```

### Using conditional operator

```cpp
larger = (a > b) ? a : b;
```

The second version is shorter.

Use the conditional operator when the decision is simple and easy to understand.

For complex logic, `if-else` is usually easier to read.

---

## 12. Conditional Operator with Output

The conditional operator can also be used directly with `cout`.

```cpp
#include <iostream>
using namespace std;

int main() {
    int number = 7;

    cout << ((number % 2 == 0) ? "Even" : "Odd");

    return 0;
}
```


```output
Odd
```

The condition checks whether the number is divisible by `2`.

---

## 13. Combining `break` and Conditions

A common use of `break` is to stop searching when a required value is found.

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 10; i++) {
        if (i == 7) {
            cout << "Found";
            break;
        }
    }

    return 0;
}
```


```output
Found
```

Once `7` is found, there is no need to continue the loop.

---

## 14. Using `continue` to Skip Values

`continue` is useful when some values should not be processed.

For example, we can skip even numbers and print only odd numbers.

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 10; i++) {
        if (i % 2 == 0) {
            continue;
        }

        cout << i << " ";
    }

    return 0;
}
```


```output
1 3 5 7 9
```

When the number is even, `continue` skips that iteration.

---

## 🌍 Real-World Example: Processing Valid Items

Suppose a program processes item numbers from `1` to `10`. Item `5` is unavailable, so we skip it. When item `9` is reached, we stop processing.

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int item = 1; item <= 10; item++) {
        if (item == 5) {
            continue;
        }

        if (item == 9) {
            break;
        }

        cout << "Processing item " << item << "\n";
    }

    return 0;
}
```


```output
Processing item 1
Processing item 2
Processing item 3
Processing item 4
Processing item 6
Processing item 7
Processing item 8
```

Here:

* `continue` skips item `5`.
* `break` stops the loop when item `9` is reached.

## ⚠️ Common Mistakes

### 1. Thinking `continue` stops the loop

`continue` only skips the current iteration.

```cpp
if (i == 5) {
    continue;
}
```

The loop continues with the next iteration.

---

### 2. Confusing `break` and `continue`

Remember:

```text
break    → stop the loop
continue → skip this iteration
```

---

### 3. Creating an infinite loop with `continue`

Be careful when using `continue` in a `while` loop.

The loop variable must still be updated.

---

### 4. Using complicated logic with the conditional operator

This can become difficult to read:

```cpp
result = condition1 ? value1 : condition2 ? value2 : value3;
```

For complex decisions, `if-else` is usually clearer.

---

### 5. Forgetting the `:` in the conditional operator

Correct:

```cpp
result = condition ? value1 : value2;
```

The `?` and `:` are both required.

---

## ⭐ Key Points

* `break` immediately stops a loop or `switch`.
* `continue` skips the current loop iteration.
* `break` moves execution outside the loop.
* `continue` moves execution to the next iteration.
* The conditional operator is also called the ternary operator.
* Its syntax is `condition ? expression1 : expression2`.
* The conditional operator is useful for simple decisions.
* Use `if-else` when the logic becomes complex.
* Be careful with `continue` inside `while` loops.
