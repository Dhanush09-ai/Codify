# Chapter 4: Control Statements

## Section 4: switch Statement

The `switch` statement is used when we want to choose **one option from multiple possible values**.

It is useful when a variable can have several fixed values, such as:

* Menu choices
* Day numbers
* Month numbers
* Calculator operations
* User-selected options

Instead of writing many `if-else if` conditions, we can use a `switch` statement to make the code easier to read.

---

## 1. What is a switch Statement?

A `switch` statement checks the value of an expression and compares it with different `case` values.

When a matching `case` is found, its statements are executed.

### Basic Syntax

```cpp
switch (expression) {
    case value1:
        // statements
        break;

    case value2:
        // statements
        break;

    case value3:
        // statements
        break;

    default:
        // statements
}
```

### How it works

1. The `expression` is evaluated.
2. Its value is compared with each `case`.
3. When a matching `case` is found, its statements execute.
4. `break` exits the `switch`.
5. If no case matches, the `default` block executes.

---

## 2. Simple switch Example

Let's create a program that prints a message based on a number.

```cpp
#include <iostream>
using namespace std;

int main() {
    int number = 2;

    switch (number) {
        case 1:
            cout << "One";
            break;

        case 2:
            cout << "Two";
            break;

        case 3:
            cout << "Three";
            break;

        default:
            cout << "Invalid number";
    }

    return 0;
}
```


```output
Two
```

The value of `number` is `2`, so `case 2` is executed.

---

## 3. The `break` Statement

The `break` statement is very important in a `switch`.

It stops the execution of the `switch` statement.

For example:

```cpp
#include <iostream>
using namespace std;

int main() {
    int choice = 1;

    switch (choice) {
        case 1:
            cout << "Start";
            break;

        case 2:
            cout << "Stop";
            break;
    }

    return 0;
}
```


```output
Start
```

After printing `Start`, the `break` statement exits the `switch`.

---

## 4. What Happens Without `break`?

If we do not use `break`, C++ continues executing the following cases after finding a match.

This is called **fall-through**.

Example:

```cpp
#include <iostream>
using namespace std;

int main() {
    int number = 1;

    switch (number) {
        case 1:
            cout << "One\n";

        case 2:
            cout << "Two\n";

        case 3:
            cout << "Three\n";
    }

    return 0;
}
```


```output
One
Two
Three
```

The program starts from `case 1` and continues into `case 2` and `case 3` because there are no `break` statements.

For beginner programs, use `break` when you want only the matching case to execute.

---

## 5. The `default` Case

The `default` case is executed when none of the cases match.

Example:

```cpp
#include <iostream>
using namespace std;

int main() {
    int number = 5;

    switch (number) {
        case 1:
            cout << "One";
            break;

        case 2:
            cout << "Two";
            break;

        case 3:
            cout << "Three";
            break;

        default:
            cout << "Number is not between 1 and 3";
    }

    return 0;
}
```


```output
Number is not between 1 and 3
```

Here, `5` does not match any case, so the `default` block executes.

The `default` case is optional, but it is useful for handling unexpected values.

---

## 6. switch with User Input

A `switch` statement is commonly used with user input.

Let's create a simple menu program.

```cpp
#include <iostream>
using namespace std;

int main() {
    int choice;

    cout << "1. Start\n";
    cout << "2. Settings\n";
    cout << "3. Exit\n";

    cout << "Enter your choice: ";
    cin >> choice;

    switch (choice) {
        case 1:
            cout << "Starting...";
            break;

        case 2:
            cout << "Opening Settings...";
            break;

        case 3:
            cout << "Exiting...";
            break;

        default:
            cout << "Invalid choice";
    }

    return 0;
}
```

### Example Output

```output
1. Start
2. Settings
3. Exit
Enter your choice: 2
Opening Settings...
```

This is a common real-world use of `switch`.

---

## 7. Multiple Cases with the Same Code

Sometimes multiple values should perform the same action.

We can place multiple `case` labels before the same statements.

Example:

```cpp
#include <iostream>
using namespace std;

int main() {
    int day = 6;

    switch (day) {
        case 1:
        case 2:
        case 3:
        case 4:
        case 5:
            cout << "Weekday";
            break;

        case 6:
        case 7:
            cout << "Weekend";
            break;

        default:
            cout << "Invalid day";
    }

    return 0;
}
```


```output
Weekend
```

Here, both `case 6` and `case 7` execute the same statements.

---

## 8. switch with Characters

A `switch` can also work with a character.

Example:

```cpp
#include <iostream>
using namespace std;

int main() {
    char grade = 'B';

    switch (grade) {
        case 'A':
            cout << "Excellent";
            break;

        case 'B':
            cout << "Very Good";
            break;

        case 'C':
            cout << "Good";
            break;

        default:
            cout << "Invalid grade";
    }

    return 0;
}
```


```output
Very Good
```

The value `'B'` matches `case 'B'`.

## 9. switch vs if-else

Both `switch` and `if-else` can be used for decision-making, but they are useful in different situations.

| switch                                 | if-else                            |
| -------------------------------------- | ---------------------------------- |
| Good for fixed values                  | Good for conditions and ranges     |
| Uses `case` values                     | Uses logical/relational conditions |
| Easier to read with many fixed choices | Better for complex conditions      |
| Uses `break` to stop a case            | Does not require `break`           |
| Has an optional `default`              | Has an optional final `else`       |

### Example

For fixed choices:

```cpp
switch (choice) {
    case 1:
        cout << "Start";
        break;

    case 2:
        cout << "Exit";
        break;
}
```

For a range:

```cpp
if (marks >= 90) {
    cout << "A";
}
else if (marks >= 75) {
    cout << "B";
}
```

A `switch` is generally better when you are comparing one expression against several fixed values.

---

## 10. Important Rules of switch

Remember these important rules:

* The `switch` expression is checked against the `case` values.
* Each `case` must have a constant value.
* `case` values must be unique within the same `switch`.
* `break` stops execution of the current `switch`.
* Without `break`, fall-through can occur.
* `default` handles values that do not match any case.
* `default` is optional.
* Multiple cases can share the same statements.

---

## 🌍 Real-World Example: Calculator Menu

A simple calculator can use `switch` to select an operation.

```cpp
#include <iostream>
using namespace std;

int main() {
    char operation;
    int a = 10;
    int b = 5;

    cout << "Enter operation (+, -, *, /): ";
    cin >> operation;

    switch (operation) {
        case '+':
            cout << a + b;
            break;

        case '-':
            cout << a - b;
            break;

        case '*':
            cout << a * b;
            break;

        case '/':
            cout << a / b;
            break;

        default:
            cout << "Invalid operation";
    }

    return 0;
}
```

### Example Output

```output
Enter operation (+, -, *, /): *
50
```

Here, the `switch` selects the operation based on the character entered by the user.

## ⚠️ Common Mistakes

### 1. Forgetting `break`

```cpp
case 1:
    cout << "One";
case 2:
    cout << "Two";
```

This can cause both cases to execute after a match.

---

### 2. Duplicate case values

```cpp
switch (number) {
    case 1:
        cout << "One";
        break;

    case 1:
        cout << "Another One";
        break;
}
```

The same case value cannot be used twice in one `switch`.

---

### 3. Forgetting the colon

Each case needs a colon `:`.

Correct:

```cpp
case 1:
    cout << "One";
    break;
```

Incorrect:

```cpp
case 1
    cout << "One";
```

---

### 4. Using a condition as a case

A `case` is used with a fixed value, not a condition such as:

```cpp
case number > 10:
```

For conditions and ranges, use `if-else`.

---

## ⭐ Key Points

* `switch` is used for multiple fixed choices.
* `case` defines possible values.
* `break` exits the `switch`.
* Without `break`, execution can fall through to the next cases.
* `default` executes when no case matches.
* Multiple cases can share the same statements.
* `switch` can work with values such as integers and characters.
* `if-else` is usually better for ranges and complex conditions.
