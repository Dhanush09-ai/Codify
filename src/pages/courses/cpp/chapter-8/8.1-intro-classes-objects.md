# Chapter 8: Classes & Objects

## Section 1: Introduction to Classes & Objects

C++ supports **Object-Oriented Programming (OOP)**.

Classes and objects are two of the most important concepts in OOP.

A **class** is a blueprint for creating objects.

An **object** is an instance of a class.

For example, a `Student` class can describe information and actions related to students.

---

## 1. What is a Class?

A class is a user-defined data type that groups related **data** and **functions** together.

### Example

```cpp
#include <iostream>
using namespace std;

class Student {
public:
    string name;
    int age;
};
```

Here:

* `Student` is the class name.
* `name` is a data member.
* `age` is another data member.
* `public` allows these members to be accessed from outside the class.

The class itself is like a **blueprint**.

It describes what a `Student` object can contain.

---

## 2. What is an Object?

An object is a variable created from a class.

For example:

```cpp
Student student1;
```

Here:

* `Student` is the class.
* `student1` is an object.

### Example

```cpp
#include <iostream>
#include <string>
using namespace std;

class Student {
public:
    string name;
    int age;
};

int main() {
    Student student1;

    student1.name = "Owais";
    student1.age = 18;

    cout << student1.name << endl;
    cout << student1.age << endl;

    return 0;
}
```


```output
Owais
18
```

---

## 3. Class vs Object

A class and an object are related, but they are not the same.

| Class                                  | Object                         |
| -------------------------------------- | ------------------------------ |
| Blueprint                              | Instance of a class            |
| Defines structure                      | Uses that structure            |
| Does not represent a specific instance | Represents a specific instance |
| Example: `Student`                     | Example: `student1`            |

Think of it like this:

```text
Class → Student
          ↓
     ┌──────────┐
     │ Blueprint│
     └──────────┘
          ↓
     ┌──────────┐
     │ student1 │
     └──────────┘
```

---

## 4. Creating a Class

A class is created using the `class` keyword.

### Syntax

```cpp
class ClassName {
    // members
};
```

For example:

```cpp
class Car {
public:
    string brand;
    int year;
};
```

The semicolon after the closing `}` is required.

---

## 5. Creating Objects

Once a class has been created, we can create objects from it.

### Example

```cpp
#include <iostream>
#include <string>
using namespace std;

class Car {
public:
    string brand;
    int year;
};

int main() {
    Car car1;
    Car car2;

    car1.brand = "Toyota";
    car1.year = 2024;

    car2.brand = "Honda";
    car2.year = 2023;

    cout << car1.brand << " " << car1.year << endl;
    cout << car2.brand << " " << car2.year << endl;

    return 0;
}
```


```output
Toyota 2024
Honda 2023
```

Here, `car1` and `car2` are two separate objects of the same class.

---

## 6. Accessing Class Members

The dot operator `.` is used to access members of an object.

### Example

```cpp
student1.name
```

Here:

* `student1` is the object.
* `.` is the member access operator.
* `name` is the data member.

### Example

```cpp
#include <iostream>
#include <string>
using namespace std;

class Student {
public:
    string name;
    int marks;
};

int main() {
    Student student1;

    student1.name = "Owais";
    student1.marks = 95;

    cout << student1.name << endl;
    cout << student1.marks << endl;

    return 0;
}
```


```output
Owais
95
```

## 7. Data Members

Variables declared inside a class are called **data members** or **member variables**.

Example:

```cpp
class Student {
public:
    string name;
    int age;
    double marks;
};
```

Here:

* `name` is a data member.
* `age` is a data member.
* `marks` is a data member.

Each object has its own values for these members.

---

## 8. Each Object Has Its Own Data

Suppose we create two objects:

```cpp
Student student1;
Student student2;
```

Each object can store different values.

### Example

```cpp
#include <iostream>
#include <string>
using namespace std;

class Student {
public:
    string name;
    int marks;
};

int main() {
    Student student1;
    Student student2;

    student1.name = "Owais";
    student1.marks = 90;

    student2.name = "Ali";
    student2.marks = 85;

    cout << student1.name << ": " << student1.marks << endl;
    cout << student2.name << ": " << student2.marks << endl;

    return 0;
}
```


```output
Owais: 90
Ali: 85
```

Changing `student1` does not change `student2`.

---

## 9. Member Functions

A class can contain functions as well as variables.

A function declared inside a class is called a **member function**.

### Example

```cpp
#include <iostream>
using namespace std;

class Student {
public:
    void display() {
        cout << "Hello from Student class!" << endl;
    }
};

int main() {
    Student student1;

    student1.display();

    return 0;
}
```


```output
Hello from Student class!
```

The function `display()` belongs to the `Student` class.

It is called using the object:

```cpp
student1.display();
```

---

## 10. Classes Can Contain Data and Functions

One of the important ideas of classes is that they can group related data and functions together.

### Example

```cpp
#include <iostream>
#include <string>
using namespace std;

class Student {
public:
    string name;
    int marks;

    void display() {
        cout << "Name: " << name << endl;
        cout << "Marks: " << marks << endl;
    }
};

int main() {
    Student student1;

    student1.name = "Owais";
    student1.marks = 95;

    student1.display();

    return 0;
}
```


```output
Name: Owais
Marks: 95
```

The class contains:

* Data → `name`, `marks`
* Function → `display()`

---

## 11. Member Functions Can Use Data Members

A member function can directly access the data members of its object.

### Example

```cpp
#include <iostream>
using namespace std;

class Rectangle {
public:
    int length;
    int width;

    void calculateArea() {
        cout << "Area = " << length * width << endl;
    }
};

int main() {
    Rectangle rectangle;

    rectangle.length = 10;
    rectangle.width = 5;

    rectangle.calculateArea();

    return 0;
}
```


```output
Area = 50
```

Inside `calculateArea()`, the function can directly use:

```cpp
length
width
```

because they belong to the same object.

---

## 12. Multiple Objects

We can create many objects from one class.

### Example

```cpp
#include <iostream>
#include <string>
using namespace std;

class Mobile {
public:
    string brand;

    void display() {
        cout << "Brand: " << brand << endl;
    }
};

int main() {
    Mobile mobile1;
    Mobile mobile2;

    mobile1.brand = "Samsung";
    mobile2.brand = "Apple";

    mobile1.display();
    mobile2.display();

    return 0;
}
```


```output
Brand: Samsung
Brand: Apple
```

The same class is used to create both objects.

## 13. Class as a Blueprint

A class can be compared to a blueprint.

For example, a building blueprint describes:

* Rooms
* Doors
* Windows
* Other features

The blueprint itself is not the actual building.

Similarly:

```text
Class → Blueprint
Object → Actual instance created from the blueprint
```

For example:

```text
Class: Car

Objects:
car1
car2
car3
```

All three objects are created from the same class, but they can contain different data.

## 15. Simple Student Class

Let's create a complete beginner-level example.

```cpp
#include <iostream>
#include <string>
using namespace std;

class Student {
public:
    string name;
    int age;
    int marks;

    void display() {
        cout << "Name: " << name << endl;
        cout << "Age: " << age << endl;
        cout << "Marks: " << marks << endl;
    }
};

int main() {
    Student student;

    student.name = "Owais";
    student.age = 18;
    student.marks = 95;

    student.display();

    return 0;
}
```


```output
Name: Owais
Age: 18
Marks: 95
```

This example combines:

* Class
* Object
* Data members
* Member function
* Dot operator

## 16. `public` Members

In the examples above, we used:

```cpp

```

Members under `public` can be accessed from outside the class.

For example:

```cpp
student.name = "Owais";
```

works because `name` is public.

Access control will be explained in more detail in the next lessons.

## 17. Class Definition Outside `main()`

Classes are normally defined outside the `main()` function.

Example:

```cpp
#include <iostream>
using namespace std;

class Calculator {
public:
    int add(int a, int b) {
        return a + b;
    }
};

int main() {
    Calculator calculator;

    cout << calculator.add(10, 20);

    return 0;
}
```


```output
30
```

The class is defined first, and the object is created inside `main()`.

---

## 18. Class with a Simple Function

A class does not always need many data members.

It can simply contain functions related to a particular concept.

### Example

```cpp
#include <iostream>
using namespace std;

class Calculator {
public:
    int square(int number) {
        return number * number;
    }
};

int main() {
    Calculator calculator;

    cout << calculator.square(5);

    return 0;
}
```


```output
25
```

The object `calculator` calls the member function `square()`.

## 20. Class vs Normal Variables

Without classes, related information may be stored in separate variables:

```cpp
string studentName;
int studentAge;
int studentMarks;
```

With a class, the information can be grouped together:

```cpp
class Student {
public:
    string name;
    int age;
    int marks;
};
```

Then:

```cpp
Student student1;
```

The class provides a clear structure for the student's data.

## 21. Common Mistakes

### Mistake 1: Forgetting the semicolon after a class

Incorrect:

```cpp
class Student {
public:
    int age;
}
```

Correct:

```cpp
class Student {
public:
    int age;
};
```

The semicolon after `}` is required.

---

### Mistake 2: Trying to access a class member without an object

If:

```cpp
class Student {
public:
    string name;
};
```

you normally access `name` through an object:

```cpp
Student student1;

student1.name = "Owais";
```

---

### Mistake 3: Forgetting the dot operator

Incorrect:

```cpp
student1 name = "Owais";
```

Correct:

```cpp
student1.name = "Owais";
```

The dot operator `.` is used to access members of an object.

---

### Mistake 4: Confusing a class with an object

```cpp
class Student {
};
```

`Student` is the class.

```cpp
Student student1;
```

`student1` is an object.

---

## Key Points 🔑

* A class is a **blueprint** for creating objects.
* An object is an **instance of a class**.
* Classes are created using the `class` keyword.
* A class can contain data members and member functions.
* Objects are created using the class name.
* The dot operator `.` is used to access public members of an object.
* Different objects of the same class can contain different data.
* Member functions are functions that belong to a class.
* Classes help organize related data and functions together.
* `public` members can be accessed from outside the class.
