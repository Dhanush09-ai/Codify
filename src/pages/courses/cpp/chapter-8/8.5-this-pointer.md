# Chapter 8: Classes & Objects

## Section 5: this Pointer

The **`this` pointer** is a special pointer available inside non-static member functions of a class.

It points to the **current object**.

The `this` pointer is especially useful when a member variable and a function parameter have the same name.

---

## 1. What is the `this` Pointer?

When a member function is called using an object, C++ provides a special pointer called `this`.

The `this` pointer refers to the object that is currently calling the member function.

### Example

```cpp
#include <iostream>
using namespace std;

class Student {
public:
    int marks;

    void display() {
        cout << this->marks << endl;
    }
};

int main() {
    Student student;

    student.marks = 95;
    student.display();

    return 0;
}
```


```output
95
```

Here:

```cpp
this->marks
```

refers to the `marks` member of the current object.

---

## 2. `this` Refers to the Current Object

Consider:

```cpp
Student student1;
Student student2;
```

If we call:

```cpp
student1.display();
```

then `this` refers to `student1`.

If we call:

```cpp
student2.display();
```

then `this` refers to `student2`.

The same member function can therefore work with different objects.

### Example

```cpp
#include <iostream>
using namespace std;

class Student {
public:
    int marks;

    void display() {
        cout << "Marks: " << this->marks << endl;
    }
};

int main() {
    Student student1;
    Student student2;

    student1.marks = 90;
    student2.marks = 85;

    student1.display();
    student2.display();

    return 0;
}
```


```output
Marks: 90
Marks: 85
```

For the first call, `this` refers to `student1`.

For the second call, `this` refers to `student2`.

---

## 3. Why Do We Need `this`?

One common use of `this` is to distinguish between:

* Data members of the class
* Parameters of a member function

Consider:

```cpp
class Student {
public:
    int marks;

    void setMarks(int marks) {
        marks = marks;
    }
};
```

This is confusing because both names are `marks`.

The statement:

```cpp
marks = marks;
```

does not clearly refer to the class member.

We can use `this` to make it clear.

```cpp
class Student {
public:
    int marks;

    void setMarks(int marks) {
        this->marks = marks;
    }
};
```

Now:

```cpp
this->marks
```

means the object's data member.

The second:

```cpp
marks
```

means the function parameter.

---

## 4. Using `this` with Same-Named Parameters

This is one of the most common uses of the `this` pointer.

### Example

```cpp
#include <iostream>
#include <string>
using namespace std;

class Student {
private:
    string name;
    int age;

public:
    void setStudent(string name, int age) {
        this->name = name;
        this->age = age;
    }

    void display() {
        cout << "Name: " << name << endl;
        cout << "Age: " << age << endl;
    }
};

int main() {
    Student student;

    student.setStudent("Owais", 18);
    student.display();

    return 0;
}
```


```output
Name: Owais
Age: 18
```

Here:

```cpp
this->name = name;
```

means:

```text
object's name = parameter name
```

Similarly:

```cpp
this->age = age;
```

means:

```text
object's age = parameter age
```

---

## 5. `this->member`

The arrow operator `->` is used with the `this` pointer to access members of the current object.

For example:

```cpp
this->name
this->age
this->marks
```

These refer to the current object's members.

### Example

```cpp
#include <iostream>
using namespace std;

class Rectangle {
private:
    int length;
    int width;

public:
    void setValues(int length, int width) {
        this->length = length;
        this->width = width;
    }

    void display() {
        cout << "Length: " << this->length << endl;
        cout << "Width: " << this->width << endl;
    }
};

int main() {
    Rectangle rectangle;

    rectangle.setValues(10, 5);
    rectangle.display();

    return 0;
}
```


```output
Length: 10
Width: 5
```

---

## 6. `this` and Multiple Objects

Each object gets its own current-object reference through `this`.

### Example

```cpp
#include <iostream>
using namespace std;

class Number {
private:
    int value;

public:
    void setValue(int value) {
        this->value = value;
    }

    void display() {
        cout << "Value: " << this->value << endl;
    }
};

int main() {
    Number number1;
    Number number2;

    number1.setValue(10);
    number2.setValue(20);

    number1.display();
    number2.display();

    return 0;
}
```


```output
Value: 10
Value: 20
```

When `number1.display()` runs, `this` refers to `number1`.

When `number2.display()` runs, `this` refers to `number2`.

---

## 7. `this` Is a Pointer

The name `this` represents a pointer to the current object.

Therefore, we can use:

```cpp
this->member
```

to access a member.

Conceptually:

```text
Current object
      ↑
     this
```

For example:

```cpp
this->marks
```

means:

```text
Access marks from the current object
```

---

## 8. `this` vs Normal Object Access

Suppose we have:

```cpp
class Student {
public:
    int marks;

    void display() {
        cout << marks << endl;
        cout << this->marks << endl;
    }
};
```

Both statements access the current object's `marks`.

```cpp
marks
```

and:

```cpp
this->marks
```

refer to the same member in this situation.

The explicit `this->` is particularly useful when names are ambiguous.

---

## 9. `this` in Member Functions

The `this` pointer can be used inside non-static member functions.

### Example

```cpp
#include <iostream>
using namespace std;

class Counter {
private:
    int count = 0;

public:
    void increase() {
        this->count++;
    }

    void display() {
        cout << this->count << endl;
    }
};

int main() {
    Counter counter;

    counter.increase();
    counter.increase();
    counter.increase();

    counter.display();

    return 0;
}
```


```output
3
```

Each call modifies the `count` belonging to the current object.

---

## 10. Returning `*this`

A member function can return `*this`.

`*this` represents the current object itself rather than the pointer to it.

This can be useful for **method chaining**.

### Example

```cpp
#include <iostream>
using namespace std;

class Number {
private:
    int value;

public:
    Number& setValue(int value) {
        this->value = value;
        return *this;
    }

    void display() {
        cout << value << endl;
    }
};

int main() {
    Number number;

    number.setValue(50).display();

    return 0;
}
```


```output
50
```

Here:

```cpp
return *this;
```

returns the current object.

This allows:

```cpp
number.setValue(50).display();
```

to work.

---

## 11. Method Chaining

When a member function returns the current object, multiple function calls can be connected together.

This is called **method chaining**.

### Example

```cpp
#include <iostream>
using namespace std;

class Calculator {
private:
    int value = 0;

public:
    Calculator& add(int number) {
        this->value += number;
        return *this;
    }

    Calculator& multiply(int number) {
        this->value *= number;
        return *this;
    }

    void display() {
        cout << value << endl;
    }
};

int main() {
    Calculator calculator;

    calculator.add(10).multiply(5).display();

    return 0;
}
```


```output
50
```

The calls happen in sequence:

```text
add(10)
   ↓
multiply(5)
   ↓
display()
```

## 12. `this` in Constructors

The `this` pointer can also be used inside constructors.

This is useful when constructor parameters have the same names as data members.

### Example

```cpp
#include <iostream>
#include <string>
using namespace std;

class Student {
private:
    string name;
    int marks;

public:
    Student(string name, int marks) {
        this->name = name;
        this->marks = marks;
    }

    void display() {
        cout << name << endl;
        cout << marks << endl;
    }
};

int main() {
    Student student("Owais", 95);

    student.display();

    return 0;
}
```


```output
Owais
95
```

Here `this` identifies the object whose constructor is currently running.

---

## 13. `this` Helps Avoid Naming Confusion

Without `this`, we can use different parameter names:

```cpp
void setMarks(int studentMarks) {
    marks = studentMarks;
}
```

This is perfectly valid.

We can also use the same names:

```cpp
void setMarks(int marks) {
    this->marks = marks;
}
```

Both approaches work.

Using `this` is useful when we want the parameter name to match the data member name.

---

## 14. `this` with Private Members

The `this` pointer can be used to access private members from within member functions.

### Example

```cpp
#include <iostream>
using namespace std;

class BankAccount {
private:
    double balance = 0;

public:
    void deposit(double balance) {
        this->balance += balance;
    }

    void display() {
        cout << "Balance: " << this->balance << endl;
    }
};

int main() {
    BankAccount account;

    account.deposit(5000);
    account.display();

    return 0;
}
```


```output
Balance: 5000
```

The member function can access the private member because it belongs to the class.

---

## 15. `this` Is Not Available in Static Member Functions

The `this` pointer belongs to a particular object.

A `static` member function does not belong to one specific object.

Therefore, a static member function cannot use `this`.

For example:

```cpp
class Test {
public:
    static void display() {
        // this cannot be used here
    }
};
```

This is because there is no current object associated with a static member function.

## 16. Real-World Example 🌍

Imagine a student profile system.

Each student object has its own:

* Name
* Roll number
* Marks

The `this` pointer makes it clear that the values belong to the current student object.

### Example

```cpp
#include <iostream>
#include <string>
using namespace std;

class Student {
private:
    string name;
    int rollNumber;
    int marks;

public:
    Student(string name, int rollNumber, int marks) {
        this->name = name;
        this->rollNumber = rollNumber;
        this->marks = marks;
    }

    void display() {
        cout << "Name: " << this->name << endl;
        cout << "Roll Number: " << this->rollNumber << endl;
        cout << "Marks: " << this->marks << endl;
    }
};

int main() {
    Student student("Owais", 101, 95);

    student.display();

    return 0;
}
```


```output
Name: Owais
Roll Number: 101
Marks: 95
```

The `this` pointer refers to the current `student` object.

## Common Mistakes

### Mistake 1: Confusing `this` with `*this`

`this` is a pointer to the current object.

```cpp
this
```

represents the pointer.

```cpp
*this
```

represents the current object itself.

---

### Mistake 2: Forgetting the `->`

When accessing a member through the `this` pointer, use:

```cpp
this->marks
```

not:

```cpp
this.marks
```

The dot operator is used with an object, while `->` is used with a pointer.

---

### Mistake 3: Using `this` outside a member function

`this` is available in appropriate non-static member-function contexts.

It cannot simply be used in `main()`.

Incorrect:

```cpp
int main() {
    cout << this;
}
```

---

### Mistake 4: Using `this` in a static member function

A static member function has no current object, so it cannot use `this`.

---

### Mistake 5: Thinking `this` is a normal variable

`this` is a special pointer provided by C++ for member-function calls. It refers to the current object.

---

## Key Points 🔑

* `this` is a special pointer available in non-static member functions.
* It points to the current object.
* `this->member` accesses a member of the current object.
* It is especially useful when parameter names and data-member names are the same.
* `*this` represents the current object itself.
* A member function can return `*this` for method chaining.
* Each object gets the appropriate `this` pointer when its member function is called.
* `this` can be used inside constructors.
* `this` cannot be used in static member functions.
* `this` is useful for making object-member access clear.
