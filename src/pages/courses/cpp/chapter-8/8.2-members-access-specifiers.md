# Chapter 8: Classes & Objects

## Section 2: Class Members & Access Specifiers

In the previous lesson, we learned that a class can contain **data members** and **member functions**.

C++ also provides **access specifiers** to control which parts of a class can be accessed from outside the class.

The three main access specifiers are:

* `public`
* `private`
* `protected`

In this lesson, we will focus on class members and the basic use of these access specifiers.

---

## 1. What Are Class Members?

Anything declared inside a class is called a **class member**.

The two common types of class members are:

1. **Data members** — variables inside a class.
2. **Member functions** — functions inside a class.

### Example

```cpp
#include <iostream>
#include <string>
using namespace std;

class Student {
public:
    string name;
    int marks;

    void display() {
        cout << name << endl;
        cout << marks << endl;
    }
};
```

Here:

* `name` → data member
* `marks` → data member
* `display()` → member function

---

## 2. Data Members

Data members are variables declared inside a class.

### Example

```cpp
class Student {
public:
    string name;
    int age;
    int marks;
};
```

The class has three data members:

```text
name
age
marks
```

Each object created from the class gets its own values for these non-static data members.

---

## 3. Member Functions

A member function is a function that belongs to a class.

### Example

```cpp
#include <iostream>
using namespace std;

class Calculator {
public:
    int add(int a, int b) {
        return a + b;
    }
};
```

Here:

```cpp
add()
```

is a member function of the `Calculator` class.

We can call it using an object:

```cpp
Calculator calculator;

cout << calculator.add(10, 20);
```


```output
30
```

---

## 4. The `public` Access Specifier

The `public` access specifier makes class members accessible from outside the class.

### Example

```cpp
#include <iostream>
using namespace std;

class Student {
public:
    int marks;
};

int main() {
    Student student;

    student.marks = 95;

    cout << student.marks;

    return 0;
}
```


```output
95
```

Because `marks` is public, it can be accessed using:

```cpp
student.marks
```

---

## 5. The `private` Access Specifier

The `private` access specifier prevents class members from being accessed directly from outside the class.

### Example

```cpp
#include <iostream>
using namespace std;

class Student {
private:
    int marks;
};

int main() {
    Student student;

    student.marks = 95;

    return 0;
}
```

This produces a compilation error because `marks` is private.

Private members can be accessed directly by member functions of the same class.

---

## 6. Using a Member Function with Private Data

A common way to work with private data is to provide public member functions.

### Example

```cpp
#include <iostream>
using namespace std;

class Student {
private:
    int marks;

public:
    void setMarks(int value) {
        marks = value;
    }

    int getMarks() {
        return marks;
    }
};

int main() {
    Student student;

    student.setMarks(95);

    cout << student.getMarks();

    return 0;
}
```


```output
95
```

Here:

* `marks` is private.
* `setMarks()` changes `marks`.
* `getMarks()` returns `marks`.
* The public functions provide controlled access to the private data.

---

## 7. Why Use Private Members?

Private members help prevent outside code from directly changing important data.

For example, instead of:

```cpp
student.marks = 95;
```

we can use:

```cpp
student.setMarks(95);
```

The class can control how the value is changed.

This idea is an important part of **encapsulation**, which we will study in more detail later.

---

## 8. Default Access in a Class

An important rule in C++ is:

> Members of a `class` are `private` by default.

For example:

```cpp
class Student {
    int marks;
};
```

Here, `marks` is private because no access specifier was written.

It is equivalent to:

```cpp
class Student {
private:
    int marks;
};
```

### Example

```cpp
#include <iostream>
using namespace std;

class Student {
    int marks;

public:
    void setMarks(int value) {
        marks = value;
    }

    void display() {
        cout << marks;
    }
};

int main() {
    Student student;

    student.setMarks(90);
    student.display();

    return 0;
}
```


```output
90
```

---

## 9. Access Specifier Syntax

Access specifiers are followed by a colon `:`.

### Example

```cpp
class Student {
public:
    int marks;

private:
    int age;
};
```

The colon is required after:

```cpp
public:
```

and:

```cpp
private:
```

---

## 10. Multiple Access Specifiers

A class can contain more than one access specifier.

### Example

```cpp
#include <iostream>
#include <string>
using namespace std;

class Student {
public:
    string name;

private:
    int marks;

public:
    void setMarks(int value) {
        marks = value;
    }

    int getMarks() {
        return marks;
    }
};

int main() {
    Student student;

    student.name = "Owais";
    student.setMarks(95);

    cout << student.name << endl;
    cout << student.getMarks() << endl;

    return 0;
}
```


```output
Owais
95
```

A class can switch between access sections as needed.

---

## 11. Public Data and Private Data

Consider this class:

```cpp
class Student {
public:
    string name;

private:
    int marks;
};
```

The following is allowed:

```cpp
student.name = "Owais";
```

But this is not allowed:

```cpp
student.marks = 95;
```

because `marks` is private.

A public member function can still access the private member:

```cpp
void setMarks(int value) {
    marks = value;
}
```

---

## 12. Public Member Functions

Member functions can also be public.

This allows code outside the class to call them.

### Example

```cpp
#include <iostream>
using namespace std;

class Calculator {
public:
    int square(int number) {
        return number * number;
    }
};

int main() {
    Calculator calculator;

    cout << calculator.square(6);

    return 0;
}
```


```output
36
```

The function `square()` is public, so it can be called using the object.

---

## 13. Private Member Functions

A member function can also be private.

A private member function cannot be called directly from outside the class.

However, another member function of the class can call it.

### Example

```cpp
#include <iostream>
using namespace std;

class Calculator {
private:
    int square(int number) {
        return number * number;
    }

public:
    void displaySquare(int number) {
        cout << square(number);
    }
};

int main() {
    Calculator calculator;

    calculator.displaySquare(5);

    return 0;
}
```


```output
25
```

Here:

```cpp
square()
```

is private.

The public function:

```cpp
displaySquare()
```

can call it because both functions belong to the same class.

---

## 14. The `protected` Access Specifier

C++ also provides a third access specifier:

```cpp
protected
```

Protected members are accessible inside the class and in derived classes.

For now, remember the basic idea:

| Access Specifier | Inside Class | Outside Class | Derived Class |
| ---------------- | ------------ | ------------- | ------------- |
| `public`         | Yes          | Yes           | Yes           |
| `private`        | Yes          | No            | No            |
| `protected`      | Yes          | No            | Yes           |

Inheritance and protected members will be covered in more detail in the OOP chapters.

---

## 15. Public, Private and Protected Example

```cpp
class Example {
public:
    int publicValue;

private:
    int privateValue;

protected:
    int protectedValue;
};
```

The three sections control access differently.

### Simple idea

```text
public
  ↓
Accessible from outside

private
  ↓
Accessible only within the class

protected
  ↓
Accessible within the class and derived classes
```

## 16. Class Members Working Together

A class can combine private data with public functions.

### Example

```cpp
#include <iostream>
using namespace std;

class BankAccount {
private:
    double balance;

public:
    void deposit(double amount) {
        balance += amount;
    }

    double getBalance() {
        return balance;
    }
};

int main() {
    BankAccount account;

    account.deposit(5000);

    cout << account.getBalance();

    return 0;
}
```


```output
5000
```

The outside code cannot directly access `balance`.

Instead, it uses the public functions.

> For a production banking class, the balance should also be initialized properly and operations should validate values. This example focuses only on access control.

## 17. Initializing Private Data

A private data member declared without an initializer does not automatically get a useful value for an ordinary local object.

For example:

```cpp
class Student {
private:
    int marks;
};
```

If an object is created locally, `marks` should be initialized before its value is read.

One simple approach at this stage is to use a public function:

```cpp
#include <iostream>
using namespace std;

class Student {
private:
    int marks;

public:
    void setMarks(int value) {
        marks = value;
    }

    void display() {
        cout << marks;
    }
};

int main() {
    Student student;

    student.setMarks(90);
    student.display();

    return 0;
}
```


```output
90
```

Constructors, which provide another important way to initialize objects, will be covered in the next lesson.

## 18. Getter and Setter Functions

Functions commonly used to access private data are called **getters** and **setters**.

### Setter

A setter changes a value.

```cpp
void setMarks(int value) {
    marks = value;
}
```

### Getter

A getter returns a value.

```cpp
int getMarks() {
    return marks;
}
```

### Complete Example

```cpp
#include <iostream>
using namespace std;

class Student {
private:
    int marks;

public:
    void setMarks(int value) {
        marks = value;
    }

    int getMarks() {
        return marks;
    }
};

int main() {
    Student student;

    student.setMarks(95);

    cout << "Marks: " << student.getMarks();

    return 0;
}
```


```output
Marks: 95
```

---

## 19. Validation Using Setters

A setter can also validate a value before storing it.

### Example

```cpp
#include <iostream>
using namespace std;

class Student {
private:
    int marks;

public:
    void setMarks(int value) {
        if (value >= 0 && value <= 100) {
            marks = value;
        }
    }

    int getMarks() {
        return marks;
    }
};

int main() {
    Student student;

    student.setMarks(95);

    cout << student.getMarks();

    return 0;
}
```


```output
95
```

The setter can prevent values outside the expected range from being stored.

> In a complete program, you should also decide how invalid input is handled.

## 20. Real-World Example 🌍

Consider a bank account.

It would not be a good design to allow every part of a program to directly change the balance.

Instead:

```text
BankAccount
     │
     ├── private: balance
     │
     ├── public: deposit()
     │
     └── public: getBalance()
```

The balance is protected from direct outside access.

The public functions provide controlled ways to work with it.

This is one of the basic ideas behind **encapsulation**.

## 21. Common Mistakes

### Mistake 1: Accessing a private member directly

Incorrect:

```cpp
class Student {
private:
    int marks;
};

Student student;

student.marks = 90;
```

`marks` cannot be accessed directly from outside the class.

Use a public member function instead.

---

### Mistake 2: Forgetting the colon

Incorrect:

```cpp
class Student {
public
    int marks;
};
```

Correct:

```cpp
class Student {
public:
    int marks;
};
```

---

### Mistake 3: Forgetting that `class` members are private by default

This:

```cpp
class Student {
    int marks;
};
```

makes `marks` private.

If outside access is required, use:

```cpp
class Student {
public:
    int marks;
};
```

---

### Mistake 4: Trying to call a private function from outside

If:

```cpp
class Calculator {
private:
    int square(int n) {
        return n * n;
    }
};
```

this is not allowed:

```cpp
calculator.square(5);
```

A public function can be provided if outside code needs access to that operation.

---

## Key Points 🔑

* Class members include data members and member functions.
* `public` members can be accessed from outside the class.
* `private` members cannot be accessed directly from outside the class.
* `protected` members are accessible inside the class and derived classes.
* Class members are `private` by default.
* Access specifiers are followed by a colon `:`.
* A class can contain multiple access-specifier sections.
* Public member functions can provide controlled access to private data.
* Getter functions usually return private data.
* Setter functions usually change private data.
* Access control is an important part of encapsulation.
