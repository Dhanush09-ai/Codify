# Chapter 8: Classes & Objects

## Section 3: Constructors

A **constructor** is a special member function of a class that is automatically called when an object is created.

Constructors are mainly used to **initialize objects**.

A constructor has the **same name as the class** and does not have a return type.

---

## 1. What is a Constructor?

A constructor is a special function that runs automatically when an object is created.

### Example

```cpp
#include <iostream>
using namespace std;

class Student {
public:
    Student() {
        cout << "Constructor called!" << endl;
    }
};

int main() {
    Student student;

    return 0;
}
```


```output
Constructor called!
```

When this statement executes:

```cpp
Student student;
```

the constructor is automatically called.

We do not need to write:

```cpp
student.Student();
```

---

## 2. Constructor Syntax

The basic syntax is:

```cpp
class ClassName {
public:
    ClassName() {
        // constructor code
    }
};
```

Important rules:

* The constructor name must be the same as the class name.
* A constructor does not have a return type.
* It is automatically called when an object is created.
* A constructor can have parameters.
* A class can have multiple constructors through overloading.

---

## 3. Constructor with Data Members

Constructors are commonly used to initialize data members.

### Example

```cpp
#include <iostream>
#include <string>
using namespace std;

class Student {
public:
    string name;
    int age;

    Student() {
        name = "Unknown";
        age = 0;
    }
};

int main() {
    Student student;

    cout << student.name << endl;
    cout << student.age << endl;

    return 0;
}
```


```output
Unknown
0
```

The constructor gives initial values to the object's data members.

---

## 4. Constructor Is Called Automatically

Consider:

```cpp
Student student;
```

When the object is created:

```text
Object created
     ↓
Constructor called
     ↓
Data initialized
```

This happens automatically.

### Example

```cpp
#include <iostream>
using namespace std;

class Message {
public:
    Message() {
        cout << "Object created" << endl;
    }
};

int main() {
    Message message1;
    Message message2;

    return 0;
}
```


```output
Object created
Object created
```

The constructor is called once for each object.

---

## 5. Constructor with Parameters

A constructor can receive parameters.

This allows us to initialize an object with specific values when it is created.

### Example

```cpp
#include <iostream>
#include <string>
using namespace std;

class Student {
public:
    string name;
    int age;

    Student(string studentName, int studentAge) {
        name = studentName;
        age = studentAge;
    }
};

int main() {
    Student student("Owais", 18);

    cout << student.name << endl;
    cout << student.age << endl;

    return 0;
}
```


```output
Owais
18
```

The values are passed when the object is created:

```cpp
Student student("Owais", 18);
```

---

## 6. Multiple Objects with a Parameterized Constructor

A parameterized constructor can initialize different objects with different values.

### Example

```cpp
#include <iostream>
#include <string>
using namespace std;

class Student {
public:
    string name;
    int marks;

    Student(string studentName, int studentMarks) {
        name = studentName;
        marks = studentMarks;
    }
};

int main() {
    Student student1("Owais", 95);
    Student student2("Ali", 88);

    cout << student1.name << ": " << student1.marks << endl;
    cout << student2.name << ": " << student2.marks << endl;

    return 0;
}
```


```output
Owais: 95
Ali: 88
```

Each object receives its own initial values.

## 7. Default Constructor

A constructor that takes no parameters is called a **default constructor**.

### Example

```cpp
#include <iostream>
using namespace std;

class Car {
public:
    Car() {
        cout << "Car object created" << endl;
    }
};

int main() {
    Car car;

    return 0;
}
```


```output
Car object created
```

The constructor:

```cpp
Car()
```

takes no arguments.

---

## 8. Parameterized Constructor

A constructor that takes one or more parameters is called a **parameterized constructor**.

### Example

```cpp
#include <iostream>
using namespace std;

class Rectangle {
public:
    int length;
    int width;

    Rectangle(int l, int w) {
        length = l;
        width = w;
    }
};

int main() {
    Rectangle rectangle(10, 5);

    cout << rectangle.length << endl;
    cout << rectangle.width << endl;

    return 0;
}
```


```output
10
5
```

The values `10` and `5` are passed to the constructor.

---

## 9. Constructor vs Normal Function

A constructor is different from a normal member function.

| Constructor                                    | Normal Function                     |
| ---------------------------------------------- | ----------------------------------- |
| Same name as class                             | Can have any valid name             |
| No return type                                 | Has a return type, including `void` |
| Called automatically when an object is created | Usually called explicitly           |
| Used mainly for initialization                 | Used to perform operations          |

### Example

```cpp
class Student {
public:
    Student() {
        // Constructor
    }

    void display() {
        // Normal member function
    }
};
```

Here:

```cpp
Student()
```

is the constructor.

```cpp
display()
```

is a normal member function.

---

## 10. Constructor Cannot Have a Return Type

A constructor must not have a return type.

Correct:

```cpp
class Student {
public:
    Student() {
    }
};
```

Incorrect:

```cpp
class Student {
public:
    void Student() {
    }
};
```

Adding `void` makes it a normal member function, not a constructor.

---

## 11. Constructor Overloading

A class can have multiple constructors with different parameter lists.

This is called **constructor overloading**.

### Example

```cpp
#include <iostream>
using namespace std;

class Rectangle {
public:
    int length;
    int width;

    Rectangle() {
        length = 0;
        width = 0;
    }

    Rectangle(int side) {
        length = side;
        width = side;
    }

    Rectangle(int l, int w) {
        length = l;
        width = w;
    }
};

int main() {
    Rectangle r1;
    Rectangle r2(5);
    Rectangle r3(10, 20);

    cout << r1.length << " " << r1.width << endl;
    cout << r2.length << " " << r2.width << endl;
    cout << r3.length << " " << r3.width << endl;

    return 0;
}
```


```output
0 0
5 5
10 20
```

C++ chooses the appropriate constructor based on the arguments.

## 12. Constructor with a Single Parameter

A constructor can have only one parameter.

### Example

```cpp
#include <iostream>
using namespace std;

class Number {
public:
    int value;

    Number(int number) {
        value = number;
    }
};

int main() {
    Number n(50);

    cout << n.value;

    return 0;
}
```


```output
50
```

The value `50` is passed to the constructor.

## 13. Using `this` with Constructors

When constructor parameters have the same names as data members, the `this` pointer can make the difference clear.

### Example

```cpp
#include <iostream>
#include <string>
using namespace std;

class Student {
public:
    string name;
    int age;

    Student(string name, int age) {
        this->name = name;
        this->age = age;
    }
};

int main() {
    Student student("Owais", 18);

    cout << student.name << endl;
    cout << student.age << endl;

    return 0;
}
```


```output
Owais
18
```

Here:

```cpp
this->name
```

refers to the object's data member.

The `this` pointer will be studied in more detail later in the course.

## 14. Constructors and Private Data

Constructors can initialize private data members.

This is very useful when a class uses encapsulation.

### Example

```cpp
#include <iostream>
using namespace std;

class Student {
private:
    int marks;

public:
    Student(int studentMarks) {
        marks = studentMarks;
    }

    int getMarks() {
        return marks;
    }
};

int main() {
    Student student(95);

    cout << student.getMarks();

    return 0;
}
```


```output
95
```

The constructor can access the private member because it belongs to the class.

---

## 15. Constructor Initialization List

C++ also provides a cleaner way to initialize data members using an **initialization list**.

### Example

```cpp
#include <iostream>
using namespace std;

class Student {
private:
    int marks;

public:
    Student(int studentMarks) : marks(studentMarks) {
    }

    int getMarks() {
        return marks;
    }
};

int main() {
    Student student(95);

    cout << student.getMarks();

    return 0;
}
```


```output
95
```

The part:

```cpp
: marks(studentMarks)
```

is called the **constructor initialization list**.

It initializes `marks` before the constructor body runs.

---

## 16. Initializing Multiple Members

An initialization list can initialize multiple data members.

### Example

```cpp
#include <iostream>
#include <string>
using namespace std;

class Student {
private:
    string name;
    int age;
    int marks;

public:
    Student(string studentName, int studentAge, int studentMarks)
        : name(studentName), age(studentAge), marks(studentMarks) {
    }

    void display() {
        cout << name << endl;
        cout << age << endl;
        cout << marks << endl;
    }
};

int main() {
    Student student("Owais", 18, 95);

    student.display();

    return 0;
}
```


```output
Owais
18
95
```

This is a common modern C++ style for initializing class members.

### Example

```cpp
class Student {

```


```output
Unknown 0
Owais 18
```

Default arguments allow the constructor to work with different numbers of supplied arguments.

## 18. What Happens When an Object Is Created?

Suppose we have:

```cpp
class Student {
public:
    Student() {
        cout << "Constructor called";
    }
};
```

And:

```cpp
Student student;
```

The general sequence is:

```text
Object creation
       ↓
Memory for the object is obtained
       ↓
Constructor is called
       ↓
Object initialization takes place
```

The constructor prepares the object for use.

## 19. Constructors with Multiple Objects

Every time an object is created, the appropriate constructor is called.

### Example

```cpp
#include <iostream>
using namespace std;

class Counter {
public:
    Counter() {
        cout << "Constructor called" << endl;
    }
};

int main() {
    Counter c1;
    Counter c2;
    Counter c3;

    return 0;
}
```


```output
Constructor called
Constructor called
Constructor called
```

There are three objects, so the constructor runs three times.

## 20. Real-World Example 🌍

Imagine a student registration system.

When a new student object is created, we want to immediately store:

* Student name
* Roll number
* Marks

A constructor can do this automatically.

```cpp
#include <iostream>
#include <string>
using namespace std;

class Student {
private:
    string name;
    int rollNumber;
    int marks;

public:
    Student(string studentName, int studentRollNumber, int studentMarks)
        : name(studentName),
          rollNumber(studentRollNumber),
          marks(studentMarks) {
    }

    void display() {
        cout << "Name: " << name << endl;
        cout << "Roll Number: " << rollNumber << endl;
        cout << "Marks: " << marks << endl;
    }
};

int main() {
    Student student("Owais", 101, 95);

    student.display();

    return 0;
}
```


```output
Name: Owais
Roll Number: 101
Marks: 95
```

The constructor initializes the student object as soon as it is created.

## 21. Common Mistakes

### Mistake 1: Giving a constructor a return type

Incorrect:

```cpp
void Student() {
}
```

Correct:

```cpp
Student() {
}
```

---

### Mistake 2: Using a different name

The constructor name must match the class name.

If the class is:

```cpp
class Student {
};
```

the constructor must be named:

```cpp
Student()
```

not:

```cpp
student()
```

or:

```cpp
StudentDetails()
```

---

### Mistake 3: Trying to call a constructor like a normal function

You normally create an object:

```cpp
Student student;
```

The constructor is automatically called.

You do not normally call:

```cpp
student.Student();
```

---

### Mistake 4: Forgetting constructor arguments

If the only constructor is:

```cpp
Student(string name, int age)
```

then this:

```cpp
Student student;
```

will not work unless another suitable constructor or default arguments are provided.

---

### Mistake 5: Forgetting the semicolon after the class

Correct:

```cpp
class Student {
public:
    Student() {
    }
};
```

The semicolon after `}` is required.

---

## Key Points 🔑

* A constructor is a special member function.
* A constructor has the same name as the class.
* A constructor has no return type.
* A constructor is automatically called when an object is created.
* Constructors are mainly used to initialize objects.
* A constructor can have parameters.
* A constructor can have default arguments.
* A class can have multiple overloaded constructors.
* Initialization lists provide a direct way to initialize data members.
* Constructors can access private members of their class.
* Each object gets its constructor call when it is created.
