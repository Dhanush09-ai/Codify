# Chapter 1: Introduction to C++

## Section 1: What is C++?

C++ is a **general-purpose programming language** used to create software, applications, games, operating systems, and many other types of programs.

C++ was developed by **Bjarne Stroustrup** as an extension of the C programming language.

It supports both **procedural programming** and **object-oriented programming (OOP)**.

---

## 1. What Does C++ Mean?

C++ is an improved and extended version of the C programming language.

The `++` symbol is the **increment operator** in C and C++. It means "increase by 1".

The name C++ represents the idea of an improved version of C.

For example:

```cpp
int number = 5;
number++;
```

After `number++`, the value becomes `6`.

---

## 2. Why Learn C++?

C++ is useful because it provides:

* Fast program execution
* Powerful programming features
* Object-oriented programming
* Memory management
* Support for large software projects
* A large collection of standard libraries

C++ is also commonly used when performance is important.

## 4. C++ and Object-Oriented Programming

One of the important features of C++ is **Object-Oriented Programming (OOP)**.

OOP organizes programs using **classes and objects**.

For example, imagine a `Student` object:

```cpp
class Student {
public:
    string name;
    int age;
};
```

A program can create objects from this class and store information about different students.

We will learn classes, objects, inheritance, polymorphism, encapsulation, and abstraction later in this course.

## 5. Your First C++ Program

A simple C++ program can display a message on the screen.

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, C++!";
    return 0;
}
```


```output
Hello, C++!
```

### How It Works

* `#include <iostream>` provides input and output functionality.
* `using namespace std;` allows us to use standard C++ names directly.
* `int main()` is the starting point of the program.
* `cout` displays text on the screen.
* `return 0;` indicates that the program finished successfully.

---

## 6. C++ Program Structure

A basic C++ program usually contains several important parts.

```cpp
#include <iostream>

using namespace std;

int main() {
    cout << "Welcome to Codify!";
    return 0;
}
```

The general structure is:

```text
Header
   ↓
Namespace
   ↓
main() function
   ↓
Statements
   ↓
return
```

The `main()` function is where program execution begins.

---

## 7. C++ is Case-Sensitive

C++ is **case-sensitive**.

This means uppercase and lowercase letters are treated differently.

For example:

```cpp
int number = 10;

cout << number;
```

Here, `number` and `Number` would be different identifiers.

```cpp
int number = 10;

// This is different from number
cout << Number;
```

The second example causes an error because `Number` was not declared.

## ⚠️ Common Mistakes

### 1. Forgetting the Semicolon

Incorrect:

```cpp
cout << "Hello"
```

Correct:

```cpp
cout << "Hello";
```

### 2. Using the Wrong Letter Case

Incorrect:

```cpp
Cout << "Hello";
```

Correct:

```cpp
cout << "Hello";
```

### 3. Forgetting `main()`

A basic executable C++ program needs a `main()` function as its entry point.
