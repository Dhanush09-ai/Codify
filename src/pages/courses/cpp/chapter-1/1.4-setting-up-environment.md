# Chapter 1: Introduction to C++

## Section 4: Setting Up Your C++ Environment

Before writing and running C++ programs, you need a **C++ development environment**.

A development environment usually includes:

* A **code editor** to write C++ programs.
* A **C++ compiler** to convert C++ code into machine code.
* A **terminal or command prompt** to compile and run programs.

---

## 1. What is a C++ Compiler?

A **compiler** is a program that converts C++ source code into a form that the computer can execute.

For example:

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, C++!";
    return 0;
}
```

The compiler processes this source code and produces an executable program.

The basic process is:

```text
C++ Source Code
       ↓
    Compiler
       ↓
Machine Code
       ↓
    Program
```

---

## 2. Popular C++ Compilers

Some commonly used C++ compilers are:

| Compiler        | Common Platform       |
| --------------- | --------------------- |
| GCC / g++       | Windows, Linux, macOS |
| Clang / clang++ | Linux, macOS, Windows |
| MSVC            | Windows               |

For beginners, **G++** is a popular choice because it is widely available and supports modern C++ standards.

---

## 3. Choosing a Code Editor

A code editor is where you write your C++ source code.

Some commonly used editors and IDEs include:

* Visual Studio Code
* Visual Studio
* Code::Blocks
* Dev-C++

For this course, you can use **Visual Studio Code** with a C++ compiler installed on your computer.

---

## 4. Installing a C++ Compiler

To compile C++ programs, you need a compiler.

On Windows, one option is to install **MinGW-w64**, which provides the `g++` compiler.

After installation, the compiler should be available through the terminal.

You can check whether `g++` is installed by opening a terminal and running:

```text
g++ --version
```

If the compiler is installed correctly, information about the installed G++ version will be displayed.

---

## 5. Checking Your Compiler

Open **Command Prompt** or a terminal and type:

```text
g++ --version
```

You may see output similar to:

```output
g++ (GCC) 13.2.0
Copyright ...
```

The exact version may be different on your computer.

The important thing is that the command is recognized and the compiler version is displayed.

---

## 6. Writing Your First C++ File

Create a new file named:

```text
hello.cpp
```

The `.cpp` extension is commonly used for C++ source files.

Write the following program:

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, C++!";
    return 0;
}
```

Save the file as `hello.cpp`.

---

## 7. Compiling a C++ Program

Open a terminal in the folder containing `hello.cpp`.

Use the following command:

```text
g++ hello.cpp -o hello
```

Here:

* `g++` starts the C++ compiler.
* `hello.cpp` is the source file.
* `-o hello` specifies the name of the output program.

If there are no errors, the compiler creates an executable program.

---

## 8. Running the Program

After compilation, run the generated program.

On Windows, you can use:

```text
hello
```

or:

```text
.\hello
```

The program will display:

```output
Hello, C++!
```

The complete process is:

```text
Write Code
    ↓
Save as hello.cpp
    ↓
Compile using g++
    ↓
Executable Program
    ↓
Run the Program
```

## 9. Using Visual Studio Code

Visual Studio Code is a lightweight code editor that can be used for C++ development.

A basic setup involves:

1. Install Visual Studio Code.

3. Add the C++ extension in Visual Studio Code.
4. Create a `.cpp` file.
5. Write your C++ program.

The **C/C++ extension** provides useful features such as code completion, syntax highlighting, and debugging support.

## 10. Compiler Errors

Sometimes your program will contain mistakes.

For example:

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, C++!"
    return 0;
}
```

The semicolon after the `cout` statement is missing.

The compiler will report an error.

Correct version:

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, C++!";
    return 0;
}
```


```output
Hello, C++!
```

Compiler errors are normal while learning programming. Read the error message carefully and check the line mentioned by the compiler.

---

## 11. Code Editor vs Compiler

A **code editor** and a **compiler** have different jobs.

| Tool        | Purpose                                  |
| ----------- | ---------------------------------------- |
| Code Editor | Write and edit C++ code                  |
| Compiler    | Convert C++ code into an executable form |
| Terminal    | Run compiler commands and programs       |
| Debugger    | Help find and investigate program errors |

For example:

```text
Visual Studio Code
       ↓
Write hello.cpp
       ↓
      g++
       ↓
Compile
       ↓
hello.exe
       ↓
     Run
```

## ⚠️ Common Mistakes

### 1. Saving the File with the Wrong Extension

A C++ source file should normally use the `.cpp` extension.

Correct:

```text
program.cpp
```

### 2. Compiler Command Not Found

If the terminal says that `g++` is not recognized, the compiler may not be installed or its location may not be added to the system `PATH`.

### 3. Compiling the Wrong File

Make sure the terminal is opened in the folder containing your `.cpp` file.

### 4. Running Before Compiling

Writing a program does not automatically create an executable file when using the command-line compiler.

Compile the program first:

```text
g++ hello.cpp -o hello
```

Then run it.
