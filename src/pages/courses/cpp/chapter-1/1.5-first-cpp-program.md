# Chapter 1: Introduction to C++

## Section 5: Your First C++ Program

Now that you know what C++ is and how to set up your environment, let's write and understand your first C++ program.

A simple C++ program can display a message on the screen.

---

## 1. Writing Your First C++ Program

Create a file named:

```text
first.cpp
```

Write the following program:

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, C++!";
    return 0;
}
```


```output
Hello, C++!
```

This is one of the simplest C++ programs.

---

## 2. Understanding the Program

Let's understand each line.

### `#include <iostream>`

```cpp
#include <iostream>
```

`iostream` is a C++ standard library header that provides input and output functionality.

It allows us to use objects such as `cout`.

---

### `using namespace std;`

```cpp
using namespace std;
```

C++ standard library features are commonly placed inside the `std` namespace.

Using this statement allows us to write:

```cpp
cout
```

instead of:

```cpp
std::cout
```

---

### `int main()`

```cpp
int main() {
```

`main()` is the starting point of a C++ program.

Program execution begins from the `main()` function.

The `int` means that the function returns an integer value.

---

### `cout`

```cpp
cout << "Hello, C++!";
```

`cout` is used to display output on the screen.

The `<<` operator sends the text to `cout`.

For example:

```cpp
cout << "Welcome to Codify!";
```


```output
Welcome to Codify!
```

---

### `return 0;`

```cpp
return 0;
```

This ends the `main()` function and returns `0` to the operating system.

A return value of `0` generally indicates that the program completed successfully.

---

## 3. Adding Multiple Lines of Output

You can use multiple `cout` statements.

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, C++!" << endl;
    cout << "Welcome to Codify!";
    
    return 0;
}
```


```output
Hello, C++!
Welcome to Codify!
```

`endl` moves the cursor to the next line.

---

## 4. Printing Numbers

`cout` can also display numbers.

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << 100;
    
    return 0;
}
```


```output
100
```

You can also print text and numbers together.

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Age: " << 16;
    
    return 0;
}
```


```output
Age: 16
```

---

## 5. Printing Variables

C++ can display the value stored in a variable.

```cpp
#include <iostream>
using namespace std;

int main() {
    int age = 16;

    cout << "Age: " << age;

    return 0;
}
```


```output
Age: 16
```

Here:

* `int` is the data type.
* `age` is the variable name.
* `16` is the value stored in the variable.
* `cout` displays the value.

---

## 6. Using Escape Sequences

Escape sequences can be used to control how output is displayed.

### New Line `\n`

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello\nC++";

    return 0;
}
```


```output
Hello
C++
```

`\n` moves the output to a new line.

---

### Tab `\t`

The `\t` escape sequence inserts a tab space.

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Name:\tOwais";

    return 0;
}
```


```output
Name:   Owais
```

---

## 7. Comments in C++

Comments are notes written inside the source code.

They are ignored by the compiler.

### Single-Line Comment

```cpp
// This is a comment
cout << "Hello";
```

### Multi-Line Comment

```cpp
/*
   This is a
   multi-line comment
*/
cout << "Hello";
```

Comments help programmers understand their code.

---

## 8. A Small C++ Program

Let's combine what we have learned.

```cpp
#include <iostream>
using namespace std;

int main() {
    string name = "Owais";
    int age = 16;

    cout << "Name: " << name << endl;
    cout << "Age: " << age << endl;
    cout << "Welcome to C++!";

    return 0;
}
```


```output
Name: Owais
Age: 16
Welcome to C++!
```

This program uses:

* Variables
* Strings
* Integers
* `cout`
* `endl`
* `main()`
* `return 0`

---

## 9. Compile and Run the Program

If your file is named `first.cpp`, open a terminal in the same folder.

Compile it using:

```text
g++ first.cpp -o first
```

Then run the program.

On Windows:

```text
.\first
```


```output
Hello, C++!
```

The general process is:

```text
Write C++ Code
      ↓
Save as .cpp
      ↓
Compile with g++
      ↓
Run the Program
      ↓
See the Output
```

## 🌍 Real-World Example

Suppose you are creating a student management application.

You could display basic student information like this:

```cpp
#include <iostream>
using namespace std;

int main() {
    string name = "Owais";
    int marks = 95;

    cout << "Student: " << name << endl;
    cout << "Marks: " << marks;

    return 0;
}
```


```output
Student: Owais
Marks: 95
```

Later, instead of writing fixed values, you will learn how to take information from the user using `cin`.

## ⚠️ Common Mistakes

### 1. Forgetting `#include <iostream>`

Without the required header, `cout` may not be available.

### 2. Forgetting the Semicolon

Incorrect:

```cpp
cout << "Hello"
```

Correct:

```cpp
cout << "Hello";
```

### 3. Writing `Cout` Instead of `cout`

C++ is case-sensitive.

Correct:

```cpp
cout << "Hello";
```

Incorrect:

```cpp
Cout << "Hello";
```

### 4. Forgetting `main()`

A basic executable C++ program needs a `main()` function as its entry point.

---

## 🔑 Key Points

* A C++ program normally starts execution from `main()`.
* `#include <iostream>` provides input/output functionality.
* `cout` is used to display output.
* `<<` sends data to `cout`.
* `endl` moves output to the next line.
* `\n` also creates a new line.
* Variables can be displayed using `cout`.
* Comments are ignored by the compiler.
* C++ is case-sensitive.
* C++ source files commonly use the `.cpp` extension.
