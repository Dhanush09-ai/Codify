# Chapter 1: Introduction to C++

## Section 2: Features of C++

C++ is a powerful programming language with many features that make it useful for developing different types of software.

Some of its important features are **object-oriented programming, portability, fast execution, memory management, and rich libraries**.

---

## 1. Object-Oriented Programming

C++ supports **Object-Oriented Programming (OOP)**.

OOP allows programs to be organized using **classes and objects**.

For example:

```cpp
class Student {
public:
    string name;
    int age;
};
```

A `Student` class can be used to create objects representing different students.

OOP helps organize large programs and makes code easier to maintain.

---

## 2. Fast and Efficient

C++ is known for its **high performance and fast execution**.

It is a compiled language, which means C++ source code is converted into machine code before execution.

This makes C++ suitable for applications where performance is important.

🌍 **Real-World Example**

Games, operating systems, and other performance-intensive software often require programs to execute quickly. C++ is suitable for such applications.

---

## 3. Portability

C++ programs can be compiled on different operating systems and hardware platforms with little or no modification, depending on the program.

For example, a C++ program can be compiled for:

* Windows
* Linux
* macOS

The source code may remain mostly the same, although platform-specific code may sometimes be required.

---

## 4. Supports Low-Level Programming

C++ provides features that allow programmers to work closer to the computer's hardware.

For example, C++ supports:

* Pointers
* References
* Direct memory management
* Bitwise operations

These features provide greater control over memory and system resources.

---

## 5. Memory Management

C++ allows programmers to manage memory manually.

Dynamic memory can be allocated when required and released when it is no longer needed.

For example:

```cpp
int* number = new int(25);

cout << *number;

delete number;
```


```output
25
```

Here:

* `new` allocates memory.
* `*number` accesses the stored value.
* `delete` releases the allocated memory.

We will study memory management in more detail later in the course.

---

## 6. Function Overloading

C++ supports **function overloading**.

This means multiple functions can have the same name as long as their parameter lists are different.

```cpp
int add(int a, int b) {
    return a + b;
}

double add(double a, double b) {
    return a + b;
}
```

The compiler determines which function to call based on the arguments.

---

## 7. Operator Overloading

C++ allows programmers to give special meanings to operators when working with user-defined types.

For example, an operator such as `+` can be overloaded for a class.

```cpp
class Number {
public:
    int value;

    Number operator+(Number other) {
        Number result;
        result.value = value + other.value;
        return result;
    }
};
```

Operator overloading is an important feature of C++ and is useful in object-oriented programming.

---

## 8. Rich Standard Library

C++ provides a large **Standard Library** containing ready-to-use features.

Some commonly used parts include:

* Input and output
* Strings
* Containers
* Algorithms
* File handling
* Mathematical operations

For example, the `<iostream>` library provides `cout` for output.

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello C++!";
    return 0;
}
```


```output
Hello C++!
```

Using standard libraries saves development time because programmers do not need to create every feature from scratch.

---

## 9. Supports Multiple Programming Styles

C++ supports different programming approaches, including:

* Procedural programming
* Object-oriented programming
* Generic programming

This gives programmers flexibility when designing programs.

For example, a simple program can use functions, while a larger application can use classes and objects.

---

## ⚠️ Common Mistakes

### 1. Thinking C++ is Only an OOP Language

C++ supports OOP, but it also supports procedural and generic programming.

### 2. Forgetting to Release Dynamically Allocated Memory

When using `new`, the allocated memory should eventually be released using `delete` when appropriate.

### 3. Confusing Function Overloading with Different Function Names

Function overloading means using the **same function name** with different parameter lists.

---

## 🔑 Key Points

* C++ is a high-performance programming language.
* C++ supports Object-Oriented Programming.
* C++ provides low-level features such as pointers and memory management.
* C++ supports function and operator overloading.
* C++ has a rich Standard Library.
* C++ can be used with different programming styles.
* C++ programs can be compiled for different platforms.
