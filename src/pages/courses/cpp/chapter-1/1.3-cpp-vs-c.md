# Chapter 1: Introduction to C++

## Section 3: C++ vs C

C and C++ are both powerful programming languages. C++ was developed as an extension of the C language and added many new features, especially **Object-Oriented Programming (OOP)**.

Although they share many similarities, C and C++ have important differences.

---

## 1. C vs C++ at a Glance

| Feature              | C                           | C++                     |
| -------------------- | --------------------------- | ----------------------- |
| Type                 | Procedural language         | Multi-paradigm language |
| Developed by         | Dennis Ritchie              | Bjarne Stroustrup       |
| OOP Support          | Not built into the language | Supported               |
| Classes & Objects    | Not supported               | Supported               |
| Function Overloading | Not supported               | Supported               |
| Operator Overloading | Not supported               | Supported               |
| References           | Not supported               | Supported               |
| Exception Handling   | Not built into the language | Supported               |
| Standard Library     | C Standard Library          | C++ Standard Library    |
| Memory Allocation    | `malloc()` / `free()`       | `new` / `delete`        |

---

## 2. Programming Approach

### C

C mainly follows a **procedural programming** approach.

Programs are commonly organized using functions.

```c
#include <stdio.h>

int add(int a, int b) {
    return a + b;
}

int main() {
    printf("%d", add(10, 20));
    return 0;
}
```


```output
30
```

### C++

C supports procedural programming, but C++ also provides **Object-Oriented Programming** and other programming features.

```cpp
#include <iostream>
using namespace std;

int add(int a, int b) {
    return a + b;
}

int main() {
    cout << add(10, 20);
    return 0;
}
```


```output
30
```

Both programs can perform the same task, but C++ provides many additional features for organizing larger programs.

---

## 3. Classes and Objects

One of the biggest differences is that C++ supports **classes and objects**.

C does not have classes as a built-in language feature.

Example in C++:

```cpp
#include <iostream>
using namespace std;

class Student {
public:
    string name;

    void display() {
        cout << name;
    }
};

int main() {
    Student student;
    student.name = "Owais";

    student.display();

    return 0;
}
```


```output
Owais
```

Here:

* `Student` is a class.
* `student` is an object.
* `name` is a data member.
* `display()` is a member function.

Classes and objects are the foundation of OOP in C++.

---

## 4. Input and Output

C commonly uses functions such as `printf()` and `scanf()` for input and output.

```c
printf("Hello");
```

C++ commonly uses `cout` and `cin`.

```cpp
cout << "Hello";
```

For input:

```cpp
cin >> age;
```

C++ provides these features through the `<iostream>` library.

---

## 5. Memory Management

Both C and C++ can dynamically allocate memory, but they commonly use different mechanisms.

### C

C uses functions such as `malloc()` and `free()`.

```c
int *number = malloc(sizeof(int));

*number = 25;

free(number);
```

### C++

C++ provides `new` and `delete`.

```cpp
int* number = new int;

*number = 25;

delete number;
```

Both approaches require programmers to handle dynamically allocated memory carefully.

---

## 6. Function Overloading

C does not support function overloading.

C++ supports **function overloading**, which allows multiple functions to have the same name with different parameter lists.

```cpp
int add(int a, int b) {
    return a + b;
}

double add(double a, double b) {
    return a + b;
}
```

The compiler selects the appropriate function based on the arguments.

---

## 7. References

C++ supports **references**.

A reference provides another name for an existing variable.

```cpp
int number = 10;
int& ref = number;

ref = 20;

cout << number;
```


```output
20
```

References are commonly used when working with functions and objects.

---

## 8. Similarities Between C and C++

Even though C and C++ have many differences, they also share several similarities.

Both languages:

* Use variables and data types.
* Support functions.
* Support loops and conditions.
* Support arrays.
* Use operators such as `+`, `-`, `*`, and `/`.
* Can work with pointers.
* Can be used to develop high-performance software.
* Use a compiler to translate source code into executable code.

For example, a simple loop looks very similar in both languages.

### C

```c
for (int i = 1; i <= 5; i++) {
    printf("%d ", i);
}
```

### C++

```cpp
for (int i = 1; i <= 5; i++) {
    cout << i << " ";
}
```


```output
1 2 3 4 5
```

## 9. Which One Should You Learn?

C and C++ are both useful languages.

### Learn C when:

* You want to understand basic programming concepts.
* You want to learn low-level programming.
* You are working with certain embedded or system-level applications.

### Learn C++ when:

* You want to learn Object-Oriented Programming.
* You want classes and objects.
* You want to use the C++ Standard Library.
* You want features such as function overloading and operator overloading.
* You are interested in game development or performance-focused applications.

Learning C first can also make it easier to understand many C++ concepts because C++ shares many basic concepts and syntax with C.

## 🌍 Real-World Example

Imagine building a large **student management system**.

In C, you can organize the program using structures and functions.

In C++, you can use classes and objects to represent students.

For example:

```cpp
class Student {
public:
    string name;
    int marks;

    void display() {
        cout << name << " " << marks;
    }
};
```

This approach allows related data and functions to be grouped together.

## ⚠️ Common Mistakes

### 1. Thinking C and C++ Are Completely Different

C++ shares many concepts and syntax with C, but it adds many additional features.

### 2. Using `printf()` and `scanf()` as the Only C++ Input/Output Method

C++ supports C-style functions, but C++ commonly uses `cout` and `cin` for input and output.

### 3. Thinking C++ Is Only Object-Oriented

C++ supports OOP, but it also supports procedural and generic programming.

### 4. Confusing `malloc()` with `new`

C commonly uses `malloc()` and `free()`, while C++ provides `new` and `delete`.

* C++ supports references.
* C commonly uses `printf()` and `scanf()`.
* C++ commonly uses `cout` and `cin`.
