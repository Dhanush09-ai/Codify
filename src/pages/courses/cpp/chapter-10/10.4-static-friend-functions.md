# Chapter 10: Advanced OOP & C++ Features

## Section 4: Static Members & Friend Functions

In C++, class members normally belong to individual objects.

However, sometimes we want a member to belong to the **class itself**, rather than to every object separately.

C++ provides **static members** for this purpose.

C++ also provides **friend functions**, which allow a non-member function to access private and protected members of a class.

---

## 1. What is a Static Member?

A **static member** belongs to the class rather than to individual objects.

This means:

* Only one shared copy exists for the class.
* All objects use the same static member.
* It can be accessed using the class name.
* A static data member exists even when no object has been created.

### Basic Syntax

```cpp
class ClassName {
public:
    static int value;
};
```

The static data member is normally defined outside the class:

```cpp
int ClassName::value = 0;
```

---

## 2. Static Data Member

Let's create a class with a static variable.

```cpp
#include <iostream>
using namespace std;

class Student {
public:
    static int count;
};

int Student::count = 0;

int main() {
    cout << Student::count << endl;

    return 0;
}
```


```output
0
```

The variable `count` belongs to the `Student` class, not to one particular student object.

---

## 3. Sharing a Static Data Member

All objects of a class share the same static data member.

```cpp
#include <iostream>
using namespace std;

class Student {
public:
    static int count;

    Student() {
        count++;
    }
};

int Student::count = 0;

int main() {
    Student s1;
    Student s2;
    Student s3;

    cout << "Students created: " << Student::count << endl;

    return 0;
}
```


```output
Students created: 3
```

Each time a `Student` object is created, the constructor increases the shared `count`.

---

## 4. Static Member vs Normal Data Member

Consider:

```cpp
class Student {
public:
    int marks;
    static int count;
};
```

Here:

* `marks` belongs to each individual object.
* `count` is shared by all objects.

For example:

```text
Student Object 1
    marks = 80

Student Object 2
    marks = 90

Student Object 3
    marks = 75

Shared by all objects:
    count = 3
```

### Comparison

| Normal Data Member                        | Static Data Member               |
| ----------------------------------------- | -------------------------------- |
| Belongs to an object                      | Belongs to the class             |
| Each object has its own copy              | One shared copy                  |
| Can have different values for each object | Same shared value                |
| Accessed using object                     | Can be accessed using class name |

---

## 5. Accessing a Static Member

The preferred way to access a static member is through the class name.

```cpp
#include <iostream>
using namespace std;

class Counter {
public:
    static int value;
};

int Counter::value = 10;

int main() {
    cout << Counter::value << endl;

    return 0;
}
```


```output
10
```

The syntax is:

```cpp
ClassName::staticMember
```

The `::` operator is called the **scope resolution operator**.

---

## 6. Changing a Static Member

Because the static member is shared, changing it affects the value seen by all objects.

```cpp
#include <iostream>
using namespace std;

class Counter {
public:
    static int value;
};

int Counter::value = 10;

int main() {
    Counter a;
    Counter b;

    Counter::value = 50;

    cout << a.value << endl;
    cout << b.value << endl;

    return 0;
}
```


```output
50
50
```

Both objects see `50` because they refer to the same static data member.

---

## 7. Static Member Function

A class can also have a **static member function**.

A static member function belongs to the class rather than to an individual object.

### Syntax

```cpp
class ClassName {
public:
    static void functionName() {
        // code
    }
};
```

It can be called using the class name:

```cpp
ClassName::functionName();
```

---

## 8. Example of Static Member Function

```cpp
#include <iostream>
using namespace std;

class Message {
public:
    static void show() {
        cout << "Hello from static function" << endl;
    }
};

int main() {
    Message::show();

    return 0;
}
```


```output
Hello from static function
```

No object is required to call the static member function.

---

## 9. Static Member Function Accessing Static Data

A static member function can directly access static members.

```cpp
#include <iostream>
using namespace std;

class Counter {
public:
    static int count;

    static void showCount() {
        cout << "Count: " << count << endl;
    }
};

int Counter::count = 5;

int main() {
    Counter::showCount();

    return 0;
}
```


```output
Count: 5
```

---

## 10. Important Rule of Static Member Functions

A static member function does **not** have a `this` pointer because it is not associated with a particular object.

Therefore, it cannot directly access non-static data members.

For example:

```cpp
class Student {
public:
    int marks;

    static void show() {
        // cout << marks;   // Error
    }
};
```

The static function does not know which `Student` object's `marks` should be used.

However, it can access static members:

```cpp
class Student {
public:
    static int count;

    static void show() {
        cout << count;
    }
};
```

---

## 11. Static Function with Object Parameter

A static function can work with an object if the object is passed to it.

```cpp
#include <iostream>
using namespace std;

class Student {
public:
    int marks;

    static void showMarks(const Student& s) {
        cout << "Marks: " << s.marks << endl;
    }
};

int main() {
    Student s;
    s.marks = 95;

    Student::showMarks(s);

    return 0;
}
```


```output
Marks: 95
```

The function is static, but it receives an object explicitly.

# Friend Functions

## 12. What is a Friend Function?

A **friend function** is a non-member function that is allowed to access the private and protected members of a class.

It is declared inside the class using the keyword `friend`.

### Syntax

```cpp
class ClassName {
private:
    int value;

public:
    friend void show(ClassName obj);
};
```

The function is not a member of the class, but the class gives it special access.

---

## 13. Simple Friend Function Example

```cpp
#include <iostream>
using namespace std;

class Student {
private:
    int marks = 95;

public:
    friend void showMarks(Student s);
};

void showMarks(Student s) {
    cout << "Marks: " << s.marks << endl;
}

int main() {
    Student s;

    showMarks(s);

    return 0;
}
```


```output
Marks: 95
```

Normally, `marks` is private and cannot be accessed directly outside the class.

But `showMarks()` is declared as a friend, so it can access `marks`.

---

## 14. Friend Function is Not a Member Function

A friend function is different from a normal member function.

### Member Function

Called using an object:

```cpp
object.function();
```

### Friend Function

Called like a normal function:

```cpp
function(object);
```

For example:

```cpp
Student s;

showMarks(s);
```

There is no `s.showMarks()` because `showMarks()` is not a member of `Student`.

---

## 15. Friend Function and Private Members

A friend function can access private members.

```cpp
#include <iostream>
using namespace std;

class Box {
private:
    int length = 10;

public:
    friend void display(Box b);
};

void display(Box b) {
    cout << "Length: " << b.length << endl;
}

int main() {
    Box b;

    display(b);

    return 0;
}
```


```output
Length: 10
```

The friend declaration gives `display()` permission to access the private member.

---

## 16. Friend Function and Multiple Objects

A friend function can receive multiple objects.

This can be useful when comparing or combining private data from different objects.

```cpp
#include <iostream>
using namespace std;

class Number {
private:
    int value;

public:
    Number(int v) {
        value = v;
    }

    friend int add(Number a, Number b);
};

int add(Number a, Number b) {
    return a.value + b.value;
}

int main() {
    Number n1(10);
    Number n2(20);

    cout << "Sum: " << add(n1, n2) << endl;

    return 0;
}
```


```output
Sum: 30
```

The friend function can access the private `value` of both objects.

---

## 17. Friend Function Declaration

The `friend` keyword is written inside the class.

```cpp
class Box {
private:
    int value;

public:
    friend void show(Box b);
};
```

The actual function definition can be written outside the class:

```cpp
void show(Box b) {
    cout << b.value;
}
```

The function remains a non-member function.

---

## 18. Friend Function Can Access Protected Members

A friend function can also access protected members.

```cpp
#include <iostream>
using namespace std;

class Parent {
protected:
    int value = 25;

public:
    friend void show(Parent p);
};

void show(Parent p) {
    cout << "Value: " << p.value << endl;
}

int main() {
    Parent p;

    show(p);

    return 0;
}
```


```output
Value: 25
```

---

## 19. Friend Function with Private Data

Consider a `BankAccount` example.

```cpp
#include <iostream>
using namespace std;

class BankAccount {
private:
    double balance;

public:
    BankAccount(double amount) {
        balance = amount;
    }

    friend void showBalance(BankAccount account);
};

void showBalance(BankAccount account) {
    cout << "Balance: " << account.balance << endl;
}

int main() {
    BankAccount account(5000);

    showBalance(account);

    return 0;
}
```


```output
Balance: 5000
```

### Real-World Example 🌍

A friend function can be useful when an operation needs access to the internal data of a class but does not naturally belong to one particular object.

However, friend functions should be used carefully because they bypass normal private access restrictions.

---

## 20. Static Members vs Friend Functions

Static members and friend functions solve different problems.

| Static Member                                     | Friend Function                                  |
| ------------------------------------------------- | ------------------------------------------------ |
| Belongs to the class                              | Does not belong to the class                     |
| Can be a static data member or function           | Usually a non-member function                    |
| Static data can be shared by all objects          | Can access private/protected members             |
| Static member function is called using class name | Friend function is called like a normal function |
| Does not use a particular object's `this` pointer | Can receive objects as parameters                |

---

## 21. Static Member and Friend Function Together

A friend function can access a class's private static data member.

```cpp
#include <iostream>
using namespace std;

class Counter {
private:
    static int count;

public:
    friend void showCount();
};

int Counter::count = 10;

void showCount() {
    cout << "Count: " << Counter::count << endl;
}

int main() {
    showCount();

    return 0;
}
```


```output
Count: 10
```

Here:

* `count` is private.
* `count` is static.
* `showCount()` is a friend.
* Therefore, `showCount()` can access `Counter::count`.

---

## 22. Important Rules to Remember

### Static Data Members

* A static data member has one shared copy for the class.
* It is normally defined outside the class.
* It can be accessed using the class name.
* All objects share the same static data member.

### Static Member Functions

* They belong to the class.
* They can be called without creating an object.
* They do not have a `this` pointer.
* They can directly access static members.
* They cannot directly access non-static members.

### Friend Functions

* They are not member functions.
* They are declared using `friend`.
* They can access private and protected members.
* They are called like normal functions.
* Friendship should be used carefully because it gives special access to class internals.

---

## 23. Common Mistakes

### Mistake 1: Forgetting to Define a Static Data Member

Declaring:

```cpp
class Counter {
public:
    static int count;
};
```

is not always enough for a traditional out-of-class definition.

A definition can be written as:

```cpp
int Counter::count = 0;
```

---

### Mistake 2: Trying to Access Non-Static Data from a Static Function

Incorrect:

```cpp
class Student {
public:
    int marks;

    static void show() {
        // cout << marks;
    }
};
```

A static member function has no particular object, so it cannot directly access `marks`.

---

### Mistake 3: Calling a Friend Function Like a Member Function

Incorrect:

```cpp
student.showMarks();
```

If `showMarks()` is a friend function, call it normally:

```cpp
showMarks(student);
```

---

### Mistake 4: Thinking `friend` Makes a Function a Member

A friend function remains a **non-member function**.

The `friend` keyword only gives it special access to private and protected members.

---

## 24. Key Points

* `static` members belong to the class rather than individual objects.
* A static data member has one shared copy.
* Static members can be accessed using the scope resolution operator `::`.
* Static member functions can be called without creating an object.
* Static member functions do not have a `this` pointer.
* Static member functions cannot directly access non-static data members.
* A friend function is not a member function.
* A friend function can access private and protected members.
* Friend functions are called like normal functions.
* Friendship should be used carefully because it gives special access to class internals.
