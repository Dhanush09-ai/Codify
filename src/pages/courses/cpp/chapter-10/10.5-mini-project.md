## 2. Step 1: Create the Student Class

First, create a class named `Student`.

```cpp
#include <iostream>
#include <string>
using namespace std;

class Student {
private:
    string name;
    int rollNumber;
    int marks;

public:
    Student(string n, int r, int m) {
        name = n;
        rollNumber = r;
        marks = m;
    }

    void display() {
        cout << "Name: " << name << endl;
        cout << "Roll Number: " << rollNumber << endl;
        cout << "Marks: " << marks << endl;
    }
};

int main() {
    Student student("Owais", 101, 95);

    student.display();

    return 0;
}
```


```output
Name: Owais
Roll Number: 101
Marks: 95
```

Here, the constructor initializes the student's details.

## 3. Step 2: Add a Result Function

Now let's add a function to check whether the student has passed.

Suppose the passing mark is `40`.

```cpp
#include <iostream>
#include <string>
using namespace std;

class Student {
private:
    string name;
    int rollNumber;
    int marks;

public:
    Student(string n, int r, int m) {
        name = n;
        rollNumber = r;
        marks = m;
    }

    void display() {
        cout << "Name: " << name << endl;
        cout << "Roll Number: " << rollNumber << endl;
        cout << "Marks: " << marks << endl;
    }

    void checkResult() {
        if (marks >= 40) {
            cout << "Result: Pass" << endl;
        } else {
            cout << "Result: Fail" << endl;
        }
    }
};

int main() {
    Student student("Owais", 101, 95);

    student.display();
    student.checkResult();

    return 0;
}
```


```output
Name: Owais
Roll Number: 101
Marks: 95
Result: Pass
```

## 4. Step 3: Add a Grade Function

We can also calculate a grade from the marks.

Let's use:

|    Marks | Grade |
| -------: | :---- |
|   90–100 | A     |
|    75–89 | B     |
|    60–74 | C     |
|    40–59 | D     |

Add this function:

```cpp
char getGrade() {
    if (marks >= 90) {
        return 'A';
    } else if (marks >= 75) {
        return 'B';
    } else if (marks >= 60) {
        return 'C';
    } else if (marks >= 40) {
        return 'D';
    } else {
        return 'F';
    }
```

## 5. Step 4: Add a Static Student Counter

Now let's count how many `Student` objects have been created.

A static data member is suitable because the count should be shared by all objects.

```cpp
static int studentCount;
```

The constructor can increase it:

```cpp
studentCount++;
```

The complete example:

```cpp
#include <iostream>
#include <string>
using namespace std;

class Student {
private:
    string name;
    int rollNumber;
    int marks;

    static int studentCount;

public:
    Student(string n, int r, int m) {
        name = n;
        rollNumber = r;
        marks = m;
        studentCount++;
    }

    void display() {
        cout << "Name: " << name << endl;
        cout << "Roll Number: " << rollNumber << endl;
        cout << "Marks: " << marks << endl;
    }

    static void showStudentCount() {
        cout << "Students created: " << studentCount << endl;
    }
};

int Student::studentCount = 0;

int main() {
    Student s1("Owais", 101, 95);
    Student s2("Rahul", 102, 82);

    s1.display();
    cout << endl;

    s2.display();
    cout << endl;

    Student::showStudentCount();

    return 0;
}
```


```output
Name: Owais
Roll Number: 101
Marks: 95

Name: Rahul
Roll Number: 102
Marks: 82

Students created: 2
```

## 8. Understanding the Constructor Call

Look at this constructor:

```cpp
CollegeStudent(string n, int r, int m, string d)
    : Student(n, r, m) {
    department = d;
}
```

The part:

```cpp
Student(n, r, m)
```

calls the constructor of the base class.

The order is:

```text
CollegeStudent constructor
        ↓
Student constructor
        ↓
CollegeStudent body
```

The base class is initialized before the derived class.

## 9. Adding Polymorphism

We can make the project more object-oriented by using a virtual function.

First, add a virtual `displayType()` function to `Student`.

```cpp
virtual void displayType() {
    cout << "Regular Student" << endl;
}
```

Then override it in `CollegeStudent`.

```cpp
void displayType() override {
    cout << "College Student" << endl;
}
```

Now we can use a base-class pointer.

```cpp
Student* ptr = &student;
ptr->displayType();
```

Because the function is virtual, the derived class version is called.

## 11. Adding a Friend Function

We can also use a friend function to display private information.

Suppose we want a function named `showPrivateMarks()` to access the private `marks`.

Inside `Student`:

```cpp
friend void showPrivateMarks(const Student& student);
```

Then define it outside the class:

```cpp
void showPrivateMarks(const Student& student) {
    cout << "Private Marks: " << student.marks << endl;
}
```

Now the complete concept is:

```cpp
#include <iostream>
#include <string>
using namespace std;

class Student {
private:
    string name;
    int marks;

public:
    Student(string n, int m) {
        name = n;
        marks = m;
    }

    friend void showPrivateMarks(const Student& student);
};

void showPrivateMarks(const Student& student) {
    cout << "Name: " << student.name << endl;
    cout << "Marks: " << student.marks << endl;
}

int main() {
    Student student("Owais", 95);

    showPrivateMarks(student);

    return 0;
}
```


```output
Name: Owais
Marks: 95
```

The friend function can access the private members because it was declared using `friend`.

## 12. Final Mini Project

Now let's combine the important concepts into one complete program.

The project will contain:

* Class and object
* Private data
* Constructor
* Static member
* Static member function
* Inheritance
* Virtual function
* Function overriding
* Friend function
* Conditional statements
* Strings

```cpp
#include <iostream>
#include <string>
using namespace std;

class Student {
private:
    string name;
    int rollNumber;
    int marks;

    static int studentCount;

public:
    Student(string n, int r, int m)
        : name(n), rollNumber(r), marks(m) {
        studentCount++;
    }

    virtual void displayType() {
        cout << "Student Type: Regular Student" << endl;
    }

    void display() {
        cout << "Name: " << name << endl;
        cout << "Roll Number: " << rollNumber << endl;
        cout << "Marks: " << marks << endl;
    }

    void checkResult() {
        if (marks >= 40) {
            cout << "Result: Pass" << endl;
        } else {
            cout << "Result: Fail" << endl;
        }
    }

    static void showStudentCount() {
        cout << "Students created: " << studentCount << endl;
    }

    friend void showMarks(const Student& student);

    virtual ~Student() {
    }
};

int Student::studentCount = 0;

void showMarks(const Student& student) {
    cout << "Marks using friend function: "
         << student.marks << endl;
}

class CollegeStudent : public Student {
private:
    string department;

public:
    CollegeStudent(string n, int r, int m, string d)
        : Student(n, r, m), department(d) {
    }

    void displayType() override {
        cout << "Student Type: College Student" << endl;
    }

    void displayDepartment() {
        cout << "Department: " << department << endl;
    }
};

int main() {
    CollegeStudent student(
        "Owais",
        101,
        95,
        "Computer Engineering"
    );

    Student* ptr = &student;

    ptr->displayType();

    student.display();
    student.displayDepartment();
    student.checkResult();

    showMarks(student);

    cout << endl;

    Student::showStudentCount();

    return 0;
}
```


```output
Student Type: College Student
Name: Owais
Roll Number: 101
Marks: 95
Result: Pass
Marks using friend function: 95

Students created: 1
```

## 17. Common Mistakes

### Mistake 1: Forgetting the Static Member Definition

If using a traditional out-of-class definition, remember:

```cpp
int Student::studentCount = 0;
```

### Mistake 2: Forgetting `virtual`

Without `virtual`, calling through a base-class pointer may not use the derived implementation.

```cpp
virtual void displayType();
```

### Mistake 3: Forgetting `override`

Using `override` helps the compiler verify that the derived function actually overrides a virtual base function.

```cpp
void displayType() override;
```

### Mistake 4: Accessing Private Data Directly

This is not allowed:

```cpp
// student.marks
```

Use a member function or an appropriately declared friend function.

### Mistake 5: Forgetting the Base Constructor

When a derived class needs to initialize a base class, use a constructor initializer list:

```cpp
CollegeStudent(string n, int r, int m, string d)
    : Student(n, r, m), department(d) {
}
```
