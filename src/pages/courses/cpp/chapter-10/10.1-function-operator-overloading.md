# Chapter 10: Advanced OOP & C++ Features

## Section 1: Function & Operator Overloading

**Overloading** is an important feature of C++ that allows the same name or operator to work in different ways.

C++ supports two important forms of overloading:

* **Function Overloading**
* **Operator Overloading**

Both are examples of **compile-time polymorphism**.

---

## 1. What is Function Overloading?

**Function overloading** means defining multiple functions with the same name but with different parameter lists.

The functions can differ in:

* Number of parameters
* Type of parameters
* Order of parameter types

For example:

```cpp
void add(int a, int b);
void add(double a, double b);
```

Both functions are named `add()`, but they accept different parameter types.

The compiler determines which function to call based on the arguments.

---

## 2. Simple Function Overloading

### Example

```cpp
#include <iostream>
using namespace std;

class Calculator {
public:
    int add(int a, int b) {
        return a + b;
    }

    double add(double a, double b) {
        return a + b;
    }
};

int main() {
    Calculator calc;

    cout << calc.add(10, 20) << endl;
    cout << calc.add(2.5, 3.5) << endl;

    return 0;
}
```


```output
30
6
```

The first call uses:

```cpp
add(int, int)
```

The second call uses:

```cpp
add(double, double)
```

The compiler selects the appropriate function.

---

## 3. Function Overloading with Different Numbers of Parameters

Functions can also be overloaded by changing the number of parameters.

### Example

```cpp
#include <iostream>
using namespace std;

class Calculator {
public:
    int add(int a, int b) {
        return a + b;
    }

    int add(int a, int b, int c) {
        return a + b + c;
    }
};

int main() {
    Calculator calc;

    cout << calc.add(10, 20) << endl;
    cout << calc.add(10, 20, 30) << endl;

    return 0;
}
```


```output
30
60
```

The first function accepts two arguments.

The second function accepts three arguments.

---

## 4. Function Overloading with Different Parameter Types

The parameter types can also be different.

### Example

```cpp
#include <iostream>
using namespace std;

class Display {
public:
    void show(int value) {
        cout << "Integer: " << value << endl;
    }

    void show(double value) {
        cout << "Double: " << value << endl;
    }

    void show(char value) {
        cout << "Character: " << value << endl;
    }
};

int main() {
    Display display;

    display.show(10);
    display.show(5.5);
    display.show('A');

    return 0;
}
```


```output
Integer: 10
Double: 5.5
Character: A
```

The same `show()` function name works with different data types.

---

## 5. Function Overloading with Different Parameter Order

Functions can also differ in the order of parameter types.

### Example

```cpp
#include <iostream>
using namespace std;

class Example {
public:
    void display(int a, double b) {
        cout << "Integer first" << endl;
    }

    void display(double a, int b) {
        cout << "Double first" << endl;
    }
};

int main() {
    Example obj;

    obj.display(10, 5.5);
    obj.display(5.5, 10);

    return 0;
}
```


```output
Integer first
Double first
```

The parameter order makes these two functions different overloads.

---

## 6. Function Signature

A function's **signature** is important when determining whether functions can be overloaded.

For beginner-level understanding, the parameter list determines the overload.

For example:

```cpp
int add(int a, int b);
```

and:

```cpp
int add(double a, double b);
```

have different parameter types, so they can be overloaded.

However, changing only the return type is not enough.

---

## 7. Return Type Alone Cannot Overload a Function

The following is **not valid function overloading**:

```cpp
int add(int a, int b) {
    return a + b;
}

double add(int a, int b) {
    return a + b;
}
```

Both functions have the same parameter list:

```text
(int, int)
```

Only the return type is different.

C++ cannot select between them based only on the return type.

---

## 8. Advantages of Function Overloading

Function overloading provides several benefits.

### 1. Same Name

Related operations can use the same function name.

### 2. Better Readability

The code becomes easier to understand.

### 3. Reusability

The same operation can work with different types or numbers of arguments.

### 4. Compile-Time Polymorphism

The compiler selects the correct overload during compilation.

---

# Operator Overloading

## 9. What is Operator Overloading?

**Operator overloading** allows operators to work with user-defined objects.

For example, the `+` operator normally works with numbers:

```cpp
int result = 10 + 20;
```

We can define how `+` should behave when used with objects of a class.

This is called **operator overloading**.

---

## 10. Why Operator Overloading?

Consider two objects:

```text
Number a
Number b
```

We may want to write:

```cpp
Number c = a + b;
```

Without operator overloading, C++ would not automatically know how to add these objects.

We can define the meaning of `+` for the class.

---

## 11. Simple Operator Overloading

### Example

```cpp
#include <iostream>
using namespace std;

class Number {
public:
    int value;

    Number(int v) {
        value = v;
    }

    Number operator+(Number other) {
        return Number(value + other.value);
    }
};

int main() {
    Number a(10);
    Number b(20);

    Number c = a + b;

    cout << c.value << endl;

    return 0;
}
```


```output
30
```

Here:

```cpp
a + b
```

uses the overloaded `+` operator.

---

## 12. Understanding `operator+`

The function:

```cpp
Number operator+(Number other)
```

defines the behavior of the `+` operator for `Number` objects.

When we write:

```cpp
Number c = a + b;
```

the overloaded operator is used.

Conceptually, the operation behaves like a member-function call involving `a` and `b`.

---

## 13. Operator Overloading with Two Objects

### Example

```cpp
#include <iostream>
using namespace std;

class Point {
public:
    int x;
    int y;

    Point(int a, int b) {
        x = a;
        y = b;
    }

    Point operator+(Point other) {
        return Point(x + other.x, y + other.y);
    }
};

int main() {
    Point p1(2, 3);
    Point p2(4, 5);

    Point p3 = p1 + p2;

    cout << "x = " << p3.x << endl;
    cout << "y = " << p3.y << endl;

    return 0;
}
```


```output
x = 6
y = 8
```

The overloaded `+` operator adds the corresponding values of the two objects.

---

## 14. Overloading the `==` Operator

Operators other than `+` can also be overloaded.

For example, we can define how two objects should be compared using `==`.

### Example

```cpp
#include <iostream>
using namespace std;

class Number {
public:
    int value;

    Number(int v) {
        value = v;
    }

    bool operator==(Number other) {
        return value == other.value;
    }
};

int main() {
    Number a(10);
    Number b(10);

    if (a == b) {
        cout << "Equal" << endl;
    } else {
        cout << "Not equal" << endl;
    }

    return 0;
}
```


```output
Equal
```

The `==` operator now compares the `value` members of two `Number` objects.

---

## 15. Overloading the `-` Operator

We can also define subtraction for objects.

### Example

```cpp
#include <iostream>
using namespace std;

class Number {
public:
    int value;

    Number(int v) {
        value = v;
    }

    Number operator-(Number other) {
        return Number(value - other.value);
    }
};

int main() {
    Number a(50);
    Number b(20);

    Number c = a - b;

    cout << c.value << endl;

    return 0;
}
```


```output
30
```

The overloaded `-` operator subtracts the values stored in the objects.

---

## 16. Overloading the `++` Operator

The increment operator can also be overloaded.

### Example

```cpp
#include <iostream>
using namespace std;

class Counter {
public:
    int value;

    Counter(int v) {
        value = v;
    }

    void operator++() {
        value++;
    }
};

int main() {
    Counter counter(5);

    ++counter;

    cout << counter.value << endl;

    return 0;
}
```


```output
6
```

The overloaded `++` operator increases the object's `value`.

---

## 17. Operator Overloading with Private Data

Operator overloading can also be used when class data is private.

### Example

```cpp
#include <iostream>
using namespace std;

class Number {
private:
    int value;

public:
    Number(int v) {
        value = v;
    }

    Number operator+(Number other) {
        return Number(value + other.value);
    }

    void display() {
        cout << value << endl;
    }
};

int main() {
    Number a(10);
    Number b(20);

    Number c = a + b;

    c.display();

    return 0;
}
```


```output
30
```

The overloaded operator is a member function, so it can access the private data of its class objects.

---

## 18. Operators That Can Be Overloaded

Many C++ operators can be overloaded.

Some common examples are:

| Operator | Common use            |
| -------- | --------------------- |
| `+`      | Addition              |
| `-`      | Subtraction           |
| `*`      | Multiplication        |
| `/`      | Division              |
| `%`      | Modulus               |
| `==`     | Equality              |
| `!=`     | Not equal             |
| `<`      | Less than             |
| `>`      | Greater than          |
| `<=`     | Less than or equal    |
| `>=`     | Greater than or equal |
| `++`     | Increment             |
| `--`     | Decrement             |

---

## 19. Operators That Cannot Be Overloaded

Some operators cannot be overloaded in C++.

Important examples include:

* `::` Scope resolution operator
* `.` Member access operator
* `.*` Pointer-to-member operator
* `?:` Conditional operator
* `sizeof`

These operators have fixed meanings in C++.

---

## 20. Operator Overloading Does Not Create New Operators

Operator overloading allows us to define behavior for an existing operator.

We cannot create a completely new operator such as:

```text
@@
```

and make it a C++ operator through operator overloading.

For example, we can overload:

```cpp
+
```

but we cannot invent:

```text
**
```

as a new C++ operator through normal operator overloading.

---

## 21. Changing Operator Precedence

Operator overloading does **not** change operator precedence.

For example, `*` still has higher precedence than `+`.

Overloading an operator only changes what that operator does for a particular user-defined type.

It does not change the rules of expression evaluation.

---

## 22. Changing the Number of Operands

Operator overloading also cannot arbitrarily change how many operands an operator requires.

For example:

```cpp
a + b
```

uses two operands.

Overloading `+` does not turn it into a three-operand operator.

The operator keeps its normal number of operands.

---

## 23. Function Overloading vs Operator Overloading

| Feature      | Function Overloading                     | Operator Overloading                           |
| ------------ | ---------------------------------------- | ---------------------------------------------- |
| Purpose      | Same function name, different parameters | Give operators behavior for user-defined types |
| Example      | `add()`                                  | `operator+()`                                  |
| Polymorphism | Compile-time                             | Compile-time                                   |
| Used with    | Functions                                | Operators                                      |
| Main benefit | Reuse function names                     | Natural syntax for objects                     |

---

## 24. Real-World Example 🌍

Consider a simple shopping application.

Suppose a `Price` class stores an item's price.

We can overload `+` so that two prices can be added naturally.

### Example

```cpp
#include <iostream>
using namespace std;

class Price {
private:
    double amount;

public:
    Price(double value) {
        amount = value;
    }

    Price operator+(Price other) {
        return Price(amount + other.amount);
    }

    void display() {
        cout << "Total: " << amount << endl;
    }
};

int main() {
    Price item1(250.50);
    Price item2(149.50);

    Price total = item1 + item2;

    total.display();

    return 0;
}
```


```output
Total: 400
```

The `+` operator provides a natural way to combine two `Price` objects.

## 25. Function Overloading and Operator Overloading Together

A class can use both forms of overloading.

### Example

```cpp
#include <iostream>
using namespace std;

class Calculator {
public:
    int add(int a, int b) {
        return a + b;
    }

    double add(double a, double b) {
        return a + b;
    }
};

class Number {
public:
    int value;

    Number(int v) {
        value = v;
    }

    Number operator+(Number other) {
        return Number(value + other.value);
    }
};

int main() {
    Calculator calc;

    cout << calc.add(10, 20) << endl;
    cout << calc.add(2.5, 3.5) << endl;

    Number a(10);
    Number b(20);

    Number c = a + b;

    cout << c.value << endl;

    return 0;
}
```


```output
30
6
30
```

The program uses:

* Function overloading with `add()`
* Operator overloading with `+`

## Common Mistakes

### Mistake 1: Overloading using only the return type

This is not allowed:

```cpp
int test(int x);
double test(int x);
```

The parameter lists are the same.

---

### Mistake 2: Confusing overloading with overriding

**Overloading** uses the same function name with different parameter lists.

**Overriding** happens when a derived class provides a new implementation of a virtual base-class function.

---

### Mistake 3: Thinking every operator can be overloaded

Some operators cannot be overloaded, such as:

```text
::
.
.*
?:
sizeof
```

---

### Mistake 4: Thinking operator overloading changes precedence

It does not change operator precedence.

For example, `*` still has higher precedence than `+`.

---

### Mistake 5: Creating a completely new operator

Operator overloading only works with existing C++ operators.

You cannot invent a new operator.

---

## Key Points 🔑

* **Function overloading** allows multiple functions with the same name and different parameter lists.
* Functions can be overloaded by changing the number, types, or order of parameters.
* Return type alone cannot distinguish overloaded functions.
* **Operator overloading** gives existing operators behavior for user-defined types.
* Operator functions can be written using the `operator` keyword.
* `+`, `-`, `==`, `++`, and many other operators can be overloaded.
* Some operators cannot be overloaded.
* Operator overloading does not change operator precedence.
* Operator overloading does not create new operators.
* Function and operator overloading are forms of compile-time polymorphism.
* Overloading can make code involving objects more readable and natural.
