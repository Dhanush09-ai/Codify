# Chapter 9: Object-Oriented Programming

## Section 1: Introduction to OOP

**OOP** stands for **Object-Oriented Programming**.

It is a programming approach where programs are designed using **objects and classes**.

C++ supports object-oriented programming and provides features such as:

* Classes and objects
* Encapsulation
* Inheritance
* Polymorphism
* Abstraction

These features help us organize large programs into smaller and reusable parts.

---

## 1. What is OOP?

Object-Oriented Programming is a way of writing programs by representing things as **objects**.

An object can contain:

* **Data** — information about the object
* **Functions** — actions that the object can perform

For example, a `Student` object can contain:

```text
Data:
Name
Age
Marks

Functions:
display()
calculateGrade()
```

In C++, classes are used to create objects.

---

## 2. Class and Object

A **class** is a blueprint or template for creating objects.

An **object** is an actual instance of a class.

### Example

```cpp
#include <iostream>
using namespace std;

class Student {
public:
    string name;
    int marks;

    void display() {
        cout << "Name: " << name << endl;
        cout << "Marks: " << marks << endl;
    }
};

int main() {
    Student student;

    student.name = "Owais";
    student.marks = 95;

    student.display();

    return 0;
}
```


```output
Name: Owais
Marks: 95
```

Here:

* `Student` is a class.
* `student` is an object.
* `name` and `marks` are data members.
* `display()` is a member function.

---

## 3. Why Do We Use OOP?

OOP is useful for organizing programs, especially when programs become large.

Without proper organization, a large program can become difficult to:

* Understand
* Modify
* Debug
* Reuse
* Maintain

OOP groups related data and functions together inside classes.

For example, instead of keeping student data and student-related functions separately, we can put them together in a `Student` class.

---

## 4. Procedural Programming vs OOP

There are different ways to organize a program.

### Procedural Programming

Procedural programming focuses mainly on **functions and procedures**.

The program is generally organized around operations.

```text
Data
 ↓
Functions
 ↓
Operations
```

### Object-Oriented Programming

OOP focuses on **objects that contain data and related functions**.

```text
Object
 ├── Data
 └── Functions
```

### Comparison

| Procedural Programming                      | Object-Oriented Programming               |
| ------------------------------------------- | ----------------------------------------- |
| Focuses mainly on functions                 | Focuses on objects                        |
| Data and functions may be separate          | Data and related functions are grouped    |
| Suitable for smaller programs               | Useful for larger and complex programs    |
| Reusability can be more limited             | Supports reusable classes and inheritance |
| C is commonly associated with this approach | C++ supports this approach                |

## 5. Main Concepts of OOP

C++ provides several important OOP concepts.

### 1. Encapsulation

Encapsulation means **grouping data and functions together** and controlling access to the data.

Example:

```cpp
class BankAccount {
private:
    double balance;

public:
    void deposit(double amount) {
        balance += amount;
    }
};
```

The `balance` is private and can be controlled through member functions.

---

### 2. Inheritance

Inheritance allows one class to **reuse and extend** another class.

For example:

```text
Vehicle
   ↓
Car
```

A `Car` can inherit common features from `Vehicle`.

Inheritance will be studied in detail later.

---

### 3. Polymorphism

Polymorphism means **one interface or name can have different behaviors** depending on the situation.

For example, the same function name can behave differently through function overloading or virtual functions.

```text
One name
   ↓
Different behaviors
```

Polymorphism will be studied in detail later.

---

### 4. Abstraction

Abstraction means **showing important information while hiding unnecessary implementation details**.

For example, when using an ATM, you select an option such as withdrawing money without needing to know the internal code that processes the transaction.

---

## 6. Encapsulation

Encapsulation is an important part of OOP.

It combines related data and functions inside a class.

### Example

```cpp
#include <iostream>
using namespace std;

class BankAccount {
private:
    double balance = 0;

public:
    void deposit(double amount) {
        balance += amount;
    }

    void displayBalance() {
        cout << "Balance: " << balance << endl;
    }
};

int main() {
    BankAccount account;

    account.deposit(5000);
    account.displayBalance();

    return 0;
}
```


```output
Balance: 5000
```

The `balance` is kept private, while public functions provide controlled access.

---

## 7. Data Hiding

Data hiding means preventing direct access to certain internal data.

C++ provides access specifiers such as:

* `private`
* `public`
* `protected`

For example:

```cpp
class Student {
private:
    int marks;

public:
    void setMarks(int value) {
        marks = value;
    }

    int getMarks() {
        return marks;
    }
};
```

Here, `marks` cannot normally be accessed directly from outside the class.

Instead, public functions control access.

## 8. Reusability

One important advantage of OOP is **code reusability**.

Once a class is created, we can create many objects from it.

### Example

```cpp
#include <iostream>
using namespace std;

class Student {
public:
    string name;

    void display() {
        cout << "Student: " << name << endl;
    }
};

int main() {
    Student student1;
    Student student2;
    Student student3;

    student1.name = "Owais";
    student2.name = "Ali";
    student3.name = "Sara";

    student1.display();
    student2.display();
    student3.display();

    return 0;
}
```


```output
Student: Owais
Student: Ali
Student: Sara
```

The same class is reused to create three different objects.

## 11. Multiple Objects

A class can be used to create many objects.

For example:

```cpp

Student student2;

```

All three objects are created from the same `Student` class.

However, each object has its own data.

```text
Student class
      │
      ├── student1
      ├── student2
      └── student3
```

## 12. OOP and Reusable Code

Suppose we create a `Rectangle` class.

```cpp
#include <iostream>
using namespace std;

class Rectangle {
public:
    int length;
    int width;

    int area() {
        return length * width;
    }
};

int main() {
    Rectangle r1;
    Rectangle r2;

    r1.length = 10;
    r1.width = 5;

    r2.length = 8;
    r2.width = 4;

    cout << "Area 1: " << r1.area() << endl;
    cout << "Area 2: " << r2.area() << endl;

    return 0;
}
```


```output
Area 1: 50
Area 2: 32
```

The `area()` function is written once inside the class and can be used by multiple objects.

## 16. Example of a Simple OOP Program

Here is a simple example combining several ideas.

```cpp
#include <iostream>
#include <string>
using namespace std;

class Student {
private:
    string name;
    int marks;

public:
    Student(string name, int marks) {
        this->name = name;
        this->marks = marks;
    }

    void display() {
        cout << "Name: " << name << endl;
        cout << "Marks: " << marks << endl;
    }
};

int main() {
    Student student("Owais", 95);

    student.display();

    return 0;
}
```


```output
Name: Owais
Marks: 95
```

This example uses several OOP ideas:

* `Student` is a class.
* `student` is an object.
* `name` and `marks` are data members.
* `display()` is a member function.
* The constructor initializes the object.
* `private` provides data hiding.
* `public` provides controlled access.

## Common Mistakes

### Mistake 1: Thinking OOP means only classes

Classes and objects are important parts of OOP, but OOP also includes concepts such as:

* Encapsulation
* Inheritance
* Polymorphism
* Abstraction

---

### Mistake 2: Confusing class and object

A class is a blueprint.

An object is an instance created from that class.

```cpp
class Student {
};

Student student;
```

Here:

* `Student` → class
* `student` → object

---

### Mistake 3: Thinking every C++ program must use OOP

C++ is a multi-paradigm language. It supports object-oriented programming as well as other programming styles.

Small programs may not need complex class designs.

---

### Mistake 4: Making every data member public

Making everything public can allow unwanted direct changes to data.

Using `private` members with suitable public functions can provide better control when needed.

---

### Mistake 5: Thinking OOP automatically makes every program better

OOP is a useful programming approach, but the design should match the problem.

For a very small program, a simple solution may be enough.

---

* OOP stands for **Object-Oriented Programming**.
* OOP organizes programs around objects and classes.
* A class is a blueprint for creating objects.
* An object is an instance of a class.
* Objects contain data and related functions.
* Encapsulation groups data and functions together.
* Data hiding can be achieved using access control such as `private`.
* Inheritance allows classes to reuse and extend other classes.
* Polymorphism allows different behaviors through a common interface or name.
