# Chapter 9: Object-Oriented Programming

## Section 3: Inheritance

**Inheritance** is an important concept of Object-Oriented Programming.

Inheritance allows one class to **reuse the data and functions of another class**.

The existing class is called the **base class** or **parent class**.

The new class is called the **derived class** or **child class**.

Inheritance helps reduce repeated code and allows us to build relationships between classes.

---

## 1. What is Inheritance?

Inheritance allows a new class to use members of an existing class.

For example:

```text
        Vehicle
           │
           ↓
          Car
```

Here:

* `Vehicle` is the base class.
* `Car` is the derived class.
* `Car` can inherit accessible members from `Vehicle`.

The derived class can also have its own additional members.

---

## 2. Basic Syntax of Inheritance

The basic syntax is:

```cpp
class DerivedClass : accessSpecifier BaseClass {
    // derived class members
};
```

For example:

```cpp
class Car : public Vehicle {
};
```

Here:

* `Car` → derived class
* `Vehicle` → base class
* `public` → inheritance mode

---

## 3. Simple Inheritance Example

### Example

```cpp
#include <iostream>
using namespace std;

class Animal {
public:
    void eat() {
        cout << "Animal is eating" << endl;
    }
};

class Dog : public Animal {
public:
    void bark() {
        cout << "Dog is barking" << endl;
    }
};

int main() {
    Dog dog;

    dog.eat();
    dog.bark();

    return 0;
}
```


```output
Animal is eating
Dog is barking
```

The `Dog` class inherits the `eat()` function from `Animal`.

The `Dog` class also has its own `bark()` function.

---

## 4. Base Class and Derived Class

Consider:

```cpp
class Animal {
};

class Dog : public Animal {
};
```

Here:

```text
Animal
  ↑
  │
 Dog
```

`Animal` is the **base class**.

`Dog` is the **derived class**.

The derived class can use accessible members of the base class.

---

## 5. Why Use Inheritance?

Inheritance provides several benefits.

### 1. Code Reusability

Existing functionality can be reused instead of writing it again.

### 2. Less Duplicate Code

Common functionality can be placed in a base class.

### 3. Easy Extension

A derived class can add new features to the base class.

### 4. Better Organization

Related classes can be arranged in a hierarchy.

For example:

```text
             Vehicle
            /       \
          Car       Bike
```

---

## 6. Adding New Members to a Derived Class

A derived class can use inherited members and also define its own members.

### Example

```cpp
#include <iostream>
using namespace std;

class Vehicle {
public:
    void start() {
        cout << "Vehicle started" << endl;
    }
};

class Car : public Vehicle {
public:
    void drive() {
        cout << "Car is driving" << endl;
    }
};

int main() {
    Car car;

    car.start();
    car.drive();

    return 0;
}
```


```output
Vehicle started
Car is driving
```

`start()` comes from the base class.

`drive()` belongs to the derived class.

---

## 7. Inheritance with Data Members

A derived class can also access inherited public data members.

### Example

```cpp
#include <iostream>
#include <string>
using namespace std;

class Person {
public:
    string name;
};

class Student : public Person {
public:
    int marks;
};

int main() {
    Student student;

    student.name = "Owais";
    student.marks = 95;

    cout << "Name: " << student.name << endl;
    cout << "Marks: " << student.marks << endl;

    return 0;
}
```


```output
Name: Owais
Marks: 95
```

`name` comes from `Person`, while `marks` belongs to `Student`.

---

## 8. Protected Members

A base class can use the `protected` access specifier when a member should be accessible inside the class and its derived classes.

### Example

```cpp
#include <iostream>
using namespace std;

class Person {
protected:
    int age;
};

class Student : public Person {
public:
    void setAge(int value) {
        age = value;
    }

    void displayAge() {
        cout << "Age: " << age << endl;
    }
};

int main() {
    Student student;

    student.setAge(18);
    student.displayAge();

    return 0;
}
```


```output
Age: 18
```

The derived class can access the protected member `age`.

However, code outside the class hierarchy cannot normally access it directly.

---

## 9. Private Members and Inheritance

Private members of a base class are **not directly accessible** from the derived class.

### Example

```cpp
#include <iostream>
using namespace std;

class Person {
private:
    int age;

public:
    void setAge(int value) {
        age = value;
    }

    int getAge() {
        return age;
    }
};

class Student : public Person {
public:
    void displayAge() {
        cout << getAge() << endl;
    }
};

int main() {
    Student student;

    student.setAge(18);
    student.displayAge();

    return 0;
}
```


```output
18
```

The derived class cannot directly use:

```cpp
age
```

because it is private in `Person`.

Instead, it can use the public functions provided by the base class.

---

## 10. Public Inheritance

The most common form of inheritance for beginner examples is **public inheritance**.

Syntax:

```cpp
class Derived : public Base {
};
```

For example:

```cpp
class Vehicle {
public:
    void start() {
        cout << "Started";
    }
};

class Car : public Vehicle {
};
```

The public members of `Vehicle` remain accessible as public members through `Car`.

---

## 11. Types of Inheritance

C++ supports several inheritance structures.

### 1. Single Inheritance

One derived class inherits from one base class.

```text
Animal
   ↓
 Dog
```

---

### 2. Multilevel Inheritance

A class inherits from another derived class.

```text
Animal
   ↓
Mammal
   ↓
Dog
```

---

### 3. Multiple Inheritance

One derived class inherits from more than one base class.

```text
Printer     Scanner
    \         /
     \       /
    AllInOne
```

---

### 4. Hierarchical Inheritance

Multiple derived classes inherit from the same base class.

```text
        Vehicle
        /     \
      Car     Bike
```

---

### 5. Hybrid Inheritance

Hybrid inheritance combines two or more inheritance structures.

For example:

```text
       A
      / \
     B   C
      \ /
       D
```

These types will be explored in more detail later.

---

## 12. Single Inheritance

Single inheritance is the simplest type.

One derived class inherits from one base class.

### Example

```cpp
#include <iostream>
using namespace std;

class Animal {
public:
    void eat() {
        cout << "Eating" << endl;
    }
};

class Dog : public Animal {
public:
    void bark() {
        cout << "Barking" << endl;
    }
};

int main() {
    Dog dog;

    dog.eat();
    dog.bark();

    return 0;
}
```


```output
Eating
Barking
```

---

## 13. Multilevel Inheritance

In multilevel inheritance, inheritance happens in multiple levels.

### Example

```text
Animal
   ↓
Mammal
   ↓
Dog
```

### Code

```cpp
#include <iostream>
using namespace std;

class Animal {
public:
    void eat() {
        cout << "Eating" << endl;
    }
};

class Mammal : public Animal {
public:
    void breathe() {
        cout << "Breathing" << endl;
    }
};

class Dog : public Mammal {
public:
    void bark() {
        cout << "Barking" << endl;
    }
};

int main() {
    Dog dog;

    dog.eat();
    dog.breathe();
    dog.bark();

    return 0;
}
```


```output
Eating
Breathing
Barking
```

The `Dog` object can access accessible members inherited through both levels.

---

## 14. Hierarchical Inheritance

In hierarchical inheritance, multiple classes inherit from the same base class.

### Example

```cpp
#include <iostream>
using namespace std;

class Vehicle {
public:
    void start() {
        cout << "Vehicle started" << endl;
    }
};

class Car : public Vehicle {
public:
    void drive() {
        cout << "Car driving" << endl;
    }
};

class Bike : public Vehicle {
public:
    void ride() {
        cout << "Bike riding" << endl;
    }
};

int main() {
    Car car;
    Bike bike;

    car.start();
    car.drive();

    bike.start();
    bike.ride();

    return 0;
}
```


```output
Vehicle started
Car driving
Vehicle started
Bike riding
```

Both `Car` and `Bike` reuse the `start()` function from `Vehicle`.

---

## 15. Multiple Inheritance

In multiple inheritance, one class inherits from more than one base class.

### Example

```cpp
#include <iostream>
using namespace std;

class Printer {
public:
    void print() {
        cout << "Printing" << endl;
    }
};

class Scanner {
public:
    void scan() {
        cout << "Scanning" << endl;
    }
};

class AllInOne : public Printer, public Scanner {
};

int main() {
    AllInOne device;

    device.print();
    device.scan();

    return 0;
}
```


```output
Printing
Scanning
```

`AllInOne` inherits from both `Printer` and `Scanner`.

---

## 16. Constructor and Inheritance

When an object of a derived class is created, the base-class constructor runs before the derived-class constructor.

### Example

```cpp
#include <iostream>
using namespace std;

class Parent {
public:
    Parent() {
        cout << "Parent constructor" << endl;
    }
};

class Child : public Parent {
public:
    Child() {
        cout << "Child constructor" << endl;
    }
};

int main() {
    Child child;

    return 0;
}
```


```output
Parent constructor
Child constructor
```

The base class is initialized first.

---

## 17. Destructor and Inheritance

When a derived object is destroyed, its derived-class destructor runs before the base-class destructor.

### Example

```cpp
#include <iostream>
using namespace std;

class Parent {
public:
    ~Parent() {
        cout << "Parent destructor" << endl;
    }
};

class Child : public Parent {
public:
    ~Child() {
        cout << "Child destructor" << endl;
    }
};

int main() {
    Child child;

    return 0;
}
```


```output
Child destructor
Parent destructor
```

The destruction order is opposite to the construction order.

---

## 18. Inheritance and Code Reuse

Suppose several classes need the same `display()` function.

Instead of repeating the function in every class, we can put the common functionality into a base class.

### Example

```cpp
#include <iostream>
#include <string>
using namespace std;

class Person {
protected:
    string name;

public:
    void setName(string value) {
        name = value;
    }

    void displayName() {
        cout << "Name: " << name << endl;
    }
};

class Student : public Person {
public:
    void study() {
        cout << name << " is studying" << endl;
    }
};

int main() {
    Student student;

    student.setName("Owais");
    student.displayName();
    student.study();

    return 0;
}
```


```output
Name: Owais
Owais is studying
```

The `Student` class reuses functionality from `Person`.

---

## 19. Inheritance Represents an "Is-A" Relationship

Inheritance is commonly useful when there is an **"is-a" relationship**.

For example:

```text
Car is a Vehicle
Dog is an Animal
Student is a Person
```

So we can write:

```cpp
class Car : public Vehicle {
};
```

and:

```cpp
class Dog : public Animal {
};
```

The derived class represents a more specific type of the base class.

---

## 20. Inheritance vs Composition

Not every relationship should use inheritance.

Inheritance commonly represents an **"is-a"** relationship.

Composition commonly represents a **"has-a"** relationship.

### Is-A

```text
Car is a Vehicle
```

Possible inheritance:

```cpp
class Car : public Vehicle {
};
```

### Has-A

```text
Car has an Engine
```

Possible composition:

```cpp
class Car {
private:
    Engine engine;
};
```

Choosing the correct relationship is important when designing classes.

## 21. Real-World Example 🌍

Consider a college system.

A general `Person` class can contain common information.

```text
          Person
         /      \
    Student    Teacher
```

Both students and teachers are people.

### Example

```cpp
#include <iostream>
#include <string>
using namespace std;

class Person {
protected:
    string name;

public:
    Person(string personName) {
        name = personName;
    }

    void displayName() {
        cout << "Name: " << name << endl;
    }
};

class Student : public Person {
private:
    int marks;

public:
    Student(string studentName, int studentMarks)
        : Person(studentName) {
        marks = studentMarks;
    }

    void displayStudent() {
        displayName();
        cout << "Marks: " << marks << endl;
    }
};

int main() {
    Student student("Owais", 95);

    student.displayStudent();

    return 0;
}
```


```output
Name: Owais
Marks: 95
```

The `Student` class reuses the common `Person` functionality and adds student-specific data.

## Common Mistakes

### Mistake 1: Confusing base and derived classes

In:

```cpp
class Car : public Vehicle {
};
```

* `Vehicle` is the base class.
* `Car` is the derived class.

---

### Mistake 2: Trying to access private base members directly

A private member of the base class cannot be directly accessed by the derived class.

Use suitable public or protected members when access is required.

---

### Mistake 3: Thinking inheritance copies everything as public

Access depends on the member's access specifier and the inheritance mode.

`private` members of a base class are not directly accessible in the derived class.

---

### Mistake 4: Using inheritance for every relationship

Use inheritance when there is a meaningful **"is-a"** relationship.

For a **"has-a"** relationship, composition may be more appropriate.

---

### Mistake 5: Forgetting the inheritance syntax

Correct:

```cpp
class Student : public Person {
};
```

The colon `:` separates the derived class name from the inheritance specification.

---

## Key Points 🔑

* Inheritance allows one class to reuse and extend another class.
* The existing class is called the **base class**.
* The new class is called the **derived class**.
* Public inheritance is written using `: public`.
* Derived classes can add their own data and functions.
* Private base-class members are not directly accessible in the derived class.
* Protected members can be accessed by the class and its derived classes.
* C++ supports single, multilevel, multiple, hierarchical, and hybrid inheritance.
* Base constructors run before derived constructors.
* Derived destructors run before base destructors.
* Inheritance commonly represents an **"is-a"** relationship.
* Inheritance supports code reuse and helps organize related classes.
