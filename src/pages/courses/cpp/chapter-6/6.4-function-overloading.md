# Chapter 6: Functions

## Section 4: Function Overloading

**Function overloading** allows us to create multiple functions with the **same name** but with different parameters.

The compiler determines which function to call based on the arguments passed to it.

Function overloading makes programs easier to read and allows the same operation to work with different types or numbers of values.

---

## 1. What is Function Overloading?

Normally, each function has a different name.

For example:

```cpp
int addTwoNumbers(int a, int b);
double addDecimalNumbers(double a, double b);
```

With function overloading, we can use the same name:

```cpp
int add(int a, int b);
double add(double a, double b);
```

The compiler chooses the appropriate `add()` function based on the arguments.

---

## 2. Simple Function Overloading

Consider these two functions:

```cpp
void display(int number) {
    cout << "Integer: " << number << endl;
}

void display(double number) {
    cout << "Double: " << number << endl;
}
```

Both functions have the same name, `display`, but different parameter types.

### Complete Example

```cpp
#include <iostream>
using namespace std;

void display(int number) {
    cout << "Integer: " << number << endl;
}

void display(double number) {
    cout << "Double: " << number << endl;
}

int main() {
    display(10);
    display(10.5);

    return 0;
}
```


```output
Integer: 10
Double: 10.5
```

When `display(10)` is called, the `int` version is selected.

When `display(10.5)` is called, the `double` version is selected.

---

## 3. Why Do We Use Function Overloading?

Function overloading is useful when several functions perform a similar task but work with different inputs.

For example:

```cpp
add(int, int)
add(double, double)
```

Both functions perform addition.

Using the same name makes the program easier to understand.

Without overloading, we might use:

```cpp
addIntegers()
addDecimals()
```

With overloading:

```cpp
add()
add()
```

The compiler decides which version is appropriate.

---

## 4. Overloading with Different Number of Parameters

Functions can also be overloaded by changing the number of parameters.

Example:

```cpp
#include <iostream>
using namespace std;

int add(int a, int b) {
    return a + b;
}

int add(int a, int b, int c) {
    return a + b + c;
}

int main() {
    cout << add(10, 20) << endl;
    cout << add(10, 20, 30) << endl;

    return 0;
}
```


```output
30
60
```

Here:

```text
add(int, int)
add(int, int, int)
```

are two different overloaded functions.

The number of arguments determines which function is called.

---

## 5. Overloading with Different Parameter Types

We can change the parameter types.

Example:

```cpp
#include <iostream>
using namespace std;

void show(int value) {
    cout << "Integer: " << value << endl;
}

void show(string value) {
    cout << "String: " << value << endl;
}

int main() {
    show(100);
    show("Hello");

    return 0;
}
```


```output
Integer: 100
String: Hello
```

The compiler selects the function based on the type of argument.

---

## 6. Overloading with Two Different Types

We can also change the combination of parameter types.

```cpp
#include <iostream>
using namespace std;

void display(int a, double b) {
    cout << "int, double" << endl;
}

void display(double a, int b) {
    cout << "double, int" << endl;
}

int main() {
    display(10, 5.5);
    display(5.5, 10);

    return 0;
}
```


```output
int, double
double, int
```

The order and types of parameters are part of the function's parameter list.

---

## 7. Function Signature

For beginner-level function overloading, it is useful to understand the idea of a **function signature**.

The parameter list helps distinguish overloaded functions.

For example:

```cpp
int add(int a, int b);
double add(double a, double b);
```

The parameter types are different, so these functions can be overloaded.

Similarly:

```cpp
int add(int a, int b);
int add(int a, int b, int c);
```

The number of parameters is different, so these functions can also be overloaded.

---

## 8. Return Type Alone Cannot Overload a Function

We cannot overload functions only by changing their return type.

For example, this is not allowed:

```cpp
int calculate(int a, int b) {
    return a + b;
}

double calculate(int a, int b) {
    return a + b;
}
```

Both functions have the same name and the same parameter list.

Only the return type is different.

C++ cannot use the return type alone to decide which function should be called.

---

## 9. Overloading with `int` and `double`

A common use of function overloading is performing calculations with different numeric types.

```cpp
#include <iostream>
using namespace std;

int multiply(int a, int b) {
    return a * b;
}

double multiply(double a, double b) {
    return a * b;
}

int main() {
    cout << multiply(4, 5) << endl;
    cout << multiply(2.5, 4.0) << endl;

    return 0;
}
```


```output
20
10
```

The first call uses the `int` version.

The second call uses the `double` version.

---

## 10. Overloading with Different Number of Arguments

A function can have multiple overloaded versions with different numbers of arguments.

```cpp
#include <iostream>
using namespace std;

void print(int a) {
    cout << "One value: " << a << endl;
}

void print(int a, int b) {
    cout << "Two values: " << a << ", " << b << endl;
}

void print(int a, int b, int c) {
    cout << "Three values: " << a << ", " << b << ", " << c << endl;
}

int main() {
    print(10);
    print(10, 20);
    print(10, 20, 30);

    return 0;
}
```


```output
One value: 10
Two values: 10, 20
Three values: 10, 20, 30
```

The compiler chooses the appropriate version according to the number of arguments.

---

## 11. Function Overloading with `string`

Function overloading can also be used with strings.

```cpp
#include <iostream>
#include <string>
using namespace std;

void display(string text) {
    cout << "Text: " << text << endl;
}

void display(int number) {
    cout << "Number: " << number << endl;
}

int main() {
    display("C++");
    display(2026);

    return 0;
}
```


```output
Text: C++
Number: 2026
```

The compiler selects the appropriate function according to the argument type.

---

## 12. How Function Overloading Works

Consider:

```cpp
void show(int value);
void show(double value);
```

When we write:

```cpp
show(10);
```

the compiler looks for a suitable function that accepts an `int`.

When we write:

```cpp
show(10.5);
```

the compiler looks for a suitable function that accepts a `double`.

The selection happens during **compile time**.

Therefore, function overloading is an example of **compile-time polymorphism**.

---

## 13. Function Overloading Flow

Consider:

```cpp
int add(int a, int b);
double add(double a, double b);
```

If we call:

```cpp
add(5, 10);
```

the compiler selects:

```text
int add(int, int)
```

If we call:

```cpp
add(5.5, 10.5);
```

the compiler selects:

```text
double add(double, double)
```

The function name remains the same, but the parameter list is different.

---

## 14. Advantages of Function Overloading

Function overloading provides several benefits.

### 1. Same name for similar operations

We can use one meaningful name for related operations.

### 2. Better readability

For example:

```cpp
add(10, 20);
add(2.5, 4.5);
```

is easier to understand than using unrelated names.

### 3. Code organization

Related operations can be grouped under the same function name.

### 4. Compile-time selection

The compiler determines which overloaded function should be used.

---

## 15. Real-World Example 🌍

Imagine a calculator that can add different types of numbers.

We can create overloaded `add()` functions.

```cpp
#include <iostream>
using namespace std;

int add(int a, int b) {
    return a + b;
}

double add(double a, double b) {
    return a + b;
}

int main() {
    cout << "Integer sum = " << add(10, 20) << endl;
    cout << "Decimal sum = " << add(10.5, 20.5) << endl;

    return 0;
}
```


```output
Integer sum = 30
Decimal sum = 31
```

The same `add()` function name is used for both integer and decimal calculations.

## 16. Common Mistakes

### 1. Changing only the return type

This does not create a valid overload.

```cpp
int test(int x);
double test(int x);
```

The parameter list is the same.

### 2. Creating identical functions

These functions have the same parameter list:

```cpp
void display(int x);
void display(int y);
```

Changing only parameter names does not create an overload.

### 3. Passing ambiguous arguments

Sometimes more than one overloaded function may be an equally suitable match after conversions.

For example, overloaded functions should be designed carefully to avoid ambiguous calls.

### 4. Confusing overloading with calling

Overloading means defining multiple functions with the same name and different parameter lists.

Calling means selecting and executing one of those functions.

---

## 17. Function Overloading vs Normal Functions

| Normal Functions                                | Function Overloading                               |
| ----------------------------------------------- | -------------------------------------------------- |
| Usually use different names for different tasks | Multiple functions use the same name               |
| Each function has its own name                  | Same name with different parameter lists           |
| Example: `add()` and `multiply()`               | Example: `add(int, int)` and `add(double, double)` |
| No overload selection is needed                 | Compiler selects a suitable overload               |

---

## 18. Key Points

* **Function overloading** means having multiple functions with the same name but different parameter lists.
* Functions can be overloaded by changing the **number of parameters**.
* Functions can be overloaded by changing the **parameter types**.
* The order of parameter types can also make parameter lists different.
* Return type alone cannot be used for function overloading.
* Parameter names alone do not create different overloads.
* The compiler selects the appropriate overloaded function during compile time.
* Function overloading is an example of **compile-time polymorphism**.
* Overloading makes related operations easier to organize and understand.
