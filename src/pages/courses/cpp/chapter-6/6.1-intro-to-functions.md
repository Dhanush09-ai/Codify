# Chapter 6: Functions

## Section 1: Introduction to Functions

A **function** is a reusable block of code that performs a specific task.

Instead of writing the same code again and again, we can put it inside a function and call the function whenever we need it.

Functions make programs:

* Easier to understand
* Easier to reuse
* Easier to test
* Easier to maintain
* More organized

---

## 1. What is a Function?

A function is a named block of statements that performs a particular task.

For example, suppose we want to print a welcome message several times.

Instead of writing:

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Welcome to Codify!" << endl;
    cout << "Welcome to Codify!" << endl;
    cout << "Welcome to Codify!" << endl;

    return 0;
}
```

We can create a function:

```cpp
#include <iostream>
using namespace std;

void welcome() {
    cout << "Welcome to Codify!" << endl;
}

int main() {
    welcome();
    welcome();
    welcome();

    return 0;
}
```


```output
Welcome to Codify!
Welcome to Codify!
Welcome to Codify!
```

The function `welcome()` contains the code for printing the message.

We can call it whenever we need it.

---

## 2. Why Do We Use Functions?

Functions are useful when a program contains tasks that need to be performed multiple times.

For example, a program may need separate tasks for:

* Calculating a sum
* Finding an average
* Checking a number
* Printing a message
* Calculating an area

Each task can be placed inside its own function.

This makes the program easier to manage.

---

## 3. Basic Structure of a Function

A simple function has this structure:

```cpp
return_type function_name() {
    // statements
}
```

For example:

```cpp
void greet() {
    cout << "Hello!" << endl;
}
```

Here:

* `void` → return type
* `greet` → function name
* `()` → parameter list
* `{ }` → function body
* `cout` → statement inside the function

---

## 4. The `void` Return Type

The keyword `void` means that the function does not return a value.

Example:

```cpp
void message() {
    cout << "Hello from C++!" << endl;
}
```

This function performs an action but does not send a value back to the place where it was called.

---

## 5. Calling a Function

Creating a function does not automatically execute it.

We must **call** the function.

Example:

```cpp
#include <iostream>
using namespace std;

void message() {
    cout << "Learning C++ is fun!" << endl;
}

int main() {
    message();

    return 0;
}
```


```output
Learning C++ is fun!
```

The statement:

```cpp
message();
```

calls the function.

When the function is called, the statements inside its body are executed.

---

## 6. Calling a Function Multiple Times

A function can be called more than once.

```cpp
#include <iostream>
using namespace std;

void hello() {
    cout << "Hello!" << endl;
}

int main() {
    hello();
    hello();
    hello();

    return 0;
}
```


```output
Hello!
Hello!
Hello!
```

The same function is reused three times.

---

## 7. Function with Multiple Statements

A function can contain multiple statements.

```cpp
#include <iostream>
using namespace std;

void studentInfo() {
    cout << "Name: Owais" << endl;
    cout << "Course: C++" << endl;
    cout << "Level: Beginner" << endl;
}

int main() {
    studentInfo();

    return 0;
}
```


```output
Name: Owais
Course: C++
Level: Beginner
```

All statements inside the function execute when the function is called.

---

## 8. Functions Help Organize a Program

Without functions, a large program can become difficult to understand.

For example:

```text
Main Program
   ↓
Input
   ↓
Calculation
   ↓
Checking
   ↓
Output
```

We can divide these tasks into separate functions:

```text
main()
 ├── getInput()
 ├── calculate()
 ├── checkResult()
 └── displayResult()
```

Each function handles a particular task.

This approach is called **modular programming**.

---

## 9. A Function for a Specific Task

A good function usually performs one clear task.

For example:

```cpp
#include <iostream>
using namespace std;

void printLine() {
    cout << "----------------" << endl;
}

int main() {
    printLine();
    cout << "C++ Functions" << endl;
    printLine();

    return 0;
}
```


```output
----------------
C++ Functions
----------------
```

The `printLine()` function has one simple responsibility: printing a line.

---

## 10. Functions and Reusability

One of the biggest advantages of functions is **code reuse**.

Suppose we need to print a line at several places in a program.

Instead of writing:

```cpp
cout << "----------------" << endl;
```

again and again, we can write:

```cpp
void printLine() {
    cout << "----------------" << endl;
}
```

Then use:

```cpp
printLine();
```

whenever required.

---

## 11. Function Execution Flow

Consider this program:

```cpp
#include <iostream>
using namespace std;

void showMessage() {
    cout << "Inside the function" << endl;
}

int main() {
    cout << "Before function" << endl;

    showMessage();

    cout << "After function" << endl;

    return 0;
}
```


```output
Before function
Inside the function
After function
```

The execution flow is:

1. `main()` starts.
2. `"Before function"` is printed.
3. `showMessage()` is called.
4. The function body executes.
5. Control returns to `main()`.
6. `"After function"` is printed.

---

## 12. Functions Can Be Called from Other Functions

One function can call another function.

Example:

```cpp
#include <iostream>
using namespace std;

void second() {
    cout << "Second function" << endl;
}

void first() {
    cout << "First function" << endl;
    second();
}

int main() {
    first();

    return 0;
}
```


```output
First function
Second function
```

Here:

* `main()` calls `first()`.
* `first()` calls `second()`.
* `second()` finishes.
* Control returns to `first()`.
* Then control returns to `main()`.

---

## 13. Function Naming

Function names should clearly describe what the function does.

Good examples:

```cpp
calculateSum()
printMessage()
findMaximum()
displayResult()
checkNumber()
```

Avoid unclear names such as:

```cpp
abc()
x()
fun1()
```

Meaningful names make programs easier to understand.

---

## 14. `main()` is Also a Function

In C++, the program starts execution from the `main()` function.

Example:

```cpp
int main() {
    cout << "Program starts here";
    return 0;
}
```

`main()` is a special function because it is the entry point of a C++ program.

Other functions can be called from `main()`.

For example:

```cpp
#include <iostream>
using namespace std;

void startProgram() {
    cout << "Program started!" << endl;
}

int main() {
    startProgram();

    return 0;
}
```


```output
Program started!
```

---

## 15. Functions Without Parameters

A function can be created without parameters.

Example:

```cpp
void showNumber() {
    cout << 100 << endl;
}
```

It can be called using:

```cpp
showNumber();
```

No information is passed to the function.

Parameters and return values will be covered in later topics.

Student Management Program

## 17. Real-World Example 🌍

Think about a calculator.

A calculator performs different tasks:

* Addition
* Subtraction
* Multiplication
* Division

Each task can be represented by a function.

For example:

```cpp
#include <iostream>
using namespace std;

void showAddition() {
    int a = 10;
    int b = 5;

    cout << "Sum = " << a + b << endl;
}

void showMultiplication() {
    int a = 10;
    int b = 5;

    cout << "Product = " << a * b << endl;
}

int main() {
    showAddition();
    showMultiplication();

    return 0;
}
```


```output
Sum = 15
Product = 50
```

Each function handles a different task.

## 18. Common Mistakes

### 1. Defining a function but never calling it

Creating:

```cpp
void hello() {
    cout << "Hello";
}
```

does not execute it automatically.

We need:

```cpp
hello();
```

### 2. Forgetting parentheses when calling a function

Correct:

```cpp
hello();
```

Incorrect:

```cpp
hello;
```

### 3. Using the wrong function name

If the function is:

```cpp
void display() {
    cout << "Hello";
}
```

the call must use the same name:

```cpp
display();
```

### 4. Forgetting braces

A function body must be enclosed in `{ }`.

Correct:

```cpp
void hello() {
    cout << "Hello";
}
```

### 5. Trying to return a value from a `void` function

A `void` function is designed not to return a value.

* A function can be called whenever its task is required.

* Creating a function does not execute it automatically.

* A function can be called multiple times.
* One function can call another function.
* `main()` is the starting point of a C++ program.

* Functions support code reuse and modular programming.
