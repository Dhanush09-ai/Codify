# Chapter 6: Functions

## Section 3: Parameters & Return Values

Functions become more useful when we can **send data to them** and **receive a result back**.

Two important concepts are:

* **Parameters** — allow a function to receive data.
* **Return values** — allow a function to send a result back.

---

## 1. What are Parameters?

A **parameter** is a variable listed in a function definition that receives a value when the function is called.

Example:

```cpp
void greet(string name) {
    cout << "Hello, " << name << "!" << endl;
}
```

Here, `name` is a parameter.

We can call the function like this:

```cpp
greet("Owais");
```

The value `"Owais"` is passed to the parameter `name`.

---

## 2. Parameter and Argument

The terms **parameter** and **argument** are related but different.

Consider:

```cpp
void display(int number) {
    cout << number << endl;
}

display(25);
```

Here:

* `number` → **parameter**
* `25` → **argument**

The parameter is the variable that receives the value.

The argument is the actual value passed during the function call.

---

## 3. Function with One Parameter

A function can have one parameter.

```cpp
#include <iostream>
using namespace std;

void square(int number) {
    cout << "Square = " << number * number << endl;
}

int main() {
    square(5);

    return 0;
}
```


```output
Square = 25
```

The value `5` is passed to `number`.

The function then calculates:

```text
5 × 5 = 25
```

---

## 4. Function with Multiple Parameters

A function can have multiple parameters.

Example:

```cpp
#include <iostream>
using namespace std;

void add(int a, int b) {
    cout << "Sum = " << a + b << endl;
}

int main() {
    add(10, 20);

    return 0;
}
```


```output
Sum = 30
```

Here:

* `a` receives `10`.
* `b` receives `20`.

The function calculates `10 + 20`.

---

## 5. Order of Arguments

Arguments are assigned to parameters according to their position.

Consider:

```cpp
void display(int a, int b) {
    cout << a << " " << b << endl;
}
```

Calling:

```cpp
display(10, 20);
```

means:

```text
a = 10
b = 20
```

Calling:

```cpp
display(20, 10);
```

means:

```text
a = 20
b = 10
```

Therefore, the order of arguments can matter.

## - [ Different Parameter Types

Parameters can have different data types.

Example:

```cpp
#include <iostream>
using namespace std;

void student(string name, int age) {
    cout << "Name: " << name << endl;
    cout << "Age: " << age << endl;
}

int main() {
    student("Owais", 16);

    return 0;
}
```


```output
Name: Owais
Age: 16
```

The function has:

* `string name`
* `int age`

The arguments are:

* `"Owais"`
* `16`

## 7. Function with Three Parameters

There is no requirement that a function must have only one or two parameters.

Example:

```cpp
#include <iostream>
using namespace std;

void displayDetails(string name, int age, double marks) {
    cout << "Name: " << name << endl;
    cout << "Age: " << age << endl;
    cout << "Marks: " << marks << endl;
}

int main() {
    displayDetails("Owais", 16, 95.5);

    return 0;
}
```


```output
Name: Owais
Age: 16
Marks: 95.5
```

Each argument is passed to the corresponding parameter.

---

## 8. What is a Return Value?

A **return value** is a value sent back from a function to the code that called it.

For example:

```cpp
int add(int a, int b) {
    return a + b;
}
```

The function returns the result of `a + b`.

We can store the returned value:

```cpp
int result = add(10, 20);
```

Now `result` contains `30`.

---

## 9. Using `return`

The `return` statement sends a value back to the caller.

Example:

```cpp
#include <iostream>
using namespace std;

int square(int number) {
    return number * number;
}

int main() {
    int result = square(6);

    cout << "Square = " << result << endl;

    return 0;
}
```


```output
Square = 36
```

The flow is:

```text
square(6)
   ↓
6 × 6
   ↓
36
   ↓
result
```

---

## 10. Return Type

The return type tells us what type of value a function returns.

For example:

```cpp
int add(int a, int b)
```

The return type is `int`.

A function returning a decimal value can use `double`:

```cpp
double calculateAverage(double a, double b) {
    return (a + b) / 2;
}
```

A function that does not return a value can use:

```cpp
void display() {
    cout << "Hello";
}
```

---

## 11. Returning an Integer

Example:

```cpp
#include <iostream>
using namespace std;

int multiply(int a, int b) {
    return a * b;
}

int main() {
    int result = multiply(4, 5);

    cout << "Product = " << result << endl;

    return 0;
}
```


```output
Product = 20
```

The function returns an `int` value.

---

## 12. Returning a Double

A function can return a `double`.

```cpp
#include <iostream>
using namespace std;

double calculateArea(double length, double width) {
    return length * width;
}

int main() {
    double area = calculateArea(5.5, 4.0);

    cout << "Area = " << area << endl;

    return 0;
}
```


```output
Area = 22
```

The function returns a `double` value.

---

## 13. Returning a Boolean Value

A function can also return `bool`.

Example:

```cpp
#include <iostream>
using namespace std;

bool isEven(int number) {
    return number % 2 == 0;
}

int main() {
    bool result = isEven(10);

    cout << result << endl;

    return 0;
}
```


```output
1
```

By default, `cout` displays `true` as `1` and `false` as `0`.

We can also use `boolalpha`:

```cpp
#include <iostream>
using namespace std;

bool isEven(int number) {
    return number % 2 == 0;
}

int main() {
    cout << boolalpha;
    cout << isEven(10) << endl;

    return 0;
}
```


```output
true
```

---

## 14. Returning a Value Directly

A returned value can be used directly without storing it in a variable.

Example:

```cpp
#include <iostream>
using namespace std;

int add(int a, int b) {
    return a + b;
}

int main() {
    cout << add(10, 15) << endl;

    return 0;
}
```


```output
25
```

The returned value from `add()` is directly given to `cout`.

---

## 15. Using a Returned Value in an Expression

A function's return value can also be used in another calculation.

```cpp
#include <iostream>
using namespace std;

int square(int number) {
    return number * number;
}

int main() {
    int result = square(5) + square(3);

    cout << result << endl;

    return 0;
}
```


```output
34
```

Because:

```text
square(5) = 25
square(3) = 9

25 + 9 = 34
```

---

## 1- [ Multiple Return Statements

A function can contain more than one `return` statement.

However, only the return statement reached during execution is used.

Example:

```cpp
#include <iostream>
using namespace std;

int checkNumber(int number) {
    if (number > 0) {
        return 1;
    }

    return 0;
}

int main() {
    cout << checkNumber(10) << endl;

    return 0;
}
```


```output
1
```

If `number` is greater than `0`, the function returns `1`.

Otherwise, it returns `0`.

---

## 17. Function with Parameters and No Return Value

A function can receive parameters without returning a value.

Example:

```cpp
#include <iostream>
using namespace std;

void printSum(int a, int b) {
    cout << "Sum = " << a + b << endl;
}

int main() {
    printSum(10, 20);

    return 0;
}
```


```output
Sum = 30
```

The function performs the calculation and prints the result directly.

---

## 18. Function with Parameters and a Return Value

A function can both receive parameters and return a value.

This is one of the most common ways to use functions.

```cpp
#include <iostream>
using namespace std;

int findMaximum(int a, int b) {
    if (a > b) {
        return a;
    }

    return b;
}

int main() {
    int result = findMaximum(25, 40);

    cout << "Maximum = " << result << endl;

    return 0;
}
```


```output
Maximum = 40
```

Here:

* `a` and `b` are parameters.
* `25` and `40` are arguments.
* `int` is the return type.
* `40` is the returned value.

---

## 19. Passing Variables to Functions

We can pass variables as arguments.

```cpp
#include <iostream>
using namespace std;

int add(int a, int b) {
    return a + b;
}

int main() {
    int x = 10;
    int y = 20;

    int result = add(x, y);

    cout << "Sum = " << result << endl;

    return 0;
}
```


```output
Sum = 30
```

Here:

* `x` is passed to `a`.
* `y` is passed to `b`.

---

## 20. Parameters Receive Copies

For ordinary value parameters, the function receives its own copy of the argument.

Example:

```cpp
#include <iostream>
using namespace std;

void change(int number) {
    number = 100;
}

int main() {
    int x = 10;

    change(x);

    cout << x << endl;

    return 0;
}
```


```output
10
```

Changing `number` inside the function does not change `x` in `main()`.

References, which allow a function to work with the original variable, will be covered later.

## 21. Real-World Example 🌍

Imagine an online shopping application.

The program may need to calculate the total price of an item.

We can create a function:

```cpp
#include <iostream>
using namespace std;

double calculateTotal(double price, int quantity) {
    return price * quantity;
}

int main() {
    double total = calculateTotal(250.50, 3);

    cout << "Total = " << total << endl;

    return 0;
}
```


```output
Total = 751.5
```

The function:

* Receives the price.
* Receives the quantity.
* Calculates the total.
* Returns the result.

This makes the calculation reusable.

## 22. Common Mistakes

### 1. Forgetting to return a value

If a function has a non-`void` return type, make sure it returns an appropriate value on every required execution path.

### 2. Using the wrong number of arguments

If a function expects:

```cpp
int add(int a, int b)
```

it requires two arguments.

Correct:

```cpp
add(10, 20);
```

### 3. Mixing up parameters and arguments

Remember:

```text
Parameter → variable in the function
Argument  → value passed during the call
```

### 4. Using the wrong return type

If a function returns an integer, its return type should be compatible with `int`.

Example:

```cpp
int add(int a, int b) {
    return a + b;
}
```

### 5. Expecting a normal value parameter to change the original variable

Changing a value parameter changes only the function's local copy.

---

## 23. Key Points

* **Parameters** allow functions to receive data.
* **Arguments** are the actual values passed to parameters.
* Arguments are matched to parameters by position.
* A function can have one or multiple parameters.
* A **return value** sends a result back to the caller.
* The return type specifies the type of value returned.
* `return` is used to send a value back.
* A function can return `int`, `double`, `bool`, and other types.
* A `void` function does not return a value.
* Returned values can be stored in variables or used directly in expressions.
* Normal value parameters receive copies of arguments.
