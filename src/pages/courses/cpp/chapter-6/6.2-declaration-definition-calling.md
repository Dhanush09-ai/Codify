# Chapter 6: Functions

## Section 2: Function Declaration, Definition & Calling

In C++, a function usually involves three important steps:

1. **Function Declaration**
2. **Function Definition**
3. **Function Calling**

Understanding these three steps helps us create and use functions correctly.

---

## 1. Function Declaration

A **function declaration** tells the compiler about a function before the function is used.

It tells the compiler:

* Function name
* Return type
* Parameters, if any

A function declaration is also called a **function prototype**.

### Syntax

```cpp
return_type function_name(parameters);
```

For example:

```cpp
void greet();
```

This tells the compiler that a function named `greet` exists and does not return a value.

---

## 2. Function Definition

A **function definition** contains the actual code that the function performs.

### Syntax

```cpp
return_type function_name(parameters) {
    // function body
}
```

Example:

```cpp
void greet() {
    cout << "Hello!" << endl;
}
```

Here, the function body contains the statement that prints `"Hello!"`.

---

## 3. Function Calling

A **function call** tells the program to execute the function.

For a function named `greet`, we call it using:

```cpp
greet();
```

When the function is called, control moves to the function body.

---

## 4. Declaration, Definition and Calling Together

Let's look at all three steps together.

```cpp
#include <iostream>
using namespace std;

// Function declaration
void greet();

// Function definition
void greet() {
    cout << "Hello, C++!" << endl;
}

int main() {
    // Function calling
    greet();

    return 0;
}
```


```output
Hello, C++!
```

The flow is:

```text
Declaration
     ↓
Definition
     ↓
Function Call
     ↓
Function Executes
```

---

## 5. Why Do We Need a Function Declaration?

Consider this program:

```cpp
#include <iostream>
using namespace std;

int main() {
    greet();

    return 0;
}

void greet() {
    cout << "Hello!" << endl;
}
```

Here, `greet()` is called before the compiler has seen its definition.

The compiler may not know about `greet()` at the point where it is called.

A function declaration solves this problem.

```cpp
#include <iostream>
using namespace std;

void greet();

int main() {
    greet();

    return 0;
}

void greet() {
    cout << "Hello!" << endl;
}
```


```output
Hello!
```

The declaration tells the compiler about the function before `main()` calls it.

---

## 6. Function Prototype

A function declaration is commonly called a **function prototype**.

For example:

```cpp
int add(int a, int b);
```

This tells the compiler:

* Return type → `int`
* Function name → `add`
* Number of parameters → `2`
* Parameter types → `int`, `int`

The actual function can then be defined later.

```cpp
int add(int a, int b) {
    return a + b;
}
```

---

## 7. Function Declaration with Parameters

A function declaration can contain parameters.

Example:

```cpp
void display(int number);
```

This means:

* Function name → `display`
* Return type → `void`
* Parameter → one `int`

The definition can be:

```cpp
void display(int number) {
    cout << number << endl;
}
```

And the function can be called as:

```cpp
display(10);
```

### Complete Example

```cpp
#include <iostream>
using namespace std;

void display(int number);

void display(int number) {
    cout << "Number = " << number << endl;
}

int main() {
    display(10);

    return 0;
}
```


```output
Number = 10
```

---

## 8. Declaration Must Match the Definition

The function declaration and definition should have matching return type, function name, and parameter types.

Correct:

```cpp
int add(int a, int b);

int add(int a, int b) {
    return a + b;
}
```

The declaration and definition describe the same function.

---

## 9. Calling a Function with Arguments

If a function has parameters, values can be passed when calling it.

Example:

```cpp
#include <iostream>
using namespace std;

void showNumber(int number);

void showNumber(int number) {
    cout << "Number = " << number << endl;
}

int main() {
    showNumber(25);

    return 0;
}
```


```output
Number = 25
```

Here:

* `number` is the parameter.
* `25` is the argument passed to the function.

---

## 10. Function with a Return Value

A function can return a value to the calling code.

Example:

```cpp
#include <iostream>
using namespace std;

int add(int a, int b);

int add(int a, int b) {
    return a + b;
}

int main() {
    int result = add(10, 20);

    cout << "Sum = " << result << endl;

    return 0;
}
```


```output
Sum = 30
```

The flow is:

```text
add(10, 20)
     ↓
10 + 20
     ↓
30
     ↓
result
```

---

## 11. Declaration Before `main()`

A common style is to place function declarations before `main()` and function definitions after `main()`.

Example:

```cpp
#include <iostream>
using namespace std;

int add(int a, int b);

int main() {
    int result = add(5, 7);

    cout << result << endl;

    return 0;
}

int add(int a, int b) {
    return a + b;
}
```


```output
12
```

This style can make the `main()` function easier to find and read.

---

## 12. Definition Before `main()`

A function can also be completely defined before `main()`.

In that case, a separate declaration is not needed before `main()` because the compiler has already seen the function definition.

```cpp
#include <iostream>
using namespace std;

int add(int a, int b) {
    return a + b;
}

int main() {
    cout << add(10, 15) << endl;

    return 0;
}
```


```output
25
```

Here, the definition itself introduces the function before it is called.

---

## 13. Multiple Function Declarations

A program can have declarations for several functions.

```cpp
#include <iostream>
using namespace std;

void first();
void second();

void first() {
    cout << "First function" << endl;
}

void second() {
    cout << "Second function" << endl;
}

int main() {
    first();
    second();

    return 0;
}
```


```output
First function
Second function
```

Each function has its own declaration and definition.

---

## 14. Function Declaration with Different Return Types

Functions can have different return types.

For example:

```cpp
int getNumber();
double getPrice();
void display();
```

These declarations tell the compiler what each function returns.

Example:

```cpp
#include <iostream>
using namespace std;

int getNumber();
double getPrice();
void display();

int getNumber() {
    return 10;
}

double getPrice() {
    return 99.50;
}

void display() {
    cout << "C++ Functions" << endl;
}

int main() {
    cout << getNumber() << endl;
    cout << getPrice() << endl;
    display();

    return 0;
}
```


```output
10
99.5
C++ Functions
```

---

## 15. Function Declaration and Parameters

The parameter types are important in a function declaration.

For example:

```cpp
int multiply(int a, int b);
```

This tells the compiler that `multiply()` expects two `int` parameters.

We can call it like:

```cpp
multiply(4, 5);
```

But a call such as:

```cpp
multiply(4);
```

does not provide the required number of arguments for this function.

---

## 16. Function Calling Flow

Consider:

```cpp
#include <iostream>
using namespace std;

void message();

int main() {
    cout << "Start" << endl;

    message();

    cout << "End" << endl;

    return 0;
}

void message() {
    cout << "Inside function" << endl;
}
```


```output
Start
Inside function
End
```

The execution flow is:

1. `main()` starts.
2. `"Start"` is printed.
3. `message()` is called.
4. Control moves to `message()`.
5. `"Inside function"` is printed.
6. Control returns to `main()`.
7. `"End"` is printed.

---

## 17. Declaration vs Definition vs Calling

| Part        | Purpose                               | Example                                   |
| ----------- | ------------------------------------- | ----------------------------------------- |
| Declaration | Tells the compiler about the function | `int add(int, int);`                      |
| Definition  | Contains the function's actual code   | `int add(int a, int b) { return a + b; }` |
| Calling     | Executes the function                 | `add(5, 10);`                             |

Remember:

**Declaration → tells**

**Definition → implements**

**Calling → executes**

## 18. Real-World Example 🌍

Imagine a calculator application.

We can declare functions for different operations:

```cpp
int add(int a, int b);
int subtract(int a, int b);
```

Then define them:

```cpp
int add(int a, int b) {
    return a + b;
}

int subtract(int a, int b) {
    return a - b;
}
```

Then call them:

```cpp
int sum = add(20, 5);
int difference = subtract(20, 5);
```

A complete program looks like this:

```cpp
#include <iostream>
using namespace std;

int add(int a, int b);
int subtract(int a, int b);

int add(int a, int b) {
    return a + b;
}

int subtract(int a, int b) {
    return a - b;
}

int main() {
    cout << "Sum = " << add(20, 5) << endl;
    cout << "Difference = " << subtract(20, 5) << endl;

    return 0;
}
```


```output
Sum = 25
Difference = 15
```

The program is easier to organize because each operation has its own function.

## 19. Common Mistakes

### 1. Forgetting the semicolon in a declaration

Correct:

```cpp
int add(int a, int b);
```

Incorrect:

```cpp
int add(int a, int b)
```

A function declaration ends with a semicolon.

### 2. Calling a function with the wrong number of arguments

If the function is:

```cpp
int add(int a, int b);
```

it requires two arguments.

Correct:

```cpp
add(10, 20);
```

### 3. Mismatching declaration and definition

Make sure the function name, return type, and parameter types are compatible.

### 4. Forgetting to define a declared function

Declaring:

```cpp
void greet();
```

does not provide the function's implementation.

A definition is still needed if the function is called.

### 5. Confusing declaration with calling

This:

```cpp
void greet();
```

is a declaration.

This:

```cpp
greet();
```

is a function call.

---

## 20. Key Points

* A **function declaration** tells the compiler about a function.
* A function declaration is also called a **function prototype**.
* A **function definition** contains the actual statements of the function.
* A **function call** executes the function.
* A declaration ends with a semicolon.
* A function can be declared before `main()` and defined later.
* A function can also be defined before `main()`.
* Parameters can be included in declarations and definitions.
* Arguments are supplied when calling functions.
* The declaration and definition should describe the same function.
* A function can return a value to the calling code.
