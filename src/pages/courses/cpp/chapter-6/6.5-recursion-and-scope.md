# Chapter 6: Functions

## Section 5: Recursion & Scope

In this section, we will learn two important function concepts:

* **Recursion** — when a function calls itself.
* **Scope** — where a variable can be accessed in a program.

Understanding these concepts helps us write better and more organized C++ programs.

---

## 1. What is Recursion?

**Recursion** is a technique where a function calls itself to solve a problem.

A recursive function normally has two important parts:

1. **Base case** — stops the recursion.
2. **Recursive case** — calls the function again.

### Basic Structure

```cpp
return_type function() {
    if (condition) {
        return result;
    }

    return function();
}
```

Without a base case, a recursive function can continue calling itself indefinitely.

---

## 2. Simple Recursive Function

Let's create a function that prints numbers from `1` to `5`.

```cpp
#include <iostream>
using namespace std;

void printNumbers(int n) {
    if (n > 5) {
        return;
    }

    cout << n << " ";
    printNumbers(n + 1);
}

int main() {
    printNumbers(1);

    return 0;
}
```


```output
1 2 3 4 5
```

The function keeps calling itself with the next number.

---

## 3. How Recursion Works

Consider:

```cpp
void count(int n) {
    if (n == 0) {
        return;
    }

    cout << n << " ";
    count(n - 1);
}
```

If we call:

```cpp
count(3);
```

the calls happen like this:

```text
count(3)
   ↓
count(2)
   ↓
count(1)
   ↓
count(0)
   ↓
Stop
```

The condition:

```cpp
if (n == 0)
```

is the **base case**.

It stops further recursive calls.

---

## 4. Base Case

The **base case** is the condition that stops a recursive function.

Example:

```cpp
void countDown(int n) {
    if (n == 0) {
        return;
    }

    cout << n << " ";
    countDown(n - 1);
}
```

Here:

```cpp
if (n == 0)
```

is the base case.

Without it, the function would keep calling itself.

---

## 5. Recursive Case

The part where a function calls itself is called the **recursive case**.

In:

```cpp
void countDown(int n) {
    if (n == 0) {
        return;
    }

    cout << n << " ";
    countDown(n - 1);
}
```

this statement is the recursive case:

```cpp
countDown(n - 1);
```

The value of `n` becomes smaller with every call.

---

## 6. Factorial Using Recursion

Factorial is a common example of recursion.

The factorial of `n` is:

```text
n! = n × (n - 1) × (n - 2) × ... × 1
```

For example:

```text
5! = 5 × 4 × 3 × 2 × 1
   = 120
```

We can calculate it using recursion.

```cpp
#include <iostream>
using namespace std;

int factorial(int n) {
    if (n == 0 || n == 1) {
        return 1;
    }

    return n * factorial(n - 1);
}

int main() {
    cout << factorial(5) << endl;

    return 0;
}
```


```output
120
```

The recursive calls are:

```text
factorial(5)
    ↓
factorial(4)
    ↓
factorial(3)
    ↓
factorial(2)
    ↓
factorial(1)
    ↓
1
```

Then the results are combined while returning from the calls.

---

## 7. Fibonacci Using Recursion

The Fibonacci sequence begins with:

```text
0 1 1 2 3 5 8 13 ...
```

A recursive Fibonacci function can be written as:

```cpp
#include <iostream>
using namespace std;

int fibonacci(int n) {
    if (n <= 1) {
        return n;
    }

    return fibonacci(n - 1) + fibonacci(n - 2);
}

int main() {
    cout << fibonacci(6) << endl;

    return 0;
}
```


```output
8
```

Here:

```text
fibonacci(6)
= fibonacci(5) + fibonacci(4)
```

The function continues breaking the problem into smaller problems until it reaches the base case.

---

## 8. Recursion vs Loop

Many problems that use recursion can also be solved using loops.

For example, printing numbers from `1` to `5` using a loop:

```cpp
for (int i = 1; i <= 5; i++) {
    cout << i << " ";
}
```

The same task using recursion:

```cpp
void printNumbers(int n) {
    if (n > 5) {
        return;
    }

    cout << n << " ";
    printNumbers(n + 1);
}
```

Both can produce:

```output
1 2 3 4 5
```

Recursion is especially useful when a problem naturally breaks into smaller versions of itself.

---

## 9. Common Recursion Mistakes

### 1. Forgetting the Base Case

A recursive function needs a stopping condition.

### 2. Never Reaching the Base Case

The recursive call should move toward the base case.

For example:

```cpp
count(n - 1);
```

moves toward `0`.

### 3. Using the Wrong Recursive Call

If the recursive call does not change the problem toward the base case, the function may not stop.

### 4. Creating Too Many Recursive Calls

Some recursive solutions can perform a large number of calls and use more memory than a simple loop.

# Scope of Variables

## 10. What is Scope?

**Scope** is the part of a program where a variable can be accessed.

For example, a variable declared inside a function is normally accessible only inside that function.

```cpp
void test() {
    int number = 10;

    cout << number << endl;
}
```

The variable `number` belongs to the scope of `test()`.

---

## 11. Local Variables

A variable declared inside a function or block is called a **local variable**.

Example:

```cpp
#include <iostream>
using namespace std;

void display() {
    int number = 10;

    cout << number << endl;
}

int main() {
    display();

    return 0;
}
```


```output
10
```

The variable `number` exists within the scope of `display()`.

It cannot be directly accessed from `main()`.

---

## 12. Variables Inside Blocks

Variables can also be declared inside a block created using `{ }`.

```cpp
#include <iostream>
using namespace std;

int main() {
    if (true) {
        int number = 50;
        cout << number << endl;
    }

    return 0;
}
```


```output
50
```

The variable `number` is available inside that block.

It is not available outside the block.

---

## 13. Scope of a `for` Loop Variable

A variable declared in a `for` loop is normally available only within the loop.

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 3; i++) {
        cout << i << " ";
    }

    return 0;
}
```


```output
1 2 3
```

The variable `i` belongs to the scope of the `for` statement.

It cannot be used after the loop:

```cpp
cout << i;
```

because `i` is no longer in scope.

---

## 14. Global Variables

A variable declared outside all functions has **global scope**.

Example:

```cpp
#include <iostream>
using namespace std;

int number = 100;

void display() {
    cout << number << endl;
}

int main() {
    cout << number << endl;
    display();

    return 0;
}
```


```output
100
100
```

The global variable `number` can be accessed by functions in its scope, subject to normal C++ name lookup rules.

---

## 15. Local and Global Variables

A local variable and a global variable can have the same name.

Example:

```cpp
#include <iostream>
using namespace std;

int number = 100;

int main() {
    int number = 50;

    cout << number << endl;

    return 0;
}
```


```output
50
```

The local variable takes precedence within its scope.

This is called **name hiding** or **shadowing**.

---

## 16. Block Scope

A variable declared inside a pair of braces has block scope.

```cpp
#include <iostream>
using namespace std;

int main() {
    int x = 10;

    {
        int y = 20;

        cout << x << endl;
        cout << y << endl;
    }

    return 0;
}
```


```output
10
20
```

The variable `x` can be accessed inside the inner block because it was declared in an outer scope.

The variable `y` can only be accessed inside its own block.

---

## 17. Nested Block Scope

Blocks can be placed inside other blocks.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 10;

    {
        int b = 20;

        {
            int c = 30;

            cout << a << " ";
            cout << b << " ";
            cout << c << endl;
        }
    }

    return 0;
}
```


```output
10 20 30
```

An inner block can generally access variables declared in its outer scopes.

---

## 18. Function Scope and Block Scope

Consider:

```cpp
void test() {
    int a = 10;

    if (a > 5) {
        int b = 20;

        cout << a << endl;
        cout << b << endl;
    }
}
```

Here:

* `a` is available throughout the function block where it is declared.
* `b` is available only inside the `if` block.

The scope of a variable depends on where it is declared.

---

## 19. Scope and Functions

Each function has its own local variables.

```cpp
#include <iostream>
using namespace std;

void first() {
    int number = 10;
    cout << number << endl;
}

void second() {
    int number = 20;
    cout << number << endl;
}

int main() {
    first();
    second();

    return 0;
}
```


```output
10
20
```

The two `number` variables are separate local variables because they belong to different function scopes.

---

## 20. Real-World Example 🌍

Imagine a school management program.

A student's name may be needed only while processing one particular function.

```cpp
#include <iostream>
#include <string>
using namespace std;

void displayStudent() {
    string name = "Owais";

    cout << "Student: " << name << endl;
}

int main() {
    displayStudent();

    return 0;
}
```


```output
Student: Owais
```

The `name` variable is local to `displayStudent()`.

Keeping variables within the smallest useful scope helps prevent accidental access or modification from unrelated parts of a program.

---

## 21. Recursion and Scope Together

Recursive function calls create separate function-call contexts.

For example:

```cpp
#include <iostream>
using namespace std;

void count(int n) {
    if (n == 0) {
        return;
    }

    cout << n << " ";
    count(n - 1);
}

int main() {
    count(3);

    return 0;
}
```


```output
3 2 1
```

Each call has its own parameter value for `n`.

The calls are:

```text
count(3)
count(2)
count(1)
count(0)
```

Each invocation has its own function-call state.

---

## 22. Common Scope Mistakes

### 1. Using a local variable outside its scope

```cpp
void test() {
    int number = 10;
}

int main() {
    cout << number;
}
```

This is invalid because `number` is local to `test()`.

### 2. Confusing similarly named variables

Variables with the same name can exist in different scopes.

Always check which variable is currently visible.

### 3. Declaring variables in unnecessarily large scopes

A variable should generally be declared where it is needed.

This makes code easier to understand and reduces accidental use.

---

## 23. Recursion vs Scope

Recursion and scope are different concepts.

| Recursion                                  | Scope                                          |
| ------------------------------------------ | ---------------------------------------------- |
| A function calls itself                    | Defines where a variable can be accessed       |
| Used to solve certain problems             | Used to control variable visibility            |
| Requires a stopping condition              | Depends on where a variable is declared        |
| Common in factorial and tree-like problems | Common with local, block, and global variables |

---

## 24. Key Points

* **Recursion** occurs when a function calls itself.
* A recursive function needs a **base case**.
* The recursive case moves the problem toward the base case.
* Factorial is a common example of recursion.
* Fibonacci can also be implemented recursively.
* Many recursive problems can also be solved using loops.
* **Scope** determines where a variable can be accessed.
* Variables declared inside functions are normally local to those functions.
* Variables declared inside blocks have block scope.
* Variables declared outside functions can have global scope.
* An inner scope can generally access names from its outer scopes.
* A local variable can hide a variable with the same name from an outer scope.
* Each recursive function call has its own call context.
