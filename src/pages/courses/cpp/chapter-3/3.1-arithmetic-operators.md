# Chapter 3: Operators

## Section 1: Arithmetic Operators

Arithmetic operators are used to perform mathematical calculations in C++.

They can be used with numbers and variables to perform operations such as addition, subtraction, multiplication, division, and finding the remainder.

---

## 1. What are Arithmetic Operators?

Arithmetic operators are symbols used to perform mathematical operations.

C++ provides these basic arithmetic operators:

| Operator | Name           | Example  | Result |
| -------- | -------------- | -------- | ------ |
| `+`      | Addition       | `10 + 5` | `15`   |
| `-`      | Subtraction    | `10 - 5` | `5`    |
| `*`      | Multiplication | `10 * 5` | `50`   |
| `/`      | Division       | `10 / 5` | `2`    |
| `%`      | Modulus        | `10 % 3` | `1`    |

These operators can be used with variables as well as direct values.

---

## 2. Addition Operator `+`

The `+` operator adds two values.

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 10;
    int b = 20;

    int result = a + b;

    cout << result;

    return 0;
}
```

```output
30
```

You can also add values directly:

```cpp
int result = 15 + 25;
```

The value of `result` is `40`.

---

## 3. Subtraction Operator `-`

The `-` operator subtracts one value from another.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 30;
    int b = 10;

    int result = a - b;

    cout << result;

    return 0;
}
```

```output
20
```

The order of values is important.

```cpp
int a = 10;
int b = 30;

cout << a - b;
```

```output
-20
```

---

## 4. Multiplication Operator `*`

The `*` operator is used for multiplication.

```cpp
#include <iostream>
using namespace std;

int main() {
    int price = 50;
    int quantity = 4;

    int total = price * quantity;

    cout << total;

    return 0;
}
```

```output
200
```

Here:

```cpp
50 * 4
```

produces `200`.

---

## 5. Division Operator `/`

The `/` operator is used for division.

```cpp
#include <iostream>
using namespace std;

int main() {
    int total = 100;
    int students = 4;

    int result = total / students;

    cout << result;

    return 0;
}
```

```output
25
```

### Integer Division

When both operands are integers, C++ performs integer division.

For example:

```cpp
cout << 7 / 2;
```

```output
3
```

The decimal part is discarded.

If you want a decimal result, use a `double`:

```cpp
cout << 7.0 / 2;
```

```output
3.5
```

---

## 6. Modulus Operator `%`

The `%` operator returns the **remainder** after integer division.

Example:

```cpp
cout << 10 % 3;
```

```output
1
```

Because:

```text
10 ÷ 3 = 3 remainder 1
```

Another example:

```cpp
cout << 20 % 4;
```

```output
0
```

Because `20` is completely divisible by `4`.

### Checking Even and Odd Numbers

The modulus operator is commonly used to check whether a number is even or odd.

```cpp
#include <iostream>
using namespace std;

int main() {
    int number = 17;

    if (number % 2 == 0) {
        cout << "Even";
    } else {
        cout << "Odd";
    }

    return 0;
}
```

```output
Odd
```

If the remainder is `0`, the number is even. Otherwise, it is odd.

---

## 7. Arithmetic Operators with Variables

Arithmetic operators can be combined with variables.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 20;
    int b = 6;

    cout << "Addition: " << a + b << "\n";
    cout << "Subtraction: " << a - b << "\n";
    cout << "Multiplication: " << a * b << "\n";
    cout << "Division: " << a / b << "\n";
    cout << "Remainder: " << a % b;

    return 0;
}
```

```output
Addition: 26
Subtraction: 14
Multiplication: 120
Division: 3
Remainder: 2
```

Notice that `20 / 6` gives `3` because both values are integers.

---

## 8. Arithmetic Expressions

An **expression** is a combination of values, variables, and operators that produces a result.

For example:

```cpp
int result = 10 + 5 * 2;
```

The expression contains:

* Values: `10`, `5`, `2`
* Operators: `+`, `*`

The result is:

```output
20
```

The multiplication is performed before addition.

---

## 9. Operator Precedence

When an expression contains multiple arithmetic operators, C++ follows **operator precedence** to determine the order of evaluation.

A simple order to remember is:

1. `*`, `/`, `%`
2. `+`, `-`

For example:

```cpp
int result = 10 + 5 * 2;
```

First:

```text
5 × 2 = 10
```

Then:

```text
10 + 10 = 20
```

Therefore:

```output
20
```

### Using Parentheses

Parentheses can be used to change the order.

```cpp
int result = (10 + 5) * 2;
```

First:

```text
10 + 5 = 15
```

Then:

```text
15 × 2 = 30
```

Result:

```output
30
```

## 10. Arithmetic with Decimal Values

Arithmetic operators also work with `float` and `double`.

```cpp
#include <iostream>
using namespace std;

int main() {
    double price = 99.50;
    double quantity = 2;

    double total = price * quantity;

    cout << total;

    return 0;
}
```

```output
199
```

Decimal values can also be used in division:

```cpp
double result = 10.0 / 4.0;
```

```output
2.5
```

## 11. Using Arithmetic Operators with Input

Arithmetic operators are often used with values entered by the user.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;

    cout << "Enter two numbers: ";
    cin >> a >> b;

    cout << "Sum: " << a + b << "\n";
    cout << "Difference: " << a - b << "\n";
    cout << "Product: " << a * b << "\n";
    cout << "Quotient: " << a / b << "\n";
    cout << "Remainder: " << a % b;

    return 0;
}
```

If the user enters:

```output
20 6
```

The output is:

```output
Sum: 26
Difference: 14
Product: 120
Quotient: 3
Remainder: 2
```

## 12. Real-World Example 🌍

Arithmetic operators are useful in everyday calculations.

For example, a shopping program can calculate the total price.

```cpp
#include <iostream>
using namespace std;

int main() {
    double price = 250.50;
    int quantity = 3;

    double total = price * quantity;

    cout << "Price: " << price << "\n";
    cout << "Quantity: " << quantity << "\n";
    cout << "Total: " << total;

    return 0;
}
```

```output
Price: 250.5
Quantity: 3
Total: 751.5
```

Here, the multiplication operator calculates the total cost.

## Common Mistakes

### Mistake 1: Expecting decimal division with integers

```cpp
int result = 7 / 2;
```

The result is:

```output
3
```

Use a decimal operand when you need a decimal result:

```cpp
double result = 7.0 / 2;
```

```output
3.5
```

---

### Mistake 2: Confusing `/` and `%`

`/` gives the quotient:

```cpp
10 / 3
```

```output
3
```

`%` gives the remainder:

```cpp
10 % 3
```

```output
1
```

---

### Mistake 3: Forgetting operator precedence

This:

```cpp
10 + 5 * 2
```

does not calculate from left to right.

Multiplication is performed first:

```text
10 + (5 × 2)
= 20
```

Use parentheses when you want a specific order:

```cpp
(10 + 5) * 2
```

---

### Mistake 4: Dividing by zero

Division by zero should be avoided.

For example:

```cpp
int result = 10 / 0;
```

is invalid and can lead to undefined behavior.

Always make sure the divisor is not zero before performing division or modulus.

---

## Key Points

* Arithmetic operators are used for mathematical calculations.
* `+` performs addition.
* `-` performs subtraction.
* `*` performs multiplication.
* `/` performs division.
* `%` gives the remainder.
* Integer division discards the fractional part.
* `%` is useful for checking even and odd numbers.
* `*`, `/`, and `%` have higher precedence than `+` and `-`.
* Parentheses can be used to control the order of evaluation.
