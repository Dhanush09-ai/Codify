# Chapter 3: Operators

## Section 2: Relational & Logical Operators

Relational and logical operators are used to **compare values** and **combine conditions** in C++.

They are commonly used in decision-making statements such as `if`, `if-else`, and loops.

For example:

```cpp
int age = 18;

if (age >= 18) {
    cout << "Eligible";
}
```

Here, `>=` compares `age` with `18`.

---

## 1. Relational Operators

Relational operators compare two values.

The result of a relational expression is a Boolean value:

* `true` → condition is correct
* `false` → condition is not correct

### Relational Operators in C++

| Operator | Meaning                  | Example  |
| -------- | ------------------------ | -------- |
| `==`     | Equal to                 | `a == b` |
| `!=`     | Not equal to             | `a != b` |
| `>`      | Greater than             | `a > b`  |
| `<`      | Less than                | `a < b`  |
| `>=`     | Greater than or equal to | `a >= b` |
| `<=`     | Less than or equal to    | `a <= b` |

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 10;
    int b = 5;

    cout << (a > b) << endl;
    cout << (a < b) << endl;
    cout << (a == b) << endl;

    return 0;
}
```

```output
1
0
0
```

By default, C++ prints:

* `1` for `true`
* `0` for `false`

---

## 2. Understanding Equality Operators

Two operators that beginners often confuse are `=` and `==`.

### `=` Assignment Operator

The `=` operator assigns a value to a variable.

```cpp
int age = 18;
```

Here, `18` is assigned to `age`.

### `==` Equality Operator

The `==` operator checks whether two values are equal.

```cpp
int age = 18;

cout << (age == 18);
```

```output
1
```

The expression is `true` because `age` contains `18`.

### Important

```cpp
age = 18;
```

means **assign 18 to age**.

```cpp
age == 18;
```

means **check whether age is 18**.

## 3. Logical Operators

Logical operators are used to **combine or reverse conditions**.

C++ provides three main logical operators:

| Operator | Name        | Meaning                      |            |                                     |
| -------- | ----------- | ---------------------------- | ---------- | ----------------------------------- |
| `&&`     | Logical AND | Both conditions must be true |            |                                     |
| `        |             | `                            | Logical OR | At least one condition must be true |
| `!`      | Logical NOT | Reverses the condition       |            |                                     |

---

## 4. Logical AND (`&&`)

The `&&` operator returns `true` only when **both conditions are true**.

### Example

```cpp
int age = 20;
bool hasID = true;

cout << (age >= 18 && hasID);
```

```output
1
```

Both conditions are true:

* `age >= 18` → true
* `hasID` → true

Therefore, the complete condition is true.

### Truth Table

| Condition A | Condition B | `A && B` |
| ----------- | ----------- | -------- |
| true        | true        | true     |
| true        | false       | false    |
| false       | true        | false    |
| false       | false       | false    |

### Real-World Example 🌍

A student can enter an examination hall only if:

* the student has a valid hall ticket **AND**
* the student has arrived on time.

```cpp
bool hallTicket = true;
bool onTime = true;

if (hallTicket && onTime) {
    cout << "You can enter the exam hall.";
}
```

```output
You can enter the exam hall.
```

---

## 5. Logical OR (`||`)

The `||` operator returns `true` when **at least one condition is true**.

### Example

```cpp
int marks = 35;
bool specialPermission = true;

cout << (marks >= 40 || specialPermission);
```

```output
1
```

The first condition is false, but the second condition is true.

Therefore, the complete condition is true.

### Truth Table

| Condition A | Condition B | `A || B` |
|---|---|---|
| true | true | true |
| true | false | true |
| false | true | true |
| false | false | false |

### Real-World Example 🌍

A user can reset a password using either:

* an email verification **OR**
* a valid recovery method.

```cpp
bool emailVerified = false;
bool recoveryVerified = true;

if (emailVerified || recoveryVerified) {
    cout << "Password reset allowed.";
}
```

```output
Password reset allowed.
```

---

## 6. Logical NOT (`!`)

The `!` operator reverses a Boolean value.

* `!true` → `false`
* `!false` → `true`

### Example

```cpp
bool loggedIn = false;

cout << !loggedIn;
```

```output
1
```

`loggedIn` is `false`, so `!loggedIn` becomes `true`.

### Another Example

```cpp
int age = 15;

cout << !(age >= 18);
```

```output
1
```

`age >= 18` is false.

The `!` operator reverses it to true.

---

## 7. Combining Relational and Logical Operators

Relational and logical operators are often used together.

### Example

```cpp
int age = 20;
int marks = 75;

if (age >= 18 && marks >= 40) {
    cout << "Eligible";
}
```

```output
Eligible
```

Here:

```text
age >= 18
```

is true, and

```text
marks >= 40
```

is also true.

Therefore:

```text
true && true = true
```

---

## 8. Using OR with Relational Operators

You can also use multiple comparisons with `||`.

```cpp
int marks = 85;

if (marks < 35 || marks > 100) {
    cout << "Invalid marks";
} else {
    cout << "Valid marks";
}
```

```output
Valid marks
```

The condition checks whether the marks are:

* below `35`, or
* above `100`.

Since `85` satisfies neither condition, the `else` block runs.

## 9. Common Mistakes

### Mistake 1: Using `=` instead of `==`

Incorrect:

```cpp
if (age = 18) {
    cout << "Adult";
}
```

Use `==` when you want to compare:

```cpp
if (age == 18) {
    cout << "Age is 18";
}
```

---

### Mistake 2: Using `&` instead of `&&`

`&` and `&&` are different operators.

For logical conditions, use:

```cpp
if (age >= 18 && hasID) {
    cout << "Allowed";
}
```

---

### Mistake 3: Using `|` instead of `||`

For logical OR conditions, use:

```cpp
if (condition1 || condition2) {
    cout << "Accepted";
}
```

---

### Mistake 4: Forgetting Parentheses

When combining multiple comparisons, parentheses can make the condition easier to understand.

```cpp
if ((age >= 18) && (marks >= 40)) {
    cout << "Eligible";
}
```

---

## Key Points

* Relational operators compare two values.
* Relational expressions produce `true` or `false`.
* `==` checks equality, while `=` assigns a value.
* `!=` checks whether values are different.
* `&&` means logical AND.
* `||` means logical OR.
* `!` means logical NOT.
* `&&` requires both conditions to be true.
* `||` requires at least one condition to be true.
* `!` reverses a Boolean condition.
* Relational and logical operators are frequently used with `if` statements and loops.
