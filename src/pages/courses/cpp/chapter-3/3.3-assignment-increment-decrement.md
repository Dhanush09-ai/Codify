# Chapter 3: Operators

## Section 3: Assignment & Increment/Decrement Operators

Assignment and increment/decrement operators are used frequently when working with variables.

* **Assignment operators** store or update values in variables.
* **Increment operators** increase a value by `1`.
* **Decrement operators** decrease a value by `1`.

These operators are especially useful in calculations and loops.

---

## 1. Assignment Operator

The basic assignment operator in C++ is:

```cpp
=
```

It assigns the value on the right side to the variable on the left side.

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int marks;

    marks = 85;

    cout << marks;

    return 0;
}
```

```output
85
```

Here, `85` is assigned to `marks`.

### Important

The assignment operator works from **right to left**.

```cpp
int a = 10;
```

means:

```text
10 → a
```

---

## 2. Compound Assignment Operators

C++ provides shorthand operators for updating a variable.

| Operator | Example  | Equivalent To |
| -------- | -------- | ------------- |
| `=`      | `a = 10` | `a = 10`      |
| `+=`     | `a += 5` | `a = a + 5`   |
| `-=`     | `a -= 5` | `a = a - 5`   |
| `*=`     | `a *= 5` | `a = a * 5`   |
| `/=`     | `a /= 5` | `a = a / 5`   |
| `%=`     | `a %= 5` | `a = a % 5`   |

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int number = 10;

    number += 5;
    cout << number << endl;

    number -= 3;
    cout << number << endl;

    number *= 2;
    cout << number << endl;

    return 0;
}
```

```output
15
12
24
```

Let's understand the operations:

```text
number = 10
number += 5 → 15
number -= 3 → 12
number *= 2 → 24
```

## 3. Division and Modulus Assignment

The `/=` operator performs division and stores the result.

```cpp
#include <iostream>
using namespace std;

int main() {
    int number = 20;

    number /= 4;

    cout << number;

    return 0;
}
```

```output
5
```

The statement:

```cpp
number /= 4;
```

is equivalent to:

```cpp
number = number / 4;
```

### Modulus Assignment

The `%=` operator calculates the remainder and stores it.

```cpp
#include <iostream>
using namespace std;

int main() {
    int number = 17;

    number %= 5;

    cout << number;

    return 0;
}
```

```output
2
```

Because:

```text
17 % 5 = 2
```

## 4. Increment Operator (`++`)

The increment operator `++` increases a variable by `1`.

```cpp
int count = 10;

count++;
```

After this statement:

```text
count = 11
```

The following two statements are equivalent:

```cpp
count++;
```

and

```cpp
count = count + 1;
```

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int count = 5;

    count++;

    cout << count;

    return 0;
}
```

```output
6
```

---

## 5. Decrement Operator (`--`)

The decrement operator `--` decreases a variable by `1`.

```cpp
int count = 10;

count--;
```

After this statement:

```text
count = 9
```

The following two statements are equivalent:

```cpp
count--;
```

and

```cpp
count = count - 1;
```

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int count = 5;

    count--;

    cout << count;

    return 0;
}
```

```output
4
```

---

## 6. Prefix and Postfix Increment

The increment operator can be used in two forms:

* **Prefix:** `++a`
* **Postfix:** `a++`

Both increase the variable by `1`, but they behave differently when used inside a larger expression.

### Prefix Increment

With prefix increment, the variable is increased **before** its value is used.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 5;

    cout << ++a;

    return 0;
}
```

```output
6
```

Here:

```text
a = 5
++a → a becomes 6
6 is used
```

---

### Postfix Increment

With postfix increment, the current value is used **before** the variable is increased.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 5;

    cout << a++;

    return 0;
}
```

```output
5
```

After the expression finishes, `a` becomes `6`.

So:

```text
a = 5
a++ → 5 is used
a becomes 6
```

---

## 7. Prefix and Postfix Decrement

The same idea applies to the decrement operator.

### Prefix Decrement

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 5;

    cout << --a;

    return 0;
}
```

```output
4
```

The value is decreased first and then used.

### Postfix Decrement

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 5;

    cout << a--;

    return 0;
}
```

```output
5
```

The current value is used first, and then `a` becomes `4`.

---

## 8. Increment and Decrement in Expressions

Prefix and postfix operators are useful when a variable is part of an expression.

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 5;
    int b = a++;

    cout << a << endl;
    cout << b;

    return 0;
}
```

```output
6
5
```

Here:

```text
a = 5
b = a++ → b gets 5
a becomes 6
```

Now consider prefix increment:

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 5;
    int b = ++a;

    cout << a << endl;
    cout << b;

    return 0;
}
```

```output
6
6
```

Here:

```text
a = 5
++a → a becomes 6
b gets 6
```

## 9. Real-World Example 🌍

Imagine a shopping application that keeps track of the number of items in a cart.

```cpp
#include <iostream>
using namespace std;

int main() {
    int items = 3;

    items++;
    items++;

    cout << "Items in cart: " << items;

    return 0;
}
```

```output
Items in cart: 5
```

Every time an item is added, the count can be increased using `++`.

Similarly, when an item is removed:

```cpp
items--;
```

This makes increment and decrement operators useful in counters and loops.

## 10. Common Mistakes

### Mistake 1: Confusing `=` and `==`

Assignment:

```cpp
int age = 18;
```

Comparison:

```cpp
age == 18
```

`=` assigns a value, while `==` compares two values.

---

### Mistake 2: Confusing Prefix and Postfix

Remember:

```cpp
++a
```

means:

```text
Increase first → use the value
```

While:

```cpp
a++
```

means:

```text
Use the value → increase afterward
```

The same rule applies to `--a` and `a--`.

---

### Mistake 3: Forgetting That `+=` Updates the Variable

```cpp
int x = 10;

x += 5;
```

The new value of `x` is `15`.

It is equivalent to:

```cpp
x = x + 5;
```

---

## Key Points

* `=` assigns a value to a variable.
* Compound assignment operators provide shorthand for updating variables.
* `+=` adds and assigns.
* `-=` subtracts and assigns.
* `*=` multiplies and assigns.
* `/=` divides and assigns.
* `%=` calculates the remainder and assigns it.
* `++` increases a value by `1`.
* `--` decreases a value by `1`.
* Prefix increment/decrement changes the value before it is used.
* Postfix increment/decrement uses the value first and changes it afterward.
