# Chapter 3: Operators

## Section 5: Operator Precedence & Expressions

When an expression contains multiple operators, C++ needs to decide **which operation should be performed first**.

This order is called **operator precedence**.

For example:

```cpp
int result = 10 + 5 * 2;
```

The multiplication is performed before addition, so:

```text
5 * 2 = 10
10 + 10 = 20
```

Therefore, `result` becomes `20`.

In this lesson, you will learn:

* What expressions are
* Operator precedence
* Associativity
* Using parentheses
* Common mistakes

---

## 1. What Is an Expression?

An **expression** is a combination of values, variables, and operators that produces a result.

### Example

```cpp
int result = 10 + 5;
```

Here:

```text
10 + 5
```

is an expression.

Its result is:

```text
15
```

### More Examples

```cpp
a + b
```

```cpp
x * 10
```

```cpp
marks >= 40
```

```cpp
(a > 10) && (b < 20)
```

Expressions can use arithmetic, relational, logical, assignment, and other operators.

---

## 2. Why Operator Precedence Is Needed

Consider this expression:

```cpp
int result = 10 + 5 * 2;
```

There are two operators:

* `+`
* `*`

If C++ performed the operations from left to right, the result would be:

```text
10 + 5 = 15
15 * 2 = 30
```

But C++ gives multiplication a higher precedence than addition.

Therefore:

```text
5 * 2 = 10
10 + 10 = 20
```

The result is:

```cpp
20
```

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int result = 10 + 5 * 2;

    cout << result;

    return 0;
}
```

```output
20
```

## 3. Common Operator Precedence

The following table shows some commonly used C++ operators from **higher precedence to lower precedence**.

| Priority | Operators                    | Description                       |   |            |
| -------- | ---------------------------- | --------------------------------- | - | ---------- |
| 1        | `()`                         | Parentheses                       |   |            |
| 2        | `++` `--`                    | Increment / Decrement             |   |            |
| 3        | `*` `/` `%`                  | Multiplication, Division, Modulus |   |            |
| 4        | `+` `-`                      | Addition, Subtraction             |   |            |
| 5        | `<` `<=` `>` `>=`            | Relational                        |   |            |
| 6        | `==` `!=`                    | Equality                          |   |            |
| 7        | `&&`                         | Logical AND                       |   |            |
| 8        | `                            |                                   | ` | Logical OR |
| 9        | `?:`                         | Conditional                       |   |            |
| 10       | `=` `+=` `-=` `*=` `/=` `%=` | Assignment                        |   |            |

A higher-priority operator is generally evaluated before a lower-priority operator.

## 4. Arithmetic Operator Precedence

Among the basic arithmetic operators:

```text
*  /  %
```

have higher precedence than:

```text
+  -
```

### Example

```cpp
int result = 20 - 6 / 2;
```

First:

```text
6 / 2 = 3
```

Then:

```text
20 - 3 = 17
```

So the result is:

```cpp
17
```

### Example Program

```cpp
#include <iostream>
using namespace std;

int main() {
    int result = 20 - 6 / 2;

    cout << result;

    return 0;
}
```

```output
17
```

---

## 5. Parentheses Have Higher Priority

Parentheses can be used to control the order of evaluation.

Consider:

```cpp
int result = 10 + 5 * 2;
```

The result is:

```text
20
```

Now add parentheses:

```cpp
int result = (10 + 5) * 2;
```

First:

```text
10 + 5 = 15
```

Then:

```text
15 * 2 = 30
```

So the result becomes:

```text
30
```

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int result = (10 + 5) * 2;

    cout << result;

    return 0;
}
```

```output
30
```

### Important

Parentheses are useful when you want to make the intended order clear.

---

## 6. Relational and Logical Precedence

Relational and logical operators can also appear together.

Consider:

```cpp
int age = 20;
int marks = 75;

if (age >= 18 && marks >= 40) {
    cout << "Eligible";
}
```

The relational expressions are evaluated before the logical `&&` operation:

```text
age >= 18
marks >= 40
```

Then:

```text
true && true
```

So the condition is true.

```output
Eligible
```

### Example with OR

```cpp
int marks = 85;

if (marks < 35 || marks > 100) {
    cout << "Invalid";
}
```

The relational comparisons are evaluated before the logical OR.

Since both comparisons are false:

```text
false || false
```

the condition is false.

---

## 7. Associativity

When operators have the **same precedence**, C++ uses their **associativity** to determine the evaluation order.

For many arithmetic operators, evaluation is from **left to right**.

### Example

```cpp
int result = 20 - 5 - 3;
```

Both `-` operators have the same precedence.

So they are evaluated from left to right:

```text
20 - 5 = 15
15 - 3 = 12
```

Therefore:

```text
result = 12
```

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int result = 20 - 5 - 3;

    cout << result;

    return 0;
}
```

```output
12
```

---

## 8. Assignment Associativity

Assignment operators are evaluated from **right to left**.

For example:

```cpp
int a, b, c;

a = b = c = 10;
```

The assignments happen from the right:

```text
c = 10
b = c
a = b
```

Therefore, all three variables contain `10`.

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b, c;

    a = b = c = 10;

    cout << a << endl;
    cout << b << endl;
    cout << c;

    return 0;
}
```

```output
10
10
10
```

---

## 9. Using Parentheses for Clear Expressions

Even when you know the precedence rules, parentheses can make code easier to understand.

Instead of:

```cpp
int result = a + b * c;
```

you can write:

```cpp
int result = a + (b * c);
```

Both have the same meaning.

For a more complex expression:

```cpp
int result = (a + b) * (c - d);
```

The parentheses clearly show which operations should happen first.

### Good Practice

Use parentheses when they improve readability or remove confusion.

## 10. Expressions with Different Operators

An expression can contain several types of operators.

### Example

```cpp
int a = 10;
int b = 5;

bool result = (a + b * 2) > 15;
```

First:

```text
b * 2 = 10
```

Then:

```text
a + 10 = 20
```

Then:

```text
20 > 15
```

So:

```text
result = true
```

### Example Program

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 10;
    int b = 5;

    bool result = (a + b * 2) > 15;

    cout << result;

    return 0;
}
```

```output
1
```

## 11. Real-World Example 🌍

Suppose a shopping application calculates the final price after adding a delivery charge.

```cpp
#include <iostream>
using namespace std;

int main() {
    int productPrice = 500;
    int quantity = 2;
    int deliveryCharge = 50;

    int total = productPrice * quantity + deliveryCharge;

    cout << "Total: " << total;

    return 0;
}
```

```output
Total: 1050
```

The multiplication is performed first:

```text
500 * 2 = 1000
```

Then the delivery charge is added:

```text
1000 + 50 = 1050
```

Parentheses can make the calculation clearer:

```cpp
int total = (productPrice * quantity) + deliveryCharge;
```

## 12. Common Mistakes

### Mistake 1: Assuming Everything Is Evaluated Left to Right

This is incorrect:

```cpp
10 + 5 * 2
```

as:

```text
(10 + 5) * 2
```

Multiplication has higher precedence, so the correct interpretation is:

```text
10 + (5 * 2)
```

---

### Mistake 2: Ignoring Parentheses

Compare:

```cpp
10 + 5 * 2
```

and:

```cpp
(10 + 5) * 2
```

They produce different results:

```text
20
30
```

---

### Mistake 3: Confusing `=` and `==`

Remember:

```cpp
=
```

is assignment.

```cpp
==
```

is equality comparison.

---

### Mistake 4: Writing Difficult Expressions Without Parentheses

A complicated expression may be technically correct but difficult to understand.

Prefer:

```cpp
int result = (a + b) * (c - d);
```

when parentheses make the intended calculation clear.

---

## Key Points

* An expression combines values, variables, and operators to produce a result.
* Operator precedence determines which operators are evaluated first.
* Parentheses have high precedence and can control evaluation order.
* `*`, `/`, and `%` have higher precedence than `+` and `-`.
* Relational operators are evaluated before logical `&&` and `||` in common expressions.
* Operators with the same precedence follow their associativity rules.
* Many arithmetic operators associate from left to right.
* Assignment operators associate from right to left.
* Parentheses make complex expressions easier to understand.
* Understanding precedence helps prevent unexpected results.
