# Chapter 7: Arrays, Strings & Pointers

## Section 4: References

A reference in C++ is another name, or **alias**, for an existing variable.

A reference does not create a separate copy of the variable. Instead, it refers to the same variable.

References are commonly used with functions because they allow a function to work directly with the original variable.

---

## 1. What is a Reference?

A reference gives another name to an existing variable.

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int number = 10;

    int& ref = number;

    cout << number << endl;
    cout << ref << endl;

    return 0;
}
```


```output
10
10
```

Here:

* `number` is the original variable.
* `ref` is a reference to `number`.
* Both refer to the same value.

---

## 2. Reference Syntax

A reference is declared using `&`.

### Syntax

```cpp
dataType& referenceName = variableName;
```

### Example

```cpp
int number = 25;
int& ref = number;
```

Now `ref` is another name for `number`.

You can think of it like:

```text
number ─────┐
            │
            ↓
          same value
            ↑
            │
ref ────────┘
```

---

## 3. Changing a Variable Through a Reference

Because a reference refers to the original variable, changing the reference also changes the original variable.

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int number = 10;

    int& ref = number;

    ref = 50;

    cout << number << endl;

    return 0;
}
```


```output
50
```

The statement:

```cpp
ref = 50;
```

changes `number` because `ref` refers to the same variable.

---

## 4. Reference and Original Variable

Consider:

```cpp
int age = 20;
int& ref = age;
```

There are two names:

```text
age
ref
```

But they refer to the same variable.

So:

```cpp
cout << age;
```

and:

```cpp
cout << ref;
```

both give:

```text
20
```

If you change either one, the same variable is changed.

---

## 5. References Must Be Initialized

A reference must be connected to a variable when it is declared.

Correct:

```cpp
int number = 10;
int& ref = number;
```

A reference cannot be declared without an initializer:

```cpp
int& ref;
```

This is invalid.

---

## 6. A Reference Cannot Be Reassigned

Once a reference is connected to a variable, it cannot later be made to refer to another variable.

### Example

```cpp
int a = 10;
int b = 20;

int& ref = a;

ref = b;
```

The last statement does **not** make `ref` refer to `b`.

Instead, it copies the value of `b` into `a`.

After:

```cpp
ref = b;
```

the values are:

```text
a = 20
b = 20
```

`ref` still refers to `a`.

---

## 7. References with Different Data Types

A reference normally has the same type as the variable it refers to.

### Integer

```cpp
int number = 10;
int& ref = number;
```

### Double

```cpp
double price = 99.50;
double& ref = price;
```

### Character

```cpp
char grade = 'A';
char& ref = grade;
```

The reference type should match the referenced variable type in normal use.

---

## 8. References and Functions

References are very useful with functions.

A function can receive a reference to a variable and modify the original variable.

### Example

```cpp
#include <iostream>
using namespace std;

void changeValue(int& number) {
    number = 100;
}

int main() {
    int value = 50;

    changeValue(value);

    cout << value << endl;

    return 0;
}
```


```output
100
```

The function receives a reference to `value`.

Therefore, the function changes the original variable.

---

## 9. Reference Parameters

A parameter declared with `&` is called a **reference parameter**.

Example:

```cpp
void changeValue(int& number)
```

Here:

```text
int& number
```

means `number` is a reference parameter.

When the function is called:

```cpp
changeValue(value);
```

the function works directly with `value`.

---

## 10. Reference vs Value Parameter

Consider a normal parameter:

```cpp
void change(int number) {
    number = 100;
}
```

Here, `number` receives a copy of the value.

Changing it does not change the original variable.

### Example

```cpp
#include <iostream>
using namespace std;

void change(int number) {
    number = 100;
}

int main() {
    int value = 50;

    change(value);

    cout << value << endl;

    return 0;
}
```


```output
50
```

Now compare it with a reference parameter:

```cpp
#include <iostream>
using namespace std;

void change(int& number) {
    number = 100;
}

int main() {
    int value = 50;

    change(value);

    cout << value << endl;

    return 0;
}
```


```output
100
```

The difference is:

| Value Parameter                | Reference Parameter             |
| ------------------------------ | ------------------------------- |
| Receives a copy                | Refers to the original variable |
| Changes do not affect original | Changes affect original         |
| `int number`                   | `int& number`                   |

---

## 11. Swapping Two Variables Using References

References make it easy to create a function that swaps two original variables.

### Example

```cpp
#include <iostream>
using namespace std;

void swapNumbers(int& a, int& b) {
    int temp = a;
    a = b;
    b = temp;
}

int main() {
    int x = 10;
    int y = 20;

    swapNumbers(x, y);

    cout << x << " " << y << endl;

    return 0;
}
```


```output
20 10
```

The function changes `x` and `y` directly because `a` and `b` are references.

---

## 12. References with Arrays

References can also be used when working with arrays.

A function can receive an array by reference.

For example:

```cpp
#include <iostream>
using namespace std;

void changeFirst(int (&numbers)[3]) {
    numbers[0] = 100;
}

int main() {
    int numbers[3] = {10, 20, 30};

    changeFirst(numbers);

    cout << numbers[0] << endl;

    return 0;
}
```


```output
100
```

The function works with the original array.

> Array references can become more advanced. For beginner programs, focus mainly on using references with variables and functions.

---

## 13. Const References

A reference can be declared with `const`.

A `const` reference cannot be used to modify the referenced value through that reference.

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int number = 50;

    const int& ref = number;

    cout << ref << endl;

    return 0;
}
```


```output
50
```

This is not allowed:

```cpp
ref = 100;
```

because `ref` is a reference to a constant value.

However, the original variable can still be changed through another non-const name:

```cpp
number = 100;
```

---

## 14. References and `const` Function Parameters

A `const` reference is often useful when a function only needs to read a value.

### Example

```cpp
#include <iostream>
#include <string>
using namespace std;

void displayName(const string& name) {
    cout << name << endl;
}

int main() {
    string student = "Owais";

    displayName(student);

    return 0;
}
```


```output
Owais
```

The function can read `name`, but it cannot modify the original string through that reference.

---

## 15. Reference vs Pointer

References and pointers can both be used to work with existing variables, but they are different.

| Reference                     | Pointer                        |
| ----------------------------- | ------------------------------ |
| Another name for a variable   | Stores a memory address        |
| Must be initialized           | Can be declared first          |
| Normally cannot be null       | Can be `nullptr`               |
| Cannot be reseated            | Can point to different objects |
| Used directly like a variable | Usually dereferenced using `*` |

### Example

Reference:

```cpp
int number = 10;
int& ref = number;

ref = 20;
```

Pointer:

```cpp
int number = 10;
int* ptr = &number;

*ptr = 20;
```

Both can change `number`, but they work differently.

---

## 16. References and Memory

A reference is an alias for an existing object.

For example:

```cpp
int number = 25;
int& ref = number;
```

Both names refer to the same object.

```text
        ┌───────────────┐
number ─┤               │
        │    25         │
ref ────┤               │
        └───────────────┘
```

The important idea is:

> A reference gives another name to an existing variable.

---

## 17. Real-World Example 🌍

Imagine a student has a name written on a record.

The student may have a nickname used by friends, but both names identify the same person.

Similarly:

```cpp
string name = "Owais";
string& nickname = name;
```

Both `name` and `nickname` refer to the same string.

If:

```cpp
nickname = "Mohammed";
```

then:

```cpp
name
```

also becomes:

```text
Mohammed
```

The reference does not create a separate copy.

---

## 18. When Are References Useful?

References are especially useful when:

* A function needs to modify the original variable.
* A function needs to work with an existing object without making a copy.
* You want another name for an existing variable.
* You want to pass large objects efficiently using `const` references.

For beginner programs, one of the most important uses is **reference parameters in functions**.

---

## 19. Common Mistakes

### Mistake 1: Declaring a reference without initialization

Incorrect:

```cpp
int& ref;
```

A reference must be initialized.

Correct:

```cpp
int number = 10;
int& ref = number;
```

---

### Mistake 2: Thinking a reference is a copy

```cpp
int number = 10;
int& ref = number;
```

`ref` is not a separate copy.

It refers to `number`.

---

### Mistake 3: Thinking `ref = other` changes what the reference refers to

```cpp
int a = 10;
int b = 20;

int& ref = a;

ref = b;
```

This changes `a` to `20`.

It does not make `ref` refer to `b`.

---

### Mistake 4: Trying to modify through a const reference

```cpp
const int& ref = number;

ref = 50;
```

This is not allowed because `ref` is a const reference.

---

## Key Points 🔑

* A reference is another name for an existing variable.
* References are declared using `&`.
* A reference must be initialized when declared.
* A reference does not create a separate copy of the variable.
* Changing a reference changes the original variable.
* A reference cannot be made to refer to another variable after initialization.
* Reference parameters allow functions to modify original variables.
* `const` references cannot modify the referenced value through that reference.
* References and pointers are different concepts.
* References are commonly used with functions.
