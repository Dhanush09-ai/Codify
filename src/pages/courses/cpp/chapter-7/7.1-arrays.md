# Chapter 7: Arrays, Strings & Pointers

## Section 1: Arrays

When a program needs to store many values of the same type, creating a separate variable for every value can become difficult.

For example, storing five marks separately:

```cpp
int mark1 = 85;
int mark2 = 90;
int mark3 = 78;
int mark4 = 92;
int mark5 = 88;
```

A better approach is to use an **array**.

An array allows us to store multiple values of the same data type under one variable name.

---

## 1. What is an Array?

An **array** is a collection of elements of the same data type stored under one name.

For example:

```cpp
int marks[5];
```

This creates an array named `marks` that can store **5 integers**.

You can think of an array like a row of boxes:

```text
marks
┌────┬────┬────┬────┬────┐
│ 85 │ 90 │ 78 │ 92 │ 88 │
└────┴────┴────┴────┴────┘
   0    1    2    3    4
```

Each box is called an **element**.

---

## 2. Why Do We Use Arrays?

Arrays are useful when we need to store multiple related values.

For example:

* Marks of students
* Prices of products
* Temperatures recorded during a day
* Scores in a game
* Ages of people
* Monthly sales

Without an array, we may need many separate variables.

With an array, one variable name can represent many values.

---

## 3. Declaring an Array

The basic syntax is:

```cpp
data_type array_name[size];
```

For example:

```cpp
int numbers[5];
```

Here:

* `int` → data type
* `numbers` → array name
* `5` → number of elements

Another example:

```cpp
double prices[10];
```

This can store 10 `double` values.

---

## 4. Array Index

Each element of an array has an **index**.

In C++, array indexing starts from **0**.

For an array with 5 elements:

```text
Index:    0    1    2    3    4
          ↓    ↓    ↓    ↓    ↓
        ┌────┬────┬────┬────┬────┐
Array:  │ 10 │ 20 │ 30 │ 40 │ 50 │
        └────┴────┴────┴────┴────┘
```

So:

```cpp
numbers[0]
```

represents the first element.

```cpp
numbers[4]
```

represents the fifth element.

The last index is always:

```text
size - 1
```

---

## 5. Accessing Array Elements

We can access an array element using its index.

```cpp
#include <iostream>
using namespace std;

int main() {
    int numbers[5] = {10, 20, 30, 40, 50};

    cout << numbers[0] << endl;
    cout << numbers[2] << endl;
    cout << numbers[4] << endl;

    return 0;
}
```


```output
10
30
50
```

Here:

* `numbers[0]` → `10`
* `numbers[2]` → `30`
* `numbers[4]` → `50`

---

## 6. Initializing an Array

We can give values to an array when it is created.

```cpp
int numbers[5] = {10, 20, 30, 40, 50};
```

The values are stored in order:

```text
numbers[0] = 10
numbers[1] = 20
numbers[2] = 30
numbers[3] = 40
numbers[4] = 50
```

---

## 7. Letting C++ Determine the Size

We can also omit the array size when initializing an array.

```cpp
int numbers[] = {10, 20, 30, 40, 50};
```

C++ determines the size from the number of values.

Here, the array contains 5 elements.

---

## 8. Partially Initializing an Array

We can provide fewer values than the declared size.

```cpp
#include <iostream>
using namespace std;

int main() {
    int numbers[5] = {10, 20};

    cout << numbers[0] << endl;
    cout << numbers[1] << endl;
    cout << numbers[2] << endl;
    cout << numbers[3] << endl;
    cout << numbers[4] << endl;

    return 0;
}
```


```output
10
20
0
0
0
```

For this initialization, the remaining elements are initialized to zero.

---

## 9. Changing an Array Element

An array element can be changed using its index.

```cpp
#include <iostream>
using namespace std;

int main() {
    int numbers[5] = {10, 20, 30, 40, 50};

    numbers[2] = 100;

    cout << numbers[2] << endl;

    return 0;
}
```


```output
100
```

Originally:

```text
numbers[2] = 30
```

After:

```cpp
numbers[2] = 100;
```

the value becomes `100`.

---

## 10. Printing All Array Elements

Instead of writing a separate `cout` statement for every element, we can use a loop.

```cpp
#include <iostream>
using namespace std;

int main() {
    int numbers[5] = {10, 20, 30, 40, 50};

    for (int i = 0; i < 5; i++) {
        cout << numbers[i] << " ";
    }

    return 0;
}
```


```output
10 20 30 40 50
```

The variable `i` acts as the array index.

---

## 11. Taking Array Input

We can use a loop to read values into an array.

```cpp
#include <iostream>
using namespace std;

int main() {
    int numbers[5];

    for (int i = 0; i < 5; i++) {
        cin >> numbers[i];
    }

    cout << "Array elements: ";

    for (int i = 0; i < 5; i++) {
        cout << numbers[i] << " ";
    }

    return 0;
}
```

### Input

```text
10 20 30 40 50
```


```output
Array elements: 10 20 30 40 50
```

The first loop stores the input values.

The second loop prints them.

---

## 12. Finding the Sum of Array Elements

Arrays are often used with loops to perform calculations.

Example:

```cpp
#include <iostream>
using namespace std;

int main() {
    int numbers[5] = {10, 20, 30, 40, 50};
    int sum = 0;

    for (int i = 0; i < 5; i++) {
        sum += numbers[i];
    }

    cout << "Sum = " << sum << endl;

    return 0;
}
```


```output
Sum = 150
```

The loop adds every element to `sum`.

---

## 13. Finding the Average

We can also calculate the average of array elements.

```cpp
#include <iostream>
using namespace std;

int main() {
    int marks[5] = {80, 90, 70, 85, 95};
    int sum = 0;

    for (int i = 0; i < 5; i++) {
        sum += marks[i];
    }

    double average = static_cast<double>(sum) / 5;

    cout << "Average = " << average << endl;

    return 0;
}
```


```output
Average = 84
```

Here, `static_cast<double>` ensures that the division produces a floating-point result.

---

## 14. Array Size and Number of Elements

Consider:

```cpp
int numbers[5];
```

The array has 5 elements.

The valid indexes are:

```text
0 1 2 3 4
```

The following is invalid:

```cpp
numbers[5]
```

because index `5` is outside the array.

For an array with `n` elements:

```text
First index = 0
Last index  = n - 1
```

---

## 15. Accessing an Invalid Index

C++ does not automatically perform bounds checking for built-in arrays.

For example:

```cpp
int numbers[5] = {10, 20, 30, 40, 50};

cout << numbers[10];
```

This accesses an index outside the array.

The result is not something a program should rely on. Accessing an element outside the valid range leads to **undefined behavior**.

Always make sure the index is within the valid range.

## 16. Character Arrays

Arrays can also store characters.

```cpp
#include <iostream>
using namespace std;

int main() {
    char letters[5] = {'A', 'B', 'C', 'D', 'E'};

    for (int i = 0; i < 5; i++) {
        cout << letters[i] << " ";
    }

    return 0;
}
```


```output
A B C D E
```

Character arrays are important because C-style strings are stored using arrays of characters.

Strings will be covered in a later chapter.

## 17. Using Different Data Types

Arrays can store different types of values, but each individual array must have one element type.

### Integer array

```cpp
int numbers[3] = {10, 20, 30};
```

### Double array

```cpp
double prices[3] = {10.5, 20.75, 30.25};
```

### Character array

```cpp
char letters[3] = {'A', 'B', 'C'};
```

An array cannot normally mix unrelated element types like this:

```cpp
int values[3] = {10, 2.5, 'A'};
```

The values would be converted to `int` according to C++ conversion rules, so this is not a way to create a mixed-type array.

---

## 18. Array with a Constant Size

We can use a constant to represent the array size.

```cpp
#include <iostream>
using namespace std;

int main() {
    const int SIZE = 5;

    int numbers[SIZE] = {10, 20, 30, 40, 50};

    for (int i = 0; i < SIZE; i++) {
        cout << numbers[i] << " ";
    }

    return 0;
}
```


```output
10 20 30 40 50
```

Using a named constant can make the program easier to maintain.

---

## 19. Arrays and Loops

Arrays and loops are commonly used together.

For example, to print the squares of numbers stored in an array:

```cpp
#include <iostream>
using namespace std;

int main() {
    int numbers[5] = {1, 2, 3, 4, 5};

    for (int i = 0; i < 5; i++) {
        cout << numbers[i] * numbers[i] << " ";
    }

    return 0;
}
```


```output
1 4 9 16 25
```

The loop visits every element one by one.

---

## 20. Real-World Example 🌍

Imagine a school program that stores the marks of five students.

```cpp
#include <iostream>
using namespace std;

int main() {
    int marks[5] = {85, 92, 78, 90, 88};

    cout << "Student Marks:" << endl;

    for (int i = 0; i < 5; i++) {
        cout << "Student " << i + 1 << ": "
             << marks[i] << endl;
    }

    return 0;
}
```


```output
Student Marks:
Student 1: 85
Student 2: 92
Student 3: 78
Student 4: 90
Student 5: 88
```

Instead of creating five separate variables, one array stores all five marks.

## 21. Common Array Mistakes

### 1. Forgetting That Indexing Starts at 0

For:

```cpp
int numbers[5];
```

the indexes are:

```text
0 1 2 3 4
```

not:

```text
1 2 3 4 5
```

### 2. Accessing Outside the Array

Avoid:

```cpp
numbers[5]
```

when the array has only 5 elements.

The valid last index is `4`.

### 3. Using the Wrong Loop Condition

For an array with 5 elements:

```cpp
for (int i = 0; i < 5; i++)
```

is correct.

Using:

```cpp
for (int i = 0; i <= 5; i++)
```

causes the loop to access index `5`.

### 4. Mixing Up Size and Index

The size of:

```cpp
int numbers[5];
```

is `5`, but the last index is `4`.

### 5. Forgetting to Initialize Values

If an array is declared without initialization:

```cpp
int numbers[5];
```

its elements do not automatically contain useful zero values when declared as a local variable.

Initialize the array before reading values from it.

## 22. Arrays and Memory

Array elements are stored in a continuous sequence of memory locations.

For example:

```cpp
int numbers[4] = {10, 20, 30, 40};
```

Conceptually:

```text
numbers[0] → 10
numbers[1] → 20
numbers[2] → 30
numbers[3] → 40
```

This organization makes arrays efficient for accessing elements by index.

Pointers and the relationship between arrays and memory will be studied later.

## 23. Advantages of Arrays

Arrays provide several benefits:

* Store multiple values using one name.
* Easy to process using loops.
* Easy to access elements using indexes.
* Useful for calculations and searching.
* Efficient for storing a fixed number of same-type values.
* Form the foundation for many data structures and algorithms.

---

## 24. Limitations of Built-in Arrays

Built-in arrays also have some limitations:

* Their size is fixed after creation.
* All elements have the same type.
* Accessing an invalid index can cause undefined behavior.
* They do not automatically keep track of their number of elements in a separate property.

For many modern C++ programs, containers such as `std::array` and `std::vector` can provide additional features. We will focus on built-in arrays first because they are important for understanding C++ fundamentals.

---

## 25. Key Points

* An **array** stores multiple values of the same type.
* Array indexes start from **0**.
* The last index is `size - 1`.
* An array is declared using a data type, name, and size.
* Array elements are accessed using `array[index]`.
* Arrays can be initialized when they are declared.
* Loops are commonly used to input and process array elements.
* Built-in array size is fixed after creation.
* Accessing outside the valid range causes undefined behavior.
* Arrays can store integers, floating-point values, characters, and other supported element types.
* Arrays and loops are commonly used together.
* Arrays are an important foundation for searching, sorting, strings, and other data structures.
