# Chapter 7: Arrays, Strings & Pointers

## Section 3: Pointers

Pointers are an important feature of C++. A pointer is a variable that stores the **memory address of another variable**.

Pointers are useful when working with memory, arrays, functions, and dynamic memory.

---

## 1. What is a Pointer?

A normal variable stores a value.

A pointer stores the **address** of another variable.

For example:

```cpp
int age = 20;
```

Here, `age` stores the value `20`.

A pointer can store the memory address of `age`:

```cpp
int* ptr = &age;
```

Here:

* `age` stores `20`.
* `&age` gives the address of `age`.
* `ptr` stores that address.
* `*ptr` gives the value stored at that address.

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int age = 20;
    int* ptr = &age;

    cout << age << endl;
    cout << ptr << endl;
    cout << *ptr << endl;

    return 0;
}
```


```output
20
0x7ffd1234
20
```

> **Note:** The actual memory address will be different on different computers and runs.

---

## 2. Address-of Operator `&`

The `&` operator is called the **address-of operator**.

It gives the memory address of a variable.

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int number = 50;

    cout << number << endl;
    cout << &number << endl;

    return 0;
}
```


```output
50
0x7ffd1234
```

The address shown is only an example.

The actual address can be different.

---

## 3. Declaring a Pointer

A pointer is declared using `*`.

### Syntax

```cpp
dataType* pointerName;
```

### Example

```cpp
int* ptr;
double* pricePtr;
char* letterPtr;
```

The pointer type tells C++ what type of value the pointer is expected to point to.

For example:

```cpp
int number = 10;
int* ptr = &number;
```

Here, `ptr` is an integer pointer.

---

## 4. Storing an Address in a Pointer

The address-of operator `&` can be used to store a variable's address in a pointer.

```cpp
#include <iostream>
using namespace std;

int main() {
    int number = 100;
    int* ptr = &number;

    cout << *ptr << endl;

    return 0;
}
```


```output
100
```

The pointer `ptr` contains the address of `number`.

---

## 5. Dereferencing a Pointer

The `*` operator is also used to **dereference** a pointer.

Dereferencing means accessing the value stored at the address held by the pointer.

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int number = 25;
    int* ptr = &number;

    cout << *ptr << endl;

    return 0;
}
```


```output
25
```

Here:

```cpp
*ptr
```

means:

> "Go to the address stored in `ptr` and get the value there."

---

## 6. Changing a Variable Using a Pointer

A pointer can also be used to change the value of the variable it points to.

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int number = 10;
    int* ptr = &number;

    *ptr = 50;

    cout << number << endl;

    return 0;
}
```


```output
50
```

Initially:

```text
number = 10
```

After:

```cpp
*ptr = 50;
```

the value becomes:

```text
number = 50
```

---

## 7. Pointer and Variable Relationship

Consider:

```cpp
int number = 30;
int* ptr = &number;
```

The relationship is:

```text
number
   |
   | stores 30
   ↓
 memory location

ptr
   |
   | stores the address of number
   ↓
 memory location
   |
   ↓
  30
```

So:

```cpp
number
```

gives the value directly.

```cpp
&number
```

gives the address.

```cpp
ptr
```

gives the address stored in the pointer.

```cpp
*ptr
```

gives the value at that address.

## 8. Pointer Example

```cpp
#include <iostream>

int main() {
    int marks = 95;
    int* ptr = &marks;

    cout << "Marks: " << marks << endl;
```

```output

Value using pointer: 95
```

Again, the address will be different on different systems.

## 9. Null Pointers

A pointer that does not point to a valid object can be represented using `nullptr`.

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int* ptr = nullptr;

    cout << ptr << endl;

    return 0;
}
```


```output
0
```

`nullptr` means that the pointer does not currently point to an object.

It is safer than leaving a pointer uninitialized.

### Important

Do not dereference a null pointer:

```cpp
int* ptr = nullptr;

cout << *ptr;
```

This is not valid because `ptr` does not point to an object.

---

## 10. Pointers with Different Data Types

Pointers can point to different types of variables.

### Integer Pointer

```cpp
int number = 10;
int* ptr = &number;
```

### Double Pointer

```cpp
double price = 99.50;
double* ptr = &price;
```

### Character Pointer

```cpp
char grade = 'A';
char* ptr = &grade;
```

The pointer type should match the type of the object it points to.

## 11. Pointers and Arrays

Pointers are closely related to arrays.

Consider:

```cpp
int numbers[3] = {10, 20, 30};
```

The array name can be used in many expressions as a pointer to its first element.

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int numbers[3] = {10, 20, 30};

    int* ptr = numbers;

    cout << *ptr << endl;

    return 0;
}
```


```output
10
```

Here, `ptr` points to the first element of the array.

---

## 12. Accessing Array Elements Using a Pointer

A pointer can be used to access array elements.

```cpp
#include <iostream>
using namespace std;

int main() {
    int numbers[3] = {10, 20, 30};

    int* ptr = numbers;

    cout << *ptr << endl;
    cout << *(ptr + 1) << endl;
    cout << *(ptr + 2) << endl;

    return 0;
}
```


```output
10
20
30
```

Here:

```cpp
*ptr
```

accesses the first element.

```cpp
*(ptr + 1)
```

accesses the second element.

```cpp
*(ptr + 2)
```

accesses the third element.

---

## 13. Pointer Arithmetic

C++ allows some arithmetic operations on pointers.

For example:

```cpp
ptr + 1
```

moves the pointer to the next element of the pointed-to type.

Similarly:

```cpp
ptr + 2
```

moves two elements forward.

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int numbers[4] = {5, 10, 15, 20};

    int* ptr = numbers;

    for (int i = 0; i < 4; i++) {
        cout << *(ptr + i) << " ";
    }

    return 0;
}
```


```output
5 10 15 20
```

Pointer arithmetic is especially useful when working with arrays.

---

## 14. Changing Array Values Using Pointers

Pointers can also be used to modify array elements.

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int numbers[3] = {10, 20, 30};

    int* ptr = numbers;

    *(ptr + 1) = 50;

    cout << numbers[1] << endl;

    return 0;
}
```


```output
50
```

The second element was changed from `20` to `50`.

---

## 15. Pointers and Functions

Pointers can be passed to functions.

This allows a function to modify the original variable.

### Example

```cpp
#include <iostream>
using namespace std;

void changeValue(int* ptr) {
    *ptr = 100;
}

int main() {
    int number = 50;

    changeValue(&number);

    cout << number << endl;

    return 0;
}
```


```output
100
```

The address of `number` is passed to the function:

```cpp
changeValue(&number);
```

The function receives that address and changes the original value using:

```cpp
*ptr = 100;
```

---

## 16. Pointer vs Normal Variable

| Normal Variable        | Pointer                             |
| ---------------------- | ----------------------------------- |
| Stores a value         | Stores an address                   |
| Example: `int x = 10;` | Example: `int* p = &x;`             |
| `x` gives the value    | `p` gives the stored address        |
| `&x` gives its address | `*p` gives the value at the address |

### Simple Example

```cpp
int x = 10;
int* p = &x;
```

Then:

```cpp
x
```

gives:

```text
10
```

```cpp
p
```

gives the address of `x`.

```cpp
*p
```

gives:

```text
10
```

## 17. Real-World Example 🌍

Imagine a house has a house number.

The **house** contains information.

The **address** tells you where the house is located.

A pointer works similarly:

```text
Variable → stores a value
Pointer  → stores the variable's address
```

For example, a student record may contain marks:

```cpp
int marks = 90;
int* ptr = &marks;
```

Here:

* `marks` stores the student's marks.
* `ptr` stores the address of `marks`.
* `*ptr` accesses the marks through that address.

## 18. Common Pointer Mistakes

### Mistake 1: Using an uninitialized pointer

```cpp
int* ptr;
*ptr = 10;
```

This is unsafe because `ptr` does not point to a valid object.

---

### Mistake 2: Dereferencing `nullptr`

```cpp
int* ptr = nullptr;

cout << *ptr;
```

A null pointer should not be dereferenced.

---

### Mistake 3: Confusing `&` and `*`

Remember:

```cpp
&variable
```

gets the address.

```cpp
*pointer
```

gets the value at the address.

---

### Mistake 4: Going outside an array

```cpp
int numbers[3] = {10, 20, 30};

int* ptr = numbers;

cout << *(ptr + 3);
```

The valid elements are only at positions `0`, `1`, and `2`.

Accessing outside the array is invalid.

---

## Key Points 🔑

* A pointer stores a **memory address**.
* `&` is the **address-of operator**.
* `*` can be used to **dereference** a pointer.
* Dereferencing accesses the value at the stored address.
* A pointer can be declared using `*`.
* `nullptr` represents a pointer that does not point to an object.
* Pointers are closely related to arrays.
* Pointer arithmetic can be used to move between array elements.
* Pointers can be passed to functions.
* Pointers can be used to modify original variables through their addresses.
