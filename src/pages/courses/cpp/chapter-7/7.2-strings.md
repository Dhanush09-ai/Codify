# Chapter 7: Arrays, Strings & Pointers

## Section 2: Strings

Strings are used to store and work with text such as names, messages, addresses, and sentences.

In C++, strings can be handled using character arrays and the `string` class. In this lesson, we will learn the basic idea of strings, how to create them, read them, print them, and perform simple operations.

---

## 1. What is a String?

A **string** is a sequence of characters.

For example:

```text
Hello
Owais
Codify
C++
```

A string can contain letters, numbers, spaces, and special characters.

In C++, one common way to work with strings is using the `string` data type.

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string name = "Owais";

    cout << name << endl;

    return 0;
}
```


```output
Owais
```

Here, `name` stores the text `"Owais"`.

---

## 2. Including the `<string>` Header

The `string` type is provided by the C++ Standard Library.

It is good practice to include:

```cpp
#include <string>
```

when using `string`.

Example:

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string message = "Hello, Codify!";

    cout << message << endl;

    return 0;
}
```


```output
Hello, Codify!
```

---

## 3. Declaring a String

The basic syntax is:

```cpp
string variable_name;
```

Example:

```cpp
string name;
```

We can also declare and initialize it at the same time:

```cpp
string name = "Owais";
```

Another example:

```cpp
string city = "Nandyal";
```

---

## 4. Printing a String

We can print a string using `cout`.

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string name = "Owais";

    cout << name << endl;

    return 0;
}
```


```output
Owais
```

We can also print a complete string directly:

```cpp
cout << "Welcome to Codify!" << endl;
```

---

## 5. Reading a Single Word

The `cin` operator can read a string containing one word.

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string name;

    cout << "Enter your name: ";
    cin >> name;

    cout << "Hello, " << name << "!";

    return 0;
}
```

### Input

```text
Owais
```


```output
Enter your name: Owais
Hello, Owais!
```

However, `cin >> name` stops reading when it encounters whitespace.

---

## 6. Reading a Full Line

To read a complete line containing spaces, use `getline()`.

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string name;

    cout << "Enter your full name: ";
    getline(cin, name);

    cout << "Hello, " << name << "!";

    return 0;
}
```

### Input

```text
Mohammed Owais
```


```output
Enter your full name: Mohammed Owais
Hello, Mohammed Owais!
```

`getline()` reads characters until it reaches the newline.

---

## 7. `cin` vs `getline()`

The two methods behave differently.

| Method               | Reads           |
| -------------------- | --------------- |
| `cin >> name`        | One word        |
| `getline(cin, name)` | A complete line |

For example, if the input is:

```text
Mohammed Owais
```

`cin >> name` reads:

```text
Mohammed
```

while `getline(cin, name)` reads:

```text
Mohammed Owais
```

## 8. Finding String Length

The `length()` function tells us how many characters are in a string.

Example:

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string name = "Owais";

    cout << name.length() << endl;

    return 0;
}
```


```output
5
```

The characters are:

```text
O w a i s
```

So the length is `5`.

---

## 9. `size()` Function

The `size()` function can also be used to find the number of characters.

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string message = "Hello";

    cout << message.size() << endl;

    return 0;
}
```


```output
5
```

For a `std::string`, `length()` and `size()` return the same number of characters.

---

## 10. Accessing Characters

A string stores characters in positions, similar to an array.

Indexes start from `0`.

For:

```cpp
string word = "Hello";
```

the indexes are:

```text
Index:    0  1  2  3  4
          ↓  ↓  ↓  ↓  ↓
Character: H  e  l  l  o
```

We can access a character using `[]`.

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string word = "Hello";

    cout << word[0] << endl;
    cout << word[2] << endl;
    cout << word[4] << endl;

    return 0;
}
```


```output
H
l
o
```

---

## 11. Changing a Character

Individual characters of a `string` can be changed using an index.

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string word = "Hello";

    word[0] = 'Y';

    cout << word << endl;

    return 0;
}
```


```output
Yello
```

The first character was changed from `H` to `Y`.

---

## 12. Traversing a String

We can use a loop to visit each character.

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string word = "Hello";

    for (int i = 0; i < word.length(); i++) {
        cout << word[i] << " ";
    }

    return 0;
}
```


```output
H e l l o
```

The loop starts at index `0` and continues until the last character.

---

## 13. String Concatenation

**Concatenation** means joining strings together.

The `+` operator can be used to join strings.

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string firstName = "Mohammed";
    string lastName = "Owais";

    string fullName = firstName + " " + lastName;

    cout << fullName << endl;

    return 0;
}
```


```output
Mohammed Owais
```

The space `" "` is included between the two names.

---

## 14. Using `+=` with Strings

The `+=` operator can add text to an existing string.

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string message = "Hello";

    message += " Codify";

    cout << message << endl;

    return 0;
}
```


```output
Hello Codify
```

The second string is added to the end of the first string.

---

## 15. Comparing Strings

Strings can be compared using comparison operators.

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string a = "apple";
    string b = "apple";

    if (a == b) {
        cout << "Strings are equal";
    }

    return 0;
}
```


```output
Strings are equal
```

Common comparison operators include:

```text
==    Equal
!=    Not equal
<     Less than
>     Greater than
<=    Less than or equal
>=    Greater than or equal
```

String comparison is based on the characters in the strings.

---

## 16. Finding a Character

We can use `find()` to search for a character or substring.

Example:

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string word = "Codify";

    size_t position = word.find('i');

    cout << position << endl;

    return 0;
}
```


```output
3
```

The character `i` is at index `3`.

The `find()` function returns the position where the match begins.

---

## 17. Searching for a Word

`find()` can also search for a substring.

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string message = "Welcome to Codify";

    size_t position = message.find("Codify");

    cout << position << endl;

    return 0;
}
```


```output
11
```

The word `"Codify"` starts at index `11`.

---

## 18. When a Search Fails

If `find()` cannot find the requested character or substring, it returns `string::npos`.

Example:

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string word = "Hello";

    if (word.find("xyz") == string::npos) {
        cout << "Not found";
    }

    return 0;
}
```


```output
Not found
```

`string::npos` is used to represent that no matching position was found.

---

## 19. Empty Strings

A string can contain no characters.

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string message;

    if (message.empty()) {
        cout << "String is empty";
    }

    return 0;
}
```


```output
String is empty
```

The `empty()` function checks whether a string contains no characters.

---

## 20. Adding Characters to a String

The `push_back()` function adds one character to the end of a string.

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string word = "Hell";

    word.push_back('o');

    cout << word << endl;

    return 0;
}
```


```output
Hello
```

Here, the character `'o'` is added to the end.

---

## 21. Removing the Last Character

The `pop_back()` function removes the last character.

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string word = "Hello";

    word.pop_back();

    cout << word << endl;

    return 0;
}
```


```output
Hell
```

The last character `o` was removed.

---

## 22. Character Array vs `string`

C++ also supports strings using character arrays.

Example:

```cpp
char word[] = "Hello";
```

A character array stores individual characters.

The C++ `string` class provides many convenient functions for working with text.

For beginner C++ programs, `string` is usually easier to work with.

| Character Array                    | `string`                       |
| ---------------------------------- | ------------------------------ |
| Uses `char` elements               | Uses `string`                  |
| Size is fixed for a built-in array | Can change its size            |
| More manual operations             | Provides many useful functions |
| Common in C-style strings          | Common in modern C++           |

## 23. Real-World Example 🌍

Imagine a simple student profile program.

## 24. Common String Mistakes

### 1. Forgetting `<string>`

When using `string`, include:

```cpp
#include <string>
```

### 2. Using `cin` for a Full Name

This:

```cpp
cin >> name;
```

reads only up to whitespace.

Use:

```cpp
getline(cin, name);
```

when you need the complete line.

### 3. Using an Invalid Index

For:

```cpp
string word = "Hello";
```

the valid indexes are:

```text
0 1 2 3 4
```

Accessing `word[5]` is outside the string's valid character positions.

### 4. Confusing Characters and Strings

A character uses single quotes:

```cpp
'A'
```

A string uses double quotes:

```cpp
"Hello"
```

### 5. Forgetting That Indexing Starts at 0

The first character is at index `0`, not `1`.

* Strings can be joined using `+` or `+=`.
