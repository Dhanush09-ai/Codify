# Chapter 7: Arrays, Strings & Pointers

## Section 5: Dynamic Memory

Sometimes a program does not know how much memory it will need until the program is running.

C++ provides **dynamic memory allocation** to allocate memory while the program is running.

Dynamic memory is created in the **free store (commonly called the heap)** and can be controlled using pointers.

The main operators used for dynamic memory are:

* `new` — allocates memory.
* `delete` — releases memory.
* `new[]` — allocates memory for an array.
* `delete[]` — releases memory allocated for an array.

---

## 1. What is Dynamic Memory?

Normally, variables are created when their declarations are executed.

For example:

```cpp
int number = 10;
```

The memory required for `number` is managed automatically.

With dynamic memory, we can request memory while the program is running.

For example:

```cpp
int* ptr = new int;
```

This asks C++ for memory that can store one `int`.

The address of that memory is stored in `ptr`.

---

## 2. The `new` Operator

The `new` operator is used to dynamically allocate memory.

### Syntax

```cpp
dataType* pointer = new dataType;
```

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int* ptr = new int;

    *ptr = 50;

    cout << *ptr << endl;

    delete ptr;

    return 0;
}
```


```output
50
```

Here:

1. `new int` allocates memory for an integer.
2. The address is stored in `ptr`.
3. `*ptr = 50` stores `50` in that memory.
4. `delete ptr` releases the memory.

---

## 3. Initializing Dynamic Memory

Dynamic memory can also be initialized when it is allocated.

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int* ptr = new int(100);

    cout << *ptr << endl;

    delete ptr;

    return 0;
}
```


```output
100
```

The expression:

```cpp
new int(100)
```

allocates memory for an integer and initializes it with `100`.

---

## 4. The `delete` Operator

Memory allocated using `new` should be released using `delete`.

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int* ptr = new int(25);

    cout << *ptr << endl;

    delete ptr;

    return 0;
}
```


```output
25
```

The statement:

```cpp
delete ptr;
```

releases the dynamically allocated integer.

After deleting the memory, the pointer should not be dereferenced.

---

## 5. Why Do We Need `delete`?

If dynamically allocated memory is not released when it is no longer needed, the program can keep consuming memory.

This is called a **memory leak**.

For example:

```cpp
int* ptr = new int(50);
```

If the memory is no longer needed, release it:

```cpp
delete ptr;
```

A simple rule is:

> Every dynamically allocated object created with `new` should eventually be released with the appropriate `delete`.

---

## 6. Dynamic Arrays

We can dynamically create an array when the required size is known only at runtime.

The `new[]` operator is used for this.

### Syntax

```cpp
dataType* pointer = new dataType[size];
```

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int size = 5;

    int* numbers = new int[size];

    for (int i = 0; i < size; i++) {
        numbers[i] = (i + 1) * 10;
    }

    for (int i = 0; i < size; i++) {
        cout << numbers[i] << " ";
    }

    delete[] numbers;

    return 0;
}
```


```output
10 20 30 40 50
```

Here:

```cpp
new int[size]
```

creates an array of `size` integers dynamically.

---

## 7. `delete[]` for Dynamic Arrays

Memory allocated with `new[]` must be released using `delete[]`.

Correct:

```cpp
int* numbers = new int[5];

delete[] numbers;
```

Do not use ordinary `delete` for an array allocated with `new[]`.

### Remember

```text
new       → delete
new[]     → delete[]
```

---

## 8. Taking the Array Size from the User

Dynamic arrays are useful when the user provides the size at runtime.

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int size;

    cout << "Enter array size: ";
    cin >> size;

    int* numbers = new int[size];

    for (int i = 0; i < size; i++) {
        cout << "Enter number " << i + 1 << ": ";
        cin >> numbers[i];
    }

    cout << "Numbers: ";

    for (int i = 0; i < size; i++) {
        cout << numbers[i] << " ";
    }

    delete[] numbers;

    return 0;
}
```

### Example Output

```output
Enter array size: 3
Enter number 1: 10
Enter number 2: 20
Enter number 3: 30
Numbers: 10 20 30
```

The size of the array is decided while the program is running.

## 9. Dynamic Memory and Pointers

Dynamic memory and pointers are closely connected.

Consider:

```cpp
int* ptr = new int(50);
```

The memory looks conceptually like:

```text
ptr
 |
 | stores address
 ↓
┌─────────────┐
│     50      │
└─────────────┘
 dynamically allocated memory
```

The pointer stores the address of the dynamically allocated memory.

The expression:

```cpp
*ptr
```

accesses the value stored there.

---

## 10. Dynamic Memory for Different Data Types

Dynamic memory can be allocated for different types.

### Integer

```cpp
int* ptr = new int(10);
```

### Double

```cpp
double* ptr = new double(25.5);
```

### Character

```cpp
char* ptr = new char('A');
```

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    double* price = new double(99.50);

    cout << *price << endl;

    delete price;

    return 0;
}
```


```output
99.5
```

## 11. Changing Dynamically Allocated Values

The value stored in dynamically allocated memory can be changed through its pointer.

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int* number = new int(10);

    cout << *number << endl;

    *number = 50;

    cout << *number << endl;

    delete number;

    return 0;
}
```


```output
10
50
```

The pointer continues to refer to the same allocated memory while its stored value changes.

---

## 12. Dynamic Arrays and Loops

Dynamic arrays can be processed using normal array indexing.

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int size = 4;

    int* numbers = new int[size];

    for (int i = 0; i < size; i++) {
        numbers[i] = i + 1;
    }

    int sum = 0;

    for (int i = 0; i < size; i++) {
        sum += numbers[i];
    }

    cout << "Sum = " << sum << endl;

    delete[] numbers;

    return 0;
}
```


```output
Sum = 10
```

---

## 13. Dynamic Memory with `nullptr`

After releasing dynamically allocated memory, it is often useful to make the pointer `nullptr`.

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int* ptr = new int(50);

    cout << *ptr << endl;

    delete ptr;
    ptr = nullptr;

    return 0;
}
```

After:

```cpp
delete ptr;
ptr = nullptr;
```

the pointer no longer contains the old address.

This can help prevent accidentally using the pointer as if it still referred to a valid object.

---

## 14. Dangling Pointers

A pointer that still contains the address of memory after that memory has been released is called a **dangling pointer**.

For example:

```cpp
int* ptr = new int(50);

delete ptr;
```

After `delete`, `ptr` should not be dereferenced.

A safer practice is:

```cpp
delete ptr;
ptr = nullptr;
```

Now the pointer clearly indicates that it does not point to a valid object.

---

## 15. Dynamic Memory and Functions

A dynamically allocated object can be passed to a function using a pointer.

### Example

```cpp
#include <iostream>
using namespace std;

void display(int* ptr) {
    cout << *ptr << endl;
}

int main() {
    int* number = new int(75);

    display(number);

    delete number;

    return 0;
}
```


```output
75
```

The pointer is passed to the function, and the function accesses the dynamically allocated value through `*ptr`.

## 16. Dynamic Array Example

Let's create a program that finds the largest value in a dynamically allocated array.

```cpp
#include <iostream>
using namespace std;

int main() {
    int size;

    cout << "Enter size: ";
    cin >> size;

    int* numbers = new int[size];

    for (int i = 0; i < size; i++) {
        cin >> numbers[i];
    }

    int largest = numbers[0];

    for (int i = 1; i < size; i++) {
        if (numbers[i] > largest) {
            largest = numbers[i];
        }
    }

    cout << "Largest = " << largest << endl;

    delete[] numbers;

    return 0;
}
```

### Example Output

```output
Enter size: 5
10 45 23 67 31
Largest = 67
```

## 17. `new` vs Normal Variables

| Normal Variable                       | Dynamic Variable                   |
| ------------------------------------- | ---------------------------------- |
| Created automatically                 | Created using `new`                |
| Example: `int x;`                     | Example: `int* x = new int;`       |
| Managed automatically                 | Must be released with `delete`     |
| Fixed object declaration              | Can allocate memory at runtime     |
| Does not require a pointer for access | Usually accessed through a pointer |

Dynamic memory is useful when the amount of memory needed is determined during program execution.

---

## 18. `new` vs `new[]`

Use `new` for one object:

```cpp
int* ptr = new int;
```

Use `new[]` for an array:

```cpp
int* numbers = new int[5];
```

Release them with the matching operator:

```cpp
delete ptr;
delete[] numbers;
```

### Quick Table

| Allocation       | Release    |
| ---------------- | ---------- |
| `new int`        | `delete`   |
| `new double`     | `delete`   |
| `new int[5]`     | `delete[]` |
| `new double[10]` | `delete[]` |

## 19. Real-World Example 🌍

Imagine a program that manages the number of students in a classroom.

If the number of students is known only when the program starts, we can allocate an array based on that number.

For example:

```cpp
int students;

cin >> students;

int* marks = new int[students];
```

If the user enters:

```text
students = 40
```

the program creates space for 40 integer marks.

After the marks are no longer needed:

```cpp
delete[] marks;
```

This allows the program to request memory according to its runtime needs.

## 20. Common Mistakes

### Mistake 1: Forgetting `delete`

```cpp
int* ptr = new int(50);
```

If the memory is no longer needed, release it:

```cpp
delete ptr;
```

---

### Mistake 2: Using `delete` for an array

Incorrect:

```cpp
int* numbers = new int[5];

delete numbers;
```

Correct:

```cpp
int* numbers = new int[5];

delete[] numbers;
```

---

### Mistake 3: Using `delete[]` for a single object

Incorrect:

```cpp
int* ptr = new int(50);

delete[] ptr;
```

For a single object, use:

```cpp
delete ptr;
```

---

### Mistake 4: Using memory after deleting it

Avoid:

```cpp
int* ptr = new int(50);

delete ptr;

cout << *ptr;
```

The memory has already been released.

---

### Mistake 5: Accessing outside a dynamic array

If:

```cpp
int* numbers = new int[5];
```

the valid indexes are:

```text
0 1 2 3 4
```

Accessing an index outside that range is invalid.

---

## Key Points 🔑

* Dynamic memory is allocated while the program is running.
* `new` allocates memory for a single object.
* `delete` releases memory allocated with `new`.
* `new[]` allocates memory for an array.
* `delete[]` releases memory allocated with `new[]`.
* Dynamically allocated memory is normally accessed through pointers.
* Forgetting to release dynamic memory can cause memory leaks.
* A pointer should not be dereferenced after its memory has been released.
* Setting a pointer to `nullptr` after deletion can help avoid accidental use.
* Always match `new` with `delete` and `new[]` with `delete[]`.
