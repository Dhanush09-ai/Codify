# Chapter 5: Loops

## Section 1: Introduction to Loops

A **loop** is used to repeat a block of code multiple times.

For example, if we want to print `"Hello"` 10 times, writing `cout` 10 times would be unnecessary. A loop allows us to write the code once and repeat it.

Loops are useful when a task needs to be performed repeatedly.

---

## 1. Why Do We Need Loops?

Suppose we want to print numbers from `1` to `5`.

Without a loop:

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << 1 << " ";
    cout << 2 << " ";
    cout << 3 << " ";
    cout << 4 << " ";
    cout << 5 << " ";

    return 0;
}
```


```output
1 2 3 4 5
```

This works, but imagine printing numbers from `1` to `1000`. Writing 1000 statements would be inefficient.

A loop solves this problem.

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 5; i++) {
        cout << i << " ";
    }

    return 0;
}
```


```output
1 2 3 4 5
```

The same task can be completed with only a few lines of code.

---

## 2. What is a Loop?

A loop repeatedly executes a block of statements as long as a specified condition is satisfied.

A simple loop generally has three important parts:

1. **Initialization** – sets the starting value.
2. **Condition** – decides whether the loop should continue.
3. **Update** – changes the loop variable.

For example:

```cpp
for (int i = 1; i <= 5; i++) {
    cout << i << " ";
}
```

Here:

* `int i = 1` → Initialization
* `i <= 5` → Condition
* `i++` → Update

---

## 3. How a Loop Works

Consider this example:

```cpp
for (int i = 1; i <= 3; i++) {
    cout << i << " ";
}
```

The execution happens like this:

| Step | Value of `i` | Condition        | Action  |
| ---- | -----------: | ---------------- | ------- |
| 1    |            1 | `1 <= 3` → true  | Print 1 |
| 2    |            2 | `2 <= 3` → true  | Print 2 |
| 3    |            3 | `3 <= 3` → true  | Print 3 |
| 4    |            4 | `4 <= 3` → false | Stop    |


```output
1 2 3
```

The loop stops when the condition becomes false.

---

## 4. Types of Loops in C++

C++ provides three main types of loops:

### 1. `for` Loop

Used when we generally know how many times we want to repeat something.

```cpp
for (initialization; condition; update) {
    // statements
}
```

### 2. `while` Loop

Used when a block should repeat while a condition remains true.

```cpp
while (condition) {
    // statements
}
```

### 3. `do-while` Loop

Similar to a `while` loop, but it executes the loop body at least once.

```cpp
do {
    // statements
} while (condition);
```

---

## 5. for Loop

The `for` loop is commonly used when the number of iterations is known.

Example:

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 5; i++) {
        cout << "Hello\n";
    }

    return 0;
}
```


```output
Hello
Hello
Hello
Hello
Hello
```

The loop executes five times.

---

## 6. while Loop

The `while` loop checks its condition before executing the loop body.

Example:

```cpp
#include <iostream>
using namespace std;

int main() {
    int i = 1;

    while (i <= 5) {
        cout << i << " ";
        i++;
    }

    return 0;
}
```


```output
1 2 3 4 5
```

The loop continues while `i <= 5` is true.

---

## 7. do-while Loop

The `do-while` loop executes its body first and checks the condition afterward.

Example:

```cpp
#include <iostream>
using namespace std;

int main() {
    int i = 1;

    do {
        cout << i << " ";
        i++;
    } while (i <= 5);

    return 0;
}
```


```output
1 2 3 4 5
```

The important difference is that the body of a `do-while` loop executes at least once.

---

## 8. while vs do-while

Consider a condition that is already false.

### while Loop

```cpp
int i = 10;

while (i < 5) {
    cout << i;
}
```

The condition is false initially, so the loop body does not execute.

### do-while Loop

```cpp
int i = 10;

do {
    cout << i;
} while (i < 5);
```

The body executes once before the condition is checked.


```output
10
```

This is the main difference between `while` and `do-while`.

---

## 9. Choosing the Right Loop

Different loops are useful in different situations.

| Loop       | Best Used When                           |
| ---------- | ---------------------------------------- |
| `for`      | Number of repetitions is generally known |
| `while`    | Repetition depends on a condition        |
| `do-while` | The code must execute at least once      |

### Example situations

**for loop:**

Print numbers from `1` to `100`.

**while loop:**

Keep processing while a condition remains true.

**do-while loop:**

Display a menu at least once and then ask whether the user wants to continue.

---

## 10. Infinite Loops

An **infinite loop** is a loop that never ends because its condition never becomes false.

Example:

```cpp
while (true) {
    cout << "Hello";
}
```

The condition `true` always remains true, so the loop continues indefinitely.

Infinite loops can sometimes be intentional, but they must have a suitable way to stop when needed.

---

## 11. Avoiding Infinite Loops

A common reason for an accidental infinite loop is forgetting to update the loop variable.

Incorrect:

```cpp
int i = 1;

while (i <= 5) {
    cout << i << " ";
}
```

Here, `i` never changes, so `i <= 5` remains true.

Correct:

```cpp
int i = 1;

while (i <= 5) {
    cout << i << " ";
    i++;
}
```

Now the value of `i` increases and eventually the condition becomes false.

---

## 12. Loop Counter

A variable used to control the number of loop iterations is commonly called a **loop counter**.

Example:

```cpp
for (int i = 1; i <= 10; i++) {
    cout << i << " ";
}
```

Here, `i` is the loop counter.

It starts at `1` and increases by `1` after each iteration.

---

## 13. Increasing and Decreasing Loops

A loop does not always have to increase.

### Increasing

```cpp
for (int i = 1; i <= 5; i++) {
    cout << i << " ";
}
```


```output
1 2 3 4 5
```

### Decreasing

```cpp
for (int i = 5; i >= 1; i--) {
    cout << i << " ";
}
```


```output
5 4 3 2 1
```

The update expression determines how the loop variable changes.

---

## 14. Loop with a Different Step

We can increase or decrease the loop variable by values other than `1`.

Example:

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 2; i <= 10; i += 2) {
        cout << i << " ";
    }

    return 0;
}
```


```output
2 4 6 8 10
```

Here, `i += 2` increases the value by `2` after every iteration.

## 🌍 Real-World Example: Printing Student Roll Numbers

Suppose a teacher wants to display roll numbers from `1` to `10`.

A loop makes this simple:

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int roll = 1; roll <= 10; roll++) {
        cout << "Roll Number: " << roll << "\n";
    }

    return 0;
}
```


```output
Roll Number: 1
Roll Number: 2
Roll Number: 3
Roll Number: 4
Roll Number: 5
Roll Number: 6
Roll Number: 7
Roll Number: 8
Roll Number: 9
Roll Number: 10
```

The same idea can be used for processing students, products, records, or other repeated tasks.

## ⚠️ Common Mistakes

### 1. Forgetting the Update

```cpp
while (i <= 10) {
    cout << i;
}
```

Without changing `i`, the loop may never end.

---

### 2. Using the Wrong Condition

```cpp
for (int i = 1; i < 5; i++) {
    cout << i << " ";
}
```

This prints:

```output
1 2 3 4
```

If you want to include `5`, use `i <= 5`.

---

### 3. Creating an Infinite Loop Accidentally

Always check whether the loop variable can eventually make the condition false.

---

### 4. Confusing `i++` and `i--`

* `i++` increases `i` by `1`.
* `i--` decreases `i` by `1`.

Using the wrong update can produce unexpected results or an infinite loop.

---

## ⭐ Key Points

* Loops are used to repeat a block of code.
* The three main loops in C++ are `for`, `while`, and `do-while`.
* A `for` loop is useful when the number of repetitions is generally known.
* A `while` loop checks its condition before executing.
* A `do-while` loop executes its body at least once.
* Initialization sets the starting value.
* The condition determines whether the loop continues.
* The update changes the loop variable.
* An infinite loop occurs when the loop condition never becomes false.
* `break` and `continue` can also be used to control loops.
