# Chapter 5: Loops

## Section 2: while Loop

The `while` loop is used to repeatedly execute a block of code **as long as a condition is true**.

It is useful when we do not know exactly how many times the loop will run in advance.

---

## 1. What is a while Loop?

A `while` loop checks a condition before executing its body.

### Syntax

```cpp
while (condition) {
    // statements
}
```

The loop works like this:

1. The condition is checked.
2. If the condition is `true`, the loop body executes.
3. The condition is checked again.
4. This continues while the condition remains `true`.
5. When the condition becomes `false`, the loop stops.

---

## 2. Simple while Loop

Let's print numbers from `1` to `5`.

```cpp
#include <iostream>
using namespace std;

int main() {
    int i = 1;

    while (i <= 5) {
        cout << i << " ";
        i++;
    }

    return 0;
}
```


```output
1 2 3 4 5
```

Here:

* `i = 1` is the starting value.
* `i <= 5` is the condition.
* `i++` increases `i` after each iteration.

---

## 3. How a while Loop Works

Consider:

```cpp
int i = 1;

while (i <= 3) {
    cout << i << " ";
    i++;
}
```

The execution is:

| Step | `i` | Condition        | Action  |
| ---- | --: | ---------------- | ------- |
| 1    |   1 | `1 <= 3` → true  | Print 1 |
| 2    |   2 | `2 <= 3` → true  | Print 2 |
| 3    |   3 | `3 <= 3` → true  | Print 3 |
| 4    |   4 | `4 <= 3` → false | Stop    |


```output
1 2 3
```

The condition is checked before every iteration.

---

## 4. Initialization, Condition and Update

A `while` loop usually requires three important parts.

### Initialization

The loop variable is given its starting value.

```cpp
int i = 1;
```

### Condition

The condition determines whether the loop should continue.

```cpp
i <= 5
```

### Update

The loop variable is changed inside the loop.

```cpp
i++;
```

Complete example:

```cpp
int i = 1;

while (i <= 5) {
    cout << i << " ";
    i++;
}
```

If the update is missing, the loop may never end.

## 5. Counting Down with while

A `while` loop can also be used to count backwards.

```cpp
#include <iostream>
using namespace std;

int main() {
    int i = 5;

    while (i >= 1) {
        cout << i << " ";
        i--;
    }

    return 0;
}
```


```output
5 4 3 2 1
```

Here, `i--` decreases the value by `1` after every iteration.

## 6. Printing Even Numbers

We can use a `while` loop to print even numbers.

```cpp

int main() {
```


The value of `i` increases by `2` each time.

## 8. Sum of Numbers Using while

A `while` loop can be used to calculate the sum of numbers.

Let's find the sum of numbers from `1` to `5`.

```cpp
#include <iostream>
using namespace std;

int main() {
    int i = 1;
    int sum = 0;

    while (i <= 5) {
        sum += i;
        i++;
    }

    cout << "Sum = " << sum;

    return 0;
}
```


```output
Sum = 15
```

The calculation is:

```text
1 + 2 + 3 + 4 + 5 = 15
```

## 9. Multiplication Table Using while

A `while` loop can also generate a multiplication table.

```cpp
#include <iostream>

int main() {
    int number = 5;

    return 0;

```

## 10. while Loop with User Input

A `while` loop is useful when the number of repetitions depends on user input.

For example, we can keep asking for a number while the user enters a positive number.

```cpp
#include <iostream>
using namespace std;

int main() {
    int number;

    cout << "Enter a number: ";
    cin >> number;

    while (number > 0) {
        cout << "You entered: " << number << "\n";

        cout << "Enter another number: ";
        cin >> number;
    }

    cout << "Loop ended";

    return 0;
}
```

### Example Output

```output
Enter a number: 8
You entered: 8
Enter another number: 4
You entered: 4
Enter another number: 2
You entered: 2
Enter another number: 0
Loop ended
```

The loop continues while the entered number is greater than `0`.

## 11. while Loop with a Condition

The condition of a `while` loop can contain logical and relational operators.

Example:

```cpp
#include <iostream>
using namespace std;

int main() {
    int i = 1;

    while (i <= 10 && i != 6) {
        cout << i << " ";
        i++;
    }

    return 0;
}
```


```output
1 2 3 4 5
```

The loop stops when `i` becomes `6` because `i != 6` becomes false.

---

## 12. Infinite while Loop

An infinite loop occurs when the condition never becomes false.

Example:

```cpp
while (true) {
    cout << "Hello";
}
```

The condition `true` always remains true, so the loop continues indefinitely.

An infinite loop can also happen accidentally.

For example:

```cpp
int i = 1;

while (i <= 5) {
    cout << i << " ";
}
```

Here, `i` is never changed.

Therefore, `i <= 5` remains true.

---

## 13. Avoiding Infinite Loops

Always make sure that something inside the loop changes in a way that can eventually make the condition false.

Correct:

```cpp
int i = 1;

while (i <= 5) {
    cout << i << " ";
    i++;
}
```

The values of `i` become:

```text
1 → 2 → 3 → 4 → 5 → 6
```

When `i` becomes `6`, the condition `i <= 5` is false, so the loop stops.

---

## 14. while Loop vs for Loop

Both `while` and `for` loops can repeat code.

### for Loop

A `for` loop is convenient when the initialization, condition, and update are closely related.

```cpp
for (int i = 1; i <= 5; i++) {
    cout << i << " ";
}
```

### while Loop

A `while` loop is useful when the condition is the main focus and the number of repetitions may depend on changing conditions.

```cpp
int i = 1;

while (i <= 5) {
    cout << i << " ";
    i++;
}
```

Both programs produce:

```output
1 2 3 4 5
```

---

## 15. Using break with while

The `break` statement can stop a `while` loop before its condition becomes false.

```cpp
#include <iostream>
using namespace std;

int main() {
    int i = 1;

    while (i <= 10) {
        if (i == 6) {
            break;
        }

        cout << i << " ";
        i++;
    }

    return 0;
}
```


```output
1 2 3 4 5
```

When `i` becomes `6`, `break` immediately exits the loop.

---

## 16. Using continue with while

The `continue` statement skips the remaining statements in the current iteration.

```cpp
#include <iostream>
using namespace std;

int main() {
    int i = 0;

    while (i < 5) {
        i++;

        if (i == 3) {
            continue;
        }

        cout << i << " ";
    }

    return 0;
}
```


```output
1 2 4 5
```

The value `3` is skipped.

## 🌍 Real-World Example: Entering a Password

A `while` loop can be used to repeatedly ask for input until a condition is satisfied.

For example, suppose a program asks the user to enter a specific numeric code.

```cpp
#include <iostream>
using namespace std;

int main() {
    int code;

    cout << "Enter code: ";
    cin >> code;

    while (code != 1234) {
        cout << "Incorrect code. Try again: ";
        cin >> code;
    }

    cout << "Correct code";

    return 0;
}
```

### Example Output

```output
Enter code: 1000
Incorrect code. Try again: 2500
Incorrect code. Try again: 1234
Correct code
```

The loop continues until the required condition is satisfied.

## ⚠️ Common Mistakes

### 1. Forgetting to Update the Loop Variable

Incorrect:

```cpp
int i = 1;

while (i <= 5) {
    cout << i << " ";
}
```

The value of `i` never changes, so the loop can become infinite.

Correct:

```cpp
int i = 1;

while (i <= 5) {
    cout << i << " ";
    i++;
}
```

---

### 2. Putting the Semicolon After while

Be careful with this:

```cpp
while (i <= 5);
{
    cout << i;
}
```

The semicolon makes the `while` statement have an empty body, which can cause unexpected behavior.

---

### 3. Using the Wrong Update

For example:

```cpp
int i = 5;

while (i >= 1) {
    cout << i << " ";
    i++;
}
```

Here, `i` increases instead of decreasing, so the condition may never become false.

For counting down, use:

```cpp
i--;
```

---

### 4. Wrong Boundary Condition

Compare:

```cpp
i < 5
```

with:

```cpp
i <= 5
```

The first stops before `5`, while the second includes `5`.

---

## ⭐ Key Points

* A `while` loop repeats code while a condition is true.
* The condition is checked before every iteration.
* A `while` loop may execute zero times if its condition is initially false.
* Initialization is normally done before the loop.
* The loop variable should be updated so the loop can eventually stop.
* `break` can stop a `while` loop immediately.
* `continue` can skip the current iteration.
* A missing or incorrect update can create an infinite loop.
* `while` loops are useful when the number of repetitions depends on a condition.
