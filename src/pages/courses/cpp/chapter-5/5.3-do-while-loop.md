# Chapter 5: Loops

## Section 3: do-while Loop

The `do-while` loop is used to repeatedly execute a block of code while a condition is true.

The main difference between a `do-while` loop and a `while` loop is that the `do-while` loop **executes its body at least once** before checking the condition.

---

## 1. What is a do-while Loop?

A `do-while` loop executes the loop body first and checks the condition afterward.

### Syntax

```cpp
do {
    // statements
} while (condition);
```

Notice the semicolon `;` after the `while` condition.

### How it works

1. The loop body executes.
2. The condition is checked.
3. If the condition is `true`, the loop executes again.
4. If the condition is `false`, the loop stops.

---

## 2. Simple do-while Example

Let's print numbers from `1` to `5`.

```cpp
#include <iostream>
using namespace std;

int main() {
    int i = 1;

    do {
        cout << i << " ";
        i++;
    } while (i <= 5);

    return 0;
}
```


```output
1 2 3 4 5
```

The loop prints the value and then checks whether `i <= 5`.

---

## 3. How a do-while Loop Works

Consider:

```cpp
int i = 1;

do {
    cout << i << " ";
    i++;
} while (i <= 3);
```

The execution is:

| Step | Value of `i` | Action  | Condition        |
| ---- | -----------: | ------- | ---------------- |
| 1    |            1 | Print 1 | `2 <= 3` → true  |
| 2    |            2 | Print 2 | `3 <= 3` → true  |
| 3    |            3 | Print 3 | `4 <= 3` → false |


```output
1 2 3
```

The condition is checked **after** each iteration.

---

## 4. do-while Executes at Least Once

This is the most important feature of a `do-while` loop.

Consider:

```cpp
#include <iostream>
using namespace std;

int main() {
    int i = 10;

    do {
        cout << i;
    } while (i < 5);

    return 0;
}
```


```output
10
```

Even though `i < 5` is false, the loop body executes once.

Why?

Because the condition is checked **after** the loop body.

---

## 5. do-while vs while

The main difference is when the condition is checked.

### while Loop

```cpp
int i = 10;

while (i < 5) {
    cout << i;
}
```

The condition is false initially, so the body does not execute.

### do-while Loop

```cpp
int i = 10;

do {
    cout << i;
} while (i < 5);
```

The body executes once before the condition is checked.


```output
10
```

### Difference

| `while`                                          | `do-while`                       |
| ------------------------------------------------ | -------------------------------- |
| Checks condition first                           | Checks condition after the body  |
| May execute zero times                           | Executes at least once           |
| Syntax does not end with `;` after the condition | Requires `;` after the condition |

---

## 6. Counting with do-while

A `do-while` loop can be used to count upwards.

```cpp
#include <iostream>
using namespace std;

int main() {
    int i = 1;

    do {
        cout << i << " ";
        i++;
    } while (i <= 5);

    return 0;
}
```


```output
1 2 3 4 5
```

Here:

* `i = 1` → initialization
* `i <= 5` → condition
* `i++` → update

---

## 7. Counting Down with do-while

A `do-while` loop can also count backwards.

```cpp
#include <iostream>
using namespace std;

int main() {
    int i = 5;

    do {
        cout << i << " ";
        i--;
    } while (i >= 1);

    return 0;
}
```


```output
5 4 3 2 1
```

The `i--` expression decreases the value after each iteration.

---

## 8. Printing Even Numbers

We can use a `do-while` loop to print even numbers.

```cpp
#include <iostream>
using namespace std;

int main() {
    int i = 2;

    do {
        cout << i << " ";
        i += 2;
    } while (i <= 10);

    return 0;
}
```


```output
2 4 6 8 10
```

The value increases by `2` after every iteration.

## 9. Sum of Numbers Using do-while

A `do-while` loop can also be used to calculate a sum.

Let's find the sum of numbers from `1` to `5`.

```cpp
#include <iostream>
using namespace std;

int main() {
    int i = 1;
    int sum = 0;

    do {
        sum += i;
        i++;
    } while (i <= 5);

    cout << "Sum = " << sum;

    return 0;
}
```


```output
Sum = 15
```

The calculation is:

```text
1 + 2 + 3 + 4 + 5 = 15
```

## 10. do-while with User Input

A `do-while` loop is especially useful when we want to take input at least once.

For example, we can ask the user to enter a positive number.

```cpp
#include <iostream>
using namespace std;

int main() {
    int number;

    do {
        cout << "Enter a positive number: ";
        cin >> number;
    } while (number <= 0);

    cout << "You entered: " << number;

    return 0;
}
```

### Example Output

```output
Enter a positive number: -5
Enter a positive number: 0
Enter a positive number: 8
You entered: 8
```

The program asks for input at least once and continues asking while the entered number is not positive.

## 11. Menu Using do-while

A common use of `do-while` is a menu that should be displayed at least once.

```cpp
#include <iostream>
using namespace std;

int main() {
    int choice;

    do {
        cout << "\n1. Start\n";
        cout << "2. Settings\n";
        cout << "3. Exit\n";
        cout << "Enter your choice: ";
        cin >> choice;

        switch (choice) {
            case 1:
                cout << "Starting...";
                break;

            case 2:
                cout << "Opening Settings...";
                break;

            case 3:
                cout << "Exiting...";
                break;

            default:
                cout << "Invalid choice";
        }

    } while (choice != 3);

    return 0;
}
```

### Example Output

```output
1. Start
2. Settings
3. Exit
Enter your choice: 1
Starting...
1. Start
2. Settings
3. Exit
Enter your choice: 3
Exiting...
```

The menu is displayed at least once and continues until the user chooses `3`.

---

## 12. Using break with do-while

The `break` statement can immediately stop a `do-while` loop.

```cpp
#include <iostream>
using namespace std;

int main() {
    int i = 1;

    do {
        if (i == 4) {
            break;
        }

        cout << i << " ";
        i++;
    } while (i <= 10);

    return 0;
}
```


```output
1 2 3
```

When `i` becomes `4`, `break` stops the loop.

---

## 13. Using continue with do-while

The `continue` statement skips the remaining statements of the current iteration.

```cpp
#include <iostream>
using namespace std;

int main() {
    int i = 0;

    do {
        i++;

        if (i == 3) {
            continue;
        }

        cout << i << " ";
    } while (i < 5);

    return 0;
}
```


```output
1 2 4 5
```

The value `3` is skipped.

When using `continue` in a `do-while` loop, make sure the loop variable is updated correctly so that the loop can eventually end.

---

## 14. Infinite do-while Loop

A `do-while` loop can also become infinite.

Example:

```cpp
do {
    cout << "Hello";
} while (true);
```

The condition is always `true`, so the loop continues indefinitely.

An infinite loop can also happen accidentally if the condition never becomes false.

---

## 15. Avoiding Infinite Loops

Always make sure that the values involved in the condition change when necessary.

Incorrect:

```cpp
int i = 1;

do {
    cout << i << " ";
} while (i <= 5);
```

Here, `i` never changes, so the condition remains true.

Correct:

```cpp
int i = 1;

do {
    cout << i << " ";
    i++;
} while (i <= 5);
```

Now `i` eventually becomes `6`, making the condition false.

---

## 16. When to Use a do-while Loop

A `do-while` loop is useful when the code must execute **at least once**.

Common examples include:

* Displaying a menu
* Asking for user input
* Repeating a program based on user choice
* Input validation
* Programs that need an initial action before checking whether to continue

---

## 🌍 Real-World Example: Continue a Program

Suppose a program asks the user whether they want to continue.

```cpp
#include <iostream>
using namespace std;

int main() {
    char choice;

    do {
        cout << "Program is running.\n";
        cout << "Do you want to continue? (y/n): ";
        cin >> choice;

    } while (choice == 'y');

    cout << "Program ended.";

    return 0;
}
```

### Example Output

```output
Program is running.
Do you want to continue? (y/n): y
Program is running.
Do you want to continue? (y/n): y
Program is running.
Do you want to continue? (y/n): n
Program ended.
```

The program runs once before checking whether the user wants to continue.

## ⚠️ Common Mistakes

### 1. Forgetting the Semicolon

A `do-while` statement must end with a semicolon.

Correct:

```cpp
do {
    cout << "Hello";
} while (condition);
```

The `;` after `while (condition)` is required.

---

### 2. Confusing while and do-while

Remember:

```text
while     → condition first
do-while  → body first
```

---

### 3. Forgetting to Update the Loop Variable

Incorrect:

```cpp
int i = 1;

do {
    cout << i;
} while (i <= 5);
```

The value of `i` never changes, so the loop can become infinite.

---

### 4. Using the Wrong Condition

Be careful with conditions such as:

```cpp
i < 5
```

and:

```cpp
i <= 5
```

They do not produce the same number of iterations.

---

### 5. Incorrect Update with continue

When using `continue`, make sure the loop variable is updated correctly before the next condition check.

---

## ⭐ Key Points

* A `do-while` loop executes its body before checking the condition.
* A `do-while` loop always executes at least once.
* The condition is checked after each iteration.
* A semicolon `;` is required after the `while` condition.
* It is useful for menus and input validation.
* `break` can stop the loop immediately.
* `continue` can skip the current iteration.
* The loop variable should be updated when necessary.
* A missing update can cause an infinite loop.
