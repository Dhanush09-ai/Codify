# Chapter 5: Loops

## Section 4: for Loop

The `for` loop is one of the most commonly used loops in C++.

It is useful when we generally know how many times a block of code should execute.

For example, if we want to print numbers from `1` to `10`, a `for` loop allows us to write the repetition in a compact way.

---

## 1. What is a for Loop?

A `for` loop repeatedly executes a block of code while its condition is true.

### Syntax

```cpp
for (initialization; condition; update) {
    // statements
}
```

The `for` loop has three main parts:

1. **Initialization** – sets the starting value.
2. **Condition** – determines whether the loop continues.
3. **Update** – changes the loop variable after each iteration.

---

## 2. Simple for Loop

Let's print numbers from `1` to `5`.

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 5; i++) {
        cout << i << " ";
    }

    return 0;
}
```


```output
1 2 3 4 5
```

Here:

* `int i = 1` → Initialization
* `i <= 5` → Condition
* `i++` → Update

---

## 3. How a for Loop Works

Consider:

```cpp
for (int i = 1; i <= 3; i++) {
    cout << i << " ";
}
```

The execution happens in this order:

1. `i` is initialized to `1`.
2. `i <= 3` is checked.
3. The loop body executes.
4. `i++` increases `i`.
5. The condition is checked again.
6. The process continues until the condition becomes false.

### Execution Table

| Step | `i` | Condition        | Action  |
| ---- | --: | ---------------- | ------- |
| 1    |   1 | `1 <= 3` → true  | Print 1 |
| 2    |   2 | `2 <= 3` → true  | Print 2 |
| 3    |   3 | `3 <= 3` → true  | Print 3 |
| 4    |   4 | `4 <= 3` → false | Stop    |


```output
1 2 3
```

---

## 4. Initialization in a for Loop

Initialization is executed only once, when the loop starts.

Example:

```cpp
for (int i = 1; i <= 5; i++) {
    cout << i << " ";
}
```

The statement:

```cpp
int i = 1
```

creates the loop variable and gives it an initial value of `1`.

The initialization does not execute again for every iteration.

---

## 5. Condition in a for Loop

The condition determines whether the loop body should execute.

Example:

```cpp
for (int i = 1; i <= 5; i++) {
    cout << i << " ";
}
```

The condition is:

```cpp
i <= 5
```

When the condition is true, the loop body executes.

When the condition becomes false, the loop stops.

---

## 6. Update in a for Loop

The update expression runs after each iteration.

For example:

```cpp
for (int i = 1; i <= 5; i++) {
    cout << i << " ";
}
```

The update is:

```cpp
i++
```

It increases `i` by `1`.

We can also use other updates.

### Increase by 2

```cpp
for (int i = 2; i <= 10; i += 2) {
    cout << i << " ";
}
```


```output
2 4 6 8 10
```

---

## 7. Counting Backwards

A `for` loop can also be used to count backwards.

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 5; i >= 1; i--) {
        cout << i << " ";
    }

    return 0;
}
```


```output
5 4 3 2 1
```

Here:

* Starting value → `5`
* Condition → `i >= 1`
* Update → `i--`

---

## 8. Printing Even Numbers

We can use a `for` loop to print even numbers.

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 2; i <= 10; i += 2) {
        cout << i << " ";
    }

    return 0;
}
```


```output
2 4 6 8 10
```

The loop increases `i` by `2` each time.

## 10. Finding the Sum Using a for Loop

A `for` loop can be used to calculate the sum of numbers.

Let's find the sum from `1` to `5`.

```cpp
#include <iostream>
using namespace std;

int main() {
    int sum = 0;

    for (int i = 1; i <= 5; i++) {
        sum += i;
    }

    cout << "Sum = " << sum;

    return 0;
}
```


```output
Sum = 15
```

The calculation is:

```text
1 + 2 + 3 + 4 + 5 = 15
```

## 11. Multiplication Table Using for

A `for` loop is commonly used to generate multiplication tables.

```cpp
#include <iostream>
using namespace std;

int main() {
    int number = 5;

    for (int i = 1; i <= 10; i++) {
        cout << number << " x " << i << " = " << number * i << "\n";
    }

    return 0;
}
```


```output

5 x 3 = 15
5 x 4 = 20
5 x 5 = 25
5 x 6 = 30
5 x 7 = 35
5 x 8 = 40
```

## 12. Multiple Statements in a for Loop

A `for` loop can contain multiple statements in its body.

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 3; i++) {
        cout << "Number: " << i << "\n";
        cout << "Square: " << i * i << "\n";
    }

    return 0;
}
```


```output
Number: 1
Square: 1
Number: 2
Square: 4
Number: 3
Square: 9
```

The braces `{ }` group multiple statements into the loop body.

---

## 13. for Loop with Multiple Variables

A `for` loop can initialize and update more than one variable.

Example:

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1, j = 5; i <= 5; i++, j--) {
        cout << i << " " << j << "\n";
    }

    return 0;
}
```


```output
1 5
2 4
3 3
4 2
5 1
```

Here, both `i` and `j` are updated after each iteration.

---

## 14. Omitting Parts of a for Loop

The three parts of a `for` loop can technically be omitted.

For example, initialization can be written outside the loop:

```cpp
int i = 1;

for (; i <= 5; i++) {
    cout << i << " ";
}
```

The initialization section is empty, but the semicolon is still required.

Similarly, the update can be written inside the loop:

```cpp
int i = 1;

for (; i <= 5;) {
    cout << i << " ";
    i++;
}
```

Although these forms are valid, keeping initialization, condition, and update in the `for` header is usually clearer for beginners.

---

## 15. Infinite for Loop

A `for` loop can also be made infinite.

```cpp
for (;;) {
    cout << "Hello";
}
```

All three sections are omitted, so there is no condition that becomes false.

An infinite loop can also happen accidentally.

For example:

```cpp
for (int i = 1; i <= 5; i--) {
    cout << i << " ";
}
```

Here, `i` decreases even though the condition requires `i <= 5`, so the condition will remain true after the loop starts.

---

## 16. Using break with for

The `break` statement can stop a `for` loop immediately.

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 10; i++) {
        if (i == 6) {
            break;
        }

        cout << i << " ";
    }

    return 0;
}
```


```output
1 2 3 4 5
```

When `i` becomes `6`, `break` exits the loop.

---

## 17. Using continue with for

The `continue` statement skips the current iteration.

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 5; i++) {
        if (i == 3) {
            continue;
        }

        cout << i << " ";
    }

    return 0;
}
```


```output
1 2 4 5
```

The value `3` is skipped, but the loop continues.

---

## 18. for Loop vs while Loop

Both loops can perform repeated tasks.

### for Loop

```cpp
for (int i = 1; i <= 5; i++) {
    cout << i << " ";
}
```

### while Loop

```cpp
int i = 1;

while (i <= 5) {
    cout << i << " ";
    i++;
}
```

Both produce:

```output
1 2 3 4 5
```

The `for` loop is often more convenient when initialization, condition, and update are closely related.

## 🌍 Real-World Example: Processing Student Marks

Suppose a teacher wants to process the marks of 5 students.

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int student = 1; student <= 5; student++) {
        cout << "Processing student " << student << "\n";
    }

    return 0;
}
```


```output
Processing student 1
Processing student 2
Processing student 3
Processing student 4
Processing student 5
```

The same idea can be used for processing products, records, transactions, or other repeated data.

## ⚠️ Common Mistakes

### 1. Using the Wrong Condition

```cpp
for (int i = 1; i < 5; i++) {
    cout << i << " ";
}
```

Output:

```output
1 2 3 4
```

If `5` should also be printed, use:

```cpp
for (int i = 1; i <= 5; i++) {
    cout << i << " ";
}
```

---

### 2. Using the Wrong Update

Be careful with `i++` and `i--`.

```cpp
for (int i = 1; i <= 5; i++) {
    cout << i << " ";
}
```

counts upward.

```cpp
for (int i = 5; i >= 1; i--) {
    cout << i << " ";
}
```

counts downward.

---

### 3. Forgetting the Semicolons in the Header

The three parts of a `for` loop are separated by semicolons.

Correct:

```cpp
for (int i = 1; i <= 5; i++) {
    cout << i;
}
```

There are two semicolons inside the `for` header.

---

### 4. Accidentally Creating an Infinite Loop

Make sure the update moves the loop variable toward a value that makes the condition false.

---

### 5. Extra Semicolon After the for Statement

Be careful with:

```cpp
for (int i = 1; i <= 5; i++);
{
    cout << i;
}
```

The semicolon creates an empty loop body and can cause unexpected behavior.

---

## ⭐ Key Points

* A `for` loop repeats a block of code.
* It has three main parts: initialization, condition, and update.
* Initialization runs once at the beginning.
* The condition is checked before each iteration.
* The update runs after each iteration.
* A `for` loop can count upward or downward.
* `break` can stop the loop immediately.
* `continue` can skip the current iteration.
* The `for` loop is convenient when the loop control is known clearly.
* Incorrect conditions or updates can create unexpected results or infinite loops.
