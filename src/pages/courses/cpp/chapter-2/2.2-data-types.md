# Chapter 2: C++ Basics

## Section 2: Data Types

Data types tell C++ **what kind of data** a variable can store.

For example, a variable may store a whole number, decimal number, character, or a true/false value.

```cpp
int age = 18;
double price = 99.50;
char grade = 'A';
bool passed = true;
```

Each variable uses a data type that matches the kind of value it stores.

---

## 1. What is a Data Type?

A **data type** specifies:

* What kind of value a variable can store.
* How the value should be treated by the program.
* What operations can be performed on that value.

### Basic Syntax

```cpp
dataType variableName = value;
```

Example:

```cpp
int marks = 95;
```

Here:

* `int` → data type
* `marks` → variable name
* `95` → value

---

## 2. Common C++ Data Types

Some commonly used C++ data types are:

| Data Type | Used For                            | Example   |
| --------- | ----------------------------------- | --------- |
| `int`     | Whole numbers                       | `25`      |
| `float`   | Decimal numbers                     | `12.5f`   |
| `double`  | Decimal numbers with more precision | `12.5`    |
| `char`    | A single character                  | `'A'`     |
| `bool`    | True or false values                | `true`    |
| `string`  | Text                                | `"Hello"` |

The first five are fundamental types. `string` is a C++ library type used to store text.

---

## 3. Integer Type — `int`

The `int` data type is used to store **whole numbers**.

Examples:

```cpp
int age = 18;
int marks = 95;
int temperature = 30;
```

Negative numbers can also be stored:

```cpp
int balance = -500;
```

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int age = 18;
    int marks = 95;

    cout << age << "\n";
    cout << marks;

    return 0;
}
```

```output
18
95
```

---

## 4. Decimal Types — `float` and `double`

`float` and `double` are used to store decimal numbers.

### `float`

```cpp
float price = 25.5f;
```

The `f` suffix is commonly used to indicate a `float` value.

### `double`

```cpp
double distance = 125.75;
```

`double` generally provides more precision than `float`.

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    float temperature = 36.5f;
    double price = 999.99;

    cout << temperature << "\n";
    cout << price;

    return 0;
}
```

```output
36.5
999.99
```

### `float` vs `double`

| Type     | Example | Typical Use                                  |
| -------- | ------- | -------------------------------------------- |
| `float`  | `12.5f` | Decimal values when less precision is enough |
| `double` | `12.5`  | Decimal values when more precision is needed |

For most beginner programs, `double` is a good choice when working with decimal calculations.

---

## 5. Character Type — `char`

The `char` data type stores **a single character**.

A character is written inside single quotes.

```cpp
char grade = 'A';
char symbol = '#';
char digit = '5';
```

Example:

```cpp
#include <iostream>
using namespace std;

int main() {
    char grade = 'A';

    cout << grade;

    return 0;
}
```

```output
A
```

### Important

`'A'` and `"A"` are different.

```cpp
char letter = 'A';
```

Here, `'A'` is a single character.

```cpp
string text = "A";
```

Here, `"A"` is text containing one character.

---

## 6. Boolean Type — `bool`

The `bool` data type stores one of two logical values:

* `true`
* `false`

Example:

```cpp
bool isStudent = true;
bool isPassed = false;
```

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    bool isStudent = true;
    bool isPassed = false;

    cout << isStudent << "\n";
    cout << isPassed;

    return 0;
}
```

```output
1
0
```

By default, `cout` displays:

* `true` as `1`
* `false` as `0`

You can also use `boolalpha` to display the words:

```cpp
#include <iostream>
using namespace std;

int main() {
    bool isPassed = true;

    cout << boolalpha << isPassed;

    return 0;
}
```

```output
true
```

---

## 7. String Type — `string`

A `string` is used to store text.

To use `string`, include the `<string>` header.

```cpp
#include <string>
```

Example:

```cpp
string name = "Owais";
```

A string can contain multiple characters:

```cpp
string message = "Welcome to Codify";
```

### Example

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string name = "Owais";

    cout << name;

    return 0;
}
```

```output
Owais
```

### Character vs String

```cpp
char grade = 'A';
string name = "Owais";
```

* `char` stores one character.
* `string` stores text containing multiple characters.

---

## 8. Checking the Size of a Data Type

C++ provides the `sizeof` operator to find how many bytes a type or variable occupies.

Example:

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << sizeof(int) << "\n";
    cout << sizeof(double) << "\n";
    cout << sizeof(char) << "\n";
    cout << sizeof(bool);

    return 0;
}
```

The exact sizes of some types can depend on the compiler and system.

For example, `char` is always 1 byte, while the sizes of other types may vary.

## 9. Choosing the Correct Data Type

Choose a data type based on the kind of data you need to store.

| Data               | Suitable Type |
| ------------------ | ------------- |
| Student age        | `int`         |
| Number of students | `int`         |
| Product price      | `double`      |
| Temperature        | `double`      |
| Grade letter       | `char`        |
| Login status       | `bool`        |
| Student name       | `string`      |

### Example

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string name = "Owais";
    int age = 18;
    double percentage = 95.5;
    char grade = 'A';
    bool passed = true;

    cout << name << "\n";
    cout << age << "\n";
    cout << percentage << "\n";
    cout << grade << "\n";
    cout << boolalpha << passed;

    return 0;
}
```

```output
Owais
18
95.5
A
true
```

Different data types allow the program to represent different kinds of information.

## 10. Real-World Example 🌍

Imagine a student information system.

A student's information may contain:

```cpp
string name = "Owais";
int age = 18;
double percentage = 95.5;
char grade = 'A';
bool passed = true;
```

Each value uses a suitable data type:

* `name` → `string`
* `age` → `int`
* `percentage` → `double`
* `grade` → `char`
* `passed` → `bool`

This makes the program organized and easier to understand.

## Common Mistakes

### Mistake 1: Using double quotes for a `char`

Incorrect:

```cpp
char grade = "A";
```

Correct:

```cpp
char grade = 'A';
```

---

### Mistake 2: Using single quotes for a string

Incorrect:

```cpp
string name = 'Owais';
```

Correct:

```cpp
string name = "Owais";
```

---

### Mistake 3: Forgetting the `f` suffix for a float

A float literal can be written as:

```cpp
float price = 25.5f;
```

Without the suffix:

```cpp
float price = 25.5;
```

the literal `25.5` is a `double` literal that is then converted to `float`.

---

### Mistake 4: Using the wrong data type

For example:

```cpp
char age = 18;
```

A person's age should normally be stored using an integer type:

```cpp
int age = 18;
```

---

## Key Points

* A data type tells C++ what kind of data a variable stores.
* `int` is used for whole numbers.
* `float` and `double` are used for decimal values.
* `char` stores a single character.
* `bool` stores `true` or `false`.
* `string` stores text.
* Single quotes are used for characters: `'A'`.
* Double quotes are used for strings: `"Hello"`.
* `sizeof` can be used to find the size of a type or variable.
* Choosing the correct data type makes programs easier to design and understand.
