# Chapter 2: C++ Basics

## Section 5: Comments & Basic Syntax

Comments and basic syntax are important parts of every C++ program.

**Comments** help explain code to humans, while **syntax** refers to the rules that C++ programs must follow.

Understanding these basics makes your programs easier to write, read, and debug.

---

## 1. What are Comments?

A **comment** is text written inside a program that is ignored by the compiler.

Comments are mainly used to:

* Explain what the code does.
* Make code easier to understand.
* Add notes for yourself or other programmers.
* Temporarily disable a line of code.

C++ provides two common types of comments:

1. Single-line comments
2. Multi-line comments

---

## 2. Single-Line Comments

A single-line comment starts with `//`.

Everything after `//` on that line is treated as a comment.

```cpp
// This is a comment
```

Example:

```cpp
#include <iostream>
using namespace std;

int main() {
    // Store the student's age
    int age = 18;

    cout << age;

    return 0;
}
```

```output
18
```

The compiler ignores:

```cpp
// Store the student's age
```

and executes the actual C++ statements.

---

## 3. Comments After Code

You can also write a comment after a C++ statement.

```cpp
int age = 18; // Student's age
```

Example:

```cpp
#include <iostream>
using namespace std;

int main() {
    int marks = 95; // Student's marks

    cout << marks;

    return 0;
}
```

```output
95
```

The comment does not affect the program's output.

---

## 4. Multi-Line Comments

A multi-line comment starts with `/*` and ends with `*/`.

Everything between these symbols is treated as a comment.

```cpp
/*
   This is a
   multi-line comment.
*/
```

Example:

```cpp
#include <iostream>
using namespace std;

int main() {
    /*
       Store and display
       the student's age.
    */

    int age = 18;

    cout << age;

    return 0;
}
```

```output
18
```

Multi-line comments are useful when you need to write a longer explanation.

---

## 5. Single-Line vs Multi-Line Comments

| Comment Type | Syntax      | Use             |
| ------------ | ----------- | --------------- |
| Single-line  | `//`        | Short comments  |
| Multi-line   | `/* ... */` | Longer comments |

### Example

Single-line:

```cpp
// Calculate total marks
```

Multi-line:

```cpp
/*
   Calculate the total
   marks of the student.
*/
```

---

## 6. What is C++ Syntax?

**Syntax** means the rules for writing valid C++ code.

Just like a language has grammar rules, C++ has syntax rules.

For example:

```cpp
int age = 18;
```

is valid C++ syntax.

But:

```cpp
int = age 18;
```

is not valid syntax.

If the syntax is incorrect, the compiler reports an error.

---

## 7. Statements and Semicolons

Most C++ statements end with a semicolon `;`.

Example:

```cpp
int age = 18;
cout << age;
```

Each statement is separated using `;`.

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int number = 10;
    int result = number * 2;

    cout << result;

    return 0;
}
```

```output
20
```

Forgetting a semicolon can cause a compilation error.

Incorrect:

```cpp
int age = 18
```

Correct:

```cpp
int age = 18;
```

---

## 8. C++ is Case-Sensitive

C++ is **case-sensitive**.

This means uppercase and lowercase letters are treated as different.

For example:

```cpp
int age = 18;
int Age = 20;
```

`age` and `Age` are two different variable names.

Similarly:

```cpp
cout
```

and

```cpp
Cout
```

are not the same.

C++ keywords and identifiers must be written using the correct capitalization.

---

## 9. Curly Braces `{ }`

Curly braces are used to define a **block of code**.

For example:

```cpp
int main() {
    cout << "Hello";
}
```

The statements between `{` and `}` belong to the `main()` function.

Curly braces are also used with control statements and other parts of C++.

Example:

```cpp
if (age >= 18) {
    cout << "Adult";
}
```

The braces define the statements controlled by the `if` statement.

---

## 10. Parentheses `( )`

Parentheses are used in several places in C++.

For example, they are used when defining or calling functions:

```cpp
int main()
```

They are also used with conditions:

```cpp
if (age >= 18)
```

and calculations:

```cpp
int result = (10 + 5) * 2;
```

Parentheses help group expressions and make the structure of the program clear.

---

## 11. C++ Identifiers

An **identifier** is a name given to something in a program, such as a variable or function.

Examples:

```cpp
age
studentName
totalMarks
calculateSum
```

### Basic Rules for Identifiers

1. They can contain letters, digits, and `_`.
2. They cannot start with a digit.
3. They cannot contain spaces.
4. C++ keywords cannot be used as identifiers.
5. They are case-sensitive.

### Valid

```cpp
studentName
marks1
_total
```

### Invalid

```cpp
1student
student name
total-marks
```

---

## 12. Keywords

**Keywords** are reserved words that have special meanings in C++.

Examples include:

```cpp
int
double
char
if
else
for
while
return
class
const
```

You cannot normally use these reserved words as variable or function names.

For example:

```cpp
int return = 10;
```

is invalid because `return` is a C++ keyword.

---

## 13. Whitespace and Indentation

C++ generally ignores extra spaces, tabs, and line breaks between tokens.

For example, these can work the same way:

```cpp
int age = 18;
```

and:

```cpp
int    age    =    18;
```

However, proper spacing and indentation make code easier to read.

Recommended style:

```cpp
int age = 18;
int marks = 95;

cout << age << "\n";
cout << marks;
```

Instead of writing everything on one line:

```cpp
int age=18;int marks=95;cout<<age<<"\n";cout<<marks;
```

Readable code is easier to understand and maintain.

---

## 14. Basic Structure of a C++ Program

A simple C++ program commonly looks like this:

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, C++!";

    return 0;
}
```

Let's understand the basic parts:

| Part                   | Purpose                                                         |
| ---------------------- | --------------------------------------------------------------- |
| `#include <iostream>`  | Provides input/output features                                  |
| `using namespace std;` | Allows common standard-library names to be used without `std::` |
| `int main()`           | Starting function of the program                                |
| `{ }`                  | Defines the function body                                       |
| `cout`                 | Displays output                                                 |
| `return 0;`            | Ends `main()` successfully                                      |

---

## 15. Putting Comments and Syntax Together

A complete program can contain comments along with normal C++ syntax.

```cpp
#include <iostream>
using namespace std;

// Program execution starts here
int main() {

    // Store two numbers
    int a = 10;
    int b = 20;

    // Calculate the total
    int total = a + b;

    // Display the result
    cout << "Total: " << total;

    return 0;
}
```

```output
Total: 30
```

The comments explain the program without changing its behavior.

---

## 16. Real-World Example 🌍

Imagine you are creating a student marks program.

Comments can explain each part:

```cpp
#include <iostream>
using namespace std;

int main() {
    // Store the marks
    int marks = 95;

    // Store the maximum marks
    const int MAX_MARKS = 100;

    // Display the result
    cout << "Marks: " << marks << "\n";
    cout << "Maximum: " << MAX_MARKS;

    return 0;
}
```

```output
Marks: 95
Maximum: 100
```

The comments make it easier for another programmer to understand what each variable is used for.

## Common Mistakes

### Mistake 1: Forgetting the semicolon

Incorrect:

```cpp
int age = 18
```

Correct:

```cpp
int age = 18;
```

---

### Mistake 2: Using the wrong capitalization

Incorrect:

```cpp
Cout << "Hello";
```

Correct:

```cpp
cout << "Hello";
```

C++ is case-sensitive.

---

### Mistake 3: Incorrect comment syntax

Incorrect:

```cpp
/ This is a comment
```

Correct:

```cpp
// This is a comment
```

---

### Mistake 4: Not closing a multi-line comment

Incorrect:

```cpp
/*
This is a comment
```

Correct:

```cpp
/*
This is a comment
*/
```

---

### Mistake 5: Using a keyword as a variable name

Incorrect:

```cpp
int return = 10;
```

`return` is a C++ keyword.

Use a different identifier:

```cpp
int result = 10;
```

---

## Key Points

* Comments are ignored by the compiler.
* `//` is used for single-line comments.
* `/* ... */` is used for multi-line comments.
* C++ syntax defines the rules for writing valid programs.
* Most C++ statements end with `;`.
* C++ is case-sensitive.
* `{ }` define blocks of code.
* `( )` are used for functions, conditions, and grouping expressions.
* Identifiers are names used for variables, functions, and other program elements.
* Keywords are reserved words with special meanings.
* Good indentation and spacing make code easier to read.
