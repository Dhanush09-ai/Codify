# Chapter 2: C++ Basics

## Section 3: Input & Output

Input and output are used to communicate with the user.

* **Input** means taking data from the user.
* **Output** means displaying information on the screen.

In C++, `cin` is commonly used for input, and `cout` is used for output.

---

## 1. Output Using `cout`

The `cout` object is used to display output on the screen.

It is available through the `<iostream>` header.

### Basic Syntax

```cpp
cout << value;
```

Example:

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, C++!";

    return 0;
}
```

```output
Hello, C++!
```

The `<<` operator sends the value to `cout`.

---

## 2. Printing Text and Numbers

You can use `cout` to print both text and numbers.

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Age: ";
    cout << 18;

    return 0;
}
```

```output
Age: 18
```

You can also print a number directly:

```cpp
cout << 100;
```

```output
100
```

---

## 3. Printing Multiple Values

Multiple values can be printed using multiple `<<` operators.

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Name: " << "Owais";
    cout << "\nAge: " << 18;

    return 0;
}
```

```output
Name: Owais
Age: 18
```

You can combine text, variables, and values in a single statement.

```cpp
#include <iostream>
using namespace std;

int main() {
    int marks = 95;

    cout << "My marks are " << marks;

    return 0;
}
```

```output
My marks are 95
```

---

## 4. New Lines Using `\n`

The `\n` escape sequence moves the output to the next line.

Example:

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello\n";
    cout << "Welcome to C++";

    return 0;
}
```

```output
Hello
Welcome to C++
```

You can use multiple `\n` characters:

```cpp
cout << "Line 1\nLine 2\nLine 3";
```

```output
Line 1
Line 2
Line 3
```

---

## 5. Using `endl`

`endl` also moves the output to the next line.

Example:

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello" << endl;
    cout << "C++";

    return 0;
}
```

```output
Hello
C++
```

Both of these can be used for a new line:

```cpp
cout << "Hello\n";
cout << "Hello" << endl;
```

For simple output, `\n` is commonly preferred.

---

## 6. Taking Input Using `cin`

The `cin` object is used to take input from the user.

### Basic Syntax

```cpp
cin >> variable;
```

Example:

```cpp
#include <iostream>
using namespace std;

int main() {
    int age;

    cout << "Enter your age: ";
    cin >> age;

    cout << "Your age is " << age;

    return 0;
}
```

If the user enters:

```output
18
```

The output will be:

```output
Enter your age: 18
Your age is 18
```

The `>>` operator takes the input and stores it in the variable.

---

## 7. Taking Different Types of Input

`cin` can be used with different data types.

### Integer Input

```cpp
int age;

cin >> age;
```

### Decimal Input

```cpp
double price;

cin >> price;
```

### Character Input

```cpp
char grade;

cin >> grade;
```

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int age;
    double percentage;
    char grade;

    cout << "Enter age: ";
    cin >> age;

    cout << "Enter percentage: ";
    cin >> percentage;

    cout << "Enter grade: ";
    cin >> grade;

    cout << "\nAge: " << age;
    cout << "\nPercentage: " << percentage;
    cout << "\nGrade: " << grade;

    return 0;
}
```

If the user enters:

```output
18
95.5
A
```

The program displays:

```output
Age: 18
Percentage: 95.5
Grade: A
```

---

## 8. Taking Multiple Inputs

You can take multiple values using one `cin` statement.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;

    cout << "Enter two numbers: ";
    cin >> a >> b;

    cout << "First number: " << a << "\n";
    cout << "Second number: " << b;

    return 0;
}
```

If the user enters:

```output
10 20
```

The output is:

```output
First number: 10
Second number: 20
```

You can also enter the values on separate lines:

```output
10
20
```

`cin` reads the values in the required order.

---

## 9. Input and Output with Strings

A `string` can be used to store text.

For a single word, `cin` can be used directly:

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string name;

    cout << "Enter your name: ";
    cin >> name;

    cout << "Hello, " << name;

    return 0;
}
```

If the user enters:

```output
Owais
```

The output is:

```output
Hello, Owais
```

### Important

`cin >> name` reads input until whitespace.

For example, if the user enters:

```output
Mohammed Owais
```

only `Mohammed` is stored in `name`.

To read a complete line containing spaces, C++ provides `getline()`.

---

## 10. Reading a Full Line with `getline()`

`getline()` can read an entire line of text, including spaces.

Example:

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string name;

    cout << "Enter your full name: ";
    getline(cin, name);

    cout << "Hello, " << name;

    return 0;
}
```

If the user enters:

```output
Mohammed Owais
```

The output is:

```output
Hello, Mohammed Owais
```

### `cin` vs `getline()`

| Method               | Reads           |
| -------------------- | --------------- |
| `cin >> name`        | One word        |
| `getline(cin, name)` | A complete line |

## 11. A Complete Input & Output Program

Let's combine input, variables, and output.

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string name;
    int age;
    double marks;

    cout << "Enter your name: ";
    getline(cin, name);

    cout << "Enter your age: ";
    cin >> age;

    cout << "Enter your marks: ";
    cin >> marks;

    cout << "\n--- Student Details ---\n";
    cout << "Name: " << name << "\n";
    cout << "Age: " << age << "\n";
    cout << "Marks: " << marks;

    return 0;
}
```

Example input:

```output
Mohammed Owais
18
95.5
```

Example output:

```output
--- Student Details ---
Name: Mohammed Owais
Age: 18
Marks: 95.5
```

## 12. Real-World Example 🌍

Input and output are used in many everyday programs.

For example, a simple shopping program can ask for a product price and quantity.

```cpp
#include <iostream>
using namespace std;

int main() {
    double price;
    int quantity;

    cout << "Enter product price: ";
    cin >> price;

    cout << "Enter quantity: ";
    cin >> quantity;

    double total = price * quantity;

    cout << "Total price: " << total;

    return 0;
}
```

If the user enters:

```output
250
3
```

The output is:

```output
Total price: 750
```

Here:

* `cin` takes the price and quantity.
* The program calculates the total.
* `cout` displays the result.

## Common Mistakes

### Mistake 1: Using `<<` with `cin`

Incorrect:

```cpp
cin << age;
```

Correct:

```cpp
cin >> age;
```

`cin` uses `>>` for input.

---

### Mistake 2: Using `>>` with `cout`

Incorrect:

```cpp
cout >> age;
```

Correct:

```cpp
cout << age;
```

`cout` uses `<<` for output.

---

### Mistake 3: Forgetting to declare the variable

Incorrect:

```cpp
cin >> age;
```

Correct:

```cpp
int age;
cin >> age;
```

The variable must exist before input is stored in it.

---

### Mistake 4: Expecting `cin >>` to read spaces

```cpp
string name;
cin >> name;
```

If the user enters:

```output
Mohammed Owais
```

only the first word is read.

Use:

```cpp
getline(cin, name);
```

when you need the complete line.

---

## Key Points

* **Input** means taking data from the user.
* **Output** means displaying information.
* `cout` is used for output.
* `cin` is used for input.
* `<<` is used with `cout`.
* `>>` is used with `cin`.
* `\n` moves output to a new line.
* `endl` can also move output to a new line.
* `cin >>` normally reads one word for string input.
* `getline()` can read a complete line containing spaces.
