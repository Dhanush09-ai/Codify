# Chapter 2: C++ Basics

## Section 4: Type Conversion

Sometimes a program needs to convert a value from one data type to another.

For example, you may need to convert an `int` into a `double`, or a `double` into an `int`.

This process is called **type conversion**.

---

## 1. What is Type Conversion?

**Type conversion** means changing a value from one data type to another.

For example:

```cpp
int number = 10;
double value = number;
```

Here, the `int` value `10` is converted to a `double`.

The value becomes:

```output
10
```

Type conversion is useful when different data types are used together in a calculation.

---

## 2. Implicit Type Conversion

**Implicit conversion** happens automatically by the compiler.

For example:

```cpp
#include <iostream>
using namespace std;

int main() {
    int number = 10;
    double value = number;

    cout << value;

    return 0;
}
```

```output
10
```

Here:

* `number` is an `int`.
* `value` is a `double`.
* C++ automatically converts `10` from `int` to `double`.

This is called **implicit type conversion**.

---

## 3. Converting `int` to `double`

When an integer is assigned to a `double`, the integer can be represented as a decimal value.

```cpp
int number = 25;
double value = number;
```

Now:

```cpp
cout << value;
```

produces:

```output
25
```

Internally, the value is represented as a `double`.

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int marks = 95;
    double percentage = marks;

    cout << percentage;

    return 0;
}
```

```output
95
```

---

## 4. Converting `double` to `int`

When a `double` is converted to an `int`, the decimal part is removed.

Example:

```cpp
double price = 99.75;
int value = price;
```

The value stored in `value` is:

```output
99
```

The decimal part `.75` is not rounded up.

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    double number = 25.89;
    int value = number;

    cout << value;

    return 0;
}
```

```output
25
```

### Important

Converting a decimal value to an integer can cause loss of information.

For example:

```cpp
25.89 → 25
```

---

## 5. Explicit Type Conversion

Sometimes you want to tell C++ explicitly to convert a value to another type.

This is called **explicit type conversion** or **type casting**.

One simple form is:

```cpp
(type)value
```

Example:

```cpp
double price = 99.75;
int value = (int)price;
```

Now `value` contains:

```output
99
```

---

## 6. `static_cast`

C++ provides `static_cast` for explicit type conversion.

### Syntax

```cpp
static_cast<type>(value)
```

Example:

```cpp
double number = 25.89;
int value = static_cast<int>(number);
```

Here, `number` is explicitly converted from `double` to `int`.

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    double number = 25.89;

    int value = static_cast<int>(number);

    cout << value;

    return 0;
}
```

```output
25
```

For modern C++, `static_cast` is generally preferred over the old C-style cast.

---

## 7. Type Conversion in Calculations

Type conversion becomes especially important when performing calculations.

Consider:

```cpp
int a = 5;
int b = 2;

cout << a / b;
```

The result is:

```output
2
```

Because both operands are integers, integer division is performed.

If you want a decimal result, convert one value to `double`.

```cpp
int a = 5;
int b = 2;

cout << static_cast<double>(a) / b;
```

Now the result is:

```output
2.5
```

### Complete Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 5;
    int b = 2;

    cout << "Integer division: " << a / b << "\n";
    cout << "Decimal division: " << static_cast<double>(a) / b;

    return 0;
}
```

```output
Integer division: 2
Decimal division: 2.5
```

---

## 8. Converting `char` to `int`

A `char` can also be converted to an integer.

Characters are stored using numeric character codes.

For example:

```cpp
char letter = 'A';
int value = letter;
```

The integer value corresponds to the character's encoding.

A simple example:

```cpp
#include <iostream>
using namespace std;

int main() {
    char letter = 'A';

    int value = static_cast<int>(letter);

    cout << value;

    return 0;
}
```

```output
65
```

The value `65` is the commonly used character code for uppercase `A` in ASCII-based systems.

---

## 9. Converting `int` to `char`

The conversion can also work in the other direction.

```cpp
int value = 65;
char letter = static_cast<char>(value);
```

Example:

```cpp
#include <iostream>
using namespace std;

int main() {
    int value = 65;

    char letter = static_cast<char>(value);

    cout << letter;

    return 0;
}
```

```output
A
```

This works because `65` corresponds to `A` in ASCII.

---

## 10. Type Conversion with User Input

Type conversion can also be useful when working with input.

For example, suppose the user enters two integers and you want to calculate their average.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;

    cout << "Enter two numbers: ";
    cin >> a >> b;

    double average = static_cast<double>(a + b) / 2;

    cout << "Average: " << average;

    return 0;
}
```

If the user enters:

```output
10 15
```

The output is:

```output
Average: 12.5
```

Without the conversion, integer division could produce an incorrect result for a decimal average.

---

## 11. Common Types of Conversion

| Conversion       | Example          | Result |
| ---------------- | ---------------- | ------ |
| `int` → `double` | `double x = 10;` | `10`   |
| `double` → `int` | `int x = 10.75;` | `10`   |
| `int` → `char`   | `char c = 65;`   | `A`    |
| `char` → `int`   | `int x = 'A';`   | `65`   |

The actual result depends on the types and values involved.

---

## 12. Real-World Example 🌍

Imagine a shop program that calculates the average price of products.

```cpp
#include <iostream>
using namespace std;

int main() {
    int price1 = 100;
    int price2 = 150;
    int price3 = 125;

    double average =
        static_cast<double>(price1 + price2 + price3) / 3;

    cout << "Average Price: " << average;

    return 0;
}
```

```output
Average Price: 125
```

The integer total is explicitly converted to `double` before division.

This allows the program to produce a decimal result when necessary.

## Common Mistakes

### Mistake 1: Expecting integer division to produce a decimal

```cpp
int a = 5;
int b = 2;

double result = a / b;
```

The result is:

```output
2
```

because `a / b` is calculated as integer division first.

Use:

```cpp
double result = static_cast<double>(a) / b;
```

to get:

```output
2.5
```

---

### Mistake 2: Forgetting that decimal data can be lost

```cpp
double number = 15.99;
int value = static_cast<int>(number);
```

The result is:

```output
15
```

The `.99` is removed.

---

### Mistake 3: Confusing conversion with rounding

Converting:

```cpp
double number = 15.9;
int value = static_cast<int>(number);
```

does **not** round `15.9` to `16`.

It produces:

```output
15
```

---

## Key Points

* **Type conversion** changes a value from one data type to another.
* **Implicit conversion** happens automatically.
* **Explicit conversion** is requested by the programmer.
* `static_cast<type>(value)` is a common C++ way to perform explicit conversion.
* Converting `double` to `int` removes the decimal part.
* Integer division can produce an integer result even when the result is mathematically a decimal.
* Converting one operand to `double` can produce a decimal result.
* Type conversion can sometimes cause loss of information.
