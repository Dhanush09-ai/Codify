# Chapter 2: C++ Basics

## Section 1: Variables & Constants

Variables and constants are used to store data in a C++ program.

A **variable** stores a value that can change during program execution, while a **constant** stores a value that cannot be changed after it is created.

---

## 1. What is a Variable?

A **variable** is a named memory location used to store a value.

For example:

```cpp
int age = 20;
```

Here:

* `int` → data type
* `age` → variable name
* `20` → value
* `=` → assignment operator

You can change the value of a variable later:

```cpp
int age = 20;

age = 21;
```

Now, `age` contains `21`.

### Basic Syntax

```cpp
dataType variableName = value;
```

Example:

```cpp
int marks = 95;
double price = 49.50;
char grade = 'A';
```

---

## 2. Declaring and Initializing Variables

There are two common steps when working with variables:

### Declaration

Declaration tells C++ about the variable and its data type.

```cpp
int age;
```

### Initialization

Initialization gives the variable its first value.

```cpp
int age = 20;
```

You can also declare first and assign later:

```cpp
int age;

age = 20;
```

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int age = 18;

    cout << age;

    return 0;
}
```

```output
18
```

---

## 3. Changing Variable Values

The value stored in a variable can be changed.

```cpp
#include <iostream>
using namespace std;

int main() {
    int score = 50;

    cout << score << "\n";

    score = 80;

    cout << score;

    return 0;
}
```

```output
50
80
```

The variable `score` first contains `50`. Later, its value is changed to `80`.

### Important

A variable can store only one current value at a time.

```cpp
int number = 10;

number = 20;
number = 30;
```

At the end, `number` contains:

```output
30
```

---

## 4. Naming Variables

C++ has rules for naming variables.

### Rules

1. A variable name can contain letters, digits, and `_`.
2. It cannot start with a digit.
3. It cannot contain spaces.
4. C++ keywords cannot be used as variable names.
5. Variable names are case-sensitive.

### Valid Names

```cpp
age
studentName
total_marks
number1
price
```

### Invalid Names

```cpp
2number
student name
total-price
int
```

For example:

```cpp
int studentAge = 18;
```

and

```cpp
int studentage = 18;
```

are different variables because C++ is **case-sensitive**.

### Good Naming Practice

Use meaningful names:

```cpp
int studentAge = 18;
double productPrice = 250.50;
```

Instead of unclear names:

```cpp
int x = 18;
double p = 250.50;
```

Meaningful names make programs easier to understand.

---

## 5. Multiple Variables

You can create multiple variables in the same program.

```cpp
#include <iostream>
using namespace std;

int main() {
    int age = 18;
    double height = 5.8;
    char grade = 'A';

    cout << age << "\n";
    cout << height << "\n";
    cout << grade;

    return 0;
}
```

```output
18
5.8
A
```

You can also declare multiple variables of the same type:

```cpp
int x = 10, y = 20, z = 30;
```

Here, three integer variables are created.

---

## 6. What is a Constant?

A **constant** is a value that cannot be changed after it has been initialized.

In C++, the `const` keyword is used to create a constant.

### Syntax

```cpp
const dataType constantName = value;
```

Example:

```cpp
const double PI = 3.14159;
```

Once `PI` is initialized, you cannot assign another value to it.

```cpp
const int days = 7;
```

The value of `days` cannot be changed.

---

## 7. Using Constants

Let's see an example:

```cpp
#include <iostream>
using namespace std;

int main() {
    const double PI = 3.14;
    double radius = 5;

    double area = PI * radius * radius;

    cout << area;

    return 0;
}
```

```output
78.5
```

Here, `PI` is a constant because its value should remain fixed.

### Constant Example

```cpp
const int MAX_MARKS = 100;
```

This is useful when a value should remain the same throughout the program.

---

## 8. Variable vs Constant

| Feature          | Variable              | Constant              |
| ---------------- | --------------------- | --------------------- |
| Value can change | Yes                   | No                    |
| Keyword          | No special keyword    | `const`               |
| Example          | `int age = 18;`       | `const int DAYS = 7;` |
| Initialization   | Can be declared first | Must be initialized   |
| Purpose          | Store changing data   | Store fixed data      |

### Example

```cpp
int score = 50;
score = 75;
```

This is allowed because `score` is a variable.

But:

```cpp
const int MAX = 100;
MAX = 200;
```

is not allowed because `MAX` is a constant.

---

## 9. Real-World Example 🌍

Imagine a student result program.

The student's marks can change:

```cpp
int marks = 85;
```

But the maximum marks may always remain `100`:

```cpp
const int MAX_MARKS = 100;
```

A program could use both:

```cpp
#include <iostream>
using namespace std;

int main() {
    int marks = 85;
    const int MAX_MARKS = 100;

    cout << "Marks: " << marks << "\n";
    cout << "Maximum Marks: " << MAX_MARKS;

    return 0;
}
```

```output
Marks: 85
Maximum Marks: 100
```

Here:

* `marks` is a variable because it can change.
* `MAX_MARKS` is a constant because it should remain fixed.

## 10. Common Mistakes

### Mistake 1: Starting a variable name with a number

Incorrect:

```cpp
int 1number = 10;
```

Correct:

```cpp
int number1 = 10;
```

---

### Mistake 2: Using spaces in variable names

Incorrect:

```cpp
int student age = 18;
```

Correct:

```cpp
int studentAge = 18;
```

---

### Mistake 3: Trying to change a constant

Incorrect:

```cpp
const int DAYS = 7;

DAYS = 10;
```

A constant cannot be changed after initialization.

---

### Mistake 4: Declaring a constant without a value

Incorrect:

```cpp
const int MAX;
```

A constant should be initialized when it is declared.

Correct:

```cpp
const int MAX = 100;
```

---

## Key Points

* A **variable** stores data that can change.
* A variable is declared using a data type and a name.
* Variables can be assigned new values.
* Variable names cannot start with a digit or contain spaces.
* C++ variable names are case-sensitive.
* A **constant** stores a value that cannot be changed.
* The `const` keyword is used to create constants.
* Constants should be initialized when they are declared.
* Meaningful variable names make programs easier to understand.
