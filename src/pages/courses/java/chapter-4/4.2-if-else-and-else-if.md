# Chapter 4: Decision Making

## Section 2: if-else and else-if

In the previous topic, we learned how to use the `if` statement to make a decision.

But what if we want to execute **one block of code when a condition is true** and **another block when it is false**?

For this, Java provides:

* `if-else`
* `else-if`

These statements help a program make decisions between different possibilities.

---

## 1. The if-else Statement

The `if-else` statement is used when there are **two possible outcomes**.

### Syntax

```java
if (condition) {
    // code when condition is true
} else {
    // code when condition is false
}
```

If the condition is `true`, the `if` block runs.

If the condition is `false`, the `else` block runs.

---

## 2. Simple if-else Example

Let's check whether a person is eligible to vote based on age.

```java id="ifelse01"
public class Main {
    public static void main(String[] args) {
        int age = 18;

        if (age >= 18) {
            System.out.println("You can vote.");
        } else {
            System.out.println("You cannot vote.");
        }
    }
}
```

### Output

```output id="out01"
You can vote.
```

Here, `age >= 18` is `true`, so the `if` block executes.

---

## 3. When the Condition is False

Let's change the age to `16`.

```java id="ifelse02"
public class Main {
    public static void main(String[] args) {
        int age = 16;

        if (age >= 18) {
            System.out.println("You can vote.");
        } else {
            System.out.println("You cannot vote.");
        }
    }
}
```

### Output

```output id="out02"
You cannot vote.
```

This time, `age >= 18` is `false`.

Therefore, Java skips the `if` block and executes the `else` block.

---

## 4. How if-else Works

The flow is simple:

```text
        Condition
           |
       +---+---+
       |       |
     true    false
       |       |
      if     else
       |       |
       +---+---+
           |
        Continue
```

For example:

```java
int number = 10;

if (number > 0) {
    System.out.println("Positive");
} else {
    System.out.println("Not positive");
}
```

### Output

```output
Positive
```

The condition `number > 0` is true, so `"Positive"` is printed.

---

## 5. if-else with Even and Odd Numbers

We can use the remainder operator `%` to check whether a number is even or odd.

```java id="ifelse03"
public class Main {
    public static void main(String[] args) {
        int number = 7;

        if (number % 2 == 0) {
            System.out.println("Even");
        } else {
            System.out.println("Odd");
        }
    }
}
```

### Output

```output id="out03"
Odd
```

Why?

`7 % 2` gives `1`, so the condition `number % 2 == 0` is false.

Therefore, the `else` block runs.

---

## 6. if-else with Two Numbers

We can use `if-else` to compare two numbers.

```java id="ifelse04"
public class Main {
    public static void main(String[] args) {
        int a = 25;
        int b = 18;

        if (a > b) {
            System.out.println("a is greater");
        } else {
            System.out.println("b is greater or equal");
        }
    }
}
```

### Output

```output id="out04"
a is greater
```

## 7. The else-if Statement

Sometimes there are **more than two possible conditions**.

For example, suppose we want to display a grade based on marks.

We may have:

* 90 or above → Grade A
* 75 or above → Grade B
* 60 or above → Grade C
* 40 or above → Grade D
* Below 40 → Fail

For this type of decision, we can use `else-if`.

### Syntax

```java
if (condition1) {
    // code
} else if (condition2) {
    // code
} else if (condition3) {
    // code
} else {
    // code
}
```

Java checks the conditions **from top to bottom**.

When it finds the first `true` condition, its block is executed and the remaining conditions are skipped.

---

## 8. Simple else-if Example

```java id="elseif01"
public class Main {
    public static void main(String[] args) {
        int marks = 82;

        if (marks >= 90) {
            System.out.println("Grade A");
        } else if (marks >= 75) {
            System.out.println("Grade B");
        } else if (marks >= 60) {
            System.out.println("Grade C");
        } else {
            System.out.println("Fail");
        }
    }
}
```

### Output

```output id="out05"
Grade B
```

The conditions are checked in this order:

1. `marks >= 90` → false
2. `marks >= 75` → true

So Java prints `"Grade B"` and stops checking the remaining conditions.

---

## 9. Multiple else-if Conditions

You can have multiple `else-if` blocks.

```java id="elseif02"
public class Main {
    public static void main(String[] args) {
        int number = 0;

        if (number > 0) {
            System.out.println("Positive");
        } else if (number < 0) {
            System.out.println("Negative");
        } else {
            System.out.println("Zero");
        }
    }
}
```

### Output

```output id="out06"
Zero
```

Here:

* `number > 0` → false
* `number < 0` → false
* Therefore, `else` executes.

---

## 10. else-if Conditions Are Checked from Top to Bottom

The order of conditions is important.

Consider:

```java id="elseif03"
public class Main {
    public static void main(String[] args) {
        int marks = 95;

        if (marks >= 40) {
            System.out.println("Pass");
        } else if (marks >= 90) {
            System.out.println("Grade A");
        }
    }
}
```

### Output

```output id="out07"
Pass
```

Why didn't `"Grade A"` print?

Because Java checks the first condition:

```java
marks >= 40
```

Since `95 >= 40` is true, Java executes that block and skips the remaining `else-if`.

### Correct Order

More specific conditions should usually come before broader conditions.

```java
if (marks >= 90) {
    System.out.println("Grade A");
} else if (marks >= 40) {
    System.out.println("Pass");
}
```

### Output

```output id="out08"
Grade A
```

---

## 11. if-else vs else-if

### if-else

Use `if-else` when there are **two possible paths**.

```java
if (condition) {
    // first path
} else {
    // second path
}
```

Example:

```java
if (number % 2 == 0) {
    System.out.println("Even");
} else {
    System.out.println("Odd");
}
```

### else-if

Use `else-if` when there are **multiple conditions**.

```java
if (condition1) {
    // path 1
} else if (condition2) {
    // path 2
} else {
    // default path
}
```

Example:

```java
if (marks >= 90) {
    System.out.println("A");
} else if (marks >= 75) {
    System.out.println("B");
} else {
    System.out.println("Other");
}
```

---

## 12. if-else Without the Final else

The final `else` is optional.

For example:

```java id="elseif04"
public class Main {
    public static void main(String[] args) {
        int age = 20;

        if (age < 13) {
            System.out.println("Child");
        } else if (age < 18) {
            System.out.println("Teenager");
        }
    }
}
```

### Output

```output id="out09"
```

There is no output because both conditions are false.

If none of the conditions is true and there is no final `else`, Java simply skips the entire `if-else-if` structure.

---

## 13. Using Logical Operators with if-else

We can combine conditions using logical operators such as `&&` and `||`.

For example, let's check whether a student has passed both subjects.

```java id="ifelse05"
public class Main {
    public static void main(String[] args) {
        int math = 75;
        int science = 68;

        if (math >= 40 && science >= 40) {
            System.out.println("Passed");
        } else {
            System.out.println("Failed");
        }
    }
}
```

### Output

```output id="out10"
Passed
```

Both conditions are true, so the `if` block executes.

## 14. Common Mistakes

### Mistake 1: Using `=` instead of `==`

Remember:

```java
if (number == 10)
```

checks whether `number` is equal to `10`.

But:

```java
number = 10;
```

assigns `10` to `number`.

---

### Mistake 2: Wrong Order of Conditions

Consider:

```java
if (marks >= 40) {
    System.out.println("Pass");
} else if (marks >= 90) {
    System.out.println("A");
}
```

The `marks >= 90` condition will never be reached for marks 90 or above because `marks >= 40` is already true.

Put the more specific condition first:

```java
if (marks >= 90) {
    System.out.println("A");
} else if (marks >= 40) {
    System.out.println("Pass");
}
```

---

### Mistake 3: Forgetting Braces

Although braces can sometimes be omitted for a single statement, using braces makes the code easier to read and reduces mistakes.

Prefer:

```java
if (age >= 18) {
    System.out.println("Adult");
} else {
    System.out.println("Minor");
}
```

---

## 15. Quick Comparison

| Statement    | Use                                     |
| ------------ | --------------------------------------- |
| `if`         | One condition                           |
| `if-else`    | Two possible paths                      |
| `if-else-if` | Multiple conditions                     |
| `else`       | Runs when previous conditions are false |

---

## Key Points

* `if-else` provides two possible paths.
* The `if` block runs when its condition is `true`.
* The `else` block runs when the `if` condition is `false`.
* `else-if` is used when there are multiple conditions.
* Conditions in an `else-if` chain are checked from top to bottom.
* Once a condition is true, the remaining conditions are skipped.
* The final `else` is optional.
* The order of `else-if` conditions is important.
* Use `==` for comparison and `=` for assignment.
* Braces `{}` are recommended for readable and safe code.
