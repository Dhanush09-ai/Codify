# Chapter 4: Decision Making

## Section 4: switch Statement

In the previous topics, we learned how to use `if`, `if-else`, `else-if`, and nested `if` statements.

Java also provides another way to make decisions when we need to choose **one option from several fixed choices**.

This is called the **`switch` statement**.

---

## 1. What is a switch Statement?

The `switch` statement checks the value of an expression and compares it with different `case` values.

When a matching `case` is found, its code is executed.

### Basic Syntax

```java id="sw01"
switch (expression) {
    case value1:
        // code
        break;

    case value2:
        // code
        break;

    case value3:
        // code
        break;

    default:
        // code when no case matches
}
```

Important parts:

* `switch` — starts the decision structure.
* `case` — specifies a possible value.
* `break` — stops the `switch` after a matching case.
* `default` — runs when no case matches.

---

## 2. Simple switch Example

Let's display a day based on a number.

```java id="sw02"
public class Main {
    public static void main(String[] args) {
        int day = 3;

        switch (day) {
            case 1:
                System.out.println("Monday");
                break;

            case 2:
                System.out.println("Tuesday");
                break;

            case 3:
                System.out.println("Wednesday");
                break;

            case 4:
                System.out.println("Thursday");
                break;

            default:
                System.out.println("Invalid day");
        }
    }
}
```

### Output

```output id="out01"
Wednesday
```

The value of `day` is `3`.

Java finds:

```java id="sw03"
case 3:
```

So it prints `"Wednesday"`.

## 3. How switch Works

Suppose:

```java id="sw04"
int number = 2;
```

and we have:

```java id="sw05"
switch (number) {
    case 1:
        System.out.println("One");
        break;

    case 2:
        System.out.println("Two");
        break;

    case 3:
        System.out.println("Three");
        break;
}
```

Java checks the cases:

```text
number → 2

case 1 → No match
case 2 → Match
          ↓
       Print "Two"
          ↓
        break
          ↓
       Exit switch
```

### Output

```output id="out02"
Two
```

## 4. The break Statement

The `break` statement is very important in a traditional `switch`.

It tells Java to **exit the switch statement** after the matching case has been executed.

Example:

```java id="sw06"
public class Main {
    public static void main(String[] args) {
        int number = 2;

        switch (number) {
            case 1:
                System.out.println("One");
                break;

            case 2:
                System.out.println("Two");
                break;

            case 3:
                System.out.println("Three");
                break;
        }
    }
}
```

### Output

```output id="out03"
Two
```

After printing `"Two"`, `break` exits the `switch`.

---

## 5. What Happens Without break?

If `break` is omitted, Java continues executing the following cases after finding a match.

This behavior is called **fall-through**.

Example:

```java id="sw07"
public class Main {
    public static void main(String[] args) {
        int number = 2;

        switch (number) {
            case 1:
                System.out.println("One");

            case 2:
                System.out.println("Two");

            case 3:
                System.out.println("Three");
        }
    }
}
```

### Output

```output id="out04"
Two
Three
```

The value `2` matches `case 2`.

Because there is no `break`, Java continues into `case 3`.

For beginners, use `break` when you want only the matching case to execute.

---

## 6. The default Case

The `default` case is used when none of the cases matches the switch expression.

Example:

```java id="sw08"
public class Main {
    public static void main(String[] args) {
        int day = 8;

        switch (day) {
            case 1:
                System.out.println("Monday");
                break;

            case 2:
                System.out.println("Tuesday");
                break;

            case 3:
                System.out.println("Wednesday");
                break;

            default:
                System.out.println("Invalid day");
        }
    }
}
```

### Output

```output id="out05"
Invalid day
```

Since there is no `case 8`, the `default` block executes.

## 7. switch with char

A `switch` can also be used with a `char`.

For example:

```java id="sw09"
public class Main {
    public static void main(String[] args) {
        char grade = 'B';

        switch (grade) {
            case 'A':
                System.out.println("Excellent");
                break;

            case 'B':
                System.out.println("Very Good");
                break;

            case 'C':
                System.out.println("Good");
                break;

            default:
                System.out.println("Invalid grade");
        }
    }
}
```

### Output

```output id="out06"
Very Good
```

The value of `grade` is `'B'`, so `case 'B'` matches.

## 8. switch with String

A `switch` can also be used with a `String`.

Example:

```java id="sw10"
public class Main {
    public static void main(String[] args) {
        String color = "blue";

        switch (color) {
            case "red":
                System.out.println("Red color");
                break;

            case "blue":
                System.out.println("Blue color");
                break;

            case "green":
                System.out.println("Green color");
                break;

            default:
                System.out.println("Unknown color");
        }
    }
}
```

### Output

```output id="out07"
Blue color
```

The value `"blue"` matches `case "blue"`.

## 9. Multiple Cases with the Same Code

Sometimes multiple values should perform the same action.

We can place multiple `case` labels together.

For example, let's check whether a number represents a weekday or weekend.

```java id="sw11"
public class Main {
    public static void main(String[] args) {
        int day = 6;

        switch (day) {
            case 1:
            case 2:
            case 3:
            case 4:
            case 5:
                System.out.println("Weekday");
                break;

            case 6:
            case 7:
                System.out.println("Weekend");
                break;

            default:
                System.out.println("Invalid day");
        }
    }
}
```

### Output

```output id="out08"
Weekend
```

Here, `case 6` and `case 7` share the same code.

## 10. switch vs if-else

Both `switch` and `if-else` can be used for decision making, but they are useful in different situations.

### Using if-else

`if-else` is useful when conditions involve comparisons or ranges.

```java id="sw12"
if (marks >= 90) {
    System.out.println("A");
} else if (marks >= 75) {
    System.out.println("B");
} else {
    System.out.println("Other");
}
```

Here we are checking ranges, so `if-else` is suitable.

### Using switch

`switch` is useful when we have a value and want to compare it with several fixed choices.

```java id="sw13"
switch (day) {
    case 1:
        System.out.println("Monday");
        break;

    case 2:
        System.out.println("Tuesday");
        break;
}
```

A common use of `switch` is creating a simple menu.

```java id="sw14"
public class Main {
    public static void main(String[] args) {

        switch (choice) {
            case 1:
                System.out.println("Add");

            case 2:

                break;

            case 3:
                System.out.println("Delete");
                break;

            default:
                System.out.println("Invalid choice");
        }
    }
}
```

### Output

```output id="out09"
Update
```

The value `2` matches `case 2`.

## 12. Important Rules of switch

Keep these rules in mind when using `switch`:

### Rule 1: case values should be different

Avoid duplicate case values.

```java
switch (number) {
    case 1:
        System.out.println("One");
        break;

    case 2:
        System.out.println("Two");
        break;
}
```

Each case represents a different choice.

### Rule 2: break is usually used

Use `break` when you want the switch to stop after the matching case.

### Rule 3: default is optional

You can write a switch without `default`, but using `default` is often helpful when no case matches.

### Rule 4: case values are fixed choices

A case represents a specific value rather than a range such as `marks >= 90`.

## 13. Common Mistakes

### Mistake 1: Forgetting break

```java id="sw15"
switch (number) {
    case 1:
        System.out.println("One");

    case 2:
        System.out.println("Two");
}
```

Without `break`, execution can continue into the next case.

---

### Mistake 2: Using a condition in case

A case is not written like an `if` condition.

Do not write:

```java id="sw16"
case number > 10:
```

Instead, use `if-else` when you need conditions such as:

```java id="sw17"
if (number > 10) {
    System.out.println("Greater than 10");
}
```

---

### Mistake 3: Forgetting the default case

If no case matches and there is no `default`, nothing inside the switch executes.

For example:

```java id="sw18"
int day = 10;

switch (day) {
    case 1:
        System.out.println("Monday");
        break;
}
```

### Output

```output id="out10"
```

There is no output because `day` does not match `case 1`.

---

## 14. Quick Comparison

| Feature          | `if-else` | `switch`             |
| ---------------- | --------- | -------------------- |
| Multiple choices | Yes       | Yes                  |
| Range conditions | Suitable  | Not the usual choice |
| Fixed values     | Yes       | Very suitable        |
| `break` required | No        | Commonly used        |
| `default`        | `else`    | `default`            |

---

## Key Points

* `switch` is used to choose between fixed values.
* `case` represents a possible value.
* `break` exits the switch after a matching case.
* Without `break`, fall-through can occur.
* `default` runs when no case matches.
* Multiple cases can share the same code.
* `switch` can be used with values such as `int`, `char`, and `String`.
* `if-else` is generally more suitable for ranges and complex conditions.
* `switch` is useful when comparing one value with several fixed choices.
