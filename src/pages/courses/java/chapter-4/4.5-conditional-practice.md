## 1. Check Whether a Number is Positive or Negative

Write a program that checks whether a number is positive or negative.

```java id="cp01"
public class Main {
    public static void main(String[] args) {
        int number = -5;

        if (number >= 0) {
            System.out.println("Positive");
        } else {
            System.out.println("Negative");
        }
    }
}
```

### Output

```output id="out01"
Negative
```

The condition `number >= 0` is false because `-5` is less than `0`.

## 4. Find the Greatest of Three Numbers

When there are multiple comparisons, we can use nested `if`.

```java id="cp04"
public class Main {
    public static void main(String[] args) {
        int a = 25;
        int b = 40;
        int c = 30;

        if (a > b) {
            if (a > c) {
                System.out.println("a is greatest");
            } else {
                System.out.println("c is greatest");
            }
        } else {
            if (b > c) {
                System.out.println("b is greatest");
            } else {
                System.out.println("c is greatest");
            }
        }
    }
}
```

### Output

```output id="out04"
b is greatest
```

## 6. Find Grade Using else-if

We can use an `else-if` chain to assign a grade.

```java id="cp06"
public class Main {
    public static void main(String[] args) {
        int marks = 86;

        if (marks >= 90) {
            System.out.println("Grade A");
        } else if (marks >= 75) {
            System.out.println("Grade B");
        } else if (marks >= 60) {
            System.out.println("Grade C");
        } else if (marks >= 40) {
            System.out.println("Grade D");
        } else {
            System.out.println("Fail");
        }
    }
}
```

### Output

```output id="out06"
Grade B
```

The conditions are checked from top to bottom.

`86 >= 90` is false.

`86 >= 75` is true, so `"Grade B"` is printed.

## 7. Check Whether a Year is a Leap Year

We can combine conditions using `&&` and `||`.

A year is a leap year when:

* it is divisible by `400`, or
* it is divisible by `4` but not by `100`.

```java id="cp07"
public class Main {
    public static void main(String[] args) {
        int year = 2024;

        if (year % 400 == 0 || (year % 4 == 0 && year % 100 != 0)) {
            System.out.println("Leap year");
        } else {
            System.out.println("Not a leap year");
        }
    }
}
```

### Output

```output id="out07"
Leap year
```

## 10. Simple Calculator Using switch

A `switch` statement can be used to choose an operation.

```java id="cp10"
public class Main {
    public static void main(String[] args) {
        int a = 10;
        int b = 5;
        char operator = '*';

        switch (operator) {
            case '+':
                System.out.println(a + b);
                break;

            case '-':
                System.out.println(a - b);
                break;

            case '*':
                System.out.println(a * b);
                break;

            case '/':
                System.out.println(a / b);
                break;

            default:
                System.out.println("Invalid operator");
        }
    }
}
```

### Output

```output id="out10"
50
```

The value of `operator` is `'*'`, so `case '*'` executes.

## 13. Nested if Practice

Let's combine an outer condition with an inner condition.

```java id="cp13"
public class Main {
    public static void main(String[] args) {
        int age = 20;
        boolean hasId = true;

        if (age >= 18) {
            if (hasId) {
                System.out.println("Entry allowed");
            } else {
                System.out.println("ID required");
            }
        } else {
            System.out.println("Entry not allowed");
        }
    }
}
```

### Output

```output id="out13"
Entry allowed
```

The outer condition checks the age first.

Only after it is true does Java check `hasId`.

## 14. Practice: Which Statement Should You Use?

Different problems can be solved using different conditional statements.

| Problem                            | Suitable statement |
| ---------------------------------- | ------------------ |
| Check whether a number is positive | `if`               |
| Check even or odd                  | `if-else`          |
| Find a grade from marks            | `else-if`          |
| Check dependent conditions         | Nested `if`        |
| Choose from fixed menu options     | `switch`           |
| Check a range                      | `if-else`          |
| Compare several fixed values       | `switch`           |

The important thing is to understand **why** a particular statement is suitable for a problem.

## 15. Predict the Output

```java id="cp14"
public class Main {

        int x = 15;

        if (x > 10) {

                System.out.println("A");

            System.out.println("C");
        }
```


1. `15 > 10` → `true`
2. `15 % 2 == 0` → `false`
3. Therefore, the inner `else` executes.
4. `"B"` is printed.

## 16. A Complete Conditional Example

Let's combine several concepts to determine the result of a student's marks.

```java id="cp15"
public class Main {
    public static void main(String[] args) {
        int marks = 78;

        if (marks < 0 || marks > 100) {
            System.out.println("Invalid marks");
        } else if (marks >= 90) {
            System.out.println("Grade A");
        } else if (marks >= 75) {
            System.out.println("Grade B");
        } else if (marks >= 60) {
            System.out.println("Grade C");
        } else if (marks >= 40) {
            System.out.println("Grade D");
        } else {
            System.out.println("Fail");
        }
    }
}
```

### Output

```output id="out15"
Grade B
```

This example combines:

* `if`
* `else-if`
* comparison operators
* logical `||`

## Key Points

* Conditional statements allow a program to make decisions.
* Use `if` for a single condition.
* Use `if-else` for two possible paths.
* Use `else-if` for multiple conditions.
* Use nested `if` when one decision depends on another.
* Use `switch` when comparing a value with several fixed choices.
* Logical operators such as `&&` and `||` can combine conditions.
* Always check the order of conditions in an `else-if` chain.
* Practice predicting the output before running the program.
