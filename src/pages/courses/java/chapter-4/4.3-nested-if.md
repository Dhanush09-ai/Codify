# Chapter 4: Decision Making

## Section 3: Nested if

Sometimes, one decision depends on another decision.

For example, we may first check whether a student passed an exam. If the student passed, we can then check whether the marks are high enough for a particular grade.

For this type of situation, Java allows us to place one `if` statement **inside another `if` statement**.

This is called a **nested `if`**.

---

## 1. What is a Nested if?

A nested `if` means an `if` statement is written inside another `if` statement.

### Basic Structure

```java id="nest01"
if (condition1) {

    if (condition2) {
        // code
    }

}
```

Here:

* The **outer `if`** checks the first condition.
* The **inner `if`** checks the second condition.
* The inner `if` is checked only when the outer `if` condition is `true`.

---

## 2. Simple Nested if Example

Let's check whether a number is positive and then check whether it is even.

```java id="nest02"
public class Main {
    public static void main(String[] args) {
        int number = 8;

        if (number > 0) {
            if (number % 2 == 0) {
                System.out.println("Positive even number");
            }
        }
    }
}
```

### Output

```output id="out01"
Positive even number
```

First, Java checks:

```text
number > 0
```

Since `8 > 0` is true, Java enters the outer `if`.

Then it checks:

```text
number % 2 == 0
```

Since `8 % 2` is `0`, the inner `if` also runs.

---

## 3. When the Outer Condition is False

The inner `if` is not checked when the outer condition is false.

```java id="nest03"
public class Main {
    public static void main(String[] args) {
        int number = -8;

        if (number > 0) {
            if (number % 2 == 0) {
                System.out.println("Positive even number");
            }
        }
    }
}
```

### Output

```output id="out02"
```

Here:

```text
number > 0
```

is false because `-8` is not greater than `0`.

Therefore, Java does not enter the outer `if`, so the inner `if` is never checked.

---

## 4. Nested if with else

We can also use `else` inside a nested `if`.

For example, let's check whether a number is positive and then determine whether it is even or odd.

```java id="nest04"
public class Main {
    public static void main(String[] args) {
        int number = 7;

        if (number > 0) {
            if (number % 2 == 0) {
                System.out.println("Positive even number");
            } else {
                System.out.println("Positive odd number");
            }
        } else {
            System.out.println("Not a positive number");
        }
    }
}
```

### Output

```output id="out03"
Positive odd number
```

The decisions happen in two levels:

1. Is the number positive?
2. If yes, is it even or odd?

---

## 5. Nested if with Student Marks

Nested `if` statements can be useful when one condition depends on another.

For example, first check whether a student passed. If the student passed, check whether the marks are 75 or above.

```java id="nest05"
public class Main {
    public static void main(String[] args) {
        int marks = 82;

        if (marks >= 40) {
            if (marks >= 75) {
                System.out.println("Passed with distinction");
            } else {
                System.out.println("Passed");
            }
        } else {
            System.out.println("Failed");
        }
    }
}
```

### Output

```output id="out04"
Passed with distinction
```

The outer `if` checks:

```text
marks >= 40
```

The student passed, so Java checks the inner `if`:

```text
marks >= 75
```

This is also true, so `"Passed with distinction"` is printed.

---

## 6. Another Example

Let's check whether a person is eligible for a driving license based on age and whether they have passed a test.

```java id="nest06"
public class Main {
    public static void main(String[] args) {
        int age = 20;
        boolean testPassed = true;

        if (age >= 18) {
            if (testPassed) {
                System.out.println("Eligible for license");
            } else {
                System.out.println("Test must be passed");
            }
        } else {
            System.out.println("Too young");
        }
    }
}
```

### Output

```output id="out05"
Eligible for license
```

The program first checks the age.

Because the person is at least 18, it then checks whether the test was passed.

---

## 7. Multiple Levels of Nested if

An `if` can contain another `if`, and that inner `if` can contain another `if`.

For example:

```java id="nest07"
public class Main {
    public static void main(String[] args) {
        int number = 12;

        if (number > 0) {
            if (number % 2 == 0) {
                if (number > 10) {
                    System.out.println("Positive even number greater than 10");
                }
            }
        }
    }
}
```

### Output

```output id="out06"
Positive even number greater than 10
```

Here there are three levels:

1. Is the number positive?
2. Is the number even?
3. Is the number greater than 10?

All three conditions must be true for the message to be printed.

---

## 8. Nested if vs Logical Operators

Sometimes a nested `if` can be replaced with a logical `&&` condition.

### Using Nested if

```java id="nest08"
if (age >= 18) {
    if (testPassed) {
        System.out.println("Eligible");
    }
}
```

### Using &&

```java id="nest09"
if (age >= 18 && testPassed) {
    System.out.println("Eligible");
}
```

Both approaches can represent the same basic condition.

For simple conditions, using `&&` can make the code shorter.

Nested `if` can be useful when the second decision has its own `else` or when the decisions are easier to understand as separate steps.

---

## 9. Nested if with else-if

A nested `if` can also contain an `else-if`.

```java id="nest10"
public class Main {
    public static void main(String[] args) {
        int marks = 85;

        if (marks >= 40) {
            if (marks >= 90) {
                System.out.println("Grade A");
            } else if (marks >= 75) {
                System.out.println("Grade B");
            } else {
                System.out.println("Grade C");
            }
        } else {
            System.out.println("Fail");
        }
    }
}
```

### Output

```output id="out07"
Grade B
```

First, the outer `if` checks whether the student passed.

Then the inner conditions determine the grade.

---

## 10. Common Mistakes

### Mistake 1: Forgetting Braces

Nested `if` statements can become difficult to read without braces.

Prefer:

```java id="nest11"
if (condition1) {
    if (condition2) {
        System.out.println("Both conditions are true");
    }
}
```

Using braces makes it clear which `if` belongs to which block.

---

### Mistake 2: Putting the Inner if in the Wrong Place

Remember that the inner `if` belongs to the outer `if` block.

```java id="nest12"
if (age >= 18) {
    if (testPassed) {
        System.out.println("Eligible");
    }
}
```

The `testPassed` condition is checked only after `age >= 18` is true.

---

### Mistake 3: Creating Too Many Nested Levels

Although Java allows nested `if` statements, too many levels can make code difficult to read.

For simple conditions, logical operators such as `&&` and `||` may sometimes provide a clearer solution.

---

## 11. Quick Comparison

| Type        | Purpose                                     |
| ----------- | ------------------------------------------- |
| `if`        | Checks one condition                        |
| `if-else`   | Chooses between two paths                   |
| `else-if`   | Checks multiple conditions                  |
| Nested `if` | Checks a condition inside another condition |

---

## Key Points

* A nested `if` is an `if` statement inside another `if`.
* The outer condition is checked first.
* The inner `if` is checked only when the outer condition is true.
* Nested `if` can contain `else` and `else-if`.
* Multiple levels of nesting are possible.
* Braces `{}` make nested conditions easier to understand.
* Simple nested conditions can sometimes be replaced with logical operators.
* Avoid unnecessary nesting because it can make code harder to read.
