# Chapter 4: Decision Making

## Section 1: `if` Statement

Programs often need to make decisions.

For example:

* Check whether a number is positive.
* Check whether a student passed.
* Check whether a person is old enough.
* Check whether two values are equal.

Java uses the **`if` statement** to execute code only when a condition is `true`.

In this lesson, we will learn:

* What an `if` statement is
* Syntax of `if`
* How an `if` statement works
* Using relational operators with `if`
* Using logical operators with `if`
* Multiple statements inside `if`
* Common mistakes

---

## 1. What is an `if` Statement?

The `if` statement is used to execute a block of code when a specified condition is `true`.

For example:

```java id="if1234"
public class Main {
    public static void main(String[] args) {
        int age = 20;

        if (age >= 18) {
            System.out.println("You are an adult.");
        }
    }
}
```

```output id="if5678"
You are an adult.
```

The condition:

```text id="cond123"
age >= 18
```

is `true` because `20` is greater than `18`.

Therefore, Java executes the statement inside the `if` block.

---

## 2. Syntax of `if`

The basic syntax is:

```java id="syntax12"
if (condition) {
    // code to execute
}
```

There are three important parts:

1. `if` keyword
2. Condition inside `( )`
3. Code inside `{ }`

For example:

```java id="syntax34"
if (number > 0) {
    System.out.println("Positive");
}
```

If `number > 0` is `true`, the message is printed.

---

## 3. How the `if` Statement Works

Consider this example:

```java id="work1234"
int number = 10;

if (number > 5) {
    System.out.println("Number is greater than 5.");
}
```

Java checks the condition:

```text id="work5678"
number > 5
```

Since:

```text id="work9012"
10 > 5
```

is `true`, Java executes the code inside the braces.

The output is:

```text id="work3456"
Number is greater than 5.
```

If the condition were `false`, Java would skip the code inside the `if` block.

---

## 4. `if` Condition Must Be Boolean

In Java, the condition of an `if` statement must produce either `true` or `false`.

For example:

```java id="bool1234"
int marks = 75;

if (marks >= 35) {
    System.out.println("Passed");
}
```

```output id="bool5678"
Passed
```

The expression:

```text id="marks123"
marks >= 35
```

produces a boolean result.

Since `75 >= 35` is `true`, the statement runs.

---

## 5. `if` with Relational Operators

Relational operators are commonly used with `if`.

For example:

```java id="rel1234"
public class Main {
    public static void main(String[] args) {
        int number = 10;

        if (number > 0) {
            System.out.println("Positive number");
        }
    }
}
```

```output id="rel5678"
Positive number
```

Other relational operators can also be used:

```text
>   Greater than
<   Less than
>=  Greater than or equal to
<=  Less than or equal to
==  Equal to
!=  Not equal to
```

---

## 6. `if` with `==`

The `==` operator can be used to check whether two values are equal.

```java id="equal123"
public class Main {
    public static void main(String[] args) {
        int number = 10;

        if (number == 10) {
            System.out.println("Number is 10");
        }
    }
}
```

```output id="equal456"
Number is 10
```

Remember:

* `=` → assignment
* `==` → comparison

For example:

```java id="assign12"
int number = 10;
```

assigns `10` to `number`.

But:

```java id="compare34"
number == 10
```

checks whether `number` is equal to `10`.

---

## 7. `if` with `!=`

The `!=` operator checks whether two values are different.

```java id="notequal12"
public class Main {
    public static void main(String[] args) {
        int number = 10;

        if (number != 5) {
            System.out.println("Number is not 5");
        }
    }
}
```

```output id="notequal34"
Number is not 5
```

Since `10` is not equal to `5`, the condition is `true`.

---

## 8. Using Logical AND `&&`

Logical operators can be used when an `if` statement needs to check multiple conditions.

For example:

```java id="and1234"
public class Main {
    public static void main(String[] args) {
        int age = 20;

        if (age >= 18 && age <= 60) {
            System.out.println("Age is within the range.");
        }
    }
}
```

```output id="and5678"
Age is within the range.
```

Both conditions must be true:

* `age >= 18`
* `age <= 60`

Because both are true, the code executes.

---

## 9. Using Logical OR `||`

The logical OR operator `||` can be used when at least one condition should be true.

```java id="or1234"
public class Main {
    public static void main(String[] args) {
        int day = 6;

        if (day == 6 || day == 7) {
            System.out.println("Weekend");
        }
    }
}
```

```output id="or5678"
Weekend
```

Here:

* `day == 6` → `true`
* `day == 7` → `false`

Because at least one condition is true, the `if` block executes.

---

## 10. Multiple Statements Inside `if`

An `if` block can contain multiple statements.

```java id="multi1234"
public class Main {
    public static void main(String[] args) {
        int marks = 80;

        if (marks >= 35) {
            System.out.println("Pass");
            System.out.println("Congratulations!");
        }
    }
}
```

```output id="multi5678"
Pass
Congratulations!
```

Both statements execute because the condition is true.

The curly braces `{ }` define the block of code controlled by the `if` statement.

---

## 11. When the Condition is False

If the condition is `false`, the code inside the `if` block is skipped.

```java id="false123"
public class Main {
    public static void main(String[] args) {
        int age = 15;

        if (age >= 18) {
            System.out.println("You are an adult.");
        }

        System.out.println("Program continues.");
    }
}
```

```output id="false456"
Program continues.
```

The condition:

```text
15 >= 18
```

is false.

Therefore, the first message is not printed.

The program continues with the next statement.

---

## 12. `if` Without Braces

If an `if` statement controls only one statement, braces can technically be omitted.

For example:

```java id="nobrace12"
public class Main {
    public static void main(String[] args) {
        int number = 10;

        if (number > 5)
            System.out.println("Greater than 5");
    }
}
```

```output id="nobrace34"
Greater than 5
```

However, using braces is recommended because it makes the code easier to read and safer when adding more statements later.

For beginners, prefer:

```java id="brace12"
if (number > 5) {
    System.out.println("Greater than 5");
}
```

---

## 13. A Practical Example

Suppose we want to check whether a student has passed.

Assume the passing mark is `35`.

```java id="pass1234"
public class Main {
    public static void main(String[] args) {
        int marks = 72;

        if (marks >= 35) {
            System.out.println("Student passed.");
        }
    }
}
```

```output id="pass5678"
Student passed.
```

The condition is:

```text
marks >= 35
```

Since `72 >= 35` is true, the message is displayed.

Later, we will learn how to display another message when the condition is false using `if-else`.

---

## 14. Common Mistake: Using `=` Instead of `==`

A common beginner mistake is confusing assignment and comparison.

Incorrect:

```java id="wrong123"
if (number = 10) {
    System.out.println("Number is 10");
}
```

`=` is the assignment operator, not the equality comparison operator.

Use:

```java id="correct456"
if (number == 10) {
    System.out.println("Number is 10");
}
```

Here, `==` correctly checks whether the value is `10`.

---

## 15. `if` Statement with a Boolean Variable

A boolean variable can also be used directly as an `if` condition.

```java id="boolean123"
public class Main {
    public static void main(String[] args) {
        boolean isJavaFun = true;

        if (isJavaFun) {
            System.out.println("Java is fun to learn!");
        }
    }
}
```

```output id="boolean456"
Java is fun to learn!
```

The variable `isJavaFun` already contains a boolean value.

Since it is `true`, the `if` block executes.

---

## Key Points

* The `if` statement is used for decision making.
* Code inside an `if` block runs only when its condition is `true`.
* The condition must produce a boolean result.
* The condition is written inside parentheses `( )`.
* Curly braces `{ }` contain the code controlled by the `if`.
* Relational operators are commonly used with `if`.
* Logical operators can be used to combine multiple conditions.
* `=` is used for assignment.
* `==` is used to compare two values.
* If the condition is `false`, the `if` block is skipped.
* Braces are recommended even when there is only one statement.
