# Chapter 2: Java Fundamentals

## Section 2: Variables, Constants and Data Types

When writing a program, we often need to store information such as:

* Student name
* Age
* Marks
* Price
* Grade
* Whether a student is present or absent

Java provides **variables, constants, and data types** to work with this information.

---

### 1. What is a Variable?

A **variable** is a named storage location used to store a value.

For example:

```java id="v7k3pm"
int age = 18;
```

Here:

* `int` → data type
* `age` → variable name
* `18` → value

We can use the variable later in our program.

```java id="n4q8tx"
public class Main {
    public static void main(String[] args) {
        int age = 18;

        System.out.println(age);
    }
}
```

```output id="c2m6rw"
18
```

The value stored in a variable can also be changed.

```java id="r5p9kd"
public class Main {
    public static void main(String[] args) {
        int age = 18;

        age = 19;

        System.out.println(age);
    }
}
```

```output id="x8f3qa"
19
```

---

### 2. Declaring a Variable

We can declare a variable without giving it a value immediately.

```java id="k6t2mz"
int age;
```

Later, we can assign a value:

```java id="b9w4pc"
age = 18;
```

We can also declare and initialize a variable in one line:

```java id="j3r7vn"
int age = 18;
```

This is commonly used in Java programs.

---

### 3. What is a Data Type?

A **data type** tells Java what kind of value a variable can store.

For example:

```java id="q5m8xs"
int age = 18;
double price = 99.50;
char grade = 'A';
boolean passed = true;
```

Here, each variable stores a different type of value.

| Data Type | Used For             | Example  |
| --------- | -------------------- | -------- |
| `int`     | Whole numbers        | `18`     |
| `double`  | Decimal numbers      | `99.50`  |
| `char`    | A single character   | `'A'`    |
| `boolean` | True or false values | `true`   |
| `String`  | Text                 | `"Java"` |

---

### 4. Integer — `int`

The `int` data type is used to store **whole numbers**.

For example:

```java id="d8k2vf"
public class Main {
    public static void main(String[] args) {
        int age = 18;
        int marks = 95;

        System.out.println(age);
        System.out.println(marks);
    }
}
```

```output id="m4q7xz"
18
95
```

---

### 5. Decimal Numbers — `double`

The `double` data type is commonly used to store decimal numbers.

```java id="h6p3yc"
public class Main {
    public static void main(String[] args) {
        double price = 99.50;

        System.out.println(price);
    }
}
```

```output id="w2n8kr"
99.5
```

Notice that Java prints `99.5` instead of `99.50`. Both represent the same numeric value.

---

### 6. Character — `char`

The `char` data type stores **one character**.

A character is written inside **single quotes**.

```java id="s4v9qm"
public class Main {
    public static void main(String[] args) {
        char grade = 'A';

        System.out.println(grade);
    }
}
```

```output id="p7c3nx"
A
```

A `char` can store one character, such as:

```text
'A'
'7'
'@'
```

---

### 7. True or False — `boolean`

The `boolean` data type stores one of two values:

* `true`
* `false`

For example:

```java id="t8m5rd"
public class Main {
    public static void main(String[] args) {
        boolean isPassed = true;

        System.out.println(isPassed);
    }
}
```

```output id="z3q6wp"
true
```

Boolean values are commonly used when making decisions in a program.

---

### 8. Text — `String`

A `String` is used to store text.

Strings are written inside **double quotes**.

```java id="f2k9vx"
public class Main {
    public static void main(String[] args) {
        String name = "Owais";

        System.out.println(name);
    }
}
```

```output id="n6r4yc"
Owais
```

A string can contain multiple characters, words, or sentences.

For example:

```java
String message = "Welcome to Java!";
```

---

### 9. What is a Constant?

A **constant** is a value that should not be changed after it is assigned.

In Java, we use the `final` keyword to create a constant.

For example:

```java id="c5x8mt"
public class Main {
    public static void main(String[] args) {
        final double PI = 3.14159;

        System.out.println(PI);
    }
}
```

```output id="v9p2ks"
3.14159
```

Once a value is assigned to a `final` variable, we cannot assign another value to it.

For example, this is not allowed:

```java
final int DAYS = 7;
DAYS = 10;
```

A constant is useful when a value should remain unchanged throughout the program.

---

### 10. Variable vs Constant

| Variable                  | Constant                                 |
| ------------------------- | ---------------------------------------- |
| Value can be changed      | Value cannot be changed after assignment |
| Usually declared normally | Uses `final`                             |
| Example: `int age = 18;`  | Example: `final int DAYS = 7;`           |

For example:

```java id="u7m3qa"
int age = 18;
age = 19;
```

The value of `age` changes.

But:

```java id="r8k5xp"
final int DAYS = 7;
```

The value of `DAYS` cannot be changed.

---

### 11. Naming Variables

Java has rules for naming variables.

A variable name:

* Can contain letters, digits, `_`, and `$`.
* Cannot start with a digit.
* Cannot contain spaces.
* Cannot be a Java keyword.
* Is case-sensitive.

For example:

```java
int studentAge = 18;
```

is valid.

But:

```java
int 2age = 18;
```

is invalid because the name starts with a number.

It is good practice to use meaningful names:

```java
int studentAge = 18;
double studentMarks = 95.5;
```

Instead of unclear names such as:

```java
int x = 18;
double y = 95.5;
```

### 12. Basic Java Data Types

Java has eight primitive data types:

| Data Type | Example   | Used For            |
| --------- | --------- | ------------------- |
| `byte`    | `100`     | Small whole numbers |
| `short`   | `1000`    | Whole numbers       |
| `int`     | `50000`   | Whole numbers       |
| `long`    | `100000L` | Large whole numbers |
| `float`   | `10.5f`   | Decimal numbers     |
| `double`  | `10.5`    | Decimal numbers     |
| `char`    | `'A'`     | Single character    |
| `boolean` | `true`    | True or false       |

For beginners, the most commonly used types are:

* `int`
* `double`
* `char`
* `boolean`
* `String`

---

### 13. Using Multiple Variables

We can use different variables in the same program.

```java id="m2q7vc"
public class Main {
    public static void main(String[] args) {
        String name = "Owais";
        int age = 18;
        double marks = 95.5;
        char grade = 'A';
        boolean passed = true;

        System.out.println(name);
        System.out.println(age);
        System.out.println(marks);
        System.out.println(grade);
        System.out.println(passed);
    }
}
```

```output id="k8f4zn"
Owais
18
95.5
A
true
```

This example shows how different types of information can be stored in variables.

## Real-World Example 🌍

Imagine a **student record** in a college application.

The application might need to store:

```text
Name       → "Owais"
Age        → 18
Marks      → 95.5
Grade      → 'A'
Passed     → true
```

In Java, these values can be stored using different data types:

```java id="q6t9pm"
String name = "Owais";
int age = 18;
double marks = 95.5;
char grade = 'A';
boolean passed = true;
```

This makes it easier for the program to work with different kinds of information.

## Key Points

* A **variable** stores a value that can change.
* A **constant** stores a value that should not change.
* The `final` keyword is used to create constants.
* A **data type** tells Java what kind of value a variable stores.
* `int` is commonly used for whole numbers.
* `double` is commonly used for decimal numbers.
* `char` stores a single character.
* `boolean` stores `true` or `false`.
* `String` stores text.
* Java has eight primitive data types.
* Java variable names are case-sensitive.
* Meaningful variable names make programs easier to understand.
