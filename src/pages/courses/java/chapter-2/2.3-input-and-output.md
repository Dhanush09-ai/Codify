# Chapter 2: Java Fundamentals

## Section 3: Input and Output

Input and output are important parts of almost every Java program.

* **Input** means taking information from the user.
* **Output** means displaying information to the user.

For example, a program can ask the user for their name and then display a welcome message.

---

## 1. Output in Java

Java provides `System.out.println()` and `System.out.print()` to display output.

### `System.out.println()`

`println()` displays the given value and then moves the cursor to the next line.

Example:

```java id="q7m2kp"
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
        System.out.println("Welcome to Codify!");
    }
}
```

### Output

```output id="v4n8ds"
Hello, Java!
Welcome to Codify!
```

Each `println()` prints the message on a new line.

---

## 2. Using `System.out.print()`

`print()` displays the value but does **not** move to a new line.

Example:

```java id="r5x9bc"
public class Main {
    public static void main(String[] args) {
        System.out.print("Hello, ");
        System.out.print("Java!");
    }
}
```

### Output

```output id="k2p6hf"
Hello, Java!
```

Here, both messages are printed on the same line.

---

## 3. Difference Between `print()` and `println()`

| Method                 | What it does                           |
| ---------------------- | -------------------------------------- |
| `System.out.print()`   | Prints without moving to the next line |
| `System.out.println()` | Prints and moves to the next line      |

Example:

```java id="m8t3za"
public class Main {
    public static void main(String[] args) {
        System.out.print("A");
        System.out.print("B");
        System.out.println("C");
        System.out.println("D");
    }
}
```

### Output

```output id="j6w4rp"
ABC
D
```

## 4. Taking Input from the User

To take input from the user, Java commonly uses the `Scanner` class.

First, we need to import `Scanner`:

```java
import java.util.Scanner;
```

Then we create a `Scanner` object:

```java
Scanner input = new Scanner(System.in);
```

Here:

* `Scanner` is used to read input.
* `input` is the name of our Scanner object.
* `System.in` means input comes from the keyboard.

---

## 5. Taking Integer Input

The `nextInt()` method is used to read an integer.

Example:

```java id="p3d7kx"
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        System.out.print("Enter your age: ");
        int age = input.nextInt();

        System.out.println("Your age is " + age);
    }
}
```

### Sample Input

```text
18
```

### Output

```output id="h9c2mv"
Enter your age: 18
Your age is 18
```

The value entered by the user is stored in the variable `age`.

---

## 6. Taking Decimal Input

The `nextDouble()` method is used to read a decimal number.

Example:

```java id="t4y8qn"
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        System.out.print("Enter your percentage: ");
        double percentage = input.nextDouble();

        System.out.println("Percentage: " + percentage);
    }
}
```

### Sample Input

```text
95.5
```

### Output

```output id="z5r1wp"
Enter your percentage: 95.5
Percentage: 95.5
```

---

## 7. Taking String Input

There are two commonly used methods for reading strings.

### `next()`

`next()` reads a single word.

Example:

```java id="c8v2lm"
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        System.out.print("Enter your name: ");
        String name = input.next();

        System.out.println("Hello, " + name);
    }
}
```

### Sample Input

```text
Owais
```

### Output

```output id="n6k3xd"
Enter your name: Owais
Hello, Owais
```

If the user enters multiple words, `next()` reads only the first word.

---

## 8. Reading a Full Line

The `nextLine()` method reads a complete line of text, including spaces.

Example:

```java id="b7m4qs"
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        System.out.print("Enter your full name: ");
        String name = input.nextLine();

        System.out.println("Hello, " + name);
    }
}
```

### Sample Input

```text
Mohammed Owais
```

### Output

```output id="w2f9ka"
Enter your full name: Mohammed Owais
Hello, Mohammed Owais
```

### `next()` vs `nextLine()`

| Method       | Reads         |
| ------------ | ------------- |
| `next()`     | One word      |
| `nextLine()` | Complete line |

---

## 9. Taking Character Input

`Scanner` does not have a `nextChar()` method.

To read a character, we can read a string and then use `charAt(0)`.

Example:

```java id="x5q8nc"
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        System.out.print("Enter a character: ");
        char ch = input.next().charAt(0);

        System.out.println("Character: " + ch);
    }
}
```

### Sample Input

```text
A
```

### Output

```output id="e3k7vz"
Enter a character: A
Character: A
```

`charAt(0)` gets the first character of the entered word.

---

## 10. Taking Multiple Inputs

We can take different types of input in the same program.

Example:

```java id="u9p2fd"
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        System.out.print("Enter your name: ");
        String name = input.next();

        System.out.print("Enter your age: ");
        int age = input.nextInt();

        System.out.print("Enter your percentage: ");
        double percentage = input.nextDouble();

        System.out.println("Name: " + name);
        System.out.println("Age: " + age);
        System.out.println("Percentage: " + percentage);
    }
}
```

### Sample Input

```text
Owais
18
95.5
```

### Output

```output id="s4m8ye"
Enter your name: Owais
Enter your age: 18
Enter your percentage: 95.5
Name: Owais
Age: 18
Percentage: 95.5
```

## 11. Common Scanner Methods

Here are some commonly used `Scanner` methods:

| Method             | Used for      |
| ------------------ | ------------- |
| `nextInt()`        | Integer input |
| `nextDouble()`     | Decimal input |
| `next()`           | One word      |
| `nextLine()`       | Complete line |
| `next().charAt(0)` | One character |

## 12. A Simple Input and Output Program

Let's combine what we learned into a simple student program.

```java id="a6r3ty"
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        System.out.print("Enter your name: ");
        String name = input.nextLine();

        System.out.print("Enter your age: ");
        int age = input.nextInt();

        System.out.println();
        System.out.println("Student Details");
        System.out.println("Name: " + name);
        System.out.println("Age: " + age);
    }
}
```

### Sample Input

```text
Mohammed Owais
18
```

### Output

```output id="d8q5mb"
Enter your name: Mohammed Owais
Enter your age: 18

Student Details
Name: Mohammed Owais
Age: 18
```

This is a basic example of how Java programs can interact with users.

---

## Key Points

* `System.out.print()` displays output without moving to a new line.
* `System.out.println()` displays output and moves to the next line.
* `Scanner` is commonly used to take keyboard input.
* `nextInt()` reads an integer.
* `nextDouble()` reads a decimal number.
* `next()` reads one word.
* `nextLine()` reads a complete line.
* `next().charAt(0)` can be used to read a character.
* `Scanner` must be imported using `import java.util.Scanner;`.
