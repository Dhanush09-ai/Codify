# Chapter 2: Java Fundamentals

## Section 4: Type Casting and Type Conversion

In Java, variables have different data types such as `int`, `double`, `char`, and `float`.

Sometimes, we need to change a value from one data type to another.

This is called **type conversion** or **type casting**.

For example:

```text
int → double
double → int
```

There are two main types:

1. **Widening Type Casting**
2. **Narrowing Type Casting**

---

## 1. What Is Type Conversion?

Type conversion means changing a value from one data type to another data type.

For example, an `int` value can be converted into a `double`.

```java id="a7k3pm"
public class Main {
    public static void main(String[] args) {
        int number = 10;
        double value = number;

        System.out.println(number);
        System.out.println(value);
    }
}
```


```output id="q4n8xz"
10
10.0
```

The integer `10` is converted to the double value `10.0`.

---

## 2. Widening Type Casting

**Widening casting** means converting a smaller data type into a larger data type.

It is usually done automatically by Java.

For example:

```text
int → double
```

An `int` can be safely stored in a `double` because `double` can represent a larger range of numeric values.

Example:

```java id="m5r2vc"
public class Main {
    public static void main(String[] args) {
        int number = 25;
        double value = number;

        System.out.println("Integer: " + number);
        System.out.println("Double: " + value);
    }
}
```


```output id="j8p6wd"
Integer: 25
Double: 25.0
```

No special casting syntax is required.

---

## 3. Common Widening Conversions

Some common widening conversions are:

```text
byte → short
short → int
int → long
long → float
float → double
```

For example:

```java id="c9t4ys"
public class Main {
    public static void main(String[] args) {
        int number = 50;
        long value = number;

        System.out.println("Integer: " + number);
        System.out.println("Long: " + value);
    }
}
```


```output id="v3k7qa"
Integer: 50
Long: 50
```

---

## 4. Narrowing Type Casting

**Narrowing casting** means converting a larger data type into a smaller data type.

Java does not perform this conversion automatically because some information may be lost.

For example:

```text
double → int
```

We need to explicitly tell Java to perform the conversion.

The basic syntax is:

```text
smallerType variable = (smallerType) value;
```

Example:

```java id="n6b4xz"
public class Main {
    public static void main(String[] args) {
        double number = 25.75;
        int value = (int) number;

        System.out.println("Double: " + number);
        System.out.println("Integer: " + value);
    }
}
```


```output id="f2m8kp"
Double: 25.75
Integer: 25
```

The decimal part `.75` is removed.

> **Remember:** Converting `double` to `int` does not round the number. The decimal part is discarded.

---

## 5. Casting Using Parentheses

The type that we want to convert to is written inside parentheses.

For example:

```java
int value = (int) 12.8;
```

Here:

* `(int)` tells Java to convert the value to an integer.
* `12.8` is the original `double` value.
* The resulting value is `12`.

Example:

```java id="p7c3mh"
public class Main {
    public static void main(String[] args) {
        double number = 12.8;
        int value = (int) number;

        System.out.println(value);
    }
}
```


```output id="r5d9wa"
12
```

---

## 6. Widening vs Narrowing Casting

| Feature              | Widening Casting           | Narrowing Casting          |
| :------------------- | :------------------------- | :------------------------- |
| Direction            | Smaller type → Larger type | Larger type → Smaller type |
| Done automatically   | Usually yes                | No                         |
| Data loss            | Usually no                 | Possible                   |
| Example              | `int → double`             | `double → int`             |
| Explicit cast needed | No                         | Yes                        |

---

## 7. Type Casting with Arithmetic

Type casting can also be useful when performing calculations.

Consider this example:

```java id="x2q6vn"
public class Main {
    public static void main(String[] args) {
        int a = 5;
        int b = 2;

        double result = (double) a / b;

        System.out.println(result);
    }
}
```


```output id="k8m4ts"
2.5
```

The `(double)` converts `a` into a `double`.

Therefore, Java performs decimal division.

Without casting:

```java
int result = a / b;
```

the result would be an integer.

Example:

```java id="z6p3fc"
public class Main {
    public static void main(String[] args) {
        int a = 5;
        int b = 2;

        int result = a / b;

        System.out.println(result);
    }
}
```


```output id="d4v9hy"
2
```

The decimal part is not stored because both operands are integers.

---

## 8. Type Conversion with `char`

A `char` can also participate in numeric conversions.

For example:

```java id="h7m2qx"
public class Main {
    public static void main(String[] args) {
        char letter = 'A';
        int number = letter;

        System.out.println(letter);
        System.out.println(number);
    }
}
```


```output id="s9c5ke"
A
65
```

The character `'A'` has the numeric value `65` in Java's character encoding.

---

## 9. Converting `int` to `char`

We can explicitly cast an integer to a character.

Example:

```java id="w4n8cz"
public class Main {
    public static void main(String[] args) {
        int number = 66;
        char letter = (char) number;

        System.out.println(letter);
    }
}
```


```output id="b6q2xp"
B
```

The integer `66` corresponds to the character `B`.

---

## 10. Type Conversion with User Input

Type casting can be useful when working with values taken from the user.

Example:

```java id="e8r3mv"
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        System.out.print("Enter a decimal number: ");
        double number = input.nextDouble();

        int value = (int) number;

        System.out.println("Original: " + number);
        System.out.println("Integer: " + value);
    }
}
```

### Sample Input

```text id="u5k9pd"
45.89
```


```output id="n3x7qa"
Enter a decimal number: 45.89
Original: 45.89
Integer: 45
```

---

## 11. Type Conversion Example

Suppose a student has marks stored as an integer:

```java
int marks = 95;
```

We can convert them to a `double`:

```java
double percentage = marks;
```

Example:

```java id="t9c4wb"
public class Main {
    public static void main(String[] args) {
        int marks = 95;
        double percentage = marks;

        System.out.println("Marks: " + marks);
        System.out.println("Percentage: " + percentage);
    }
}
```


```output id="f7m2kc"
Marks: 95
Percentage: 95.0
```

---

## Key Points

* Type conversion changes a value from one data type to another.
* **Widening casting** converts a smaller type to a larger type.
* Widening conversion is usually performed automatically.
* **Narrowing casting** converts a larger type to a smaller type.
* Narrowing conversion requires explicit casting.
* Explicit casting uses parentheses, such as `(int)`.
* Narrowing a `double` to an `int` removes the decimal part.
* Type casting can also affect arithmetic calculations.
* `char` values can be converted to numeric values and vice versa.
