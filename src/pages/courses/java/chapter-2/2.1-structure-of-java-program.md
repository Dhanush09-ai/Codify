# Chapter 2: Java Fundamentals

## Section 1: Structure of a Java Program

A Java program is made up of different parts.

Understanding the basic structure of a Java program will help you read and write Java code more easily.

Let's start with a simple Java program.

```java id="m42ktz"
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
```

```output id="ceeinu"
Hello, Java!
```

Now let's understand each part.

---

### 1. Class Declaration

A Java program usually contains a **class**.

In our example:

```java
public class Main {
}
```

Here:

* `public` is an access modifier.
* `class` tells Java that we are creating a class.
* `Main` is the name of the class.

The class name is `Main`.

If the class is declared as `public`, the file name should match the class name.

So:

```text
Main.java
```

contains:

```java
public class Main
```

---

### 2. The Main Method

Inside the class, we have the `main()` method:

```java
public static void main(String[] args) {
}
```

The `main()` method is where execution starts for a simple Java application.

When we run the program, Java starts executing the statements inside this method.

---

### 3. Statements

A **statement** is an instruction given to Java.

For example:

```java
System.out.println("Hello, Java!");
```

This statement tells Java to display a message.

Most Java statements end with a **semicolon `;`**.

For example:

```java
System.out.println("Hello");
System.out.println("Welcome");
```

---

### 4. Curly Braces `{ }`

Curly braces are used to define a **block of code**.

For example:

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
```

The outer braces belong to the `Main` class.

The inner braces belong to the `main()` method.

You can think of braces as showing where a particular part of the program starts and ends.

---

### 5. The `System.out.println()` Statement

The following statement displays text on the screen:

```java
System.out.println("Hello, Java!");
```

For example:

```java id="s7k2qp"
public class Main {
    public static void main(String[] args) {
        System.out.println("Welcome to Codify!");
    }
}
```

```output id="r4m8xd"
Welcome to Codify!
```

The text inside `" "` is called a **string**.

---

### 6. Comments

Comments are notes written inside a program.

They are useful for explaining code.

Java supports single-line comments using `//`.

```java id="v3n6qa"
public class Main {
    public static void main(String[] args) {
        // Display a welcome message
        System.out.println("Welcome to Java!");
    }
}
```

```output id="t8p2kw"
Welcome to Java!
```

The comment is not executed by Java.

We will learn more about comments later in the course.

---

### 7. Indentation

Indentation means adding spaces before code to make it easier to read.

For example:

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
```

The spaces make it clear which code belongs to the class and which code belongs to the `main()` method.

Java does not require indentation for the program to work, but **good indentation makes code easier to read and understand**.

---

### 8. A Complete Java Program

Let's look at the complete structure again:

```java id="m42ktz"
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
```

```output id="ceeinu"
Hello, Java!
```

The basic structure can be represented as:

```text id="h5c9mz"
Class
│
└── main() method
    │
    └── Statements
```

This is the basic structure you will see in many beginner Java programs.

---

## Understanding the Structure

Let's break the program into parts:

```java
public class Main {                 // Class
    public static void main(String[] args) {  // Main method
        System.out.println("Hello, Java!");   // Statement
    }
}
```

| Part                   | Purpose                                     |
| ---------------------- | ------------------------------------------- |
| `public`               | Access modifier                             |
| `class`                | Defines a class                             |
| `Main`                 | Class name                                  |
| `main()`               | Starting point of a simple Java application |
| `{ }`                  | Defines a block of code                     |
| `System.out.println()` | Displays output                             |
| `;`                    | Ends a statement                            |

You don't need to memorize every keyword immediately. As you continue through the course, each part will become easier to understand.

---

## Real-World Example 🌍

Think about a **college building**.

The building contains different rooms.

Similarly, a Java class can contain different parts of a program.

For example:

```text
Java Program
     ↓
   Class
     ↓
   main()
     ↓
 Statements
```

The class provides the overall structure, the `main()` method provides the starting point, and statements perform the actual tasks.

---

## Key Points

* A Java program is organized using **classes**.
* A simple Java application usually has a `main()` method.
* Program execution starts from the `main()` method.
* Statements are instructions given to Java.
* Most Java statements end with a semicolon `;`.
* Curly braces `{ }` define blocks of code.
* `System.out.println()` is used to display output.
* Comments can be used to explain code.
* Proper indentation makes Java code easier to read.
