# Chapter 9: More Java Fundamentals

## Section 3: final Keyword

In the previous topics, we learned about different types of variables, including local, instance, and static variables.

Now, we will learn about the **`final` keyword** in Java.

The `final` keyword is used when we want something to become fixed and not be changed in a particular way.

We will learn how to:

* Understand the `final` keyword
* Create final variables
* Understand constants
* Use `final` with local variables
* Use `final` with instance variables
* Use `final` with static variables
* Understand the difference between `final` and `static`
* Avoid common mistakes with `final`

## 1. What Is the `final` Keyword?

The `final` keyword is used to prevent a variable from being assigned a new value after it has been initialized.

For example:

```java id="s93001"
public class Main {
    public static void main(String[] args) {
        final int age = 16;

        System.out.println(age);
    }
}
```

### Output:

```output id="o93001"
16
```

Here, `age` is a final variable.

Once `age` has been assigned `16`, we cannot assign another value to it.

---

## 2. Trying to Change a Final Variable

A final variable cannot be reassigned.

For example:

```java id="final_error_1"
public class Main {
    public static void main(String[] args) {
        final int age = 16;

        age = 17;
    }
}
```

This causes a **compilation error** because `age` is final and cannot be assigned a new value.

---

## 3. Final Variables Are Read-Only After Initialization

A final variable can be read and used like a normal variable.

It simply cannot be assigned a new value.

### Example:

```java id="s93002"
public class Main {
    public static void main(String[] args) {
        final int marks = 95;

        System.out.println(marks);
        System.out.println(marks + 5);
    }
}
```

### Output:

```output id="o93002"
95
100
```

The value of `marks` itself is not changed.

---

## 4. Final Variables Must Be Initialized Before Use

A final variable must receive a value before it is used.

### Example:

```java id="s93003"
public class Main {
    public static void main(String[] args) {
        final int number;

        number = 10;

        System.out.println(number);
    }
}
```

### Output:

```output id="o93003"
10
```

Here, `number` is declared first and assigned a value later.

After it is assigned, it cannot be assigned again.

---

## 5. A Final Variable Can Be Assigned Only Once

A final variable can be assigned only once.

### Example:

```java id="s93004"
public class Main {
    public static void main(String[] args) {
        final int number;

        number = 10;

        System.out.println(number);
    }
}
```

### Output:

```output id="o93004"
10
```

This is valid because `number` receives its value only once.

Trying to assign it again causes a compilation error.

---

## 6. Final Local Variables

A final variable declared inside a method is a **final local variable**.

### Example:

```java id="s93005"
public class Main {
    public static void main(String[] args) {
        final double pi = 3.14159;

        System.out.println(pi);
    }
}
```

### Output:

```output id="o93005"
3.14159
```

Here, `pi` is a final local variable.

---

## 7. Using a Final Variable in a Calculation

A final variable can be used in calculations.

### Example:

```java id="s93006"
public class Main {
    public static void main(String[] args) {
        final int price = 100;
        int quantity = 3;

        int total = price * quantity;

        System.out.println(total);
    }
}
```

### Output:

```output id="o93006"
300
```

The `price` cannot be changed, but it can be used in calculations.

---

## 8. Final Instance Variables

An instance variable can also be declared as `final`.

### Example:

```java id="s93007"
class Student {
    final int rollNumber = 101;
}

public class Main {
    public static void main(String[] args) {
        Student student = new Student();

        System.out.println(student.rollNumber);
    }
}
```

### Output:

```output id="o93007"
101
```

Here, `rollNumber` is a final instance variable.

Its value cannot be reassigned after initialization.

---

## 9. Final Instance Variables for Object Data

A final instance variable can be used when an object's value should not change after it has been assigned.

### Example:

```java id="s93008"
class Student {
    final String id;

    Student(String id) {
        this.id = id;
    }
}

public class Main {
    public static void main(String[] args) {
        Student student = new Student("ST101");

        System.out.println(student.id);
    }
}
```

### Output:

```output id="o93008"
ST101
```

Here, `id` is assigned through the constructor.

Once assigned, it cannot be assigned again for that object.

---

## 10. Final Static Variables

A variable can be both `static` and `final`.

### Example:

```java id="s93009"
class Student {
    static final String COLLEGE = "CODIFY College";
}

public class Main {
    public static void main(String[] args) {
        System.out.println(Student.COLLEGE);
    }
}
```

### Output:

```output id="o93009"
CODIFY College
```

Here:

* `static` means the variable belongs to the class.
* `final` means its value cannot be changed.

---

## 11. Constants

A `static final` variable is commonly used to represent a **constant**.

A constant is a value that should remain fixed throughout the program.

By convention, constant names are usually written in uppercase letters.

### Example:

```java id="s93010"
public class Main {

    static final double PI = 3.14159;

    public static void main(String[] args) {
        System.out.println(PI);
    }
}
```

### Output:

```output id="o93010"
3.14159
```

`PI` is a constant because its value should not be changed.

---

## 12. Why Use Constants?

Constants make programs easier to understand.

For example:

```java id="s93011"
public class Main {

    static final int DAYS_IN_WEEK = 7;

    public static void main(String[] args) {
        int weeks = 3;

        System.out.println(weeks * DAYS_IN_WEEK);
    }
}
```

### Output:

```output id="o93011"
21
```

The name `DAYS_IN_WEEK` clearly explains what the value `7` represents.

---

## 13. `final` vs Normal Variable

A normal variable can be reassigned.

A final variable cannot be reassigned.

### Example:

```java id="s93012"
public class Main {
    public static void main(String[] args) {
        int normalNumber = 10;
        final int finalNumber = 20;

        normalNumber = 30;

        System.out.println(normalNumber);
        System.out.println(finalNumber);
    }
}
```

### Output:

```output id="o93012"
30
20
```

`normalNumber` can change, while `finalNumber` cannot be assigned a new value.

---

## 14. `final` vs `static`

The `final` and `static` keywords have different purposes.

| Keyword  | Basic meaning                      |
| -------- | ---------------------------------- |
| `final`  | Prevents reassignment              |
| `static` | Associates a member with the class |

They can also be used together.

For example:

```java id="s93013"
class College {
    static final String NAME = "CODIFY College";
}

public class Main {
    public static void main(String[] args) {
        System.out.println(College.NAME);
    }
}
```

### Output:

```output id="o93013"
CODIFY College
```

Here, `NAME` belongs to the class and cannot be reassigned.

---

## 15. Final Reference Variables — Basic Idea

The `final` keyword can also be used with a reference variable.

For beginners, remember that `final` prevents the reference from being assigned to another object.

It does not automatically make the object itself completely unchangeable.

### Example:

```java id="s93014"
public class Main {
    public static void main(String[] args) {
        final int[] numbers = {10, 20};

        numbers[0] = 50;

        System.out.println(numbers[0]);
    }
}
```

### Output:

```output id="o93014"
50
```

The array contents can still be changed.

The final reference cannot simply be assigned to a different array.

---

## 16. Common Mistakes with `final`

### Mistake 1: Trying to change a final variable

```java id="mistake_final_1"
final int number = 10;
number = 20;
```

This causes a compilation error.

### Mistake 2: Thinking `final` means the value can never be used

A final variable can still be used in calculations and expressions.

```java id="s93015"
public class Main {
    public static void main(String[] args) {
        final int price = 50;

        int total = price * 2;

        System.out.println(total);
    }
}
```

### Output:

```output id="o93015"
100
```

### Mistake 3: Confusing `final` with `static`

`final` controls reassignment.

`static` controls whether a member belongs to the class rather than an individual object.

---

## 17. Choosing Between Normal and Final Variables

Use a normal variable when its value needs to change.

Use a final variable when its value should not be reassigned.

### Example:

```java id="s93016"
public class Main {
    public static void main(String[] args) {
        final int MAX_MARKS = 100;
        int marks = 85;

        System.out.println("Maximum marks: " + MAX_MARKS);
        System.out.println("Student marks: " + marks);
    }
}
```

### Output:

```output id="o93016"
Maximum marks: 100
Student marks: 85
```

Here, `MAX_MARKS` is fixed, while `marks` can change.

---

## 18. Final Variables and Methods

A final variable can be used inside methods just like other variables.

### Example:

```java id="s93017"
public class Main {

    static final int BONUS = 10;

    static int calculateMarks(int marks) {
        return marks + BONUS;
    }

    public static void main(String[] args) {
        System.out.println(calculateMarks(80));
    }
}
```

### Output:

```output id="o93017"
90
```

The method uses the final constant `BONUS` in its calculation.

---

## 19. Common Uses of `final`

The `final` keyword is commonly useful when a value should remain fixed.

Examples include:

* Maximum marks
* Number of days in a week
* Mathematical constants
* Fixed configuration values
* IDs that should not be reassigned
* Other values that should remain constant

For example:

```java id="s93018"
public class Main {

    static final int DAYS_IN_WEEK = 7;
    static final int MAX_MARKS = 100;

    public static void main(String[] args) {
        System.out.println(DAYS_IN_WEEK);
        System.out.println(MAX_MARKS);
    }
}
```

### Output:

```output id="o93018"
7
100
```

---

## 20. Quick Example

Let's use different types of final variables in one program.

```java id="s93019"
class Student {
    final int rollNumber;

    static final String COLLEGE = "CODIFY College";

    Student(int rollNumber) {
        this.rollNumber = rollNumber;
    }
}

public class Main {
    public static void main(String[] args) {
        final int age = 16;

        Student student = new Student(101);

        System.out.println(age);
        System.out.println(student.rollNumber);
        System.out.println(Student.COLLEGE);
    }
}
```

### Output:

```output id="o93019"
16
101
CODIFY College
```

Here:

* `age` is a final local variable.
* `rollNumber` is a final instance variable.
* `COLLEGE` is a final static variable and acts as a constant.

## Key Points

* The `final` keyword prevents a variable from being reassigned.
* A final variable can be assigned only once.
* A final variable can still be read and used in calculations.
* Final variables can be local, instance, or static variables.
* A `static final` variable is commonly used as a constant.
* Constant names are conventionally written in uppercase letters.
* `final` and `static` have different purposes.
* `final` prevents reassignment.
* `static` associates a member with the class.
* A final reference cannot be assigned to another object, but the referenced object's contents may still be changeable.
