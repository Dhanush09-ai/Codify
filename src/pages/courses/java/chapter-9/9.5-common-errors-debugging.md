# Chapter 9: More Java Fundamentals

## Section 5: Common Java Errors and Debugging

In the previous topics, we learned about variables, the `final` keyword, and wrapper classes.

While writing Java programs, you may sometimes get errors or unexpected results.

Understanding common errors and learning how to debug them is an important part of programming.

Now, we will learn how to:

* Understand common types of Java errors
* Understand syntax errors
* Understand compilation errors
* Understand runtime errors
* Understand logical errors
* Read error messages
* Find errors using line numbers
* Use debugging techniques
* Avoid common programming mistakes

## 1. What Is an Error?

An error is a problem in a program that prevents it from compiling, running, or producing the expected result.

For example:

```java id="s95001"
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello Java");
    }
}
```


```output id="o95001"
Hello Java
```

This program has no error.

But if we accidentally write the code incorrectly, Java may report an error.

---

## 2. Main Types of Errors

Java programs can commonly have three types of errors:

1. Syntax or compilation errors
2. Runtime errors
3. Logical errors

Each type happens at a different stage.

| Error Type                 | When it happens                                     |
| -------------------------- | --------------------------------------------------- |
| Syntax / Compilation Error | While compiling the program                         |
| Runtime Error              | While the program is running                        |
| Logical Error              | When the program runs but produces the wrong result |

---

## 3. Syntax Errors

A syntax error happens when the code does not follow Java's syntax rules.

For example, forgetting a semicolon can cause an error.

```java id="syntax_error_1"
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello")
    }
}
```

The semicolon is missing after `println("Hello")`.

Java will report a compilation error.

The program cannot run successfully until the error is fixed.

---

## 4. Missing Braces

Curly braces `{ }` are important in Java.

For example:

```java id="syntax_error_2"
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello");
}
```

A closing brace is missing.

Java will report a compilation error because the braces do not match correctly.

The corrected program is:

```java id="s95002"
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello");
    }
}
```


```output id="o95002"
Hello
```

---

## 5. Compilation Errors

A compilation error occurs when Java cannot successfully compile the source code.

For example:

```java id="compilation_error_1"
public class Main {
    public static void main(String[] args) {
        int number = "10";
    }
}
```

Here, `"10"` is a String, but `number` is declared as an `int`.

Java reports a compilation error because the types do not match.

The correct code is:

```java id="s95003"
public class Main {
    public static void main(String[] args) {
        int number = 10;

        System.out.println(number);
    }
}
```


```output id="o95003"
10
```

---

## 6. Using an Undeclared Variable

Java does not allow us to use a variable that has not been declared.

For example:

```java id="undeclared_error"
public class Main {
    public static void main(String[] args) {
        System.out.println(number);
    }
}
```

The variable `number` has not been declared.

This causes a compilation error.

The corrected version is:

```java id="s95004"
public class Main {
    public static void main(String[] args) {
        int number = 10;

        System.out.println(number);
    }
}
```


```output id="o95004"
10
```

---

## 7. Runtime Errors

A runtime error occurs while the program is running.

The program may compile successfully but then fail during execution.

For example:

```java id="runtime_error_1"
public class Main {
    public static void main(String[] args) {
        int number = 10 / 0;

        System.out.println(number);
    }
}
```

This code compiles, but dividing an integer by zero causes an `ArithmeticException` during execution.

---

## 8. Array Index Error

Another common runtime error occurs when we try to access an invalid array index.

### Example:

```java id="runtime_error_2"
public class Main {
    public static void main(String[] args) {
        int[] numbers = {10, 20, 30};

        System.out.println(numbers[3]);
    }
}
```

The valid indexes are:

```text id="e8u4l1"
0  1  2
```

Index `3` does not exist.

This causes an `ArrayIndexOutOfBoundsException`.

---

## 9. String Index Error

A similar problem can happen with Strings.

### Example:

```java id="runtime_error_3"
public class Main {
    public static void main(String[] args) {
        String word = "Java";

        System.out.println(word.charAt(4));
    }
}
```

The valid indexes are `0` to `3`.

Index `4` is outside the String, so Java throws a `StringIndexOutOfBoundsException`.

---

## 10. `NullPointerException`

A `NullPointerException` can occur when we try to use a method or access something through a reference that is `null`.

### Example:

```java id="runtime_error_4"
public class Main {
    public static void main(String[] args) {
        String name = null;

        System.out.println(name.length());
    }
}
```

Here, `name` does not refer to a String object.

Calling `length()` on it causes a `NullPointerException`.

---

## 11. Logical Errors

A logical error is different from a syntax or runtime error.

The program may compile and run successfully, but the result is incorrect.

### Example:

```java id="s95005"
public class Main {
    public static void main(String[] args) {
        int length = 10;
        int width = 5;

        int area = length + width;

        System.out.println(area);
    }
}
```


```output id="o95005"
15
```

The program runs, but the calculation is wrong because the area of a rectangle should be calculated using multiplication.

The corrected code is:

```java id="s95006"
public class Main {
    public static void main(String[] args) {
        int length = 10;
        int width = 5;

        int area = length * width;

        System.out.println(area);
    }
}
```


```output id="o95006"
50
```

---

## 12. What Is Debugging?

**Debugging** is the process of finding and fixing errors in a program.

When a program does not work correctly, we can:

1. Read the error message.
2. Find the location of the error.
3. Understand what caused it.
4. Fix the code.
5. Run the program again.
6. Check the result.

Debugging is a normal part of programming.

---

## 13. Reading Error Messages

Java error messages often provide useful information.

For example, an error may contain:

* The type of error
* The file name
* The line number
* A description of the problem

A line number tells you where Java detected the problem.

However, the actual cause can sometimes be on an earlier line.

So, do not only look at the exact line mentioned. Check the surrounding code too.

---

## 14. Using Line Numbers

Suppose Java reports an error on line 5.

You should:

* Go to line 5.
* Read the statement carefully.
* Check the previous line.
* Check brackets and semicolons.
* Check variable names and data types.

For example:

```java id="s95007"
public class Main {
    public static void main(String[] args) {
        int number = 10;

        System.out.println(number);
    }
}
```

If there is an error, the line number can help you quickly locate the area that needs checking.

---

## 15. Check Spelling and Capitalization

Java is **case-sensitive**.

For example:

```java id="case_error"
public class Main {
    public static void main(String[] args) {
        String name = "Owais";

        System.out.println(Name);
    }
}
```

This causes a compilation error because `name` and `Name` are different identifiers.

The corrected code is:

```java id="s95008"
public class Main {
    public static void main(String[] args) {
        String name = "Owais";

        System.out.println(name);
    }
}
```


```output id="o95008"
Owais
```

---

## 16. Check Brackets and Quotes

Missing or incorrect brackets and quotation marks are common beginner mistakes.

For example:

```java id="bracket_error"
System.out.println("Hello;
```

The closing quotation mark is missing.

The corrected version is:

```java id="s95009"
System.out.println("Hello");
```


```output id="o95009"
Hello
```

When debugging, check:

* `()`
* `{}`
* `[]`
* `""`
* `''`

---

## 17. Check Data Types

Make sure that the value being assigned matches the variable's data type.

For example:

```java id="datatype_error"
int age = "16";
```

This is incorrect because `"16"` is a String.

The correct version is:

```java id="s95010"
int age = 16;

System.out.println(age);
```


```output id="o95010"
16
```

---

## 18. Check the Program's Logic

If the program runs but produces the wrong answer, check the logic.

For example:

```java id="s95011"
public class Main {
    public static void main(String[] args) {
        int a = 20;
        int b = 10;

        int result = a - b;

        System.out.println(result);
    }
}
```


```output id="o95011"
10
```

If subtraction was intended, the result is correct.

If addition was intended, the logic needs to be changed.

Debugging is not always about fixing syntax. Sometimes we need to understand what the program is supposed to do and compare that with what it actually does.

---

## 19. Simple Debugging Techniques

Beginners can use several simple techniques when debugging.

### Technique 1: Read the error message

Do not immediately ignore the message.

### Technique 2: Check the line number

Look at the line mentioned by the compiler.

### Technique 3: Check nearby lines

The actual mistake may be before the reported line.

### Technique 4: Print values

Use `System.out.println()` to see the values of variables.

### Example:

```java id="s95012"
public class Main {
    public static void main(String[] args) {
        int a = 10;
        int b = 5;

        System.out.println("a = " + a);
        System.out.println("b = " + b);

        int result = a + b;

        System.out.println("result = " + result);
    }
}
```


```output id="o95012"
a = 10
b = 5
result = 15
```

Printing values can help us understand what is happening inside the program.

## 20. Common Beginner Mistakes

Some common mistakes include:

* Forgetting semicolons
* Missing `{ }`
* Missing `"` or `'`
* Using an undeclared variable
* Using the wrong data type
* Spelling a variable name incorrectly
* Using the wrong capitalization
* Accessing an invalid array or String index
* Dividing an integer by zero
* Writing incorrect logic
* Forgetting that Java is case-sensitive

Checking these areas can help you find many beginner-level errors.

---

## 21. Quick Example

Let's look at a simple program and identify a logical error.

Incorrect version:

```java id="s95013"
public class Main {
    public static void main(String[] args) {
        int marks1 = 80;
        int marks2 = 90;

        int total = marks1 - marks2;

        System.out.println("Total: " + total);
    }
}
```


```output id="o95013"
Total: -10
```

The program runs, but the logic is incorrect if we want the total marks.

Correct version:

```java id="s95014"
public class Main {
    public static void main(String[] args) {
        int marks1 = 80;
        int marks2 = 90;

        int total = marks1 + marks2;

        System.out.println("Total: " + total);
    }
}
```


```output id="o95014"
Total: 170
```

This is a logical error because the original program was valid Java syntax and could run, but it did not perform the intended calculation.

## Key Points

* Errors are a normal part of programming.
* Syntax and compilation errors prevent a program from compiling successfully.
* Runtime errors happen while the program is running.
* Logical errors allow the program to run but produce an incorrect result.
* Read error messages carefully.
* Use line numbers to locate the area of a problem.
* Check the surrounding lines as well.
* Java is case-sensitive.
* Check brackets, quotation marks, semicolons, and data types.
* Invalid array and String indexes can cause runtime errors.
* `NullPointerException` can occur when using a `null` reference.
* Debugging means finding and fixing problems in a program.
* `System.out.println()` can help inspect variable values while debugging.
