# Chapter 9: More Java Fundamentals

## Section 4: Wrapper Classes — Basic Introduction

In the previous topics, we learned about variables, the `final` keyword, and different types of variables in Java.

Now, we will learn about **Wrapper Classes**.

Wrapper classes allow primitive data types such as `int`, `double`, and `boolean` to be represented as objects.

We will learn how to:

* Understand primitive data types and wrapper classes
* Learn the common wrapper classes
* Create wrapper class objects
* Understand autoboxing
* Understand unboxing
* Convert Strings into numbers
* Convert numbers into Strings
* Use common wrapper class methods
* Understand when wrapper classes are useful

## 1. What Are Wrapper Classes?

Java has primitive data types such as:

```text
int
double
char
boolean
```

Wrapper classes provide an object version of these primitive types.

For example:

| Primitive Type | Wrapper Class |
| -------------- | ------------- |
| `byte`         | `Byte`        |
| `short`        | `Short`       |
| `int`          | `Integer`     |
| `long`         | `Long`        |
| `float`        | `Float`       |
| `double`       | `Double`      |
| `char`         | `Character`   |
| `boolean`      | `Boolean`     |

For example, the wrapper class for `int` is `Integer`.

---

## 2. Primitive Type vs Wrapper Class

A primitive variable stores a primitive value directly.

### Example:

```java id="s94001"
public class Main {
    public static void main(String[] args) {
        int number = 10;
        Integer wrappedNumber = 10;

        System.out.println(number);
        System.out.println(wrappedNumber);
    }
}
```

### Output:

```output id="o94001"
10
10
```

Here:

* `int` is a primitive type.
* `Integer` is a wrapper class.

Both can represent the value `10`, but they are different types.

---

## 3. Common Wrapper Classes

Java provides wrapper classes for all primitive data types.

| Primitive | Wrapper     |
| --------- | ----------- |
| `byte`    | `Byte`      |
| `short`   | `Short`     |
| `int`     | `Integer`   |
| `long`    | `Long`      |
| `float`   | `Float`     |
| `double`  | `Double`    |
| `char`    | `Character` |
| `boolean` | `Boolean`   |

One important point is that the wrapper class names usually start with a capital letter.

## 4. Creating Wrapper Objects

We can create wrapper class values using their wrapper classes.

For example:

```java id="s94002"
public class Main {
    public static void main(String[] args) {
        Integer number = Integer.valueOf(25);
        Double price = Double.valueOf(99.5);

        System.out.println(number);
        System.out.println(price);
    }
}
```

### Output:

```output id="o94002"
25
99.5
```

`valueOf()` creates a wrapper object representing the given value.

---

## 5. Autoboxing

Java can automatically convert a primitive value into its corresponding wrapper type.

This is called **autoboxing**.

### Example:

```java id="s94003"
public class Main {
    public static void main(String[] args) {
        int number = 10;

        Integer wrappedNumber = number;

        System.out.println(wrappedNumber);
    }
}
```

### Output:

```output id="o94003"
10
```

Java automatically converts the `int` value into an `Integer`.

---

## 6. Unboxing

**Unboxing** is the opposite of autoboxing.

It means converting a wrapper object into its corresponding primitive type.

### Example:

```java id="s94004"
public class Main {
    public static void main(String[] args) {
        Integer wrappedNumber = 20;

        int number = wrappedNumber;

        System.out.println(number);
    }
}
```

### Output:

```output id="o94004"
20
```

Java automatically converts the `Integer` object into an `int`.

---

## 7. Autoboxing and Unboxing Together

Autoboxing and unboxing can happen automatically when needed.

### Example:

```java id="s94005"
public class Main {
    public static void main(String[] args) {
        int number = 10;

        Integer wrappedNumber = number;
        int result = wrappedNumber + 5;

        System.out.println(result);
    }
}
```

### Output:

```output id="o94005"
15
```

Here:

1. `number` is an `int`.
2. It is automatically boxed into `Integer`.
3. `wrappedNumber + 5` requires a primitive value, so Java unboxes it.
4. The result is `15`.

## 9. Converting a String to an Integer

The `Integer.parseInt()` method converts a String containing a valid integer into an `int`.

### Example:

```java id="s94007"
public class Main {
    public static void main(String[] args) {
        String text = "123";

        int number = Integer.parseInt(text);

        System.out.println(number + 10);
    }
}
```

### Output:

```output id="o94007"
133
```

The String `"123"` is converted into the integer `123`.

## 17. Wrapper Classes and `null`

Unlike primitive variables, wrapper variables can refer to `null`.

`null` means that the variable does not currently refer to a value.

### Example:

```java id="s94015"
public class Main {
    public static void main(String[] args) {
        Integer number = null;

        System.out.println(number);
    }
}
```

### Output:

```output id="o94015"
null
```

A primitive `int` cannot store `null`, but an `Integer` reference can.

---

## 18. Why Are Wrapper Classes Useful?

Wrapper classes are useful when Java needs an object instead of a primitive value.

They are especially useful when:

* Working with APIs that require objects
* Using collections such as `ArrayList`
* Converting Strings to numbers
* Using useful methods provided by wrapper classes
* Representing the absence of a value with `null`

For example:

```java id="s94016"
import java.util.ArrayList;

public class Main {
    public static void main(String[] args) {
        ArrayList<Integer> numbers = new ArrayList<>();

        numbers.add(10);
        numbers.add(20);

        System.out.println(numbers.get(0));
    }
}
```

### Output:

```output id="o94016"
10
```

Here, `ArrayList` uses `Integer` rather than `int`.

## 20. Common Mistakes with Wrapper Classes

### Mistake 1: Trying to store `null` in a primitive

This is not valid:

```java id="wrapper_error_1"
int number = null;
```

A primitive cannot store `null`.

Use `Integer` if `null` is required:

```java id="s94017"
Integer number = null;

System.out.println(number);
```

### Output:

```output id="o94017"
null
```

### Mistake 2: Parsing invalid numeric text

For example:

```java id="wrapper_error_2"
int number = Integer.parseInt("Hello");
```

This causes a `NumberFormatException` because `"Hello"` is not a valid integer.

### Mistake 3: Confusing `Integer` with `int`

`Integer` is a wrapper class, while `int` is a primitive type.

## 21. Quick Example

Let's use several wrapper class features together.

```java id="s94018"
public class Main {
    public static void main(String[] args) {

        String text = "250";

        int number = Integer.parseInt(text);
        Integer wrappedNumber = number;

        System.out.println("Number: " + number);
        System.out.println("Wrapper: " + wrappedNumber);
        System.out.println("Maximum int: " + Integer.MAX_VALUE);
    }
}
```

### Output:

```output id="o94018"
Number: 250
Wrapper: 250
Maximum int: 2147483647
```

Here:

* `Integer.parseInt()` converts the String to an `int`.
* Autoboxing converts the `int` to an `Integer`.
* `Integer.MAX_VALUE` gives the maximum value of an `int`.

## Key Points

* Wrapper classes represent primitive data types as objects.
* `Integer` is the wrapper class for `int`.
* `Double` is the wrapper class for `double`.
* `Character` is the wrapper class for `char`.
* `Boolean` is the wrapper class for `boolean`.
* Autoboxing converts a primitive into its wrapper type automatically.
* Unboxing converts a wrapper object into its primitive type automatically.
* `Integer.parseInt()` converts a String to an `int`.
* `Double.parseDouble()` converts a String to a `double`.
* `String.valueOf()` can convert a value into a String.
* Wrapper objects can represent `null`.
* Wrapper classes provide useful methods and constants.
* Wrapper classes are commonly used with object-based APIs and collections.
