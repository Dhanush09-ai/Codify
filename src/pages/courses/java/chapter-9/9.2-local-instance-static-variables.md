## 1. What Are the Three Types of Variables?

In Java, variables can be commonly classified based on where they are declared.

The three types we will learn are:

| Variable          | Where it is declared                     |
| ----------------- | ---------------------------------------- |
| Local variable    | Inside a method or block                 |
| Instance variable | Inside a class but outside methods       |
| Static variable   | Inside a class with the `static` keyword |

Each type has a different purpose.

---

## 2. Local Variables

A **local variable** is declared inside a method, constructor, or block.

### Example:

```java id="s92001"
public class Main {
    public static void main(String[] args) {
        int number = 10;

        System.out.println(number);
    }
}
```

### Output:

```output id="o92001"
10
```

Here, `number` is a local variable because it is declared inside the `main()` method.

---

## 3. Scope of a Local Variable

A local variable can be used only within the method or block where it is declared.

### Example:

```java id="s92002"
public class Main {

    static void showNumber() {
        int number = 25;

        System.out.println(number);
    }

    public static void main(String[] args) {
        showNumber();
    }
}
```

### Output:

```output id="o92002"
25
```

The variable `number` belongs to the `showNumber()` method.

It cannot be directly accessed from `main()`.

---

## 4. Each Method Can Have Its Own Local Variables

Different methods can have local variables with the same name.

### Example:

```java id="s92003"
public class Main {

    static void first() {
        int number = 10;
        System.out.println(number);
    }

    static void second() {
        int number = 20;
        System.out.println(number);
    }

    public static void main(String[] args) {
        first();
        second();
    }
}
```

### Output:

```output id="o92003"
10
20
```

The two `number` variables are separate local variables.

---

## 5. Instance Variables

An **instance variable** is declared inside a class but outside methods, constructors, and blocks.

### Example:

```java id="s92004"
public class Main {

    int age = 16;

    public static void main(String[] args) {
        Main obj = new Main();

        System.out.println(obj.age);
    }
}
```

### Output:

```output id="o92004"
16
```

Here, `age` is an instance variable.

It belongs to an object created from the `Main` class.

---

## 6. Creating Objects for Instance Variables

To access an instance variable from a `static` method such as `main()`, we can create an object.

### Example:

```java id="s92005"
public class Main {

    String name = "Owais";

    public static void main(String[] args) {
        Main obj = new Main();

        System.out.println(obj.name);
    }
}
```

### Output:

```output id="o92005"
Owais
```

Here:

* `name` is an instance variable.
* `obj` is an object of the `Main` class.
* `obj.name` accesses the instance variable.

---

## 7. Instance Variables Belong to Objects

Each object can have its own value for an instance variable.

### Example:

```java id="s92006"
class Student {
    String name;
}

public class Main {
    public static void main(String[] args) {
        Student student1 = new Student();
        Student student2 = new Student();

        student1.name = "Owais";
        student2.name = "Ali";

        System.out.println(student1.name);
        System.out.println(student2.name);
    }
}
```

### Output:

```output id="o92006"
Owais
Ali
```

Both objects have their own `name` value.

---

## 8. Changing an Instance Variable

The value of an instance variable can be changed for a particular object.

### Example:

```java id="s92007"
class Student {
    String name;
}

public class Main {
    public static void main(String[] args) {
        Student student = new Student();

        student.name = "Owais";
        System.out.println(student.name);

        student.name = "Ali";
        System.out.println(student.name);
    }
}
```

### Output:

```output id="o92007"
Owais
Ali
```

Changing the value affects that particular object.

---

## 9. Static Variables

A **static variable** is a variable declared inside a class using the `static` keyword.

### Example:

```java id="s92008"
public class Main {

    static int count = 10;

    public static void main(String[] args) {
        System.out.println(count);
    }
}
```

### Output:

```output id="o92008"
10
```

Here, `count` is a static variable.

It belongs to the class rather than to a particular object.

---

## 10. Accessing a Static Variable

A static variable can be accessed using the class name.

### Example:

```java id="s92009"
public class Main {

    static int count = 10;

    public static void main(String[] args) {
        System.out.println(Main.count);
    }
}
```

### Output:

```output id="o92009"
10
```

The general form is:

```text
ClassName.variableName
```

---

## 11. Static Variables Are Shared

A static variable is associated with the class, so there is one shared class-level variable rather than a separate copy for each object.

### Example:

```java id="s92010"
class Student {
    static String college = "CODIFY College";
}

public class Main {
    public static void main(String[] args) {
        Student student1 = new Student();
        Student student2 = new Student();

        System.out.println(student1.college);
        System.out.println(student2.college);
    }
}
```

### Output:

```output id="o92010"
CODIFY College
CODIFY College
```

Both objects access the same static variable.

---

## 12. Changing a Static Variable

Changing a static variable changes the shared value.

### Example:

```java id="s92011"
class Student {
    static String college = "CODIFY College";
}

public class Main {
    public static void main(String[] args) {
        Student student1 = new Student();
        Student student2 = new Student();

        Student.college = "ABC College";

        System.out.println(student1.college);
        System.out.println(student2.college);
    }
}
```

### Output:

```output id="o92011"
ABC College
ABC College
```

Both objects see the changed value because the variable is shared.

---

## 13. Local vs Instance vs Static

The three types can be compared like this:

| Feature                                | Local                  | Instance                       | Static                     |
| -------------------------------------- | ---------------------- | ------------------------------ | -------------------------- |
| Declared                               | Inside method/block    | Inside class, outside methods  | Inside class with `static` |
| Belongs to                             | Method/block           | Object                         | Class                      |
| Separate for each object               | No                     | Yes                            | No                         |
| Can be accessed directly from `main()` | Yes, if declared there | No, an object is normally used | Yes                        |
| Example                                | `int age = 16;`        | `int age = 16;`                | `static int count = 10;`   |

---

## 14. A Program Using All Three

We can use local, instance, and static variables in the same program.

### Example:

```java id="s92012"
class Student {
    String name = "Owais";
    static String college = "CODIFY College";
}

public class Main {
    public static void main(String[] args) {

        int age = 16;

        Student student = new Student();

        System.out.println(age);
        System.out.println(student.name);
        System.out.println(Student.college);
    }
}
```

### Output:

```output id="o92012"
16
Owais
CODIFY College
```

Here:

* `age` is a local variable.
* `name` is an instance variable.
* `college` is a static variable.

---

## 15. Local Variables vs Instance Variables

Consider the following example:

```java id="s92013"
class Student {
    String name = "Owais";

    void show() {
        int age = 16;

        System.out.println(name);
        System.out.println(age);
    }
}

public class Main {
    public static void main(String[] args) {
        Student student = new Student();

        student.show();
    }
}
```

### Output:

```output id="o92013"
Owais
16
```

Here:

* `name` is an instance variable.
* `age` is a local variable.

The instance variable belongs to the `Student` object, while the local variable belongs to the `show()` method.

---

## 16. Instance Variables vs Static Variables

Instance variables belong to individual objects.

Static variables belong to the class.

### Example:

```java id="s92014"
class Student {
    String name;
    static String college = "CODIFY College";
}

public class Main {
    public static void main(String[] args) {
        Student student1 = new Student();
        Student student2 = new Student();

        student1.name = "Owais";
        student2.name = "Ali";

        System.out.println(student1.name);
        System.out.println(student2.name);
        System.out.println(Student.college);
    }
}
```

### Output:

```output id="o92014"
Owais
Ali
CODIFY College
```

Here:

* `name` can be different for each object.
* `college` is shared by the class.

---

## 17. When Should We Use a Local Variable?

Use a local variable when a value is needed only inside a particular method or block.

### Example:

```java id="s92015"
public class Main {
    public static void main(String[] args) {
        int length = 10;
        int width = 5;

        int area = length * width;

        System.out.println(area);
    }
}
```

### Output:

```output id="o92015"
50
```

The variables are needed only for the calculation in `main()`.

---

## 18. When Should We Use an Instance Variable?

Use an instance variable when a value represents information belonging to an object.

For example, a `Student` object can have:

* name
* age
* roll number

### Example:

```java id="s92016"
class Student {
    String name;
    int age;
}

public class Main {
    public static void main(String[] args) {
        Student student = new Student();

        student.name = "Owais";
        student.age = 16;

        System.out.println(student.name);
        System.out.println(student.age);
    }
}
```

### Output:

```output id="o92016"
Owais
16
```

The values belong to the particular `Student` object.

---

## 19. When Should We Use a Static Variable?

Use a static variable when one value should be associated with the class and shared by its objects.

For example, if all students belong to the same college:

```java id="s92017"
class Student {
    static String college = "CODIFY College";
}

public class Main {
    public static void main(String[] args) {
        System.out.println(Student.college);
    }
}
```

### Output:

```output id="o92017"
CODIFY College
```

The college name does not need to be separately stored for every student object.

## 20. Common Mistakes

### Mistake 1: Trying to access an instance variable without an object

An instance variable belongs to an object.

```java id="instance_error"
class Student {
    String name = "Owais";
}
```

From a `static` method such as `main()`, you normally access it through an object:

```java id="s92018"
Student student = new Student();

System.out.println(student.name);
```

### Mistake 2: Creating separate static variables for every object

A static variable is shared by the class, so it should be used for class-level information.

### Mistake 3: Thinking a local variable belongs to the whole class

A local variable belongs only to the method or block where it is declared.

### Mistake 4: Confusing `static` with `final`

`static` means the variable is associated with the class.

`final` means the variable cannot be reassigned after it has been initialized.

They have different purposes.

## 21. Quick Example

Let's see all three types together.

```java id="s92019"
class Student {
    String name;
    static String college = "CODIFY College";

    void show() {
        int age = 16;

        System.out.println("Name: " + name);
        System.out.println("Age: " + age);
        System.out.println("College: " + college);
    }
}

public class Main {
    public static void main(String[] args) {
        Student student = new Student();

        student.name = "Owais";

        student.show();
    }
}
```

### Output:

```output id="o92019"
Name: Owais
Age: 16
College: CODIFY College
```

In this example:

* `name` is an instance variable.
* `college` is a static variable.
* `age` is a local variable.

## Key Points

* Java commonly has three types of variables: local, instance, and static.
* A local variable is declared inside a method, constructor, or block.
* A local variable is available only within its scope.
* An instance variable is declared inside a class but outside methods.
* Each object has its own instance variables.
* A static variable is declared using the `static` keyword.
* A static variable belongs to the class rather than a particular object.
* Static variables are shared among objects of the class.
* Instance variables are useful for object-specific information.
* Static variables are useful for information shared by the class.
* Local variables are useful for temporary values needed inside a method or block.
* `static` and `final` have different purposes.
