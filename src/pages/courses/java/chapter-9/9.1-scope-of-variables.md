# Chapter 9: More Java Fundamentals

## Section 1: Scope of Variables

In the previous chapters, we learned about variables, data types, methods, arrays, Strings, and other Java fundamentals.

Now, we will learn about the **scope of a variable** and understand where a variable can be used in a Java program.

We will learn how to:

* Understand what scope means
* Understand local variables
* Understand method parameters
* Understand block scope
* Understand instance variables
* Understand class variables at a basic level
* Understand where variables can and cannot be accessed
* Avoid common scope mistakes

## 1. What Is Scope?

The **scope** of a variable means the part of a program where that variable can be accessed and used.

For example:

```java id="s91001"
public class Main {
    public static void main(String[] args) {
        int age = 16;

        System.out.println(age);
    }
}
```

### Output:

```output id="o91001"
16
```

The variable `age` can be used inside the `main()` method because it was declared there.

---

## 2. Why Is Scope Important?

Scope tells Java where a variable is available.

It helps us:

* Avoid accidentally using a variable in the wrong place
* Keep variables organized
* Prevent naming conflicts
* Understand where a variable can be accessed
* Write cleaner programs

For example, a variable created inside one method cannot normally be used directly inside another method.

---

## 3. Local Variables

A variable declared inside a method is called a **local variable**.

### Example:

```java id="s91002"
public class Main {
    public static void main(String[] args) {
        int number = 10;

        System.out.println(number);
    }
}
```

### Output:

```output id="o91002"
10
```

Here, `number` is a local variable because it is declared inside `main()`.

---

## 4. Scope of a Local Variable

A local variable can be used only within the block where it is declared.

### Example:

```java id="s91003"
public class Main {
    public static void main(String[] args) {
        int number = 20;

        System.out.println(number);
    }
}
```

### Output:

```output id="o91003"
20
```

The variable `number` is available inside the `main()` block.

Once the program leaves that block, the variable cannot be accessed from outside it.

---

## 5. Local Variables in Different Methods

Each method can have its own local variables.

### Example:

```java id="s91004"
public class Main {

    static void first() {
        int number = 10;
        System.out.println(number);
    }

    static void second() {
        int number = 20;
        System.out.println(number);
    }

    public static void main(String[] args) {
        first();
        second();
    }
}
```

### Output:

```output id="o91004"
10
20
```

Both methods have a variable named `number`, but they are separate local variables.

The `number` inside `first()` cannot be directly accessed inside `second()`.

---

## 6. Method Parameters

A parameter is also a variable with a limited scope.

### Example:

```java id="s91005"
public class Main {

    static void greet(String name) {
        System.out.println("Hello " + name);
    }

    public static void main(String[] args) {
        greet("Owais");
    }
}
```

### Output:

```output id="o91005"
Hello Owais
```

Here, `name` is a parameter of the `greet()` method.

It can be used inside `greet()`.

---

## 7. Scope of a Method Parameter

A method parameter is available only inside the method where it is declared.

For example:

```java id="s91006"
public class Main {

    static void greet(String name) {
        System.out.println(name);
    }

    public static void main(String[] args) {
        greet("Owais");
    }
}
```

Here, `name` belongs to the `greet()` method.

It cannot be directly used inside `main()`.

---

## 8. Block Scope

A **block** is a group of statements surrounded by curly braces `{ }`.

For example:

```java id="s91007"
public class Main {
    public static void main(String[] args) {

        {
            int number = 50;
            System.out.println(number);
        }
    }
}
```

### Output:

```output id="o91007"
50
```

The variable `number` exists only inside that block.

---

## 9. Variable Inside an `if` Block

Variables declared inside an `if` block have scope only inside that block.

### Example:

```java id="s91008"
public class Main {
    public static void main(String[] args) {

        if (true) {
            int number = 100;
            System.out.println(number);
        }
    }
}
```

### Output:

```output id="o91008"
100
```

The variable `number` can be used inside the `if` block.

It cannot be directly accessed outside the `if` block.

---

## 10. Variable Inside a Loop

Variables declared inside a loop can be used within that loop.

### Example:

```java id="s91009"
public class Main {
    public static void main(String[] args) {

        for (int i = 1; i <= 3; i++) {
            System.out.println(i);
        }
    }
}
```

### Output:

```output id="o91009"
1
2
3
```

The variable `i` belongs to the `for` loop.

It cannot be directly used after the loop.

---

## 11. Outer and Inner Scope

A variable declared in an outer block can generally be accessed inside an inner block.

### Example:

```java id="s91010"
public class Main {
    public static void main(String[] args) {

        int number = 10;

        if (number > 5) {
            System.out.println(number);
        }
    }
}
```

### Output:

```output id="o91010"
10
```

The `if` block is inside the `main()` block, so it can access `number`.

---

## 12. Inner Variables Cannot Be Used Outside

A variable declared inside an inner block cannot be used outside that block.

For example:

```java id="example_scope_error"
public class Main {
    public static void main(String[] args) {

        if (true) {
            int number = 10;
        }

        // number cannot be used here
    }
}
```

The variable `number` exists only inside the `if` block.

Trying to use it outside that block causes a compilation error.

---

## 13. Instance Variables

A variable declared inside a class but outside methods is called an **instance variable**.

### Example:

```java id="s91011"
public class Main {

    int age = 16;

    public static void main(String[] args) {
        Main obj = new Main();

        System.out.println(obj.age);
    }
}
```

### Output:

```output id="o91011"
16
```

Here, `age` is declared inside the class but outside any method.

It belongs to an object of the `Main` class.

---

## 14. Local Variable vs Instance Variable

Consider this example:

```java id="s91012"
public class Main {

    int age = 16;

    public static void main(String[] args) {
        int number = 10;

        Main obj = new Main();

        System.out.println(obj.age);
        System.out.println(number);
    }
}
```

### Output:

```output id="o91012"
16
10
```

Here:

* `age` is an instance variable.
* `number` is a local variable.

The two variables have different scopes and purposes.

---

## 15. Class Variables — Basic Idea

A variable declared with the `static` keyword is associated with the class rather than with a particular object.

For example:

```java id="s91013"
public class Main {

    static int count = 10;

    public static void main(String[] args) {
        System.out.println(count);
    }
}
```

### Output:

```output id="o91013"
10
```

The detailed use of `static` variables will be covered in the next section.

---

## 16. Same Variable Name in Different Scopes

Variables in different scopes can have the same name.

### Example:

```java id="s91014"
public class Main {

    public static void main(String[] args) {

        int number = 10;

        {
            int otherNumber = 20;

            System.out.println(number);
            System.out.println(otherNumber);
        }
    }
}
```

### Output:

```output id="o91014"
10
20
```

The outer variable `number` and inner variable `otherNumber` are different variables.

---

## 17. A Variable's Scope Depends on Where It Is Declared

The location where a variable is declared determines where it can be accessed.

For example:

```java id="s91015"
public class Main {
    public static void main(String[] args) {

        int number = 25;

        if (number > 10) {
            System.out.println(number);
        }
    }
}
```

### Output:

```output id="o91015"
25
```

Since `number` is declared in the outer `main()` block, the inner `if` block can access it.

---

## 18. Scope and Lifetime

**Scope** tells us where a variable can be accessed.

**Lifetime** refers to how long the variable exists during program execution.

For beginners, remember:

* Scope → Where the variable can be used
* Lifetime → How long the variable exists

These two concepts are related but are not exactly the same.

---

## 19. Common Mistakes with Variable Scope

### Mistake 1: Using a local variable outside its block

```java id="nq6g6n"
if (true) {
    int number = 10;
}

// number cannot be used here
```

The variable `number` belongs to the `if` block.

### Mistake 2: Trying to use a variable from another method

```java id="5hjh9c"
static void first() {
    int number = 10;
}

static void second() {
    // number cannot be directly used here
}
```

The local variable `number` belongs only to `first()`.

### Mistake 3: Confusing local and instance variables

A local variable is declared inside a method or block, while an instance variable is declared inside a class but outside methods.

---

## 20. Quick Example

Let's see different scopes in one program.

```java id="s91016"
public class Main {

    int age = 16;

    static void showNumber() {
        int number = 10;
        System.out.println(number);
    }

    public static void main(String[] args) {
        Main obj = new Main();

        System.out.println(obj.age);

        showNumber();

        if (true) {
            int value = 30;
            System.out.println(value);
        }
    }
}
```

### Output:

```output id="o91016"
16
10
30
```

In this program:

* `age` is an instance variable.
* `number` is a local variable of `showNumber()`.
* `value` is a local variable of the `if` block.

Each variable has its own scope.

---

## Key Points

* Scope means the part of a program where a variable can be accessed.
* A variable declared inside a method is a local variable.
* Method parameters are available inside their method.
* Variables declared inside a block have scope within that block.
* An inner block can generally access variables declared in an outer block.
* A variable declared inside an inner block cannot be directly accessed outside that block.
* A variable declared inside a class but outside methods can be an instance variable.
* A `static` variable belongs to the class rather than a particular object.
* Scope and lifetime are related but different concepts.
* The place where a variable is declared determines its scope.
