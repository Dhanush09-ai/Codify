# Chapter 5: Loops

## Section 1: Introduction to Loops

In the previous chapter, we learned how Java makes decisions using `if`, `if-else`, `else-if`, nested `if`, and `switch`.

But sometimes we need to **repeat the same code multiple times**.

For example, suppose we want to print `"Hello"` 5 times.

Without a loop, we would have to write:

```java id="loop01"
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello");
        System.out.println("Hello");
        System.out.println("Hello");
        System.out.println("Hello");
        System.out.println("Hello");
    }
}
```

### Output

```output id="out01"
Hello
Hello
Hello
Hello
Hello
```

This works, but writing the same statement repeatedly is not a good approach when the number of repetitions becomes large.

This is where **loops** are useful.

---

## 1. What is a Loop?

A **loop** is a programming structure that allows us to execute a block of code repeatedly while a condition is satisfied.

Instead of writing the same code again and again, we can write it once inside a loop.

### Example

```java id="loop02"
public class Main {
    public static void main(String[] args) {
        int i = 1;

        while (i <= 5) {
            System.out.println("Hello");
            i++;
        }
    }
}
```

### Output

```output id="out02"
Hello
Hello
Hello
Hello
Hello
```

The statement inside the loop executes 5 times.

---

## 2. Why Do We Need Loops?

Loops are useful when we need to repeat an operation.

For example:

* Printing numbers from 1 to 100
* Printing a message multiple times
* Adding numbers
* Processing elements of an array
* Repeating a calculation
* Creating patterns
* Reading multiple values

Without loops, these tasks would require a lot of repeated code.

---

## 3. Basic Working of a Loop

A loop generally follows these steps:

```text id="flow01"
Start
  ↓
Check condition
  ↓
Is condition true?
  ↓
 Yes ──→ Execute code
  ↑          ↓
  └──── Update
             ↓
       Check again
             ↓
        No → Stop
```

The loop keeps repeating while its condition is true.

When the condition becomes false, the loop stops.

---

## 4. A Simple Counting Example

Let's print numbers from `1` to `5`.

```java id="loop03"
public class Main {
    public static void main(String[] args) {
        int i = 1;

        while (i <= 5) {
            System.out.println(i);
            i++;
        }
    }
}
```

### Output

```output id="out03"
1
2
3
4
5
```

Let's understand what happens:

1. `i` starts at `1`.
2. Java checks `i <= 5`.
3. The condition is true, so `i` is printed.
4. `i++` increases `i` by `1`.
5. The condition is checked again.
6. This continues until `i` becomes `6`.
7. `6 <= 5` is false, so the loop stops.

---

## 5. Main Parts of a Loop

A loop usually needs three important parts:

### 1. Initialization

This gives the starting value.

```java id="loop04"
int i = 1;
```

### 2. Condition

This decides whether the loop should continue.

```java id="loop05"
i <= 5
```

### 3. Update

This changes the value so that the loop can eventually stop.

```java id="loop06"
i++;
```

Together:

```java id="loop07"
int i = 1;

while (i <= 5) {
    System.out.println(i);
    i++;
}
```

---

## 6. Types of Loops in Java

Java provides several ways to repeat code.

The three main loops are:

### `for` Loop

Used when the number of repetitions is usually known.

```java
for (initialization; condition; update) {
    // code
}
```

### `while` Loop

Used when a condition controls the repetition.

```java
while (condition) {
    // code
}
```

### `do-while` Loop

Similar to `while`, but the code runs at least once before the condition is checked.

```java
do {
    // code
} while (condition);
```

We will learn each loop separately in the next topics.

---

## 7. for, while and do-while

Here is a simple comparison:

| Loop       | Main Idea                                   |
| ---------- | ------------------------------------------- |
| `for`      | Useful when repetitions are known           |
| `while`    | Checks the condition before each iteration  |
| `do-while` | Executes once before checking the condition |

For example, all three loops can be used to print numbers from `1` to `5`.

The syntax is different, but the basic idea is the same: **repeat a block of code**.

---

## 8. What is an Iteration?

Each single execution of a loop body is called an **iteration**.

For example:

```java id="loop08"
int i = 1;

while (i <= 3) {
    System.out.println(i);
    i++;
}
```

### Output

```output id="out04"
1
2
3
```

This loop has **3 iterations**.

| Iteration | Value of `i` |
| --------- | -----------: |
| 1st       |            1 |
| 2nd       |            2 |
| 3rd       |            3 |

After the third iteration, `i` becomes `4`.

The condition `4 <= 3` is false, so the loop stops.

---

## 9. Infinite Loops

An **infinite loop** is a loop that never stops because its condition never becomes false.

For example:

```java id="loop09"
while (true) {
    System.out.println("Hello");
}
```

The condition is always `true`, so the loop continues indefinitely.

For beginners, always make sure that a loop has a clear way to reach its stopping condition.

For example:

```java id="loop10"
int i = 1;

while (i <= 5) {
    System.out.println(i);
    i++;
}
```

Here, `i++` changes the value of `i`, so eventually the condition becomes false.

---

## 10. Common Loop Mistake

A common mistake is forgetting to update the loop variable.

For example:

```java id="loop11"
int i = 1;

while (i <= 5) {
    System.out.println(i);
}
```

Here, `i` never changes.

Therefore, `i <= 5` remains true and the loop does not naturally reach its stopping condition.

A correct version is:

```java id="loop12"
int i = 1;

while (i <= 5) {
    System.out.println(i);
    i++;
}
```

---

## 11. Loop Control Flow

Consider:

```java id="loop13"
int i = 1;

while (i <= 3) {
    System.out.println(i);
    i++;
}
```

The execution can be understood like this:

```text
i = 1
  ↓
1 <= 3 → true
  ↓
Print 1
  ↓
i = 2
  ↓
2 <= 3 → true
  ↓
Print 2
  ↓
i = 3
  ↓
3 <= 3 → true
  ↓
Print 3
  ↓
i = 4
  ↓
4 <= 3 → false
  ↓
Stop
```

Understanding this flow will make it easier to learn `for`, `while`, and `do-while` loops.

---

## 12. Loop vs Repeated Statements

### Without a loop

```java id="loop14"
System.out.println(1);
System.out.println(2);
System.out.println(3);
System.out.println(4);
System.out.println(5);
```

### With a loop

```java id="loop15"
int i = 1;

while (i <= 5) {
    System.out.println(i);
    i++;
}
```

The loop version is shorter and easier to modify.

For example, changing:

```java id="loop16"
i <= 5
```

to:

```java id="loop17"
i <= 100
```

allows the same logic to print numbers from `1` to `100`.

---

## 13. Choosing a Loop

A simple guideline is:

### Use `for`

When you generally know how many times you want to repeat something.

Example:

```java id="loop18"
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}
```

### Use `while`

When repetition mainly depends on a condition.

Example:

```java id="loop19"
while (number > 0) {
    // code
}
```

### Use `do-while`

When the code should execute at least once before checking the condition.

Example:

```java id="loop20"
do {
    // code
} while (condition);
```

You will learn the detailed syntax and use cases of each loop in the next topics.

---

## 14. A Simple Real-Life Example

Imagine climbing stairs.

You can think of each step as one iteration:

```text
Step 1
  ↓
Step 2
  ↓
Step 3
  ↓
Step 4
  ↓
Step 5
```

A loop works in a similar way.

It performs an action, updates the current state, checks the condition, and repeats until the stopping condition is reached.

---

## Key Points

* A loop repeats a block of code.
* Loops help avoid writing the same code repeatedly.
* An iteration is one execution of the loop body.
* A loop generally has initialization, a condition, and an update.
* The loop continues while its condition is true.
* The loop stops when its condition becomes false.
* Java has `for`, `while`, and `do-while` loops.
* Forgetting to update a loop variable can cause an infinite loop.
* Choose the type of loop based on the problem you are solving.
