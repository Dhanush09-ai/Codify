# Chapter 5: Loops

## Section 3: while and do-while

Loops allow us to repeat a block of code multiple times.

In the previous topic, we learned about the `for` loop. Java also provides two other important loops:

* `while` loop
* `do-while` loop

Both are useful when we want to repeat code while a condition is true.

---

## 1. What is a while Loop?

A `while` loop repeats a block of code **as long as its condition is true**.

### Syntax

```java
while (condition) {
    // code to repeat
}
```

The condition is checked **before** the loop body runs.

### Simple Example

```java id="w8k2pa"
public class Main {
    public static void main(String[] args) {
        int i = 1;

        while (i <= 5) {
            System.out.println(i);
            i++;
        }
    }
}
```

### Output

```output id="q4m7xz"
1
2
3
4
5
```

### How it works

1. `i` starts at `1`.
2. Java checks `i <= 5`.
3. If the condition is true, the loop body runs.
4. `i++` increases the value of `i`.
5. The condition is checked again.
6. The loop stops when `i <= 5` becomes false.

---

## 2. Flow of a while Loop

The basic flow is:

```text
Start
  ↓
Initialize variable
  ↓
Check condition
  ↓
Is condition true?
  ↓ Yes
Run loop body
  ↓
Update variable
  ↓
Check condition again
  ↓
  No
End
```

The important point is that the **condition is checked before the loop body**.

## 4. Counting Backwards

A `while` loop can also be used for counting down.

```java id="p7x4qd"
public class Main {
    public static void main(String[] args) {
        int i = 5;

        while (i >= 1) {
            System.out.println(i);
            i--;
        }
    }
}
```

### Output

```output id="r2v9mc"
5
4
3
2
1
```

## 5. Adding Numbers Using while

We can use a `while` loop to calculate a sum.

For example, let's find the sum of numbers from 1 to 5.

```java id="t5h8bn"
public class Main {
    public static void main(String[] args) {
        int i = 1;
        int sum = 0;

        while (i <= 5) {
            sum = sum + i;
            i++;
        }

        System.out.println("Sum = " + sum);
    }
}
```

### Output

```output id="c9k3wf"
Sum = 15
```

---

## 6. while Loop with a Condition

A `while` loop can contain an `if` statement.

```java id="v4j6sm"
public class Main {
    public static void main(String[] args) {
        int i = 1;

        while (i <= 5) {
            if (i % 2 == 0) {
                System.out.println(i);
            }

            i++;
        }
    }
}
```

### Output

```output id="b7q2xe"
2
4
```

Here, the loop checks every number from 1 to 5, but the `if` statement prints only even numbers.

---

## 7. What Happens When the Condition is False?

Because the condition is checked before the loop body, the body may run **zero times**.

```java id="k8d5rp"
public class Main {
    public static void main(String[] args) {
        int i = 10;

        while (i < 5) {
            System.out.println(i);
            i++;
        }

        System.out.println("Loop finished");
    }
}
```

### Output

```output id="z3m7qa"
Loop finished
```

The condition `10 < 5` is false from the beginning, so the loop body does not execute.

---

## 8. What is a do-while Loop?

A `do-while` loop is similar to a `while` loop, but there is one important difference:

> A `do-while` loop executes its body **at least once**.

### Syntax

```java
do {
    // code to repeat
} while (condition);
```

Notice the semicolon `;` after the condition.

---

## 9. Simple do-while Example

```java id="e6w9kc"
public class Main {
    public static void main(String[] args) {
        int i = 1;

        do {
            System.out.println(i);
            i++;
        } while (i <= 5);
    }
}
```

### Output

```output id="h2p5vd"
1
2
3
4
5
```

The loop works like this:

1. The `do` block runs.
2. `i` is increased.
3. The condition is checked.
4. If the condition is true, the block runs again.
5. The loop stops when the condition becomes false.

---

## 10. do-while Runs at Least Once

This is the main difference between `while` and `do-while`.

### while Example

```java id="s4n8yx"
public class Main {
    public static void main(String[] args) {
        int i = 10;

        while (i < 5) {
            System.out.println("Hello");
        }
    }
}
```

### Output

```output id="u7c3me"
```

Nothing is printed because the condition is false before the loop starts.

### do-while Example

```java id="j5r2kd"
public class Main {
    public static void main(String[] args) {
        int i = 10;

        do {
            System.out.println("Hello");
        } while (i < 5);
    }
}
```

### Output

```output id="a9f6qt"
Hello
```

Even though `i < 5` is false, `"Hello"` is printed once.

---

## 11. while vs do-while

| Feature                   | while                       | do-while                    |
| ------------------------- | --------------------------- | --------------------------- |
| Condition checked         | Before the body             | After the body              |
| Minimum executions        | 0                           | 1                           |
| Uses `do`                 | No                          | Yes                         |
| Semicolon after condition | No                          | Yes                         |
| Useful when               | Execution may not be needed | Code must run at least once |

### Easy way to remember

**while:**

> Check → Run

**do-while:**

> Run → Check

## 14. Updating the Loop Variable

Just like a `for` loop, a `while` or `do-while` loop usually needs an update.

```java id="n5q8tc"
public class Main {
    public static void main(String[] args) {
        int i = 1;

        while (i <= 3) {
            System.out.println(i);
            i++;
        }
    }
}
```

If we forget `i++`, the value of `i` never changes and the condition remains true.

This can create an **infinite loop**.

---

## 15. Infinite while Loop

An infinite loop keeps running because its condition never becomes false.

For example:

```java
while (true) {
    System.out.println("Running");
}
```

The condition `true` is always true, so the loop does not stop by itself.

Use infinite loops carefully.

---

## 16. while vs for

Both `for` and `while` can be used for repeated tasks.

### for Loop

```java
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}
```

### while Loop

```java
int i = 1;

while (i <= 5) {
    System.out.println(i);
    i++;
}
```

Both produce:

```output
1
2
3
4
5
```

### When to use them?

Use a `for` loop when the number of repetitions is clear.

Use a `while` loop when the loop depends more naturally on a condition.

## 17. Common Mistakes

### Mistake 1: Forgetting the update

```java
int i = 1;

while (i <= 5) {
    System.out.println(i);
}
```

The value of `i` never changes, so the condition stays true.

---

### Mistake 2: Using the wrong condition

Always check whether the condition can eventually become false.

```java
while (i >= 1) {
    i++;
}
```

Here, `i` is increasing while the condition requires it to be at least 1, which can cause an infinite loop.

---

### Mistake 3: Forgetting the semicolon in do-while

Correct:

```java
do {
    System.out.println("Hello");
} while (condition);
```

The semicolon after `while (condition)` is required.

---

## 18. Quick Comparison

```text
for       → Initialize → Check → Run → Update
while     → Initialize → Check → Run → Update
do-while  → Initialize → Run → Update → Check
```

The main difference is **when the condition is checked**.

## Key Points

* A `while` loop repeats code while a condition is true.
* A `while` loop checks its condition **before** executing the body.
* A `while` loop can execute zero times.
* A `do-while` loop checks its condition **after** executing the body.
* A `do-while` loop executes at least once.
* The loop variable should usually be updated.
* Forgetting the update can create an infinite loop.
* A `do-while` loop has a semicolon after its condition.
* `for`, `while`, and `do-while` can all be used for repetition.
