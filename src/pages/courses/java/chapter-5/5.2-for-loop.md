# Chapter 5: Loops

## Section 2: for Loop

In the previous topic, we learned what loops are and why they are useful.

The `for` loop is one of the most commonly used loops in Java.

It is especially useful when we **know how many times we want to repeat a block of code**.

---

## 1. What is a for Loop?

A `for` loop repeats a block of code as long as its condition is `true`.

### Basic Syntax

```java id="for01"
for (initialization; condition; update) {
    // code to repeat
}
```

A `for` loop usually has three parts:

1. **Initialization** — sets the starting value.
2. **Condition** — decides whether the loop should continue.
3. **Update** — changes the loop variable after each iteration.

---

## 2. Simple for Loop

Let's print numbers from `1` to `5`.

```java id="for02"
public class Main {
    public static void main(String[] args) {
        for (int i = 1; i <= 5; i++) {
            System.out.println(i);
        }
    }
}
```

### Output

```output id="out01"
1
2
3
4
5
```

Here:

```java id="for03"
int i = 1
```

starts `i` at `1`.

```java id="for04"
i <= 5
```

checks whether the loop should continue.

```java id="for05"
i++
```

increases `i` by `1` after each iteration.

---

## 3. How a for Loop Works

Consider:

```java id="for06"
for (int i = 1; i <= 3; i++) {
    System.out.println(i);
}
```

The execution happens like this:

```text id="flow01"
Initialization
     ↓
   i = 1
     ↓
 Check condition
     ↓
  i <= 3 ?
   ↙     ↘
 true    false
  ↓        ↓
Print i   Stop
  ↓
 Update i
  ↓
 Check again
```

The loop continues until the condition becomes false.

---

## 4. Printing a Message Multiple Times

A `for` loop does not have to print numbers.

We can repeat any valid Java statement.

```java id="for07"
public class Main {
    public static void main(String[] args) {
        for (int i = 1; i <= 3; i++) {
            System.out.println("Hello, Java!");
        }
    }
}
```

### Output

```output id="out02"
Hello, Java!
Hello, Java!
Hello, Java!
```

The loop runs three times.

## 6. Counting Backward

A `for` loop can also count downward.

Instead of using `i++`, we can use `i--`.

```java id="for09"
public class Main {
    public static void main(String[] args) {
        for (int i = 5; i >= 1; i--) {
            System.out.println(i);
        }
    }
}
```

### Output

```output id="out04"
5
4
3
2
1
```

Here:

* `i = 5` → starting value
* `i >= 1` → condition
* `i--` → decreases `i` by `1`

---

## 7. Increment by More Than 1

The update part does not have to increase by exactly `1`.

For example, we can increase by `2`.

```java id="for10"
public class Main {
    public static void main(String[] args) {
        for (int i = 2; i <= 10; i += 2) {
            System.out.println(i);
        }
    }
}
```

### Output

```output id="out05"
2
4
6
8
10
```

The values increase by `2` each time.

## 10. Sum of Numbers Using for Loop

A loop can also be used to calculate a sum.

Let's calculate the sum of numbers from `1` to `5`.

```java id="for13"
public class Main {
    public static void main(String[] args) {
        int sum = 0;

        for (int i = 1; i <= 5; i++) {
            sum += i;
        }

        System.out.println(sum);
    }
}
```

### Output

```output id="out08"
15
```

The calculation is:

```text
0 + 1 + 2 + 3 + 4 + 5 = 15
```

## 12. for Loop with a Condition

We can also use an `if` statement inside a `for` loop.

For example, let's print only numbers greater than `5`.

```java id="for15"
public class Main {
    public static void main(String[] args) {
        for (int i = 1; i <= 10; i++) {
            if (i > 5) {
                System.out.println(i);
            }
        }
    }
}
```

### Output

```output id="out10"
6
7
8
9
10
```

The loop visits all numbers from `1` to `10`, but the `if` statement prints only numbers greater than `5`.

## 13. Multiple Statements Inside a for Loop

A loop can contain multiple statements.

```java id="for16"
public class Main {
    public static void main(String[] args) {
        for (int i = 1; i <= 3; i++) {
            System.out.println("Number: " + i);
            System.out.println("Welcome to Java");
        }
    }
}
```

### Output

```output id="out11"
Number: 1
Welcome to Java
Number: 2
Welcome to Java
Number: 3
Welcome to Java
```

Both statements execute during every iteration.

---

## 14. Declaring the Loop Variable

The loop variable can be declared directly inside the `for` statement.

```java id="for17"
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}
```

Here, `i` exists only inside the `for` loop.

You can also declare the variable before the loop:

```java id="for18"
int i;

for (i = 1; i <= 5; i++) {
    System.out.println(i);
}
```

In this case, `i` is declared outside the loop.

---

## 15. Scope of the for Loop Variable

When a variable is declared inside the `for` loop, it can normally be used only inside that loop.

```java id="for19"
public class Main {
    public static void main(String[] args) {
        for (int i = 1; i <= 3; i++) {
            System.out.println(i);
        }
    }
}
```

Here, `i` belongs to the `for` loop.

This is useful because the loop variable is kept limited to where it is needed.

---

## 16. Omitting Parts of a for Loop

Java allows some parts of a `for` loop to be omitted.

For example:

```java id="for20"
int i = 1;

for (; i <= 3; i++) {
    System.out.println(i);
}
```

### Output

```output id="out12"
1
2
3
```

The initialization was written before the loop.

Although this is valid Java, beginners should usually use the normal form:

```java id="for21"
for (int i = 1; i <= 3; i++) {
    System.out.println(i);
}
```

because it is easier to read.

---

## 17. Infinite for Loop

A `for` loop can also become infinite if its condition never becomes false.

For example:

```java id="for22"
for (;;) {
    System.out.println("Hello");
}
```

There is no condition, so the loop continues indefinitely unless something stops it.

Be careful when creating loops like this.

---

## 18. Common Mistakes

### Mistake 1: Using the Wrong Condition

```java id="for23"
for (int i = 1; i < 5; i++) {
    System.out.println(i);
}
```

### Output

```output id="out13"
1
2
3
4
```

Notice that `5` is not printed because the condition is:

```java id="for24"
i < 5
```

If we want to include `5`, use:

```java id="for25"
i <= 5
```

---

### Mistake 2: Forgetting the Update

Be careful with:

```java id="for26"
for (int i = 1; i <= 5;) {
    System.out.println(i);
}
```

The value of `i` never changes, so the condition remains true.

This can result in an infinite loop.

---

### Mistake 3: Wrong Update Direction

If the loop starts at `5` and the condition is `i >= 1`, use a decreasing update:

```java id="for27"
for (int i = 5; i >= 1; i--) {
    System.out.println(i);
}
```

Using `i++` here would move `i` away from the stopping condition.

---

## 19. for Loop vs while Loop

Both loops can repeat code.

### for Loop

```java id="for28"
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}
```

### while Loop

```java id="for29"
int i = 1;

while (i <= 5) {
    System.out.println(i);
    i++;
}
```

Both produce:

```output id="out14"
1
2
3
4
5
```

The `for` loop keeps the initialization, condition, and update together, which makes it convenient for counting loops.

---

## 20. Quick Structure to Remember

Remember this pattern:

```java id="for30"
for (start; condition; update) {
    // repeated code
}
```

For example:

```java id="for31"
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}
```

Think of it as:

```text
Start → Check → Execute → Update → Check → ...
```

When the condition becomes false, the loop ends.

## Key Points

* A `for` loop repeats a block of code.
* It is commonly used when the number of repetitions is known.
* A `for` loop has initialization, condition, and update.
* The condition is checked before each iteration.
* The update runs after each iteration.
* `i++` increases a value by `1`.
* `i--` decreases a value by `1`.
* `i += 2` increases a value by `2`.
* A `for` loop can contain `if` statements and multiple statements.
* An incorrect condition or update can cause unexpected results or an infinite loop.
