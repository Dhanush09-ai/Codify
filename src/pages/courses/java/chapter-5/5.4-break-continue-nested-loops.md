# Chapter 5: Loops

## Section 4: break, continue and Nested Loops

In the previous topics, we learned about `for`, `while`, and `do-while` loops.

Java also provides some useful statements that give us more control over loops:

* `break`
* `continue`
* Nested loops

These are useful when we want to stop a loop, skip an iteration, or run one loop inside another loop.

---

## 1. What is break?

The `break` statement is used to **immediately stop a loop**.

When Java reaches `break`, the loop ends and execution continues with the statement after the loop.

### Syntax

```java id="b7k3mp"
break;
```

---

## 2. Simple break Example

```java id="m4r8tx"
public class Main {
    public static void main(String[] args) {
        for (int i = 1; i <= 10; i++) {
            if (i == 5) {
                break;
            }

            System.out.println(i);
        }
    }
}
```

### Output

```output id="q9v2kc"
1
2
3
4
```

When `i` becomes `5`, the `break` statement stops the loop.

So `5` and the remaining numbers are not printed.

---

## 3. break with while

`break` can also be used inside a `while` loop.

```java id="t6n5wa"
public class Main {
    public static void main(String[] args) {
        int i = 1;

        while (i <= 10) {
            if (i == 6) {
                break;
            }

            System.out.println(i);
            i++;
        }
    }
}
```

### Output

```output id="e3p7yd"
1
2
3
4
5
```

The loop stops when `i` becomes `6`.

---

## 4. Why Use break?

`break` is useful when we have found what we are looking for and do not need to continue the loop.

For example:

```java id="k8w4qn"
public class Main {
    public static void main(String[] args) {
        int[] numbers = {4, 7, 12, 9, 15};

        for (int number : numbers) {
            if (number == 12) {
                System.out.println("Number found");
                break;
            }
        }
    }
}
```

### Output

```output id="x5m2rb"
Number found
```

Once `12` is found, the loop stops.

---

## 5. What is continue?

The `continue` statement is used to **skip the current iteration** of a loop.

It does not stop the entire loop.

### Syntax

```java id="v3q7hs"
continue;
```

When Java reaches `continue`, it skips the remaining statements in the current iteration and moves to the next iteration.

---

## 6. Simple continue Example

```java id="n6k4pd"
public class Main {
    public static void main(String[] args) {
        for (int i = 1; i <= 5; i++) {
            if (i == 3) {
                continue;
            }

            System.out.println(i);
        }
    }
}
```

### Output

```output id="r8c2mz"
1
2
4
5
```

When `i` is `3`, `continue` skips that iteration.

The loop then continues with `4`.

---

## 7. break vs continue

This is an important difference.

### `break`

Stops the **entire loop**.

```text
1 → 2 → 3 → break → STOP
```

### `continue`

Skips the **current iteration** and continues the loop.

```text
1 → 2 → 3 → continue → 4 → 5
```

### Comparison

| Statement  | What it does                          |
| ---------- | ------------------------------------- |
| `break`    | Stops the loop completely             |
| `continue` | Skips the current iteration           |
| `break`    | Execution moves outside the loop      |
| `continue` | Execution moves to the next iteration |

---

## 8. Printing Only Odd Numbers Using continue

We can use `continue` to skip even numbers.

```java id="p7d4xn"
public class Main {
    public static void main(String[] args) {
        for (int i = 1; i <= 10; i++) {
            if (i % 2 == 0) {
                continue;
            }

            System.out.println(i);
        }
    }
}
```

### Output

```output id="c2m9vq"
1
3
5
7
9
```

When a number is even, `continue` skips that iteration.

---

## 9. continue with while

`continue` can also be used with a `while` loop.

When using `continue` in a `while` loop, make sure the loop variable is updated correctly.

```java id="h5r8yk"
public class Main {
    public static void main(String[] args) {
        int i = 0;

        while (i < 5) {
            i++;

            if (i == 3) {
                continue;
            }

            System.out.println(i);
        }
    }
}
```

### Output

```output id="j7x3qm"
1
2
4
5
```

The value `3` is skipped.

---

## 10. What is a Nested Loop?

A **nested loop** is a loop inside another loop.

For example:

```java id="z4n6bs"
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 2; j++) {
        System.out.println(i + " " + j);
    }
}
```

Here:

* The outer loop uses `i`.
* The inner loop uses `j`.
* The inner loop runs completely for every iteration of the outer loop.

### Output

```output id="m8q2vd"
1 1
1 2
2 1
2 2
3 1
3 2
```

---

## 11. How Nested Loops Work

Suppose the outer loop runs 3 times and the inner loop runs 2 times.

```text
Outer: 1
    Inner: 1
    Inner: 2

Outer: 2
    Inner: 1
    Inner: 2

Outer: 3
    Inner: 1
    Inner: 2
```

So the inner loop runs **2 times for each outer-loop iteration**.

Total executions:

```text
3 × 2 = 6
```

---

## 12. Nested Loop with Numbers

We can use nested loops to print a small multiplication table.

```java id="q6w3kt"
public class Main {
    public static void main(String[] args) {
        for (int i = 1; i <= 3; i++) {
            for (int j = 1; j <= 3; j++) {
                System.out.print(i * j + " ");
            }

            System.out.println();
        }
    }
}
```

### Output

```output id="a5m9xr"
1 2 3 
2 4 6 
3 6 9 
```

The outer loop controls the rows and the inner loop controls the values in each row.

---

## 13. Nested Loops with `while`

Nested loops are not limited to `for` loops.

A `while` loop can also be placed inside another loop.

```java id="d8p4vn"
public class Main {
    public static void main(String[] args) {
        int i = 1;

        while (i <= 2) {
            int j = 1;

            while (j <= 3) {
                System.out.println(i + " " + j);
                j++;
            }

            i++;
        }
    }
}
```

### Output

```output id="f2k7mc"
1 1
1 2
1 3
2 1
2 2
2 3
```

---

## 14. Nested Loops for Patterns

Nested loops are commonly used to create patterns.

For example, we can print a rectangle of stars.

```java id="s9v5bx"
public class Main {
    public static void main(String[] args) {
        for (int i = 1; i <= 3; i++) {
            for (int j = 1; j <= 4; j++) {
                System.out.print("* ");
            }

            System.out.println();
        }
    }
}
```

### Output

```output id="w3c8qn"
* * * * 
* * * * 
* * * * 
```

The outer loop controls the rows.

The inner loop controls the stars in each row.

---

## 15. Nested Loops for a Triangle

We can also change the number of repetitions of the inner loop.

```java id="e7m2kp"
public class Main {
    public static void main(String[] args) {
        for (int i = 1; i <= 4; i++) {
            for (int j = 1; j <= i; j++) {
                System.out.print("* ");
            }

            System.out.println();
        }
    }
}
```

### Output

```output id="y6q4rs"
* 
* * 
* * * 
* * * * 
```

Here, the inner loop runs:

```text
1 time
2 times
3 times
4 times
```

## 16. break in Nested Loops

When `break` is used inside a nested loop, it stops the **nearest loop containing it**.

```java id="u8k5dz"
public class Main {
    public static void main(String[] args) {
        for (int i = 1; i <= 3; i++) {
            for (int j = 1; j <= 3; j++) {
                if (j == 2) {
                    break;
                }

                System.out.println(i + " " + j);
            }
        }
    }
}
```

### Output

```output id="c4n7wp"
1 1
2 1
3 1
```

When `j` becomes `2`, the inner loop stops.

The outer loop continues with its next iteration.

---

## 17. continue in Nested Loops

`continue` also affects the **nearest loop** where it is used.

```java id="r5m8ya"
public class Main {
    public static void main(String[] args) {
        for (int i = 1; i <= 2; i++) {
            for (int j = 1; j <= 3; j++) {
                if (j == 2) {
                    continue;
                }

                System.out.println(i + " " + j);
            }
        }
    }
}
```

### Output

```output id="k9x3vf"
1 1
1 3
2 1
2 3
```

Only the current iteration of the inner loop is skipped.

---

## 18. break, continue and Nested Loops Together

These concepts are often used together.

For example:

```java id="t2m7qd"
public class Main {
    public static void main(String[] args) {
        for (int i = 1; i <= 3; i++) {
            for (int j = 1; j <= 4; j++) {
                if (j == 2) {
                    continue;
                }

                if (j == 4) {
                    break;
                }

                System.out.println(i + " " + j);
            }
        }
    }
}
```

### Output

```output id="p6v4nk"
1 1
2 1
3 1
```

For each row:

* `j == 2` skips that iteration.
* `j == 4` stops the inner loop.
* The outer loop continues.

## 19. Common Mistakes

### Mistake 1: Confusing break and continue

Remember:

```text
break    → Stop the loop
continue → Skip this iteration
```

---

### Mistake 2: Thinking break stops every loop

In nested loops, a normal `break` stops only the **nearest loop**.

The outer loop can continue.

---

### Mistake 3: Forgetting to update a while loop

Be careful when using `continue` with `while`.

The loop variable must still be updated so that the condition can eventually become false.

---

### Mistake 4: Mixing outer and inner variables

Use different variables for nested loops.

For example:

```java
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        // code
    }
}
```

Here, `i` controls the outer loop and `j` controls the inner loop.

## 20. Quick Summary

```text
break
  ↓
Stops the loop completely

continue
  ↓
Skips the current iteration

Nested loop
  ↓
A loop inside another loop
```

For nested loops:

```text
Outer loop
    ↓
  Inner loop
    ↓
  Inner loop finishes
    ↓
Outer loop continues
```

## Key Points

* `break` stops a loop immediately.
* `continue` skips the current iteration.
* `break` moves execution outside the nearest loop.
* `continue` moves to the next iteration of the nearest loop.
* A nested loop is a loop inside another loop.
* The inner loop runs completely for each outer-loop iteration.
* `break` inside a nested loop normally stops only the inner loop.
* `continue` inside a nested loop normally affects only the inner loop.
* Nested loops are useful for patterns, tables, and repeated comparisons.
