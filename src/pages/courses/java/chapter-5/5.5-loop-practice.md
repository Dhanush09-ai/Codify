## 4. Find the Sum of Numbers

Let's calculate the sum of numbers from 1 to 10.

```java id="t4n8vp"
public class Main {
    public static void main(String[] args) {
        int sum = 0;

        for (int i = 1; i <= 10; i++) {
            sum = sum + i;
        }

        System.out.println("Sum = " + sum);
    }
}
```

### Output

```output id="c7q2mz"
Sum = 55
```

The important idea is:

```text
sum = sum + i
```

The value of `sum` is updated during every iteration.

## 5. Find the Factorial of a Number

The factorial of a positive number is the product of all positive integers up to that number.

For example:

```text
5! = 5 × 4 × 3 × 2 × 1 = 120
```

We can calculate it using a loop.

```java id="y6k3ds"
public class Main {
    public static void main(String[] args) {
        int number = 5;
        int factorial = 1;

        for (int i = 1; i <= number; i++) {
            factorial = factorial * i;
        }

        System.out.println("Factorial = " + factorial);
    }
}
```

### Output

```output id="p8m4wx"
Factorial = 120
```

## 7. Count Digits in a Number

A `while` loop can be used to count the number of digits.

For example, `12345` contains 5 digits.

```java id="m8x4qt"
public class Main {
    public static void main(String[] args) {
        int number = 12345;
        int count = 0;

        while (number > 0) {
            number = number / 10;
            count++;
        }

        System.out.println("Digits = " + count);
    }
}
```

### Output

```output id="v6p2kr"
Digits = 5
```

Each division by `10` removes the last digit.

## 8. Reverse a Number

We can repeatedly take the last digit of a number and build the reversed number.

```java id="b9n5ws"
public class Main {
    public static void main(String[] args) {
        int number = 1234;
        int reverse = 0;

        while (number > 0) {
            int digit = number % 10;
            reverse = reverse * 10 + digit;
            number = number / 10;
        }

        System.out.println("Reverse = " + reverse);
    }
}
```

### Output

```output id="d4q8xm"
Reverse = 4321
```

## 9. Check Whether a Number is Palindrome

A palindrome number reads the same from left to right and right to left.

For example:

```text
121 → 121
```

We can reverse the number and compare it with the original number.

```java id="s7m3kp"
public class Main {
    public static void main(String[] args) {
        int number = 121;
        int original = number;
        int reverse = 0;

        while (number > 0) {
            int digit = number % 10;
            reverse = reverse * 10 + digit;
            number = number / 10;
        }

        if (original == reverse) {
            System.out.println("Palindrome");
        } else {
            System.out.println("Not Palindrome");
        }
    }
}
```

### Output

```output id="q5r9vc"
Palindrome
```

## 10. Check Whether a Number is Prime

A prime number has exactly two positive factors: `1` and itself.

We can use a loop to check whether a number has any divisor other than `1` and itself.

```java id="x2k6nd"
public class Main {
    public static void main(String[] args) {
        int number = 17;
        boolean prime = true;

        if (number < 2) {
            prime = false;
        } else {
            for (int i = 2; i < number; i++) {
                if (number % i == 0) {
                    prime = false;
                    break;
                }
            }
        }

        if (prime) {
            System.out.println("Prime");
        } else {
            System.out.println("Not Prime");
        }
    }
}
```

### Output

```output id="w8m4pt"
Prime
```

Notice that `break` is useful here. Once a divisor is found, there is no need to continue checking.

## 11. Find the Largest Number

A loop can be used to find the largest value from a group of numbers.

```java id="c5q8zr"
public class Main {
    public static void main(String[] args) {
        int[] numbers = {12, 45, 7, 30, 18};
        int largest = numbers[0];

        for (int i = 1; i < numbers.length; i++) {
            if (numbers[i] > largest) {
                largest = numbers[i];
            }
        }

        System.out.println("Largest = " + largest);
    }
}
```

### Output

```output id="j3v7kx"
Largest = 45
```

The loop compares each number with the current largest value.

## 14. Nested Loop Practice

Nested loops are useful for printing patterns.

Let's print a square of numbers.

```java id="k3v6bp"
public class Main {
    public static void main(String[] args) {
        for (int i = 1; i <= 3; i++) {
            for (int j = 1; j <= 3; j++) {
                System.out.print(j + " ");
            }

            System.out.println();
        }
    }
}
```

### Output

```output id="m5r8xd"
1 2 3 
1 2 3 
1 2 3 
```

The outer loop controls the rows.

The inner loop controls the numbers in each row.

## 16. Using Different Loops for Different Problems

There is no rule that says every problem must use a `for` loop.

Choose the loop based on the problem.

### Use `for`

When the number of iterations is known.

```java
for (int i = 1; i <= 10; i++) {
    System.out.println(i);
}
```

### Use `while`

When the loop mainly depends on a condition.

```java
while (number > 0) {
    number = number / 10;
}
```

### Use `do-while`

When the code should execute at least once.

```java
do {
    System.out.println("Running");
} while (choice != 0);
```

## 18. Common Loop Mistakes

### Mistake 1: Wrong starting value

```java
for (int i = 1; i < 5; i++)
```

This runs for `1, 2, 3, 4`.

If you want to include `5`, use:

```java
for (int i = 1; i <= 5; i++)
```

---

### Mistake 2: Wrong condition

Always check whether the condition includes the value you need.

For example:

```java
i < 10
```

does not include `10`.

But:

```java
i <= 10
```

includes `10`.

---

### Mistake 3: Forgetting to update the variable

```java
while (i <= 10) {
    System.out.println(i);
}
```

If `i` is never changed, the loop can become infinite.

---

### Mistake 4: Using break when you only want to skip

If you want to skip one value, use `continue`.

If you want to stop the loop completely, use `break`.

## 19. Loop Problem-Solving Steps

When solving a loop problem, follow these steps:

### Step 1: Identify what should repeat

Ask:

> What operation needs to happen again and again?

### Step 2: Choose the loop

* Known number of repetitions → `for`
* Condition-based repetition → `while`
* Must execute at least once → `do-while`

### Step 3: Set the starting value

For example:

```java
int i = 1;
```

### Step 4: Write the condition

For example:

```java
i <= 10
```

### Step 5: Write the main operation

For example:

```java
System.out.println(i);
```

### Step 6: Update the loop variable

For example:

```java
i++;
```

### Step 7: Check the output

Test the program with small values first.

---

## Key Points

* Loops are useful for solving repetitive problems.
* `for` is useful when the number of repetitions is known.
* `while` is useful for condition-based repetition.
* `do-while` executes its body at least once.
* `break` stops a loop.
* `continue` skips the current iteration.
* Nested loops are useful for patterns and tables.
* Loops can be used with conditions and arrays.
* Always make sure a loop can eventually stop.
* Practice is the best way to become comfortable with loops.
