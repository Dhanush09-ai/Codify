# Chapter 3: Operators

## Section 4: Ternary Operator

The **ternary operator** is a short way of writing a simple `if-else` condition.

It is called a **ternary operator** because it works with three parts:

1. A condition
2. A value if the condition is `true`
3. A value if the condition is `false`

In this lesson, we will learn:

* Ternary operator syntax
* How the ternary operator works
* Using it with numbers
* Using it with strings
* Using it to find the greater value
* Ternary operator vs `if-else`

---

## 1. What is the Ternary Operator?

The ternary operator is represented by:

```text
? :
```

It provides a shorter way to write a simple `if-else` statement.

For example:

```java id="ter1234"
public class Main {
    public static void main(String[] args) {
        int age = 18;

        String result = (age >= 18) ? "Eligible" : "Not Eligible";

        System.out.println(result);
    }
}
```

```output id="ter5678"
Eligible
```

Here:

* `age >= 18` is the condition.
* `"Eligible"` is selected when the condition is `true`.
* `"Not Eligible"` is selected when the condition is `false`.

---

## 2. Ternary Operator Syntax

The general syntax is:

```text
condition ? value_if_true : value_if_false
```

Think of it like this:

```text
condition ? true_value : false_value
```

For example:

```java id="syntax12"
int age = 16;

String result = (age >= 18) ? "Adult" : "Minor";
```

Since `16 >= 18` is false, the second value is selected.

So:

```text
result = "Minor"
```

---

## 3. How the Ternary Operator Works

Consider:

```java
int number = 10;

String result = (number > 0) ? "Positive" : "Not Positive";
```

Java checks the condition:

```text
number > 0
```

The condition is `true`.

Therefore, Java chooses:

```text
"Positive"
```

The basic flow is:

```text
Condition
   |
   +-- true  → first value
   |
   +-- false → second value
```

---

## 4. Ternary Operator with Numbers

The ternary operator can also return numbers.

```java id="num1234"
public class Main {
    public static void main(String[] args) {
        int a = 10;
        int b = 20;

        int greater = (a > b) ? a : b;

        System.out.println(greater);
    }
}
```

```output id="num5678"
20
```

The condition `a > b` is false because `10` is not greater than `20`.

Therefore, `b` is selected.

---

## 5. Finding the Greater Number

A common use of the ternary operator is finding the greater of two numbers.

```java id="great123"
public class Main {
    public static void main(String[] args) {
        int a = 25;
        int b = 18;

        int greater = (a > b) ? a : b;

        System.out.println("Greater number: " + greater);
    }
}
```

```output id="great456"
Greater number: 25
```

The condition:

```text
a > b
```

is true, so `a` is selected.

---

## 6. Finding the Smaller Number

We can also use the ternary operator to find the smaller number.

```java id="small123"
public class Main {
    public static void main(String[] args) {
        int a = 15;
        int b = 25;

        int smaller = (a < b) ? a : b;

        System.out.println("Smaller number: " + smaller);
    }
}
```

```output id="small456"
Smaller number: 15
```

The condition `a < b` is true, so `a` is selected.

---

## 7. Ternary Operator with Strings

The ternary operator can return strings.

```java id="str1234"
public class Main {
    public static void main(String[] args) {
        int marks = 75;

        String result = (marks >= 35) ? "Pass" : "Fail";

        System.out.println(result);
    }
}
```

```output id="str5678"
Pass
```

Since `75 >= 35` is true, `"Pass"` is selected.

---

## 8. Ternary Operator with Boolean Values

The result of a ternary expression can also be stored in a `boolean` variable.

```java id="bool1234"
public class Main {
    public static void main(String[] args) {
        int number = 10;

        boolean result = (number > 5) ? true : false;

        System.out.println(result);
    }
}
```

```output id="bool5678"
true
```

However, in a case like this, the ternary operator is unnecessary because the condition itself already produces a boolean value:

```java
boolean result = number > 5;
```

For beginners, the important idea is that the ternary operator can choose between two values based on a condition.

---

## 9. Ternary Operator vs `if-else`

The ternary operator can sometimes replace a simple `if-else`.

### Using `if-else`

```java id="if1234"
public class Main {
    public static void main(String[] args) {
        int age = 20;
        String result;

        if (age >= 18) {
            result = "Adult";
        } else {
            result = "Minor";
        }

        System.out.println(result);
    }
}
```

```output id="if5678"
Adult
```

The same logic can be written using the ternary operator:

```java id="ternif12"
public class Main {
    public static void main(String[] args) {
        int age = 20;

        String result = (age >= 18) ? "Adult" : "Minor";

        System.out.println(result);
    }
}
```

```output id="ternif34"
Adult
```

The ternary version is shorter.

---

## 10. When Should You Use the Ternary Operator?

The ternary operator is useful when the condition is **simple** and there are only two possible results.

For example:

```java
String result = (marks >= 35) ? "Pass" : "Fail";
```

This is easy to understand.

For more complicated decisions, an `if-else` statement is usually easier to read.

We will learn `if`, `if-else`, and other decision-making statements in **Chapter 4**.

---

## 11. Ternary Operator with Multiple Conditions

A ternary expression can contain a condition that uses relational and logical operators.

For example:

```java id="multi123"
public class Main {
    public static void main(String[] args) {
        int age = 20;

        String result = (age >= 18 && age <= 60) ? "Allowed" : "Not Allowed";

        System.out.println(result);
    }
}
```

```output id="multi456"
Allowed
```

Here, both conditions must be true:

* `age >= 18`
* `age <= 60`

Because both are true, `"Allowed"` is selected.

---

## 12. Nested Ternary Operator

A ternary operator can technically be placed inside another ternary operator.

For example:

```java id="nested123"
public class Main {
    public static void main(String[] args) {
        int number = 5;

        String result = (number > 0) ? "Positive" :
                        (number < 0) ? "Negative" : "Zero";

        System.out.println(result);
    }
}
```

```output id="nested456"
Positive
```

However, nested ternary expressions can become difficult to read.

As a beginner, it is better to use the ternary operator mainly for **simple two-choice conditions**.

---

## Key Points

* The ternary operator is a short form of a simple `if-else`.
* It uses the symbols `?` and `:`.
* Its basic syntax is `condition ? value_if_true : value_if_false`.
* The condition is checked first.
* If the condition is `true`, the first value is selected.
* If the condition is `false`, the second value is selected.
* The ternary operator can return numbers, strings, and other values.
* It is useful for simple two-choice decisions.
* Complex conditions are usually easier to understand using `if-else`.
* Nested ternary operators are possible, but they can make code harder to read.
