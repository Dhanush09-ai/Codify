# Chapter 3: Operators

## Section 1: Arithmetic and Assignment Operators

Operators are symbols that tell Java to perform an operation on one or more values.

For example:

```java
int result = 10 + 5;
```

Here, `+` is an operator that adds two numbers.

In this lesson, we will learn:

* Arithmetic operators
* Assignment operators
* How to use them in Java programs

---

## 1. Arithmetic Operators

Arithmetic operators are used to perform mathematical calculations.

Java provides these basic arithmetic operators:

| Operator | Name           | Example  |
| :------- | :------------- | :------- |
| `+`      | Addition       | `10 + 5` |
| `-`      | Subtraction    | `10 - 5` |
| `*`      | Multiplication | `10 * 5` |
| `/`      | Division       | `10 / 5` |
| `%`      | Modulus        | `10 % 5` |

---

## 2. Addition Operator `+`

The `+` operator adds two values.

Example:

```java id="a7k4pm"
public class Main {
    public static void main(String[] args) {
        int a = 10;
        int b = 5;

        int result = a + b;

        System.out.println(result);
    }
}
```

### Output

```output id="m3q8vx"
15
```

---

## 5. Division Operator `/`

The `/` operator divides one value by another.

Example:

```java id="v3p8nm"
public class Main {
    public static void main(String[] args) {
        int a = 10;
        int b = 5;

        int result = a / b;

        System.out.println(result);
    }
}
```

### Output

```output id="j5k9rx"
2
```

When both operands are integers, Java performs **integer division**.

For example:

```java id="q2d6wp"
public class Main {
    public static void main(String[] args) {
        int a = 7;
        int b = 2;

        System.out.println(a / b);
    }
}
```

### Output

```output id="n4c7ya"
3
```

The decimal part is discarded because both values are integers.

---

## 6. Decimal Division

If at least one value is a `double`, Java can produce a decimal result.

Example:

```java id="t8m3vc"
public class Main {
    public static void main(String[] args) {
        double a = 7;
        double b = 2;

        System.out.println(a / b);
    }
}
```

### Output

```output id="h6q2pf"
3.5
```

---

## 7. Modulus Operator `%`

The `%` operator gives the **remainder** after division.

Example:

```java id="k9r4xb"
public class Main {
    public static void main(String[] args) {
        int a = 10;
        int b = 3;

        int remainder = a % b;

        System.out.println(remainder);
    }
}
```

### Output

```output id="s5n8wm"
1
```

Because:

```text
10 ÷ 3 = 3 remainder 1
```

So:

```text
10 % 3 = 1
```

The modulus operator is useful for checking whether a number is even or odd.

Example:

```java id="f7c2ma"
public class Main {
    public static void main(String[] args) {
        int number = 8;

        System.out.println(number % 2);
    }
}
```

### Output

```output id="b3v9qx"
0
```

A remainder of `0` means the number is divisible by `2`.

## 8. Using Multiple Arithmetic Operators

We can use multiple operators in one expression.

Example:

```java id="u6p4zk"
public class Main {
    public static void main(String[] args) {
        int a = 10;
        int b = 5;
        int c = 2;

        int result = a + b * c;

        System.out.println(result);
    }
}
```

### Output

```output id="w8m2qd"
20
```

Multiplication is performed before addition.

Operator precedence will be studied in more detail later.

---

## 9. Assignment Operator `=`

The assignment operator `=` is used to assign a value to a variable.

Example:

```java id="e5k7pn"
public class Main {
    public static void main(String[] args) {
        int age = 18;

        System.out.println(age);
    }
}
```

### Output

```output id="y3c9vx"
18
```

Here:

```text
age = 18
```

means that the value `18` is assigned to `age`.

The `=` operator does not mean "equal to" in the mathematical sense. It means **assign the value on the right to the variable on the left**.

---

## 10. Changing a Variable's Value

We can assign a new value to an existing variable.

Example:

```java id="n2x6mb"
public class Main {
    public static void main(String[] args) {
        int age = 18;

        System.out.println(age);

        age = 19;

        System.out.println(age);
    }
}
```

### Output

```output id="q7r4kc"
18
19
```

The value of `age` changes from `18` to `19`.

---

## 11. Compound Assignment Operators

Java provides shorthand assignment operators.

| Operator | Meaning             | Example  |
| :------- | :------------------ | :------- |
| `=`      | Assign              | `a = 5`  |
| `+=`     | Add and assign      | `a += 5` |
| `-=`     | Subtract and assign | `a -= 5` |
| `*=`     | Multiply and assign | `a *= 5` |
| `/=`     | Divide and assign   | `a /= 5` |
| `%=`     | Modulus and assign  | `a %= 5` |

---

## 12. Addition Assignment `+=`

The `+=` operator adds a value to a variable and stores the result back in that variable.

For example:

```text
a += 5
```

is similar to:

```text
a = a + 5
```

Example:

```java id="r5m8za"
public class Main {
    public static void main(String[] args) {
        int number = 10;

        number += 5;

        System.out.println(number);
    }
}
```

### Output

```output id="c4p7yx"
15
```

---

## 17. Arithmetic and Assignment Together

We can use arithmetic and assignment operators together in a program.

Example:

```java id="z4p7mc"
public class Main {
    public static void main(String[] args) {
        int number = 10;

        number += 5;
        number *= 2;
        number -= 4;

        System.out.println(number);
    }
}
```

### Output

```output id="v9q2kx"
26
```

The operations happen in this order:

```text
10 + 5 = 15
15 × 2 = 30
30 - 4 = 26
```

---

## Key Points

* Operators are symbols used to perform operations.
* Arithmetic operators are used for mathematical calculations.
* `+` performs addition.
* `-` performs subtraction.
* `*` performs multiplication.
* `/` performs division.
* `%` gives the remainder.
* `=` assigns a value to a variable.
* `+=`, `-=`, `*=`, `/=`, and `%=` are compound assignment operators.
* Integer division removes the decimal part.
* If at least one operand is a `double`, division can produce a decimal result.
