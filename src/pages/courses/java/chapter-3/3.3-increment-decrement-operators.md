# Chapter 3: Operators

## Section 3: Increment & Decrement Operators

Increment and decrement operators are used to increase or decrease the value of a variable by `1`.

In this lesson, we will learn:

* Increment operator `++`
* Decrement operator `--`
* Prefix increment and decrement
* Postfix increment and decrement
* Difference between prefix and postfix

---

## 1. Increment Operator `++`

The increment operator `++` increases the value of a variable by `1`.

For example:

```java id="inc1234"
public class Main {
    public static void main(String[] args) {
        int number = 5;

        number++;

        System.out.println(number);
    }
}
```

```output id="inc5678"
6
```

The value changes from:

`5 → 6`

So, `number++` means:

`number = number + 1`

---

## 2. Decrement Operator `--`

The decrement operator `--` decreases the value of a variable by `1`.

```java id="dec1234"
public class Main {
    public static void main(String[] args) {
        int number = 5;

        number--;

        System.out.println(number);
    }
}
```

```output id="dec5678"
4
```

The value changes from:

`5 → 4`

So, `number--` means:

`number = number - 1`

---

## 3. Prefix Increment `++variable`

When `++` is written **before** a variable, it is called **prefix increment**.

```java id="preinc12"
public class Main {
    public static void main(String[] args) {
        int number = 5;

        int result = ++number;

        System.out.println(result);
        System.out.println(number);
    }
}
```

```output id="preinc34"
6
6
```

First, `number` is increased:

`number = 6`

Then, the new value `6` is assigned to `result`.

So:

`++number` → increase first, then use the value.

---

## 4. Postfix Increment `variable++`

When `++` is written **after** a variable, it is called **postfix increment**.

```java id="postinc12"
public class Main {
    public static void main(String[] args) {
        int number = 5;

        int result = number++;

        System.out.println(result);
        System.out.println(number);
    }
}
```

```output id="postinc34"
5
6
```

Here, the original value is used first.

Then `number` is increased.

So:

`number++` → use first, then increase.

---

## 5. Prefix vs Postfix Increment

The main difference is **when the value is changed**.

|  Operator  | Meaning                            |
| :--------: | :--------------------------------- |
| `++number` | Increase first, then use the value |
| `number++` | Use the value first, then increase |

Example:

```java id="compare12"
int number = 5;

int a = ++number;
```

Result:

```text
number = 6
a = 6
```

But:

```java id="compare34"
int number = 5;

int a = number++;
```

Result:

```text
number = 6
a = 5
```

---

## 6. Prefix Decrement `--variable`

When `--` is written before a variable, it is called **prefix decrement**.

The value is decreased first and then used.

```java id="predec12"
public class Main {
    public static void main(String[] args) {
        int number = 5;

        int result = --number;

        System.out.println(result);
        System.out.println(number);
    }
}
```

```output id="predec34"
4
4
```

First:

`number = 4`

Then the value `4` is assigned to `result`.

So:

`--number` → decrease first, then use.

---

## 7. Postfix Decrement `variable--`

When `--` is written after a variable, it is called **postfix decrement**.

The original value is used first, and then the variable is decreased.

```java id="postdec12"
public class Main {
    public static void main(String[] args) {
        int number = 5;

        int result = number--;

        System.out.println(result);
        System.out.println(number);
    }
}
```

```output id="postdec34"
5
4
```

So:

`number--` → use first, then decrease.

---

## 8. Prefix vs Postfix Decrement

|  Operator  | Meaning                            |
| :--------: | :--------------------------------- |
| `--number` | Decrease first, then use the value |
| `number--` | Use the value first, then decrease |

Example:

```java id="deccompare1"
int number = 5;

int a = --number;
```

Result:

```text
number = 4
a = 4
```

But:

```java id="deccompare2"
int number = 5;

int a = number--;
```

Result:

```text
number = 4
a = 5
```

---

## 9. Using Increment in an Expression

Increment operators can also be used inside expressions.

For example:

```java id="expression12"
public class Main {
    public static void main(String[] args) {
        int number = 5;

        System.out.println(number++);
        System.out.println(number);
    }
}
```

```output id="expression34"
5
6
```

The first `println()` uses the original value `5`.

After that, `number` becomes `6`.

---

## 10. Using Decrement in an Expression

The same idea applies to decrement.

```java id="expression56"
public class Main {
    public static void main(String[] args) {
        int number = 5;

        System.out.println(--number);
        System.out.println(number);
    }
}
```

```output id="expression78"
4
4
```

Because `--number` decreases the value before using it.

---

## 11. Increment and Decrement in Simple Programs

Increment and decrement operators are commonly used when working with repeated operations.

For example:

```java id="simpleinc12"
public class Main {
    public static void main(String[] args) {
        int count = 1;

        count++;
        count++;
        count++;

        System.out.println(count);
    }
}
```

```output id="simpleinc34"
4
```

The value changes like this:

`1 → 2 → 3 → 4`

We will use increment and decrement operators more frequently when learning **loops**.

---

## 12. `++` and `--` Only Change by One

The increment operator increases a value by exactly `1`.

```java
number++;
```

is equivalent to:

```java
number = number + 1;
```

Similarly:

```java
number--;
```

is equivalent to:

```java
number = number - 1;
```

They do not increase or decrease a value by an arbitrary amount.

---

## Key Points

* `++` is the increment operator.
* `--` is the decrement operator.
* `++` increases a variable by `1`.
* `--` decreases a variable by `1`.
* `++number` is prefix increment.
* `number++` is postfix increment.
* `--number` is prefix decrement.
* `number--` is postfix decrement.
* Prefix changes the value before it is used.
* Postfix uses the value before changing it.
* Increment and decrement operators are commonly used with loops.
* `number++` is equivalent to `number = number + 1`.
* `number--` is equivalent to `number = number - 1`.
