# Chapter 3: Operators

## Section 5: Operator Precedence

When an expression contains more than one operator, Java needs to know **which operation should be performed first**.

The rules that determine the order of operations are called **operator precedence**.

In this lesson, we will learn:

* What operator precedence means
* Why precedence is important
* Arithmetic operator precedence
* Using parentheses
* Operators with the same precedence
* Precedence with relational and logical operators

---

## 1. What is Operator Precedence?

**Operator precedence** determines which operator is evaluated first when an expression contains multiple operators.

For example:

```java id="prec1234"
public class Main {
    public static void main(String[] args) {
        int result = 10 + 5 * 2;

        System.out.println(result);
    }
}
```

```output id="prec5678"
20
```

You might expect:

`10 + 5 = 15`

Then:

`15 * 2 = 30`

But Java does not calculate it from left to right.

The multiplication `*` has higher precedence than addition `+`.

So Java calculates:

`5 * 2 = 10`

Then:

`10 + 10 = 20`

Therefore, the output is:

`20`

---

## 2. Why is Operator Precedence Important?

Operator precedence helps Java determine the correct order of operations.

Consider:

```java id="why1234"
int result = 20 - 6 / 2;
```

Division has higher precedence than subtraction.

So Java calculates:

`6 / 2 = 3`

Then:

`20 - 3 = 17`

Therefore:

```java id="why5678"
System.out.println(result);
```

produces:

```output id="why9012"
17
```

Without understanding precedence, it can be easy to predict the wrong result.

---

## 3. Basic Arithmetic Precedence

For the arithmetic operators we have learned, the general order is:

| Priority | Operators   | Meaning                           |
| :------: | :---------- | :-------------------------------- |
|     1    | `()`        | Parentheses                       |
|     2    | `*` `/` `%` | Multiplication, Division, Modulus |
|     3    | `+` `-`     | Addition, Subtraction             |

Operators with a higher priority are evaluated first.

For example:

```text id="order123"
10 + 5 * 2
```

First:

`5 * 2 = 10`

Then:

`10 + 10 = 20`

---

## 4. Parentheses Have Higher Priority

Parentheses `()` can be used to control the order of evaluation.

For example:

```java id="paren123"
public class Main {
    public static void main(String[] args) {
        int result = (10 + 5) * 2;

        System.out.println(result);
    }
}
```

```output id="paren456"
30
```

The parentheses are evaluated first:

`10 + 5 = 15`

Then:

`15 * 2 = 30`

Without parentheses:

```java
int result = 10 + 5 * 2;
```

The result would be:

`20`

So parentheses allow us to clearly specify which operation should happen first.

---

## 5. Multiplication, Division and Modulus

The operators:

* `*`
* `/`
* `%`

have higher precedence than:

* `+`
* `-`

For example:

```java id="mdm1234"
public class Main {
    public static void main(String[] args) {
        int result = 20 + 10 % 3;

        System.out.println(result);
    }
}
```

```output id="mdm5678"
21
```

First:

`10 % 3 = 1`

Then:

`20 + 1 = 21`

---

## 6. Operators with the Same Precedence

Sometimes an expression contains operators with the same precedence.

For example:

```java id="same1234"
public class Main {
    public static void main(String[] args) {
        int result = 20 / 5 * 2;

        System.out.println(result);
    }
}
```

```output id="same5678"
8
```

Both `/` and `*` have the same precedence.

They are evaluated from **left to right**:

`20 / 5 = 4`

Then:

`4 * 2 = 8`

So the result is `8`.

---

## 7. Addition and Subtraction with the Same Precedence

`+` and `-` also have the same precedence.

They are evaluated from left to right.

```java id="addsub12"
public class Main {
    public static void main(String[] args) {
        int result = 20 - 5 + 3;

        System.out.println(result);
    }
}
```

```output id="addsub34"
18
```

Java evaluates from left to right:

`20 - 5 = 15`

Then:

`15 + 3 = 18`

---

## 8. Using Parentheses to Make Expressions Clear

Even when you understand precedence, parentheses can make your code easier to read.

For example:

```java id="clear123"
public class Main {
    public static void main(String[] args) {
        int result = 10 + (5 * 2);

        System.out.println(result);
    }
}
```

```output id="clear456"
20
```

The parentheses clearly show that multiplication should happen first.

Using parentheses is especially useful when an expression is becoming difficult to understand.

---

## 9. Precedence with Relational Operators

Relational operators are also used in expressions.

For example:

```java id="rel1234"
public class Main {
    public static void main(String[] args) {
        boolean result = 10 + 5 > 12;

        System.out.println(result);
    }
}
```

```output id="rel5678"
true
```

Java first evaluates:

`10 + 5 = 15`

Then checks:

`15 > 12`

The result is `true`.

So arithmetic operations are evaluated before the relational comparison in this expression.

---

## 10. Precedence with Logical Operators

Logical operators also have their own precedence.

A simplified order for the operators learned so far is:

| Priority | Operators            |   |   |
| :------: | :------------------- | - | - |
|  Higher  | Arithmetic operators |   |   |
|     ↓    | Relational operators |   |   |
|     ↓    | `&&`                 |   |   |
|     ↓    | `                    |   | ` |
|   Lower  | Ternary `?:`         |   |   |

The `!` operator has higher precedence than `&&` and `||`.

For example:

```java id="logic1234"
public class Main {
    public static void main(String[] args) {
        boolean result = 10 > 5 && 20 > 15;

        System.out.println(result);
    }
}
```

```output id="logic5678"
true
```

First Java evaluates the relational expressions:

* `10 > 5` → `true`
* `20 > 15` → `true`

Then:

`true && true` → `true`

---

## 11. Using Parentheses with Conditions

Parentheses can make conditions easier to understand.

```java id="cond1234"
public class Main {
    public static void main(String[] args) {
        int age = 20;

        boolean result = (age >= 18) && (age <= 60);

        System.out.println(result);
    }
}
```

```output id="cond5678"
true
```

The parentheses clearly separate the two conditions.

---

## 12. Assignment Comes After the Expression

When assigning an expression to a variable, Java evaluates the expression before storing its result.

For example:

```java id="assign123"
public class Main {
    public static void main(String[] args) {
        int result = 10 + 5 * 2;

        System.out.println(result);
    }
}
```

```output id="assign456"
20
```

Java first evaluates:

`5 * 2 = 10`

Then:

`10 + 10 = 20`

Finally, `20` is assigned to `result`.

---

## 13. A Simple Way to Remember Precedence

For the operators covered in this chapter, remember this general order:

```text id="remember12"
Parentheses
     ↓
Arithmetic
     ↓
Relational
     ↓
Logical
     ↓
Ternary
     ↓
Assignment
```

For arithmetic operators:

```text id="remember34"
()
↓
* / %
↓
+ -
```

When operators have the same precedence, Java generally evaluates them from **left to right** for the operators discussed here.

---

## 14. Example with Multiple Operators

Let's look at a slightly larger expression:

```java id="multi1234"
public class Main {
    public static void main(String[] args) {
        int result = 10 + 6 / 2 * 3 - 4;

        System.out.println(result);
    }
}
```

```output id="multi5678"
15
```

Let's evaluate it step by step.

First, `/` and `*` have higher precedence than `+` and `-`.

Starting from the left:

`6 / 2 = 3`

Then:

`3 * 3 = 9`

The expression becomes:

`10 + 9 - 4`

Now evaluate from left to right:

`10 + 9 = 19`

Then:

`19 - 4 = 15`

Therefore, the output is:

`15`

---

## Key Points

* Operator precedence determines the order in which operators are evaluated.
* Parentheses have high priority and can control the order of evaluation.
* `*`, `/`, and `%` have higher precedence than `+` and `-`.
* Operators with the same precedence are evaluated from left to right for the operators discussed here.
* Arithmetic operations can be evaluated before relational comparisons.
* Relational results can then be combined using logical operators.
* `&&` has higher precedence than `||`.
* Parentheses can make complicated expressions easier to understand.
* Understanding precedence helps you predict the correct output of an expression.
* When in doubt, use parentheses to make the intended order clear.
