# Chapter 3: Operators

## Section 2: Relational & Logical Operators

Operators are symbols used to perform operations on values and variables.

In this lesson, we will learn about:

* Relational operators
* Comparing values
* Logical operators
* Combining conditions
* Using relational and logical operators together

---

## 1. What are Relational Operators?

**Relational operators** are used to compare two values.

The result of a relational operation is always either:

* `true`
* `false`

For example:

```java id="r1a2b3"
public class Main {
    public static void main(String[] args) {
        int a = 10;
        int b = 5;

        System.out.println(a > b);
    }
}
```

```output id="o1a2b3"
true
```

Here, `10 > 5` is true, so Java prints `true`.

---

## 2. Relational Operators in Java

Java provides the following relational operators:

| Operator | Meaning                  | Example  |
| :------: | :----------------------- | :------- |
|   `==`   | Equal to                 | `a == b` |
|   `!=`   | Not equal to             | `a != b` |
|    `>`   | Greater than             | `a > b`  |
|    `<`   | Less than                | `a < b`  |
|   `>=`   | Greater than or equal to | `a >= b` |
|   `<=`   | Less than or equal to    | `a <= b` |

These operators are mainly used when we need to make decisions based on conditions.

---

## 3. Equal to `==`

The `==` operator checks whether two values are equal.

```java id="eq1234"
public class Main {
    public static void main(String[] args) {
        int a = 10;
        int b = 10;

        System.out.println(a == b);
    }
}
```

```output id="eq5678"
true
```

Both values are `10`, so the result is `true`.

### Important

Do not confuse `==` with `=`.

* `=` assigns a value.
* `==` compares two values.

For example:

```java id="eq9012"
int x = 10;
System.out.println(x == 10);
```

```output id="eq3456"
true
```

---

## 4. Not Equal to `!=`

The `!=` operator checks whether two values are different.

```java id="ne1234"
public class Main {
    public static void main(String[] args) {
        int a = 10;
        int b = 5;

        System.out.println(a != b);
    }
}
```

```output id="ne5678"
true
```

Because `10` and `5` are different, the result is `true`.



## 7. Greater Than or Equal to `>=`

The `>=` operator checks whether a value is greater than or equal to another value.

```java id="ge1234"
public class Main {
    public static void main(String[] args) {
        int marks = 50;

        System.out.println(marks >= 50);
    }
}
```

```output id="ge5678"
true
```

The condition is true because `50` is equal to `50`.

It would also be true if `marks` were greater than `50`.


## 9. What are Logical Operators?

**Logical operators** are used to combine or reverse conditions.

Java provides three main logical operators:

| Operator | Name        | Meaning                      |            |                                     |
| :------: | :---------- | :--------------------------- | ---------- | ----------------------------------- |
|   `&&`   | Logical AND | Both conditions must be true |            |                                     |
|     `    |             | `                            | Logical OR | At least one condition must be true |
|    `!`   | Logical NOT | Reverses the result          |            |                                     |

Logical operators are especially useful when a program needs to check multiple conditions.

---

## 10. Logical AND `&&`

The `&&` operator returns `true` only when **both conditions are true**.

```java id="and1234"
public class Main {
    public static void main(String[] args) {
        int age = 20;

        System.out.println(age >= 18 && age <= 60);
    }
}
```

```output id="and5678"
true
```

Both conditions are true:

* `age >= 18` → `true`
* `age <= 60` → `true`

Therefore:

`true && true` → `true`

### AND Truth Table

| Condition 1 | Condition 2 |  Result |
| :---------: | :---------: | :-----: |
|    `true`   |    `true`   |  `true` |
|    `true`   |   `false`   | `false` |
|   `false`   |    `true`   | `false` |
|   `false`   |   `false`   | `false` |

---

## 11. Logical OR `||`

The `||` operator returns `true` when **at least one condition is true**.

```java id="or1234"
public class Main {
    public static void main(String[] args) {
        int age = 16;

        System.out.println(age < 18 || age > 60);
    }
}
```

```output id="or5678"
true
```

Here:

* `age < 18` → `true`
* `age > 60` → `false`

At least one condition is true, so the final result is `true`.

### OR Truth Table

| Condition 1 | Condition 2 |  Result |
| :---------: | :---------: | :-----: |
|    `true`   |    `true`   |  `true` |
|    `true`   |   `false`   |  `true` |
|   `false`   |    `true`   |  `true` |
|   `false`   |   `false`   | `false` |

---

## 12. Logical NOT `!`

The `!` operator reverses a boolean result.

* `true` becomes `false`
* `false` becomes `true`

```java id="not1234"
public class Main {
    public static void main(String[] args) {
        boolean isJavaFun = true;

        System.out.println(!isJavaFun);
    }
}
```

```output id="not5678"
false
```

The original value is `true`.

The `!` operator reverses it:

`!true` → `false`

---

## 13. Combining Relational and Logical Operators

Relational and logical operators can be used together.

For example, we can check whether a student's marks are between `35` and `100`.

```java id="combo123"
public class Main {
    public static void main(String[] args) {
        int marks = 75;

        System.out.println(marks >= 35 && marks <= 100);
    }
}
```

```output id="combo456"
true
```

Here, Java checks two conditions:

* `marks >= 35` → `true`
* `marks <= 100` → `true`

Therefore:

`true && true` → `true`

This type of combination is very useful when checking multiple requirements.

---

## 14. Relational Operators Return Boolean Values

Relational operators produce a boolean result.

For example:

```java id="bool1234"
public class Main {
    public static void main(String[] args) {
        int a = 10;
        int b = 20;

        boolean result = a < b;

        System.out.println(result);
    }
}
```

```output id="bool5678"
true
```

The expression `a < b` produces `true`, which is stored in the `boolean` variable `result`.

---

## 15. Simple Real-Life Example

Suppose a student can enter a competition if their age is between `15` and `18`.

We can represent this condition using `&&`.

```java id="real1234"
public class Main {
    public static void main(String[] args) {
        int age = 16;

        boolean eligible = age >= 15 && age <= 18;

        System.out.println(eligible);
    }
}
```

```output id="real5678"
true
```

Both conditions must be true:

* Age must be at least `15`.
* Age must be at most `18`.

---

## Key Points

* Relational operators are used to compare values.
* Relational operations produce `true` or `false`.
* `==` checks whether two values are equal.
* `!=` checks whether two values are different.
* `>` checks for greater than.
* `<` checks for less than.
* `>=` checks for greater than or equal to.
* `<=` checks for less than or equal to.
* `&&` means logical AND.
* `||` means logical OR.
* `!` means logical NOT.
* `&&` requires both conditions to be true.
* `||` requires at least one condition to be true.
* `!` reverses a boolean result.
* Relational and logical operators can be combined to create more useful conditions.
