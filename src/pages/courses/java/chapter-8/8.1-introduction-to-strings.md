# Chapter 8: Strings

## Section 1: Introduction to Strings

So far, we have worked with data types such as `int`, `double`, `char`, and arrays.

In this chapter, we will learn about **Strings**.

Strings are used whenever we need to work with text, such as names, messages, sentences, and words.

---

## 1. What is a String?

A **String** is a sequence of characters.

For example:

```text id="s81001"
Hello
Java
CODIFY
Owais
```

In Java, a String is represented using the `String` class.

Example:

```java id="s81002"
public class Main {

    public static void main(String[] args) {
        String name = "Owais";

        System.out.println(name);
    }
}
```

```output id="o81002"
Owais
```

Here:

```text id="s81003"
name
```

is a variable that stores the String:

```text id="s81004"
"Owais"
```

---

## 2. Creating a String

We can create a String by assigning text inside double quotation marks.

```java id="s81005"
public class Main {

    public static void main(String[] args) {
        String message = "Hello, Java!";

        System.out.println(message);
    }
}
```

```output id="o81005"
Hello, Java!
```

The text is written inside:

```text id="s81006"
" "
```

These are called **double quotation marks**.

---

## 3. String vs Character

A `char` stores a **single character**.

A `String` can store multiple characters.

Example:

```java id="s81007"
public class Main {

    public static void main(String[] args) {
        char grade = 'A';
        String name = "Owais";

        System.out.println(grade);
        System.out.println(name);
    }
}
```

```output id="o81007"
A
Owais
```

The difference is:

| `char`                   | `String`                        |
| ------------------------ | ------------------------------- |
| Stores one character     | Stores a sequence of characters |
| Uses single quotes `' '` | Uses double quotes `" "`        |
| Example: `'A'`           | Example: `"Owais"`              |

---

## 4. A String Can Contain Spaces

A String can contain spaces between words.

```java id="s81008"
public class Main {

    public static void main(String[] args) {
        String message = "Welcome to CODIFY";

        System.out.println(message);
    }
}
```

```output id="o81008"
Welcome to CODIFY
```

The entire text is stored as one String.

---

## 5. Strings Can Contain Numbers

A String can contain numbers as text.

```java id="s81009"
public class Main {

    public static void main(String[] args) {
        String number = "12345";

        System.out.println(number);
    }
}
```

```output id="o81009"
12345
```

However, `"12345"` is **text**, not an integer.

For example:

```java id="s81010"
String number = "12345";
int value = 12345;
```

Here:

* `number` stores text.
* `value` stores an integer.

---

## 6. Joining Strings

We can join two or more Strings using the `+` operator.

This is called **String concatenation**.

```java id="s81011"
public class Main {

    public static void main(String[] args) {
        String firstName = "Owais";
        String lastName = "Mohammed";

        String fullName = firstName + " " + lastName;

        System.out.println(fullName);
    }
}
```

```output id="o81011"
Owais Mohammed
```

The `+` operator joins the Strings together.

---

## 7. String Concatenation with Numbers

A String can also be joined with numbers.

```java id="s81012"
public class Main {

    public static void main(String[] args) {
        String name = "Owais";
        int age = 16;

        System.out.println("Name: " + name);
        System.out.println("Age: " + age);
    }
}
```

```output id="o81012"
Name: Owais
Age: 16
```

When a String is combined with a number using `+`, the result is treated as text.

---

## 8. The `+` Operator with Strings

The position of the String can affect the result.

Consider:

```java id="s81013"
public class Main {

    public static void main(String[] args) {
        System.out.println("Result: " + 10 + 20);
        System.out.println(10 + 20 + " is the result");
    }
}
```

```output id="o81013"
Result: 1020
30 is the result
```

Why?

In:

```text id="s81014"
"Result: " + 10 + 20
```

the String appears first, so `10` and `20` are joined as text.

In:

```text id="s81015"
10 + 20 + " is the result"
```

Java first calculates:

```text id="s81016"
10 + 20 = 30
```

and then joins `30` with the String.

## 9. Finding the Length of a String

The `length()` method gives the number of characters in a String.

Example:

```java id="s81017"
public class Main {

    public static void main(String[] args) {
        String name = "Java";

        System.out.println(name.length());
    }
}
```

```output id="o81017"
4
```

The String:

```text id="s81018"
Java
```

contains four characters.

```text id="s81019"
J  a  v  a
```

The spaces in a String are also counted.

For example:

```java id="s81020"
public class Main {

    public static void main(String[] args) {
        String message = "Hello Java";

        System.out.println(message.length());
    }
}
```

```output id="o81020"
10
```

There are 10 characters, including the space.

## 10. Accessing Characters in a String

We can access an individual character using the `charAt()` method.

Example:

```java id="s81021"
public class Main {

    public static void main(String[] args) {
        String name = "Java";

        System.out.println(name.charAt(0));
        System.out.println(name.charAt(2));
    }
}
```

```output id="o81021"
J
v
```

String indexes start at `0`.

So:

```text id="s81022"
J → index 0
a → index 1
v → index 2
a → index 3
```

---

## 11. String Indexes

Just like arrays, String indexes start from `0`.

For:

```text id="s81023"
"Java"
```

the indexes are:

| Character | Index |
| --------- | ----: |
| `J`       |     0 |
| `a`       |     1 |
| `v`       |     2 |
| `a`       |     3 |

The last index is:

```text id="s81024"
length - 1
```

So for `"Java"`:

```text id="s81025"
4 - 1 = 3
```

---

## 12. Traversing a String

We can use a loop to visit each character in a String.

```java id="s81026"
public class Main {

    public static void main(String[] args) {
        String word = "Java";

        for (int i = 0; i < word.length(); i++) {
            System.out.println(word.charAt(i));
        }
    }
}
```

```output id="o81026"
J
a
v
a
```

The loop starts at index `0` and continues until the last character.

---

## 13. Printing a String Character by Character

We can also print all characters on one line.

```java id="s81027"
public class Main {

    public static void main(String[] args) {
        String word = "CODIFY";

        for (int i = 0; i < word.length(); i++) {
            System.out.print(word.charAt(i) + " ");
        }
    }
}
```

```output id="o81027"
C O D I F Y 
```

## 14. Strings Are Case-Sensitive

Java Strings are **case-sensitive**.

This means uppercase and lowercase letters are considered different.

For example:

```java id="s81028"
public class Main {

    public static void main(String[] args) {
        String first = "Java";
        String second = "java";

        System.out.println(first.equals(second));
    }
}
```

```output id="o81028"
false
```

`"Java"` and `"java"` are different because `J` and `j` have different cases.

---

## 15. Comparing Strings

To compare the contents of two Strings, we commonly use the `equals()` method.

```java id="s81029"
public class Main {

    public static void main(String[] args) {
        String first = "Hello";
        String second = "Hello";

        System.out.println(first.equals(second));
    }
}
```

```output id="o81029"
true
```

If the contents are the same, `equals()` returns `true`.

If they are different, it returns `false`.

---

## 16. Changing String Case

Java provides methods for changing the case of a String.

### `toUpperCase()`

Converts the String to uppercase.

```java id="s81030"
public class Main {

    public static void main(String[] args) {
        String message = "hello java";

        System.out.println(message.toUpperCase());
    }
}
```

```output id="o81030"
HELLO JAVA
```

### `toLowerCase()`

Converts the String to lowercase.

```java id="s81031"
public class Main {

    public static void main(String[] args) {
        String message = "HELLO JAVA";

        System.out.println(message.toLowerCase());
    }
}
```

```output id="o81031"
hello java
```

---

## 17. Removing Extra Spaces

The `trim()` method removes leading and trailing spaces from a String.

```java id="s81032"
public class Main {

    public static void main(String[] args) {
        String message = "   Hello Java   ";

        System.out.println(message.trim());
    }
}
```

```output id="o81032"
Hello Java
```

The spaces inside the String are not removed.

---

## 18. Replacing Characters or Text

The `replace()` method can replace characters or text.

```java id="s81033"
public class Main {

    public static void main(String[] args) {
        String message = "I like Java";

        String result = message.replace("Java", "CODIFY");

        System.out.println(result);
    }
}
```

```output id="o81033"
I like CODIFY
```

The original String is not directly changed.

The replacement result is stored in `result`.

## 19. Important String Methods

Here are some commonly used String methods:

| Method          | Purpose                             |
| --------------- | ----------------------------------- |
| `length()`      | Finds the number of characters      |
| `charAt(index)` | Gets a character at an index        |
| `equals()`      | Compares String contents            |
| `toUpperCase()` | Converts to uppercase               |
| `toLowerCase()` | Converts to lowercase               |
| `trim()`        | Removes leading and trailing spaces |
| `replace()`     | Replaces characters or text         |

We will learn these methods in more detail in later String topics.

## 20. Quick Example

Let's combine some basic String operations.

```java id="s81034"
public class Main {

    public static void main(String[] args) {
        String name = "Java";

        System.out.println("Name: " + name);
        System.out.println("Length: " + name.length());
        System.out.println("First character: " + name.charAt(0));
        System.out.println("Uppercase: " + name.toUpperCase());
    }
}
```

```output id="o81034"
Name: Java
Length: 4
First character: J
Uppercase: JAVA
```

The program:

1. Creates a String.
2. Prints the String.
3. Finds its length.
4. Gets its first character.
5. Converts it to uppercase.

## Key Points

* A **String** is a sequence of characters.
* Java uses the `String` class to work with text.
* Strings are written using double quotes `" "`.
* A `char` stores one character, while a `String` can contain multiple characters.
* String indexes start from `0`.
* `length()` returns the number of characters.
* `charAt()` accesses a character at a particular index.
* The `+` operator can join Strings.
* `equals()` compares the contents of two Strings.
* Java Strings are case-sensitive.
* `toUpperCase()` converts text to uppercase.
* `toLowerCase()` converts text to lowercase.
* `trim()` removes leading and trailing spaces.
* `replace()` can replace characters or text.
