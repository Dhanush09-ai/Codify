# Chapter 8: Strings

## Section 4: Comparing and Modifying Strings

In the previous topics, we learned how to find String length, access characters, traverse Strings, and concatenate Strings.

Now, we will learn how to:

* Compare Strings
* Use `equals()`
* Compare Strings without considering case
* Convert Strings to uppercase and lowercase
* Remove extra spaces
* Replace characters and text
* Combine String methods
* Understand common String mistakes

---

## 1. Comparing Two Strings

We can compare two Strings using the `equals()` method.

The `equals()` method checks whether two Strings contain the same characters.

Example:

```java id="s84001"
public class Main {

    public static void main(String[] args) {
        String first = "Java";
        String second = "Java";

        System.out.println(first.equals(second));
    }
}
```

```output id="o84001"
true
```

Both Strings contain `"Java"`, so `equals()` returns `true`.

---

## 2. Comparing Different Strings

If two Strings contain different text, `equals()` returns `false`.

```java id="s84002"
public class Main {

    public static void main(String[] args) {
        String first = "Java";
        String second = "Python";

        System.out.println(first.equals(second));
    }
}
```

```output id="o84002"
false
```

---

## 3. String Comparison Is Case-Sensitive

The `equals()` method considers uppercase and lowercase letters as different.

For example:

```java id="s84003"
public class Main {

    public static void main(String[] args) {
        String first = "Java";
        String second = "java";

        System.out.println(first.equals(second));
    }
}
```

```output id="o84003"
false
```

`"Java"` and `"java"` are different because `J` and `j` have different cases.

---

## 4. Using `equalsIgnoreCase()`

Sometimes we want to compare Strings without considering uppercase and lowercase letters.

For this, we can use `equalsIgnoreCase()`.

```java id="s84004"
public class Main {

    public static void main(String[] args) {
        String first = "Java";
        String second = "java";

        System.out.println(first.equalsIgnoreCase(second));
    }
}
```

```output id="o84004"
true
```

Here, `"Java"` and `"java"` are considered equal.

---

## 5. `equals()` vs `equalsIgnoreCase()`

The difference is:

| Method               | Case-sensitive |
| -------------------- | -------------- |
| `equals()`           | Yes            |
| `equalsIgnoreCase()` | No             |

Use `equals()` when uppercase and lowercase should matter.

Use `equalsIgnoreCase()` when they should not matter.

---

## 6. Comparing User Input

We can use String comparison when checking input from the user.

```java id="s84005"
import java.util.Scanner;

public class Main {

    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        String answer = input.nextLine();

        if (answer.equalsIgnoreCase("yes")) {
            System.out.println("You entered yes");
        } else {
            System.out.println("You entered something else");
        }
    }
}
```

Input:

```text id="i84005"
YES
```

Output:

```output id="o84005"
You entered yes
```

---

## 7. Why Not Use `==` for String Comparison?

The `==` operator is not normally used to compare the content of two Strings.

For String content, use:

```java id="s84006"
first.equals(second)
```

Remember:

```text id="s84007"
equals() → compares String content
==       → compares references
```

For beginner String comparisons, use `equals()`.

## 8. Converting a String to Uppercase

The `toUpperCase()` method converts letters in a String to uppercase.

```java id="s84008"
public class Main {

    public static void main(String[] args) {

        System.out.println(text.toUpperCase());
    }
}
```

```output id="o84008"

```

---

## 10. Removing Extra Spaces

The `trim()` method removes spaces from the beginning and end of a String.

```java id="s84010"
public class Main {

    public static void main(String[] args) {
        String text = "   Java   ";

        System.out.println(text.trim());
    }
}
```

```output id="o84010"
Java
```

The spaces before and after `"Java"` are removed.

---

## 11. Spaces Between Words

`trim()` does not remove spaces between words.

For example:

```text id="s84011"
Java Programming
```

remains:

```text id="s84012"
Java Programming
```

The space between `"Java"` and `"Programming"` is not removed.

---

## 12. Replacing Characters

The `replace()` method can replace one character with another.

```java id="s84013"
public class Main {

    public static void main(String[] args) {
        String word = "banana";

        System.out.println(word.replace('a', 'o'));
    }
}
```

```output id="o84013"
bonono
```

Every `a` is replaced with `o`.

---

## 13. Replacing Text

The `replace()` method can also replace one piece of text with another.

```java id="s84014"
public class Main {

    public static void main(String[] args) {
        String message = "I like Java";

        System.out.println(message.replace("Java", "Python"));
    }
}
```

```output id="o84014"
I like Python
```

---

## 14. Storing a Modified String

String methods return a new String.

If we want to keep the modified result, we should assign it back to a variable.

```java id="s84015"
public class Main {

    public static void main(String[] args) {
        String text = "java";

        text = text.toUpperCase();

        System.out.println(text);
    }
}
```

```output id="o84015"
JAVA
```

Here:

```text id="s84016"
text.toUpperCase()
```

returns `"JAVA"`.

The result is then stored back in `text`.

---

## 15. Modifying Without Storing the Result

If we do not store the returned String, the original variable remains unchanged.

```java id="s84017"
public class Main {

    public static void main(String[] args) {
        String text = "java";

        text.toUpperCase();

        System.out.println(text);
    }
}
```

```output id="o84017"
java
```

The result of `toUpperCase()` was not stored.

So `text` still contains `"java"`.

---

## 16. Combining String Methods

We can use more than one String method on the same String.

```java id="s84018"
public class Main {

    public static void main(String[] args) {
        String text = "  Hello Java  ";

        text = text.trim();
        text = text.toUpperCase();

        System.out.println(text);
    }
}
```

```output id="o84018"
HELLO JAVA
```

The program:

1. Removes the extra spaces.
2. Converts the text to uppercase.
3. Stores the result in `text`.

---

## 17. Method Chaining

We can also use multiple String methods in one statement.

```java id="s84019"
public class Main {

    public static void main(String[] args) {
        String text = "  Hello Java  ";

        System.out.println(text.trim().toUpperCase());
    }
}
```

```output id="o84019"
HELLO JAVA
```

Here:

```text id="s84020"
trim() → removes extra spaces
toUpperCase() → converts to uppercase
```

---

## 18. Comparing After Modification

We can combine modification and comparison methods.

```java id="s84021"
public class Main {

    public static void main(String[] args) {
        String answer = " yes ";

        if (answer.trim().equalsIgnoreCase("yes")) {
            System.out.println("Accepted");
        } else {
            System.out.println("Rejected");
        }
    }
}
```

```output id="o84021"
Accepted
```

Here:

1. `trim()` removes the extra spaces.
2. `equalsIgnoreCase()` compares the result with `"yes"`.

## 19. Common Mistakes with String Comparison

### Mistake 1: Using `==`

Avoid:

```java id="s84022"
if (first == second)
```

For comparing String content, use:

```java id="s84023"
if (first.equals(second))
```

---

### Mistake 2: Forgetting Case Sensitivity

This:

```java id="s84024"
"Java".equals("java")
```

returns:

```text id="s84025"
false
```

If case should not matter, use:

```java id="s84026"
"Java".equalsIgnoreCase("java")
```

---

## 20. Common Mistakes with String Modification

### Mistake 1: Forgetting to Store the Result

This does not update `text`:

```java id="s84027"
text.toUpperCase();
```

Use:

```java id="s84028"
text = text.toUpperCase();
```

---

### Mistake 2: Expecting `trim()` to Remove All Spaces

`trim()` removes spaces from the beginning and end.

It does not remove spaces between words.

---

## 21. Quick Example

Let's combine String comparison and modification.

```java id="s84029"
public class Main {

    public static void main(String[] args) {
        String answer = "  java  ";

        answer = answer.trim();

        if (answer.equalsIgnoreCase("java")) {
            System.out.println("Correct answer");
        }

        System.out.println("Uppercase: " + answer.toUpperCase());
    }
}
```

```output id="o84029"
Correct answer
Uppercase: JAVA
```

The program:

1. Removes the extra spaces.
2. Compares the String without considering case.
3. Converts the String to uppercase.

---

## Key Points

* `equals()` compares String content.
* `equals()` is case-sensitive.
* `equalsIgnoreCase()` compares Strings without considering case.
* Avoid using `==` to compare String content.
* `toUpperCase()` converts letters to uppercase.
* `toLowerCase()` converts letters to lowercase.
* `trim()` removes leading and trailing spaces.
* `replace()` replaces characters or text.
* String methods return a new String.
* Store the returned String when you want to keep the modification.
* Multiple String methods can be combined.
* String methods can be chained together.
