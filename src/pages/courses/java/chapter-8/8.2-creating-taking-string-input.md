# Chapter 8: Strings

## Section 2: Creating and Taking String Input

In the previous topic, we learned what Strings are and how to perform some basic operations on them.

Now, we will learn how to:

* Create Strings
* Store Strings in variables
* Take String input from the user
* Take a single word as input
* Take a complete line as input
* Work with multiple String inputs

---

## 1. Creating a String

We can create a String by assigning text to a String variable.

```java id="s82001"
public class Main {

    public static void main(String[] args) {
        String name = "Owais";

        System.out.println(name);
    }
}
```

```output id="o82001"
Owais
```

Here:

```text id="s82002"
String
```

is the data type.

```text id="s82003"
name
```

is the variable name.

```text id="s82004"
"Owais"
```

is the String value.

---

## 2. Creating an Empty String

A String can also contain no characters.

```java id="s82005"
public class Main {

    public static void main(String[] args) {
        String message = "";

        System.out.println("Message: " + message);
    }
}
```

```output id="o82005"
Message: 
```

The String is empty because it contains no characters.

---

## 3. Creating Strings with Spaces

A String can contain spaces between words.

```java id="s82006"
public class Main {

    public static void main(String[] args) {
        String message = "Welcome to CODIFY";

        System.out.println(message);
    }
}
```

```output id="o82006"
Welcome to CODIFY
```

The entire sentence is stored in one String variable.

## 4. Taking String Input with `Scanner`

We can use the `Scanner` class to take input from the user.

First, import `Scanner`:

```java id="s82007"
import java.util.Scanner;
```

Then create a Scanner object:

```java id="s82008"
Scanner input = new Scanner(System.in);
```

Now we can use the Scanner to read input.

---

## 5. Taking a Single Word with `next()`

The `next()` method reads one word.

Example:

```java id="s82009"
import java.util.Scanner;

public class Main {

    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        String name = input.next();

        System.out.println("Name: " + name);
    }
}
```

Input:

```text id="i82009"
Owais
```

Output:

```output id="o82009"
Name: Owais
```

---

## 6. `next()` Reads Only One Word

Suppose the user enters:

```text id="i82010"
Owais Mohammed
```

and the program uses:

```java id="s82010"
String name = input.next();
```

The value stored in `name` is only:

```text id="s82011"
Owais
```

The `next()` method stops reading when it reaches whitespace.

So `next()` is useful when the input contains a **single word**.

---

## 7. Taking a Complete Line with `nextLine()`

If we want to read a complete line, including spaces, we can use `nextLine()`.

Example:

```java id="s82012"
import java.util.Scanner;

public class Main {

    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        String message = input.nextLine();

        System.out.println("Message: " + message);
    }
}
```

Input:

```text id="i82012"
Welcome to CODIFY
```

Output:

```output id="o82012"
Message: Welcome to CODIFY
```

Unlike `next()`, `nextLine()` reads the complete line.

---

## 8. `next()` vs `nextLine()`

The main difference is how much input they read.

| Method       | Reads         |
| ------------ | ------------- |
| `next()`     | One word      |
| `nextLine()` | Complete line |

Example input:

```text id="x82001"
Hello Java World
```

Using:

```java id="s82013"
input.next();
```

reads:

```text id="x82002"
Hello
```

Using:

```java id="s82014"
input.nextLine();
```

reads:

```text id="x82003"
Hello Java World
```

## 10. Taking Multiple String Inputs

We can take multiple String values using a loop.

For example, let's take three names:

```java id="s82016"
import java.util.Scanner;

public class Main {

    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        String[] names = new String[3];

        for (int i = 0; i < names.length; i++) {
            names[i] = input.next();
        }

        for (int i = 0; i < names.length; i++) {
            System.out.println(names[i]);
        }
    }
}
```

Input:

```text id="i82016"
Owais
Sara
Ali
```

Output:

```output id="o82016"
Owais
Sara
Ali
```

Each `next()` call reads one word.

---

## 11. Taking Multiple Lines of String Input

We can also use `nextLine()` inside a loop.

```java id="s82017"
import java.util.Scanner;

public class Main {

    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        String[] messages = new String[3];

        for (int i = 0; i < messages.length; i++) {
            messages[i] = input.nextLine();
        }

        for (int i = 0; i < messages.length; i++) {
            System.out.println(messages[i]);
        }
    }
}
```

Input:

```text id="i82017"
Hello Java
I am learning programming
Welcome to CODIFY
```

Output:

```output id="o82017"
Hello Java
I am learning programming
Welcome to CODIFY
```

Each `nextLine()` reads one complete line.

## 12. Taking a String and an Integer

We can take different types of input using the same `Scanner`.

For example:

```java id="s82018"
import java.util.Scanner;

public class Main {

    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        String name = input.next();
        int age = input.nextInt();

        System.out.println("Name: " + name);
        System.out.println("Age: " + age);
    }
}
```

Input:

```text id="i82018"
Owais 16
```

Output:

```output id="o82018"
Name: Owais
Age: 16
```

Here:

* `next()` reads the String.
* `nextInt()` reads the integer.

---

## 13. Taking an Integer Before a String

There is an important situation to understand when using `nextInt()` and `nextLine()` together.

Consider:

```java id="s82019"
import java.util.Scanner;

public class Main {

    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        int age = input.nextInt();
        String name = input.nextLine();

        System.out.println("Age: " + age);
        System.out.println("Name: " + name);
    }
}
```

Input:

```text id="i82019"
16
Owais
```

The output is:

```output id="o82019"
Age: 16
Name: 
```

Why?

`nextInt()` reads the integer but does not consume the end-of-line character.

Then `nextLine()` reads the remaining part of the current line, which is empty.

---

## 14. Fixing the `nextInt()` and `nextLine()` Issue

To move to the next line, call `nextLine()` once after `nextInt()`.

```java id="s82020"
import java.util.Scanner;

public class Main {

    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        int age = input.nextInt();
        input.nextLine();

        String name = input.nextLine();

        System.out.println("Age: " + age);
        System.out.println("Name: " + name);
    }
}
```

Input:

```text id="i82020"
16
Owais Mohammed
```

Output:

```output id="o82020"
Age: 16
Name: Owais Mohammed
```

The extra:

```java id="s82021"
input.nextLine();
```

consumes the remaining newline before reading the actual String.

## 18. Creating a String Without User Input

Strings do not always need to come from the user.

We can directly create them in the program.

```java id="s82025"
public class Main {

    public static void main(String[] args) {
        String language = "Java";

        System.out.println(language);
        System.out.println(course);
    }
}
```

```output id="o82025"
Java
CODIFY
```

This is useful when the text is already known.

## 19. Common Mistakes

### Mistake 1: Using `char` for a String

Incorrect:

```java id="s82026"
char name = "Owais";
```

A `char` can store only one character.

Correct:

```java id="s82027"
String name = "Owais";
```

---

### Mistake 2: Using Single Quotes for a String

Incorrect:

```java id="s82028"
String name = 'Owais';
```

Strings use double quotes.

Correct:

```java id="s82029"
String name = "Owais";
```

---

### Mistake 3: Using `next()` When Spaces Are Needed

If the input is:

```text id="i82025"
Owais Mohammed
```

and we use:

```java id="s82030"
String name = input.next();
```

only `Owais` is read.

Use:

```java id="s82031"
String name = input.nextLine();
```

when the complete line is required.

## 20. Quick Example

Let's take a user's name and print some information about it.

```java id="s82032"
import java.util.Scanner;

public class Main {

    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        String name = input.nextLine();

        System.out.println("Name: " + name);
        System.out.println("Length: " + name.length());
        System.out.println("Uppercase: " + name.toUpperCase());
    }
}
```

Input:

```text id="i82032"
Owais Mohammed
```

Output:

```output id="o82032"
Name: Owais Mohammed
Length: 14
Uppercase: OWAIS MOHAMMED
```

The program:

1. Takes the complete name as input.
2. Prints the name.
3. Finds its length.
4. Converts it to uppercase.

---

## Key Points

* A String can be created by assigning text to a `String` variable.
* Strings use double quotes `" "`.
* `Scanner` can be used to take String input.
* `next()` reads one word.
* `nextLine()` reads a complete line.
* `nextLine()` can read spaces between words.
* `nextInt()` reads an integer.
* When using `nextInt()` followed by `nextLine()`, an extra `nextLine()` may be needed to consume the remaining newline.
* String methods such as `length()`, `charAt()`, and `toUpperCase()` can be used on input.
* A String can also be stored in an array and read using a loop.
