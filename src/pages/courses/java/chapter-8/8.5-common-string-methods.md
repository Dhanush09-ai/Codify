# Chapter 8: Strings

## Section 5: Common String Methods

In the previous topics, we learned how to create Strings, take String input, access characters, combine Strings, compare Strings, and modify Strings.

Now, we will learn some common String methods that are useful when working with text in Java.

We will learn how to:

* Find the length of a String
* Access characters
* Extract part of a String
* Search inside a String
* Check how a String starts or ends
* Find the position of text
* Check whether a String is empty
* Join Strings using `concat()`
* Compare Strings using `compareTo()`
* Use multiple String methods together

## 1. What Are String Methods?

A String method is a built-in method that performs an operation on a String.

For example:

```java id="s85001"
String name = "Java";

System.out.println(name.length());
```

### Output:

```output id="o85001"
4
```

Here, `length()` tells us how many characters are present in the String.

---

## 2. The `length()` Method

The `length()` method returns the number of characters in a String.

### Example:

```java id="s85002"
public class Main {
    public static void main(String[] args) {
        String language = "Java";

        System.out.println(language.length());
    }
}
```

### Output:

```output id="o85002"
4
```

The String `"Java"` contains 4 characters.

---

## 3. The `charAt()` Method

The `charAt()` method returns the character at a specified index.

Remember that String indexing starts from `0`.

For example:

```text
J  a  v  a
0  1  2  3
```

### Example:

```java id="s85003"
public class Main {
    public static void main(String[] args) {
        String language = "Java";

        System.out.println(language.charAt(0));
        System.out.println(language.charAt(2));
    }
}
```

### Output:

```output id="o85003"
J
v
```

`charAt(0)` gives the first character, while `charAt(2)` gives the third character.

---

## 4. Using `charAt()` with `length()`

We can use `length()` to find the last character.

The last index is always:

```text
length - 1
```

### Example:

```java id="s85004"
public class Main {
    public static void main(String[] args) {
        String word = "Java";

        char last = word.charAt(word.length() - 1);

        System.out.println(last);
    }
}
```

### Output:

```output id="o85004"
a
```

This works because `"Java"` has a length of `4`, so its last index is `3`.

---

## 5. The `substring()` Method

The `substring()` method is used to extract a part of a String.

It can be used in two common ways:

```java
substring(start)
```

and

```java
substring(start, end)
```

The `end` index is not included.

### Example:

```java id="s85005"
public class Main {
    public static void main(String[] args) {
        String word = "Programming";

        System.out.println(word.substring(0, 7));
    }
}
```

### Output:

```output id="o85005"
Program
```

The characters from index `0` through `6` are selected.

---

## 6. Using `substring(start)`

When only the starting index is provided, `substring()` returns the String from that index to the end.

### Example:

```java id="s85006"
public class Main {
    public static void main(String[] args) {
        String word = "Programming";

        System.out.println(word.substring(7));
    }
}
```

### Output:

```output id="o85006"
ming
```

The character at index `7` is included.

---

## 7. The `contains()` Method

The `contains()` method checks whether a String contains a particular sequence of characters.

It returns either `true` or `false`.

### Example:

```java id="s85007"
public class Main {
    public static void main(String[] args) {
        String message = "Welcome to Java";

        System.out.println(message.contains("Java"));
        System.out.println(message.contains("Python"));
    }
}
```

### Output:

```output id="o85007"
true
false
```

`"Java"` is present in the String, but `"Python"` is not.

---

### Output:

## 9. The `endsWith()` Method

The `endsWith()` method checks whether a String ends with specific text.

## 10. The `indexOf()` Method

The `indexOf()` method finds the position of a character or text inside a String.

### Example:

```java id="s85010"
public class Main {
    public static void main(String[] args) {
        String word = "Programming";

        System.out.println(word.indexOf('g'));
        System.out.println(word.indexOf("gram"));
    }
}
```

### Output:

```output id="o85010"
3
3
```

The first `g` in `"Programming"` is at index `3`.

---

## 11. When `indexOf()` Cannot Find Something

If the specified character or text is not found, `indexOf()` returns `-1`.

### Example:

```java id="s85011"
public class Main {
    public static void main(String[] args) {
        String word = "Java";

        System.out.println(word.indexOf('z'));
    }
}
```

### Output:

```output id="o85011"
-1
```

This means that `'z'` does not exist in the String.

---

## 12. The `lastIndexOf()` Method

The `lastIndexOf()` method finds the position of the last occurrence of a character or text.

### Example:

```java id="s85012"
public class Main {
    public static void main(String[] args) {
        String word = "banana";

        System.out.println(word.indexOf('a'));
        System.out.println(word.lastIndexOf('a'));
    }
}
```

### Output:

```output id="o85012"
1
5
```

The first `a` is at index `1`, while the last `a` is at index `5`.

---

## 13. The `isEmpty()` Method

The `isEmpty()` method checks whether a String contains zero characters.

It returns `true` when the String length is `0`.

### Example:

```java id="s85013"
public class Main {
    public static void main(String[] args) {
        String first = "";
        String second = "Java";

        System.out.println(first.isEmpty());
        System.out.println(second.isEmpty());
    }
}
```

### Output:

```output id="o85013"
true
false
```

A String containing spaces is not empty because spaces are still characters.

---

## 14. The `concat()` Method

The `concat()` method joins another String to the end of the current String.

### Example:

```java id="s85014"
public class Main {
    public static void main(String[] args) {
        String first = "Hello ";
        String second = "Java";

        System.out.println(first.concat(second));
    }
}
```

### Output:

```output id="o85014"
Hello Java
```

The same result can usually be achieved more simply with the `+` operator.

---

## 15. Using `concat()` with Multiple Strings

We can call `concat()` more than once.

### Example:

```java id="s85015"
public class Main {
    public static void main(String[] args) {
        String result = "Hello ".concat("from ").concat("Java");

        System.out.println(result);
    }
}
```

### Output:

```output id="o85015"
Hello from Java
```

Each `concat()` adds the next String to the end.

---

## 16. The `compareTo()` Method

The `compareTo()` method compares two Strings lexicographically, meaning it compares them based on their character values.

It returns:

* `0` if both Strings are equal
* A negative value if the first String comes before the second
* A positive value if the first String comes after the second

### Example:

```java id="s85016"
public class Main {
    public static void main(String[] args) {
        String first = "Apple";
        String second = "Banana";

        System.out.println(first.compareTo(second));
        System.out.println(second.compareTo(first));
        System.out.println(first.compareTo("Apple"));
    }
}
```

### Output:

```output id="o85016"
-1
1
0
```

The exact negative or positive value can depend on the characters being compared, so focus mainly on whether the result is negative, positive, or zero.

---

## 17. Using String Methods Together

String methods can be combined to perform multiple operations.

### Example:

```java id="s85017"
public class Main {
    public static void main(String[] args) {
        String word = "Programming";

        System.out.println(word.substring(0, 7).toUpperCase());
    }
}
```

### Output:

```output id="o85017"
PROGRAM
```

First, `substring(0, 7)` extracts `"Program"`.

Then, `toUpperCase()` converts it to `"PROGRAM"`.

---

## 18. Searching Before Using an Index

It is useful to check whether text exists before using its position.

### Example:

```java id="s85018"
public class Main {
    public static void main(String[] args) {
        String language = "Java";

        if (language.indexOf("Java") != -1) {
            System.out.println("Java was found.");
        }
    }
}
```

### Output:

```output id="o85018"
Java was found.
```

Here, `indexOf()` returns `0`, so the condition is true.

## 20. Common Mistakes with String Methods

### Mistake 1: Using an invalid index

```java
String word = "Java";
System.out.println(word.charAt(4));
```

This causes an error because the valid indexes are `0` to `3`.

### Mistake 2: Forgetting that the end index is excluded

```java
String word = "Java";
System.out.println(word.substring(0, 3));
```

The output is:

```output
Jav
```

Index `3` is not included.

### Mistake 3: Assuming `indexOf()` always finds the text

If the text does not exist, `indexOf()` returns `-1`.

### Mistake 4: Confusing an empty String with a String containing spaces

```java
String a = "";
String b = " ";
```

`a.isEmpty()` is `true`, but `b.isEmpty()` is `false`.

## 21. Quick Example

Let's use several String methods together.

```java id="s85019"
public class Main {
    public static void main(String[] args) {
        String word = "Java Programming";

        System.out.println("Length: " + word.length());
        System.out.println("First character: " + word.charAt(0));
        System.out.println("Contains Java: " + word.contains("Java"));
        System.out.println("Starts with Java: " + word.startsWith("Java"));
        System.out.println("Ends with ing: " + word.endsWith("ing"));
    }
}
```

### Output:

```output id="o85019"
Length: 16
First character: J
Contains Java: true
Starts with Java: true
Ends with ing: true
```

This example shows how several common String methods can be used together.

## Key Points

* `length()` returns the number of characters in a String.
* `charAt()` returns a character at a specified index.
* String indexes start from `0`.
* `substring()` extracts part of a String.
* The ending index of `substring(start, end)` is not included.
* `contains()` checks whether specific text exists.
* `startsWith()` checks the beginning of a String.
* `endsWith()` checks the end of a String.
* `indexOf()` finds the first occurrence of a character or text.
* `lastIndexOf()` finds the last occurrence.
* `indexOf()` returns `-1` when the text is not found.
* `isEmpty()` checks whether the String has zero characters.
* `concat()` joins Strings together.
* `compareTo()` compares Strings lexicographically.
* String methods can be combined to perform multiple operations.
