## 1. Finding the Length of a String

The `length()` method returns the number of characters in a String.

Example:

```java id="s83001"
public class Main {

    public static void main(String[] args) {
        String word = "Java";

        System.out.println(word.length());
    }
}
```

```output id="o83001"
4
```

The String `"Java"` contains four characters:

```text id="s83002"
J  a  v  a
```

Therefore:

```text id="s83003"
word.length() → 4
```

---

## 2. Spaces Are Also Counted

Spaces inside a String are also counted as characters.

```java id="s83004"
public class Main {

    public static void main(String[] args) {
        String message = "Hello Java";

        System.out.println(message.length());
    }
}
```

```output id="o83004"
10
```

The String contains:

```text id="s83005"
Hello → 5 characters
space → 1 character
Java  → 4 characters
```

So:

```text id="s83006"
5 + 1 + 4 = 10
```

---

## 3. Finding the Length of User Input

Input:


Output:


## 4. Accessing a Character

We can access an individual character using the `charAt()` method.

The syntax is:

```java id="s83008"
string.charAt(index)
```

Example:

```java id="s83009"
public class Main {

    public static void main(String[] args) {
        String word = "Java";

        System.out.println(word.charAt(0));
        System.out.println(word.charAt(1));
        System.out.println(word.charAt(2));
        System.out.println(word.charAt(3));
    }
}
```

```output id="o83009"
J
a
v
a
```

---

## 5. String Indexes Start from 0

Like arrays, String indexes start from `0`.

For:

```text id="s83010"
"Java"
```

the indexes are:

| Character | Index |
| --------- | ----: |
| `J`       |     0 |
| `a`       |     1 |
| `v`       |     2 |
| `a`       |     3 |

So:

```text id="s83011"
word.charAt(0) → J
word.charAt(1) → a
word.charAt(2) → v
word.charAt(3) → a
```

---

## 6. Accessing the First Character

The first character is always at index `0`.

```java id="s83012"
public class Main {

    public static void main(String[] args) {
        String word = "CODIFY";

        System.out.println("First character = " + word.charAt(0));
    }
}
```

```output id="o83012"
First character = C
```

---

## 7. Accessing the Last Character

The last character is at:

```text id="s83013"
length() - 1
```

Example:

```java id="s83014"
public class Main {

    public static void main(String[] args) {
        String word = "CODIFY";

        char last = word.charAt(word.length() - 1);

        System.out.println("Last character = " + last);
    }
}
```

```output id="o83014"
Last character = Y
```

For `"CODIFY"`:

```text id="s83015"
length = 6
last index = 6 - 1 = 5
```

So:

```text id="s83016"
word.charAt(5) → Y
```

## 8. Traversing a String

We can use a `for` loop to visit every character.

```java id="s83017"
public class Main {

    public static void main(String[] args) {
        String word = "Java";

        for (int i = 0; i < word.length(); i++) {
            System.out.println(word.charAt(i));
        }
    }
}
```

```output id="o83017"
J
a
v
a
```

The loop starts at index `0` and continues until the last index.

---

## 9. Printing Characters on One Line

We can use `System.out.print()` to print characters on the same line.

```java id="s83018"
public class Main {

    public static void main(String[] args) {
        String word = "Java";

        for (int i = 0; i < word.length(); i++) {
            System.out.print(word.charAt(i) + " ");
        }
    }
}
```

```output id="o83018"
J a v a 
```

## 10. Joining Two Strings

Joining Strings together is called **concatenation**.

We can use the `+` operator to concatenate Strings.

```java id="s83019"
public class Main {

    public static void main(String[] args) {
        String firstName = "Owais";
        String lastName = "Mohammed";

        String fullName = firstName + " " + lastName;

        System.out.println(fullName);
    }
}
```

```output id="o83019"
Owais Mohammed
```

Here:

```text id="s83020"
firstName + " " + lastName
```

creates:

```text id="s83021"
Owais Mohammed
```

The `" "` adds a space between the two names.

---

## 11. Concatenating Without a Space

If we do not add a space, the Strings are joined directly.

```java id="s83022"
public class Main {

    public static void main(String[] args) {
        String first = "Hello";
        String second = "Java";

        System.out.println(first + second);
    }
}
```

```output id="o83022"
HelloJava
```

To get a space, write:

```java id="s83023"
first + " " + second
```

---

## 12. Concatenating Multiple Strings

We can join more than two Strings.

```java id="s83024"
public class Main {

    public static void main(String[] args) {
        String first = "Learn";
        String second = "Java";
        String third = "with";
        String fourth = "CODIFY";

        String message = first + " " + second + " " + third + " " + fourth;

        System.out.println(message);
    }
}
```

```output id="o83024"
Learn Java with CODIFY
```

The `+` operator joins the Strings from left to right.

---

## 13. Concatenating a String and a Number

A String can also be joined with a number.

```java id="s83025"
public class Main {

    public static void main(String[] args) {
        String name = "Owais";
        int age = 16;

        System.out.println("Name: " + name);
        System.out.println("Age: " + age);
    }
}
```

```output id="o83025"
Name: Owais
Age: 16
```

Java converts the number to text as part of the concatenation.

## 15. Concatenation with Arithmetic

The order of operations is important when using `+` with Strings and numbers.

Example:

```java id="s83027"
public class Main {

    public static void main(String[] args) {
        System.out.println("Sum = " + 10 + 20);
        System.out.println("Sum = " + (10 + 20));
    }
}
```

```output id="o83027"
Sum = 1020
Sum = 30
```

In:

```text id="s83028"
"Sum = " + 10 + 20
```

the String appears first, so the numbers are joined as text.

In:

```text id="s83029"
"Sum = " + (10 + 20)
```

the parentheses make Java calculate `10 + 20` first.

## 18. Comparing String Lengths

We can use `length()` to compare the lengths of two Strings.

```java id="s83032"
public class Main {

    public static void main(String[] args) {
        String first = "Java";
        String second = "Programming";

        if (first.length() > second.length()) {
            System.out.println("First string is longer");
        } else if (first.length() < second.length()) {
            System.out.println("Second string is longer");
        } else {
            System.out.println("Both strings have the same length");
        }
    }
}
```

```output id="o83032"
Second string is longer
```

## 19. Common Mistakes with `charAt()`

### Mistake 1: Using an Invalid Index

For:

```java id="s83033"
String word = "Java";
```

the valid indexes are:

```text id="s83034"
0, 1, 2, 3
```

This is invalid:

```java id="s83035"
word.charAt(4);
```

because index `4` does not exist.

Java will throw a `StringIndexOutOfBoundsException`.

---

### Mistake 2: Using `length` Instead of `length()`

For Strings, use:

```java id="s83036"
word.length()
```

not:

```java id="s83037"
word.length
```

`length()` is a String method.

---

## 20. Common Mistakes with Concatenation

### Forgetting Spaces

This:

```java id="s83038"
String fullName = firstName + lastName;
```

can produce:

```text id="s83039"
OwaisMohammed
```

If a space is required, use:

```java id="s83040"
String fullName = firstName + " " + lastName;
```

which produces:

```text id="s83041"
Owais Mohammed
```

## 21. Quick Example

Let's combine length, character access, and concatenation.

```java id="s83042"
public class Main {

    public static void main(String[] args) {
        String first = "Java";
        String second = "Programming";

        String message = first + " " + second;

        System.out.println("Message: " + message);
        System.out.println("Length: " + message.length());
        System.out.println("First character: " + message.charAt(0));
        System.out.println("Last character: " + message.charAt(message.length() - 1));
    }
}
```

```output id="o83042"
Message: Java Programming
Length: 16
First character: J
Last character: g
```

The program:

1. Creates two Strings.
2. Combines them with a space.
3. Finds the length of the combined String.
4. Gets the first character.
5. Gets the last character.

## Key Points

* `length()` returns the number of characters in a String.
* Spaces are also counted by `length()`.
* String indexes start from `0`.
* `charAt(index)` returns the character at a particular index.
* The last character is at `length() - 1`.
* A `for` loop can be used to traverse a String.
* String concatenation means joining Strings together.
* The `+` operator is commonly used for concatenation.
* A space can be added using `" "`.
* Strings can be concatenated with numbers and other data types.
* Parentheses can be used when arithmetic should happen before concatenation.
* Using an invalid index with `charAt()` causes an exception.
