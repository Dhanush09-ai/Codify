# Chapter 7: Arrays

## Section 4: Basic Array Operations

In the previous topic, we learned how to traverse an array and take input from the user.

Now, we will learn some **basic operations that can be performed on arrays**.

These operations help us work with array data in useful ways.

We will learn:

* Accessing elements
* Updating elements
* Finding the sum
* Finding the average
* Finding the largest element
* Finding the smallest element
* Searching for an element
* Counting elements based on a condition

---

## 1. Accessing an Array Element

We can access an element using its index.

For example:

```java id="ar74001"
public class Main {

    public static void main(String[] args) {
        int[] numbers = {10, 20, 30, 40, 50};

        System.out.println(numbers[0]);
        System.out.println(numbers[2]);
        System.out.println(numbers[4]);
    }
}
```

```output id="out74001"
10
30
50
```

Remember that array indexes start from `0`.

So:

```text
numbers[0] → 10
numbers[1] → 20
numbers[2] → 30
numbers[3] → 40
numbers[4] → 50
```

---

## 2. Updating an Array Element

We can change an element by assigning a new value to its index.

```java id="ar74002"
public class Main {

    public static void main(String[] args) {
        int[] numbers = {10, 20, 30, 40, 50};

        numbers[2] = 100;

        System.out.println(numbers[2]);
    }
}
```

```output id="out74002"
100
```

Originally:

```text
numbers[2] = 30
```

After updating:

```text
numbers[2] = 100
```

Only that element is changed.

---

## 3. Printing the Updated Array

We can use a loop to see all the elements after an update.

```java id="ar74003"
public class Main {

    public static void main(String[] args) {
        int[] numbers = {10, 20, 30, 40, 50};

        numbers[2] = 100;

        for (int i = 0; i < numbers.length; i++) {
            System.out.print(numbers[i] + " ");
        }
    }
}
```

```output id="out74003"
10 20 100 40 50 
```

## 4. Finding the Sum of Array Elements

We can calculate the sum of all elements using a loop.

```java id="ar74004"
public class Main {

    public static void main(String[] args) {
        int[] numbers = {10, 20, 30, 40, 50};

        int sum = 0;

        for (int i = 0; i < numbers.length; i++) {
            sum += numbers[i];
        }

        System.out.println("Sum = " + sum);
    }
}
```

```output id="out74004"
Sum = 150
```

The calculation is:

```text
10 + 20 + 30 + 40 + 50 = 150
```

---

## 5. Finding the Average

The average can be calculated using:

```text
Average = Sum / Number of elements
```

Example:

```java id="ar74005"
public class Main {

    public static void main(String[] args) {
        int[] numbers = {10, 20, 30, 40, 50};

        int sum = 0;

        for (int i = 0; i < numbers.length; i++) {
            sum += numbers[i];
        }

        double average = (double) sum / numbers.length;

        System.out.println("Average = " + average);
    }
}
```

```output id="out74005"
Average = 30.0
```

We use `(double)` so that the division can produce a decimal result when necessary.

## 6. Finding the Largest Element

We can find the largest element by comparing each element with the current largest value.

```java id="ar74006"
public class Main {

    public static void main(String[] args) {
        int[] numbers = {25, 10, 45, 30, 15};

        int largest = numbers[0];

        for (int i = 1; i < numbers.length; i++) {
            if (numbers[i] > largest) {
                largest = numbers[i];
            }
        }

        System.out.println("Largest = " + largest);
    }
}
```

```output id="out74006"
Largest = 45
```

The first element is initially considered the largest.

Then the remaining elements are checked one by one.

## 8. Searching for an Element

We can search for a particular value by checking every element.

This is called a **linear search**.

Example:

```java id="ar74008"
public class Main {

    public static void main(String[] args) {
        int[] numbers = {10, 20, 30, 40, 50};

        int search = 30;
        boolean found = false;

        for (int i = 0; i < numbers.length; i++) {
            if (numbers[i] == search) {
                found = true;
                break;
            }
        }

        if (found) {
            System.out.println("Element found");
        } else {
            System.out.println("Element not found");
        }
    }
}
```

```output id="out74008"
Element found
```

The program checks:

```text
10 → 20 → 30
```

When it finds `30`, the search stops because of `break`.

---

## 9. Finding the Index of an Element

Instead of only checking whether an element exists, we can find its index.

```java id="ar74009"
public class Main {

    public static void main(String[] args) {
        int[] numbers = {10, 20, 30, 40, 50};

        int search = 40;
        int index = -1;

        for (int i = 0; i < numbers.length; i++) {
            if (numbers[i] == search) {
                index = i;
                break;
            }
        }

        System.out.println("Index = " + index);
    }
}
```

```output id="out74009"
Index = 3
```

Here:

```text
numbers[3] = 40
```

We use `-1` to indicate that the element has not been found.

## 11. Counting Even Numbers

We can count elements that satisfy a condition.

For example, let's count the even numbers.

```java id="ar74011"
public class Main {

    public static void main(String[] args) {
        int[] numbers = {10, 15, 20, 25, 30};

        int count = 0;

        for (int i = 0; i < numbers.length; i++) {
            if (numbers[i] % 2 == 0) {
                count++;
            }
        }

        System.out.println("Even numbers = " + count);
    }
}
```

```output id="out74011"
Even numbers = 3
```

The even numbers are:

```text
10, 20, 30
```

So the count is `3`.

---

## 13. Replacing All Negative Numbers

We can also update multiple elements while traversing the array.

For example, replace negative numbers with `0`.

```java id="ar74013"
public class Main {

    public static void main(String[] args) {
        int[] numbers = {10, -5, 20, -3, 30};

        for (int i = 0; i < numbers.length; i++) {
            if (numbers[i] < 0) {
                numbers[i] = 0;
            }
        }

        for (int i = 0; i < numbers.length; i++) {
            System.out.print(numbers[i] + " ");
        }
    }
}
```

```output id="out74013"
10 0 20 0 30 
```

The loop checks every element and changes only the negative values.

## 14. Copying an Array

We can copy elements from one array to another using a loop.

```java id="ar74014"
public class Main {

    public static void main(String[] args) {
        int[] numbers = {10, 20, 30, 40, 50};
        int[] copy = new int[numbers.length];

        for (int i = 0; i < numbers.length; i++) {
            copy[i] = numbers[i];
        }

        for (int i = 0; i < copy.length; i++) {
            System.out.print(copy[i] + " ");
        }
    }
}
```

```output id="out74014"
10 20 30 40 50 
```

The second array receives each value from the first array.

## 15. Reversing an Array

We can create a new array containing the elements in reverse order.

```java id="ar74015"
public class Main {

    public static void main(String[] args) {
        int[] numbers = {10, 20, 30, 40, 50};
        int[] reverse = new int[numbers.length];

        for (int i = 0; i < numbers.length; i++) {
            reverse[i] = numbers[numbers.length - 1 - i];
        }

        for (int i = 0; i < reverse.length; i++) {
            System.out.print(reverse[i] + " ");
        }
    }
}
```

```output id="out74015"
50 40 30 20 10 
```

For example:

```text
numbers[0] → reverse[4]
numbers[1] → reverse[3]
numbers[2] → reverse[2]
```

The original array is not changed.

## 16. Comparing Two Arrays Element by Element

We can compare corresponding elements of two arrays.

```java id="ar74016"
public class Main {

    public static void main(String[] args) {
        int[] a = {10, 20, 30};
        int[] b = {10, 20, 30};

        boolean same = true;

        for (int i = 0; i < a.length; i++) {
            if (a[i] != b[i]) {
                same = false;
                break;
            }
        }

        if (same) {
            System.out.println("Arrays are equal");
        } else {
            System.out.println("Arrays are not equal");
        }
    }
}
```

```output id="out74016"
Arrays are equal
```

This compares the values at the same indexes.

## 17. Important Array Operations

Here are some common operations we can perform on arrays:

| Operation | Purpose                                   |
| --------- | ----------------------------------------- |
| Access    | Read an element                           |
| Update    | Change an element                         |
| Sum       | Add all elements                          |
| Average   | Find the average value                    |
| Maximum   | Find the largest element                  |
| Minimum   | Find the smallest element                 |
| Search    | Find a particular element                 |
| Count     | Count elements satisfying a condition     |
| Copy      | Create another array with the same values |
| Reverse   | Arrange elements in reverse order         |

---

## 18. Array Operations Use Traversal

Many array operations use a loop to visit the elements.

For example:

```text
Array
  ↓
Visit each element
  ↓
Check or process the element
  ↓
Continue until the end
```

This is why understanding array traversal is important before learning more advanced array operations.

---

## 19. Quick Example

Let's combine searching and counting in one program.

```java id="ar74017"
public class Main {

    public static void main(String[] args) {
        int[] numbers = {10, 20, 10, 30, 10};

        int search = 10;
        int count = 0;

        for (int i = 0; i < numbers.length; i++) {
            if (numbers[i] == search) {
                count++;
            }
        }

        System.out.println("Occurrences = " + count);
    }
}
```

```output id="out74017"
Occurrences = 3
```

The value `10` appears three times in the array.

## Key Points

* Array elements are accessed using their indexes.
* Array indexes start from `0`.
* Existing elements can be updated using their indexes.
* A loop can be used to process every element.
* The sum can be calculated by adding all elements.
* The average is calculated using the sum and number of elements.
* The largest and smallest elements can be found by comparing values.
* Linear search checks elements one by one.
* `-1` can be used to indicate that an element was not found.
* We can count elements that satisfy a condition.
* Array elements can be copied or reversed using loops.
* Many basic array operations are based on array traversal.
