# Chapter 7: Arrays

## Section 2: Creating, Initializing and Accessing Arrays

In the previous topic, we learned what arrays are, why they are useful, and how array indexes work.

Now let's learn how to **create, initialize, and access arrays** in Java.

---

## 1. Creating an Array

There are different ways to create an array in Java.

One common way is to specify the data type and size:

```java id="a72001"
int[] numbers = new int[5];
```

Here:

* `int` → type of values
* `[]` → indicates an array
* `numbers` → array name
* `new int[5]` → creates an array with 5 elements

The indexes will be:

```text id="x72001"
Index:    0   1   2   3   4
Value:    0   0   0   0   0
```

For an `int` array, the elements are initially `0`.

---

## 2. Initializing an Array

**Initializing an array** means giving values to its elements.

We can assign values using indexes:

```java id="a72002"
public class Main {

    public static void main(String[] args) {
        int[] numbers = new int[3];

        numbers[0] = 10;
        numbers[1] = 20;
        numbers[2] = 30;

        System.out.println(numbers[0]);
        System.out.println(numbers[1]);
        System.out.println(numbers[2]);
    }
}
```

```output id="o72002"
10
20
30
```

The array now contains:

```text id="x72002"
Index:    0   1   2
Value:   10  20  30
```

---

## 3. Creating and Initializing an Array at the Same Time

We can create an array and provide its values in one statement.

```java id="a72003"
int[] numbers = {10, 20, 30, 40, 50};
```

Java automatically determines the size from the number of values.

Here, the array contains 5 elements.

```java id="a72004"
System.out.println(numbers.length);
```

```output id="o72004"
5
```

---

## 4. Array Initialization Using `new`

We can also use `new` while providing the values:

```java id="a72005"

```

This creates an array containing four integers.

The indexes are:

```text id="x72005"
Index:    0   1   2   3

```

## 5. Creating Arrays of Different Data Types

Arrays can store different types of values.

### Integer Array

```java id="a72006"
int[] numbers = {10, 20, 30};
```

### Double Array

```java id="a72007"

```

### String Array

```java id="a72008"

```

```java id="a72009"

```

The type of the array determines the type of values it can store.

## 6. Accessing an Array Element

To access an element, use its index.

Example:

```java id="a72010"
public class Main {

    public static void main(String[] args) {
        int[] numbers = {10, 20, 30, 40, 50};

        System.out.println(numbers[0]);
        System.out.println(numbers[3]);
    }
}
```

```output id="o72010"
10
40
```

Here:

```text id="x72010"
numbers[0] → 10
numbers[3] → 40
```

---

## 7. Accessing the First Element

The first element is always at index `0`.

```java id="a72011"
int[] marks = {85, 90, 75, 95};

System.out.println(marks[0]);
```

```output id="o72011"
85
```

Remember:

> **First element → index 0**

---

## 8. Accessing the Last Element

The last index is:

```text id="x72012"
length - 1
```

For example:

```java id="a72012"
public class Main {

    public static void main(String[] args) {
        int[] numbers = {10, 20, 30, 40, 50};

        System.out.println(numbers[numbers.length - 1]);
    }
}
```

```output id="o72012"
50
```

Here:

```text id="x72013"
numbers.length = 5
5 - 1 = 4
```

So:

```text id="x72014"
numbers[4] → 50
```

---

## 9. Accessing All Elements Using a Loop

Instead of accessing every element separately, we can use a `for` loop.

```java id="a72013"
public class Main {

    public static void main(String[] args) {
        int[] numbers = {10, 20, 30, 40, 50};

        for (int i = 0; i < numbers.length; i++) {
            System.out.println(numbers[i]);
        }
    }
}
```

```output id="o72013"
10
20
30
40
50
```

The variable `i` represents the current index.

---


```output id="o72014"

```

Originally:

```text id="x72015"

```

After:

```java id="a72015"
numbers[1] = 100;
```

The array becomes:

```text id="x72016"

```

## 11. Initializing an Array Using a Loop

When an array has many elements, we can initialize its values using a loop.

```java id="a72016"
public class Main {

    public static void main(String[] args) {
        int[] numbers = new int[5];

        for (int i = 0; i < numbers.length; i++) {
            numbers[i] = (i + 1) * 10;
        }

        for (int i = 0; i < numbers.length; i++) {
            System.out.println(numbers[i]);
        }
    }
}
```

```output id="o72016"
10
20
30
40
50
```

The first loop assigns values:

```text id="x72017"
numbers[0] = 10
numbers[1] = 20
numbers[2] = 30
numbers[3] = 40
numbers[4] = 50
```

The second loop prints them.

## 14. Array Length

The `length` property tells us how many elements an array contains.

```java id="a72019"
public class Main {

    public static void main(String[] args) {
        String[] names = {"Owais", "Sara", "Ali", "Ahmed"};

        System.out.println(names.length);
    }
}
```

```output id="o72019"
4
```

Remember:

```java id="x72021"
names.length
```

not:

```java id="x72022"
names.length()
```

For arrays, `length` is a **property**, not a method.


```output id="o72020"

```

Here:

```text id="x72023"
index = 2
```

Therefore:

```text id="x72024"
numbers[index]
= numbers[2]
= 30
```

## 16. Invalid Array Index

An array with 4 elements has indexes:

```text id="x72025"
0, 1, 2, 3
```

Trying to access index `4` is invalid.

For example:

```java id="a72021"
int[] numbers = {10, 20, 30, 40};

System.out.println(numbers[4]);
```

This causes:

```text id="x72026"
ArrayIndexOutOfBoundsException
```

The index must always be within the valid range.

---

## 17. Valid Index Range

If an array has `n` elements:

```text id="x72027"
First index = 0
Last index = n - 1
```

For example, if:

```java id="x72028"
int[] numbers = new int[5];
```

then:

```text id="x72029"
Valid indexes: 0, 1, 2, 3, 4
```

Index `5` is invalid.

## 18. Creating an Array with User Input

Arrays can also be filled using values entered by the user.

For example:

```java id="a72022"
import java.util.Scanner;

public class Main {

    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        int[] numbers = new int[3];

        for (int i = 0; i < numbers.length; i++) {
            numbers[i] = input.nextInt();
        }

        for (int i = 0; i < numbers.length; i++) {
            System.out.println(numbers[i]);
        }
    }
}
```

For the input:

```text id="i72022"
10
20
30
```

the output is:

```output id="o72022"
10
20
30
```

The first loop stores the input values in the array.

The second loop displays them.

## 19. Two Main Ways to Initialize Arrays

### Method 1: Direct Initialization

Use this when the values are already known:

```java id="a72023"
int[] numbers = {10, 20, 30, 40};
```

### Method 2: Create First, Assign Later

Use this when values will be provided later:

```java id="a72024"
int[] numbers = new int[4];

numbers[0] = 10;
numbers[1] = 20;
numbers[2] = 30;
numbers[3] = 40;
```

Both create an array containing four integers.

---

## 20. Quick Example

Let's combine creating, initializing, accessing, and changing an array:

```java id="a72025"
public class Main {

    public static void main(String[] args) {
        int[] marks = {80, 85, 90, 75, 95};

        marks[2] = 92;

        System.out.println("First mark: " + marks[0]);
        System.out.println("Updated third mark: " + marks[2]);
        System.out.println("Last mark: " + marks[marks.length - 1]);
        System.out.println("Number of marks: " + marks.length);
    }
}
```

```output id="o72025"
First mark: 80
Updated third mark: 92
Last mark: 95
Number of marks: 5
```

---

## Key Points

* An array can be created using `new` and a fixed size.
* An array can also be created and initialized with values at the same time.
* Array elements are accessed using indexes.
* Array indexes start from `0`.
* The last index is `length - 1`.
* Array elements can be changed using their indexes.
* The `length` property gives the number of elements.
* Arrays can store types such as `int`, `double`, `String`, and `char`.
* A `for` loop can be used to access all array elements.
* A `for` loop can also be used to initialize an array.
* Accessing an invalid index causes an `ArrayIndexOutOfBoundsException`.
* Once an array is created, its size is fixed.
