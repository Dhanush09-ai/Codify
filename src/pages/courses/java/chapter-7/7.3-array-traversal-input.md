# Chapter 7: Arrays

## Section 3: Array Traversal and Input

In the previous topics, we learned how to create, initialize, and access arrays.

When an array contains many elements, accessing each element one by one can be difficult.

Instead, we can use a **loop to visit each element**.

This process is called **array traversal**.

We will also learn how to take array values as input from the user.

---

## 1. What is Array Traversal?

**Array traversal** means visiting each element of an array one by one.

For example:

```java id="a73001"
int[] numbers = {10, 20, 30, 40, 50};
```

We can traverse the array like this:

```text id="x73001"
10 → 20 → 30 → 40 → 50
```

A loop is commonly used for array traversal.

---

## 2. Traversing an Array Using `for`

The `for` loop is one of the most common ways to traverse an array.

```java id="a73002"
public class Main {

    public static void main(String[] args) {
        int[] numbers = {10, 20, 30, 40, 50};

        for (int i = 0; i < numbers.length; i++) {
            System.out.println(numbers[i]);
        }
    }
}
```

```output id="o73002"
10
20
30
40
50
```

Here:

* `i = 0` starts at the first index.
* `i < numbers.length` keeps the loop inside the valid indexes.
* `numbers[i]` accesses the current element.
* `i++` moves to the next index.

---

## 3. Understanding the Traversal

Consider:

```java id="a73003"
int[] numbers = {10, 20, 30};
```

The loop:

```java id="a73004"
for (int i = 0; i < numbers.length; i++) {
    System.out.println(numbers[i]);
}
```

works like this:

```text id="x73003"
i = 0 → numbers[0] → 10
i = 1 → numbers[1] → 20
i = 2 → numbers[2] → 30
```

When `i` becomes `3`:

```text id="x73004"
3 < 3
```

is false, so the loop stops.

## 4. Traversing and Printing on One Line

We can print array elements on the same line.

```java id="a73005"
public class Main {

    public static void main(String[] args) {
        int[] numbers = {10, 20, 30, 40, 50};

        for (int i = 0; i < numbers.length; i++) {
            System.out.print(numbers[i] + " ");
        }
    }
}
```

```output id="o73005"
10 20 30 40 50 
```

`System.out.print()` does not move to a new line after printing.

---

## 5. Traversing an Array in Reverse

We can also traverse an array from the last element to the first.

```java id="a73006"
public class Main {

    public static void main(String[] args) {
        int[] numbers = {10, 20, 30, 40, 50};

        for (int i = numbers.length - 1; i >= 0; i--) {
            System.out.println(numbers[i]);
        }
    }
}
```

```output id="o73006"
50
40
30
20
10
```

The loop starts at:

```text id="x73005"
numbers.length - 1
```

which is the last valid index.

## 6. Traversing Using the Enhanced `for` Loop

Java also provides a simpler form of loop for traversing arrays called the **enhanced `for` loop**.

Example:

```java id="a73007"
public class Main {

    public static void main(String[] args) {
        int[] numbers = {10, 20, 30, 40, 50};

        for (int number : numbers) {
            System.out.println(number);
        }
    }
}
```

```output id="o73007"
10
20
30
40
50
```

Here:

```java id="8xk3t2"
int number
```

receives each element one by one.

The loop automatically moves through the array.

---

## 7. `for` Loop vs Enhanced `for` Loop

Both loops can traverse an array.

### Normal `for` Loop

```java id="a73008"
for (int i = 0; i < numbers.length; i++) {
    System.out.println(numbers[i]);
}
```

It gives us access to the **index**.

### Enhanced `for` Loop

```java id="a73009"
for (int number : numbers) {
    System.out.println(number);
}
```

It directly gives us the **element value**.

| `for` Loop                  | Enhanced `for` Loop               |
| --------------------------- | --------------------------------- |
| Gives index and value       | Directly gives value              |
| Useful when index is needed | Useful for simple traversal       |
| Uses `numbers[i]`           | Uses the current element directly |

## 12. Traversing and Calculating the Sum

Traversal is useful for calculations.

For example, we can find the sum of all elements.

```java id="a73015"
public class Main {

    public static void main(String[] args) {
        int[] numbers = {10, 20, 30, 40, 50};

        int sum = 0;

        for (int i = 0; i < numbers.length; i++) {
            sum = sum + numbers[i];
        }

        System.out.println("Sum = " + sum);
    }
}
```

```output id="o73015"
Sum = 150
```

The loop processes every element:

```text id="x73007"
10 + 20 + 30 + 40 + 50 = 150
```

## 13. Finding the Largest Element

We can also use traversal to find the largest value.

```java id="a73016"
public class Main {

    public static void main(String[] args) {
        int[] numbers = {25, 10, 45, 30, 15};

        int largest = numbers[0];

        for (int i = 1; i < numbers.length; i++) {
            if (numbers[i] > largest) {
                largest = numbers[i];
            }
        }

        System.out.println("Largest = " + largest);
    }
}
```

```output id="o73016"
Largest = 45
```

The array is checked element by element.

## 15. Counting Elements Based on a Condition

Traversal can also be used to count elements.

For example, count even numbers:

```java id="a73018"
public class Main {

    public static void main(String[] args) {
        int[] numbers = {10, 15, 20, 25, 30};

        int count = 0;

        for (int i = 0; i < numbers.length; i++) {
            if (numbers[i] % 2 == 0) {
                count++;
            }
        }

        System.out.println("Even numbers = " + count);
    }
}
```

```output id="o73018"
Even numbers = 3
```

The even numbers are:

```text id="x73008"
10, 20, 30
```

So the count is `3`.

## 17. Common Mistakes

### Mistake 1: Using `<=` Instead of `<`

Incorrect:

```java id="a73020"
for (int i = 0; i <= numbers.length; i++) {
    System.out.println(numbers[i]);
}
```

The last valid index is:

```text id="x73009"
numbers.length - 1
```

So the correct condition is:

```java id="a73021"
for (int i = 0; i < numbers.length; i++) {
    System.out.println(numbers[i]);
}
```

---

### Mistake 2: Starting at Index 1

Incorrect:

```java id="a73022"
for (int i = 1; i < numbers.length; i++) {
    System.out.println(numbers[i]);
}
```

This skips the first element.

For normal forward traversal, start at:

```text id="x73010"
i = 0
```

---

### Mistake 3: Using the Wrong Array Length

Always use:

```java id="a73023"
numbers.length
```

instead of manually writing a number.

For example:

```java id="a73024"
for (int i = 0; i < numbers.length; i++) {
    System.out.println(numbers[i]);
}
```

This works correctly even if the array size changes.

## 18. Quick Example

Let's combine input, traversal, and calculation:

```java id="a73025"
import java.util.Scanner;

public class Main {

    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        int[] numbers = new int[5];

        for (int i = 0; i < numbers.length; i++) {
            numbers[i] = input.nextInt();
        }

        int sum = 0;

        for (int i = 0; i < numbers.length; i++) {
            sum += numbers[i];
        }

        System.out.println("Sum = " + sum);
    }
}
```

Input:

```text id="i73025"
10 20 30 40 50
```

Output:

```output id="o73025"
Sum = 150
```

The program:

1. Creates an array of 5 integers.
2. Takes 5 values as input.
3. Traverses the array.
4. Adds all the values.
5. Prints the sum.

---

## Key Points

* **Array traversal** means visiting array elements one by one.
* A `for` loop is commonly used for array traversal.
* `numbers[i]` accesses the element at index `i`.
* `numbers.length` gives the number of elements.
* The enhanced `for` loop can directly access each element.
* A reverse loop can traverse an array from the last element to the first.
* `Scanner` can be used to take array input.
* A loop can be used to fill an array with user input.
* Traversal can be used for calculations such as sum, largest, smallest, and counting.
* The normal traversal condition is usually `i < array.length`.
* Starting from `0` ensures that the first element is included.
* Using `<= array.length` can cause an invalid index error.
