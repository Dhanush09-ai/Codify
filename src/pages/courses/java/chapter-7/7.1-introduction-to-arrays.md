# Chapter 7: Arrays

## Section 1: Introduction to Arrays

So far, we have stored individual values using variables.

For example:

```java id="a71001"
int mark1 = 85;
int mark2 = 90;
int mark3 = 78;
```

This works for a few values, but imagine storing the marks of **100 students**.

Creating 100 separate variables would be difficult and repetitive.

Java provides **arrays** to solve this problem.

---

## 1. What is an Array?

An **array** is a collection of values of the **same data type** stored under one variable name.

For example:

```java id="a71002"
int[] marks = {85, 90, 78, 92, 88};
```

Here, `marks` is an array that stores five integer values.

Instead of creating:

```text id="a71003"
mark1
mark2
mark3
mark4
mark5
```

we can store all five values in one array:

```text id="a71004"
marks
```

### Simple Definition

> An array stores multiple values of the same data type under one variable name.

---

## 2. Why Do We Need Arrays?

Suppose we want to store five numbers.

Without an array:

```java id="a71005"
int num1 = 10;
int num2 = 20;
int num3 = 30;
int num4 = 40;
int num5 = 50;
```

With an array:

```java id="a71006"
int[] numbers = {10, 20, 30, 40, 50};
```

The array makes the program easier to manage.

---

## 3. Creating an Array

One simple way to create and initialize an array is:

```java id="a71007"
int[] numbers = {10, 20, 30, 40, 50};
```

Here:

* `int` → data type of the array
* `[]` → indicates an array
* `numbers` → array name
* `{10, 20, 30, 40, 50}` → values stored in the array

All values in this array are integers.

---

## 4. Accessing Array Elements

Each value in an array has a position called an **index**.

Array indexes start from **0**.

For example:

```java id="a71008"
int[] numbers = {10, 20, 30, 40, 50};
```

The positions are:

```text id="9s2r1x"
Index:    0   1   2   3   4
Value:   10  20  30  40  50
```

To access a value, use its index.

```java id="a71009"
System.out.println(numbers[0]);
System.out.println(numbers[2]);
System.out.println(numbers[4]);
```

```output id="o71009"
10
30
50
```

So:

```text id="3f6r2a"
numbers[0] → 10
numbers[2] → 30
numbers[4] → 50
```

---

## 5. Why Does Array Index Start at 0?

The first element of an array is always at index `0`.

For an array:

```java id="a71010"
int[] numbers = {10, 20, 30};
```

The indexes are:

```text id="8m2k4v"
Index 0 → 10
Index 1 → 20
Index 2 → 30
```

There is no index `3` because the array contains only three elements.

Remember:

> **First element → index 0**

---

## 6. Changing an Array Element

Array elements can be changed after the array is created.

Example:

```java id="a71011"
public class Main {

    public static void main(String[] args) {
        int[] numbers = {10, 20, 30};

        numbers[1] = 50;

        System.out.println(numbers[1]);
    }
}
```

```output id="o71011"
50
```

Originally:

```text id="q1x6fz"
10  20  30
```

After:

```java id="7h4m2p"
numbers[1] = 50;
```

The array becomes:

```text id="6m8p1z"
10  50  30
```

---

## 7. Arrays Store the Same Data Type

An array has a fixed data type.

For example:

```java id="a71012"
int[] numbers = {10, 20, 30};
```

This array stores integers.

A `String` array stores strings:

```java id="a71013"
String[] names = {"Owais", "Sara", "Ali"};
```

A `double` array stores decimal values:

```java id="a71014"
double[] prices = {10.5, 20.75, 15.25};
```

The values in an array should match its declared type.

---

## 8. Different Types of Arrays

Arrays can store different types of values.

### Integer Array

```java id="a71015"
int[] numbers = {10, 20, 30};
```

### Double Array

```java id="a71016"
double[] prices = {10.5, 20.5, 30.5};
```

### String Array

```java id="a71017"
String[] names = {"Owais", "Sara", "Ali"};
```

### Character Array

```java id="a71018"
char[] letters = {'A', 'B', 'C'};
```

The array type determines what kind of values it can store.

---

## 9. Finding the Number of Elements

Java provides the `length` property to find the number of elements in an array.

Example:

```java id="a71019"
public class Main {

    public static void main(String[] args) {
        int[] numbers = {10, 20, 30, 40, 50};

        System.out.println(numbers.length);
    }
}
```

```output id="o71019"
5
```

The array contains five elements, so:

```text id="z4y7v1"
numbers.length → 5
```

### Important

For arrays, use:

```java id="f1j8w3"
array.length
```

There are no parentheses.

---

## 10. Using an Array with a Loop

Arrays are very useful with loops.

For example, we can print all elements using a `for` loop:

```java id="a71020"
public class Main {

    public static void main(String[] args) {
        int[] numbers = {10, 20, 30, 40, 50};

        for (int i = 0; i < numbers.length; i++) {
            System.out.println(numbers[i]);
        }
    }
}
```

```output id="o71020"
10
20
30
40
50
```

The loop uses the index to access each element.

---

## 11. Understanding Array Indexes

Consider:

```java id="a71021"
int[] marks = {85, 90, 75, 95};
```

The array looks like this:

```text id="6d8p2n"
Index:    0   1   2   3
Value:   85  90  75  95
```

Therefore:

```text id="f6k3a2"
marks[0] → 85
marks[1] → 90
marks[2] → 75
marks[3] → 95
```

If we use:

```java id="3p1x8v"
marks[4]
```

Java will produce an `ArrayIndexOutOfBoundsException` because index `4` does not exist.

---

## 12. Creating an Empty Array with a Fixed Size

An array can also be created by specifying its size.

For example:

```java id="a71022"
int[] numbers = new int[5];
```

This creates an integer array that can hold **5 values**.

Initially, the integer elements contain `0`.

```java id="a71023"
public class Main {

    public static void main(String[] args) {
        int[] numbers = new int[5];

        System.out.println(numbers[0]);
        System.out.println(numbers[4]);
    }
}
```

```output id="o71023"
0
0
```

The array has five positions:

```text id="p8r2m5"
Index:    0   1   2   3   4
Value:    0   0   0   0   0
```

---

## 13. Assigning Values Later

After creating an array with a fixed size, we can assign values using indexes.

```java id="a71024"
public class Main {

    public static void main(String[] args) {
        int[] numbers = new int[3];

        numbers[0] = 10;
        numbers[1] = 20;
        numbers[2] = 30;

        System.out.println(numbers[0]);
        System.out.println(numbers[1]);
        System.out.println(numbers[2]);
    }
}
```

```output id="o71024"
10
20
30
```

---

## 14. Array Size Cannot Be Changed

Once an array is created, its size is fixed.

For example:

```java id="a71025"
int[] numbers = new int[5];
```

This array can hold exactly five elements.

We cannot simply increase it to six elements later.

If a different size is needed, a new array must be created.

For now, remember:

> **An array has a fixed size after it is created.**

---

## 15. Example with Student Marks

Arrays are useful when storing related data.

For example:

```java id="a71026"
public class Main {

    public static void main(String[] args) {
        int[] marks = {85, 90, 78, 92, 88};

        System.out.println("First mark: " + marks[0]);
        System.out.println("Third mark: " + marks[2]);
        System.out.println("Total students: " + marks.length);
    }
}
```

```output id="o71026"
First mark: 85
Third mark: 78
Total students: 5
```

The array stores the marks together instead of using separate variables.

---

## 16. Array vs Normal Variables

Suppose we need to store three numbers.

### Without an Array

```java id="a71027"
int a = 10;
int b = 20;
int c = 30;
```

### With an Array

```java id="a71028"
int[] numbers = {10, 20, 30};
```

| Normal Variables                     | Array                           |
| ------------------------------------ | ------------------------------- |
| Each value needs a separate variable | Multiple values use one array   |
| Harder to manage many values         | Easier to manage many values    |
| No index                             | Uses indexes                    |
| No fixed group                       | Values belong to one collection |

---

## 17. Important Array Rules

Remember these basic rules:

### Rule 1: Index Starts at 0

```text id="a7r001"
First element → 0
```

### Rule 2: Last Index is `length - 1`

If an array has 5 elements:

```text id="a7r002"
length = 5
last index = 4
```

### Rule 3: All Elements Have the Same Type

```java id="a7r003"
int[] numbers = {10, 20, 30};
```

All elements are integers.

### Rule 4: Array Size is Fixed

Once created, the array's size cannot simply be changed.

---

## 18. Quick Example

Let's combine the basic concepts:

```java id="a71029"
public class Main {

    public static void main(String[] args) {
        int[] numbers = {10, 20, 30, 40, 50};

        System.out.println("First: " + numbers[0]);
        System.out.println("Last: " + numbers[numbers.length - 1]);
        System.out.println("Size: " + numbers.length);
    }
}
```

```output id="o71029"
First: 10
Last: 50
Size: 5
```

Here:

```text id="a7r004"
numbers[0]                    → first element
numbers[numbers.length - 1]  → last element
numbers.length                → number of elements
```

---

## Key Points

* An **array** stores multiple values under one variable name.
* All elements of an array have the same data type.
* Array indexes start from `0`.
* The first element is at index `0`.
* The last index is `length - 1`.
* Use `array.length` to find the number of elements.
* Array elements can be accessed using their indexes.
* Array elements can be changed using their indexes.
* An array can be created with initial values.
* An array can also be created using `new` with a fixed size.
* The size of an array is fixed after it is created.
* Arrays are commonly used with loops to process multiple values.
