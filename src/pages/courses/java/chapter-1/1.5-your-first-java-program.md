# Chapter 1: Introduction to Java

## Section 5: Your First Java Program

In the previous lessons, we learned what Java is, its features, and how to set up Java and VS Code.

Now it is time to write and run our **first Java program**.

---

### 1. Creating a Java File

First, create a file named:

```text id="x7m2qa"
Main.java
```

The `.java` extension tells the computer that the file contains Java source code.

The name of the file should match the public class name.

For example:

```java id="m42ktz"
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
```

Here:

* `Main.java` → file name
* `Main` → class name

---

### 2. Understanding the Java Program

Let's understand the program step by step.

#### `public class Main`

```java id="p1a7cx"
public class Main {
}
```

This creates a class named `Main`.

A Java program is usually organized using classes.

For now, you can think of a **class as a container that holds Java code**.

---

#### `public static void main(String[] args)`

```java id="k4v9mn"
public static void main(String[] args) {
}
```

This is the **main method**.

When we run a simple Java application, the program starts executing from the `main()` method.

You don't need to memorize every word yet. We will understand each part in more detail later.

---

#### `System.out.println()`

```java id="w6n3rp"
System.out.println("Hello, Java!");
```

This statement displays text on the screen.

The text inside the quotation marks is:

```text
Hello, Java!
```

---

### 3. Complete Program

Now let's put everything together:

```java id="m42ktz"
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
```

```output id="ceeinu"
Hello, Java!
```

The program prints **Hello, Java!** on the screen.

---

### 4. How to Compile the Program

If you are using the terminal, first open the folder containing `Main.java`.

Then use:

```text id="e7q3ks"
javac Main.java
```

The `javac` command compiles the Java source code.

If compilation is successful, Java creates a file named:

```text
Main.class
```

This file contains the bytecode that can be executed by the JVM.

---

### 5. How to Run the Program

After compiling the program, use:

```text id="r8v5jt"
java Main
```

The output will be:

```text id="o3k6pw"
Hello, Java!
```

Notice that we use `Main`, not `Main.java`, when running the compiled program.

---

### 6. Printing Different Messages

We can use `System.out.println()` to print different messages.

For example:

```java id="a5t2qm"
public class Main {
    public static void main(String[] args) {
        System.out.println("Welcome to Codify!");
        System.out.println("I am learning Java.");
        System.out.println("Java is fun!");
    }
}
```

```output id="v9r4kd"
Welcome to Codify!
I am learning Java.
Java is fun!
```

Each `println()` statement prints its message on a new line.

---

### 7. Printing Numbers

`System.out.println()` can also display numbers.

For example:

```java id="c8p3nx"
public class Main {
    public static void main(String[] args) {
        System.out.println(10);
        System.out.println(25);
        System.out.println(10 + 5);
    }
}
```

```output id="j2w7hf"
10
25
15
```

Java calculates `10 + 5` and prints the result.

---

### 8. `print()` vs `println()`

Java provides both `print()` and `println()` for displaying output.

`println()` moves to the next line after printing.

```java id="q6r1mv"
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello");
        System.out.println("Java");
    }
}
```

```output id="d4k8zs"
Hello
Java
```

`print()` does not automatically move to the next line.

```java id="u3n9pc"
public class Main {
    public static void main(String[] args) {
        System.out.print("Hello ");
        System.out.print("Java!");
    }
}
```

```output id="f5m2rx"
Hello Java!
```

---

### 9. Common Mistakes

Beginners often make small mistakes while writing their first Java program.

#### Missing semicolon

Incorrect:

```java
System.out.println("Hello, Java!")
```

Correct:

```java
System.out.println("Hello, Java!");
```

#### Wrong class and file name

If the file is:

```text
Main.java
```

the public class should be:

```java
public class Main
```

#### Incorrect capitalization

Java is **case-sensitive**.

For example:

```java
System.out.println()
```

is correct.

But:

```java
system.out.println()
```

is incorrect.

## Real-World Example 🌍

Imagine a college application that needs to display a welcome message when a student opens it.

A simple Java program could display:

```java id="n7x4kp"
public class Main {
    public static void main(String[] args) {
        System.out.println("Welcome to the College Management System!");
    }
}
```

```output id="b6q2wd"
Welcome to the College Management System!
```

This is a simple example of how Java can produce output that users can see.

---

## Key Points

* A Java source file normally uses the `.java` extension.
* The `main()` method is the starting point of a simple Java application.
* `System.out.println()` displays output and moves to the next line.
* `System.out.print()` displays output without moving to the next line.
* `javac` is used to compile Java source code.
* `java` is used to run the compiled program.
* Java is **case-sensitive**.
* A public class name should match its Java file name.
* Always use `;` at the end of Java statements where required.
