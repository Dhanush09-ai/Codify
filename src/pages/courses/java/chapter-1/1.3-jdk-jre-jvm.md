# Chapter 1: Introduction to Java

## Section 3: JDK, JRE and JVM

When we write a Java program, the computer needs a way to **compile and run** that program.

Three important terms are used in Java:

* **JDK** — Java Development Kit
* **JRE** — Java Runtime Environment
* **JVM** — Java Virtual Machine

A simple way to remember them is:

> **JDK → JRE → JVM**

The JDK is used to develop Java programs, the JRE provides the environment to run them, and the JVM actually runs the Java bytecode.

---

### 1. What is JVM?

**JVM** stands for **Java Virtual Machine**.

It is the part of Java that runs **Java bytecode**.

When we write Java code, the JVM does not directly execute the `.java` source code. Java source code is first converted into **bytecode**.

For example:

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
```

The Java compiler converts this source code into bytecode.

The JVM then reads and executes that bytecode.

The JVM is also responsible for important tasks such as:

* Running Java bytecode
* Managing memory
* Providing a runtime environment for Java programs

---

### 2. What is JRE?

**JRE** stands for **Java Runtime Environment**.

The JRE provides everything needed to **run** a Java application.

It contains:

* JVM
* Java class libraries
* Other files required to run Java programs

In simple words:

> **JRE = JVM + Libraries required to run Java programs**

If you only want to run a Java application, you need a Java runtime environment.

---

### 3. What is JDK?

**JDK** stands for **Java Development Kit**.

The JDK is used by programmers to **develop Java applications**.

It contains:

* JRE
* Development tools
* Java compiler
* Other tools required for Java development

The Java compiler is called **`javac`**.

It converts Java source code into bytecode.

In simple words:

> **JDK = JRE + Development Tools**

---

### 4. How Do JDK, JRE and JVM Work Together?

Let's understand the process step by step.

Suppose we write this Java program:

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
```

The process is:

1. We write Java source code in a `.java` file.
2. The **JDK** provides the Java compiler.
3. The compiler converts the source code into **bytecode**.
4. The bytecode is stored in a `.class` file.
5. The **JRE** provides the environment required to run the program.
6. The **JVM** executes the bytecode.

The basic flow is:

> **Java Source Code → Compiler → Bytecode → JVM → Output**

---

### 5. Simple Real-World Example 🌍

Think about a **restaurant**.

* **JDK** → Complete restaurant with all tools needed to prepare food.
* **JRE** → Restaurant environment needed to serve the food.
* **JVM** → The part that actually handles the prepared order.

This is only an analogy to help you remember the relationship.

The important relationship is:

> **JDK contains JRE, and JRE contains JVM.**

---

### 6. Difference Between JDK, JRE and JVM

| Term | Full Form                | Main Purpose          |
| ---- | ------------------------ | --------------------- |
| JDK  | Java Development Kit     | Develop Java programs |
| JRE  | Java Runtime Environment | Run Java programs     |
| JVM  | Java Virtual Machine     | Execute Java bytecode |

A simple way to remember:

| If you want to...     | You need... |
| --------------------- | ----------- |
| Develop Java programs | JDK         |
| Run Java programs     | JRE         |
| Execute Java bytecode | JVM         |

---

### 7. Source Code, Bytecode and Machine Code

There are three important terms to understand.

**Source Code**

This is the Java code written by the programmer.

Example:

```java
System.out.println("Hello, Java!");
```

**Bytecode**

The Java compiler converts the source code into bytecode.

Bytecode is stored in a `.class` file.

**Machine Code**

The JVM interprets or compiles bytecode into instructions that the computer can execute.

So the basic idea is:

```text
Source Code
    ↓
Java Compiler
    ↓
Bytecode
    ↓
JVM
    ↓
Program Output
```

---

## Key Points

* **JDK** stands for Java Development Kit.
* **JRE** stands for Java Runtime Environment.
* **JVM** stands for Java Virtual Machine.
* JDK is mainly used to **develop** Java programs.
* JRE provides the environment needed to **run** Java programs.
* JVM **executes Java bytecode**.
* The Java compiler is called **`javac`**.
* Java source code is converted into **bytecode**.
* The bytecode is stored in a `.class` file.
* The basic relationship is **JDK → JRE → JVM**.
