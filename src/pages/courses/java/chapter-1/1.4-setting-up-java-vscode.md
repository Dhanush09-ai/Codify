# Chapter 1: Introduction to Java

## Section 4: Setting Up Java and VS Code

Before writing Java programs, we need to set up a few things on our computer.

We need:

* **JDK (Java Development Kit)** — to compile and run Java programs
* **VS Code (Visual Studio Code)** — to write and manage our Java code

In this lesson, we will set up both.

---

### 1. Install the JDK

The **JDK** is required to develop Java programs.

Without the JDK, we cannot properly compile and run Java programs from our development environment.

You can download a JDK from a trusted Java distribution provider such as **Oracle** or **Eclipse Adoptium**.

After downloading the JDK installer:

1. Open the installer.
2. Follow the installation steps.
3. Keep the default installation options unless you have a specific reason to change them.
4. Complete the installation.

After installation, we should check whether Java is working correctly.

---

### 2. Check the Java Installation

Open **Command Prompt** on Windows.

Type:

```text
java -version
```

You should see information about the installed Java version.

You can also check the Java compiler by typing:

```text
javac -version
```

If both commands display a version number, the Java installation is working correctly.

For example:

```text
java version "..."
javac ...
```

The exact version number may be different depending on the JDK version installed on your computer.

---

### 3. Install Visual Studio Code

**Visual Studio Code**, commonly called **VS Code**, is a code editor.

It allows us to:

* Write Java programs
* Edit source code
* Organize project files
* Open a terminal
* Install useful extensions

Download and install VS Code from the official Visual Studio Code website.

During installation, follow the instructions shown by the installer.

---

### 4. Install the Java Extension Pack

VS Code needs Java support to provide useful Java development features.

Open VS Code and go to the **Extensions** section.

Search for:

> **Extension Pack for Java**

Install the extension pack provided by Microsoft.

It provides several useful Java development features, such as:

* Java code support
* Code completion
* Debugging
* Running Java programs
* Project support

After installing the extension pack, restart VS Code if necessary.

---

### 5. Create Your First Java Folder

It is a good idea to keep your Java programs organized inside a folder.

For example, create a folder called:

```text
JavaPrograms
```

Inside this folder, you can create folders for different programs or lessons.

For example:

```text
JavaPrograms
│
├── HelloJava
├── Variables
├── Conditions
└── Loops
```

This keeps your programs organized as you continue learning Java.

---

### 6. Open the Folder in VS Code

Now open your Java folder in VS Code.

You can do this by:

1. Open VS Code.
2. Select **File → Open Folder**.
3. Select your `JavaPrograms` folder.
4. Click **Select Folder**.

The folder will appear in the **Explorer** panel on the left side of VS Code.

---

### 7. Create a Java File

Inside your project folder, create a new file named:

```text
Main.java
```

The `.java` extension tells the computer that this is a Java source-code file.

Write the following program:

```java id="m42ktz"
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
```

```output id="ceeinu"
Hello, Java!
```

The class name and file name should match.

Here:

* File name → `Main.java`
* Class name → `Main`

We will learn the structure of this program in the next lesson.

---

### 8. Run the Java Program

VS Code can provide a **Run** option for Java programs.

You can run the program using the **Run** button displayed above the `main()` method.

The output will appear in the terminal.

You can also use the terminal to compile and run the program manually.

First, compile the program:

```text
javac Main.java
```

Then run it:

```text
java Main
```

The output will be:

```text
Hello, Java!
```

---

### 9. Common Setup Problems

Sometimes Java may not work immediately after installation.

Here are some common problems:

| Problem                             | Possible Reason                                   |
| ----------------------------------- | ------------------------------------------------- |
| `java` is not recognized            | Java may not be installed or configured correctly |
| `javac` is not recognized           | JDK may not be installed or added to PATH         |
| Java code is not running in VS Code | Java extension support may be missing             |
| Run option is missing               | Java extension or project setup may not be ready  |
| Wrong Java version                  | Another Java installation may be selected         |

Don't worry if you encounter an error. Understanding and fixing errors is a normal part of programming.

---

## Setup Checklist ✅

Before continuing with the Java course, make sure:

* JDK is installed
* `java -version` works
* `javac -version` works
* VS Code is installed
* Extension Pack for Java is installed
* A Java project folder is created
* `Main.java` is created
* The Hello Java program runs successfully

---

## Key Points

* The **JDK** is required to develop Java programs.
* **VS Code** can be used to write and manage Java code.
* The **Extension Pack for Java** adds Java development support to VS Code.
* Java source files use the `.java` extension.
* The file name should match the public class name.
* `javac` is used to compile Java source code.
* `java` is used to run a compiled Java program.
* Always keep your Java programs organized in folders.
