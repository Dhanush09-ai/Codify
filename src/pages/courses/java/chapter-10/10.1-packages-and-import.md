# Chapter 10: More Java Fundamentals

## Section 1: Packages and `import`

In the previous chapter, we learned about variables, `final`, wrapper classes, and common Java errors.

Now, we will learn how Java organizes classes using **packages** and how the `import` statement helps us use classes from other packages.

We will learn how to:

* Understand what a package is
* Create a simple package
* Understand package names
* Use the `import` statement
* Use classes from another package
* Understand `java.lang`
* Use fully qualified class names
* Understand common beginner mistakes

---

## 1. What Is a Package?

A **package** is a way of grouping related Java classes together.

You can think of a package like a **folder** that contains related Java classes.

For example:

```text
school
 ├── Student.java
 ├── Teacher.java
 └── Subject.java
```

The classes can belong to a package named `school`.

Packages help organize large Java programs.

---

## 2. Why Do We Need Packages?

Imagine a large project containing hundreds of Java classes.

Without packages, all classes would be mixed together.

Packages help us:

* Organize classes
* Group related classes
* Avoid name conflicts
* Make large projects easier to manage

For example:

```text
college
 ├── Student
 ├── Teacher
 └── Course

library
 ├── Book
 ├── Student
 └── Library
```

Both packages can have a class named `Student`.

The package name tells Java which `Student` class we mean.

---

## 3. Creating a Package

A package is declared using the `package` keyword.

Example:

```java id="s10001"
package school;

public class Student {
    public void display() {
        System.out.println("Student class");
    }
}
```

Here:

```java
package school;
```

means that the `Student` class belongs to the `school` package.

---

## 4. Package Statement Must Come First

The `package` statement is normally written at the beginning of the Java source file.

Example:

```java id="s10002"
package school;

public class Student {
    public static void main(String[] args) {
        System.out.println("Hello from school package");
    }
}
```

The package declaration appears before the class declaration.

---

## 5. Package Names

Package names are usually written in lowercase letters.

Example:

```java
package school;
```

Another example:

```java
package college.students;
```

The dot `.` can be used to represent levels of packages.

For example:

```text
college
   └── students
```

can be represented as:

```java
package college.students;
```

---

## 6. Using a Class from the Same Package

Classes inside the same package can generally use each other without an `import` statement.

For example:

```text
school
 ├── Student.java
 └── Teacher.java
```

If both classes belong to:

```java
package school;
```

they are in the same package.

An `import` statement is not required just to use another class from the same package.

---

## 7. What Is `import`?

The `import` statement allows us to use a class from another package without writing its complete package name every time.

Syntax:

```java
import packageName.ClassName;
```

For example:

```java
import java.util.Scanner;
```

This allows us to use `Scanner` directly in our program.

---

## 8. Using `Scanner` with `import`

`Scanner` belongs to the `java.util` package.

Example:

```java id="s10003"
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        System.out.println("Enter your name:");
        String name = input.nextLine();

        System.out.println("Hello, " + name);
    }
}
```

Input:

```text
Owais
```

Output:

```text
Enter your name:
Hello, Owais
```

The statement:

```java
import java.util.Scanner;
```

allows us to write:

```java
Scanner input
```

instead of writing the complete class name every time.

---

## 9. Importing a Specific Class

We can import one specific class from a package.

Example:

```java
import java.util.Scanner;
```

Here:

* `java` → top-level package
* `util` → subpackage
* `Scanner` → class

The complete name is:

```text
java.util.Scanner
```

---

## 10. Importing Multiple Classes

We can import multiple classes from the same package.

Example:

```java id="s10004"
import java.util.Scanner;
import java.util.ArrayList;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        ArrayList<String> names = new ArrayList<>();

        names.add("Owais");
        names.add("Ali");

        System.out.println(names);
    }
}
```

Output:

```text
[Owais, Ali]
```

Each imported class has its own `import` statement.

---

## 11. Importing All Classes from a Package

Java allows us to import all accessible classes from a package using `*`.

Example:

```java
import java.util.*;
```

The `*` means all classes in that package can be referred to by their simple names.

For example:

```java id="s10005"
import java.util.*;

public class Main {
    public static void main(String[] args) {
        ArrayList<String> names = new ArrayList<>();

        names.add("Owais");
        names.add("Rahul");

        System.out.println(names);
    }
}
```

Output:

```text
[Owais, Rahul]
```

---

## 12. What Does `java.util.*` Mean?

Consider:

```java
import java.util.*;
```

It means:

> Import accessible classes from the `java.util` package so their simple names can be used.

For example, classes such as:

```text
Scanner
ArrayList
```

can be used directly after the import.

---

## 13. `java.lang` Package

Java automatically makes the classes in the `java.lang` package available to every Java program.

For example:

```java
String
System
Math
Integer
```

belong to `java.lang`.

We normally do not need to write:

```java
import java.lang.String;
```

or:

```java
import java.lang.Math;
```

because `java.lang` is automatically available.

---

## 14. Example with `Math`

We can use `Math` without importing it.

Example:

```java id="s10006"
public class Main {
    public static void main(String[] args) {
        double number = Math.sqrt(25);

        System.out.println(number);
    }
}
```

Output:

```text
5.0
```

We do not need:

```java
import java.lang.Math;
```

because `java.lang` is automatically available.

---

## 15. Fully Qualified Class Name

Instead of using `import`, we can write the complete class name.

For example, instead of:

```java
import java.util.Scanner;
```

we can write:

```java id="s10007"
public class Main {
    public static void main(String[] args) {
        java.util.Scanner input =
            new java.util.Scanner(System.in);

        System.out.println("Enter your name:");
        String name = input.nextLine();

        System.out.println("Hello, " + name);
    }
}
```

Input:

```text
Owais
```

Output:

```text
Enter your name:
Hello, Owais
```

Here:

```text
java.util.Scanner
```

is the **fully qualified class name**.

---

## 16. `import` vs Fully Qualified Name

There are two ways to use a class from another package.

### Using `import`

```java
import java.util.Scanner;

Scanner input = new Scanner(System.in);
```

### Using the complete name

```java
java.util.Scanner input =
    new java.util.Scanner(System.in);
```

The `import` approach is usually easier to read.

---

## 17. Package and `import` Together

A Java file can contain a package declaration and import statements.

Example:

```java
package school;

import java.util.Scanner;

public class Student {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        System.out.println("Enter your age:");
        int age = input.nextInt();

        System.out.println("Age: " + age);
    }
}
```

Input:

```text
16
```

Output:

```text
Enter your age:
Age: 16
```

The general order is:

```text
package declaration
        ↓
import statements
        ↓
class declaration
```

## 18. Package Structure Example

Suppose we have a project named `CollegeApp`.

It may have a structure like:

```text
CollegeApp
│
├── student
│   └── Student.java
│
├── teacher
│   └── Teacher.java
│
└── Main.java
```

The `Student.java` file may contain:

```java
package student;

public class Student {
    public void display() {
        System.out.println("Student class");
    }
}
```

Then `Main.java` can import it:

```java
import student.Student;

public class Main {
    public static void main(String[] args) {
        Student student = new Student();

        student.display();
    }
}
```

Output:

```text
Student class
```

## 19. Why Packages Are Useful in Large Projects

Consider a college management application.

It may contain:

```text
college.student
college.teacher
college.exam
college.library
college.admin
```

Each package can contain classes related to that part of the application.

For example:

```text
college.student
    Student
    Attendance

college.library
    Book
    Library
```

This keeps the project organized.

## 20. Common Mistakes

### Mistake 1: Writing the package statement after the class

Incorrect:

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello");
    }
}

package school;
```

The package declaration should be placed before the class declaration.

---

### Mistake 2: Forgetting the package name in `import`

Incorrect:

```java
import Scanner;
```

Correct:

```java
import java.util.Scanner;
```

The package name is required when importing a class.

---

### Mistake 3: Using the wrong class name

Incorrect:

```java
import java.util.scanner;
```

Correct:

```java
import java.util.Scanner;
```

Java is case-sensitive.

---

### Mistake 4: Importing `java.lang` unnecessarily

This is not normally needed:

```java
import java.lang.String;
```

Classes from `java.lang` are automatically available.

---

## 21. Quick Example

Here is a simple example using `import`:

```java id="s10008"
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        System.out.print("Enter a number: ");
        int number = input.nextInt();

        System.out.println("Square = " + (number * number));
    }
}
```

Input:

```text
5
```

Output:

```text
Enter a number: Square = 25
```

Here:

```java
import java.util.Scanner;
```

allows the program to use the `Scanner` class.

---

## Key Points

* A **package** groups related Java classes.
* Packages help organize large Java programs.
* The `package` statement declares which package a class belongs to.
* Package names are commonly written in lowercase.
* The `import` statement allows us to use classes from another package.
* `java.util.Scanner` is an example of a fully qualified class name.
* `import java.util.Scanner;` lets us use `Scanner` directly.
* `import java.util.*;` imports accessible classes from `java.util`.
* Classes in `java.lang` are automatically available.
* A fully qualified class name can be used without an `import` statement.
* The usual order is `package` → `import` → class.
