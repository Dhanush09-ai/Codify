In the previous topic, we learned about packages and the `import` statement.

We will learn how to:

* Understand Java documentation
* Find information about Java classes and methods
* Understand method descriptions and parameters
* Use the `Math` class
* Find the absolute value of a number
* Find powers and square roots
* Find maximum and minimum values
* Round decimal numbers
* Generate random numbers
* Use mathematical constants

## 1. What Is Java Documentation?

**Java documentation** is reference information that explains Java classes, methods, parameters, return values, and other features.

When you are learning Java, you may not remember every method.

Instead of guessing, you can check the documentation to understand how a method works.

For example, if you want to know how `Math.sqrt()` works, Java documentation tells you what the method does and what it returns.

---

## 2. Why Is Documentation Useful?

Documentation helps us:

* Understand what a class does
* Find available methods
* Understand method parameters
* Understand return values
* Learn how to use a method correctly
* Check details when we forget something

For example, if you see:

```java
Math.max(10, 20)
```

documentation can help you understand that `max()` returns the larger value.

---

## 3. What Information Can Documentation Provide?

Documentation for a Java class can provide information such as:

* Class name
* Description
* Methods
* Parameters
* Return type
* Exceptions
* Constants
* Examples

For a method, you may see information similar to:

```text
max(int a, int b)
```

This tells us that the method accepts two `int` values.

---

## 4. Understanding a Method Description

Consider:

```java
Math.max(10, 20)
```

Here:

```text
Math
```

is the class.

```text
max
```

is the method.

```text
10, 20
```

are the arguments passed to the method.

The method returns the larger value.

Output:

```text
20
```

Documentation helps us understand this information without having to guess.

---

## 5. What Is the `Math` Class?

The Java `Math` class provides methods for performing common mathematical operations.

It belongs to:

```text
java.lang
```

Because `java.lang` is automatically available, we normally do not need to import `Math`.

For example:

```java id="s10201"
public class Main {
    public static void main(String[] args) {
        System.out.println(Math.sqrt(25));
    }
}
```

Output:

```text
5.0
```

---

## 6. Finding the Absolute Value

The `Math.abs()` method returns the absolute value of a number.

Example:

```java id="s10202"
public class Main {
    public static void main(String[] args) {
        System.out.println(Math.abs(-25));
        System.out.println(Math.abs(25));
    }
}
```

Output:

```text
25
25
```

For example:

```java
Math.abs(-10)
```

returns:

```text
10
```

## 9. Finding a Power

The `Math.pow()` method is used to calculate a number raised to a power.

Syntax:

```java
Math.pow(base, exponent)
```

Example:

```java id="s10205"
public class Main {
    public static void main(String[] args) {
        System.out.println(Math.pow(2, 3));
    }
}
```

Output:

```text
8.0
```

This means:

```text
2³ = 8
```

The result of `Math.pow()` is a `double`.

---

## 14. `ceil()` vs `floor()`

Consider the number:

```text
5.7
```

`Math.ceil()` gives:

```text
6.0
```

`Math.floor()` gives:

```text
5.0
```

The difference is:

| Method         | Meaning        | Result for `5.7` |
| -------------- | -------------- | ---------------: |
| `Math.ceil()`  | Round upward   |            `6.0` |
| `Math.floor()` | Round downward |            `5.0` |

## 15. Generating a Random Number

The `Math.random()` method generates a random `double` value from `0.0` up to, but not including, `1.0`.

Example:

```java id="s10210"
public class Main {
    public static void main(String[] args) {
        System.out.println(Math.random());
    }
}
```

Possible output:

```text
0.483721
```

The exact value changes each time the program runs.

So, the output is not fixed.

---

## 16. Generating a Random Integer from 0 to 9

We can use `Math.random()` with multiplication and casting.

Example:

```java id="s10211"
public class Main {
    public static void main(String[] args) {
        int number = (int) (Math.random() * 10);

        System.out.println(number);
    }
}
```

Possible output:

```text
7
```

The output can be any integer from:

```text
0 to 9
```

Because the value generated by `Math.random()` is less than `1.0`.

## 19. Combining Math Methods

We can use multiple `Math` methods in the same expression.

Example:

```java id="s10214"
public class Main {
    public static void main(String[] args) {
        double number = Math.sqrt(Math.pow(3, 2) + Math.pow(4, 2));

        System.out.println(number);
    }
}
```

Output:

```text
5.0
```

The calculation is:

```text
√(3² + 4²)
= √(9 + 16)
= √25
= 5
```

This shows how Java methods can be combined to perform calculations.

## 20. Common Beginner Mistakes

### Mistake 1: Writing `math` instead of `Math`

Incorrect:

```java
math.sqrt(25);
```

Correct:

```java
Math.sqrt(25);
```

Java is case-sensitive.

---

### Mistake 2: Forgetting the parentheses

Incorrect:

```java
Math.sqrt;
```

Correct:

```java
Math.sqrt(25);
```

A method needs parentheses when it is called.

---

### Mistake 3: Expecting `Math.random()` to return an integer

`Math.random()` returns a `double`.

For example:

```java
Math.random()
```

can produce a value such as:

```text
0.735421
```

To generate an integer, additional operations are required.

---

### Mistake 4: Expecting `Math.pow()` to return an integer

For example:

```java
Math.pow(2, 3)
```

returns:

```text
8.0
```

The result is a `double`.

---

## 21. Quick Example

The following program uses several `Math` methods:

```java id="s10215"
public class Main {
    public static void main(String[] args) {
        int a = -12;
        int b = 20;

        System.out.println("Absolute value: " + Math.abs(a));
        System.out.println("Maximum: " + Math.max(a, b));
        System.out.println("Minimum: " + Math.min(a, b));
        System.out.println("Square root: " + Math.sqrt(25));
    }
}
```

Output:

```text id="o10215"
Absolute value: 12
Maximum: 20
Minimum: -12
Square root: 5.0
```
