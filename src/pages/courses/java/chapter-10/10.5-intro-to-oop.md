## 1. What Is Object-Oriented Programming?

**Object-Oriented Programming (OOP)** is a programming approach where programs are organized around **objects**.

An object can represent something from the real world or something useful inside a program.

For example:

```text
Student
Car
Book
Bank Account
Employee
```

Each object can have **data** and **behavior**.

---

## 2. What Is an Object?

An **object** is a particular instance of a class.

For example, a `Student` class can be used to create student objects.

```text
Student
   ↓
Student object 1
Student object 2
Student object 3
```

Each object can contain its own data.

For example:

```text
Student 1
Name: Owais
Age: 16

Student 2
Name: Ali
Age: 17
```

Both are Student objects, but their data can be different.

---

## 3. What Is a Class?

A **class** is a blueprint or template used to create objects.

For example, a `Student` class can describe what information and behavior a student object should have.

```text
Class: Student
----------------
Name
Age
Display information
```

Objects can then be created from this class.

```text
Student class
      ↓
 ┌────┴────┐
 ↓         ↓
Object 1   Object 2
```

---

## 4. Class vs Object

A class and an object are related, but they are not the same.

| Class                     | Object               |
| ------------------------- | -------------------- |
| Blueprint or template     | Instance of a class  |
| Defines data and behavior | Contains actual data |
| Used to create objects    | Created from a class |

For example:

```text
Class → Student
Object → Owais's Student object
```

## 6. Creating a Simple Class

We can create a class using the `class` keyword.

Example:

```java id="s10501"
class Student {
    String name;
    int age;
}
```

Here:

```text
Student
```

is the class name.

The class contains:

```text
name
age
```

These are variables that describe a Student object.

---

## 7. Creating an Object

We can create an object using the `new` keyword.

Example:

```java id="s10502"
class Student {
    String name;
    int age;
}

public class Main {
    public static void main(String[] args) {
        Student student = new Student();

        student.name = "Owais";
        student.age = 16;

        System.out.println(student.name);
        System.out.println(student.age);
    }
}
```

Output:

```text id="o10502"
Owais
16
```

Here:

```java
Student student = new Student();
```

creates a new `Student` object.

---

## 8. Understanding `new`

The `new` keyword is used to create a new object.

For example:

```java id="s10503"
Student student = new Student();
```

This can be understood as:

```text
Student
   ↓
data type

student
   ↓
reference variable

new Student()
   ↓
creates a new Student object
```

---

## 9. Accessing Object Data

After creating an object, we can access its variables using the dot `.` operator.

Example:

```java id="s10504"
class Student {
    String name;
    int age;
}

public class Main {
    public static void main(String[] args) {
        Student student = new Student();

        student.name = "Owais";
        student.age = 16;

        System.out.println(student.name);
        System.out.println(student.age);
    }
}
```

Output:

```text id="o10504"
Owais
16
```

The dot operator connects the object with its member.

For example:

```java
student.name
```

means the `name` belonging to the `student` object.

---

## 10. Creating Multiple Objects

A class can be used to create multiple objects.

Example:

```java id="s10505"
class Student {
    String name;
    int age;
}

public class Main {
    public static void main(String[] args) {
        Student student1 = new Student();
        Student student2 = new Student();

        student1.name = "Owais";
        student1.age = 16;

        student2.name = "Ali";
        student2.age = 17;

        System.out.println(student1.name + " " + student1.age);
        System.out.println(student2.name + " " + student2.age);
    }
}
```

Output:

```text id="o10505"
Owais 16
Ali 17
```

Each object has its own data.

---

## 11. Objects Have Their Own Data

Consider:

```java id="s10506"
class Student {

public class Main {
    public static void main(String[] args) {
        Student student1 = new Student();
        Student student2 = new Student();

        student1.name = "Owais";
        student2.name = "Ali";

        System.out.println(student1.name);
        System.out.println(student2.name);
    }
}
```

Output:

```text id="o10506"
Owais
Ali
```

Both objects were created from the same class, but each object has its own `name` value.

## 12. Adding Methods to a Class

A class can contain methods as well as variables.

Example:

```java id="s10507"
class Student {
    String name;

    void introduce() {
        System.out.println("My name is " + name);
    }
}

public class Main {
    public static void main(String[] args) {
        Student student = new Student();

        student.name = "Owais";
        student.introduce();
    }
}
```

Output:

```text id="o10507"
My name is Owais
```

Here:

```java
introduce()
```

is a method of the `Student` class.

---

## 13. Calling an Object's Method

We use the dot operator to call a method belonging to an object.

Example:

```java id="s10508"
class Car {
    void start() {
        System.out.println("Car started");
    }
}

public class Main {
    public static void main(String[] args) {
        Car car = new Car();

        car.start();
    }
}
```

Output:

```text id="o10508"
Car started
```

The statement:

```java
car.start();
```

calls the `start()` method of the `car` object.

---

## 14. Properties and Behavior

An object can have:

### Properties

Properties describe the object's data.

For a `Car`:

```text
color
model
speed
```

### Behavior

Behavior describes what the object can do.

For a `Car`:

```text
start()
stop()
accelerate()
```

In Java, properties can be represented using variables and behavior can be represented using methods.

## 16. Why Is OOP Useful?

OOP helps us organize large programs into smaller, understandable parts.

For example, a college application might have classes such as:

```text
Student
Teacher
Course
Attendance
Library
Exam
```

Each class can contain the data and behavior related to that part of the application.

This can make a large program easier to understand and maintain.

## 17. Class as a Blueprint

A useful way to remember a class is to think of it as a **blueprint**.

For example:

```text
Blueprint
   ↓
House
```

The blueprint describes how a house should be built.

Similarly:

```text
Class
   ↓
Object
```

The class describes what an object can contain.

For example:

```text
Student class
     ↓
 ┌───┴────┐
 ↓        ↓
Student  Student
Object 1  Object 2
```

## 18. OOP in Java

Java is designed around object-oriented programming.

Many Java programs use classes and objects to organize their code.

For example:

```java id="s10510"
class Book {
    String title;

    void read() {
        System.out.println("Reading " + title);
    }
}

public class Main {
    public static void main(String[] args) {
        Book book = new Book();

        book.title = "Java Basics";
        book.read();
    }
}
```

Output:

```text id="o10510"
Reading Java Basics
```

The `Book` class describes what a book object contains and what it can do.

## 19. Common Beginner Mistakes

### Mistake 1: Forgetting `new`

Incorrect:

```java id="v4q0wh"
Student student;
student.name = "Owais";
```

The variable is declared, but an object has not been created.

Correct:

```java id="1g6z9c"
Student student = new Student();
student.name = "Owais";
```

---

### Mistake 2: Using the class name instead of the object

If we create:

```java id="z9n6dr"
Student student = new Student();
```

we access its data using:

```java id="9xq1mj"
student.name
```

not:

```java id="j7f7ce"
Student.name
```

for an ordinary instance variable.

---

### Mistake 3: Forgetting the dot operator

Incorrect:

```java id="5npp9e"
student name
```

Correct:

```java id="k9j6va"
student.name
```

The dot operator is used to access members of an object.

---

### Mistake 4: Thinking one class means one object

A class can be used to create many objects.

For example:

```java id="k3s6cb"
Student student1 = new Student();
Student student2 = new Student();
Student student3 = new Student();
```

All three objects are created from the same `Student` class.

## 20. OOP Terms to Remember

Here are some important beginner-level OOP terms:

| Term     | Meaning                                   |
| -------- | ----------------------------------------- |
| Class    | Blueprint for creating objects            |
| Object   | Instance of a class                       |
| Property | Data belonging to an object               |
| Method   | Behavior or action performed by an object |
| `new`    | Creates an object                         |
| `.`      | Accesses members of an object             |

These terms will be used frequently in the next OOP lessons.

## 21. Quick Example

Here is a simple example combining a class, object, property, and method:

```java id="s10511"
class Student {
    String name;
    int age;

    void display() {
        System.out.println("Name: " + name);
        System.out.println("Age: " + age);
    }
}

public class Main {
    public static void main(String[] args) {
        Student student = new Student();

        student.name = "Owais";
        student.age = 16;

        student.display();
    }
}
```

Output:

```text id="o10511"
Name: Owais
Age: 16
```

Here:

```text
Student
   ↓
Class

student
   ↓
Object

name, age
   ↓
Properties

display()
   ↓
Method / Behavior
```

## Key Points

* OOP stands for **Object-Oriented Programming**.
* Java programs can be organized using classes and objects.
* A **class** is a blueprint used to create objects.
* An **object** is an instance of a class.
* Objects can contain their own data.
* Variables inside a class can represent an object's properties.
* Methods inside a class can represent an object's behavior.
* The `new` keyword is used to create an object.
* The dot `.` operator is used to access an object's variables and methods.
* One class can be used to create many objects.
* Each object can have different values for its instance variables.
* OOP helps organize larger programs into understandable parts.
