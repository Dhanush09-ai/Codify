# Chapter 10: More Java Fundamentals

## Section 3: Command-Line Arguments

In the previous topic, we learned about Java documentation and the `Math` class.

Now, we will learn about **command-line arguments** and how values can be passed to a Java program when it starts.

We will learn how to:

* Understand command-line arguments
* Understand the `args` parameter of `main()`
* Pass values to a Java program
* Access command-line arguments using an index
* Understand that arguments are stored as Strings
* Convert command-line arguments to numbers
* Use multiple command-line arguments
* Understand common beginner mistakes

---

## 1. What Are Command-Line Arguments?

**Command-line arguments** are values that we pass to a Java program when we start it.

For example, suppose we have a program:

```java id="s10301"
public class Main {
    public static void main(String[] args) {
        System.out.println(args[0]);
    }
}
```

If we start the program with:

```text
Hello
```

the program receives `"Hello"` as a command-line argument.

Output:

```text id="o10301"
Hello
```

---

## 2. The `args` Parameter

You have already seen this line many times:

```java
public static void main(String[] args)
```

Here:

```text
String[]
```

means that `args` is an array of Strings.

The variable:

```text
args
```

contains the command-line arguments passed to the program.

For example:

```java id="s10302"
public class Main {
    public static void main(String[] args) {
        System.out.println(args[0]);
    }
}
```

If the program receives:

```text
Owais
```

then:

```text
args[0]
```

contains:

```text
"Owais"
```

---

## 3. Passing the First Argument

Suppose we have:

```java id="s10303"
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, " + args[0]);
    }
}
```

If we run the program with:

```text
Owais
```

Output:

```text id="o10303"
Hello, Owais
```

The first argument is stored at index `0`.

Remember:

```text
First argument  → args[0]
Second argument → args[1]
Third argument  → args[2]
```

---

## 4. Command-Line Arguments Are Strings

All command-line arguments are received as `String` values.

For example, if we pass:

```text
25
```

Java receives it as:

```text
"25"
```

not as the integer:

```text
25
```

Example:

```java id="s10304"
public class Main {
    public static void main(String[] args) {
        String value = args[0];

        System.out.println(value);
    }
}
```

If we pass:

```text
25
```

Output:

```text id="o10304"
25
```

The value is stored as a String.

---

## 5. Checking the Type

Because `args` is a `String` array, this is valid:

```java
String value = args[0];
```

But this is not valid:

```java
int value = args[0];
```

We cannot directly store a String in an `int` variable.

We need to convert the String first.

---

## 6. Converting a Command-Line Argument to an Integer

We can use:

```java
Integer.parseInt()
```

to convert a String into an `int`.

Example:

```java id="s10305"
public class Main {
    public static void main(String[] args) {
        int number = Integer.parseInt(args[0]);

        System.out.println(number);
    }
}
```

If we pass:

```text
25
```

Output:

```text id="o10305"
25
```

Now `number` is an `int`.

---

## 7. Performing Calculations

After converting a command-line argument to an integer, we can perform calculations.

Example:

```java id="s10306"
public class Main {
    public static void main(String[] args) {
        int number = Integer.parseInt(args[0]);

        System.out.println("Square = " + (number * number));
    }
}
```

If we pass:

```text
5
```

Output:

```text id="o10306"
Square = 25
```

Without conversion, Java would treat `"5"` as text rather than as an integer.

## 8. Passing Multiple Arguments

We can pass more than one argument.

For example:


These values are stored as:


```java id="s10307"
public class Main {
    public static void main(String[] args) {

    }

```

Output:

```text id="o10307"

```

## 10. Finding the Number of Arguments

The `args` array has a `length` property.

We can use:

```java
args.length
```

to find how many arguments were passed.

Example:

```java id="s10309"
public class Main {
    public static void main(String[] args) {
        System.out.println("Number of arguments: " + args.length);
    }
}
```

If we pass:

```text
Java Python C
```

Output:

```text id="o10309"
Number of arguments: 3
```

---

## 11. Printing All Arguments Using a Loop

Because `args` is an array, we can use a loop to access all arguments.

Example:

```java id="s10310"
public class Main {
    public static void main(String[] args) {
        for (int i = 0; i < args.length; i++) {
            System.out.println(args[i]);
        }
    }
}
```

If we pass:

```text
Java Python C
```

Output:

```text id="o10310"
Java
Python
C
```

The loop starts at index `0` and continues until `args.length - 1`.

## 12. Adding Two Numbers

Command-line arguments can be converted and used in calculations.

Example:

```java id="s10311"
public class Main {
    public static void main(String[] args) {
        int a = Integer.parseInt(args[0]);
        int b = Integer.parseInt(args[1]);

        System.out.println("Sum = " + (a + b));
    }
}
```

If we pass:

```text
10 20
```

Output:

```text id="o10311"
Sum = 30
```

Here:

```text
args[0] → "10"
args[1] → "20"
```

After conversion:

```text
a → 10
b → 20
```

## 15. Command-Line Arguments vs User Input

Command-line arguments and `Scanner` input are two different ways to provide data.

### Command-line arguments

The values are provided when the program starts.

```text
java Main Owais
```

The program receives:

```text
Owais
```

through `args`.

### `Scanner`

The program asks the user for input while it is running.

Example:

```java
Scanner input = new Scanner(System.in);
String name = input.nextLine();
```

Both methods allow a program to receive data, but they work differently.

---

## 16. Checking `args.length` Before Accessing Arguments

A program should make sure that an argument exists before trying to access it.

For example:

```java id="s10314"
public class Main {
    public static void main(String[] args) {
        if (args.length > 0) {
            System.out.println("Hello, " + args[0]);
        }
    }
}
```

If we run the program without arguments, there is no attempt to access `args[0]`.

If we pass:

```text
Owais
```

Output:

```text id="o10314"
Hello, Owais
```

---

## 17. What Happens If an Argument Is Missing?

Consider:

```java id="s10315"
public class Main {
    public static void main(String[] args) {
        System.out.println(args[0]);
    }
}
```

If we run the program without providing an argument, `args[0]` does not exist.

The program will throw an:

```text
ArrayIndexOutOfBoundsException
```

This happens because the program is trying to access an array element that is not available.

## 18. Common Mistakes

### Mistake 1: Forgetting that arguments are Strings

Incorrect:

```java
int number = args[0];
```

Correct:

```java
int number = Integer.parseInt(args[0]);
```

---

### Mistake 2: Using the wrong index

If only one argument is provided:

```text
Owais
```

then only:

```java
args[0]
```

is available.

Trying to access:

```java
args[1]
```

will cause an error.

---

### Mistake 3: Forgetting that indexing starts from zero

For three arguments:

```text
args[0] → first
args[1] → second
args[2] → third
```

There is no `args[3]` when only three arguments are provided.

---

### Mistake 4: Forgetting numeric conversion

This:

```java
System.out.println(args[0] + args[1]);
```

performs String concatenation.

For example, if the arguments are:

```text
10 20
```

the output is:

```text
1020
```

To add the numbers, convert them first.

```java
int a = Integer.parseInt(args[0]);
int b = Integer.parseInt(args[1]);
```

Then:

```java
System.out.println(a + b);
```

Output:

```text
30
```

## 19. Simple Command-Line Calculator

We can combine command-line arguments with calculations.

Example:

```java id="s10316"
public class Main {
    public static void main(String[] args) {
        int a = Integer.parseInt(args[0]);
        int b = Integer.parseInt(args[1]);

        System.out.println("Addition = " + (a + b));
        System.out.println("Subtraction = " + (a - b));
        System.out.println("Multiplication = " + (a * b));
    }
}
```

If we pass:

```text
20 5
```

Output:

```text id="o10316"
Addition = 25
Subtraction = 15
Multiplication = 100
```

## 20. Command-Line Arguments in a Nutshell

The basic idea is:

```text
Command line
     ↓
args array
     ↓
String values
     ↓
Convert if necessary
     ↓
Use the values
```

For example:

```text
20 30
```

becomes:

```text
args[0] → "20"
args[1] → "30"
```

Then:

```java
Integer.parseInt(args[0])
```

converts `"20"` into the integer `20`.

## Key Points

* Command-line arguments are values passed to a program when it starts.
* They are stored in the `args` array of the `main()` method.
* `args` is a `String` array.
* The first argument is `args[0]`.
* The second argument is `args[1]`.
* `args.length` gives the number of arguments.
* Numeric arguments are initially received as Strings.
* `Integer.parseInt()` converts a String into an `int`.
* `Double.parseDouble()` converts a String into a `double`.
* Always make sure an argument exists before accessing its index.
* Command-line arguments are different from input received using `Scanner`.
* If a required argument is missing, accessing its index can cause an `ArrayIndexOutOfBoundsException`.
