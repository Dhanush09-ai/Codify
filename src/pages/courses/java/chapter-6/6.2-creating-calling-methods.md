# Chapter 6: Methods

## Section 2: Creating and Calling Methods

A method is a block of code that performs a specific task.

In the previous topic, we learned **what methods are**. Now, let's learn how to **create a method and call it** in a Java program.

---

## 1. Creating a Method

A simple method can be created using the following structure:

```java
static void methodName() {
    // statements
}
```

Here:

* `static` allows the method to be called from `main()`.
* `void` means the method does not return a value.
* `methodName` is the name of the method.
* `()` contains parameters. We will learn about parameters in the next topic.
* `{ }` contains the statements that the method performs.

For example:

```java id="m62a01"
static void greet() {
    System.out.println("Hello, Java!");
}
```

This creates a method named `greet`.

However, **creating a method does not execute it**.

The method must be called.

---

## 2. Calling a Method

To execute a method, write its name followed by parentheses:

```java
greet();
```

Example:

```java id="m62a02"
public class Main {

    static void greet() {
        System.out.println("Hello, Java!");
    }

    public static void main(String[] args) {
        greet();
    }
}
```

```output id="o62a02"
Hello, Java!
```

The statement:

```java
greet();
```

calls the `greet()` method.

---

## 3. Creating and Calling a Method Together

A complete example looks like this:

```java id="m62a03"
public class Main {

    static void showMessage() {
        System.out.println("Welcome to CODIFY!");
    }

    public static void main(String[] args) {
        showMessage();
    }
}
```

```output id="o62a03"
Welcome to CODIFY!
```

The method is created first, and then it is called from `main()`.

---

## 4. Calling a Method Multiple Times

A method can be called more than once.

```java id="m62a04"
public class Main {

    static void greet() {
        System.out.println("Hello!");
    }

    public static void main(String[] args) {
        greet();
        greet();
        greet();
    }
}
```

```output id="o62a04"
Hello!
Hello!
Hello!
```

Every time `greet()` is called, the statements inside the method execute.

This is one of the main benefits of methods: **we can reuse the same code**.

---

## 5. Calling Different Methods

A Java program can contain many methods.

```java id="m62a05"
public class Main {

    static void start() {
        System.out.println("Program started");
    }

    static void finish() {
        System.out.println("Program finished");
    }

    public static void main(String[] args) {
        start();
        finish();
    }
}
```

```output id="o62a05"
Program started
Program finished
```

Here, the program has two methods:

* `start()`
* `finish()`

The `main()` method calls them in order.

---

## 6. Order of Method Calls

Methods execute in the order in which they are called.

```java id="m62a06"
public class Main {

    static void first() {
        System.out.println("First");
    }

    static void second() {
        System.out.println("Second");
    }

    static void third() {
        System.out.println("Third");
    }

    public static void main(String[] args) {
        second();
        third();
        first();
    }
}
```

```output id="o62a06"
Second
Third
First
```

The order in which methods are **written** does not decide the execution order.

The order of the **method calls** decides it.

---

## 7. A Method Can Contain Multiple Statements

A method can contain more than one statement.

```java id="m62a07"
public class Main {

    static void studentInfo() {
        System.out.println("Name: Owais");
        System.out.println("Course: Java");
        System.out.println("Level: Beginner");
    }

    public static void main(String[] args) {
        studentInfo();
    }
}
```

```output id="o62a07"
Name: Owais
Course: Java
Level: Beginner
```

All the statements inside `studentInfo()` execute when the method is called.

---

## 8. Calling Methods from a Loop

A method can also be called inside a loop.

```java id="m62a08"
public class Main {

    static void greet() {
        System.out.println("Hello!");
    }

    public static void main(String[] args) {
        for (int i = 1; i <= 3; i++) {
            greet();
        }
    }
}
```

```output id="o62a08"
Hello!
Hello!
Hello!
```

The loop calls `greet()` three times.

This becomes especially useful when the same task needs to be performed repeatedly.

---

## 9. Method Naming

Method names should clearly describe what the method does.

Good examples:

```text
greet()
printMessage()
showMenu()
calculateTotal()
displayResult()
```

For multiple words, Java commonly uses **camelCase**:

```java
calculateTotal()
printStudentDetails()
showFinalResult()
```

A clear method name makes a program easier to understand.

---

## 10. Where Can We Create Methods?

Methods are created **inside a class**.

For example:

```java id="m62a09"
public class Main {

    static void message() {
        System.out.println("Learning Java");
    }

    public static void main(String[] args) {
        message();
    }
}
```

Here:

* `Main` is the class.
* `message()` is a method.
* `main()` is also a method.
* `message()` is called from `main()`.

Methods are not normally written inside another method.

---

## 11. The `main()` Method

The `main()` method is the starting point of a normal Java program.

For example:

```java id="m62a10"
public class Main {

    static void sayHello() {
        System.out.println("Hello!");
    }

    public static void main(String[] args) {
        sayHello();
    }
}
```

The execution starts from:

```java
main()
```

Then `main()` calls:

```java
sayHello();
```

The `sayHello()` method executes and prints the message.

---

## 12. Method Execution Flow

Consider this program:

```java id="m62a11"
public class Main {

    static void message() {
        System.out.println("Inside method");
    }

    public static void main(String[] args) {
        System.out.println("Before method");
        message();
        System.out.println("After method");
    }
}
```

```output id="o62a11"
Before method
Inside method
After method
```

The execution flow is:

```text
main()
   ↓
Print "Before method"
   ↓
Call message()
   ↓
Execute message()
   ↓
Return to main()
   ↓
Print "After method"
```

So, after a method finishes, execution continues from the statement after the method call.

---

## 13. Methods Help Avoid Repeated Code

Without methods, we may write the same statements many times:

```java
System.out.println("Welcome!");
System.out.println("Welcome!");
System.out.println("Welcome!");
```

Instead, we can create a method:

```java id="m62a12"
public class Main {

    static void welcome() {
        System.out.println("Welcome!");
    }

    public static void main(String[] args) {
        welcome();
        welcome();
        welcome();
    }
}
```

```output id="o62a12"
Welcome!
Welcome!
Welcome!
```

The method allows us to write the code once and reuse it.

## 14. Simple Method Structure

Remember this basic structure:

```java
static void methodName() {
    // statements
}
```

And call it using:

```java
methodName();
```

For example:

```java
static void display() {
    System.out.println("Java");
}
```

Call it:

```java
display();
```

Output:

```text
Java
```

## 15. Common Mistakes

### Mistake 1: Creating a Method but Not Calling It

```java
static void greet() {
    System.out.println("Hello!");
}
```

The method exists, but it will not execute unless it is called:

```java
greet();
```

---

### Mistake 2: Forgetting Parentheses

Incorrect:

```java
greet;
```

Correct:

```java
greet();
```

---

### Mistake 3: Writing a Method Inside Another Method

Incorrect:

```java
public static void main(String[] args) {

    static void greet() {
        System.out.println("Hello!");
    }
}
```

Methods should be declared inside the class, not inside another method.

Correct:

```java
public class Main {

    static void greet() {
        System.out.println("Hello!");
    }

    public static void main(String[] args) {
        greet();
    }
}
```

---

## 16. Creating vs Calling a Method

These two things are different.

### Creating a Method

```java
static void greet() {
    System.out.println("Hello!");
}
```

This defines what the method should do.

### Calling a Method

```java
greet();
```

This tells Java to execute the method.

### Easy way to remember

> **Create = define the task**
> **Call = perform the task**

---

## 17. Quick Example

Let's put everything together:

```java id="m62a13"
public class Main {

    static void morning() {
        System.out.println("Good morning!");
    }

    static void study() {
        System.out.println("Time to study Java.");
    }

    static void finish() {
        System.out.println("Study completed.");
    }

    public static void main(String[] args) {
        morning();
        study();
        finish();
    }
}
```

```output id="o62a13"
Good morning!
Time to study Java.
Study completed.
```

The methods are called in the same order as the statements inside `main()`.

---

## Key Points

* A method is a block of code that performs a specific task.
* A method is created inside a class.
* `static void` is commonly used for simple beginner methods.
* Creating a method does not execute it.
* A method is executed by calling its name followed by `()`.
* A method can be called multiple times.
* A program can contain multiple methods.
* Methods execute according to the order in which they are called.
* Methods help reduce repeated code.
* Clear method names make programs easier to understand.
* The `main()` method is the starting point of a normal Java program.
