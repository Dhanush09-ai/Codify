# Chapter 6: Methods

## Section 4: Return Values and `void`

In the previous topics, we learned how to create methods, call methods, and pass values using **parameters and arguments**.

Now we will learn how a method can **send a value back** to the place where it was called.

This is called a **return value**.

We will also learn about the `void` keyword.

---

## 1. What is a Return Value?

A method can perform a calculation or task and then send a result back to the caller.

For example:

```java id="r64a01"
static int add(int a, int b) {
    return a + b;
}
```

This method:

* Accepts two integers.
* Adds them.
* Sends the result back using `return`.
* Has `int` as its return type.

---

## 2. The `return` Keyword

The `return` keyword is used to send a value back from a method.

Example:

```java id="r64a02"
public class Main {

    static int add(int a, int b) {
        return a + b;
    }

    public static void main(String[] args) {
        int result = add(10, 20);
        System.out.println(result);
    }
}
```

```output id="o64a02"
30
```

The method calculates:

```text id="4f0j3a"
10 + 20 = 30
```

Then `return` sends `30` back to `main()`.

---

## 3. Understanding the Return Type

The word before the method name tells Java what type of value the method returns.

For example:

```java id="2i4t1p"
static int add(int a, int b)
```

Here:

```text
int
```

is the **return type**.

It means the method must return an integer value.

Other examples include:

```java id="e2b1lq"
static double calculate()
static String getName()
static boolean isEven()
```

The return type must match the type of value returned by the method.

---

## 4. Storing a Returned Value

A returned value can be stored in a variable.

```java id="r64a03"
public class Main {

    static int square(int number) {
        return number * number;
    }

    public static void main(String[] args) {
        int result = square(5);

        System.out.println("Square = " + result);
    }
}
```

```output id="o64a03"
Square = 25
```

Here:

```java id="6qk5a7"
square(5)
```

returns `25`.

That value is stored in:

```java id="2e7s9w"
result
```

---

## 5. Using a Returned Value Directly

We do not always need to store the returned value in a variable.

We can use it directly.

```java id="r64a04"
public class Main {

    static int add(int a, int b) {
        return a + b;
    }

    public static void main(String[] args) {
        System.out.println(add(15, 5));
    }
}
```

```output id="o64a04"
20
```

The method returns `20`, and `System.out.println()` prints it directly.

---

## 6. Returning Different Values

A method can return the result of different calculations.

```java id="r64a05"
public class Main {

    static int multiply(int a, int b) {
        return a * b;
    }

    static int subtract(int a, int b) {
        return a - b;
    }

    public static void main(String[] args) {
        int product = multiply(6, 4);
        int difference = subtract(10, 3);

        System.out.println("Product = " + product);
        System.out.println("Difference = " + difference);
    }
}
```

```output id="o64a05"
Product = 24
Difference = 7
```

Each method returns its own result.

---

## 7. `void` Methods

The `void` keyword means that a method **does not return a value**.

Example:

```java id="r64a06"
static void greet() {
    System.out.println("Hello!");
}
```

This method performs an action, but it does not send a value back.

Complete example:

```java id="r64a07"
public class Main {

    static void greet() {
        System.out.println("Hello!");
    }

    public static void main(String[] args) {
        greet();
    }
}
```

```output id="o64a07"
Hello!
```

---

## 8. `void` vs Return Value

Compare these two methods.

### `void` Method

```java id="r64a08"
static void greet() {
    System.out.println("Hello!");
}
```

It performs an action but returns no value.

### Method with Return Value

```java id="r64a09"
static int add(int a, int b) {
    return a + b;
}
```

It calculates a value and returns it.

### Simple Difference

| `void`                              | Return Value                         |
| ----------------------------------- | ------------------------------------ |
| Does not return a value             | Returns a value                      |
| Used for performing an action       | Used when a result is needed         |
| Does not need a value after calling | Returned value can be stored or used |
| Example: `static void greet()`      | Example: `static int add()`          |

## 9. A Return Value Can Be Used in a Calculation

A returned value can be used in another calculation.

```java id="r64a10"
public class Main {

    static int square(int number) {
        return number * number;
    }

    public static void main(String[] args) {
        int result = square(4) + square(3);

        System.out.println(result);
    }
}
```

```output id="o64a10"
25
```

Here:

```text id="0i2j1x"
square(4) = 16
square(3) = 9

16 + 9 = 25
```

## 12. Returning a `boolean`

A method can return `true` or `false`.

```java id="r64a13"
public class Main {

    static boolean isEven(int number) {
        return number % 2 == 0;
    }

    public static void main(String[] args) {
        System.out.println(isEven(10));
        System.out.println(isEven(7));
    }
}
```

```output id="o64a13"
true
false
```

The method returns:

* `true` when the number is even.
* `false` when the number is not even.

## 13. `return` Stops the Method

When Java reaches a `return` statement, the method finishes immediately.

Example:

```java id="r64a14"
public class Main {

    static int test() {
        System.out.println("Before return");
        return 10;
    }

    public static void main(String[] args) {
        int value = test();

        System.out.println(value);
    }
}
```

```output id="o64a14"
Before return
10
```

The statement after `return` inside the method would not execute.

For example:

```java
return 10;
```

ends the method at that point.

---

## 14. A Non-`void` Method Must Return a Value

If a method has a return type such as `int`, it must return a compatible value.

Correct:

```java id="r64a15"
static int getNumber() {
    return 10;
}
```

Incorrect:

```java id="6y1q7s"
static int getNumber() {
}
```

The second method does not return an `int`.

Java will give a compilation error.

---

## 15. The Returned Type Must Match

The return value should match the method's return type.

For example:

```java id="r64a16"
static int getNumber() {
    return 25;
}
```

Here, `25` is an integer, so it matches `int`.

Similarly:

```java id="r64a17"
static String getName() {
    return "Owais";
}
```

The returned string matches the `String` return type.

---

## 16. `void` Methods Can Use `return`

A `void` method cannot return a value, but it can use `return;` to stop execution early.

Example:

```java id="r64a18"
public class Main {

    static void checkNumber(int number) {
        if (number < 0) {
            return;
        }

        System.out.println("Number is positive or zero");
    }

    public static void main(String[] args) {
        checkNumber(-5);
        checkNumber(10);
    }
}
```

```output id="o64a18"
Number is positive or zero
```

When `-5` is passed, the method reaches:

```java id="rj6c3v"
return;
```

and stops.

There is no value after `return` because the method is `void`.

---

## 17. Parameters and Return Values Together

Parameters and return values can be used together.

```java id="r64a19"
public class Main {

    static int calculateArea(int length, int width) {
        return length * width;
    }

    public static void main(String[] args) {
        int area = calculateArea(10, 5);

        System.out.println("Area = " + area);
    }
}
```

```output id="o64a19"
Area = 50
```

The flow is:

```text id="6zq6e7"
10, 5
  ↓
calculateArea(10, 5)
  ↓
length × width
  ↓
10 × 5
  ↓
50
  ↓
return 50
  ↓
area = 50
```

This is a very common pattern in Java programs.

---

## 18. `void` or Return Value?

Use a `void` method when the method mainly needs to **perform an action**.

Example:

```java id="r64a20"
static void printWelcome() {
    System.out.println("Welcome!");
}
```

Use a return value when the method needs to **produce a result**.

Example:

```java id="r64a21"
static int calculateSum(int a, int b) {
    return a + b;
}
```

### Easy Rule

> **Need a result from the method? → Use a return value.**
> **Only need the method to perform an action? → `void` may be suitable.**

## 19. Quick Example

Let's combine parameters, calculations, and return values:

```java id="r64a22"
public class Main {

    static int add(int a, int b) {
        return a + b;
    }

    static int multiply(int a, int b) {
        return a * b;
    }

    static void showResult(int result) {
        System.out.println("Result = " + result);
    }

    public static void main(String[] args) {
        int sum = add(10, 5);
        int product = multiply(4, 3);

        showResult(sum);
        showResult(product);
    }
}
```

```output id="o64a22"
Result = 15
Result = 12
```

Here:

* `add()` returns an `int`.
* `multiply()` returns an `int`.
* `showResult()` is a `void` method.
* Parameters are used to pass values into the methods.
* Return values are used to send results back.

---

## Key Points

* A **return value** is a value sent back by a method.
* The `return` keyword sends a value back to the caller.
* The word before the method name is its **return type**.
* A method with return type `int` must return an `int`.
* `void` means the method does not return a value.
* A returned value can be stored in a variable.
* A returned value can also be used directly in an expression.
* Methods can return types such as `int`, `double`, `String`, and `boolean`.
* A `return` statement ends the method's execution.
* A non-`void` method must return a compatible value.
* Parameters pass values **into** a method.
* Return values send results **out of** a method.
