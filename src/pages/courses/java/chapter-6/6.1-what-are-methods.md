# Chapter 6: Methods

## Section 1: What are Methods?

As Java programs become larger, writing all the code inside the `main()` method can make the program difficult to understand.

Java provides **methods** to divide a program into smaller and reusable blocks of code.

A method can contain a set of statements that perform a particular task.

---

## 1. What is a Method?

A **method** is a block of code that performs a specific task.

For example, instead of writing the same code many times, we can put that code inside a method and call the method whenever we need it.

### Simple Example

```java id="m7k4px"
public class Main {

    static void greet() {
        System.out.println("Hello, Java!");
    }

    public static void main(String[] args) {
        greet();
    }
}
```

### Output

```output id="q3v8nd"
Hello, Java!
```

Here:

* `greet()` is a method.
* The method prints `"Hello, Java!"`.
* `greet();` calls the method.
* The method runs when it is called.

---

## 2. Why Do We Use Methods?

Methods help us organize our programs.

They provide several benefits:

* **Reusability** — use the same code multiple times.
* **Readability** — make programs easier to understand.
* **Organization** — divide a large program into smaller tasks.
* **Easy maintenance** — changes can be made in one place.

For example, instead of writing:

```java id="v6r2km"
System.out.println("Welcome!");
System.out.println("Welcome!");
System.out.println("Welcome!");
```

we can create a method:

```java id="x9p4ct"
static void welcome() {
    System.out.println("Welcome!");
}
```

Then call it whenever needed.

---

## 3. Creating a Method

A simple method can be written like this:

```java id="n5w8qb"
static void greet() {
    System.out.println("Hello!");
}
```

The important parts are:

```text id="a2m7vd"
static
   ↓
Method can be called from main in this example

void
   ↓
Method does not return a value

greet
   ↓
Method name

()
   ↓
Parameters go here

{ }
   ↓
Method body
```

We will learn more about `static`, parameters, and return values in the upcoming topics.

---

## 4. Calling a Method

Creating a method does not automatically execute it.

We need to **call** the method.

```java id="r4k7xm"
public class Main {

    static void greet() {
        System.out.println("Hello!");
    }

    public static void main(String[] args) {
        greet();
    }
}
```

### Output

```output id="t8c3qp"
Hello!
```

The statement:

```java id="z6m2nd"
greet();
```

calls the `greet()` method.

---

## 5. Calling a Method Multiple Times

One of the biggest advantages of methods is that we can call the same method multiple times.

```java id="p5v8kr"
public class Main {

    static void greet() {
        System.out.println("Hello!");
    }

    public static void main(String[] args) {
        greet();
        greet();
        greet();
    }
}
```

### Output

```output id="w3q6mx"
Hello!
Hello!
Hello!
```

We wrote the method only once, but we used it three times.

---

## 6. Method with Multiple Statements

A method can contain more than one statement.

```java id="c8n4yp"
public class Main {

    static void showMessage() {
        System.out.println("Welcome to CODIFY!");
        System.out.println("Learn Java step by step.");
    }

    public static void main(String[] args) {
        showMessage();
    }
}
```

### Output

```output id="j7m2vd"
Welcome to CODIFY!
Learn Java step by step.
```

All statements inside the method execute when the method is called.

---

## 7. Method Execution Flow

Consider this program:

```java id="s4k9bx"
public class Main {

    static void greet() {
        System.out.println("Hello!");
    }

    public static void main(String[] args) {
        System.out.println("Start");
        greet();
        System.out.println("End");
    }
}
```

### Output

```output id="e6p3qw"
Start
Hello!
End
```

The execution happens like this:

```text id="c7m5za"
main()
  ↓
Print "Start"
  ↓
Call greet()
  ↓
greet() runs
  ↓
Print "Hello!"
  ↓
Return to main()
  ↓
Print "End"
```

When the method finishes, execution returns to the place where it was called.

## 8. Methods for Different Tasks

A program can contain multiple methods.

For example:

```java id="h2v7nk"
public class Main {

    static void greet() {
        System.out.println("Hello!");
    }

    static void showCourse() {
        System.out.println("Java for Beginners");
    }

    public static void main(String[] args) {
        greet();
        showCourse();
    }
}
```

### Output

```output id="f9r4xc"
Hello!
Java for Beginners
```

Each method performs a different task.

---

## 9. Methods Help Avoid Repeated Code

Suppose we need to print the same message several times.

Without a method:

```java id="q8m3wp"
public class Main {
    public static void main(String[] args) {
        System.out.println("Welcome!");
        System.out.println("Welcome!");
        System.out.println("Welcome!");
    }
}
```

With a method:

```java id="b5x7kd"
public class Main {

    static void welcome() {
        System.out.println("Welcome!");
    }

    public static void main(String[] args) {
        welcome();
        welcome();
        welcome();
    }
}
```

Both programs produce:

```output id="n6t2vq"
Welcome!
Welcome!
Welcome!
```

The second approach makes the repeated task easier to manage.

---

## 10. Method Naming

A method should have a meaningful name that describes what it does.

Good examples:

```text id="p7k2mc"
greet()
printMessage()
calculateSum()
showMenu()
displayResult()
```

Avoid unclear names such as:

```text id="w4n8qx"
abc()
xyz()
doSomething()
```

A meaningful name makes the program easier to understand.

---

## 11. Methods Can Be Called from Loops

A method can also be called inside a loop.

```java id="r9m4bv"
public class Main {

    static void greet() {
        System.out.println("Hello!");
    }

    public static void main(String[] args) {
        for (int i = 1; i <= 3; i++) {
            greet();
        }
    }
}
```

### Output

```output id="c5q8zn"
Hello!
Hello!
Hello!
```

The loop calls the method three times.

---

## 12. Methods and `main()`

The `main()` method is the starting point of a Java application.

For example:

```java id="x6p3kt"
public class Main {
    public static void main(String[] args) {
        greet();
    }

    static void greet() {
        System.out.println("Hello, Java!");
    }
}
```

### Output

```output id="m8v2qd"
Hello, Java!
```

The program starts from `main()` and then calls `greet()`.

---

## 13. A Method Can Perform a Calculation

A method does not have to print something.

It can also perform a task.

```java id="k4r7xp"
public class Main {

    static void calculateSum() {
        int a = 10;
        int b = 20;
        int sum = a + b;

        System.out.println("Sum = " + sum);
    }

    public static void main(String[] args) {
        calculateSum();
    }
}
```

### Output

```output id="v9m3tc"
Sum = 30
```

The method performs the calculation when it is called.

---

## 14. Method Body

The statements between `{` and `}` form the **method body**.

For example:

```java id="q5x8nb"
static void greet() {
    System.out.println("Hello!");
}
```

Here:

```text id="m2v7kp"
static void greet()
        ↓
Method declaration

{
    System.out.println("Hello!");
}
        ↓
Method body
```

The method body contains the instructions that should execute when the method is called.

---

## 15. A Method Does Not Run Automatically

Consider:

```java id="d8k4yr"
public class Main {

    static void greet() {
        System.out.println("Hello!");
    }

    public static void main(String[] args) {
        System.out.println("Program started");
    }
}
```

### Output

```output id="s6p2qm"
Program started
```

The `greet()` method is created but never called.

Therefore, `"Hello!"` is not printed.

To execute it, we need:

```java id="j3v9cx"
greet();
```

## 16. Methods Make Large Programs Easier

Imagine a program that performs several tasks:

```text id="x7m4qb"
Main Program
    │
    ├── login()
    │
    ├── showMenu()
    │
    ├── calculate()
    │
    └── displayResult()
```

Each method handles a particular task.

This makes a large program easier to read and understand.

## 17. Basic Method Structure

For now, remember this basic structure:

```java id="c9w5nk"
static void methodName() {
    // statements
}
```

And to call it:

```java id="h6r2mp"
methodName();
```

Example:

```java id="v4k8xd"
public class Main {

    static void sayHello() {
        System.out.println("Hello!");
    }

    public static void main(String[] args) {
        sayHello();
    }
}
```

### Output

```output id="q7m3zp"
Hello!
```
