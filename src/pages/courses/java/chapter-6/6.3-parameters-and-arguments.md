# Chapter 6: Methods

## Section 3: Parameters and Arguments

In the previous topic, we learned how to **create and call methods**.

Sometimes, a method needs some information to perform its task.

For example, if we create a method to greet a student, we may want to give the student's name to the method.

This is where **parameters and arguments** are used.

---

## 1. What are Parameters?

A **parameter** is a variable written inside the parentheses of a method definition.

For example:

```java id="p63a01"
static void greet(String name) {
    System.out.println("Hello, " + name);
}
```

Here:

```java id="n63a01"
String name
```

is a **parameter**.

The parameter receives a value when the method is called.

---

## 2. What are Arguments?

An **argument** is the actual value passed to a method when we call it.

Example:

```java id="p63a02"
greet("Owais");
```

Here:

```text id="a63a02"
"Owais"
```

is the **argument**.

So:

* **Parameter** → variable in the method definition
* **Argument** → actual value passed during the method call

### Easy way to remember

> **Parameter = receives the value**
> **Argument = sends the value**

---

## 3. Simple Example

Let's create a method that accepts a name.

```java id="p63a03"
public class Main {

    static void greet(String name) {
        System.out.println("Hello, " + name);
    }

    public static void main(String[] args) {
        greet("Owais");
    }
}
```

```output id="o63a03"
Hello, Owais
```

Here:

* `String name` → parameter
* `"Owais"` → argument
* `greet("Owais")` → method call

---

## 4. Why Do We Need Parameters?

Parameters allow a method to work with different values.

Without parameters, we might need separate methods for different names:

```java id="p63a04"
static void greetOwais() {
    System.out.println("Hello, Owais");
}

static void greetAli() {
    System.out.println("Hello, Ali");
}
```

This is unnecessary.

Instead, we can create one method:

```java id="p63a05"
static void greet(String name) {
    System.out.println("Hello, " + name);
}
```

Then we can use different arguments:

```java id="p63a06"
greet("Owais");
greet("Ali");
greet("Sara");
```

Output:

```output id="o63a06"
Hello, Owais
Hello, Ali
Hello, Sara
```

One method can now work with different values.

---

## 5. Method with One Parameter

A method can have one parameter.

```java id="p63a07"
public class Main {

    static void square(int number) {
        System.out.println(number * number);
    }

    public static void main(String[] args) {
        square(5);
    }
}
```

```output id="o63a07"
25
```

Here:

```java
int number
```

is the parameter.

And:

```java
5
```

is the argument.

The value `5` is passed to `number`.

---

## 6. Different Arguments

The same method can be called with different arguments.

```java id="p63a08"
public class Main {

    static void square(int number) {
        System.out.println(number * number);
    }

    public static void main(String[] args) {
        square(3);
        square(5);
        square(10);
    }
}
```

```output id="o63a08"
9
25
100
```

The method performs the same task for each value.

---

## 7. Method with Two Parameters

A method can have more than one parameter.

For example:

```java id="p63a09"
static void add(int a, int b) {
    System.out.println(a + b);
}
```

Here the method has two parameters:

* `a`
* `b`

We can call it like this:

```java id="p63a10"
add(10, 20);
```

Here:

* `10` is passed to `a`
* `20` is passed to `b`

Complete program:

```java id="p63a11"
public class Main {

    static void add(int a, int b) {
        System.out.println(a + b);
    }

    public static void main(String[] args) {
        add(10, 20);
    }
}
```

```output id="o63a11"
30
```

---

## 8. Multiple Parameters

When a method has multiple parameters, the arguments are matched according to their position.

```java id="p63a12"
public class Main {

    static void student(String name, int age) {
        System.out.println("Name: " + name);
        System.out.println("Age: " + age);
    }

    public static void main(String[] args) {
        student("Owais", 16);
    }
}
```

```output id="o63a12"
Name: Owais
Age: 16
```

Here:

```text id="x63a12"
"Owais" → name
16      → age
```

The first argument goes to the first parameter, and the second argument goes to the second parameter.

---

## 9. Parameter Order Matters

The order of parameters and arguments must match.

For example:

```java id="p63a13"
static void display(String name, int age) {
    System.out.println(name);
    System.out.println(age);
}
```

Correct:

```java id="p63a14"
display("Owais", 16);
```

Here:

```text id="x63a14"
"Owais" → String name
16      → int age
```

The data types also need to be compatible with the parameters.

---

## 10. Parameters Can Have Different Data Types

Parameters can use different Java data types.

For example:

```java id="p63a15"
public class Main {

    static void showDetails(String name, int marks) {
        System.out.println("Student: " + name);
        System.out.println("Marks: " + marks);
    }

    public static void main(String[] args) {
        showDetails("Owais", 95);
    }
}
```

```output id="o63a15"
Student: Owais
Marks: 95
```

Here:

* `String name` accepts a string.
* `int marks` accepts an integer.

---

## 11. Passing Variables as Arguments

Arguments do not have to be direct values.

We can also pass variables.

```java id="p63a16"
public class Main {

    static void square(int number) {
        System.out.println(number * number);
    }

    public static void main(String[] args) {
        int value = 7;

        square(value);
    }
}
```

```output id="o63a16"
49
```

Here:

```java
square(value);
```

passes the value stored in `value` to the parameter `number`.

---

## 12. Passing Expressions as Arguments

We can also pass an expression as an argument.

```java id="p63a17"
public class Main {

    static void square(int number) {
        System.out.println(number * number);
    }

    public static void main(String[] args) {
        square(3 + 2);
    }
}
```

```output id="o63a17"
25
```

First:

```text
3 + 2 = 5
```

Then `5` is passed to the method.

So the method calculates:

```text
5 × 5 = 25
```

---

## 13. Parameters Are Local to the Method

A parameter behaves like a local variable inside the method.

For example:

```java id="p63a18"
public class Main {

    static void showNumber(int number) {
        System.out.println(number);
    }

    public static void main(String[] args) {
        showNumber(50);
    }
}
```

```output id="o63a18"
50
```

The parameter `number` is available inside `showNumber()`.

It cannot simply be used outside the method as if it were a variable declared in `main()`.

---

## 14. Using Parameters in Calculations

Parameters are especially useful when performing calculations.

```java id="p63a19"
public class Main {

    static void rectangleArea(int length, int width) {
        int area = length * width;
        System.out.println("Area = " + area);
    }

    public static void main(String[] args) {
        rectangleArea(10, 5);
    }
}
```

```output id="o63a19"
Area = 50
```

Here:

```text id="j63a19"
length = 10
width  = 5
```

Therefore:

```text
area = 10 × 5
     = 50
```

## 15. Reusing a Method with Different Values

One of the biggest benefits of parameters is **reusability**.

```java id="p63a20"
public class Main {

    static void rectangleArea(int length, int width) {
        int area = length * width;
        System.out.println("Area = " + area);
    }

    public static void main(String[] args) {
        rectangleArea(10, 5);
        rectangleArea(4, 3);
        rectangleArea(8, 2);
    }
}
```

```output id="o63a20"
Area = 50
Area = 12
Area = 16
```

The same method works with different values.

## 17. Boolean Parameters

A method can also accept a `boolean` parameter.

```java id="p63a22"
public class Main {

    static void checkStatus(boolean active) {
        if (active) {
            System.out.println("Account is active");
        } else {
            System.out.println("Account is inactive");
        }
    }

    public static void main(String[] args) {
        checkStatus(true);
        checkStatus(false);
    }
}
```

```output id="o63a22"
Account is active
Account is inactive
```

The argument `true` is passed to `active` during the first call, and `false` during the second call.

## 18. Parameter vs Argument

The difference is easy to remember:

| Parameter                    | Argument                   |
| ---------------------------- | -------------------------- |
| Written in method definition | Written in method call     |
| Acts like a variable         | Actual value or expression |
| Receives the value           | Provides the value         |
| Example: `int number`        | Example: `10`              |

Example:

```java id="p63a23"
static void square(int number) {
    System.out.println(number * number);
}
```

Here:

```text
int number → Parameter
```

When we call:

```java
square(10);
```

```text
10 → Argument
```

## 19. Common Mistakes

### Mistake 1: Giving the Wrong Number of Arguments

Suppose we have:

```java
static void add(int a, int b) {
    System.out.println(a + b);
}
```

This requires **two arguments**.

Correct:

```java
add(10, 20);
```

Incorrect:

```java
add(10);
```

---

### Mistake 2: Using Incompatible Data Types

Suppose:

```java
static void showAge(int age) {
    System.out.println(age);
}
```

A number should be passed:

```java
showAge(16);
```

Do not pass a string where an `int` is required:

```java
showAge("sixteen");
```

---

### Mistake 3: Mixing Up the Order

Suppose:

```java
static void student(String name, int age) {
    System.out.println(name);
    System.out.println(age);
}
```

Correct:

```java
student("Owais", 16);
```

The first argument matches the first parameter, and the second argument matches the second parameter.

---

## 20. Quick Example

Let's combine the concepts:

```java id="p63a24"
public class Main {

    static void studentInfo(String name, int marks) {
        System.out.println("Name: " + name);
        System.out.println("Marks: " + marks);
    }

    public static void main(String[] args) {
        studentInfo("Owais", 95);
        studentInfo("Sara", 88);
    }
}
```

```output id="o63a24"
Name: Owais
Marks: 95
Name: Sara
Marks: 88
```

The same method is reused for two different students by passing different arguments.

---

## Key Points

* A **parameter** is a variable written in a method definition.
* An **argument** is the actual value passed when calling a method.
* Parameters allow methods to work with different values.
* A method can have one or more parameters.
* Arguments are matched with parameters according to their position.
* The argument's data type must be compatible with the parameter.
* Variables can also be passed as arguments.
* Expressions can also be passed as arguments.
* Parameters behave like local variables inside the method.
* Parameters make methods more reusable.
* Parameters and arguments are different, but they work together.
