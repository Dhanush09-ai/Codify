# Chapter 6: Methods

## Section 5: Method Overloading

In the previous topics, we learned how to create methods, use parameters and arguments, and return values.

Sometimes, we want to create **multiple methods with the same name**, but each method should work with different types or numbers of parameters.

This is called **method overloading**.

---

## 1. What is Method Overloading?

**Method overloading** means creating multiple methods with the **same name** but with **different parameters**.

For example:

```java id="m65101"
static int add(int a, int b) {
    return a + b;
}

static int add(int a, int b, int c) {
    return a + b + c;
}
```

Both methods are named:

```text id="x65101"
add()
```

But they have different numbers of parameters.

* First method → 2 parameters
* Second method → 3 parameters

Java can determine which method to use based on the arguments provided.

---

## 2. Simple Example

```java id="m65102"
public class Main {

    static void greet(String name) {
        System.out.println("Hello, " + name);
    }

    static void greet(String name, int age) {
        System.out.println("Hello, " + name);
        System.out.println("Age: " + age);
    }

    public static void main(String[] args) {
        greet("Owais");
        greet("Sara", 16);
    }
}
```

```output id="o65102"
Hello, Owais
Hello, Sara
Age: 16
```

Both methods are named `greet()`.

Java chooses the correct method based on the arguments.

---

## 3. Why Use Method Overloading?

Method overloading allows us to use the **same meaningful method name** for related tasks.

Without overloading, we might create names like:

```text id="x65103"
addTwoNumbers()
addThreeNumbers()
```

With overloading, we can simply use:

```text id="x65104"
add()
add()
```

The parameters tell Java which version to use.

This can make related methods easier to understand and use.

---

## 4. Overloading by Number of Parameters

One way to overload a method is to change the **number of parameters**.

Example:

```java id="m65103"
public class Main {

    static int add(int a, int b) {
        return a + b;
    }

    static int add(int a, int b, int c) {
        return a + b + c;
    }

    public static void main(String[] args) {
        System.out.println(add(10, 20));
        System.out.println(add(10, 20, 30));
    }
}
```

```output id="o65103"
30
60
```

Here:

```text id="x65103"
add(10, 20)       → two-parameter version
add(10, 20, 30)   → three-parameter version
```

---

## 5. Overloading by Different Parameter Types

Methods can also be overloaded by changing the **data types of parameters**.

```java id="m65104"
public class Main {

    static void display(int number) {
        System.out.println("Integer: " + number);
    }

    static void display(double number) {
        System.out.println("Double: " + number);
    }

    public static void main(String[] args) {
        display(10);
        display(10.5);
    }
}
```

```output id="o65104"
Integer: 10
Double: 10.5
```

Here:

```text id="x65104"
display(int)     → called for 10
display(double)  → called for 10.5
```

The parameter types are different, so Java can distinguish the methods.

---

## 6. Overloading with Different Types and Number of Parameters

We can also change both the number and types of parameters.

```java id="m65105"
public class Main {

    static void show(int number) {
        System.out.println("Number: " + number);
    }

    static void show(String text) {
        System.out.println("Text: " + text);
    }

    static void show(String text, int number) {
        System.out.println(text + ": " + number);
    }

    public static void main(String[] args) {
        show(10);
        show("Age");
        show("Marks", 95);
    }
}
```

```output id="o65105"
Number: 10
Text: Age
Marks: 95
```

There are three versions of `show()`.

Java selects the appropriate version based on the arguments.

---

## 7. How Java Selects the Method

Consider:

```java id="m65106"
static void print(int number) {
    System.out.println("Integer");
}

static void print(String text) {
    System.out.println("String");
}
```

If we call:

```java id="m65107"
print(10);
```

Java selects:

```java id="m65108"
print(int)
```

If we call:

```java id="m65109"
print("Hello");
```

Java selects:

```java id="m65110"
print(String)
```

So Java looks at the **arguments and their types** to determine which overloaded method should be called.

---

## 8. Method Overloading with Return Values

Overloaded methods can return values.

```java id="m65111"
public class Main {

    static int multiply(int a, int b) {
        return a * b;
    }

    static int multiply(int a, int b, int c) {
        return a * b * c;
    }

    public static void main(String[] args) {
        System.out.println(multiply(2, 3));
        System.out.println(multiply(2, 3, 4));
    }
}
```

```output id="o65111"
6
24
```

The first method multiplies two numbers.

The second method multiplies three numbers.

---

## 9. Return Type Alone Cannot Overload a Method

Changing **only the return type** is not enough to overload a method.

For example, this is not allowed:

```java id="m65112"
static int getNumber() {
    return 10;
}

static double getNumber() {
    return 10.5;
}
```

Both methods have:

```text id="x65112"
getNumber()
```

with no parameters.

The only difference is the return type.

Java cannot overload methods based only on the return type.

The parameter list must be different.

---

## 10. Valid Method Overloading

These are valid overloaded methods:

```java id="m65113"
static void show(int number) {
    System.out.println(number);
}

static void show(double number) {
    System.out.println(number);
}
```

The parameter types are different.

Another valid example:

```java id="m65114"
static void show(int a, int b) {
    System.out.println(a + b);
}

static void show(int a, int b, int c) {
    System.out.println(a + b + c);
}
```

The number of parameters is different.

---

## 11. Method Overloading vs Normal Methods

Suppose we have:

```java id="m65115"
static void greet() {
    System.out.println("Hello!");
}
```

This is a normal method.

Now we can overload it:

```java id="m65116"
static void greet(String name) {
    System.out.println("Hello, " + name);
}
```

And:

```java id="m65117"
static void greet(String name, int age) {
    System.out.println("Hello, " + name);
    System.out.println("Age: " + age);
}
```

Now there are three versions of `greet()`.

---

## 12. Calling Overloaded Methods

Let's see all three versions together:

```java id="m65118"
public class Main {

    static void greet() {
        System.out.println("Hello!");
    }

    static void greet(String name) {
        System.out.println("Hello, " + name);
    }

    static void greet(String name, int age) {
        System.out.println("Hello, " + name);
        System.out.println("Age: " + age);
    }

    public static void main(String[] args) {
        greet();
        greet("Owais");
        greet("Sara", 16);
    }
}
```

```output id="o65118"
Hello!
Hello, Owais
Hello, Sara
Age: 16
```

The method name remains the same, but the parameters are different.

---

## 13. Method Overloading with Different Data Types

Here is another example:

```java id="m65119"
public class Main {

    static int square(int number) {
        return number * number;
    }

    static double square(double number) {
        return number * number;
    }

    public static void main(String[] args) {
        System.out.println(square(5));
        System.out.println(square(2.5));
    }
}
```

```output id="o65119"
25
6.25
```

The first method works with `int`.

The second method works with `double`.

## 14. Common Mistakes

### Mistake 1: Changing Only the Return Type

This does **not** create valid overloading:

```java id="0e7xq3"
static int test() {
    return 10;
}

static double test() {
    return 10.5;
}
```

The parameter lists are the same.

---

### Mistake 2: Creating Exactly the Same Method

These two methods are also not valid together:

```java id="q3s6j7"
static void show(int number) {
    System.out.println(number);
}

static void show(int number) {
    System.out.println(number);
}
```

They have the same:

* Method name
* Number of parameters
* Parameter types

They are the same method signature for overloading purposes.

---

### Mistake 3: Confusing Arguments with Parameters

In:

```java id="8j0m2v"
static void show(int number) {
    System.out.println(number);
}
```

`int number` is the **parameter**.

In:

```java id="m4r6x8"
show(10);
```

`10` is the **argument**.

---

## 15. Advantages of Method Overloading

Method overloading can make programs easier to use.

### 1. Same Name for Related Tasks

Related operations can use the same method name.

### 2. Better Readability

Instead of remembering many different method names, we can use one meaningful name.

### 3. Reusability

Different versions of a method can handle different types or numbers of values.

### 4. Flexible Method Calls

The caller can provide different arguments depending on what is needed.

---

## 16. Quick Example

Let's combine everything:

```java id="m65120"
public class Main {

    static int add(int a, int b) {
        return a + b;
    }

    static int add(int a, int b, int c) {
        return a + b + c;
    }

    static double add(double a, double b) {
        return a + b;
    }

    public static void main(String[] args) {
        System.out.println(add(10, 20));
        System.out.println(add(10, 20, 30));
        System.out.println(add(2.5, 3.5));
    }
}
```

```output id="o65120"
30
60
6.0
```

Here, all three methods have the same name:

```text id="x65120"
add()
```

But they have different parameter lists.

Java selects the appropriate method based on the arguments.

---

## Key Points

* **Method overloading** means having multiple methods with the same name but different parameters.
* Methods can be overloaded by changing the **number of parameters**.
* Methods can also be overloaded by changing the **parameter types**.
* Java uses the arguments to select the appropriate overloaded method.
* The return type alone cannot be used for method overloading.
* Overloaded methods can have return values.
* Overloading is useful for related tasks that need the same method name.
* The parameter list must be different for valid overloading.
* Parameters are part of the method definition.
* Arguments are the actual values passed during a method call.
